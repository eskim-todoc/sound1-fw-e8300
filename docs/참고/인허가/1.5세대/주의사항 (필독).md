1.5세대에서 사용했던 주요 IC들은 다음과 같다.
- 메인 칩셋 : Ezairo8300
- BLE 칩셋 : nRF51822
- FPGA
- TX PMIC (링크 파워 IC)
- 가속도 센서 (더블 클릭, 사용자 이벤트 용도)

사운드1에서 사용하는 주요 IC들은 다음과 같다.
- 메인 칩셋 : Ezairo8300
- BLE 칩셋 : nRF51822 -> 블루투스 콤보 : QCC5181
- FPGA
- TX PMIC (링크 파워 IC)
- 가속도 센서 -> 터치 센서 (롱 터치 이벤트로 변경)

변경 사항은 BLE 칩셋에서 블루투스 콤보 칩셋으로 변경된 것과, 가속도 센서에서 터치 센서로 변경된 점이다.
또한, 기능적으로도 배터리 체크를 1.5세대에서는 Ezairo8300이 했는데, 사운드1에서는 QCC5182이 하고 SPI 통신으로 Ezairo8300에게 알려주는 방식이다.
배터리 뿐만 아니라, Charger 연결/충전 상태 또한 QCC->EZ8300으로 SPI 통신으로 알려준다.

그리고 1.5세대에서 사운드1으로 오면서 제거된 사항은 대표로 아래와 같아.
- 이어피스 연결
- USB 충전 기능

이 외에 추가된 기능이나 제거된 기능도 있긴 할 건데, 다 기억나는 상황은 아니라 직접 분석할 필요도 있어.
