# QCC 자료 추가 위치 관리

QCC 자료를 받았을 때 **어떤 문서의 어디를 채워야 하는지** 이 파일에서 찾는다. 폴더별로 목록을 나누지 않고, 앞으로 발견되는 추가 위치도 여기에 모은다.

최종 확인: 2026-10-02, I/A/D/T 안내를 간소화한 뒤 저장된 설계 출력 SUVC/SITC/SSTC의 안내 셀 외 본문, 제목, ID와 QCC 추가 위치가 그대로임을 확인했다. 아래 위치는 유지한다. 필수성능시험 기준서는 후속 지시에 따라 수정하지 않았다. 본문/제목 번호의 최근 확인 범위는 아래 이력을 따른다. 최초 확인 범위는 `DHF/03_설계 출력`의 펌웨어 문서 6종과 필수성능시험 기준서 1종이다. 설계 계획/설계 입력 등 다른 폴더까지 전수 확인했다는 뜻은 아니다. 해당 폴더를 작업할 때 필요한 항목을 이 목록에 추가한다.

현재 E8300 측 SPI/I2S/GPIO 연계는 문서에 반영되어 있다. **QCC 내부 설계와 내부 시험은 자료 대기 중**이다. 아래의 ‘반영 완료’는 문서에 내용을 넣고 연결을 확인한 상태를 뜻하며, 실제 시험 통과와 구분한다.

2026-10-02 예상 테스트 입출력 자료를 `DHF/04_설계 검증`에 추가했다. 새 MD의 QCC 후속 위치는 아래 6절에서 관리한다. 기존 Word/Excel은 이번 작업에서 수정하지 않아 위 제목/시트/행 위치는 유지된다.

### QCC 단독 시험

아래 ID는 각각 `SW-FW-SYS-Test-ID-`, `SW-FW-RID-`, `SYS-RID-FW-` 뒤의 번호다. 본문 B열이 시험 ID, E열이 SW 요구사항, F열이 SYS 요구사항이다.

## 4. 자료 반영과 위치 변경 시 갱신 방법

1. 대상 파일을 수정하기 전에 이 목록에서 파일/제목/ID를 찾는다. 없으면 기존 번호와 겹치지 않는 관리 항목을 추가한다.
2. 파일을 수정한 뒤 저장된 결과에서 제목, 시트와 ID를 다시 찾는다. 파일명/폴더/절/행이 바뀌면 위 위치와 링크를 같은 작업에서 고친다. 행이 그대로여도 식별자의 의미가 바뀌지 않았는지 확인한다.
3. 상태는 `자료 대기`, `반영 중`, `반영 완료`, `영향 없음`, `통합/삭제`로 관리한다. 부분 반영이면 무엇이 남았는지 적는다. 완료 시 수령 자료 이름/버전, 반영 위치와 관련 시험 ID를 적는다.
4. 같은 항목이 옮겨졌으면 관리 항목 이름은 유지한다. 합치거나 삭제한 항목은 조용히 지우지 않고 대체 항목/제외 이유를 남긴다. 위치 미확인이면 추측하지 말고 `위치 재확인 필요`로 표시한다.
5. Word 변경 추적과 Excel 비교 시트를 보존한다. 문서 반영 완료와 시험 실행/통과 여부를 구분한다. 실제 결과 보고서가 추가되면 그 파일과 항목도 이 목록에 연결한다.
6. 마지막에 관련 파일 링크와 검색 기준이 유효한지 확인하고 확인일/이력을 갱신한다. 무관한 문서 작업에는 이 목록 전체 재검사를 강제하지 않는다.
