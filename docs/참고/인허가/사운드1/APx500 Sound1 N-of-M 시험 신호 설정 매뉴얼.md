# APx500 Sound1 N-of-M 시험 신호 설정 매뉴얼

APx525 B Series의 APx500에서 여러 주파수를 **한 개의 합성음으로 동시에 출력**하는 방법이다. [WAV와 조합별 입력표](APx%20NofM%20합성%20파형/파형%20목록.md)를 함께 제공한다. 조합을 고른 뒤 3절의 WAV 재생 방법을 따르면 된다.

> [!IMPORTANT]
> 기본 맵 1은 **CIS / 50µs / 3프레임 → 최대 8자극/ms**다. **NofM / 14µs / 2프레임 → 12자극 슬롯/ms**는 기본 맵 3이다. 16톤 입력은 NofM 선택 후보를 만들며, 12슬롯/ms는 별개의 전송 용량이다. 제공 파일은 음향 입력이지 전극 출력을 강제하는 패킷 파일이 아니다.

문서의 음압은 **APx 표시 보정 −8.293dB가 적용된 표시값**이다. 물리 음압과의 관계는 ‘실제 음압 = 표시 음압 + 8.293dB’이다. WAV의 dBFS와 마이크의 dB SPL도 구분한다.

## 1. 시험 조합 선택

**16채널씩 묶고 시작점을 8채널씩 이동**한다. 전극 번호는 1부터 시작하며 양 끝을 포함한다. 따라서 가운데 조합은 8~24(17개)가 아니라 **9~24(16개)**다.

| 조합 | 목표 전극 대역 | 톤 수 | 파일 |
|---|---|---:|---|
| A | 1~16 | 16 | [ch01-16.wav](APx%20NofM%20합성%20파형/ch01-16.wav) |
| B | 9~24 | 16 | [ch09-24.wav](APx%20NofM%20합성%20파형/ch09-24.wav) |
| C | 17~32 | 16 | [ch17-32.wav](APx%20NofM%20합성%20파형/ch17-32.wav) |

A·B는 9~16, B·C는 17~24의 8채널이 겹친다. A·C는 겹치지 않으며 세 조합으로 전체 32대역을 다룬다. 각 조합은 별도 WAV로 선택해 재생한다. 한 파일 안에서 조합을 자동 전환하지 않는다.

**현재 시험에는 위 16톤 WAV 3개를 사용**한다. 출력 방법과 각 조합의 16행 입력표는 [파형 목록](APx%20NofM%20합성%20파형/파형%20목록.md)에 있다.

## 2. Sound1 맵과 1ms 전송 조건

### 기본 맵 확인

현재 작업 트리에서 첫 번째 내부기용으로 생성하는 기본값이다. 장치에 이미 저장된 맵은 다를 수 있으므로 실제 선택 맵의 전략·펄스폭·채널 배정을 확인한다.

| 기본 프로그램 | 전략 | 위상당 펄스폭 | 채널당 프레임 | 1ms 전송 용량 |
|---|---|---:|---:|---:|
| 1 | CIS | 50µs | 3 | 최대 8자극 |
| 3 | NofM | 14µs | 2 | 12자극 슬롯 |

CM3 계산은 ‘소요시간 = 2 × 펄스폭 + 4 + 10’이며, ‘소요시간 < 41 × 프레임 수’를 만족하는 최소 프레임 수를 택한다. 50µs는 114µs → 3프레임, 14µs는 42µs → 2프레임이다. 1ms 버퍼의 24프레임을 3 또는 2로 나눈 결과가 8과 12다. 경계 비교는 ≤가 아닌 **<**다.

출처: [기본 맵](../../../../src/2__cm3/Gen1_5/FS/ci_map.c), [CM3 프레임 계산](../../../../src/2__cm3/Cortex-M3-src/signalProcessing/stimulationParaCal.c), [전송·선택 수 상수](../../../../src/1__cfx/signalProcessing/definitionsForAlgorithm.h).

### NofM은 16개를 선택하고 12슬롯씩 전송한다

현재 df_MaxNum_NofM은 16이다. 선택된 16개를 교차 배치한 뒤 기본 맵 3에서는 다음처럼 전송한다. 아래 숫자는 **전극 번호가 아니라 교차 배치된 목록의 위치**다.

| 구간 | 전송 목록 위치 | 처리 |
|---|---|---|
| 첫 1ms | 1~12 | 새 목록 계산, 전송 인덱스 초기화 |
| 다음 1ms | 13~16, 1~8 | 나머지 4개 뒤 앞의 8개 재전송 |
| 그다음 1ms | 새 목록 1~12 | 재계산 후 인덱스 초기화 |

stimulationStrategy_NofM의 2단계 실행과 stimulationStrategy_NofM_PCM_Write의 순환 인덱스에서 도출된다. 묵음 패킷이면 슬롯이 있어도 실제 자극 펄스는 없을 수 있다. **12슬롯/ms를 N=12 또는 매번 동일한 12전극 출력으로 해석하지 않는다.** [CFX NofM 구현](../../../../src/1__cfx/signalProcessing/stimulationStrategy.c)

이번 시험은 16대역에 대응하는 합성음을 넣는 시험이다. 16개 자극이 모두 하나의 1ms 구간에 들어간다는 의미는 아니다. 실제 선택 전극과 여러 1ms에 걸친 출력은 별도로 관측한다. 이번 작업에서는 펌웨어나 맵을 변경하지 않았다.

## 3. 제공 WAV를 APx에서 출력하기 — 권장

1. 기존 음향 시험 프로젝트를 연다. 출력은 **아날로그 출력 → 앰프 → 스피커**, 입력은 기준 마이크로 유지한다. Sound1에는 스피커의 합성음을 입력한다. 사용자에게 장착하지 않은 시험 장치와 측정용 부하에서 수행한다.
2. Sound1의 실제 맵 3이 **NofM·14µs**인지 확인한다. 볼륨을 고정하고 기본 왼쪽 빔포밍 방향과 기존 배치를 유지한다. I2S·Bluetooth 오디오·매핑 Live 등 다른 입력 경로는 사용하지 않는다.
3. WAV를 지원하는 측정 화면에서 **Signal Generation → Waveform → Browse for file…**로 원하는 WAV를 선택한다. 해당 메뉴가 없으면 WAV 지원 측정으로 이동한다. 설치 버전에 따라 패널 위치가 다를 수 있다.
4. 파일 정보가 **48kHz / 24bit / 1 channel**인지 확인하고, 스피커가 연결된 출력에 모노 신호를 배정한다. APx 출력 채널 1은 전극 1이 아니라 여러 톤이 합쳐진 **하나의 오디오 선로**다.
5. **Start Position=0**, 파일 전체 **1.024초(49,152샘플)**를 사용한다. 연속 반복 시 무음이나 클릭이 없는지 확인한다. **재생 구간을 1ms로 자르지 않는다.**
6. 낮은 Generator Level에서 켜고, 마이크의 보정 후 표시 음압을 보며 시험 목표까지 조절한다. 출력 전압 숫자나 WAV dBFS를 음압으로 읽지 않는다. 입력·출력 overload가 없어야 한다.
7. FFT/스펙트럼에서 지정 주파수들이 동시에 존재하는지 확인한다. 스피커·마이크 응답 때문에 톤별 실제 음압은 다를 수 있으므로 전극 간 크기를 비교할 때는 톤별 음압도 확인한다.
8. 설정이 안정된 뒤 여러 1ms 구간을 포함해 자극 파형을 캡처한다. 조합을 바꾸면 음압을 다시 확인한다. 파일명·실제 맵·볼륨·표시 음압·관측 전극을 함께 기록한다.

파일 재생 메뉴: [APx500 공식 매뉴얼, Generator Waveforms and Controls](https://www.ap.com/fileadmin-ap/technical-library/APx500_Users_Manual_v4-4-0.pdf?force=). WAV의 Generator Level이 합성파 RMS와 직접 일치하지 않을 수 있는 이유: [Audio Precision의 arbitrary waveform 레벨 설명](https://www.audioprecision.com/blog/setting-the-apx-generator-level-for-arbitrary-waveforms).

### WAV 공통 설정

| 항목 | 설정 |
|---|---|
| 형식 | 48,000Hz / 모노 / 선형 PCM 24비트 |
| 길이 | 1.024초 = 32ms 패턴 32회 |
| 톤별 상대 레벨·위상 | 모두 0dB·0°; 위상 최적화 없음 |
| 전체 RMS | 1 FS 기준 −24dBFS; 모든 파일 동일 |
| 피크 | 파일별 약 −12.14~−11.52dBFS; 클리핑 없음 |
| 용도 | 음향 입력의 주파수 조합 확인용; 전극 출력 합격 기준 아님 |

각 주파수가 31.25Hz의 정수배이므로 32ms마다 위상이 일치한다. 1ms는 자극 전송 버퍼 단위이지 합성음 반복 주기가 아니다. 125Hz 한 주기도 8ms이므로 1ms 음향 조각을 반복하면 원래 주파수 조합이 유지되지 않는다.

## 4. APx 화면에서 직접 합성음을 만들기

제공 WAV를 쓰면 이 절은 생략한다.

1. **Multitone Analyzer → Signal Generation → Waveform → Create New…**에서 새 정의를 만들고 **Edit Multitone Signal Definition**으로 들어간다.
2. Waveform Settings의 Sample Rate·Length는 목표 주파수를 정확히 표현할 격자로 정한다. **48,000Hz / 1,536샘플은 계산상 31.25Hz 격자**지만 해당 길이를 설치 버전이 허용하는지 확인해야 한다. 값이 거절되거나 주파수가 반올림되면 제공 WAV를 사용한다. 이전 매뉴얼의 ‘48kHz/1536이면 반드시 설정 가능’이라는 전제는 사용하지 않는다.
3. **Tone Description Grid**에서 필요한 주파수만 **Add Tone**으로 추가하고 나머지는 **Remove Tone**으로 삭제한다. [조합별 입력표](APx%20NofM%20합성%20파형/파형%20목록.md)의 행을 그대로 사용한다. 수동 편집하면 Step Type은 Custom이 된다.
4. **Frequency (Hz)**를 표와 맞추고, **Level (dB)=0 / Phase (deg)=0**으로 지정한다. 0dB는 무음이 아니라 같은 기준 진폭이다. 제외할 톤은 레벨을 0dB로 바꾸지 말고 행을 삭제한다.
5. Tone Bin은 APx의 Sample Rate/Length에 따른다. 아래 Sound1 bin을 APx에 그대로 입력하지 말고 **Frequency 값을 확인**한다.
6. 이번 WAV와 조건을 맞추려면 **Optimize Crest Factor를 실행하지 않는다.** 위상이 바뀌면 시간영역 피크와 AGC 반응이 달라질 수 있다.
7. 이름을 저장한다. 필요하면 **Create WAV File…**로 내보낸다. 실제 음압은 3절처럼 마이크로 설정한다.

편집 기능·필드: [APx500 v9.0 공식 매뉴얼, 703쪽](https://www.ap.com/fileadmin-ap/technical-library/APx500_User_Manual_v9-0-0.pdf?force=). 새 정의 진입: [APx500 v4.5 공식 매뉴얼, 411쪽](https://www.ap.com/fileadmin-ap/technical-library/APx500_Users_Manual_v4-5-0.pdf?force=). 설치된 APx에서 직접 재현한 결과가 아니라 공식 문서로 확인한 메뉴다.

## 6. 음압과 전극 출력 해석

### 전체 음압과 톤당 음압

같은 음압의 서로 다른 N개 주파수를 합성하면 충분한 관측 시간에서 ‘전체 = 톤당 음압 + 10log10(N)’이다. 전체 표시70dB SPL을 예로 들면:

| 톤 수 | 전체와의 차이 | 톤당 표시 음압: 이상적인 동일 음압 조건 |
|---:|---:|---:|
| 16 | 12.041dB | 57.959dB SPL |

세 파일은 모두 16톤이며 전체 RMS와 각 톤의 전기적 진폭도 동일하다. 실제 음향 경로에서는 주파수 응답에 따라 달라질 수 있다. **전체 음압 일정** 시험인지 **톤당 음압 일정** 시험인지 먼저 정한다. 위 70dB는 설명 예시이며 공식 합격 조건이 아니다.

### 지정 범위 밖 전극이 관측될 수 있는 이유

- **Hann창:** Sound1 FFT에는 Hann창이 적용된다. 정확한 bin 주파수도 인접 bin으로 성분이 퍼진다. 저주파에는 1bin 폭의 대역도 있어 ‘1톤=1전극’이 성립하지 않을 수 있다.
- **N=16:** 입력 톤 수와 선택 수를 모두16으로 맞췄어도, 비대상 대역의 잔류 성분·잡음·동점 처리 때문에 목표16전극과 실제 선택16전극이 다를 수 있다.
- **기본 맵의 전극16:** 기본 맵3에는 전극16의 T=C=1500µA 설정이 있다. 입력이 없다고 일률적으로 무자극이라 가정하지 않는다. 실제 맵과 T미만 묵음 조건을 확인한다.
- **AGC·매핑:** 순위는 음압 자체가 아니라 매핑 후 Amplitude에 의해 결정된다. AGC·T/C·포화·스피커 응답도 영향을 준다.

따라서 이번 파일로 ‘지정16전극 이외는 반드시0µA’라는 합격 기준을 만들지 않는다. **군별 합성파는 기존 ID-9의 32톤 강약 선택 시험을 대체하지 않는다.** 정식 선택 시험은 고정한 입력·맵 조건과 해당 기준서를 따른다.

근거: [Hann창·밴드 표](../../../../src/2__cm3/Gen1_5/FS/ci_fft.c), [T/C 기본값](../../../../src/2__cm3/Gen1_5/FS/ci_map.c), [선택·묵음·패킷 처리](../../../../src/1__cfx/signalProcessing/stimulationStrategy.c).

## 7. 검증 범위

현재 3개 WAV를 재디코딩하여 PCM형식·길이·32ms 반복·지정 주파수·톤별 동일 진폭·클리핑 부재를 검사했다. [검증 상세](APx%20NofM%20합성%20파형/파형%20목록.md)에 실제 수치를 수록했다.

APx 실재생, 마이크 음압, Sound1 전극 전류는 미측정이다. 파일 수치 검증을 실기 시험 통과로 취급하지 않는다.
