# APx 합성 파형 목록

16채널씩 묶고 시작점을 8채널씩 이동한 1~16 / 9~24 / 17~32 조합이다. 8~24는 17채널이므로 사용하지 않는다.

현재 시험에는 아래 16톤 WAV 3개를 사용한다.

생성 파형의 수치 검증 결과다. APx 실재생·음향 출력·전극 출력 실측 결과가 아니다.

모든 파일: 48 kHz / 모노 / PCM 24비트 / 1.024초 / 모든 톤 상대 레벨 0 dB·위상 0°.
총 RMS는 1 FS 기준 -24 dBFS로 동일하다. 실제 음압은 기준 마이크로 별도 설정한다.

파일 전체를 연속 반복한다. 1ms로 자르지 않는다. 선택 주파수 목록은 기본 32밴드 맵 기준이다.

| 파일 | 구분 | 톤 수 | Peak dBFS |
|---|---|---:|---:|
| [ch01-16.wav](ch01-16.wav) | A: 전극 대역 1~16 | 16 | -12.136 |
| [ch09-24.wav](ch09-24.wav) | B: 전극 대역 9~24 | 16 | -11.534 |
| [ch17-32.wav](ch17-32.wav) | C: 전극 대역 17~32 | 16 | -11.516 |

## APx에서 WAV 출력하기

기존 음향 시험 연결인 **APx 아날로그 출력 → 앰프 → 스피커 → Sound1 마이크**를 사용한다. 기준 마이크는 APx 입력에 연결한다. 사람에게 장착하지 않은 시험 장치와 측정용 부하에서 수행한다.

1. **Generator를 OFF**로 두고 기존 음향 시험 프로젝트를 연다.
2. WAV를 지원하는 측정 화면에서 **Signal Generation → Waveform → Browse for file…**를 선택한다. 이 폴더의 원하는 WAV를 연다. 예: 1~16 대역은 **ch01-16.wav**.
3. 파일 정보가 **48 kHz / 24 bit / 1 channel**인지 확인하고, 스피커가 연결된 APx 아날로그 출력 채널에 배정한다. APx의 채널 1은 전극 1이 아니라 여러 주파수가 합쳐진 하나의 오디오 출력이다.
4. **Start Position=0**, 파일 전체 **1.024초(49,152샘플)**를 사용한다. **1ms 구간으로 자르지 않는다.**
5. 낮은 **Generator Level**에서 **Generator를 ON**으로 전환한다. 기준 마이크에 신호가 들어오는지 확인하고, 파일 전체가 끊김 없이 반복되는지 확인한다.
6. 기준 마이크의 표시 음압을 보며 목표 음압까지 천천히 조절한다. 기존 **−8.293dB 표시 보정**을 유지한다. 표시70dB SPL은 실제78.293dB SPL에 해당하며, WAV의 −24dBFS나 출력 전압 숫자를 음압으로 해석하지 않는다. 입력·출력 overload가 발생하면 레벨을 낮춘다.
7. FFT/스펙트럼에서 아래 표의 주파수들이 **동시에** 출력되는지 확인한다. 스피커 응답 때문에 실제 톤별 음압은 달라질 수 있다. 안정된 뒤 여러1ms 구간의 전극 출력을 측정한다.
8. 다른 조합으로 바꿀 때는 **Generator OFF → 다음 WAV 선택 → 낮은 레벨에서 ON → 음압 재확인** 순서로 진행한다. 종료 시 Generator를 OFF로 둔다.

| 확인할 상황 | 조치 |
|---|---|
| Browse for file 메뉴가 없음 | WAV를 지원하는 측정 화면으로 이동한다. 메뉴 위치는 APx 버전에 따라 다를 수 있다. |
| 마이크 입력이 없음 | Generator ON, 아날로그 출력 채널 배정, 앰프·스피커 연결을 확인한다. |
| 반복 경계에서 무음·클릭 발생 | 파일 전체 재생과 연속 반복 설정을 확인한 후 측정한다. |
| 목표 밖 전극도 출력됨 | 16톤을 넣어도 Hann창·AGC·T/C에 따라 다른 전극이 선택될 수 있다. 이를 WAV 오류로 단정하지 않는다. |

**Sound1 기본 맵 3은 NofM·14µs·12슬롯/ms지만 선택 수는16이다.** 기본 맵 1은 CIS·50µs·최대8자극/ms다. 저장된 실제 맵을 확인하고, 16톤 입력이 해당16전극만의 선택을 보장하지 않는다는 점을 유의한다.

출력 메뉴 근거: [APx500 공식 매뉴얼](https://www.ap.com/fileadmin-ap/technical-library/APx500_Users_Manual_v4-4-0.pdf?force=). 자세한 맵·전송 순서와 음압 설명은 [상위 매뉴얼](../APx500%20Sound1%20N-of-M%20시험%20신호%20설정%20매뉴얼.md)을 참고한다. **제공 파일의 수치 검증은 완료했지만 APx 실재생·전극 출력 실측은 미수행이다.**

## 검증

3개 WAV를 다시 디코딩하여 길이·PCM 형식·32ms 반복·FFT 주파수·톤별 진폭을 검사했다.
합격 조건: RMS 오차 <0.0001 dB, 톤 간 레벨 차 <0.0001 dB, 비지정 FFT 성분 <-100 dBc.
FFT 검사는 파일 자체에 직사각창을 적용한 결과이며, Sound1의 Hann창 처리 후 채널 분리 검증은 아니다.
상세 수치: [검증 결과](검증%20결과.json). 사용법: [상위 매뉴얼](../APx500%20Sound1%20N-of-M%20시험%20신호%20설정%20매뉴얼.md).
