# Sound1 펌웨어 설계 계획 변경사항

## 현재 반영 내용

기존 내용이 Sound1에도 적용되면 원문을 유지했습니다. 앞서 덧붙인 기능 목록과 적용 대상 설명은 21개 문단에서 삭제하거나 줄였습니다. 제목, 번호 체계, 표, 그림, 시험 방법과 절차는 그대로입니다.

| 문서 | 정리한 내용 | 유지한 변경 |
|---|---|---|
| 개발 계획서(SDP) | 대상, 요구사항 분석, 아키텍쳐 설계, 개발 도구, 통합 계획, 통합 시험의 추가 설명 제거 | 제품명, 문서번호, 오자와 문서 목록 일련번호 정정 |
| 형상관리 계획서(SCMP) | 형상관리 도구, 배포 형상, 개발 환경의 추가 설명 제거. NRF/QCC 대응 설명 삭제 | 제품명, 문서번호, 제품 식별 예시. 5절 분기 그림의 NRF 표기를 QCC로 교체 |
| 변경관리 계획서(SCCP) | 변경 요청과 변경 영향에 덧붙인 코어, 부트로더, 맵, 보정 데이터 등의 나열 제거 | 제품명, 문서번호 |
| 유지보수 계획서(SMP) | 피드백 수집, 협력사 정보, 피드백 분석의 추가 설명 제거 | 제품명, 문서번호 |
| 문제해결 계획서(SPRP) | 버전 식별, 적용 범위, 원인 조사에 덧붙인 구성 요소와 조건 나열 제거 | 제품명, 문서번호 |
| 위험관리 계획서(SRMP) | 적용범위와 위험 식별의 추가 설명 제거 | 제품명, 문서번호 |

## 공통 변경

- 제품명과 문서번호는 Sound1 / TD24A-A-EXT / TD24A로 변경했습니다.
- 작성은 김은수 수석연구원으로 하며 작성 일자와 서명, 검토 및 승인란은 비웠습니다.
- 개정 번호는 0, 개정 내용은 최초 제정, 개정 일자는 빈칸입니다.
- 품목 등급은 사용자 지시에 따라 원본과 동일하게 유지했습니다.
- 현재 본문에 가운뎃점이 남아 있지 않은지 검사했습니다.

## 변경 추적과 파일

같은 폴더의 DOCX 6개가 검토할 파일입니다. 별도 접미어 또는 중복본은 만들지 않았습니다. Word의 검토 메뉴에서 모든 표시를 선택하면 원본 대비 남아 있는 변경을 확인하고 수락하거나 거부할 수 있습니다.

이번에 제거한 설명은 아직 수락하지 않은 삽입 제안이므로 해당 제안을 철회했습니다. 제품명, 작성자 등 나머지 변경 이력은 유지했습니다. 삭제 이력에 보이는 이전 이름, 일자와 서명은 Sound1의 승인 기록이 아닙니다.

참고 원본은 수정하지 않았습니다. 이 작업은 문서 전환이며 새 시험 결과나 승인 기록을 작성한 것이 아닙니다.

5절 교체 이미지는 `이미지 참조/SCMP 형상관리 분기 구성.png`에 저장했습니다. 원본 PNG의 NRF 글자 영역만 수정했으며 그 밖의 픽셀과 투명 배경은 동일합니다. 문서에는 기존 크기로 삽입하고 그림 교체 이력을 남겼습니다.
