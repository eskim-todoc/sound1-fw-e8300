## 시험 준비와 입력

<!-- source-cell:H1308 -->
- 격리 LED 시험에서 초기화/시작/ISR4000회/10440회 추가/정지 후100회 조건을 준비한다. ISR 호출 횟수는 시험 입력이며 실제 타이머 측정 시간이 아니다. 정상 기동의 LED 확인은 UART 공유핀과 LED 활성 조건을 맞춰 준비한다.<br>
<!-- /source-cell:H1308 -->


## 가정 및 제한 조건

<!-- source-cell:I1308 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. 운영 이미지 대신 격리된 시험 저장소를 사용한다. 초기 RTT 미사용 시 결과를 보존한 뒤 읽는다.<br>
<!-- /source-cell:I1308 -->


## 시험 절차

<!-- source-cell:J1308 -->
- 경과 카운터0→100→361ms, 완료 상태1, 정지 후 카운터/쓰기 횟수 유지와 응용 상태 분리를 비교한다. 정상 기동에서 LED 표시와 정지 후 표시 갱신 중단을 확인한다. 수동 ISR 호출에 따른 카운터 값과 실제 타이머의 측정 시간은 구분한다.<br>
<!-- /source-cell:J1308 -->

#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1308 -->
검증 결과<br>
기동 표시 초기화 → 시작, ISR 호출 전 / 경과 카운터=0 ms; G/B duty=0/0<br>
타이머 가동 상태에서 ISR 누계=4000회 / 경과 카운터=100 ms<br>
ISR 10440회 추가, 누계=14440회 / 경과 카운터=361 ms; 완료 여부=1(완료)<br>
정상 기동에서 LED 표시와 정지 후 표시 갱신 중단을 확인했다. 경과 카운터와 완료 상태를 포함해 통과 기준과 일치했다.<br>
