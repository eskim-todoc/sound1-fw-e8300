## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K809 -->
판정 범위<br>
- 해당 tick에서 시스템 제어→맵 반영→내부기 처리→통신 처리가 설계 순서로 호출된다. 반복 금지 조건에는 정상 처리를 시작하지 않는다.<br>
<!-- /source-cell:K809 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L809 -->
검증 결과<br>
iterationFlag=0(처리할 tick 없음) / 정상 반복 호출=없음<br>
iterationFlag=1(1회 처리 허용) / 처리 순서=입력 수집 → systemControl → update\_mapNum → isd\_interface → bleCommunication; 처리 후 iterationFlag=0<br>
<!-- /source-cell:L809 -->
