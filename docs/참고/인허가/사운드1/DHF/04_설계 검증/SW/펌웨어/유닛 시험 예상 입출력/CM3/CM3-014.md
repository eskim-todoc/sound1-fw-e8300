## 시험 준비와 입력

<!-- source-cell:H897 -->
- 실제 LED 엔진이 동작하는 정상/승인된 시험 상태에서 전원ON/OFF, 각 오류, 배터리 READY/MID/CRITICAL, 매핑 READY/LOW×내부기 연결/미연결, LED설정1/2, 종료/강제 소등을 독립 준비한다. 펌웨어 변형(APP/공장)/보드/공유 UART 핀/엔진 상태를 기록한다. 설계 패턴의 승인 근거를 준비하고 LOW+ISD100/900↔200/800 및 색/fade 불일치를 보류 표기한다.<br>
<!-- /source-cell:H897 -->


## 가정 및 제한 조건

<!-- source-cell:I897 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I897 -->


## 시험 절차

<!-- source-cell:J897 -->
- 입력 조건별 led\_request 요청과 선택 상태, 실제 LED 표시를 비교한다. 색상/점등/소등, 점멸 횟수와 ON/OFF 순서, 종료 소등을 확인한다. POWER\_ON/OFF는4회 점멸 뒤 요청이NONE으로 해제되고 소등되어야 한다. 표시 금지 예외와 엔진 가능/불가 상태의 종료 동작도 확인한다. 오류180/360은 ON180/주기360(OFF180)으로 읽는다.<br>
<!-- /source-cell:J897 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K897 -->
판정 범위<br>
- 설계된 상태별 LED 패턴과 종료 시점이 선택된다. 표시 금지의 예외 우선순위는 요청 규칙과 같고 종료/강제 소등 뒤 이전 패턴이 남지 않는다.<br>
<!-- /source-cell:K897 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L897 -->
검증 결과<br>
다른 요청=NONE(0), POWER\_ON/POWER\_OFF 요청 / 선택 표시=앱 SKYBLUE(공장 WHITE)/BLUE; 점멸 횟수=각 4회; 종료 순서=4회 점멸 완료 → 요청 자동 해제(NONE=0) → 소등<br>
ERROR\_MAP/MCU/ACCEL/FPGA/PMIC 요청 / 선택 표시=RED 점멸; 반복=요청 유지 중 계속<br>
매핑 중 배터리 READY/LOW, 내부기 연결/미연결 / 선택 표시=READY BLUE, LOW PURPLE; 연결 시=점멸; 미연결 시=지속 점등<br>
요청별 LED 색상과 점등/점멸 상태, 전원 표시4회 반복 후 요청 해제/소등, 표시 금지 예외와 종료 동작을 확인했다. 통과 기준과 일치했다.<br>
