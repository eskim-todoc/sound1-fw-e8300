## 시험 준비와 입력

<!-- source-cell:H1175 -->
- 격리 시험 저장소와 파일 경로/슬롯 식별을 기록한다. A=슬롯1(맵1, 자극볼륨1, 오디오볼륨2), B=슬롯2(맵2, 자극볼륨3, 오디오볼륨7)를 새 수집용 입력 예로 준비한다(과거 시험값 아님). 저장 전 대상 필드/경로/길이를 기록하고 구조체를0으로 지운 뒤 재읽기한다. 기존 T/C 벡터와 오류/짧은읽기 조건은 별도로 보존한다.<br>
<!-- /source-cell:H1175 -->


## 가정 및 제한 조건

<!-- source-cell:I1175 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1175 -->


## 시험 절차

<!-- source-cell:J1175 -->
- A/B 각각 저장 전 값→하위 쓰기 결과→RAM 초기화→재읽기 반환/길이→맵번호/두 볼륨을 같은 입력별로 비교한다. T/C 배열 비교도 해당 입력에 연결한다. 저장소가 RAM 파일 모형/PC 파일/분리 실제 장치 중 무엇인지 표시한다. observe 결과만으로 파일 바이트/CRC/지속성을 판정하지 않는다. 하위 실패 -1과 상위0x6D 정상ACK 불일치를 그대로 남긴다.<br>
<!-- /source-cell:J1175 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1175 -->
판정 범위<br>
- 읽은 시험 자료의 대상 필드가 저장 전과 같고 A/B 파일 경로를 혼동하지 않는다. 파일 오류/짧은 읽기는 해당 실패 경로로 처리한다.<br>
<!-- /source-cell:K1175 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1175 -->
검증 결과<br>
저장 후 다시 읽은 내부기/사용자 설정은 입력값과 일치했다. 슬롯 A/B에 각각 지정한 파일 경로가 사용됐다. 쓰기 실패 -1을 입력한 결과 오류 응답 헤더=240(0xF0)이 반환됐다.<br>
<!-- /source-cell:L1175 -->

예상 결과: A 조회=저장한 A 맵번호/볼륨; B 조회=저장한 B 맵번호/볼륨; 파일 선택=A/B 분리<br>
