## 시험 준비와 입력

<!-- source-cell:H996 -->
- Tx 초기 상태에서 \[0x12,0x34\]를 쓰고 길이/준비 상태/버퍼 비어 있음 조회를 기록한다. RAM SPI 준비 훅 상태와 실제 준비 핀 High/Low를 구분한다. 데이터만 초기화한 조건과 ACK 소비/준비 해제 조건을 독립 준비한다.<br>
<!-- /source-cell:H996 -->


## 가정 및 제한 조건

<!-- source-cell:I996 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I996 -->


## 시험 절차

<!-- source-cell:J996 -->
- \[UT-CM3-026\] 배열에서 응답 순서/길이, 준비 상태High와 empty=false, 데이터만0으로 만든 뒤 준비 상태 유지, ACK/준비 해제 뒤Low와 empty=true를 비교한다. GPIO/DMA 우회 RAM 기록을 실제 핀 전압 또는 QCC 수신 완료로 사용하지 않는다. <br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-026의 조건별 배열/상태와 판정 줄을 찾는다. <br>
<!-- /source-cell:J996 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K996 -->
판정 범위<br>
- 응답 바이트는 \[0x12,0x34\] 순서다. 응답 준비 신호가 High이면 버퍼 비어 있음 조회는 false다. 준비 신호 해제 후 Low이며 조회는 true다.<br>
- 버퍼 초기화 후 모든 데이터는 0이다. 데이터 지우기와 응답 준비 신호 해제는 별도 기능이다.<br>
<!-- /source-cell:K996 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L996 -->
검증 결과<br>
초기 응답 없음 / 응답 준비 신호=Low; TxBufferEmpty=true<br>
응답 \[0x12,0x34\] 게시 / tx\[0..1\]=\[0x12,0x34\]; tx\[20\]=2; 응답 준비 신호=High; TxBufferEmpty=false<br>
응답 준비 상태에서 배열만 초기화 / tx\[0..20\]=전부 0; 응답 준비 신호=High; TxBufferEmpty=false<br>
