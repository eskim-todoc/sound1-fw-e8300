## 유닛 설명

<!-- source-cell:E987 -->
여러 장치가 하나의 I2C 경로를 사용할 때 전송 상태를 공통으로 관리한다.<br>

## 시험 준비와 입력

<!-- source-cell:H987 -->
- I2C 유닛 입력 경계에 가상 ACK/NACK/전송 완료/status와 RX\[0x12,0x34\]/\[0x56,0x78\]을 독립 준비한다. START/읽기/쓰기/STOP, busy/error 조건의 상태와 반환을 기록한다. RAM 레지스터/수동 ISR/시험 poll인지 실제 버스 실행인지 구분한다.<br>
<!-- /source-cell:H987 -->


## 가정 및 제한 조건

<!-- source-cell:I987 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I987 -->


## 시험 절차

<!-- source-cell:J987 -->
- 가상 조건별 드라이버 상태/반환/전송/수신 배열과 횟수의 \[UT-CM3-025\] 원문을 저장해 K와 비교한다. 실제 SCL/SDA/인터럽트 도착 시간/주변장치 동작을 이 로그로 판정하지 않는다. 별도 실제 버스 요구가 있으면 실제 측정 자료로 수집한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-025의 조건별 배열/상태와 판정 줄을 찾는다. <br>

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K987 -->
판정 범위<br>
- 전송 진행 상태와 완료/오류를 구분하고 수신 버퍼는\[0x12,0x34\]다. busy 기간의 새 요청 처리는 정의된 분기와 같고 완료 후 사용 상태를 정리한다.<br>
<!-- /source-cell:K987 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L987 -->
검증 결과<br>
주소=0x44, 쓰기 데이터=\[0x56,0x78\] / 전송 데이터=\[0x56,0x78\]; 전송 길이=2바이트; 상태=1(쓰기 진행) → 2(완료); 완료 후=Idle<br>
주소=0x44, 읽기 응답=\[0x12,0x34\] / 수신 버퍼=\[0x12,0x34\]; 전송 길이=2바이트; 상태=3(읽기 진행) → 4(완료); 제어 순서=ACK → NACK/STOP<br>
버스 오류 주입 후 재초기화 / 상태=5(오류); 재초기화 후=Idle<br>
