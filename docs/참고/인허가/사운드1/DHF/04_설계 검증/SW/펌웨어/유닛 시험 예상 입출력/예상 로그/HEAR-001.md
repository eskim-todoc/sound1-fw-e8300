# HEAR-001 예상 RTT 출력

[입력 조건과 전체 예상 결과](../HEAR/HEAR-001.md)

보고서 1차본의 결과 칸에서 RTT 관련 기록을 옮겼다. 조건 번호, 배열값과 줄 나눔은 원문과 같다.

## RTT 비교 1

<!-- source-cell:L648 -->

```text
[UT-HEAR-001] C1 A[0:12]=100,32,17,100,99,0,0,0,0,0,0,0,0
[UT-HEAR-001] C1 A[13:17]=0,0,0,1,0
[UT-HEAR-001] C1 PASS N=18 F=0
```
