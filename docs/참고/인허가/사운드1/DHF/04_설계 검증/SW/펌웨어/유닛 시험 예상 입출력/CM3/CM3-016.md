## 시험 준비와 입력

<!-- source-cell:H908 -->
- 오류 비트 하나를 설정한다. 공유 메모리 주소가 일치하거나 다른 조건과 CFX의 EEPROM 자료 적재 완료 플래그가 0(미적재) 또는 1(적재 완료)인 조건을 각각 준비한다.<br>
<!-- /source-cell:H908 -->


## 가정 및 제한 조건

<!-- source-cell:I908 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I908 -->


## 시험 절차

<!-- source-cell:J908 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-016의 조건별 배열/상태와 판정 줄을 찾는다. <br>
