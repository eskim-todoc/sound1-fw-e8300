# CM3-043 맵 저장과 삭제 범위

시험 ID: `SW-FW-UnitTest-CM3-ID-43`  
원본: [유닛 검증 보고서 1차본](../../SUVR-FW-TD24A%20%EC%86%8C%ED%94%84%ED%8A%B8%EC%9B%A8%EC%96%B4%20%EC%9C%A0%EB%8B%9B%20%EA%B2%80%EC%A6%9D%20%EB%B3%B4%EA%B3%A0%EC%84%9C_1%EC%B0%A8%EB%B3%B8.xlsx), `보고서_유닛 시험` 1181~1184행.  
아래 예상 결과는 보고서에 기록된 결과를 그대로 옮긴 비교값이다.

## 유닛 설명

<!-- source-cell:E1181 -->
매핑 변경을 보존하면서 삭제 명령이 의도한 범위를 넘지 않게 구분한다.<br>
<!-- /source-cell:E1181 -->

<!-- /source-cell:G1181 -->


## 시험 준비와 입력

<!-- source-cell:H1181 -->
- 격리 A/B 각각 맵1/2에 구분 가능한 자료를 준비한다. 맵1삭제/A전체/전체삭제마다 같은 초기 파일 집합에서 다시 시작한다. 대상 파일 경로/전체 길이/내용 또는 해시를 먼저 기록한다. ‘삭제’는 해당 파일의 기본값 기록임을 명시하고 운영 저장소는 접근하지 않는다.<br>
<!-- /source-cell:H1181 -->


## 가정 및 제한 조건

<!-- source-cell:I1181 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1181 -->


## 시험 절차

<!-- source-cell:J1181 -->
- 조건별 선택 맵의 기본값 전체 대상 필드와 비선택 파일의 전후 목록/길이/바이트/해시를 비교한다. T\[31\] 표식만 확인했다면 그 범위만 결과로 적고 전체 파일 불변을 통과시키지 않는다. write\_fault 하위 실패/상위0x6F 정상ACK 및 재읽기948/T\[31\]=141은 기존 보류로 유지한다.<br>
<!-- /source-cell:J1181 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1181 -->
판정 범위<br>
- 맵 1 삭제는 해당 내부기의 맵 1 만, A전체는A만, 전체삭제는시험A/B전체가 대상이다. 남겨야 할 파일은 그대로이고 제품 저장소는 시험하지 않는다.<br>
<!-- /source-cell:K1181 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1181 -->
검증 결과<br>
격리 A/B에 맵1/2 준비, A의 맵1 삭제 / 초기화 대상=A 맵1; 유지 대상=A 맵2, B 맵1/2; 처리 방식=기본값 쓰기<br>
같은 초기 상태에서 A 전체 삭제 / 초기화 대상=A 전체; 유지 대상=B 맵1/2; 처리 방식=기본값 쓰기<br>
