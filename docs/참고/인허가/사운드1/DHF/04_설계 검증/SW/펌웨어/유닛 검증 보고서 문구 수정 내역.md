# 유닛 검증 보고서 문구 수정 내역

은수님이 편집한 `SUVR-FW-TD24A 소프트웨어 유닛 검증 보고서_수정중.xlsx`를 수정했다. 수정전 파일과 작성자 전용 파일은 변경하지 않았다.

시험값/기존 RTT 문자열/판정과 행/병합/그림은 유지했다. 수정 범위는 문장, 검증 번호 표시, 유닛 이름, 불필요한 자료 안내이다.

## 1. 요청별 변경 내용

| 요청 | 변경 전 | 변경 후 / 적용 위치 |
|---|---|---|
| 짧은 문장 종결 | `호출합니다`, `같습니다`, `기대입니다` | `호출한다`, `같다`, `예상값이다`. 표지를 제외한 본문/보조 시트의 해당 문구 전체 |
| 검증 번호 연결 | `RTT C1` | `검증 [1]의 RTT 출력 (C1)`. 본문 K열과 RTT 결과 대조 B열 |
| 입력과 RTT 연결 | `입력/원소별 기준: C1` | `검증 [1]의 입력/원소별 기준 (C1)`. 해당 기준/결과 제목 |
| 로그 저장 지시 삭제 | `그룹 전체 원본 .log를 저장한다.` | 해당 문장 삭제. 실행/배열/판정 비교 절차는 유지 |
| 쉬운 예상 출력 표현 | `예상 RTT 전문`, `기대값` | `예상 RTT 출력 결과`, `예상값`. 본문과 보조 시트 모두 적용 |

HEAR-ID-2의 C80/C81은 검증 [1]의 원시값 기록이다. `검증 [1]의 RTT 출력 (C80)` / `(C81)`로 표시하며 로그 안의 C번호는 바꾸지 않았다. C101처럼 기존 시험에 사용된 번호도 원래 C번호와 함께 표시했다.
