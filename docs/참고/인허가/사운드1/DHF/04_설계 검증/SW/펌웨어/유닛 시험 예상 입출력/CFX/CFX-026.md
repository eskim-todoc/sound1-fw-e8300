## 시험 준비와 입력

<!-- source-cell:H285 -->
- AGC 출력\[i\]=i(i=0~15)를 설정하고 FIFO 쓰기를 관찰한다.<br>
AGC 출력 RAM을 준비하고 tdc\_ut\_fft\_write가 기록한 RAM trace를 관찰한다. 시험 override에서 실제 FIFO\_ACCESS 쓰기는 하지 않는다.<br>
<!-- /source-cell:H285 -->


## 가정 및 제한 조건

<!-- source-cell:I285 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I285 -->


## 시험 절차

<!-- source-cell:J285 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-026의 조건별 배열/상태와 판정 줄을 찾는다. <br>
