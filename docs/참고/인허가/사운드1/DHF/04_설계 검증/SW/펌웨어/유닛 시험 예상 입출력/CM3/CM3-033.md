## 시험 준비와 입력

<!-- source-cell:H1109 -->
- 매핑 시작/진행counter0~7/종료와 정상 역방향 응답/응답 없음/오류/FIFO 정리 실패를 독립 준비한다. 응답의 RAM/실제 경로와 상위 연결 반영에 필요한 매핑 여부/자극 파라미터 완료 조건을 기록한다.<br>
<!-- /source-cell:H1109 -->


## 가정 및 제한 조건

<!-- source-cell:I1109 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1109 -->


## 시험 절차

<!-- source-cell:J1109 -->
- 하위 검사 뒤 isd\_controlState, 수신/에러, 완료/진행 플래그를 기록한다. 정상 처리에서 상위 반영을 완료한 뒤 conneded\_ISD를 별도 기록해 K와 비교한다. 실제 관찰은 입력을 정상 루프에서 처리한 후 정지해 OBSERVED/디버거 값으로 수집한다. 관찰 호출만으로 입력 처리 완료 또는 RF 연결 성공을 주장하지 않는다.<br>
<!-- /source-cell:J1109 -->
