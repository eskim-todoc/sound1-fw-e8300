## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K39 -->
판정 범위<br>
- 1-DMIC는 SINGLE, 2-DMIC는 DUAL이다. 각 경로의 입력/핀 설정이 보드 정의와 같고 DUAL에서만 빔포밍을 선택한다.<br>
<!-- /source-cell:K39 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L39 -->
검증 결과<br>
공통 오디오 경로, 현재 2-DMIC 빌드 / 표본율=16 kHz; 입력 ADC=0/2; DMIC 데이터 핀=DIO23/DIO17; 클럭 원천=DIO22<br>
1-DMIC 활성 / 활성 수=1(SINGLE); DIO22=ADCCLK; DIO10=DISABLE; 비I2S 경로=DMIC1 단일 혼합<br>
