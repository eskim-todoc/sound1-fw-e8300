## 가정 및 제한 조건

<!-- source-cell:I585 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I585 -->


## 시험 절차

<!-- source-cell:J585 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-035의 조건별 배열/상태와 판정 줄을 찾는다. <br>

### 비교 3

#### 입력 조건과 통과 기준

<!-- source-cell:K587 -->

입력 adjacent\[i\]=i(i=0..15)로 두고 Interleaving을 호출한다. 결과 notAdjacent\[2j\]=j, notAdjacent\[2j+1\]=8+j(j=0..7)다. 레코드 I0..I15 전체는 \[0,8,1,9,2,10,3,11,4,12,5,13,6,14,7,15\]로 정확히 비교한다.<br>

#### 예상 결과 (보고서 기록값)

<!-- source-cell:L587 -->

입력: 입력 adjacent\[i\]=i(i=0..15)로 두고 Interleaving. 결과 notAdjacent\[2j\]=j, notAdjacent\[2j+1\]=8+j(j=0..7)다<br>
출력: A\[0..11\]=\[0,8,1,9,2,10,3,11,4,12,5,13\]; A\[12..15\]=\[6,14,7,15\]<br>
