## 시험 준비와 입력

<!-- source-cell:H1243 -->
OTA 시작 \[0xC0,0,7\]/종료 \[0xC1,9\] 명령을 각각 입력하고 기존 DFU 플래그는 각각 0/1로 둔다. 별도로 QCC 시스템 정보 \[0x35,4\](OTA\_EZAIRO)/\[0x35,0\](NONE)을 입력한다. 입력 상태 4와 연결 플래그 1을 구분한다.<br>
<!-- /source-cell:H1243 -->


## 가정 및 제한 조건

<!-- source-cell:I1243 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1243 -->


## 시험 절차

<!-- source-cell:J1243 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 상태 변화, 반환 결과와 처리 순서를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-050의 조건별 배열/상태와 판정 줄을 찾는다. <br>
<!-- /source-cell:J1243 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1243 -->
판정 범위<br>
시작 ACK=\[0xC0,0,7\], 종료 ACK=\[0xC1,0,9\], 길이=3이며 기존 DFU 플래그 0/1은 각각 유지된다. QCC \[0x35,4\]/\[0x35,0\]의 ACK는 \[0x35,1\], 길이=2이며 연결 조회 플래그는 각각 1/0이다. 시작/종료 응답만으로 연결 상태가 바뀐다고 가정하지 않는다.<br>
<!-- /source-cell:K1243 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1243 -->

기존 DFU=0, START \[0xC0,0,7\] / ACK=\[0xC0,0,7\]; 길이=3; DFU 연결=0<br>
기존 DFU=1, END \[0xC1,9\] / ACK=\[0xC1,0,9\]; 길이=3; DFU 연결=1<br>
