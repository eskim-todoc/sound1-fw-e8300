## 시험 준비와 입력

<!-- source-cell:H54 -->
- 입력 블록 A\[i\]=i, B\[i\]=100+i(i=0~15)를 구성하여 복사 함수를 두 번 호출한다. 두 마이크를 구분할 때 다른 마이크에는 각 값에 1000 을 더한다.<br>
DMIC FIFO 입력은 g\_tdc\_ut\_io\_dmic\_fifo의 RAM 대체 블록으로 설정하고 tdc\_copy\_DMIC\_buffers를 호출한다. 실제 마이크에 소리를 넣거나 실제 DMIC FIFO에서 수집한 표본이 아니다.<br>
<!-- /source-cell:H54 -->


## 가정 및 제한 조건

<!-- source-cell:I54 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I54 -->
