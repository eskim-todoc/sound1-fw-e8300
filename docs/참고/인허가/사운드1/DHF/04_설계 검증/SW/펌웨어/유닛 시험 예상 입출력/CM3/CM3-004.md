<!-- source-cell:E802 -->

## 시험 준비와 입력

<!-- source-cell:H802 -->
- 실행 허용0/자료 미준비, 준비 완료 후1, 금지 후0 조건을 준비한다. RAM coordination 시험은 CFX 시작/초기화 입력을 훅으로 대체함을 표시한다. 기준의 실제 CFX 조회는 공유 자료가 준비된 각 단계에서 CFX 측 조회 지점/주소를 정해 별도 확인하며 공유 사용자 정지 조건을 기록한다.<br>
<!-- /source-cell:H802 -->


## 가정 및 제한 조건

<!-- source-cell:I802 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I802 -->


## 시험 절차

<!-- source-cell:J802 -->
- CM3 RAM 시험의 \[UT-CM3-004\] 전체 배열과 공유 주소/준비/허가 순서를 저장한다. 실제 CFX 조회 자료는 같은 0→1→0 단계/주소를 CFX 측에서 읽은 기록으로 별도 붙인다. CM3 훅의 PASS만으로 CFX 기동/조회 완료를 판정하지 않는다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-004의 조건별 배열/상태와 판정 줄을 찾는다. <br>
<!-- /source-cell:J802 -->
