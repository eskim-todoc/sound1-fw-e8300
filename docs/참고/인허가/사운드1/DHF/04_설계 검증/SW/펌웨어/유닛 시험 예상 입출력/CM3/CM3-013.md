<!-- source-cell:E889 -->

## 시험 준비와 입력

<!-- source-cell:H889 -->
- 배터리 BATT\_READY와 오류 ERROR\_MCU 요청을 동시에 설정한다. 오류 요청 해제 뒤 배터리 요청, 모두 해제 뒤 NONE을 확인한다. 본 시험은 요청 저장/우선순위 선택의 RAM 시험이며 실제 LED 점등/패턴은 CM3-014에서 관찰한다.<br>
<!-- /source-cell:H889 -->


## 가정 및 제한 조건

<!-- source-cell:I889 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I889 -->


## 시험 절차

<!-- source-cell:J889 -->
- \[UT-CM3-013\]에서 요청/선택값 ERROR\_MCU(14)→BATT\_READY(2)→NONE(0)과 요청 조회값을 저장해 K와 비교한다. 확인 범위: LED 요청/선택값의 RAM 기록.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-013의 조건별 배열/상태와 판정 줄을 찾는다. <br>
