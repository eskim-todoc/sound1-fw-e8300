## 가정 및 제한 조건

<!-- source-cell:I1154 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>

## 시험 절차

<!-- source-cell:J1154 -->

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1154 -->
판정 범위<br>
- VP 활성 요청은 출력 허용 설정을, 비활성 및 차단 리셋은 출력 차단 설정을 전달한다. 각 요청 후 제어 상태가 해당 명령과 같아야 한다. 추가 관찰에서는 활성/차단에 따른 출력 유무를 확인한다. 전압 정확도와 전극 전류는 이 시험으로 판정하지 않는다.<br>
<!-- /source-cell:K1154 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1154 -->
검증 결과<br>
적용 보드의 VP 활성 요청 / PMIC 명령=출력 허용 설정; 제어 상태=활성<br>
적용 보드의 VP 비활성 요청 / PMIC 명령=출력 차단 설정; 제어 상태=비활성<br>
적용 보드의 VP 출력 차단 리셋 요청 / PMIC 명령=출력 차단 리셋; 제어 상태=출력 차단<br>
VP 활성 상태에서는 출력이 있고, 비활성 및 차단 리셋 후에는 출력이 없음을 확인했다. 명령/제어 상태와 출력 유무가 통과 기준과 일치했다.<br>
