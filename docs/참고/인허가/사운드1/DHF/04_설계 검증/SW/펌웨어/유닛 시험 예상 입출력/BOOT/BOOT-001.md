판정 범위<br>

#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1284 -->

CAL=1: DIO 준비→인터럽트 차단/보류 해제→인터럽트 허용. QCC\_CTRL=0, QCC\_ISD\_CHECK=0으로 설정됐다.<br>
<!-- /source-cell:L1284 -->

<!-- source-cell:K1285 -->

예상 결과: 처리 순서=초기 DIO/디버그 설정 → PRIMASK 인터럽트 차단 → NVIC 비활성화/보류 해제 → 인터럽트 허용<br>
