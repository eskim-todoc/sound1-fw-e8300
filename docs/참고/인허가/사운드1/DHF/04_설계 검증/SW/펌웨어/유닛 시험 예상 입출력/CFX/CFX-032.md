## 시험 준비와 입력

<!-- source-cell:H401 -->
- 디지털 T 레벨은 50, 변경 후 C 레벨은 150, 오프셋은 0으로 설정하고 자극 알림을 끈다. 상하한 제한 직전 계산값 y를 \[40,50,100,160\]으로 각각 고정한다.<br>
- 별도 SDK 경로: 채널 i=0~31에 \[0,1,8,64,512,4096,16384,262143\]\[i%8\]을 넣는다. xMin=16/xMax=4096, p=1258291(Q1.23), 정규화 계수=5163793(Q8.16), T=50/C=150으로 실제 계수를 계산한다. 묵음 모드 1/2를 각각 적용한다.<br>
<!-- /source-cell:H401 -->


## 가정 및 제한 조건

<!-- source-cell:I401 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>

## 시험 절차

<!-- source-cell:J401 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
- 실제 SDK 경로의 PCM 크기와 알림 처리 전 공유값을 32채널 각각 비교한다. 원본 계산값/하한/상한도 별도 RTT로 보존한다.<br>
