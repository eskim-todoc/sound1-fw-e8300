## 시험 준비와 입력

<!-- source-cell:H812 -->

## 가정 및 제한 조건

<!-- source-cell:I812 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I812 -->


## 시험 절차

<!-- source-cell:J812 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 상태 변화, 반환 결과와 처리 순서를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-006의 조건별 배열/상태와 판정 줄을 찾는다. <br>

#### 입력 조건과 통과 기준

<!-- source-cell:K812 -->

- 동일 맵은 불필요한 변경 요청을 만들지 않고 변경 맵은 새 번호/요청을 반영한다. 시스템 공유 플래그는 입력값과 같다.<br>

#### 예상 결과 (보고서 기록값)

<!-- source-cell:L812 -->
검증 결과<br>
맵 1을 다시 요청했을 때 맵 변경 요청=0, 재계산 요청=0, CFX 적재 완료=1이었다. 맵 복사/FFT 읽기 호출은 각각 0회였다. 맵 2를 요청했을 때 현재 맵=2, 변경/재계산 요청=1, CFX 적재 완료=0으로 바뀌었다.<br>
