## 시험 준비와 입력

<!-- source-cell:H116 -->
- LEFT와 RIGHT를 차례로 설정한 뒤 조회값과 PCM\_LiveStimulation\_Mode의 인자 순서를 확인한다.<br>
<!-- /source-cell:H116 -->


## 가정 및 제한 조건

<!-- source-cell:I116 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I116 -->


## 시험 절차

<!-- source-cell:J116 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 상태 변화, 반환 결과와 처리 순서를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
기본 CFX-013 벡터는 LEFT/RIGHT 설정/조회만 실행한다. PCM\_LiveStimulation\_Mode 좌우 인자 선택은 코드 대조(분석)와 실제 실행 추적을 구분해 기록하며, 실행 추적 미수집을 기본 벡터 통과로 덮지 않는다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-013의 조건별 배열/상태와 판정 줄을 찾는다. <br>
<!-- /source-cell:J116 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K116 -->
판정 범위<br>
- 조회값은 설정 방향과 같고 LEFT는 DMIC2, RIGHT는 DMIC1 의 현재/직전 블록이 지연 입력에 전달되어야 한다.<br>
<!-- /source-cell:K116 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L116 -->
검증 결과<br>
전면 방향=LEFT(1) / 조회 방향=1; 지연 현재/직전 블록=DMIC2; 비지연 현재 블록=DMIC1<br>
전면 방향=RIGHT(2) / 조회 방향=2; 지연 현재/직전 블록=DMIC1; 비지연 현재 블록=DMIC2<br>
<!-- /source-cell:L116 -->


### 비교 2

<!-- source-cell:K117 -->

예상 결과: 조회 방향=1; 지연 현재/직전 블록=DMIC2; 비지연 현재 블록=DMIC1<br>
<!-- /source-cell:K117 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L117 -->

판정: 출력/동작이 기준과 일치하여 통과.<br>

### 비교 4

#### 입력 조건과 통과 기준

<!-- source-cell:K119 -->
검증 \[1\]의 입력/원소별 기준 (C1) 왼쪽과 오른쪽 선택 저장/조회<br>
