## 유닛 설명

<!-- source-cell:E1208 -->
리모콘 연결 허용 상태에 따라 조회와 설정 명령을 처리하고, 명령별 응답을 준비한다.<br>
<!-- /source-cell:E1208 -->

<!-- /source-cell:G1208 -->


## 시험 준비와 입력

<!-- source-cell:H1208 -->
- 처리허용false/true에서 조회/설정 입력과 초기/기존 명령을 독립 기록한다. 연결 확인은 별도 준비한다. 슬롯0/busy는 기존 보충 오류 조건으로 분리하고 실제 운영 저장 접근은 하지 않는다. 무선QCC/실제 파서/상위 처리와 RAM 스냅샷을 구분한다.<br>
<!-- /source-cell:H1208 -->


## 가정 및 제한 조건

<!-- source-cell:I1208 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1208 -->


## 시험 절차

<!-- source-cell:J1208 -->
- 정상 입력을 수신→기능 처리→명령 정리한 단계별 허용값/요청 명령/반환ACK/처리후IDLE을 기록한다. 실제 관찰은 정상 처리 후 정지한 OBSERVED로 보조한다. E-05 명령75잔류/E-07 이전74유실을 보류로 남기며 이를 정상 통과로 합치지 않는다. <br>
<!-- /source-cell:J1208 -->

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1208 -->
판정 범위<br>
- 일반 명령은 처리 허용 상태에서만 대응 기능을 실행하고 처리 후 명령을 대기 상태로 정리한다. 연결 확인 명령은 별도 경로로 처리한다. 이 허용 상태를 암호학적 패스키 인증 결과로 해석하지 않는다.<br>
<!-- /source-cell:K1208 -->

<!-- source-cell:L1208 -->
검증 결과<br>

처리 허용=true, 슬롯1/4 정보 조회 / 실행 기능=내부기 정보 조회; 선택 슬롯=1/4; 처리 명령=0x4A → 처리 후 0(IDLE)<br>
