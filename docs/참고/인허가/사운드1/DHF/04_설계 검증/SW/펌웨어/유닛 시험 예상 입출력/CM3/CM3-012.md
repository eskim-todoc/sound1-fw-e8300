## 시험 준비와 입력

<!-- source-cell:H883 -->
- CFX에 전달할 PMIC 제어 요청을 켜짐과 꺼짐으로 각각 설정한다. 저전력 진입 요청 플래그는 0(요청 없음)에서 1(요청 있음)로 변경한다.<br>
<!-- /source-cell:H883 -->


## 가정 및 제한 조건

<!-- source-cell:I883 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I883 -->


## 시험 절차

<!-- source-cell:J883 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 상태 변화, 반환 결과와 처리 순서를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-012의 조건별 배열/상태와 판정 줄을 찾는다. <br>
