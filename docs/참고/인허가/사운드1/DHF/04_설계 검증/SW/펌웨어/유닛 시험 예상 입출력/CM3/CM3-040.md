## 시험 준비와 입력

<!-- source-cell:H1159 -->
- 보조 PMIC 읽기 응답=0x5A를 고정하고 읽기 및 리셋 경로를 실행한다.<br>
<!-- /source-cell:H1159 -->


## 가정 및 제한 조건

<!-- source-cell:I1159 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I1159 -->


## 시험 절차

<!-- source-cell:J1159 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-040의 조건별 배열/상태와 판정 줄을 찾는다. <br>
<!-- /source-cell:J1159 -->

### 비교 4

#### 입력 조건과 통과 기준

<!-- source-cell:K1162 -->
검증 \[1\]의 RTT 출력 (C1)<br>
입력/조건: value=0, RX=\[90,0,0,0\], 오류=0. 레지스터=0x11을 읽는다. 타깃 RAM 전제 조건에서 report 지원. 실장치 실행 결과가 아닌 통과 시 비교용.<br>
