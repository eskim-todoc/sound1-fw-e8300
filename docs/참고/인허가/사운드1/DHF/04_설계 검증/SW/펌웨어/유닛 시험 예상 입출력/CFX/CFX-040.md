## 시험 준비와 입력

<!-- source-cell:H624 -->
24프레임 버퍼의 앞 3칸을 \[0x11,0x22,0x33\], 나머지 21칸을 NOP(0x25555)로 준비한다. 별도로 i=0~23에 0x50080+513\*i를 넣어 모든 단어를 구분한다. 초기 읽기 인덱스=17, 읽기 중 플래그=0, 요청 모드=SpecificCommand, 다음 모드=NopStandby다.<br>
<!-- /source-cell:H624 -->


## 가정 및 제한 조건

<!-- source-cell:I624 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
24프레임 PCM 쓰기는 TDC\_UT\_PCM\_WRITE의 RAM capture로 관찰한다. 쓰기 순간 읽기 중 플래그/인덱스는 소프트웨어 기록이며 FPGA 실제 소비/전극 출력 완료를 뜻하지 않는다.<br>
<!-- /source-cell:I624 -->
