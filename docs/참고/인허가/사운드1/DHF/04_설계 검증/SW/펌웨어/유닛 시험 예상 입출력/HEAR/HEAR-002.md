## 시험 준비와 입력

<!-- source-cell:H650 -->
512점 Hanning 창, n=0~511. 표본 배열 P=\[0,25080,46341,60547,65536,60547,46341,25080,0,-25080,-46341,-60547,-65536,-60547,-46341,-25080\]. 입력은 (1)0, (2)P\[n%16\], (3)P\[(2\*n)%16\], (4)32768, (5)짝수 n은32768/홀수 n은-32768이다. 매 조건 FIFO 전부를 다시 채운다.<br>
입력 1~5는 HEAR FFT 입력 메모리의 512개 디지털 코드이다. 입력2/3의 수치적 주기는 각각 bin32/bin64를 만들며 실제 스피커 톤이나 마이크 주파수 응답 시험을 뜻하지 않는다. 실기 준비: 실제 E8300 HEAR가 초기화/유휴 상태인지 확인하고 정상 오디오/PCM 생산자와 결과 버퍼 쓰기의 간섭을 막는다. 완료 ISR은 동작 가능해야 한다. 시작 시 function\_chain0/1=0이어야 한다. tdc\_ut\_hear\_start는 HEAR를 초기화하지 않으며 hardware\_ready=1만 입력했다고 실기 준비가 증명되는 것은 아니다. PC 합성 이벤트/배열로 엔진 결과를 대신하지 않는다.<br>

## 가정 및 제한 조건

<!-- source-cell:I650 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>

## 시험 절차

<!-- source-cell:J650 -->
실제 CMD1/Event1 완료 후 FFT 512단어, vMag 256단어, BFP 블록 지수 E를 보존한다. HEAR 예상값 시트의 사전 DFT 값과 비교하며 FFT 실수/허수는 bin \[0,1,31,32,33,63,64,65,255\], vMag는 256개 전부를 판정한다. 원본 배열도 RTT로 남긴다.<br>
매 입력 조건을 구분하여 실제 CMD1/Event1 완료 뒤 FFT 원본값512개/vMag 원본값256개/장치에서 읽은 E/완료 플래그를 RTT 원문으로 보존한다. 비교 레코드의 1은 허용구간 충족 Boolean이며 raw FFT/vMag 값이 아니다. FFT 원본값×2^E 및 vMag 원본값×2^(E+1)로 K73의 사전 오차/대상 성분/전256개를 그대로 비교한다. 합성 E=4 또는 예상값으로 실제 E를 채우지 않는다. PC 합성 검사/시험자 기록/실기 수집 자료를 분리한다.<br>
수집: 준비된 HEAR 그룹(ut hear 1) 실행 후 UT-HEAR-002의 조건별 배열/상태와 판정 줄을 찾는다. <br>

영 입력은 위 오차식을 쓰지 않고 FFT 512개와 vMag 256개 전부 정확히 0인지 비교한다. 비영 입력은 FFT의 9개 bin만 직접 비교하고 vMag는 256개 전체를 비교한다. 나머지 FFT raw 성분도 보존하지만 자동 통과 비교 범위는 아니다. 실제 E는 고정 예상값이 없으며 OBSERVED(관찰값)로 남긴다. 합성 RAM의 E=4를 장치의 기대 E로 복사하지 않는다.<br>
