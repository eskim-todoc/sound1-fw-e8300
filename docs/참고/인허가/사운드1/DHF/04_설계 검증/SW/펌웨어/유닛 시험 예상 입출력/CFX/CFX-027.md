## 시험 준비와 입력

<!-- source-cell:H289 -->
- 인덱스\[bin\]=bin%32(bin=0~255)로 구성한다. 맵 대역 수와 분석 대역 수가 동일/상이한 조건에서 호출한다.<br>
<!-- /source-cell:H289 -->


## 가정 및 제한 조건

<!-- source-cell:I289 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I289 -->

<!-- source-cell:J289 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K289 -->
판정 범위<br>
- 동일하면 256 개 인덱스가 모두 입력과 같다. 상이하면 기존 배열 256 개가 유지된다. -1 과 0~31 외 인덱스는 정상 입력에 사용하지 않는다.<br>
<!-- /source-cell:K289 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L289 -->
검증 결과<br>
맵 대역 수=32, 분석 대역 수=32, 원본\[k\]=k%32 / 목적지 인덱스\[k\]=k%32(k=0~255); 채널 순서=0~31을 8회 반복<br>
맵 대역 수=32, 분석 대역 수=31, 기존 목적지=모두 -1 / 목적지 인덱스\[0~255\]=모두 -1 유지; 원본 복사=없음<br>
