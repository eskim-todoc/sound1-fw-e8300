<!-- source-cell:K1622 -->
payload 인덱스: 3<br>
의미/단위: 전송 이후 잠금 설정 횟수 (회)<br>
사전 예상값: 1<br>
표준 16바이트 자료의 독립 CRC=0xA3AA, data\_crc 인자=0xAAA3다. CRC는 독립 CCITT 식을 사용한다. 초기값 0xFFFF, 다항식 0x1021, 비트 반사 없음, 최종 XOR=0이다. 바이트마다 CRC 상위 8비트에 입력을 XOR하고 8회 왼쪽 이동하며 최상위 비트가 1이면 0x1021을 XOR한다. 매번 하위 16비트만 유지한다. 파일 헤더 끝의 CRC는 상위 바이트부터 저장한다. 데이터 CRC 인자는 이 16비트 결과의 바이트 순서를 바꾼 값이다. boot\_info와 제조 표의 CRC 필드는 little-endian 정수로 저장하므로 파일 헤더와 구분한다.<br>
