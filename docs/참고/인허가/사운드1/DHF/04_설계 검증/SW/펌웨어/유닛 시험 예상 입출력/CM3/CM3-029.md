## 시험 준비와 입력

<!-- source-cell:H1040 -->
- 펄스폭 25us, 전극 수 32, 전 채널 T/C 입력 전류 100/300uA를 설정한다. DAC 자극 상한 A/B/C/D=400/803/1203/1606uA, 오프셋 상한 A/B=295/592uA, A 환산계수=20871/14435(Q1.15)를 적용한다. CIS와 NofM을 각각 선택한다.<br>
- CIS의 펄스폭을 249/250/251us로 나누어 전하량 경계를 시험한다. 별도 DAC 실패는 T=100uA/C=2500uA, 펄스폭 25us다. 실패 상태 관찰에서는 기존 완료 플래그를 0/1로 각각 둔다.<br>

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1040 -->
판정 범위<br>
- NofM 32대역은 자극당 3프레임, 1ms당 8채널이다. CIS는 자극당 2프레임, 1ms당 12채널이다. 공유한 32채널 디지털 T/C는 각각 0/127이다. 계산 실패를 정상 공유 완료로 처리하지 않는다.<br>
- CIS 249us/250us는 각각 성공, 자극당 13프레임/1ms당 1채널이다. 251us(75300pC)는 실패다. 계산 함수 자체는 완료 플래그를 설정하지 않는다. 실패 후 공유값 유지/초기화 정책은 상세 설계에서 결정한 뒤 별도 판정하며 현재 관찰을 합격으로 처리하지 않는다.<br>
<!-- /source-cell:K1040 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1040 -->
검증 결과<br>
CIS 계산 후 프레임=2, 전송 채널=12, NofM은 프레임=3, 전송 채널=8이었다. 펄스폭 249/250 μs에서 계산 성공=1, 프레임=13, 채널=1이었다. 251 μs/75300 pC는 반환값=0이었다. 실패를 입력한 완료 게시 시험에서 완료 플래그=0을 확인했다.<br>
