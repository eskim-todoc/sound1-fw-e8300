## 시험 준비와 입력

<!-- source-cell:H614 -->
- 16표본 오디오 블록과 CIS/NofM 처리 자료를 준비한다. HEAR 연산 완료 플래그를 0(미완료)과 1(완료)로 나누어 결과 사용 순서를 코드에서 검토한다.<br>
현재 CMD0/CMD1의 완료와 이전 CMD1의 잔류 fc1=1을 구분한다. 현재 CMD1 미완료 fc1=0, 현재 완료 fc1=1, 진입 시 잔류 fc1=1, 완료 미발생 조건을 같은 행 안에서 구분해 분석한다.<br>
<!-- /source-cell:H614 -->


## 가정 및 제한 조건

<!-- source-cell:I614 -->
코드 분석으로 판정한다. 실제 핀 파형, 전원, 처리 시간 및 전극 전류의 실측과 구분한다.<br>
<!-- /source-cell:I614 -->


## 시험 절차

<!-- source-cell:J614 -->
- 준비한 각 입력과 초기 상태에 대해 조건 분기, 호출 순서, 인자, 반환값 및 상태 변경을 코드에서 확인한다. 아래 예상 결과와 대조하고 검토한 조건 및 근거를 기록한다.<br>
<!-- /source-cell:J614 -->


## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K614 -->
판정 범위<br>
- HEAR 연산 완료 전에는 연산 결과를 사용하지 않는다. 완료 후 AGC, FFT, 대역 대표값, 매핑 및 선택한 자극 전략 순서로 처리한다. 패킷 생성 함수와 전달 인자는 해당 전략의 설계 조건과 같아야 한다.<br>
<!-- /source-cell:K614 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L614 -->
검증 결과<br>
CMD 0 완료 표시를 지운 뒤 AGC와 FFT 입력 준비가 실행됐다. CMD 1을 요청하고 이번 완료 표시를 받은 뒤 다음 처리를 진행했다. 완료 전 결과 사용은 없었다. CIS는 대표값/매핑/패킷 출력, NofM은 선택/교차 배치 후 앞 8개와 뒤 8개를 순서대로 출력했다.<br>
<!-- /source-cell:L614 -->
