## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1323 -->
판정 범위<br>
- 성공 경로에서만 다음 기동 단계로 진행하고 반환 오류가 무시되지 않아야 한다.<br>
<!-- /source-cell:K1323 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1323 -->
검증 결과<br>
하위 단계 반환값이 0인 경우에만 다음 기동 단계가 실행됐다. FatFs 오류값 1과 음수 오류를 넣었을 때 해당 오류가 상위로 전달됐고 이후 단계는 실행되지 않았다.<br>
<!-- /source-cell:L1323 -->


### 비교 2

#### 입력 조건과 통과 기준

<!-- source-cell:K1324 -->
조건 \[1\]<br>
입력/조건 \[1\]: 저장 준비/헤더/구획 적재 성공, 두 코어의 기동 자료 있음<br>
예상 결과: 처리 순서=슬롯 선택 → 파일 열기 → 헤더/구획 적재 → CFX 기동 → CM3 기동<br>
