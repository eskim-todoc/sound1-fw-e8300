## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K1114 -->
판정 범위<br>
- 전송 주소/데이터가 대상 레지스터 정의와 같다. RF/리셋 비트 외 유지 대상 비트는 불변이다. 가상 쓰기 기록을 실제 RF 출력으로 판정하지 않는다.<br>
<!-- /source-cell:K1114 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L1114 -->
검증 결과<br>
제어값 0x1C에서 RF ON 후=0x1E, RF OFF 후=0x1C였다. FPGA 리셋 요청은 리셋 비트에 반영됐고 RF/리셋 이외의 기존 비트는 유지됐다. 전송 주소와 데이터가 지정한 FPGA 제어 레지스터와 일치했다.<br>
<!-- /source-cell:L1114 -->

#### 입력 조건과 통과 기준

<!-- source-cell:K1115 -->

입력/조건 \[1\]: FPGA 제어 캐시=0x1C, RF ON<br>
예상 결과: 전송 대상=FPGA 제어 레지스터; 전송 데이터=0x1E; RF bit1=1; 유지 비트=0x1C 보존<br>
<!-- /source-cell:K1115 -->
