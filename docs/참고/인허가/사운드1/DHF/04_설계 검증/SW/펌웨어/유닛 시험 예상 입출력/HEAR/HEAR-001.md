## 시험 준비와 입력

<!-- source-cell:H644 -->
- 입력=\[0,-32,17,-100,99, 나머지 0\]으로 고정하고 CMD 0 을 호출한다.<br>
입력은 HEAR 메모리의 16개 디지털 코드이다. 마이크/스피커 입력이나 실제 수음 측정이 아니다. 실기 준비: 실제 E8300 HEAR가 초기화/유휴 상태인지 확인하고 정상 오디오/PCM 생산자와 결과 버퍼 쓰기의 간섭을 막는다. 완료 ISR은 동작 가능해야 한다. 시작 시 function\_chain0/1=0이어야 한다. tdc\_ut\_hear\_start는 HEAR를 초기화하지 않으며 hardware\_ready=1만 입력했다고 실기 준비가 증명되는 것은 아니다. PC 합성 이벤트/배열로 엔진 결과를 대신하지 않는다.<br>
<!-- /source-cell:H644 -->


## 가정 및 제한 조건

<!-- source-cell:I644 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I644 -->


## 시험 절차

<!-- source-cell:J644 -->
중간 vAbsolute 배열은 함수체인 순서와 절대값 수식으로 분석한다. 실제 CMD 0/Event 0 완료 후 배열과 최대값을 별도 저장하여 RTT로 비교한다. 완료 후 배열을 중간 시점의 실측으로 쓰지 않는다.<br>
실제 CMD0/Event0 체인 완료 후 16개 최종 ABS와 function\_chain0/1을 별도 버퍼로 저장하여 RTT 원문을 기록한다. vAbsolute 직후 값은 분석(A)으로만 표시하고 완료 후 word0=100을 중간 ABS 실측으로 쓰지 않는다. PC 합성 검사, 시험자 충족 확인 기록, 실제 장치 수집 로그에 각각 출처/시험일/펌웨어 빌드를 표시한다.<br>
수집: 준비된 HEAR 그룹(ut hear 1) 실행 후 UT-HEAR-001의 조건별 배열/상태와 판정 줄을 찾는다. <br>
