## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K633 -->
판정 범위<br>
- 대기/역방향 통신은 해당 NOP 패턴을 사용한다. FILL\_ZERO는 지정 출력이 0 이다. 리셋은 FIFO/모드 초기화 경로를 실행하며 네 동작을 혼동하지 않는다.<br>
<!-- /source-cell:K633 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L633 -->
검증 결과<br>
대기 출력 24개=0x25555, 역방향 통신 출력 24개=0x35555, FILL\_ZERO 출력 24개=0이었다. 리셋 후 FIFO/모드 초기화가 실행됐고 preamble=0, Reset\_PCM=0이었다.<br>
<!-- /source-cell:L633 -->
