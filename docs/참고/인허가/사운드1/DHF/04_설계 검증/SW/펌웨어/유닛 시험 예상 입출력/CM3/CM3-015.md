## 시험 준비와 입력

<!-- source-cell:H904 -->

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K904 -->
판정 범위<br>
요청 플래그가 1인 동안 CM3는 CFX 정리를 기다린다. CFX가 주변장치를 정리한 뒤 0으로 해제하면 저클럭 전환/절전 진입을 진행한다. 복귀는 재기동/초기화를 거쳐 정상 처리를 준비한다.<br>
<!-- /source-cell:K904 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L904 -->
검증 결과<br>
ULP 요청 플래그=1(정리 대기) / CM3 상태=CFX 정리 대기; 저클럭 전환=진행하지 않음<br>
CFX 정리 후 ULP 요청 플래그=0 / 진행 순서=CFX/HEAR 정리 → 요청 해제 → CM3 2.56MHz/I2C PRESCALE\_6 → 절전 진입<br>
<!-- /source-cell:L904 -->
