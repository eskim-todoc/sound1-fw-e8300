#### 입력 조건과 통과 기준

I2S 핀 및 수신 처리 연결 / 클럭=DIO25; 프레임=DIO19; 데이터 입력=DIO14; 입력 유효=DIO29(active-low); 수신 버퍼=I2S 전용, DMIC와 분리<br>
