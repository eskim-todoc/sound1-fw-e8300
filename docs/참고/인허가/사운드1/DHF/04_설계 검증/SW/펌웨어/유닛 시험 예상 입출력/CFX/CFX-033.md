## 시험 준비와 입력

<!-- source-cell:H559 -->
- CIS 전략, 전극 수 32, 대역i의 전극=i+1, CIS 대역순서\[i\]=i+1, 크기 100, 묵음꺼짐, 채널당 2 프레임, 1ms12 채널, 시작인덱스 0 을 고정한다. NofM으로 전환할 때 선택 경로를 기록한다.<br>
<!-- /source-cell:H559 -->


## 가정 및 제한 조건

<!-- source-cell:I559 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
PCM 송신 목적지는 시험 override의 RAM 슬롯이다. '1ms12채널'은 본 유닛의 설정값/한 호출 단위 조건이며 실제1ms 타이밍이나 전극 전류를 측정한 결과가 아니다.<br>
<!-- /source-cell:I559 -->


## 시험 절차

<!-- source-cell:J559 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-033의 조건별 배열/상태와 판정 줄을 찾는다. <br>
