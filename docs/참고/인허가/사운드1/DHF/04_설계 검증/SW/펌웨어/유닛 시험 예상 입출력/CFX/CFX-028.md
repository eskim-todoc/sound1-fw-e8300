# CFX-028 대역별 대표값 및 크기 보상

시험 ID: `SW-FW-UnitTest-CFX-ID-28`  
원본: [유닛 검증 보고서 1차본](../../SUVR-FW-TD24A%20%EC%86%8C%ED%94%84%ED%8A%B8%EC%9B%A8%EC%96%B4%20%EC%9C%A0%EB%8B%9B%20%EA%B2%80%EC%A6%9D%20%EB%B3%B4%EA%B3%A0%EC%84%9C_1%EC%B0%A8%EB%B3%B8.xlsx), `보고서_유닛 시험` 298~303행.  
아래 예상 결과는 보고서에 기록된 결과를 그대로 옮긴 비교값이다.

## 유닛 설명

<!-- source-cell:E298 -->
여러 FFT bin으로 구성된 한 대역의 대표 크기를 정하고 매핑 입력 범위에 맞춘다.<br>
<!-- /source-cell:E298 -->

<!-- source-cell:F298 -->
T<br>
<!-- /source-cell:F298 -->


## 상세 설계 유닛

<!-- source-cell:G298 -->

<!-- /source-cell:G298 -->


## 시험 준비와 입력

<!-- source-cell:H298 -->
- 처음 네 bin 크기=\[16,80,48,4096\], 대역=\[0,0,1,-1\], 나머지 크기=0/대역=-1 로 설정한다.<br>
vMag 출력 배열과 g\_pass\_bin\_index에 위 크기/대역 벡터를 RAM으로 직접 설정한다. CMD1/FFT나 스피커/마이크 순음 입력을 실행하지 않는다.<br>
<!-- /source-cell:H298 -->


## 가정 및 제한 조건

<!-- source-cell:I298 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>
<!-- /source-cell:I298 -->


## 시험 절차

<!-- source-cell:J298 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-028의 조건별 배열/상태와 판정 줄을 찾는다. <br>
