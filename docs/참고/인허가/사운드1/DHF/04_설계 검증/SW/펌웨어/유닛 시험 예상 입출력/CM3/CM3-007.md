## 시험 준비와 입력

<!-- source-cell:H824 -->
- 정상 사용 상태에서 터치나 저배터리 종료 조건을 제외한다. 내부기 미연결 상태의 누적 카운터를 호출 전 179999와 180000으로 각각 설정한다. 내부기 연결 완료 상태도 별도로 시험한다.<br>
<!-- /source-cell:H824 -->


## 가정 및 제한 조건

<!-- source-cell:I824 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
<!-- /source-cell:I824 -->


## 시험 절차

<!-- source-cell:J824 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
수집: 준비된 CM3 그룹(ut cm3 1) 실행 후 UT-CM3-007의 조건별 배열/상태와 판정 줄을 찾는다. <br>

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K824 -->
판정 범위<br>
- 미연결 상태의 179999는 한 번 처리 후 180000이 되며 자동 종료를 요청하지 않는다. 180000은 180001에서 종료를 요청하고 카운터를 0으로 초기화한다. 내부기 사용 허용 상태(enable\_ISD)는 false(사용 중지)로 바뀐다.<br>
- 내부기 연결 완료 상태에서는 카운터가 0으로 유지된다. 경계값 주입은 종료 분기 시험이며 실제 3분 경과 측정을 대신하지 않는다.<br>
<!-- /source-cell:K824 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L824 -->
검증 결과<br>
내부기 미연결, 호출 전 카운터=179999 / 처리 후 카운터=180000; 종료 요청=0<br>
내부기 미연결, 호출 전 카운터=180000 / 비교 시 카운터=180001; 처리 후 카운터=0; 종료 요청=1; enable\_ISD=false(사용 중지)<br>
내부기 연결 완료 / 처리 후 카운터=0; 종료 요청=0<br>
