## 시험 준비와 입력

<!-- source-cell:H1644 -->
- 서비스 표시와 reboot 호출 횟수 시험은 TDC\_UNIT\_TEST\_HOST의 격리 PC fixture에서 수행한다. PC reset 대체 함수가 하드웨어 재시작 대신 횟수만 기록하는 것을 확인한다. 실제 제품/타깃 서비스 콘솔에 reboot를 보내지 않는다. 물리 LED 관찰은 별도의 승인된 서비스 표시 상태에서 재기동 명령 없이 수행한다.<br>
<!-- /source-cell:H1644 -->


## 가정 및 제한 조건

<!-- source-cell:I1644 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. 운영 이미지 대신 격리된 시험 저장소를 사용한다. 초기 RTT 미사용 시 결과를 보존한 뒤 읽는다.<br>
<!-- /source-cell:I1644 -->


## 시험 절차

<!-- source-cell:J1644 -->
- 격리 시험의 RTT 입력에 reboot\\n을 적용하고 시스템 재시작 함수 호출 횟수=1, 응용 코어 기동=0, 서비스 tick/색상/GPIO 쓰기 상태를 확인한다. 정상 서비스 동작에서는 UART 공유핀 조건을 맞춘 뒤 LED 표시와 재시작 요청에 따른 재시작 동작을 확인한다.<br>
<!-- /source-cell:J1644 -->
