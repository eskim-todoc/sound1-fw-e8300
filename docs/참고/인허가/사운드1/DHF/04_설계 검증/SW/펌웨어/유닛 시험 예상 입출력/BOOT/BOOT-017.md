## 시험 준비와 입력

<!-- source-cell:H1623 -->
- 서비스 파서의 PC 격리 fixture에 MANIFEST.TXT, APP000.FEZ, APP001.FEZ, APP002.FEZ 각각 \[0x12,0x34\]를 준비한다. RTT 입력 대체/UP 출력 기록과 실제 서비스 RTT DOWN0/UP0를 구분한다. dump\\n, unknown\\n, 파일 열기/읽기 실패를 독립 준비한다. 운영 이미지/NVM 파일을 시험 파일로 바꾸거나 dump하지 않는다.<br>
<!-- /source-cell:H1623 -->


## 가정 및 제한 조건

<!-- source-cell:I1623 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. 운영 이미지 대신 격리된 시험 저장소를 사용한다. 초기 RTT 미사용 시 결과를 보존한 뒤 읽는다.<br>
<!-- /source-cell:I1623 -->


## 시험 절차

<!-- source-cell:J1623 -->
- PC fixture에서 각 RTT 입력과 원시 출력(파일 BEGIN/END/12 34/FW DUMP BEGIN/END/invalid command./ERROR)을 저장한다. 이미 준비/승인된 격리 실기 서비스 경로를 사용한 경우만 실제 RTT DOWN0에 명령을 보내고 UT 필터를 해제한 UP0 원문을 별도 보존한다. 유닛 콘솔에 dump를 보내거나 자동END로017완료를 판정하지 않는다. 실패는 정상 dump 성공으로 바꾸지 않는다.<br>
