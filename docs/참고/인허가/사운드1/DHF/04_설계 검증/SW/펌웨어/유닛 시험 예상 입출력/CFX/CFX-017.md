## 가정 및 제한 조건

<!-- source-cell:I138 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>

## 시험 절차

<!-- source-cell:J138 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
기본 CFX-017 벡터는 RAM 인자를 지정하여 지연 합산 함수를 직접 호출한다. LEFT/RIGHT 분기 선택은 별도 코드 대조(분석) 또는 실제 실행 추적으로 구분해 K46과 대조하고, 실제 마이크 방향성 성능으로 확대하지 않는다.<br>

### 비교 5

#### 입력 조건과 통과 기준

<!-- source-cell:K142 -->
검증 \[1\]의 입력/원소별 기준 (C1) 현재 블록 15표본과 직전 블록 경계<br>
지연 마이크 현재 A\[i\]=64×i(i=0..15), 직전 B\[0\]=2048, B\[1..15\]=-64, 지연 없는 마이크 C\[0..15\]=0으로 설정한다. A/B/C를 순서대로 빔포밍 함수에 전달한다. i=0..14는 ((C\[i\]&gt;&gt;5)+(A\[i+1\]&gt;&gt;5))&gt;&gt;1, i=15는 ((C\[15\]&gt;&gt;5)+(B\[0\]&gt;&gt;5))&gt;&gt;1이다.<br>
출력/레코드 인덱스: 0..14<br>
예상값 전체: i+1, 즉 1부터 15까지 1씩 증가<br>
출력/레코드 인덱스: 15<br>
예상값 전체: 32<br>
A\[0\]와 B\[1..15\]는 이 출력 계산에 쓰이지 않는다. 입력 3개는 각각 16표본이며 결과 16개 전부를 비교한다.<br>
