## 시험 준비와 입력

<!-- source-cell:H124 -->
- I2S 입력 16표본을 100+i(i=0~15)로 설정한다. FIFO 수신 처리 허용 플래그는 1(처리 가능), 수신 버퍼 위치와 복사 횟수는 0으로 설정한다.<br>
- 버퍼 복사 완료 플래그는 0(미완료)에서 시작하고 복사, 완료 조회, 완료 해제, 출력 버퍼 초기화를 차례로 실행한다.<br>
I2S 입력은 s\_tdc\_ut\_input RAM 16표본을 lib\_i2s\_copy\_data\_from\_fifo에 전달한다. g\_tdc\_ut\_io\_override\_enabled=1에서는 실제 IRQ enable/disable 경로를 우회하므로 I2S 선로 수신/인터럽트 안전성을 이 결과로 판정하지 않는다.<br>
<!-- /source-cell:H124 -->


## 가정 및 제한 조건

<!-- source-cell:I124 -->
현재 복사 코드에는 복사 완료 플래그를 1로 설정하는 처리가 없다. 상세 설계의 완료 조건과 비교하여 불일치를 기록한다. 시험에서 완료 플래그를 대신 설정하지 않는다.<br>
<!-- /source-cell:I124 -->

## 입력 조건별 기준과 예상 결과

### 비교 1

#### 입력 조건과 통과 기준

<!-- source-cell:K124 -->
판정 범위<br>
- 첫 수신 위치의 16표본은 100~115, 복사 후 수신 위치와 복사 횟수는 각각 1이다. 처리한 FIFO 수신 허용 플래그는 0으로 해제된다.<br>
- 버퍼 복사 완료 조회는 복사 후 1(완료), 완료 해제 후 0(미완료)이어야 한다. 출력 버퍼 초기화 후 16표본은 모두 0이다.<br>
<!-- /source-cell:K124 -->


#### 예상 결과 (보고서 기록값)

<!-- source-cell:L124 -->
검증 결과<br>
100~115의 16표본을 복사한 결과, 다음 버퍼 위치=1, 복사 횟수=1, FIFO 플래그=0이었다. 복사 직후 copy\_done=1, 완료 표시를 지운 뒤=0이었다. 초기화 후 16표본은 모두 0이었다.<br>
