## 시험 준비와 입력

<!-- source-cell:H182 -->

- 로그 변환 직후 입력 d를 \[-7700297,-7700296,-7700295,-6209353,-6209352,-6209351\](Q8.16)로 차례로 고정하여 시간 변화 적용 전 목표 이득 g를 기록한다.<br>
- 별도 SDK 경로: 입력=\[1,8,128,4096,65536,262143\], 볼륨 1/10. 이전 이득=0, 어택=62259/상보=3276, 릴리즈=655/상보=64880(Q8.16)으로 매 조건을 초기화한다. 로그/거듭제곱 결과 고정은 해제한다.<br>

## 가정 및 제한 조건

<!-- source-cell:I182 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다. CFX/HEAR 결과는 별도 버퍼에 보존한 뒤 CM3 RTT로 읽고 ISR에서 긴 로그를 출력하지 않는다.<br>

## 시험 절차

<!-- source-cell:J182 -->
- 준비한 조건을 각각 독립 초기화하여 해당 유닛을 실행한다. 입력/출력 배열, 계산값과 횟수를 처리 완료 후 RTT로 기록하여 아래 예상 결과와 비교한다.<br>
- SDK 경로의 목표 이득/평활 이득/선형 이득과 사전 하한/상한을 RTT로 보존한다. 실제값과 허용 구간을 먼저 읽고, 구간 판정 결과를 별도로 비교한다.<br>
SDK 입력6개×볼륨1/10의 12조건마다 목표/평활/선형 이득 실제값/하한/상한의 별도 numeric RTT 레코드 원문을 입력조건과 함께 보존한다. 비교 결과1은 Boolean이며 실제 수치가 아니다. PC analytic SDK stand-in/컴파일 검사와 실제 타깃 SDK 실행을 구분하고 관측값에 맞추어 K열 허용구간을 늘리지 않는다.<br>
수집: 준비된 CFX 그룹(ut cfx 1) 실행 후 UT-CFX-023의 조건별 배열/상태와 판정 줄을 찾는다. <br>
