## 시험 준비와 입력

<!-- source-cell:H1124 -->
- FPGA의 시험 레지스터 응답은 0(오류 없음)으로 준비한다. 이후 오류 표시 비트와 FIFO 비어 있음 표시 비트를 한 개씩 1로 설정한 응답을 각각 준비한다. FIFO 읽기 응답은 \[0x12,0x34\]다.<br>
<!-- /source-cell:H1124 -->


## 가정 및 제한 조건

<!-- source-cell:I1124 -->
시험 입력 또는 가상 장치 응답은 유닛 입력 경계에 설정한다. 실행 결과를 미리 예상값으로 덮어쓰지 않는다. 실제 전원이나 RF 연결 확인과 소프트웨어 상태 확인을 구분한다.<br>
