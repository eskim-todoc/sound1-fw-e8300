# Sound1 입력 음압 대비 ADC 출력 산출 근거

**TL;DR**: 1.5세대와 Sound1 은 **같은 스펙의 마이크**를 쓴다. 그래서 1.5세대 테이블의 생성 규칙을 그대로 두고 **Sound1 의 실측 감쇠만 반영**했다. 감쇠는 고음압 평탄 구간(80~110 dB SPL) 실측 평균으로, **PCB 상태 -3.644 dB · 기구 조립 -5.593 dB** 다. 기구에 의한 추가 감쇠는 **약 1.95 dB**. 조립 이상이 의심되는 3 시료는 기준에서 빼고 기록만 남겼다.

> [!NOTE]
> 표는 같은 폴더의 **`[참고] Sound1 입력 음압 대비 ADC 출력 테이블.xlsx`** 에 있다.
> 이 문서는 그 표를 어떻게 만들었는지 적은 것이다.

## 1. 무엇을 만들었나

| 열 | 내용 | 근거 |
|---|---|---|
| 1.5세대 (멤브레인 미적용) | 원본 그대로 | 참조용. 재계산하지 않았다 |
| 1.5세대 (멤브레인 고려) | 원본 그대로 | 참조용 |
| **Sound1 (PCB 상태)** | 1.5세대에서 **-3.644 dB** | 실측 5 시료 평균 |
| **Sound1 (기구 조립 상태)** | 1.5세대에서 **-5.593 dB** | 실측 3 시료 평균 |

범위는 1.5세대와 같은 **29~120 dB SPL**, 92 행이다.

```
ADC = floor(262143 x 10^((dB SPL - 120 + 감쇠) / 20))
      262143 = 2^18 - 1   (18 비트 포화)
      감쇠는 소수 3 자리로 확정한다.  PCB -3.644,  기구 -5.593
```

> [!NOTE]
> 감쇠를 소수 3 자리로 **확정**한 이유가 있다. 실측 평균은 -3.6443..., -5.5928... 인데
> 그 전체 자리를 쓰면 이 문서에 적힌 값(-3.644)으로 다시 계산했을 때 내림 결과가
> 몇 자리에서 1 씩 달라진다. **문서만 보고도 같은 표가 나와야** 하므로 3 자리로 못박았다.

주요 지점만 옮기면 이렇다.

## 2. 왜 이렇게 만들었나

### 2.1 같은 마이크이므로 감쇠는 하나의 dB 차다

두 세대가 같은 스펙의 마이크를 쓴다. 그러면 출력 차이는 **음압에 무관한 일정한 dB 차**로 나타난다. 1.5세대 테이블이 이미 로그 선형(1 dB 마다 10^(1/20) 배)이므로, Sound1 테이블은 **그 곡선을 통째로 아래로 내린 것**이면 된다. 새로 곡선을 그릴 이유가 없다.

### 2.2 1.5세대 테이블의 생성 규칙을 먼저 밝혔다

```
미적용    ADC = floor(262143 x 10^((dB SPL - 120) / 20))
멤브레인   미적용 열을 3 dB 옮긴 것.  멤브레인[d] = 미적용[d - 3]
          표 범위 밖인 29~31 dB 는 최소값 7 로 채워져 있다
```

멤브레인 규칙은 **범위 안 89 개 전건이 일치**한다. 즉 1.5세대는 「3 dB 낮춘 값을 새로 계산」한 것이 아니라 **표를 3 칸 밀어 재사용**했다. Sound1 은 감쇠가 정수 dB 가 아니라 밀기가 성립하지 않으므로 직접 계산했다.

### 2.3 감쇠는 고음압 평탄 구간에서 구했다

측정값을 1.5세대 대비 dB 로 환산하면 저음압에서 흔들리고 고음압에서 평탄해진다. 501C 를 예로 들면 이렇다.

| dB SPL | 45 | 50 | 55 | 60 | 70 | 80 | 90 | 100 | 110 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 감쇠 | +0.55 | -1.36 | -2.13 | -2.65 | -3.05 | -3.46 | -3.78 | -3.69 | -3.50 |

저음압의 흔들림은 **잡음 바닥** 탓이다. 45 dB SPL 에서 오히려 1.5세대보다 큰 값(+0.55 dB)이 나오는 것이 그 증거다. 실측값을 구간별로 그대로 쓰면 테이블이 로그 선형을 벗어나 **오히려 틀린 표**가 된다.

그래서 **80~110 dB SPL 일곱 점의 평균**을 전 구간에 일괄 적용했다. 이 구간에서 각 시료의 편차는 0.20 ~ 0.65 dB 다.

## 3. 시료별 실측 감쇠

1.5세대(멤브레인 미적용) 대비, 고음압 평탄 구간 평균이다.

| 그룹 | 시료 | 감쇠 | 구간 편차 | 판정 |
|---|---|---:|---:|---|
| **PCB 상태** | 501C | -3.63 | 0.32 | 채택 |
| PCB 상태 | 501D | -3.68 | 0.49 | 채택 |
| PCB 상태 | 501E | -3.75 | 0.31 | 채택 |
| PCB 상태 | 501F | -3.57 | 0.43 | 채택 |
| PCB 상태 | 5020 | -3.60 | 0.65 | 채택 |
| **기구 조립** | 500E | -5.15 | 0.20 | 채택 |
| 기구 조립 | 500F | -5.65 | 0.33 | 채택 |
| 기구 조립 | 500A | -5.97 | 0.57 | 채택 |
| 기구 조립 | 500D | **-6.76** | 0.45 | **제외** |
| 기구 조립 | 500C-2차 | **-7.48** | 0.66 | **제외** |
| 기구 조립 | 500C-1차 | **-11.43** | 0.37 | **제외** |

| 기준 | 값 | 표본 |
|---|---:|---:|
| PCB 상태 평균 | **-3.644 dB** | 5 |
| 기구 조립 평균 (제외 후) | **-5.593 dB** | 3 |
| 기구에 의한 추가 감쇠 | **-1.949 dB** | |
| 기구 조립 전체 평균 (참고) | -7.075 dB | 6 |

### 3.1 PCB 상태는 매우 고르다

5 시료가 **-3.57 ~ -3.75 dB**, 범위 **0.18 dB** 다. 마이크와 입력단 자체의 특성으로 보기에 충분히 안정적이다. 이 값이 이 작업에서 가장 믿을 만한 숫자다.

### 3.2 세 시료를 제외한 이유

> [!IMPORTANT]
> **같은 500C 가 1차 -11.43 dB, 2차 -7.48 dB 로 4 dB 나 달라졌다.**
> 시료가 바뀐 것이 아니라 **조립 상태가 바뀐 것**이다. 이 한 가지가 「기구 조립 편차」를 가장 분명히 보여 준다.

- **500C-1차 (-11.43)** : 가장 낮다. 정상군 평균과 5.8 dB 차이다.
- **500C-2차 (-7.48)** : 재측정에서 4 dB 개선됐지만 여전히 정상군보다 1.9 dB 낮다. 홀수 음압(55·65·75·85·95·105)이 결측이라 표본도 4 점뿐이다.
- **500D (-6.76)** : 정상군 최저(500A -5.97)보다 0.8 dB 낮다.

이 셋을 넣으면 기준이 -7.075 dB 가 되어 **조립 불량이 정상 기준에 섞여 들어간다.** 은수님 지시대로 제외하고 기록만 남겼다.

### 3.3 정상군 안에서도 편차가 있다

500E -5.15, 500F -5.65, 500A -5.97 로 **0.82 dB** 벌어져 있다. PCB 상태의 0.18 dB 에 비하면 4 배가 넘는다. **기구 조립이 편차의 주된 원인**이라는 것을 뒷받침한다.

## 4. 원본 데이터에서 확인한 것

### 4.1 측정값이 헤더보다 한 행 아래에 있다

원본 시트를 그대로 읽으면 45 dB SPL 측정이 통째로 빠지고 마지막 행 데이터가 음압 없이 뜬다. 한 행 아래로 읽어야 맞는다.

| 확인 | 값 |
|---|---|
| 음압 값 개수 (4~17 행) | 14 (45~110) |
| 측정값이 있는 행 (5~18 행) | 14 |
| 4 행에 측정값 | 없다 (「최대/평균」 부제 행) |
| 18 행에 측정값 | 있다 |
| 18 행에 음압 값 | 없다 |

`analyze.py` 가 실행할 때마다 이 구조를 확인하고, 깨지면 경고를 낸다.

### 4.2 88 dB SPL 값이 튄다

| 음압 | 원본 | 모델 | 차 |
|---:|---:|---:|---:|
| 88 | **6564** | 6584.7 | **-20** |

다른 어긋남은 모두 ±1 의 부동소수점 차이인데 이 한 건만 크다. **6584 를 6564 로 잘못 적은 것**으로 보인다.

> [!WARNING]
> 이 문서에서는 **고치지 않았다.** 참조용 1.5세대 열에는 원본을 그대로 실었다.
> 원본 파일의 관리자가 확인할 사항이다.

### 4.3 500A 가 두 번 적혀 있다

16 열과 26 열이 모두 「500A」 이고 **모든 음압에서 값이 완전히 같다**. 중복 기재로 보아 한 번만 셈했다.

### 4.4 500C-2차는 홀수 음압이 결측이다

55, 65, 75, 85, 95, 105 dB SPL 이 비어 있다. 평탄 구간 표본이 4 점(80·90·100·110)뿐이다.

## 5. 이 표를 쓸 때

- **PCB 상태 열**은 기판 단위 시험이나 펌웨어·마이크 자체 특성을 볼 때 쓴다.
- **기구 조립 상태 열**은 완제품 상태 시험에 쓴다. 실제 제품이 이 상태다.
- 두 열의 차 **약 1.95 dB** 가 기구에 의한 감쇠다.
- 조립 편차가 정상군 안에서도 0.82 dB 있으므로, 개체 판정에 쓸 때는 여유를 두는 것이 좋다.
