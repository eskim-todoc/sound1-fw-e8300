"cis, nofm 출력 패턴" jpg 파일이 CIS 및 NofM을 사용할 때 출력되는 자극 파형의 패턴을 그린 모습이다.

사용 가능한 전극/채널은 32개를 예로 한 것이다.

편의상 Interleaved 된 상태로 하지 않고 채널을 번호 순서로 출력하는 것으로 표시하였다.

NofM은 항상 16ofM 으로 N은 항상 16개 이다. 그래서 M이 17개 이상이어야 의미가 있다. M이 16 이하이면 CIS를 사용한다.

e8300에서는 PCM 인터페이스를 사용해서 20bit 데이터를 하나의 채널 자극 정보 패킷으로 사용한다.
1ms에 24개의 PCM 패킷을 FIFO를 사용해 출력한다. 이게 무한히 반복되면서 PCM 패킷이 계속 전송되는 구조다.

PCM 패킷은 FPGA로 전송되어, FPGA가 todoc의 자체 프로토콜인 COLA 프로토콜로 변형하여 무선 링크 통신으로 내부이식장치에 전송한다.

자극 펄스는 biphasic 펄스이며, negative 펄스가 선행 펄스가 기본이다.
pulse phase는 최소 길이가 13usec 이다. 그래서 negative 13usec, interchange gap 4usec, positive 13usec 가 최소 자극 펄스의 형태이다.
이 최소 duration (=13)을 전송하는 COLA 프로토콜 시간이 약 33usec이다.

e8300의 PCM 프로토콜 clk는 480kHz이다. 그래서 20비트 PCM 패킷 하나 전송하는데 약 41.6usec가 소요된다.
펌웨어에서는 41usec로 계산하여 사용한다.
0.6usec 오차가 있지만, 여유 시간이 생기는게 오히려 좋다. 왜냐하면 전송하는 패킷에 대해서, 이전 PCM 패킷이 COLA로 변형되어 전송이 완료되기 전에 다음 PCM 패킷이 입려되면 clock rate 에러라는 상태로 진입하기 때문이다.

duration이 13을 초과하는 시점부터, 예를 들어 14는 14-3 = 1 이라서, COLA 프로토콜 전송 시간에 phase 별로 1씩 증가, 즉, 1 + 1 = 2가 늘어나는 구조이다. duration 14 = COLA 약 35usec.

단, 너무 타이트하게 맞추면 e8300과 FPGA간의 클럭 속도 차이 이슈도 있을 수 있기 때문에 10usec의 여유를 둔다.
그래서 duration에 따라 하나의 채널 정보를 전송해야 하는 PCM 패킷의 개수를 구하는 방법은 아래 함수를 참조하면 된다.

1, 2, 3, ..., 31, 32, 1, 2, 3, ..., 31, 32, 1, 2, ... 반복
이렇게 출력된다. jpg 그림의 패턴을 참고하면 된다.
1ms에 24개의 PCM 패킷이 전송되기 때문에 duraion이 13인 경우 채널당 1패킷이면 된다.
그래서 1ms에 24채널까지 전송하고, 다음 2ms 지점에서 남은 25~32채널 + 1~16채널 전송, 3ms 지점에 17~32채널 + 1~8채널, ... 이렇게 반복이다.
이에 따라 duration 설정에 따라 채널의 자극 rate이 변하게 된다.
duration 설정이 14인 경우 채널당 PCM 패킷 2개를 사용하므로 1ms에 전송하는 채널이 1~12로 줄어들게 된다. 이런 이유료 채널별 자극 rate가 변하게 되는것이다.
채널 31개만 사용 가능한 경우 1~24, 25~31+1~17, 18~31+1~14,... 이렇게 출력 패턴도 변하게 된다. 채널별 자극 rate도 마찬가지다.

NofM의 경우 항상 16개의 채널이 선택된다는 가정으로 동작한다.
NofM은 채널당 PCM 3패킷을 고정으로 사용하고 있어. 그래서 패킷 3개를 초과하는 duration은 사용할 수 없어. 대신, 채널의 자극 rate가 항상 일정한 구조야. 동일한 채널 16개가 매번 선택된다는 가정하에서 말이야. 그래서 채널 x PCM 패킷 3 x 8채널 = 24, 즉, 1ms에 8채널씩 전송. 결과적으로 2ms에 16개가 모두 출력되는 구조야. 그래서 자극 rate, PPS는 500이야.
