## TL;DR

"자극 펄스 상세(연속 2펄스)" 통계 행과 하단 요약/에러 박스를 완전히 제거하고, 대신 각 패널의 "자극 펄스" 행 자체에 예시 펄스 기준 (a)duration (b)펄스 폭 (c)다음 펄스까지 간격을 화살표+텍스트로 직접 표시하도록 재구성했다. 부수적으로 `#nofmDisabled`가 `[hidden]`에도 불구하고 항상 보이던 CSS 버그(전 라운드에서 추가한 `display:flex`가 원인)를 함께 수정했다.

## 부수 발견 및 수정: `#nofmDisabled` 항상 표시되던 CSS 버그

이전 라운드(레이아웃 점프 방지)에서 `.disabled-msg { display: flex; ... }`를 추가했는데, 이는 **AUTHOR 스타일시트 규칙이 UA 기본값 `[hidden]{display:none}`보다 우선 적용**되는 CSS 캐스케이드 규칙 때문에, `.hidden=true`를 줘도 실제로는 계속 `display:flex`로 보이는 버그였다(이전에 `canvas.tl-canvas{display:block}`에서 겪었던 것과 동일한 종류의 함정). 이번에 `.disabled-msg`에서 `display` 속성 자체를 제거해 근본적으로 해결했다 — 이제 `[hidden]` 시 확실히 안 보인다.

## 검증

Python으로 (a)(b)(c) 계산값을 여러 (K,p,isNofM) 조합에서 재현: duration=239(1ms당 1채널)처럼 다음 활성 그룹이 다음 ms로 넘어가는 경우까지 포함해 (c) 간격이 정확히 984usec(=1ms) 등으로 올바르게 계산됨을 확인했다. HTML/JS 정적 검사(괄호·태그·id 참조, 제거된 요소/함수의 잔여 참조 없음) 전부 통과.
