## TL;DR

사용자가 새 참고 이미지(`pcm, cola protocol data rate.JPG`)와 10개 구체적 피드백을 주어 전면 재작성했다. 재작성 직후 독립 검증 패스에서 "기본 화면 로드 시 채널 번호가 실제로는 안 보이는" 회귀 버그를 발견해 즉시 수정했다.

## 1. 새 참고 이미지 반영

`pcm, cola protocol data rate.JPG`: PCM clock 480kHz, 20bit/패킷, 41.6usec 주기 연속 전송. COLA는 66bit/패킷이며 **PCM 대비 정확히 1슬롯(41.6usec) 파이프라인 지연** 후 33usec 동안 전송(최소 duration 기준, 기존 `COLA(13)=2*13+7=33` 공식과 정합). 기존 구현은 COLA 활성구간을 PCM과 같은 슬롯에 겹쳐 그렸는데(구조적 오류), 이번에 `groupX + slotPx`로 1슬롯 시프트해 COLA·펄스 파형 행 모두 수정했다.

## 2. 피드백 10건 반영 요약

| # | 피드백 | 반영 내용 |
|---|---|---|
| 1 | PCM/COLA 이미지 참고 | 1슬롯 파이프라인 지연 구조 반영 + footer에 480kHz/20bit/66bit 명시 |
| 2 | 채널 번호 텍스트 표시 | 블록 안에 채널 번호(1~32) 텍스트 렌더링 |
| 3 | PCM 패킷 수 명확화 | 블록 내부 세로 구분선(패킷 경계)으로 시각화 |
| 4 | 라이트 테마만, 크림베이지+크림오렌지 | 다크모드 완전 제거, `--page-plane:#EFE7D6`(크림베이지)/`--cis-accent:#C15F3C`(크림오렌지), NofM은 보색 계열 딥틸 `#3E6E64`로 조합 |
| 5 | (a)+(b) 병합 | `채널 · PCM 패킷` 단일 행으로 통합 |
| 6 | NOP만 회색 구분 | idle 슬롯만 회색 계열(`--idle-fill`) — 활성 채널 틴트와 명확히 분리 |
| 7 | 가시성 개선 | 아래 §3 참조(회귀 버그 수정 포함) |
| 8 | 가로 폭 확장/반응형 | `main` 최대폭 1900px + `.scrollwrap` 실측 폭 기반 자동 슬롯 확대(`computeSlotPx`) + `resize` 이벤트 대응 |
| 9 | NofM 불가 시 명확 표시 | `nofmAvailability()`로 게이팅 — 불가 시 타임라인 자체를 렌더링하지 않고 "불가" 메시지로 완전 대체 |
| 10 | 전반적 완성도 | 독립 critique 에이전트로 검증(§3) |

## 3. 독립 검증(critique) 결과 및 후속 수정

재작성 직후 "회의적 UI/UX 검증자" 페르소나로 10개 항목을 코드에서 직접 재확인시켰다. 결과: 7개 PASS, 3개 PARTIAL.

- **#2 PARTIAL → 수정 완료**: `w>=15`일 때만 채널 번호를 그리는 조건 때문에, **기본 화면(duration=13usec, f=1, 기존 zoomRange 기본값 10px)에서 블록폭이 10px<15px가 되어 채널 번호가 전혀 안 보이는 회귀**가 있었다. 원인은 `computeSlotPx`의 자동 맞춤값(fitPx)이 10ms 창(240슬롯) 기준으로는 대부분의 화면 폭에서 사용자 최소값(당시 10px)에 그대로 머무는데, 10px는 텍스트 표시 임계값(15px) 미만이었기 때문. **수정**: ① 폰트 크기를 폭에 따라 적응형으로(`w>=22→12px`, `w>=8→9px`, 그 미만만 생략) 낮춰 대부분의 경우 항상 번호가 보이도록 함, ② 기본 표시 구간을 10ms→5ms로, 기본 슬롯 폭을 10px→14px로 올려 기본 화면에서부터 여유 확보. Python으로 1000~2200px 대의 여러 창 폭에서 재시뮬레이션해 f=1 블록도 항상 9px 폰트로 렌더링됨을 확인했다.
- **#6 PARTIAL → 수정 완료**: `--idle-fill`(#DCD3BC)이 CIS 최담색 틴트(#F5DECB)와 유클리드 거리 31로 너무 가까워 "진짜 회색"으로 안 읽힐 수 있다는 지적. `#C7C0B0`(더 무채색에 가깝게)로 교체, 거리 61로 확대. `--idle-border`도 `#AAA089`로 동반 조정.
- **#7 PARTIAL → 수정 완료**: `--text-muted`(#96877E)가 배경 대비 3.23:1로 WCAG AA(4.5:1) 미달이라는 지적. `#6E5F48`로 낮춰 surface-1 대비 5.69:1, page-plane 대비 5.03:1로 개선(Python WCAG 공식으로 재계산 확인).
- **부가 지적(반영)**: COLA/펄스 행의 "초과 시 빨간색 번짐" 로직이 범례 설명 없이 존재한다는 지적에 대해서는, **이 로직 자체가 이제 도달 불가능한 죽은 코드임을 재확인 후 완전히 제거**했다(NofM은 `nofmAvailability()`로 `frames(p)>3`일 때 렌더링 자체를 막으므로 오버플로우 케이스가 발생할 수 없고, CIS는 `f=frames(p)`로 항상 정확히 맞춰 계산되므로 애초에 초과가 불가능). `groupOverflow()` 함수와 관련 분기를 삭제해 코드도 단순해졌다.

## 4. 남은 한계

- 이번 회차도 브라우저 실행 없이 정적 코드 검토 + Python 시뮬레이션(대비비, 슬롯폭 계산)으로만 검증했다. 실제 브라우저에서 폰트 렌더링·캔버스 안티앨리어싱까지 확인한 것은 아니므로, 은수님이 직접 열어 특히 좁은 창 폭에서 채널 번호 가독성을 한 번 봐주시면 좋겠다.
