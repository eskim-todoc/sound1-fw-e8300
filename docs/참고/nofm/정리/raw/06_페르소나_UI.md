# CIS vs NofM 자극 출력 패턴 & PCM/COLA 타이밍 뷰어 — 시각 레이아웃 설계안

> 단일 HTML 페이지(프레임워크·CDN 無) 대상 와이어프레임 + 색상/타이포 스펙.

## 0. 핵심 설계 결정

| 결정 | 근거 |
|---|---|
| CIS/NofM = 스몰멀티플(상하 스택 2패널), 공유 ms축 | 두 계열 동시 비교 → 패널 분리, 축 공유 |
| 채널(1~32) 색상 = categorical 아님, sequential 1-hue 램프 | 32는 CVD-safe categorical 상한(8) 초과. 채널 번호는 전극 배열상 순서형 데이터 |
| CIS 패널 = blue 램프, NofM 패널 = aqua 램프 | 두 sequential 컨텍스트 동시 등장 시 각각 다른 hue 램프 |
| 활성/유휴 = 색상 축 재사용 금지, 명도·회색 톤으로 별도 인코딩 | 색상은 이미 채널 정체성 인코딩에 사용 중 → 이중 인코딩 방지 |
| (a)(b)(c) 행은 기본적으로 단일 레인(32개 레인 아님) | 한 순간엔 한 채널만 발화 → 시퀀스는 본질적으로 1차원 스트림 |
| 펄스 파형(d)은 ms 개관 + usec Pulse Inspector 인셋 이원화 | ms 창과 usec 펄스폭은 3~4자릿수 스케일 차이 → Focus+Context 패턴 |

## 1. 상단 컨트롤 패널

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ CIS vs NofM 자극 출력 패턴 & PCM/COLA 타이밍 뷰어              [표로 보기]  [☾ 다크모드]  │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 채널 수(N)         [──●───────────] [ 22 ] ch   (1–32)                                 │
│ phase duration     [───────●──────] [ 55 ] usec  (13–255)                              │
│ 표시 구간(ms 창)    ○5   ○10   ●20   ○50   ○100   [직접입력: ___ ms]                    │
│ CIS/NofM 동시비교   ( ● On  ○ Off )        Off일 때만 → 전략 선택 [ CIS ▾ ]              │
│ 펄스 확대(usec 줌)  [──●───────────]  1x                (Pulse Inspector 별도, §2 참조) │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

- 슬라이더+숫자입력은 항상 쌍(sync).
- "표시 구간(ms)"은 프리셋 라디오 + 커스텀.
- "CIS/NofM 동시비교" Off 시 패널 1개+전략 드롭다운으로 축소.
- "펄스 확대(usec 줌)"과 "표시 구간(ms)"은 별개 축 — 라벨로 명확히 구분(혼동 주의).

## 2. 메인 시각화 — CIS/NofM 스택 패널

```
┌ ms 눈금자 (0 1 2 3 … 20ms, 공유 x축) ─────────────────────────────────────────────────┐
│        0        5        10        15        20  (ms)                        [미니맵▾]│
├──────────────────────────────────────────────────────────────────────────────────────┤
│ CIS ▮blue                                                                    idle 32%  │
│ (a) 채널 시퀀스   █▓░█▓█░░█▓█░░█▓░█▓█░░█▓ ...                                          │
│ (b) PCM 슬롯 그리드│▪▪▫▪▪▪▫▫▪▪▪▫▫▪▪▫▪▪▪▫▫│ ...                                          │
│ (c) COLA 전송창    ▭▭▭▭▭    ▭▭▭▭▭    ▭▭▭  ...                                          │
│ (d) biphasic 파형  ⎍⎍ ⎍ ⎍⎍  ⎍ ⎍⎍⎍  ⎍ ⎍  ...  (요약 실루엣, 클릭→Inspector)             │
├──────────────────────────────────────────────────────────────────────────────────────┤
│ NofM ▮aqua                                                                   idle 51%  │
│ (a)~(d) 동일 구조                                                                       │
└──────────────────────────────────────────────────────────────────────────────────────┘
  채널 스케일:  1 ▮░░░░░░░░░░░░░░░░░░░░░░░░░░░░▮ 32   (그라디언트 범례, 8/16/24 눈금)
```

> [!WARNING]
> 위 목업의 "NofM idle 51%"는 **PCM 슬롯 레벨이 아니라 예시 수치**다. 실제로 NofM 정상 동작 시 PCM 슬롯 레벨 idle은 duration/채널수와 무관하게 **항상 0%**다(임베디드타이밍 페르소나 검증). 구현 시 "PCM 슬롯 레벨 유휴"(NofM=항상 0)와 "16-풀 대비 미선택 채널 비율"(채널 레벨, 가변) 두 지표를 반드시 별개 라벨로 분리해 표시할 것.

- **공유 crosshair**: 포인터 위치에 수직 헤어라인이 CIS+NofM 전체 8개 행 관통, 툴팁 1개가 해당 x의 모든 값 나열.
- **(a) 채널 시퀀스**: 색상 블록(rect), 블록 색=발화 채널 index의 sequential 램프 값. 확장 토글로 32개 레인 펼치기(가상화).
- **(b) PCM 슬롯 그리드**: 로직 애널라이저 스타일 고정폭 셀. 저배율에서 canvas density strip 자동 전환.
- **(c) COLA 전송 활성구간**: fill=실제 전송 중(풀톤), track=프레임 범위이나 비전송(밝은 스텝).
- **(d) biphasic 파형**: ms뷰는 canvas 2px stepped path 실루엣, 클릭 시 Pulse Inspector(usec 정확도 확대, negative-first 파형).

### 32채널 색상 팔레트 전략

- 32색 categorical 시도 안 함(CVD-safe 상한 8 초과) — 1-hue sequential 램프(OKLCH 보간, 채널1→32를 라이트→다크로 매핑).
- 활성/유휴는 색상 축과 분리 — 유휴는 항상 muted/gridline 회색.
- 범례는 그라디언트 스케일 바 + 1/8/16/24/32 눈금.

## 3. 요약 통계 카드 (KPI 행)

```
┌───────────┬───────────┬───────────┬───────────┬─────────────────────┐
│ 프레임 수  │ 채널 처리율│ 채널당 rate│ 유휴 슬롯  │ CIS ↔ NofM 유휴비율  │
│  22       │ 1.10/ms   │  50 pps   │ 12/ms(25%)│  ●───────○──●       │
└───────────┴───────────┴───────────┴───────────┴─────────────────────┘
```

- idle 비율 delta의 방향성(많을수록 좋음/나쁨은 목적에 따라 다름) → status 색(초록/빨강) 기본 적용 안 함, 중립 텍스트 잉크 사용.

## 4. 반응형/가독성 — 32채널 시 가로 확장 대응

1. 가로 스크롤 + sticky 헤더/좌측 라벨.
2. 줌 컨트롤(전체 타임라인용, "표시 구간"과는 별개 — 혼동 대표 실패 지점이므로 절대 같은 컨트롤로 섞지 않음).
3. 저배율 시 canvas density strip 자동 전환 + "세부 숨김 — 확대 필요" 배지.
4. 미니맵/오버뷰 리본(DAW 스타일).
5. 동시비교 Off 모드로 세로 공간 절반만 사용.

### 열린 질문

- NofM 채널 선택이 프레임마다 바뀌는 정도를 애니메이션으로 보여줄지 정적 스냅샷으로 할지 — 미정 시 정적 스냅샷 권장.
- COLA "전송 활성구간"의 정확한 On/Off 정의는 펌웨어 로직 확인 후 라벨 확정 권장.
