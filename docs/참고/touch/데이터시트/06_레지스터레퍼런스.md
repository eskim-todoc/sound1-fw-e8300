# IQS323 데이터시트 — 06 레지스터 레퍼런스 (§9 + 부록 A)

> **TL;DR**: IQS323 전체 레지스터 맵. §9 주소표(0x00~0xE1·기본값)와 부록 A(A.1~A.37) 비트필드를 통합한 SSOT. Sensor(0x30·40·50)·Channel(0x60·70·80)·Slider·Gesture·Filter Betas·System Control·General·I²C Settings. 펌웨어 작업 1차 참조. 원문 p.35~37, 49~64.

> [!NOTE]
> 동작 개념(LTA·ATI·UI 등)은 [`02_proxfusion동작.md`](02_proxfusion동작.md)·[`04_부가기능·UI.md`](04_부가기능·UI.md), 하드웨어 설정은 [`03_하드웨어설정.md`](03_하드웨어설정.md). 데이터는 16-bit word·**little endian**(LSB first), 각 주소에 2 byte.

### A.6 Conversion Frequency Setup (0x31, 0x41, 0x51) — 기본값 0x057F

| 비트 | 필드 | 값/의미 |
|---|---|---|
| 15-8 | Conversion Frequency Period (CONV_FREQ_PERIOD) | Range 0-127 |
| 7-0 | Conversion Frequency Fraction (CONV_FREQ_FRAC) | **Fix to 127** |

**Fraction은 127 고정 권장.** Period 값으로 conversion frequency 선택. Dead Time 설정 주의.

**Table A.1 — Capacitive Sensing** (Fraction=127, Dead Time **enabled**)

| Period | Conversion Frequency f_xfer |
|---|---|
| 2 | 1.75 MHz |
| 3 | 1.40 MHz |
| 5 | 1.00 MHz |
| 7 | 778 kHz |
| 12 | 500 kHz |
| 16 | 389 kHz |
| 23 | 280 kHz |

> self-capacitive 최대 권장 conversion frequency = 1 MHz, mutual-capacitive = 2 MHz.

**Table A.2 — Inductive Sensing** (Fraction=127, Dead Time **disabled**)

| Period | Conversion Frequency f_xfer |
|---|---|
| 0 | 7.00 MHz |
| 1 | 3.50 MHz |
| 2 | 2.33 MHz |
| 3 | 1.75 MHz |
| 4 | 1.40 MHz |
| 6 | 1.00 MHz |
| 8 | 778 kHz |
| 13 | 500 kHz |

> ⁱ IQS3ed 하드웨어는 bit11이 read only이며 항상 set. bit12가 양 하드웨어 리비전에서 80pF Cs를 enable. **IQS3ed용 product GUI로 생성한 header file을 IQS3dd에 사용 금지** — A.7의 reserved bit11이 set되어 sensing engine 정상 동작 방해 가능.
> ⁱⁱ CRx2/CTx2/Bias를 inductive 측정의 Rx로 사용 시 PXS Mode를 Current Measurement로 설정.
