# IQS323 데이터시트 — 08 개정이력·Known Issues (부록 B·C)

> **TL;DR**: 데이터시트 개정이력(v1.1 2022-08 ~ v1.11 2025-08)과 **Known Issues 2종**(① I²C Settings Register: v1.3↓ bit clear 불가 → reset 후 재기록 ② I²C Lock Up: 00x v1.3↓·A0x v1.4↓, 전 byte 상수 반환 → 매 통신 끝 없는 register read·0xEE 아니면 hard reset). 펌웨어 회피책 필수 참고. 원문 p.65~68.

> [!IMPORTANT]
> 부록 C Known Issues는 펌웨어 구현 시 직접 영향 — 특히 **I²C Lock Up 회피책**(매 통신 끝 존재하지 않는 register read 후 0xEE 확인)은 드라이버에 반영 검토 필요.

## 부록 C — Known Issues

### I²C Settings Register

- **Versions Affected**: IQS323-00x **v1.3 and below**.
- **Issue Description**: 한 번 set되면 `I2C Settings` register의 bit를 **clear할 수 없음**.
- **Recommended Workaround**: §6.6 가이드라인대로 device reset → I²C register bit clear됨. 단 master는 모든 application setting 재기록 필요. `Stop Bit Disable` bit가 set이어도 master는 §8.9의 terminate communications command로 communication window 닫기 가능.

### I²C Lock Up

- **Versions Affected**: IQS323-00x **v1.3 and below** · IQS323-A0x **v1.4 and below**.
- **Issue Description**: 특정 경우 IQS323이 **I²C로 read하는 모든 byte가 상수 값을 반환**하는 상태에 진입 가능. §8.13 force communications 방법 사용 시 발생 가능성↑.
- **Recommended Workaround**: 매 I²C 통신 끝에 **존재하지 않는 register에서 1 byte read**. 반환 값이 `0xEE`가 아니면 §6.6 가이드라인대로 IQS323 hard reset.
