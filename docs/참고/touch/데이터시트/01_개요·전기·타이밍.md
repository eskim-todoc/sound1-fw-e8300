# IQS323 데이터시트 — 01 개요·전기·타이밍 (§1~4)

> **TL;DR**: IQS323 = 3ch Self/Mutual-Cap + 2ch Inductive ProxFusion® 컨트롤러(14MHz, I²C ≤1MHz, VDD 1.71~3.6V). §1 개요·블록도, §2 핀맵 3종·신호·레퍼런스 회로, §3 전기특성(정격·소비전류), §4 타이밍(Reset·MCLR·I²C·Start-Up) 원문 정리. v1.11, 원문 p.1~14.

> [!NOTE]
> 본 문서는 Azoteq IQS323 데이터시트 **원문 1차 정리**(SSOT)다. 개념 해설·Sound1 적용은 [`../레퍼런스/`](../레퍼런스/) 2차 문서를 참조. 레지스터 비트 상세는 [`06_레지스터레퍼런스.md`](06_레지스터레퍼런스.md).

## 1. Device Overview (원문 p.1~2)

IQS323 ProxFusion® IC는 단일·이중 채널 센싱용 **센서 퓨전 디바이스**. 응용: 근접·터치 버튼, 슬라이더, 메탈 센서, wear-detection 쌍. 완전 I²C 호환이며 on-chip 연산으로 최저 전력 모드에서도 효과적으로 응답.

### 1.1 Main Features

- 고유연 ProxFusion® 디바이스, **외부 센서 패드 3개** 연결
- 외부 핀에 다중 채널 구성 (Self/Mutual/Inductive)
- 외부 센서 옵션:
  - Self-capacitive 버튼 3개
  - wear-detection 쌍 최대 2개 (공유 물리 reference)
  - Mutual-capacitive 터치/근접 센서 3개
  - Inductive 모드 센서 2개
- 내장 기본 기능: Automatic tuning, Noise filtering, 차동 측정(reference 채널), Debounce & Hysteresis, Dual direction 트리거, **Halt Mode**
- 내장 신호처리 옵션: Touch/Proximity 출력, Slider 출력, Gesture 출력, **Reference UI**, **Release UI**(Release UI order code 한정), **Movement UI**(Movement UI order code 한정)
- 자동 시스템 전력 모드 (응답 vs 소비 최적), **분산 ULP(Ultra Low Power) 모드**
- I²C 통신 + Ready Indicator (up to fast-mode-plus 1MHz), Event/Streaming 모드
- 공급 전압 **1.71 V ~ 3.5 V**
- 패키지: WLCSP11(1.48×1.08×0.345mm, **interleaved 0.35mm × 0.35mm** ball pitch), DFN12(3×3×0.75mm, 0.5mm pitch), QFN20(3×3×0.55mm, 0.4mm pitch)

> [!NOTE]
> 표지 부제는 "Supply Voltage 1.71 V to 3.5 V"로 표기되나, §3.2 권장 동작 조건의 VDD max는 3.6 V다(원문 그대로).

### 1.2 Applications

TWS 이어폰 · Wear detection · 방수 버튼(Inductive) · 저전력 wake-up 버튼/근접 · 시계·피트니스 밴드 · SAR safety sensor.

### 1.3 Block Diagram (Figure 1.4)

내부 구성: **Power Management**, **Clock System**, **14 MHz CPU**, **Custom Output**(→OutA), **ProxFusion Driver Engine**, **ProxFusion Sensing Engine (ADC)**(→CRx0/CRx1/CRx2), **I2C HW**(SDA/SCL/RDY ↔ MCU Master). 전원: VDD/VREG/VSS. 출력 TxA.
