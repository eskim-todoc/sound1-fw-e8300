# IQS323 데이터시트 — 07 Ordering·Package (§10~11)

> **TL;DR**: Order code `IQS323-zzz-ppb`(zzz: 001=0x44/002=0x58 Release UI, A01=0x44 Movement UI · pp: CS/QF/DN · b: R). Top marking 3종, 패키지 치수(WLCSP11 1.48×1.08, DFN12 3×3, QFN20 3×3) outline·footprint, Tape&Reel 사양을 원문 정리. 원문 p.38~48.

## 10. Ordering Information (원문 p.38~40)

### 10.1 Ordering Code

형식: **IQS323 zzz ppb**

**Table 10.1 — Order Code Description**

| 구분 | 코드 | 설명 |
|---|---|---|
| **IC NAME** | IQS323 | |
| **DEFAULT CONFIGURATION** (zzz) | 001 | I²C address = **0x44**. 3 button self capacitance with **Release UI**, configurable via I²C |
| | 002 | I²C address = **0x58**. 3 button self capacitance with **Release UI**, configurable via I²C |
| | A01 | I²C address = **0x44**. 3 button self capacitance with **Movement UI**, configurable via I²C |
| **PACKAGE TYPE** (pp) | CS | WLCSP11 package |
| | QF | QFN20 package |
| | DN | DFN12 package (On special order only ⁱ) |
| **BULK PACKAGING** (b) | R | WLCSP11 Reel (3000 pcs/reel) · QFN20 Reel (2000 pcs/reel) · DFN12 Reel (6000 pcs/reel) |

- **예시**: `IQS323001QFR`
- generic order code는 device 이름 + default config로만 참조. 예: `IQS323-00x`는 Release UI 모든 버전·모든 패키지·모든 bulk packaging 지칭.
- ⁱ Special order code는 더 큰 MOQ·긴 lead time·non-cancelable·non-returnable.

### 10.2 Top Marking

- **10.2.1 WLCSP11** (Figure 10.1): `IQS323` / `pppxx` — "ppp" = Product Code, "xx" = Batch Code.
- **10.2.2 DFN12** (Figure 10.2~10.4): `IQS323`/`pppxx` 또는 `IQS3dd`/`pppxx` 또는 `IQS3ed`/`pppxx`.
- **10.2.3 QFN20** (Figure 10.5): Azoteq 로고 + `IQS323` / `pppxx`.
