# IQS323 터치 회로 구성·분석 (Sound1)

> **TL;DR**: IQS323001CSR(U13)을 전원 스위치 겸 터치로 쓰는 Sound1 회로를 실제 회로도(JPG) 기준으로 정리하고, 데이터시트 권장값 대조·현재 구현(self-cap·FIXED·200ms 방전·CalCap)·이슈(채터링 재부팅·ESD·드리프트)를 회로 관점에서 분석한 개선 스터디 기반 문서. C54는 실측 **4.7µF**(요구사항 ASCII의 4.7nF는 오기).

> [!NOTE]
> 본 문서는 `touch/개선/` **스터디 기반 자료**(분석 포함). 회로 사실의 ground truth는 [`../Touch Sensor Schematic.JPG`](../Touch%20Sensor%20Schematic.JPG). 순수 회로 레퍼런스는 [`../레퍼런스/IQS323-회로-구성.md`](../레퍼런스/IQS323-회로-구성.md), 데이터시트 원문은 [`../데이터시트/`](../데이터시트/), 사용 시나리오·이슈 원본은 [`../개발 요구 사항 및 예상 문제 정리.md`](../개발%20요구%20사항%20및%20예상%20문제%20정리.md).

## 1. 개요

| 항목 | 내용 |
|---|---|
| 부품 | IQS323001CSR (Azoteq ProxFusion®, WLCSP11, U13) |
| 용도 | **전원 스위치 겸 터치 센서** |
| 현재 측정 방식 | Self-Capacitance, **CRX0(CH0) 단일 채널**만 활성 |
| 호스트 | Ezairo8300 (E8300) — I²C 마스터 |

**사용 시나리오** (요구사항 문서):
1. 터치 센서를 전원 스위치로 사용
2. 절전 모드에서 2~3초 지속 터치 → 노말 모드 부팅 (**E8300만** 워치독 리셋)
3. 노말 모드에서 2~3초 지속 터치 → 절전 모드 진입
4. 노말·절전 모드에서 터치 센서 전원은 **중단되지 않음**
5. 보드 최초 전원 연결 시에만 터치 센서 **콜드 부팅**

> 즉 터치 IC는 (콜드부트 1회를 제외하면) 상시 전원이 유지되고, E8300만 워치독 리셋되는 비대칭 전원 구조다. 이 비대칭이 후술하는 "터치 중 초기화 먹통"·"드리프트" 이슈의 근원이다.

```
1.8V_QCC ── R28(0Ω/1005) ──┬──────────────── VDD (C5)
                            ├── C54(4.7µF/0603) ── GND   (벌크)
                            └── C55(100pF/0603) ── GND   (고주파)

VREG (A3) ──┬── C56(2.2µF/0603) ── GND   (벌크)

RDY (C7)  ──── C58(1nF/0603) ── GND
```

### 데이터시트 §2.5 권장 대조

| 노드 | 데이터시트 권장 | 실제 회로 | 판정 |
|---|---|---|---|
| VDD | 100pF + 4.7µF | C55 100pF + **C54 4.7µF** | ✅ 일치 |
| VREG | 100pF + 2.2µF | C57 100pF + C56 2.2µF | ✅ 일치 |
| RDY/MCLR | 1nF | C58 1nF | ✅ 일치 |

- **R28 (0Ω/1005)**: 전원 점퍼. 페라이트 비드 교체 또는 전류 측정용 절단 지점. 현재 0Ω이라 **전원 경로 필터링 없음**(채터링·ESD 관점 §11 참조).
- VREG는 내부 레귤레이터 출력 핀으로 외부 전원 없이 디커플링만 부착해 안정화.

## 6. 디지털 인터페이스

| 신호 | 방향 | 연결 |
|---|---|---|
| SDA_E8300 | 양방향 | E8300 I²C 마스터 ↔ IQS323 슬레이브 (주소 0x44) |
| SCL_E8300 | E8300 → IQS323 | I²C 클럭 |
| INTERRUPT_n | IQS323 → E8300 | RDY 핀 (Active Low) |

> [!NOTE]
> **I²C 풀업 저항(SDA/SCL/RDY)이 IQS323 회로 측에는 없다.** 데이터시트 §2.5 레퍼런스는 4.7kΩ 풀업을 권장하므로, 풀업은 **E8300(마스터) 측에 있는 것으로 추정**된다(확인 필요). RDY는 open-drain active-low이므로 풀업이 필수다.
>
> 현재 SW는 RDY 인터럽트가 아닌 **poll 방식**(`tdc_drv_iqs323_read_status()`)으로 상태를 읽는다. 스트리밍 모드 운용([§10])과 정합.

## 7. 아날로그 채널

### 7.1 CRX0 (CH0) — 활성 채널

```
CRX0 (B2) ── R31(100Ω/0603) ── C51(100pF/0603) ── J3 ── 터치 전극 패드
```

- **R31 (100Ω)**: ESD 전류 제한 + 고주파 필터용 직렬 저항.
- **C51 (100pF)**: R31과 RC 저역통과 필터 형성.
  $$f_c = \frac{1}{2\pi R C} = \frac{1}{2\pi \times 100 \times 100\text{p}} \approx 15.9\ \text{MHz}$$
- **J3 (SCS05-065-10)**: 스프링 핀 커넥터 → 제품 PCB 터치 전극 패드.

> [!WARNING]
> R31=100Ω은 데이터시트 §2.5 권장 직렬 저항 **470Ω보다 작다.** 데이터시트는 470Ω을 "수신·방사 EMI 방지 + ESD 보호 추가" 목적으로 권장한다([01 §3.2 각주]). 100Ω은 RC 필터 fc를 높이고 ESD 보호 여유를 줄이는 방향 — ESD 누적 먹통 이슈([§11])와 연관 가능성. (분석)

### 7.2 CRX1 (CH1) — 배선 완료, SW상 CalCap

```
CRX1 (A1) ── C52(100nF/0603) ── R32(0Ω/0603) ── J4
```

- **C52 (100nF)**: CH0(C51=100pF) 대비 1000배 큰 직렬 커패시터 → DC 차단(AC 커플링) 특성. 외부 전극 라인.
- **R32 (0Ω)**: 저항 삽입 가능 위치.
- **J4 (SCS05-065-10)**: J3와 동일 규격. HW 배선은 완료, 전극 연결은 미사용.

> [!NOTE]
> 현재 구현([§10] #4)에서 **CRX1을 내부 CalCap(데이터시트 §5.12.3)으로 SW 설정**한다 — "CRX0를 주기적으로 VSS로 두려면 활성 채널이 최소 1개 필요"하기 때문에 CRX1을 더미 활성 채널(CalCap)로 쓴다. 이 SW상 CalCap 설정은 IC **내부** 기능이며, 외부 회로의 C52 100nF·J4 배선과는 직접 관련이 없는 것으로 보인다. (추정 — 확인 필요)

### 7.3 CRX2 (CH2) — 미연결

```
CRX2 (C1) ── R33(470Ω/0603) ── ✕ NC
```

- 470Ω 종단만 있고 전극 연결 없음. 완전 미사용. (직렬 저항값은 데이터시트 권장 470Ω과 일치)

## 10. 현재 구현과 회로의 관계

요구사항 문서 "현재 구현된 사항":

| # | 구현 | 회로/데이터시트 근거 |
|---|---|---|
| 1 | Self-Cap, CRX0 사용 | PXS Mode 0x10, CRX0/CTx0 동일 채널 ([데이터시트 02 §5.12.1, 06 A.7]) |
| 2 | autoATI 미사용, MULT·COMP **FIXED** | ATI Mode를 'Compensation Only' 등으로 고정, divider/multiplier 수동 ([06 A.12]) |
| 3 | 200ms 주기 CRX0→VSS→재측정 (캡 방전 유도) | Inactive Rxs 'VSS'([06 A.10])를 활용한 self-cap 드리프트 억제 |
| 4 | CRX1을 CalCap 설정 (활성 채널 ≥1 필요) | 내부 CalCap([데이터시트 §5.12.3])을 더미 활성 채널로 |
| 5 | 스트리밍 모드 동작 | Interface Selection=0 ([06 A.30]) |

> 핵심: autoATI를 **포기**하고 FIXED + 주기 방전으로 우회한 구조다. autoATI를 안 쓴 이유는 "전원 버튼 겸용이라 터치 중 ATI가 걸리면 먹통"([§11])이며, 그 대가로 드리프트·카운트 변동을 SW로 떠안았다.

## 11. 이슈의 회로적 해석

요구사항 문서 "예상 이슈"를 회로 관점에서 정리한다.

### 11.1 충전 케이블 채터링 → 재부팅 우려

- 충전 케이블 연결 시 터치 IC 전원에 **~1µs 채터링** 발생, IC 재부팅 여부 불확실(요구사항 "주의사항").
- 회로적 요인: **R28이 0Ω**이라 전원 경로 필터링이 없고, VDD 디커플링(C54 4.7µF + C55 100pF)만으로 µs급 채터링을 흡수해야 함. 데이터시트 §4.1 reset trigger는 전원 slope(>100V/s)·레벨(power-up 1.65V·power-down 0.9V) 기반이므로([01 §4.1]), 채터링이 이 임계를 건드리면 reset 가능.
- 보수적 설계 방향(요구사항): 전원 불안정에 의한 재부팅을 **가정**하고 SW가 콜드부트와 동일하게 복구하도록.
- 회로 측 완화 후보: R28 자리에 **페라이트 비드** 또는 작은 직렬 저항 + VDD 벌크 증강. (개선 검토 §12)

### 11.2 ESD 누적 → 터치 먹통

- 현상(기존 [RESEED.md] 맥락): 절전 2~3회 반복 후 터치 먹통, GND 쇼트 시 정상 복귀 → ESD 전하 누적 추정.
- 회로 방어 요소: **R31(100Ω)** + **C51(100pF)** 이 CRX0 입력을 보호하나, R31이 권장 470Ω보다 작아 ESD 방전 전류 제한이 약함. 전원 경로(R28 0Ω)도 ESD 우회로가 될 수 있음.
- SW RESEED로는 미해결([RESEED.md]) → HW 측 보강 필요.

### 11.3 드리프트·카운트 변동·threshold 들쭉날쭉

- FIXED MULT·COMP 사용 → autoATI의 내부 충/방전 보정이 없어 **self-cap 드리프트** 발생. 일정 터치 횟수 후 먹통.
- 대응: 200ms 주기로 CRX0를 VSS로 방전([§10] #3).
- 잔여 문제: RESEED로 LTA 초기화할 때마다 **카운트 기준이 달라짐**(340~660대) — MULT·COMP가 고정이라 그 시점 정전용량에 따라 raw count가 변동. 고정 threshold와 맞물려 터치 감도가 들쭉날쭉.
- 회로 vs SW: 이 이슈는 1차적으로 **운용 전략(FIXED vs autoATI)** 문제이며 회로보다 펌웨어 영역. (후속 스터디 [README])

### 11.4 전원 버튼 겸용 → 터치 중 초기화 먹통

- 절전↔노말 전환 시 E8300만 리셋되고 터치 IC는 전원 유지([§1] 비대칭 구조). 전환 트리거가 "지속 터치"이므로 **초기화 시점에 손가락이 닿아 있는** 상태가 빈번.
- autoATI를 쓰면 터치 중 ATI가 그 정전용량을 기준으로 잡아 터치 해제·재터치가 인식 안 됨. → autoATI 포기의 직접 원인.

## 12. 개선 검토 포인트 (회로 관점)

> 펌웨어 측 개선(autoATI 재도입 여부·드리프트 대응 알고리즘 등)은 후속 스터디([README] 로드맵)에서 다룬다. 여기서는 **회로 관점** 후보만.

- **전원 안정화 (채터링/ESD)**: R28(0Ω) 자리에 페라이트 비드 또는 소직렬 저항 + VDD 벌크 보강 → µs 채터링·전원 경유 ESD 완화.
- **CRX0 ESD 보강**: R31을 100Ω→데이터시트 권장 470Ω 방향으로 재검토(단, RC fc·감도 영향 동시 평가).
- **Guard electrode (능동 실드)**: 미사용 자원 활용 — **CRX1(J4)** 또는 **TxA(B6, 현재 NC)** 를 guard ring 구동에 사용해 CH0 전극 주변 간섭·ESD 경로 차폐. (기존 [회로-구성.md §8] 검토안 계승)
- **I²C 풀업 확인**: 회로 측 부재 → 마스터 측 풀업 실재·값 확인(RDY open-drain 필수).

> [!NOTE]
> 위 항목은 **검토 후보**이며 실증·측정 전 확정안이 아니다. 실제 변경은 측정(채터링 파형·ESD 재현·전류 실측)으로 검증 후 결정.
