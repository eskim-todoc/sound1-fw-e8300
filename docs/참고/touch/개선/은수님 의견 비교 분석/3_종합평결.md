# 03 · 종합 평결

> **TL;DR**: 은수님 안은 **방향(auto-ATI 복귀·빠른 수렴·드리프트 해소)이 옳고, 핵심 통찰("잘못 시딩돼도 자기정상화 → B1 시점 의존 우회")이 가치 있다.** 단 검증 결과 ① 메커니즘 설명 일부가 데이터시트와 반대(frozen) ② 단독 채택은 위험(손 안 떼면 고착·약터치 흡수·I²C 무응답·Max stuck). **은수님 안과 이전 결론은 상보 — 최적해는 하이브리드**(ATI Full + 노터치 게이트 + Fast Filter Band 비대칭 BETA + 터치중 차단 + 통신관리).

## 1. 페르소나 verdict 분포

| 페르소나 | verdict | 한 줄 |
|---|---|---|
| A1 Steelman | 조건부지지 | "올바른 시딩"이 아니라 "잘못 시딩돼도 자기정상화" → B1 우회. 약점: ATI Full의 I²C 무응답 |
| A2 데이터시트 | 조건부지지 | 결과 달성 가능, 단 **ATI는 LTA seed 안 함**·**frozen 명명 정반대** |
| A3 BETA 동역학 | 조건부지지 | 빠른 BETA 약터치 흡수 위험, **Fast Filter Band 비대칭 설계가 해법** |
| A4 Adversarial | **반대** | frozen 반증·M5↔M6 자기모순·Max stuck·I²C 무응답·진동 |
| A5 이전결론 대조 | 조건부지지 | 두 안 목표 동일, 충돌은 "노터치 게이트" 한 줄 → **하이브리드 최적** |
| A6 절전·실측 | 조건부반대 | **BETA·전력모드·auto-ATI 현 코드 부재**, M7·M8 반증(절전 세팅 실재·방전≠ATI) |

→ **다수(4) 조건부지지, adversarial 반대, 절전 조건부반대.** 즉 "목표는 타당하나 조건·수정 다수, 단독 채택 불가".

## 2. 명제 M1~M8 판정

| 명제 | 판정 | 근거 |
|---|---|---|
| M1 (터치 중 ATI가 MULT/COMP 적절 세팅) | 조건부 | 정규화 가능(V3), 단 Max stuck·역앵커링 위험 |
| M2 (ATI 직후 LTA가 터치 카운트 seed) | **반증(부분)** | ATI는 LTA seed 안 함(V2). 수렴은 IIR 추적 동력 |
| M3 (손 떼면 LTA 노터치 수렴→인식) | **성립** | §5.5 IIR + self-cap 부호 (V1·V2 Part2) |
| M4 (터치 인식 시 LTA frozen) | 성립(일반) / 부팅선 미적용 | frozen은 인식 후만 (V1) |
| M5 (빠른 BETA 수렴 가속) | 조건부 | 미구현 신규, 약터치 흡수 위험·Fast Filter 비대칭 필요 (V4·A3) |
| **M6 (터치부팅 시 해제 전 LTA 멈춤→자기정상화)** | **결과 성립 / 메커니즘 반증** | "frozen 부재 덕분", 손 떼야 정상화 100% 의존 (V1) |
| M7 (절전 추가세팅 불필요) | **반증** | apply_sleep 255/255→reseed 다단계 실재, 현 코드 IC 전력모드 미사용 (A6) |
| M8 (auto-ATI가 방전 대체) | **반증(메커니즘 상이)** | ATI=LTA 재캘리브, 방전=물리 전하 제거. LTA 드리프트는 해결하나 ESD 물리누적은 별개 (A6) |

## 3. 은수님 안 vs 이전 결론 — 상보 관계

**목표는 동일**(양쪽 다 ATI Full·빠른 수렴·드리프트 해소). **충돌은 단 한 축**: LTA를 새로 잡는 순간 손가락 여부 확인 여부.

| 축 | 은수님 안 | 이전 결론(B1/S2) |
|---|---|---|
| 진입 baseline | 잘못 잡혀도 자기정상화(손 떼면) | 노터치 게이트로 처음부터 안 오염 |
| 강점 | 시점 의존 우회(단순)·과도구간 BETA 단축 | 손 안 떼도 안전·I²C hang 차단 |
| 약점 | 손 안 떼면 고착·약터치 흡수·I²C 무응답 | 게이트 임계 튜닝·과도구간 미보강 |

→ **상보**: 은수님(빠른 수렴·자기정상화 발상) + 이전(노터치 게이트 안전망). 은수님의 **빠른 BETA·Fast Filter Band 비대칭**은 이전 결론이 안 다룬 **과도구간 단축**을 메우는 정당한 기여.

## 4. 평결

### 받아들일 것 (은수님 기여)
- **ATI Full 복귀** 방향 — 드리프트·카운트변동(이슈6·8·9) 해소. (이전 결론과 합치)
- **빠른 회복**(Fast Filter Band 비대칭) — 손뗌 후 과도구간 단축. self-cap 방향성 활용한 영리한 설계.
- **자기정상화 관점** — baseline이 일시 오염돼도 회복하는 robustness는 안전망과 결합 시 견고성↑.

### 수정·보완할 것 (검증이 드러냄)
1. "frozen 덕분" → "frozen 부재 덕분"으로 **메커니즘 재인식**. 부팅 시 터치 미인식 구간 존재를 전제.
2. **노터치 seed 게이트 필수**(이전 B1) — "손 안 떼면 고착" 안전망. `boot_touch_ignore`(`tdc_touch.c:318~325`) 승격.
3. **빠른 BETA 단일 상향 금지** — 일반 LTA beta 보수적 + Fast Filter Band로 회복만 가속(비대칭).
4. **터치중 Re-ATI 차단** — 진동·재보정 방지.
5. **I²C 통신관리 선행**(RDY 핸드셰이크·타임아웃) — ATI Full 재활성 = 현 펌웨어가 끈 I²C 무응답 재현 방지.
6. **Max Counts 설정 검토** — 강터치 stuck 방지.
7. **드리프트 정체 실측** — LTA 드리프트(ATI 해결) vs ESD 물리누적(방전 필요) 구분. 방전 제거는 ESD 실측 후.

### 하이브리드 (최적해)
**ATI Full + 노터치 seed 게이트 + Fast Filter Band 비대칭 BETA + 터치중 Re-ATI 차단 + I²C 통신관리.** 상세는 [개선/제어 재설계 분석·권고 §하이브리드](../제어%20재설계%20분석·권고.md).

## 5. 실측 게이트 (은수님 안 관련 추가)

기존 3종(오염 실채널·1ch 전류·0x30 Linearise)에 추가:
- **BETA 부호 세만틱** — Beta 클수록 빠름(데이터시트 §5.6)인지 실칩 확인(A6 단 일부 제품군 역정의 가능성).
- **자기정상화 과도구간** — 손뗌~수렴 동안 재터치 미인식 빈도·시간.
- **ATI Full I²C 무응답** — Full 재활성 시 RDY 윈도우 점유로 통신 멈춤 재현 여부.
