# 02 · 핵심 주장 adversarial 검증

> **TL;DR**: 6 페르소나 분석의 낙관·할루시네이션을 차단하기 위해, 은수님 안의 4개 핵심 주장을 데이터시트 원문·코드로 독립 재검증. **4건 모두 "조건부성립"** — 결과(목표)는 달성 가능하나, 메커니즘 설명·전제·안전성에 수정이 필요. 특히 V1(자기정상화)은 "frozen 덕분"이 아니라 "frozen 부재 덕분"으로 인과가 정반대.

> [!NOTE]
> 입력: [00 은수님 의견](00_은수님-의견-입력.md). 검증자는 6 분석을 맹신하지 않고 데이터시트 §·코드 라인을 1차 근거로 재검증함.

---

## V1 · 자기정상화 (M6/7번) — 조건부성립

- **결과 성립**: §5.5 IIR `LTA_new = LTA_old + (Counts−LTA_old)×(Beta/256)`. frozen이 아니면 LTA가 현재 counts로 수렴 → 손 떼면 노터치(500) 추적 → 이후 터치 시 인식. **은수님 3~5단계와 정확히 일치**.
- **🔴 메커니즘 명명 반증**: 은수님 7단계 "frozen 덕분에 LTA가 멈춰 자기정상화"는 **인과 정반대**. 부팅 baseline=터치 → delta≈0 → `(LTA−Counts)>Threshold` 미달 → **CHx Touch bit 미set → frozen 미발동** → LTA가 터치 카운트를 IIR 추적. 자기정상화는 **frozen이 "없어서"** 일어난다.
- **🔴 "손 떼야 정상화" 100% 의존**: §5.5 line348 직접 경고 — "터치 중 LTA 갱신되면 터치 counts를 baseline 학습 → 해제 미인식". **부팅 후 손 안 떼면 LTA는 영구히 터치 카운트에 고착**.
- **반례**: (가) 부팅 후 지속 접촉 → 자기정상화 0%, 영구 고착 (나) 빠른 BETA가 정상화 가속 vs 약터치 흡수 자기모순 (다) Fast Filter Band 미설정 시 노이즈까지 가속.

## V2 · LTA seed (M2/2번) — 조건부성립

- **🔴 Part1 반증**: "auto-ATI가 LTA를 seed한다"는 **데이터시트에 없음**. §5.9는 MULT/COMP/divider만 조정(counts를 ATI Target에). LTA seed는 §5.5.1 **별개 Reseed**(수동) 또는 §5.5 IIR. → A2가 "메커니즘 정확히 일치"라 한 건 seed 단계를 데이터시트 없이 가정한 낙관. **B1(오염 실채널=Reseed)과 정합**.
- **Part2 성립**: "손 떼면 LTA가 노터치 추적"은 §5.5 IIR로 성립. → 은수님 4단계 수렴은 **ATI seed가 아니라 순수 IIR 추적**에 의존(불필요한 가정 제거).

## V3 · auto-ATI 안전성 (M1/1번·Q5) — 조건부성립

- ATI Target = ATI Base × (ResFactor/16). 코드 ATI Setup `0x0408` → ResFactor 64 → **Target = Base(100)×4 ≈ 400**.
- **(1) Max Counts**: write 0건 → reset Max Counts **1023**. 노터치 500 < 1023 명목 안전. **단 강터치(매우 낮은 터치 카운트) 보정 시 노터치 카운트가 1023 초과 → conversion 정지·max stuck → 영구 미인식**.
- **(2) 정규화**: 터치 카운트를 anchor로 정규화 → 설계 의도(노터치 baseline) 역앵커링(데이터시트 위반 아니나 의도 역전).
- **(3) 🔴 Re-ATI 진동·I²C hang**: 터치-해제 반복 시 노터치 카운트가 ATI Band 경계 횡단 → Full 모드 auto Re-ATI 반복 → **§(코드 line561·658) "Full Mode auto-ATI 중 I²C 무응답" 재현**. 현 펌웨어가 ATI Disabled로 차단한 바로 그 장애.

## V4 · 빠른 BETA 흡수 (M5/6번) — 조건부성립

- **BETA 물리 성립**: §5.6 "Beta 클수록 빠르게 추적". 빠른 LTA beta가 sub-threshold 구간 delta를 깎아 **약/느린 터치 흡수 가능**(인공와우 사용자 특성과 겹치면 미인식 회귀).
- **frozen 게이트**: 인식된 터치 중엔 BETA 무의미(흡수 불가). 흡수는 (a) 부팅 미인식 구간 (b) sub-threshold 약터치만.
- **🟢 Fast Filter Band 결합 — 반증(은수님 유리)**: §5.6 "counts가 **sensing 반대 방향**(=손뗌, counts 증가)으로 drift 시 fast filtering". self-cap 터치(counts 감소)엔 **발동 안 함**. → **Fast Filter Band가 터치 흡수를 가속한다는 우려는 메커니즘상 반대**. 오히려 손뗌 회복 가속용.
- **🎯 안전 설계 도출**: 흡수는 **일반 LTA beta(0xB1)만의 함수**. → **일반 beta 느리게(약터치 보호) + Fast Filter Band/Fast beta로 손뗌 회복만 가속**하는 **비대칭 설계**가 trade-off 회피 경로(데이터시트 §5.6 비대칭 근거).

## 검증 종합

| 주장 | holds | 한 줄 |
|---|---|---|
| V1 자기정상화 | 조건부성립 | 결과 ○, 메커니즘 명명 ✗(frozen 부재 덕분), 손 떼야 정상화 100% 의존 |
| V2 LTA seed | 조건부성립 | ATI seed 데이터시트 부재 → IIR 추적이 실제 동력(B1 정합) |
| V3 auto-ATI 안전 | 조건부성립 | Max stuck·Re-ATI 진동·**I²C 무응답 재현**(ATI Full의 핵심 리스크) |
| V4 빠른 BETA | 조건부성립 | 단일 상향 위험, **Fast Filter Band 비대칭이 안전 정답** |

**확정 사실**: 자기정상화 결과는 성립(self-cap 부호+IIR). **반증**: "frozen 덕분"·"ATI가 LTA seed"·"auto-ATI가 방전 대체"(A6). **재등장 리스크**: ATI Full → I²C 무응답(현 펌웨어가 끈 이유). **실측 필요**: BETA 부호 세만틱·과도구간 미인식·Max Counts 헤드룸·드리프트 정체(LTA vs ESD).
