# IQS323 펌웨어 적용값 분석 — RDY 타이밍 ground truth

> **TL;DR**: Sound1 펌웨어가 IQS323에 실제 write하는 설정값 전수 추출. Report Rate/Power Mode/I²C 통신 모드/Transaction Timeout 등 RDY 주기 결정 인자를 코드 근거와 함께 정리하고, 정상 운용 시 RDY 주기(T_주기)·t_Low·t_High 추정치를 산출.

| 항목 | 내용 |
|---|---|
| 역할(페르소나) | Sound1 펌웨어 적용값 분석가 (노드 04) |

## 1. Report Rate 설정

| 레지스터 | 이름 | write 값 | 의미 |
|---|---|---|---|
| 0xC1 | Normal Power Report Rate | **write 없음** (기본값 0x0000) | default = 0 ms → IQS323 최대속도로 연속 업데이트 |
| 0xC2 | Low Power Report Rate | **write 없음** (기본값 0x0000) | 동일 |
| 0xC3 | Ultra Low Power Report Rate | **write 없음** (기본값 0x0000) | 동일 |
| 0xC4 | Halt Mode Report Rate | **write 없음** (기본값 0x0000) | 동일 |

> [!NOTE]
> `tdc_drv_iqs323_apply_settings()` 및 `tdc_drv_iqs323_apply_sleep_settings()` 어디에서도 0xC1~0xC4에 write하는 코드가 존재하지 않는다. 데이터시트 기본값 0x0000 = 0 ms. IQS323 데이터시트에 따르면 Report Rate = 0이면 측정 완료 즉시 RDY를 열어 통신 윈도우를 제공한다.

## 2. 전력 모드 설정

모든 System Control(0xC0) write에서 LSB bits[6:4](Power Mode 필드)를 확인한다.

| 호출 지점 | LSB 값 | MSB 값 | Power Mode bits[6:4] | Interface bit[7] | 의미 |
|---|---|---|---|---|---|
| `ack_reset_event()` — `tdc_drv_iqs323.c:382` | 0x01 | 0x00 | 000 | 0 | Normal Power + Streaming |
| `tdc_drv_iqs323_reseed()` — `tdc_drv_iqs323.c:945` | 0x08 | 0x00 | 000 | 0 | Normal Power + Streaming + Reseed |
| `tdc_drv_iqs323_apply_sleep_settings()` CH_TIMEOUT — `tdc_drv_iqs323.c:1024` | 0x00 | 0x07 | 000 | 0 | Normal Power + Streaming + CH Timeout Disable |
| `tdc_drv_iqs323_apply_settings()` Reseed — `tdc_drv_iqs323.c:1147` | 0x08 | 0x00 | 000 | 0 | Normal Power + Streaming + Reseed |
| `tdc_drv_iqs323_apply_settings()` CH_TIMEOUT — `tdc_drv_iqs323.c:1155` | 0x00 | 0x07 | 000 | 0 | Normal Power + Streaming + CH Timeout Disable |

**결론**: 펌웨어는 **Power Mode = 000 (Normal Power)** 만 write한다. Automatic·Low·ULP 모드로 전환하는 write는 코드에 없다.

### Power Mode Timeout (0xC5)

write 없음 — 기본값 0x0000 (0 ms).

> [!NOTE]
> Power Mode가 Normal Power 고정이므로 Timeout은 의미 없음. 코드에서 0xC5 레지스터에 대한 write 호출이 전혀 없다.

### ULP 사용 여부

IQS323의 ULP 모드(Power Mode = 010)를 활성화하는 write가 없다. 펌웨어 내부 플래그 `g_tdc_iqs323_in_ulp_mode`는 절전 설정 적용 여부를 추적하는 **SW 플래그**일 뿐이며, 실제 IQS323 레지스터의 ULP 모드와 무관하다. IQS323은 항상 Normal Power 모드로 동작한다.

## 3. 통신 모드 — Streaming vs Event

System Control(0xC0) LSB bit[7] = Interface Selection.

| bit7 값 | 모드 | 동작 |
|---|---|---|
| 0 | **I²C Streaming** | IQS323이 측정 완료마다 자동으로 RDY를 LOW로 당겨 통신 윈도우를 연다 |
| 1 | I²C Events | 설정된 Event 발생 시에만 RDY LOW |

모든 write에서 bit7 = 0. **Streaming 모드** 적용.

### Events Enable (0xD3) 설정

`events_enable()` — `tdc_drv_iqs323.c:423~437`:

| 필드 | 설정값 |
|---|---|
| ATI Error | ENABLE (1) |
| ATI Event | ENABLE (1) |
| Power Event | DISABLE (0) |
| Slider Event | DISABLE (0) |
| Touch Event | ENABLE (1) |
| Prox Event | DISABLE (0) |

> [!NOTE]
> Event Mode(bit7=1)가 아니므로 Events Enable 비트는 Streaming 모드에서 **RDY 발생 트리거 조건에 영향을 주지 않는다**. Streaming 모드에서는 측정 완료 시 무조건 RDY가 LOW로 떨어진다. Events Enable은 System Status 레지스터의 event flag 세트 여부에만 관여한다.

---

## 4. I²C Transaction Timeout (0xD1)

write 없음 — **기본값 0x00C8 = 200 ms**.

`tdc_drv_iqs323.c` 및 `tdc_drv_iqs323_apply_settings()` 내부에서 0xD1 레지스터에 대한 write 호출이 전혀 없다. 데이터시트 기본값인 **200 ms**가 적용된다.

---

## 5. Auto Prox Cycle Select (Prox Input and Control 0x33 bits[3:2])

0x33 레지스터에 대한 write 없음 — **기본값 0x01CF 유지**.

기본값 0x01CF의 bits[3:2] = 11 → Auto Prox Cycle Select = **32 conversion/RDY**. 그러나 Power Mode = Normal Power이므로 Auto Prox Cycle Select는 ULP(Auto Mode) 전용 설정이며 Normal Power에서는 적용되지 않는다.

---

## 6. RDY 수신 방식 — 폴링 vs 인터럽트

`is_rdy_window_opened()` — `tdc_drv_iqs323.c:115~118`:

```c
return (Sys_GPIO_Read(TDC_DRV_IQS323_RDY_PIN) == TDC_DRV_IQS323_RDY_WINDOW_OPENED);
```

`force_window_open()` — `tdc_drv_iqs323.c:143~172`: GPIO 레벨을 busy-wait 루프로 읽는다.

**GPIO 폴링** 방식. 인터럽트(edge-triggered) 미사용. 호출 경로:

1. `write_register()` → `force_window_open()` (GPIO 폴링)
2. `read_register()` → `force_window_open()` × 2 (GPIO 폴링)
3. `tdc_touch_process()` → 100 ms 폴링 간격 체크 후 `tdc_touch_get_state()` → `tdc_drv_iqs323_read_status()` 호출

상위 레이어 폴링 간격: `TDC_TOUCH_POLL_INTERVAL = 200 ms` (`tdc_touch.h:25`).

## 7. I²C SCL 클럭

### 정상 운용 모드 (SYSCLK = 30.72 MHz)

`driver_i2c.h:25`: `CM3_I2C_CFG_VAL_AsMaster` = `I2C_MASTER_PRESCALE_240`

- 공식: SCL = SYSCLK / ((PRESCALE+1) × 3) = 30,720,000 / (241 × 3) = **~42.5 kHz**
  - 단, `I2C_MASTER_PRESCALE_240`의 실제 레지스터 필드값은 0x4F = 79. SCL = 30,720,000 / (80 × 3) ≈ **128 kHz**

  > [!NOTE]
  > `driver_i2c.h:17`에 `I2C_MASTER_PRESCALE_240 ... // 128 kHz`로 명시. PRESCALE=240이 아니라 필드값 0x4F(=79)이므로 SCL = 30,720,000 / ((79+1)×3) = 30,720,000 / 240 = **128 kHz**.

### 절전 모드 (SYSCLK = 2.56 MHz)

`main.c:950`: `i2c_set_master_prescale(I2C_MASTER_PRESCALE_6)` 로 재설정.

- `I2C_MASTER_PRESCALE_6`(SDK 기본 제공, 필드값 = 2): SCL = 2,560,000 / ((2+1)×3) = 2,560,000 / 9 ≈ **284 kHz** — 그러나 주석에 "SCL ≈ 122 kHz 유지"로 기록됨.

  > [!NOTE]
  > `driver_i2c.h:21` 주석: "240→21로 낮춰 SCL ≈ 122 kHz 유지". `main.c:950` 주석에도 "SCL → 122 kHz 유지 (저속 방지)". `I2C_MASTER_PRESCALE_6`는 SDK 매크로로 내부 필드값은 코드에서 직접 확인 불가. 주석 기준 절전 SCL ≈ **122 kHz**.

## 8. RDY 타이밍 추정

### 추정 전제

| 항목 | 값 | 근거 |
|---|---|---|
| Power Mode | Normal Power (000) | 0xC0 write 전수 확인 |
| Report Rate | 0 ms (측정 즉시 RDY) | 0xC1~C4 write 없음, 기본값 0 |
| 통신 모드 | Streaming | 0xC0 bit7 = 0 |
| Transaction Timeout | 200 ms | 0xD1 write 없음, 기본값 0x00C8 |
| SCL (정상) | 128 kHz | `I2C_MASTER_PRESCALE_240` 주석 |
| SCL (절전) | 122 kHz | `main.c:950` 주석 |
| 상위 폴링 간격 | 200 ms | `TDC_TOUCH_POLL_INTERVAL` |

### I²C 트랜잭션 1회 소요 시간 추정 (SCL = 128 kHz)

SCL 비트 주기: 1 / 128,000 ≈ 7.8 µs

`tdc_drv_iqs323_read_status()` 호출 시 `read_register(0x10, ...)` 1회:
- write 주소 1 byte: START + 주소(7+1) + W + ACK + 레지스터(8) + ACK + STOP = 약 20 bit → 20 × 7.8 µs ≈ **156 µs**
- read 데이터 2 byte: START + 주소(7+1) + R + ACK + 데이터(8) + ACK + 데이터(8) + NACK + STOP = 약 30 bit → 30 × 7.8 µs ≈ **234 µs**
- **합계 1회 read: ~390 µs**, 실제 stretch·ACK 오버헤드 포함 시 ~500 µs 이내 추정.

write 3 byte: START + 주소 + W + ACK + 레지스터 + ACK + LSB + ACK + MSB + ACK + STOP = 약 50 bit → 50 × 7.8 µs ≈ **390 µs**.

### RDY 타이밍 추정치

| 항목 | 추정값 | 산출 근거 |
|---|---|---|
| **T_주기** (정상 운용 IQS323 RDY 주기) | **코드 미발견** (측정값 필요) | Report Rate=0이면 IC 내부 측정 사이클에 의존 — 데이터시트에 사이클 시간 비공개. 일반적 capacitive 센서 Normal Power 기준 수 ms ~ 수십 ms 범위 추정. |
| **t_Low** (RDY가 LOW인 구간 = 통신 윈도우) | **측정값 필요** | IC 내부 Transaction Timeout(200 ms)이 상한이나, 실제는 펌웨어 I²C 트랜잭션 완료 후 RDY가 HIGH로 복귀. 1회 read 약 0.5 ms, write 약 0.4 ms. 1 트랜잭션당 t_Low ≈ **0.4 ~ 0.5 ms** 추정. |
| **t_High** (RDY가 HIGH인 구간 = IC 측정 중) | **코드 미발견** | T_주기 − t_Low. Normal Power, Report Rate=0 조건에서 IC 측정 사이클 길이에 의존. |
| **상위 레이어 폴링 주기** | 200 ms | `TDC_TOUCH_POLL_INTERVAL` |
| **절전 모드 폴링 주기** | 200 ms (ULP Timer 설정) | `main.c:954`: `ci_timer_init_prescaled(ULP_TIMER_PRESCALE, ULP_TIMER_TIMEOUT_VALUE)` — 200 ms 주기 주석 |

> [!NOTE]
> T_주기(IQS323 RDY 주기)와 t_High는 코드에서 직접 설정하는 값이 아니라 IC 내부 측정 사이클 시간에 의존한다. Report Rate = 0이면 IC가 한 번의 측정을 마치자마자 RDY를 내리므로, 실측 없이는 정확한 값을 산출할 수 없다. **오실로스코프 또는 RTT 타임스탬프 측정이 필요하다.**

## 9. 정상 운용 초기화 시퀀스 요약

`tdc_drv_iqs323_apply_settings()` (운용 모드) write 순서:

| 순서 | 레지스터 | LSB | MSB | 내용 |
|---|---|---|---|---|
| 1 | 0xC0 | 0x01 | 0x00 | ACK Reset |
| 2 | 0x10 | (read) | (read) | Reset Event 확인 (폴링) |
| 3 | 0x50 | 0x00 | 0x00 | Sensor2 비활성 (Floating) |
| 4 | 0x40 (DUMMY_ENABLE) | 0x00 | 0x60 | Sensor1 CalCap 더미 enable |
| 5 | 0x44 (DUMMY_ENABLE) | 0x2A | 0x03 | Pattern Def: CalCap 1pF |
| 6 | 0x46 (DUMMY_ENABLE) | 0x08 | 0x04 | CH1 ATI Mode=Disabled |
| 7 | 0x70 (DUMMY_ENABLE) | 0x00 | 0x00 | CH1 Mode=Independent |
| 8 | 0x30 | 0x01 | 0x01 | Sensor0 enable (CTx0, CH enable) |
| 9 | 0x62 | 100 (0x64) | 80 (0x50) | Touch Threshold=100, Hysteresis=80 |
| 10 | 0xD3 | 0x52 | 0x00 | Events Enable: ATI_ERR+ATI_EVT+TOUCH_EVT |
| 11 | 0x36 | 0x08 | 0x04 | ATI Setup (Mode=Disabled) |
| 12 | 0x38 | 0x82 | 보드별 | ATI Mult (고정 보상값) |
| 13 | 0x39 | 보드별 | 보드별 | ATI Comp (고정 보상값) |
| 14 | 0xC0 | 0x08 | 0x00 | Reseed + NP + Streaming |
| 15 | 0xC0 | 0x00 | 0x07 | CH0/1/2 Timeout Disable |

> [!NOTE]
> 10번 Events Enable LSB 0x52: bit6(ATI_ERR)=1 + bit4(ATI_EVT)=1 + bit1(TOUCH_EVT)=1 = 0b01010010 = 0x52. 코드 `events_enable()` `tdc_drv_iqs323.c:423`.

## 10. 결론 — RDY 타이밍 코드 ground truth 요약

| 항목 | 코드 설정값 | 비고 |
|---|---|---|
| NP Report Rate | 0 ms (기본값) | write 없음 |
| LP/ULP/Halt Report Rate | 0 ms (기본값) | write 없음 |
| Power Mode | Normal Power (000) | ULP/Automatic 미사용 |
| Power Mode Timeout | 0 ms (기본값) | write 없음 |
| 통신 모드 | Streaming (bit7=0) | 측정 완료마다 RDY |
