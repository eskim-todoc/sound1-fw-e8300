**TL;DR**: IQS323 reset 후 모든 Report Rate 레지스터는 0x0000(0 ms)이며, 칩이 자체 내부 타이밍으로 동작한다. I²C Transaction Timeout만 0x00C8 = 200 ms로 명시된 비-제로 default를 가진다. 인터페이스 모드는 Streaming, 전력 모드는 Normal Power가 reset default다.

## 3. 항목별 상세 해설

### 질문_1~4: Report Rate 레지스터 (0xC1~0xC4)

원문 메모리맵 §9 Default 컬럼에 모두 `0x0000`으로 명시됨.  
0 ms의 의미는 데이터시트 원문에 별도 설명 없음. 실제 동작은 칩 내부 기본 주기에 따르거나, 각 오더 코드(IQS323-001/002/A01)의 OTP 초기값에 의해 결정될 가능성이 높으나, 원문에 해당 설명은 없음 — **원문 명시: 레지스터 default = 0x0000, 0 ms의 동작 의미는 원문 미명시**.

> [!NOTE]
> §5.2에서 전력 모드 종류(NP/LP/ULP/Halt)를 설명하며, §8.11.1에서 NP/LP/ULP 각 Report Rate 레지스터가 해당 모드의 보고 주기(ms)를 결정한다고 명시함. 0x0000 write 시 동작 정의는 원문에 없음.

### 질문_3b: Auto Prox Cycle Select — 0x01CF 해석

Prox Input and Control 레지스터(0x33, 0x43, 0x53) reset default = **0x01CF**.

```
0x01CF = 0b0000_0001_1100_1111
  bit[7]    = 1   → Reserved (Set to 1, 정상)
  bits[6]   = 1   → Dead Time Enable = 1 (Dead Time 활성)
  bits[5:4] = 00  → Reserved
  bits[3:2] = 11b = 3 → Auto Prox Cycle Select: 32 conversions
  bits[1:0] = 11b     → Reserved (Set to 11, 정상)
```

Appendix A.9 디코딩 기준:

| bits[3:2] | Auto Prox Cycle Select |
|-----------|----------------------|
| 00 | 4 cycles |
| 01 | 8 cycles |
| 10 | 16 cycles |
| **11** | **32 cycles (default)** |

ULP 모드 실효 보고 주기 = (Auto Prox Cycle Select × ULP Report Rate) ms = 32 × ULP_Rate ms

### 질문_5: I²C Transaction Timeout (0xD1)

- Default = **0x00C8 = 200 ms** — 메모리맵 + §8.8 원문 이중 확인
- §8.8 원문: "The default I²C Transaction Timeout is set to 200 ms. The I²C Transaction Timeout must be between 2 ms and 230 ms."
- 0x00을 쓰면 타임아웃 비활성(watchdog timer 제어로 전환)

### 질문_6: Interface Selection (bit[7] of 0xC0)

System Control 레지스터 Default = **0x0000** → bit[7] = 0 → **I²C Streaming**.

Appendix A.30:
- `0`: I²C Streaming — 매 전력 모드 보고 주기마다 RDY 발생
- `1`: I²C Events — 이벤트 발생 시에만 RDY 발생

**reset default는 Streaming 모드**.

### 질문_7: Power Mode 선택 (bits[6:4] of 0xC0)

System Control Default = 0x0000 → bits[6:4] = **000b = Normal Power Mode**.

Appendix A.30 전체 인코딩:

| bits[6:4] | 전력 모드 |
|-----------|---------|
| 000 | Normal Power Mode **(default)** |
| 001 | Low Power Mode |
| 010 | Ultra Low Power Mode |
| 011 | Halt Mode |
| 100 | Automatic |
| 101 | Automatic No ULP |

### 질문_8: Power Mode Timeout (0xC5)

Default = **0x0000 (0 ms)**.  
§5.3: "Setting the power mode timeout to '0x00' will prevent the chip from lowering the power mode."  
즉 reset 직후 Automatic 전력 강하 없이 Normal Power 유지.

## 5. 핵심 요약

```
Reset 직후 상태:
  인터페이스 모드   = Streaming (bit[7]=0)
  전력 모드         = Normal Power Mode (bits[6:4]=000)
  Power Mode Timeout = 0 → 자동 강하 없음 (NP 고정)
  모든 Report Rate  = 0 ms (실제 보고 동작은 원문 미명시)
  Transaction Timeout = 200 ms (유일한 비-제로 default)
  Auto Prox Cycle Select = 32 cycles (bits[3:2]=11b of 0x01CF)
```
