# 00 · C51 DC 블로킹 → J3 전하 누적 가설 — 오케스트레이터 입력 (공통)

> **TL;DR**: 모든 페르소나 공통 입력. 은수님 가설 — CRX0-J3 직렬 C51(100pF)이 DC 블로킹 + J3 전극 GND 부재로 전극 전하가 누적 해소 안 됨 → 일정 횟수 후 먹통. 회로 사실, 가설 분해, 6 검증 질문, 제약, 5 페르소나. **핵심: 이 회로적 판단이 타당한가, 진짜 먹통 원인인가.**

## 1. 회로 사실 (ground truth)

- **CRX0 경로**: CRX0(B2) → **R31(100Ω)** → **C51(100pF)** → **J3**(SCS05-065-10 커넥터 → 터치패드). self-cap(PXS 0x10).
- **J3 터치패드**: 은수님 제공 — **GND 없이 패드 1핀만 J3에 연결**(별도 그라운드 연결 없음).
- R31·C51 RC LPF fc ≈ 15.9 MHz([회로 §7.1]).
- 데이터시트 레퍼런스(§2.5): Sound1과 동일 **WLCSP11**의 self-cap **슬라이더 레퍼런스(Fig 2.3)에 CRx 직렬 C6 100pF 존재** → C51 100pF 직렬은 **표준 변형 범주(비표준 부작용 아님)**. (Fig 2.1은 DFN12 단순 버튼이라 C 없음 — 패키지·전극형태 불일치라 이 비교는 부적절. **검증 D2 정정**)

## 2. 은수님 가설 (분해)

| 단계 | 명제 |
|---|---|
| H1 | C51(100pF)이 CRX0와 J3 전극 사이 **직렬 → DC 블로킹** |
| H2 | J3 전극이 GND 없이 1핀만 연결 → 전극 노드가 **DC floating** (전하 빠질 경로 제한) |
| H3 | 전극에 쌓인 전하(ESD·정전기)가 C51 때문에 IC로도, GND로도 **해소 안 됨 → 누적** |
| H4 | 누적 전하가 self-cap 측정(충전전달)에 영향 → **일정 횟수/시간 후 터치 먹통** |
| H5 (연결) | SW 방전(CRX0 VSS)도 C51 너머 전극 전하를 **못 뺌 → 방전 무력** (이전 검토 정합) |

## 3. 검증 질문 (Q)

- **Q1**: C51(100pF) 직렬이 CRX0-J3 사이 DC를 실제로 블로킹하나? (커패시터 DC 차단 — 자명하나 self-cap 충전전달 펄스는 통과하는가)
- **Q2**: J3 전극이 GND 없이 1핀만 연결 → 전극 노드 DC가 floating인가? 전하 빠질 경로(전극 누설·공기·PCB 표면·IC 내부 bias·R31 너머 IC)는?
- **Q3**: self-cap 충전전달(CRX0가 전극 충·방전, 02 §5.4)에서 **C51 직렬이 측정에 어떤 영향**? 전극 Cx와 C51(100pF) 직렬 합성. 측정은 되나(터치 동작 중), 전극 DC 누적이 동작점 시프트·counts 변동을 일으키나?
- **Q4**: C51(100pF) 직렬이 IQS323 self-cap **표준 설계인가 비표준 부작용인가**? 데이터시트 §2.5 레퍼런스 회로 대조. C51의 의도(AC 커플링·EMI·ESD)?
- **Q5**: SW 방전(CRX0 VSS, 0x30 토글)이 **C51 때문에 전극 전하를 못 빼나**? (방전 무력의 회로적 이유 — [방전·autoATI 공존] B2 "0x30=VSS 미확정"과 결합)
- **Q6**: "일정 횟수 후 먹통"이 **C51 전하 누적으로 설명되나**, 아니면 LTA 드리프트/FIXED MULT·COMP/ATI 등 다른 원인인가? (이슈해결 ESD 누적·GND 쇼트 복귀 사례와 정합)

## 4. 제약

- self-cap: 터치 시 counts 감소(02 §5.7). 충전전달 원리(02 §5.4 NOTE).
- 이전 사실: 현재 ATI Disabled+FIXED, 200ms 방전(0x30, 단 진짜 VSS 미확정 B2), CRX1 CalCap.
- 이슈해결 사례: 절전 2~3회 후 먹통, **GND 쇼트 시 복귀**(전극 전하 누적 정황).
- 아날로그 추정은 "확인 필요"(실측: 오실로·전극 DC 측정).

## 5. 페르소나 (5) + adversarial 검증

| # | 페르소나 | 임무 |
|---|---|---|
| D1 | **아날로그 회로 이론가** | H1~H5 회로 이론 — C51 DC 블로킹·전극 floating DC·전하 누적·충전전달 영향. 임피던스·시정수 정량 |
| D2 | **데이터시트 정합** | Q3·Q4 — self-cap 충전전달(§5.4)·레퍼런스 회로(§2.5) 대조. C51 직렬 표준/비표준, 측정 영향 |
| D3 | **Adversarial 반대** | 가설 허점 — 전극 누설 경로·C51 충전전달 통과·다른 먹통 원인·전하 누적 정량 의문 |
| D4 | **이전 검토 정합** | Q5·Q6 — ESD 이슈(GND 쇼트 복귀)·방전 무력(C51 너머)·B2(0x30 미확정)·SW 분석과 연결 |
| D5 | **대안 원인** | Q6 — 먹통이 C51 전하 누적이 아니라 LTA 드리프트/FIXED/ATI일 가능성. 가설 간 우열 |

- **adversarial-verify(별도)**: 핵심 주장(H1~H4 성립·H5 방전무력·진짜 원인)을 데이터시트·회로 이론으로 독립 재검증(낙관·할루시네이션 차단).

## 6. 평가 기준

① H1~H5 각 성립 여부 ② 진짜 먹통 원인 판정(C51 전하누적 vs 대안) ③ 실측으로 가를 항목 ④ 해결 방향 시사(HW: GND 연결·C51 제거·블리더 / SW).
