# 1 · D2 데이터시트 정합 분석 — C51 직렬과 self-cap 충전전달 (Q3·Q4)

> **TL;DR**: 결론 **조건부반대**. C51(100pF) CRX0 직렬은 데이터시트상 **비표준이 아니다** — 정합 figure는 self-cap 버튼(Fig 2.1, C 없음)이 아니라 **self-cap 슬라이더(Fig 2.3, WLCSP11)이며 거기엔 C6 100pF가 직렬로 존재**한다. 또한 self-cap 충전전달(02 §5.4)은 매 사이클 Cx를 충전→Cs로 전달하는 **양방향 AC 동작**이라 100pF는 측정 펄스를 통과시킨다. 따라서 H1의 "C51이 DC를 막아 측정·방전을 무력화"라는 명제는 **데이터시트 근거로 약화**된다. 진짜 영향은 "DC 차단으로 전하 누적"이 아니라 **C51·Cx 직렬 합성으로 인한 유효 정전용량 축소(감도 저하)·동작점 시프트**이며, 전하 누적 자체는 C51이 막는 게 아니라 self-cap 동작이 매 사이클 Cx를 능동 충방전한다는 점에서 정량 재검토가 필요하다(실측 항목 명시).

> [!IMPORTANT]
> 근거: [00 입력](00_입력.md) · [회로 §7.1·§2.5 대조](../회로%20구성·분석.md) · 데이터시트 [02 §5.4 Count Value/충전전달](../../데이터시트/02_proxfusion동작.md) · [01 §2.5 Reference Schematic·§3.2](../../데이터시트/01_개요·전기·타이밍.md). 임무: **Q3(충전전달에서 C51 영향)·Q4(C51 직렬 표준/비표준·의도)**. 아날로그 정량은 "확인 필요"(실측).

## 2. Q4 — C51 직렬은 표준인가 비표준인가 (§2.5 레퍼런스 대조)

### 2.1 00_입력의 전제 재검토 — "self-cap 버튼엔 C 없음" 비교 대상 오류

00_입력 §1은 *"self-cap 버튼(Fig 2.1)은 CRx에 직렬 R(470Ω)만, C 없음. 슬라이더(Fig 2.3)엔 C6 100pF 존재 → C51 직렬은 self-cap 버튼 표준과 다름"* 으로 적었다. 그러나 데이터시트 §2.5(01 라인 113~131)를 직접 보면 비교 프레임이 달라진다.

| Figure | 용도 / 패키지 | CRx 직렬 부품 | C51 정합 |
|---|---|---|---|
| **Fig 2.1** | 3 Button **Self-Cap** (DFN12) | R 470Ω **만** (C 없음) | 직접 비교 시 C51 = 추가 부품 |
| Fig 2.2 | Single Prox/Touch + Inductive (DFN12) | coil에 C6 100pF·C7 100nF | — |
| **Fig 2.3** | **Self-Cap Slider** + Inductive (**WLCSP11**) | R9 1MΩ, **C6 100pF**, C7 TBD | **C51 100pF과 동일 토폴로지** |
| Fig 2.4 | 3 Button Self-Cap (QFN20) | 공통(R 470Ω) | — |

> [!IMPORTANT]
> **핵심: Sound1(U13)은 WLCSP11 패키지다**(회로 §1·§3, [01 §1.1 WLCSP11]). 데이터시트에서 **WLCSP11 + self-cap 조합의 레퍼런스 figure는 Fig 2.3(슬라이더)이며, 거기엔 CRx 직렬 C6 100pF가 명시적으로 존재한다.** 즉 C51(100pF)은 동일 패키지·동일 측정방식(self-cap) 레퍼런스에 **이미 존재하는 부품 토폴로지**다. 00_입력이 비교 대상으로 삼은 Fig 2.1(DFN12 버튼)은 패키지·전극형태가 다른 다른 케이스다.

→ **C51 100pF 직렬은 "비표준 부작용"으로 단정할 수 없다.** 데이터시트 self-cap 슬라이더 레퍼런스(Fig 2.3)에 동일 100pF 직렬 C가 등장하므로, **표준 설계 변형의 범주**로 봐야 한다. (단, Fig 2.3는 슬라이더이고 Sound1은 단일 버튼이라 1:1 동형은 아님 — 후술 §4 차이)

### 2.2 R31=100Ω vs 권장 470Ω (별도 이슈, C51과 분리)

직렬 저항 R31=100Ω이 §3.2 권장 470Ω 미달인 것은 회로 §7.1·§9에서 이미 ESD 보호 여유 축소로 지적됐다([01 §3.2 각주 ⁱⁱⁱ: 470Ω = EMI 방지 + ESD 보호]). 이는 **C51의 표준성과는 독립된 별개 이슈**다. C51 100pF은 figure 정합, R31 100Ω은 권장 미달 — 둘을 분리해야 한다.

### 2.3 C51의 의도 (AC 커플링 / EMI / ESD)

데이터시트가 CRx 직렬 C를 직접 "의도" 서술한 문장은 없으나, §2.5·§3.2·회로 분석을 종합하면:

| 후보 의도 | 데이터시트 근거 | 평가 |
|---|---|---|
| **EMI/RF 필터링** | R31(100Ω)·C51(100pF) RC LPF fc≈15.9MHz(회로 §7.1). IC 동작 14MHz·fxfer 근처 고주파 차단 | **유력** — R 직렬은 §3.2가 EMI 목적 명시, C 추가 시 LPF 완성 |
| **AC 커플링(DC 차단)** | self-cap은 AC(충전전달)만 통과시키면 됨. C가 DC offset·전극 부유 DC를 차단 | **유력** — Fig 2.3 슬라이더가 C6 100pF 채택한 합리적 이유 |
| **ESD 직렬 보호** | §3.2: 직렬 R이 ESD 보호. C는 직접 ESD 방전 경로 아님 | 부차적 (R 역할이 주, C는 보조) |

> [!NOTE]
> **§3.2 직렬 저항 한계 공식**: `RCx_max × Cm_max = 1/(6×fxfer)`([01 §3.2 각주 ⁱᵛ]). 직렬 임피던스(R·C)는 fxfer(충전전달 주파수)·RC 시정수의 함수로 상한이 정해진다. C51 100pF은 self-cap Cx SELF-VSS 최대 400pF([01 §3.2])와 직렬이므로, **이 합성이 충전전달 시정수 한계 안에 드는지**가 핵심 — §3절에서 정량.

## 3. Q3 — 충전전달에서 C51 직렬의 측정 영향 (02 §5.4)

### 3.1 self-cap 충전전달은 양방향 AC 동작 — DC 차단 ≠ 측정 차단

데이터시트 02 §5.4(라인 153~159)의 충전전달 1사이클:
1. 측정 전극(Cx)에 전압 인가 → 전하 축적
2. Cx의 전하를 내부 기준 Cs로 **전달**
3. Cs 전압 ≥ 임계값 → Cs **방전** + 1카운트
4. 반복. Counts = 임계값 도달까지 사이클 수.

> [!IMPORTANT]
> **이 동작은 매 사이클 Cx를 충전(인가)했다가 Cs로 빼내는(전달) 양방향 스위칭 = 본질적으로 AC다.** Cx 노드 전압은 매 사이클 오르내린다. **커패시터(C51)는 AC를 통과시키고 DC만 막는다.** 따라서 C51 100pF은 충전전달 펄스(고주파 스위칭)를 **통과**시키며, "C51이 DC를 막아 측정을 무력화한다"는 H1·H4의 함의는 **성립하지 않는다.** 측정은 C51 너머 전극과 정상적으로 이뤄진다(실제 터치가 동작 중이라는 00_입력 사실과 정합).

### 3.2 직렬 합성 정전용량 — 유효 Cx 축소 (감도 영향)

self-cap이 보는 것은 전극 Cx가 아니라 **C51과 Cx의 직렬 합성**이다(전극 노드가 C51 너머에 있으므로):

$$C_{eff} = \frac{C_{51} \cdot C_x}{C_{51} + C_x}$$

| 전극 Cx (가정) | C_eff (C51=100pF 직렬) | 비고 |
|---|---|---|
| Cx = 10 pF | 9.1 pF | C51 영향 작음(~9%) |
| Cx = 50 pF | 33.3 pF | 33% 축소 |
| Cx = 100 pF | 50 pF | 50% 축소 (C51과 동일) |
| Cx = 400 pF(self 최대) | 80 pF | **C51이 상한 캡 역할** — Cx 아무리 커도 C_eff < 100pF |

> [!WARNING]
> **이것이 C51의 가장 실질적 측정 영향이다.** 100pF 직렬 C는 전극 Cx가 클수록 C_eff를 **100pF로 점근 제한**한다. 터치 시 손가락이 Cx를 키워도(ΔCx) C_eff 변화(ΔC_eff)는 직렬 분압으로 **압축**된다 → **터치 delta(counts 변화량) 감쇠 = 감도 저하.** §5.4: Counts ∝ 1/C이므로 C_eff가 100pF로 포화될수록 노터치·터치 counts 차이가 줄어 SNR이 낮아진다. 정량은 전극 실제 Cx·기생 C 실측 필요(**확인 필요**).

### 3.3 "동작점 시프트·전하 누적"에 대한 데이터시트 관점

00_입력 H3·H4는 "C51 때문에 전극 DC 전하가 누적 → 동작점 시프트 → 먹통"을 주장한다. 데이터시트 정합 관점에서:

- **충전전달은 매 사이클 Cx를 능동 충·방전**한다(§5.4 ①②③). 즉 C51 **너머 전극 노드**의 전하는 매 측정 사이클마다 IC 쪽으로 일부 전달·재충전된다. 전극이 완전 DC-floating이어도, self-cap 동작 자체가 Cx 노드를 주기적으로 구동(VREG 도메인 내, [01 §3.1 Prox pin -0.3~VREG])하므로 **무한 누적이 자명하지 않다.**
- 다만 **C51 너머 노드의 평균 DC 레벨**은 C51이 DC를 막으므로 IC의 DC bias로 직접 정의되지 않는다. ESD로 주입된 순 전하(net charge)가 C51·전극 누설로만 빠진다면 **느린 DC 시프트는 가능** — 이 부분은 H2/H3(아날로그 floating, D1 담당)와 충전전달(매 사이클 AC 구동)의 **상호작용 정량**이 필요하며, 데이터시트만으로는 판정 불가(**확인 필요 — 실측**).
- §5.4의 LTA/COMP 흐름상, 느린 DC 시프트는 본래 **LTA가 추적**(§5.5)하고 **COMP가 기생 상쇄**(§5.10)하도록 설계됐다. **그러나 Sound1은 ATI Disabled + FIXED MULT·COMP**(회로 §10, 이슈해결)라 이 자동 보정을 **포기**한 상태 → 동작점 시프트가 자동 흡수되지 않고 누적 표출될 수 있다. **즉 "먹통"의 더 직접적 데이터시트 근거는 C51 DC차단보다 FIXED 운용(자동보정 부재)** 쪽이다(Q6·대안원인 영역, D5와 정합).

## 5. 실측으로 가를 항목 (데이터시트만으로 미결)

1. **전극 실제 Cx·기생 C** — C_eff 축소율·감도 영향 정량 (Cx SELF-VSS 400pF 한계 대비 위치).
2. **C51 너머 전극 노드 DC 레벨** (오실로) — 충전전달 양방향 구동에도 순 전하 DC 시프트가 실측되는가(H3 핵심).
3. **충전전달 펄스가 C51을 실제 통과하는지** — CRX0 vs J3 양단 파형 비교(§3.1 AC 통과 명제 실증).
4. **C51 제거/단락 시 counts·delta·먹통 재현 변화** — C51 기여 분리(감도 vs 누적).
5. **방전(0x30) 물리효력** — [방전·autoATI 공존 권고] B2: 0x30 0x02가 진짜 VSS 단락인지 미확정. C51 너머 전하 제거 여부는 방전 진위에 종속.

## 6. 한 줄 결론

> **데이터시트 정합상 C51(100pF) CRX0 직렬은 비표준 부작용이 아니라 WLCSP11 self-cap 레퍼런스(Fig 2.3)에 존재하는 표준 변형(EMI 필터+AC 커플링)이며, self-cap 충전전달은 양방향 AC라 C51이 측정 펄스를 통과시키므로 "DC 차단→전하 누적→먹통"(H1·H4) 명제는 데이터시트 근거로 약화된다. C51의 실측 가능한 영향은 직렬 합성에 의한 유효 Cx 축소·터치 delta 압축(감도 저하)이며, 먹통의 더 유력한 데이터시트 근거는 ATI Disabled+FIXED 운용에 따른 자동보정(LTA·COMP) 부재다 — 단, C51 너머 노드의 순 DC 시프트 누적 가능성은 오실로 실측으로만 확정된다.**
