# 1 · 대안 원인 검증 (D5) — C51 전하누적 vs SW 원인

> **TL;DR**: Q6 검증. "일정 횟수 후 먹통"은 C51 전하누적 단일 원인이 아니다. 문서 증거상 **이미 재현·정합된 SW 원인이 2건**(FIXED MULT·COMP 드리프트 → counts 이탈, auto-ATI 타이밍 → 전역 ati_error 영구 SET)이며 이 둘은 C51 가설보다 **인과 사슬이 짧고 실측·코드로 입증**됐다. C51 전하누적(H1~H5)은 **아날로그 추정 단계**로 미실측. 다만 "GND 쇼트 시 복귀" 정황은 SW 드리프트만으로 완전 설명 안 돼 **물리 누적 성분의 공존**을 시사한다. 평결: **조건부반대** — C51을 주원인으로 단정하는 가설에는 반대(주원인은 SW 드리프트 쪽 증거가 우세), 단 물리 누적의 부차 기여는 배제 불가 → 공존 모델.

> [!IMPORTANT]
> 근거: [00 입력](00_입력.md) · [회로 §11.2/§11.3/§10](../회로%20구성·분석.md) · [이슈해결 2026-06 CRX1-ESD](../../이슈해결/2026-06_CRX1-ESD-더미채널.md) · [방전·autoATI 공존 권고 §3/§4](../방전·autoATI%20공존%20권고.md). 아날로그 추정은 "확인 필요"로 명시.

## 1. 임무와 결론 먼저

은수님의 C51 전하누적 가설(H1~H5)은 회로적으로 **그럴듯하나 미실측 추정**이다. 본 페르소나는 "먹통의 진짜 원인이 정말 C51인가, 아니면 SW 쪽인가"를 가린다. 핵심 결론:

- **이미 입증된 SW 원인 2건**이 동일 증상("일정 횟수/시간 후 먹통")을 설명한다 — C51보다 증거 등급이 높다.
- C51 전하누적은 **그 SW 원인들과 인과적으로 분리되지 않은 채** 같은 증상을 공유한다 → 단독 귀인 위험.
- 단, "GND 쇼트 복귀" 한 가지 정황은 SW만으론 설명이 약함 → **물리 누적 부차 기여 공존**.

## 2. 대안 원인 카탈로그 (SW 측, 문서 입증 등급순)

| 대안 | 메커니즘 | 증상 정합 | 증거 등급 | 출처 |
|---|---|---|---|---|
| **A. FIXED MULT·COMP 드리프트** | autoATI 포기 → 내부 충/방전 보정 부재 → self-cap raw count가 온·습도·정전용량 변화로 서서히 이동 → 고정 threshold 교차 → 항시 TOUCH 오판 → 먹통 | "일정 **횟수/시간** 후" 누적성 증상과 **직접 일치**. RESEED마다 기준 340~660 변동 실측 | **실측·재현** (회로 §11.3) | 회로 §11.3 |
| **B. auto-ATI 타이밍 → 전역 ati_error 영구 SET** | MCLR 직후 auto-ATI가 sensor_setup보다 먼저 돌아 CH1(reset값 C52 부하)에서 수렴 실패 → 전역 ati_error SET → CAL_ERROR 단락 → 터치 불가. 운용 모드 re-ATI 없어 영구 잔류 | 절전(리셋) 반복마다 발생 → "절전 2~3회 후 먹통"과 **정합** | **실측·코드 입증** (이슈해결 §4·§6) | 이슈해결 §4,§6 |
| **C. LTA 드리프트 (온·습도)** | self-cap LTA가 환경 변화 추종 중 ATI Band 이탈. autoATI/LTA가 흡수해야 하나 FIXED라 흡수 안 됨 | 시간 의존 먹통과 정합. 물리 전하 누적과 **구별 불가**한 외형 | 추정 (방전 권고 §4가 "갈래 판별 필요"로 명시) | 방전 권고 §4 |
| **D. ATI Disabled 부작용** | ATI를 운용에서 안 씀 → 내부 자동 보정 전무 → A·C를 SW(RESEED·방전)로 떠안았으나 불완전 | A·C의 상위 원인(설계 선택) | 설계 사실 | 회로 §10 #2, 이슈해결 §7 |

핵심: **A와 B는 "추정"이 아니라 로그·코드로 재현된 사실**이다. C51 가설(H1~H5)은 아직 그 등급에 도달하지 못했다(실측: 오실로·전극 DC 미수행, 00 §4).

## 3. C51 전하누적 가설 vs 대안 — 우열 판정 6축

| 판정 축 | C51 전하누적 (H1~H5) | SW 원인 (A·B·C) | 우위 |
|---|---|---|---|
| **증거 등급** | 아날로그 추정, 미실측 | **로그·코드 재현** | SW |
| **인과 사슬 길이** | C51 DC블록→전극 floating→전하누적→충전전달 시프트→먹통 (5단, 각 단 가정) | FIXED→count 이탈→threshold 교차 (3단) | SW (짧음 = 반증 적음) |
| **증상 외형 일치** | "일정 횟수 후" 설명 가능 | "일정 횟수/시간 후" **직접 일치** | 동등~SW |
| **방전 무력 설명** | C51 너머라 SW 방전 못 뺌 (H5) | 0x30=Linearise일 뿐 진짜 VSS 아닐 수 있음(B2 미확정) → **방전이 원래 무력했을 수도** | SW (대안 설명 존재) |
| **GND 쇼트 복귀 설명** | 물리 전하를 GND로 뺌 → **잘 설명** | 드리프트는 GND 쇼트로 안 풀림 (전극 표면 누설 외엔) | **C51** |
| **재현·반증 용이** | 전극 DC 실측 필요(미수행) | 이미 재현됨 | SW |

**5:1 (한 축 동등)로 SW 원인 우세.** 단 유일하게 C51이 우세한 축 — "GND 쇼트 복귀"(§4) — 이 가설을 완전히 죽이지 못하게 한다.

## 4. 결정적 단서 — "GND 쇼트 시 복귀"의 양면 해석

이슈해결 §0·회로 §11.2: **GND 쇼트로 방전하면 정상화 → ESD 원인 확정**. 이 정황은 두 갈래로 읽힌다.

1. **물리 전하 누적 (C51 가설 지지)**: 전극/노드에 쌓인 DC 전하를 GND가 직접 뺌 → 복귀. 순수 SW 드리프트(LTA/count)는 GND 쇼트만으로 LTA가 재수렴하지 않으므로 이 외형을 못 만든다.
2. **GND 쇼트가 강제 baseline 리셋 트리거**: 큰 정전용량 변화 → IC 내부 재기준(또는 사용자가 동반한 재기동) → 결과적으로 count 정상화. 이 경우 SW 드리프트도 설명 가능.

> [!CAUTION]
> 해석 1이 맞다면 **C51 가설의 핵심 예측(물리 누적)이 성립**한다. 단 "GND 쇼트가 J3 전극에 직접 닿았는지, 아니면 보드 GND 전반을 흔든 것인지"가 불명 → **실측 분기 항목**. 전극 패드를 직접 GND 단락했을 때만 복귀한다면 해석 1(C51 지지), 어디든 GND 흔들면 복귀한다면 해석 2(SW).

## 5. 공존 모델 — 가설은 배타적이지 않다

C51 전하누적과 SW 드리프트는 **택일이 아니라 가산**일 가능성이 높다. 방전 권고 §4가 이미 같은 갈래를 제시했다:

> "ESD가 LTA 드리프트(온·습도)면 auto-ATI/LTA가 흡수 → 방전 redundant. ESD가 핀 물리 전하 누적이면 방전 고유 기능."

```mermaid
flowchart TD
    subgraph 먹통 증상 "일정 횟수/시간 후"
        T[count가 고정 threshold 교차 → 항시 TOUCH]
    end
    A[FIXED MULT·COMP<br/>내부 보정 부재] -->|실측 재현| T
    B[auto-ATI 타이밍<br/>전역 ati_error] -->|코드 입증| CAL[CAL_ERROR 단락]
    C[LTA 드리프트<br/>온·습도] -->|FIXED라 미흡수| T
    D[C51 물리 전하 누적<br/>전극 floating DC] -.->|추정·미실측| T
    CAL --> X[터치 인식 불가]
    T --> X
    style D stroke-dasharray: 5 5
    style A stroke:#c00,stroke-width:2px
    style B stroke:#c00,stroke-width:2px
```

- 실선(A·B·C) = 입증/정합된 경로. 점선(D) = C51 추정 경로.
- **B(ati_error)는 이미 "ati_error 무시"로 코드 해결됨**(이슈해결 §7) → 현 시점 주의심은 A·C·D로 좁혀짐.
- A·C(드리프트)와 D(물리 누적)는 **같은 출력(count threshold 교차)을 공유** → 외형만으로 구별 불가. 이것이 "C51 단독 귀인" 위험의 본질.

## 6. C51 가설을 약화시키는 반론 (adversarial)

1. **B 원인은 이미 해결됐는데 C51은 미해결인가?** ati_error 무시 패치 후 ESD 먹통이 여전한지 실측 데이터가 본 문서엔 없음 → "C51이 진짜 원인"의 전제(여전히 먹통)부터 확인 필요.
2. **C51이 진짜 DC를 막으면 self-cap 충전전달도 막혀 애초에 터치가 안 돼야** — 그런데 터치는 동작 중(일정 횟수까지는). 즉 충전전달 펄스는 C51을 통과(AC 결합)한다는 뜻 → "전하가 못 빠진다"는 H3의 비대칭(AC는 통과, DC는 누적) 가정이 정량 입증 필요(D1/D2 영역).
3. **방전 무력(H5)의 더 단순한 설명**: 0x30 0x02가 데이터시트상 Linearise+Enable=0이지 핀 VSS가 아님(방전 권고 §3, B2 미확정). 즉 **방전이 C51 때문에 무력한 게 아니라 애초에 진짜 VSS 방전이 아니었을** 수 있음 → C51을 끌어들이지 않아도 방전 무력 설명됨.
4. **FIXED가 근본**: 회로 §11.3이 "1차적으로 운용 전략(FIXED vs autoATI) 문제이며 회로보다 펌웨어 영역"이라 명시. 문서 자체가 SW를 1차 원인으로 지목.

## 7. 실측으로 가를 항목 (가설 판별 게이트)

| # | 실측 | C51 지지 결과 | SW 지지 결과 |
|---|---|---|---|
| 1 | **J3 전극 노드 DC 전위** 시간 추이(고임피던스 프로브) | DC가 단조 누적·먹통 시점에 임계 도달 | DC 안정, count만 이동 |
| 2 | **ati_error 무시 패치 후 ESD 먹통 재현 여부** | 여전히 먹통 (B 제거해도 남음) | 먹통 소멸 (B가 주범) |
| 3 | **GND 쇼트 위치 변별** — J3 패드 직접 vs 보드 GND 전반 | 패드 직접만 복귀 | 어디든 복귀 |
| 4 | **raw count 추이** 로깅(터치 횟수 vs count) | 계단형 점프(전하 이벤트) | 완만 드리프트(온·습도) |
| 5 | **C51 단락(점퍼) 시험** | 먹통 사라짐 | 변화 없음 |

> 항목 2·5가 가장 결정적이고 저비용 — **ati_error 패치 후에도 먹통이면** A·C·D로 좁혀지고, **C51 단락으로 사라지면** D 확정.

## 8. 해결 방향 시사 (대안 관점)

- **SW가 주범일 가능성이 더 높으므로 SW 개선이 1순위 ROI**: auto-ATI 재도입(부팅 1회 + auto Re-ATI 억제, 방전 권고 §2/§5) 또는 드리프트 추적 알고리즘 → A·C 직접 해소.
- **C51은 저비용 검증 가능**(§7-5 단락 시험)하므로 **병행 실측**으로 D 기여를 확정/배제. HW 변경(C51 제거·블리더·GND 연결)은 D 확정 후.
- 두 갈래(드리프트 vs 물리누적)는 방전 권고 §4가 이미 "ESD 실측의 핵심 갈래"로 규정 → **본 검토의 결론은 그 실측 게이트로 수렴**.
