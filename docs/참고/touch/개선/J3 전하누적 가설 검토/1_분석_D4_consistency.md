# 1 · D4 이전 검토 정합 검증 — Q5·Q6 (C51 전하누적 가설)

> **TL;DR**: 본 가설(C51 DC블로킹→J3 전극 전하누적)은 이전 두 검토와 **부분 정합·부분 충돌**. ESD 이슈해결(절전 2~3회 후 먹통·GND 쇼트 복귀)과는 **현상 수준에서 강하게 정합** — GND 쇼트 복귀는 "전극에 빠질 GND 경로가 없다"는 H2의 직접 증거다. 그러나 Q5(방전 무력)에서 가설은 **두 겹의 무력화 이유**를 만난다: ① 현재 방전 코드(0x30 LSB=0x02)가 데이터시트상 **VSS 단락이 아니라 Linearise+Enable=0**이라 애초에 핀 전하를 못 뺀다(B2, 가설과 독립한 SW 결함), ② 설령 진짜 VSS 방전(0x34=0x0A)이어도 방전점은 IC측 CRX0 핀이라 **C51 건너편 J3 전극 전하는 못 뺀다**(가설의 회로적 무력화). 즉 가설은 "방전 무력"에 **회로적 이유를 제공하나, 그것이 유일/주원인은 아니다** — B2 SW 결함이 더 앞단·더 확실한 무력화다. Q6 먹통 원인은 C51 단독 설명 불충분, **다인자(전하누적∥SW방전결함∥FIXED 드리프트)** 가 맞다. **판정: 조건부지지.**

## 1. 검증 범위 (D4)

Q5(방전이 C51 때문에 전극 전하를 못 빼나 — 방전 무력의 회로적 이유)와 Q6(일정 횟수 후 먹통이 C51 전하누적으로 설명되나)를, 이전 3개 검토 산출물과 **정합**시킨다:

- **이슈해결**: [2026-06_CRX1-ESD-더미채널] — ESD 누적·GND 쇼트 복귀·CalCap·ATI error.
- **방전 검토**: [방전·autoATI 공존 권고] §3 — **B2: "현재 방전 0x30=VSS 미확정"**(0x02는 데이터시트상 Linearise이지 VSS 아님).
- **회로**: §7.1(C51 경로)·§11.2(ESD 먹통).

## 2. ESD 이슈해결과의 정합 — 현상 수준 강한 정합 (Q6 일부)

| 이슈해결 사실 | 본 가설(H1~H4)과의 관계 | 정합도 |
|---|---|---|
| 절전 2~3회 반복 후 터치 먹통 | H4 "일정 횟수/시간 후 먹통"과 **현상 일치** | 강 |
| **GND 쇼트 시 정상 복귀** | H2/H3 직접 증거 — 전극이 GND 경로가 없어(H2) 전하가 누적(H3)했고, **외부 GND 단락을 줘야** 빠진다 | 강 |
| SW RESEED 3회로 해결 불가 | 누적이 LTA(SW 베이스라인) 차원이 아니라 **물리 전극 전하** 차원임을 시사 → H3 지지 | 중 |
| counts drift → 항시 TOUCH 오판 | self-cap 터치=counts 감소(02 §5.4) 방향. DC 누적이 동작점을 시프트시켜 LTA−Counts>Th 상시 성립으로 끌면 정합 | 중(정량 확인 필요) |

> [!NOTE]
> **GND 쇼트 복귀가 가설의 가장 강한 정황 증거.** ESD가 단순 IC 내부 LTA 드리프트라면 SW RESEED(LTA 리시드)로 풀려야 하는데 안 풀렸고, **물리적 외부 GND 단락**으로만 풀렸다. 이는 "전극 노드에 빠질 DC 경로가 없다"(H2)와 "그 경로를 외부에서 강제로 만들어줘야 한다"는 그림에 정확히 부합한다. → **H2·H3 현상 지지.** (단 "왜 GND가 없으면 안 빠지나"의 정량은 D1 아날로그 영역, 실측 필요.)

## 3. Q5 — 방전 무력의 회로적 이유 (핵심) — 이중 무력화

은수님 가설 H5: "SW 방전(CRX0 VSS)도 C51 너머 전극 전하를 못 뺌 → 방전 무력." 이 명제를 **방전 검토 B2와 결합**하면 무력화가 **두 겹**으로 드러난다.

### 3.1 무력화 ① — B2: 현재 방전이 애초에 VSS 단락이 아니다 (가설과 독립한 SW 결함, 더 앞단)

[방전·autoATI 공존 권고 §3]의 라이브 발견:
- 현재 `discharge_crx0`는 `0x30 LSB = 0x02`를 blind write.
- 데이터시트 A.5 검증(본 분석 재확인): **bit 1 = Linearise Counts, bit 0 = Enable Channel**. 따라서 `0x02` = **Linearise=1 + Enable=0**. 핀-VSS 단락 비트가 아니다.
- 핀 VSS 단락은 **A.10 `0x34`(Pattern Definitions) Inactive Rxs = 0x0A(VSS)**, CRx 핀 enable은 0x33 경로. → 현재 코드는 "채널 disable→enable + Linearise flip"일 뿐 **핀-VSS 물리 단락 보장 없음**.

→ **이 무력화는 C51과 무관하다.** 방전이 IC 핀조차 VSS로 떨구지 못하면, C51 건너편 전극은 논할 필요도 없이 못 뺀다. **B2 SW 결함이 H5보다 앞단·더 확실한 방전 무력 원인.**

### 3.2 무력화 ② — H5: 설령 진짜 VSS 방전이어도 C51이 막는다 (가설의 고유 기여)

가정: 코드를 0x34=0x0A로 고쳐 CRX0 **핀**이 진짜 VSS로 단락된다고 하자.

```
[IC CRX0 핀] ──R31(100Ω)── C51(100pF) ──[J3 전극 노드]── (터치패드, GND 無)
   │
   └─ 방전 시 VSS 단락점 (여기까지만 0V로 끌림)
```

- 방전은 **R31·C51의 IC 쪽**을 VSS로 끈다. C51은 직렬 DC 블로킹(H1)이라 **DC 관점에서 J3 전극 노드는 C51 건너편**에 고립(H2).
- 전극에 쌓인 **DC 성분 전하**는 C51을 가로질러 VSS로 흐를 직접 DC 경로가 없다. 방전 펄스가 만드는 건 C51 양단 전압 변화(AC 결합)뿐 → 전극의 누적 DC 바이어스는 **방전으로 안 빠진다(H3·H5 회로적 성립)**.
- 빠지려면 전극→C51→VSS의 미소 누설(C51 ESR·유전체 누설)·전극 표면 누설·공기 경로뿐이며 시정수가 매우 길 가능성 → 누적.

> [!IMPORTANT]
> **Q5 결론**: 본 가설은 "방전 무력"에 **타당한 회로적 이유를 제공한다**(무력화 ②). 그러나 현장에서 **현재 방전이 무력한 1차 이유는 무력화 ①(B2, 방전이 VSS 단락이 아님)** 이다 — 이건 C51과 무관한 SW 결함으로, **가설 없이도 방전은 이미 무력**이다. 따라서 H5는 "방전 무력의 한 회로적 이유는 맞으나, 단독·유일 원인이라 단정할 수 없다." 두 무력화는 **OR 관계로 중첩**돼 있어, B2를 고쳐 진짜 VSS 방전을 만들어야 비로소 H5(C51 차단)가 단독으로 검증 가능해진다. → **실측 순서: 먼저 0x34 경로로 진짜 VSS 방전화 → 그래도 GND 쇼트로만 복귀하면 H5(C51 차단) 입증.**

## 4. Q6 — "일정 횟수 후 먹통"의 원인 정합 — 다인자

이슈해결·회로·방전 검토를 종합하면 먹통 후보가 **최소 3개** 병존하며, 셋이 배타적이지 않다:

| 후보 | 출처 | C51 가설과의 관계 |
|---|---|---|
| 가-1. **C51 전극 DC 전하 누적** | 본 가설 H3·H4 | GND 쇼트 복귀로 정황 지지. 물리 전하 차원 |
| 가-2. **SW 방전 결함**(0x30≠VSS) | 방전 검토 B2 | 누적을 빼주려던 안전판이 **실은 작동 안 함** → 누적을 방치(가설을 *악화*시키는 인자, 보완관계) |
| 가-3. **FIXED MULT·COMP self-cap 드리프트** | 회로 §11.3 | autoATI 없이 고정 보상 → 횟수 누적 시 동작점 이탈. C51과 독립적으로도 먹통 유발 가능 |
| 가-4. ATI error 영구 잔류 | 이슈해결 §4·§6 | **별개 경로**(전역 ati_error). 단 이슈해결 §7에서 "ESD 먹통은 ATI Error 아니라 counts drift"로 이미 분리됨 → Q6 주범 아님 |

> [!NOTE]
> 이슈해결 §7 마지막 문장이 결정적: **"ESD 먹통은 ATI Error가 아니라 counts drift(LTA/delta) 문제"**. 이는 먹통을 ati_error(가-4)에서 떼어내 **counts drift 계열(가-1·가-3)** 로 못박는다. 본 가설(가-1)은 그 drift의 **물리적 하위 원인 후보** 중 하나로 들어맞으나, 가-3(FIXED 드리프트)도 같은 자리를 노린다. **둘은 실측으로 갈라야 한다**(아래 §6). → **Q6: C51 단독 설명은 불충분, 다인자가 정합.**

## 6. 가를 항목 (실측 게이트, D4 관점)

H5·Q6를 이전 검토와 모순 없이 확정하려면:

1. **방전 진위(B2 우선)**: 현재 0x30=0x02 적용 시 CRX0 핀 전압을 오실로로 관측 — 실제로 VSS로 떨어지나? (떨어지면 B2 기각, 안 떨어지면 무력화 ① 확정). → **방전 코드를 0x34=0x0A로 교정 후 재측정.**
2. **C51 차단(H5) 분리 실험**: 진짜 VSS 방전화한 뒤에도 (a) 전극 DC가 안 빠지고 (b) GND 쇼트로만 복귀하면 → **H5(C51 건너편 못 뺌) 입증**. 방전화 후 바로 복귀되면 H5 기각(원인은 B2였음).
3. **전극 DC 직접 측정**: 먹통 시 J3 전극 노드 DC 전위(고임피던스 측정) — 누적 전하 유무 직접 확인(H3).
4. **C51 가-1 vs FIXED 가-3 분리**: C51을 점퍼(0Ω 대체)로 단락한 보드와 원본 보드의 먹통 재현 횟수 비교 → C51 기여분 분리.

## 7. D4 결론

- **ESD 이슈(현상)**: 절전 2~3회 먹통·GND 쇼트 복귀는 가설(특히 H2·H3)과 **강하게 정합**. 가설은 "왜 GND를 줘야 풀리나"에 회로적 그림(전극 DC floating·C51 차단)을 제공한다.
- **방전 무력(Q5)**: 가설은 방전 무력에 **회로적 이유를 제공하나 유일 원인은 아니다.** 현 시점 방전 무력의 **1차 원인은 B2(방전이 VSS 단락 아님, C51과 무관한 SW 결함)** 이며, C51 차단(H5)은 그것을 **교정한 뒤에야** 단독 검증 가능. 두 무력화가 OR로 중첩 → **조건부 정합**.
- **먹통 원인(Q6)**: C51 전하누적 단독으로 단정 불가. **counts drift 계열 다인자(C51 물리누적 ∥ FIXED 드리프트)** + 안전판 부재(B2)의 복합. 이슈해결 §7이 ati_error 경로는 이미 배제.
- **종합 판정: 조건부지지** — 가설은 이전 검토와 **모순 없이 정합**하고 ESD 현상의 유력한 물리 설명이지만, "방전 무력=C51 단독", "먹통=C51 단독"으로 단정하면 **B2 SW 결함과 FIXED 드리프트라는 더 앞단·병존 원인을 가린다.** 실측(§6, 특히 방전 VSS 교정 후 분리실험)으로 C51 고유 기여를 분리해야 지지로 격상.
