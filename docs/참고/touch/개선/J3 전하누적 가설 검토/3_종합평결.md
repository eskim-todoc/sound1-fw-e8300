# 03 · 종합 평결

> **TL;DR**: 은수님 가설은 **회로 토폴로지(H1 DC블로킹·H2 전극 IC측 격리·H5 C51 너머 못뺌)는 정확하나, "C51 전하누적 단독 먹통"으로는 약하다.** 진짜 그림은 **SW 드리프트(주, FIXED+LTA 고착) + C51 물리누적(부) 가산 모델**. 방전 무력의 1차는 C51이 아니라 B2(0x30≠VSS). 단 "GND 쇼트 복귀" 정황이 C51 부차 기여를 살려 완전 기각 불가 → **실측이 가른다**.

> 근거: [1_분석 D1~D5](.) · [2_검증 X1~X4](2_검증_핵심주장.md) · [00 입력](00_입력.md) · [회로 분석](../회로%20구성·분석.md) · [방전·autoATI 공존 권고](../방전·autoATI%20공존%20권고.md) · [이슈해결](../../이슈해결/2026-06_CRX1-ESD-더미채널.md).

## 1. 페르소나 verdict

| 페르소나 | 가설 | 진짜 원인 |
|---|---|---|
| D1 아날로그 | 조건부지지 | C51 단독 약함, ESD+R31+방전 못닿음 복합 |
| D2 데이터시트 | 조건부반대 | ATI Disabled+FIXED 동작점 시프트 미흡수 |
| D3 Adversarial | **반대** | LTA 드리프트 동작점 고착(C51 자기모순) |
| D4 정합 | 조건부지지 | 다인자(C51 ∥ FIXED) + 방전 1차=B2 |
| D5 대안 | 조건부반대 | SW(FIXED/LTA) 주, C51 부차 공존 |

→ **조건부지지 2·조건부반대 2·반대 1.** C51 단독 지지는 0 — **공존(가산) 모델로 수렴**.

## 2. 명제 H1~H5 판정

| 명제 | 판정 | 근거 |
|---|---|---|
| H1 C51 DC 블로킹 | ✅ 성립 | 자명. 단 측정 AC는 통과(Z 1.59kΩ@1MHz) |
| H2 전극 DC floating | △ 부분(과장) | IC측 격리 ○, "완전·영구"는 ✗(누설 다수·손가락 방전) |
| H3 영구 누적 | ✗ 반증 성향 | 충전전달 전하 회수(net DC≈0)·누설 τ 유한. R_leak 가름 |
| H4 먹통 단독 | ✗ 약함 | C51≫Cx 분압비 작음·충전전달 양방향(정류 아님) |
| H5 방전 무력 | △ 2차 | 토폴로지 ○, **1차는 B2(0x30≠VSS)**, H5는 0x34 교정 후 |

## 3. 핵심 정정

1. **C51 100pF 직렬 = 비표준 부작용 아님**: Sound1 **WLCSP11** self-cap **슬라이더 레퍼런스(Fig 2.3)에 C6 100pF 표준 존재**. 00_입력의 "Fig 2.1(버튼, C 없음) 비교"는 **패키지·전극형태 불일치 오류** → 정정.
2. **방전 무력 1차 = B2(SW 결함)**, C51(H5)은 2차. C51 안 끌어들여도 방전이 원래 무력(0x30=0x02는 Linearise).
3. **먹통 1차 = SW 드리프트**(이슈해결 §7 "counts drift", LTA 고착 기제, 회로 §11.3 "펌웨어 영역"). 증거 등급 SW≫C51.

## 4. 평결 — 가산(공존) 모델

> 은수님 판단은 **"회로 토폴로지의 출발점은 옳다"**. C51이 DC를 막고 전극이 IC·GND와 DC 격리되는 것은 사실. 그러나 **"그래서 전하가 영구 누적돼 단독으로 먹통"**은 약하다 — ① 충전전달이 전하를 회수하고 ② 전극 누설이 있으며 ③ 먹통의 더 유력한 원인은 SW 드리프트(증거 우세)이고 ④ 방전 무력의 1차는 B2다.
>
> **단 "GND 쇼트 시 복귀"가 SW 드리프트만으로는 설명이 약하다**(물리 전하 제거 외형). 이 한 축이 C51 물리누적의 **부차 기여**를 살린다. → **배타 택일이 아니라 SW(주) + C51(부) 가산 모델.**

## 5. 판별 실측 (저비용·결정적)

| # | 실험 | 결과 해석 |
|---|---|---|
| 1 | **C51 단락(점퍼)** 후 먹통 재현 | 소멸 → C51 확정 / 잔존 → SW |
| 2 | **방전 0x34(진짜 VSS) 교정 + auto-Re-ATI 억제** 후 N회 먹통 | 잔존 → 물리누적 강화 / 소멸 → SW 단독 |
| 3 | **GND 쇼트 위치 변별** | J3 패드 직접만 복귀 → C51(물리) / 어디든 복귀 → SW(LTA) |
| 4 | **전극 노드 DC 오실로** | 수V 단조 누적 확인 → H3/H4 부활 |
| 5 | **전극-GND 절연저항 R_leak** | 높음(>1e13Ω) → 누적 가능 / 낮음 → 누설로 해소 |

## 6. 해결 방향 (실측 결과별)

- **C51 물리누적 확인 시**: **전극측 GND 고저항 블리더(1~10MΩ)** — 측정 감도 유지하며 DC 전하 배출 (C51 제거는 EMI·표준성 손실이라 비권장). 또는 TVS.
- **SW 드리프트 확인 시**: ATI Full 복귀 + 노터치 seed 게이트(이전 하이브리드 권고).
- **가산(둘 다)**: 블리더(HW) + SW 개선 병행. + 방전 0x34 교정·R31 470Ω 검토.

## 7. 은수님 질문 답

> "이 판단(C51 DC블로킹→전하 누적→먹통)이 맞을까?"

**부분적으로 맞습니다.** C51이 DC를 막고 전극이 떠 있는 회로 토폴로지(H1·H2·H5)는 정확합니다. 그러나 **"단독 주원인"으로는 약합니다** — 충전전달이 전하를 회수하고, 전극 누설이 있으며, 먹통의 더 직접적 원인은 SW 드리프트(FIXED+LTA 고착)이고, 방전이 무력했던 1차 이유는 C51이 아니라 방전 코드 자체(0x30≠VSS)입니다. **단 "GND 쇼트 복귀"가 물리 누적을 시사해 부차 기여로 공존할 수 있으니, C51 단락·전극 DC 실측으로 가려야 합니다.**
