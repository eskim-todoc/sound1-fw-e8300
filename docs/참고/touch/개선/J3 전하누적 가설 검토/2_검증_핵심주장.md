# 02 · 핵심 주장 adversarial 검증

> **TL;DR**: 5 페르소나 분석을 데이터시트·회로 이론으로 독립 재검증. 4건 모두 "조건부성립" — **C51 단독 누적·먹통은 반증, "SW 드리프트(주) + C51 물리누적(부) 가산 모델"이 성립.** 핵심 정정: C51 100pF 직렬은 비표준 아님(WLCSP11 슬라이더 Fig 2.3에 C6 100pF), 방전 무력 1차는 C51이 아니라 B2(0x30≠VSS).

> [!NOTE]
> 입력: [00 입력](00_입력.md). 검증자는 5 분석을 맹신하지 않고 데이터시트 §·회로 이론·정량으로 재검증.

---

## X1 · DC 블로킹·전극 누적 (H1~H3) — 조건부성립

- **H1 DC 블로킹**: 성립(자명). 단 self-cap 충전전달은 양방향 AC 펌핑(§5.4) → C51을 "측정 통과 / DC 차단"으로 분리. Z_C51≈1.59kΩ@1MHz → 측정 펄스 통과.
- **H2 전극 floating**: 부분 성립·과장. C51이 IC측 DC 차단은 맞으나 전극은 **다중 누설 경로**(PCB 표면저항 1e9~1e12Ω·공기·스프링핀 오염·**터치 시 손가락 kΩ~MΩ 방전**). C_node~수pF, R_leak~1e11Ω → τ~수초. "완전 floating·영구 격리" 과장.
- **H3 영구 누적**: **반증 성향**. 영구 누적엔 ①지속 DC 주입원 ②누설 0 둘 다 필요한데, 충전전달이 매 사이클 전하 회수(net DC≈0)·누설 τ 유한 → 빠짐. **단 R_leak 예외적 높으면(>1e13Ω, τ 분~시간) 부차 기여 가능**(실측 가름).

## X2 · 먹통 인과 (H4) — 조건부성립

- **(A) C51 양면성 확정**: 측정 펄스 통과(Z 1.59kΩ@1MHz) + DC 차단 — 회로 이론 성립.
- **(B) "정상 측정 → 전극 DC 단조 누적" 경로 데이터시트에 없음** → 정상 터치만으로 무한누적→먹통(H3·H4 단독)은 **데이터시트 미지원**.
- **(C) 복합 인과는 조건부 성립**: 외부 ESD 주입(매개=C51 DC차단+전극 floating) → 충전전달 동작점(Q=Cx·ΔV) 편향 → counts 시프트 → 고정 threshold 교차 → 먹통. 이슈해결 §7(절전 2~3회 후 먹통·GND 쇼트 복귀)과 정합. **"동력=외부 ESD, 매개=C51, 발현=SW 동작점 시프트"**.
- 반례: 1차 동력이 FIXED+LTA 드리프트(SW)일 수 있음. GND 쇼트 복귀는 LTA 리셋으로도 설명.

## X3 · 방전 무력 (H5) — 조건부성립

- **토폴로지 성립**: CRX0→R31→C51→J3. C51 직렬이라 IC측 CRX0를 VSS로 둬도 전극 DC 못 뺌(회로 이론 명확).
- **🔴 1차 원인은 B2(선행 차단)**: 현재 방전 `0x30 0x02`는 A.5상 Linearise+Enable=0(핀 VSS 아님, VSS는 0x34). **IC핀조차 VSS 못 도달** → C51 격리(H5)는 그 전에 IC핀이 실제 VSS에 닿아야 논할 수 있음. **방전 무력 1차=B2, H5는 0x34 교정 후 2차 요인**.
- 반례: 과도 토글은 ΔQ=C51·ΔV만큼 1회분 재분배 → "완전 무력" 과장.

## X4 · 진짜 원인 (Q6) — 조건부성립

- **C51 단독 반증, "SW 드리프트(주) + C51 물리누적(부) 가산 모델" 성립.**
- **SW 드리프트 = 1차(증거 高)**: ① 이슈해결 §7 "ESD 먹통은 ATI Error 아닌 **counts drift(LTA/delta)**" — IC 자체 진단. ② §5.5 LTA frozen + FIXED + auto-Re-ATI 부재 → counts 드리프트 시 LTA 고착 → 강제 리셋으로만 복귀(기제 직접 설명). ③ 회로 §11.3 "FIXED 운용 문제, 펌웨어 영역" 명시.
- **C51 물리누적 = 부차(증거 低·미실측)**: Z 1.59kΩ로 AC 통과, C51≫Cx 분압비 작음. **C51 비표준 프레이밍 과장** — WLCSP11 슬라이더 Fig 2.3에 C6 100pF 표준.
- **판별 게이트**: 방전 0x34(진짜 VSS) 교정 + auto-Re-ATI 억제 후 ① 전극 노드 DC 오실로 ② N회 후 먹통 재현 여부.

## 검증 종합

| 주장 | holds | 한 줄 |
|---|---|---|
| X1 DC누적 | 조건부성립 | H1 성립·H2 과장·H3 반증 성향(R_leak 가름) |
| X2 먹통인과 | 조건부성립 | 정상측정 누적 경로 없음, 외부 ESD 복합만 조건부 |
| X3 방전무력 | 조건부성립 | 토폴로지 성립, **1차는 B2(0x30≠VSS), H5는 2차** |
| X4 진짜원인 | 조건부성립 | **SW 드리프트(주)+C51 물리누적(부) 가산** |

**확정**: C51 토폴로지(DC차단·전극격리) 성립. **반증**: C51 단독 영구누적·먹통. **정정**: C51 100pF 비표준(→WLCSP11 슬라이더 표준), 방전무력 1차 C51(→B2). **실측 게이트**: ①C51 단락 시 먹통 소멸 ②0x34 교정+Re-ATI 억제 후 재현 ③GND 쇼트 위치 변별 ④전극 DC 오실로 ⑤R_leak.
