# 02 · 핵심 주장 adversarial 검증

> **TL;DR**: 5 페르소나 분석의 낙관을 데이터시트·코드로 독립 재검증. 4건 모두 "조건부성립". **라이브로 잡은 결정적 정정 — 현재 방전 코드 `0x30 0x02`는 데이터시트상 "CRX0 VSS"가 아니라 "Linearise+Enable off"** (VSS는 0x34, 핀 enable은 0x33). → 방전의 물리 효력 자체가 미검증(B2). 또한 현 ATI Disabled config에선 교란·진동이 0(ATI Full 도입 가정에서만 발생).

> [!NOTE]
> 입력: [00 입력](00_입력.md). 검증자는 5 분석을 맹신하지 않고 데이터시트 §·코드 라인 1차 재검증.

---

## W1 · 토글 교란 (Q1) — 조건부성립

- **🔴 B2 라이브 정정**: `discharge_crx0`(`drv.c:942`)가 `0x30 LSB 0x02`를 쓰는데, 데이터시트 A.5상 0x30 LSB = bit0 Enable·bit1 Linearise·bit2 Dual Dir·bit3 Invert. **0x02 = Linearise=1 + Enable=0**. **"CRX0 VSS"가 아님** — VSS(Inactive Rxs 0x0A)는 0x34(A.10), CRx 핀 enable은 0x33(A.9 bit8). 코드 상수 `INACTIVE_RXS_CRX0_VSS=0x02`·주석은 데이터시트 오적용. → 실제 동작은 "CH0 enable 토글 + Linearise 비트 의도치 않은 flip", **핀 VSS 단락 미보장**.
- **현 config 충돌 0**: ATI Mode=Disabled(0x36=0x0408) + CH timeout disable(0xC0 0x07) → auto-ATI/Re-ATI 비동작. **교란은 "ATI Full 도입 가정"에서만**.
- ATI Full 시: §5.9 ATI는 연속 measured counts 의존인데 200ms enable 토글이 입력 단절 → 수렴 교란(데이터시트 미규정, 확인 필요).

## W2 · Re-ATI 진동 (Q3) — 조건부성립

- **현 Disabled config에선 진동 없음** — auto Re-ATI 자체가 안 돎(§5.10/5.11). 진동을 막는 건 "터치 게이트"가 아니라 **ATI Disabled config 자체**(5 페르소나 "터치 게이트가 막는다"는 부정확).
- ATI Full 시: 방전 복원 카운트 튐 → LTA가 ATI Band 이탈 → auto Re-ATI 재트리거 → 다음 토글이 또 단절 → ATI Error → I²C hang **진동 루프** 성립.
- 코드: 200ms 폴링(`get_state→discharge_crx0`)에 **ATI 진행 gate 없음**(`touch.c:422`).

## W3 · 레이어 분리 (Q5) — 조건부성립

- **레이어 분리 데이터시트로 성립**: auto-ATI/Re-ATI(MULT 분배비·COMP 내부 pF offset·LTA IIR, §5.9·5.10·5.5)는 **전적으로 IC 내부 레지스터 조작** — 외부 핀 물리전하를 빼는 경로 없음. 핀-VSS 방전은 별도 1차 기능(Inactive Rxs 0x34=VSS, A.10). → **ESD가 진짜 핀 물리전하면 auto-ATI는 제거 불가**(A6 대체불가 옳음, 할루시네이션 아님).
- **단 조건부**: ① ESD가 LTA 드리프트(온·습도)면 auto-ATI/Reseed로 흡수 → 방전 redundant (전제 붕괴). ② **방전 코드가 실제 VSS 단락인지 미검증(B2)** — `0x30 0x02`가 Linearise일 뿐이면 방전 물리효력 자체가 거짓. → **개념적 레이어 분리는 성립, 현 구현의 물리효력은 미확정**.

## W4 · 최선 대안 (Q6) — 조건부성립

- **auto Re-ATI 억제는 메커니즘 타당**: §5.10 auto Re-ATI는 LTA drift 시만, §5.11 ATI Error는 자동 재시도 없음(수동 bit). 부팅 1회 Full 수렴 후 Disabled 고정 + 수동 Re-ATI(`re_ati_trigger drv.c:569`)는 기존 코드 재활용. **auto Re-ATI 끄면 방전 카운트 튐이 LTA 흔들어도 자동 재캘리브 안 걸려 진동 원천 제거**.
- **단 "방전이 ESD 잡는다" 전제가 코드상 거짓 가능성**(W1·W3 B2). → "최선·동시 해결" 단정은 ESD 실측 + 0x30 비트매핑 실측 통과 위에서만.

## 검증 종합

| 주장 | holds | 한 줄 |
|---|---|---|
| W1 토글 교란 | 조건부성립 | 현 config 0, ATI Full 시만. **0x30 0x02 = Linearise(VSS 아님)** |
| W2 Re-ATI 진동 | 조건부성립 | 현 Disabled가 막음(터치 게이트 아님), Full 시 진동 |
| W3 레이어 분리 | 조건부성립 | 분리 참(방전 고유) — 단 ESD 물리누적 AND 방전 실효 시만 |
| W4 최선 대안 | 조건부성립 | auto Re-ATI 억제 타당, 단 방전 실효·ESD 실측 게이트 |

**🔴 최우선 실측 (새 발견)**: **현재 방전(`0x30 0x02`)이 실칩에서 핀 VSS 단락을 일으키는가** — 데이터시트상 Linearise일 뿐. 아니면 방전 코드를 0x34(Inactive Rxs)/0x33으로 고쳐야 진짜 방전. **방전 존폐 논의 이전에 "방전이 방전인가"부터.**
**확정**: 레이어 분리(개념). **정정**: "터치 게이트가 진동 막음"(→ ATI Disabled config가 막음), "0x30=VSS"(→ Linearise). **실측 게이트**: 방전 물리효력·ESD 정체·ATI Full I²C hang.
