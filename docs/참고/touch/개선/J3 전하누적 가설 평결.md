# C51 전하누적 가설 — 평결·해결 방향 (정식)

> **TL;DR**: "CRX0-J3 사이 C51(100pF)이 DC를 막아 GND 없는 전극에 전하가 누적 → 일정 횟수 후 먹통"이라는 은수님 판단은 — **회로 토폴로지(C51 DC차단·전극 IC측 격리)는 맞지만 "단독 주원인"으로는 약하다.** 진짜 그림은 **SW 드리프트(주) + C51 물리누적(부) 가산 모델**. 방전 무력의 1차는 C51이 아니라 B2(0x30≠VSS). 단 "GND 쇼트 복귀"가 물리 누적을 시사 → **C51 단락·전극 DC 실측이 가른다.**

> [!NOTE]
> 검증 과정: [J3 전하누적 가설 검토/](J3%20전하누적%20가설%20검토/) — [00 입력](J3%20전하누적%20가설%20검토/00_입력.md)·[1_분석 D1~D5]·[2_검증 X1~X4](J3%20전하누적%20가설%20검토/2_검증_핵심주장.md)·[3_종합평결](J3%20전하누적%20가설%20검토/3_종합평결.md). 회로 SSOT: [회로 구성·분석](회로%20구성·분석.md).

## 1. 은수님 질문에 대한 답

> "C51 DC 블로킹 → J3 전하 누적 해소 안 됨 → 일정 횟수 후 먹통. 이 판단이 맞을까?"

**부분적으로 맞습니다 — 회로 토폴로지는 정확하나 단독 원인으로는 약합니다.**

| 명제 | 판정 |
|---|---|
| C51 DC 블로킹 | ✅ 성립 (단 측정 AC는 통과, Z 1.59kΩ@1MHz) |
| 전극 IC측 DC 격리 (GND 없음) | ✅ 성립 (단 "완전·영구"는 과장 — 누설·손가락 방전) |
| **전하 영구 누적** | ✗ 약함 (충전전달이 매 사이클 회수, 전극 누설 τ 수초) |
| **누적 → 단독 먹통** | ✗ 약함 (C51≫Cx 분압비 작음, 충전전달 양방향=정류 아님) |
| C51 너머 전극 방전 못 함 | △ 토폴로지 성립, **단 방전 무력 1차는 B2(0x30≠VSS)** |

## 2. 진짜 그림 — 가산(공존) 모델

- **먹통 1차 = SW 드리프트**(증거 高): FIXED MULT/COMP + ATI Disabled로 LTA 자동보정 포기 → counts 드리프트 시 LTA 고착 → 강제 리셋으로만 복귀. 이슈해결 §7 "ESD 먹통은 ATI Error 아닌 **counts drift**"가 IC 자체 진단. 회로 §11.3 "펌웨어 영역" 명시.
- **C51 물리누적 = 부차**(증거 低·미실측): **단 "GND 쇼트 시 복귀"가 SW만으로는 설명 약함**(물리 전하 제거 외형) → 부차 기여로 공존 가능. **R_leak(전극 절연저항)이 높으면 누적 가능**.
- **방전 무력 1차 = B2**: 현재 방전 `0x30 0x02`는 데이터시트상 Linearise(핀 VSS 아님). C51 격리(H5)는 0x34 교정 후 2차.

> [!IMPORTANT]
> **정정**: 00_입력에서 "C51 100pF 직렬은 데이터시트 self-cap 표준과 다름(Fig 2.1 C 없음)"이라 했으나 **오류**. Sound1과 동일 **WLCSP11**의 self-cap **슬라이더 레퍼런스(Fig 2.3)에 C6 100pF가 표준으로 존재**한다 → C51은 비표준 부작용이 아니다. (Fig 2.1은 DFN12 단순 버튼이라 패키지·전극형태 불일치)

## 3. 판별 실측 (저비용·결정적)

| # | 실험 | 해석 |
|---|---|---|
| 1 | **C51 단락(점퍼)** 후 먹통 재현 | 소멸=C51 / 잔존=SW |
| 2 | **방전 0x34(진짜 VSS) 교정 + auto-Re-ATI 억제** 후 N회 | 잔존=물리누적 / 소멸=SW |
| 3 | **GND 쇼트 위치 변별** | J3 패드 직접만 복귀=C51(물리) / 어디든=SW(LTA) |
| 4 | **전극 노드 DC 오실로** | 수V 단조 누적 확인=물리누적 부활 |
| 5 | **전극-GND 절연저항 R_leak** | 높음(>1e13Ω)=누적 가능 / 낮음=누설로 해소 |

→ **가장 빠른 단일 게이트**: 실험 1(C51 단락) 또는 2(0x34 교정 후 재현). 먹통이 사라지면 C51, 남으면 SW.

## 4. 해결 방향 (실측 결과별)

| 결과 | 해결 |
|---|---|
| **C51 물리누적** | **전극측 GND 고저항 블리더(1~10MΩ)** — 감도 유지하며 DC 배출. (C51 제거는 EMI·표준성 손실로 비권장). 또는 TVS |
| **SW 드리프트** | **ATI Full 복귀 + 노터치 seed 게이트**([하이브리드 권고](은수님%20안%20평결·하이브리드%20권고.md)) + 방전 0x34 교정 |
| **가산(둘 다)** | 블리더(HW) + SW 개선 병행 + R31 470Ω 검토 |

## 5. 회로 분석 문서 반영

[회로 구성·분석 §12 개선 검토](회로%20구성·분석.md)에 **"전극 GND 블리더(1~10MΩ)"** 를 ESD 누적 대응 후보로 추가 권고. 단 실측(C51 단락·전극 DC) 선행.

## 6. 한 줄 결론

> **은수님의 회로 직관(C51 DC 차단·전극 격리)은 정확하다. 다만 그것이 "단독 먹통 원인"인지는 약하고, 실제로는 SW 드리프트(주)와의 가산이며, 방전이 무력했던 1차 이유는 C51이 아니라 방전 코드 결함(0x30≠VSS)이다. "C51 단락 시 먹통이 사라지는가" 한 실험이 모든 것을 가른다 — 사라지면 전극 GND 블리더가, 남으면 ATI Full+노터치 게이트가 해법이다.**
