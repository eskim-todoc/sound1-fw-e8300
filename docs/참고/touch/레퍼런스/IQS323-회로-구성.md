# IQS323 회로 구성 (Sound1)

**TL;DR**: IQS323001CSR(U13)을 1.8V_QCC로 구동. I2C(SDA/SCL/RDY)로 E8300에 연결. CH0(CRX0)만 활성 사용 — J3 커넥터를 통해 터치 전극 패드에 연결. CH1(CRX1)은 J4에 배선 완료(SW 비활성), CH2(CRX2)는 470Ω 종단 후 미연결.

## 2. 핀 연결 요약

| 핀 좌표 | 핀 이름 | 연결 대상 | 비고 |
|---|---|---|---|
| C5 | VDD | 1.8V_QCC (R28 경유) | 전원 입력 |
| A3 | VREG | 바이패스만 (C56·C57) | 내부 레귤레이터 출력 |
| A5 | SDA | SDA_E8300 | I2C 데이터 |
| C3 | SCL | SCL_E8300 | I2C 클럭 |

| A7 | GND | GND | |
| B4 | OUTA | No Connect | 미사용 |
| B6 | TxA | R30(0Ω) → **No Connect** | 미사용 (종단 없이 플로팅) |
| B2 | CRX0 | R31 → C51 → J3 | **CH0 — 현재 유일한 활성 채널** |

| C1 | CRX2 | R33 → No Connect | CH2 — 종단 후 미연결 |

## 3. 전원 회로

```
1.8V_QCC ── R28(0Ω/1005) ──┬──────────────── VDD(C5)
                            ├── C54(4.7µF/0603) ── GND
                            └── C55(100pF/0603) ── GND

VREG(A3) ──┬── C56(2.2µF/0603) ── GND
           └── C57(100pF/0603)  ── GND
```

- **R28**: 0Ω 점퍼 (1005 크기). 필요 시 페라이트 비드 교체 또는 전류 측정용 끊기 지점
- **C54/C55**: VDD 바이패스 (C54 4.7µF 벌크, C55 100pF 고주파)
- **VREG**: 내부 레귤레이터 출력 핀. 외부 전원 연결 없이 바이패스만 붙여 안정화

> [!NOTE]
> **C54 = 4.7µF 정정 (2026-06-11)**: 종전 본 문서는 C54를 4.7nF로 표기했으나, 실제 회로도 `Touch Sensor Schematic.JPG`(4.7µF/0603) 및 데이터시트 §2.5 VDD 권장(100pF + 4.7µF)에 근거해 **4.7µF**로 정정. 상세: [`../개선/회로 구성·분석.md`](../개선/회로%20구성·분석.md).

## 4. 디지털 인터페이스

| 신호 | 방향 | 연결 |
|---|---|---|
| SDA_E8300 | 양방향 | E8300 I2C 마스터 ↔ IQS323 슬레이브 |
| SCL_E8300 | E8300 → IQS323 | I2C 클럭 |
| INTERRUPT_n | IQS323 → E8300 | RDY 핀 (Active Low) |

> [!NOTE]
> `INTERRUPT_n`은 현재 `tdc_drv_iqs323_read_status()` poll 방식 사용.

## 5. 아날로그 채널 회로

### 5.1 TxA — 미연결

```
TxA (B6) ── R30(0Ω/0603) ── No Connect
```

- R30은 현재 0Ω이며, 선단이 플로팅(No Connect). TxA는 회로에서 사용되지 않는다.
- R30 자리에 저항 삽입으로 추후 용도 변경 가능.

### 5.2 CH0 (CRX0) — 활성 채널

```
CRX0 (B2) ── R31(100Ω/0603) ── C51(100pF/0603) ── J3
```

- **R31 (100Ω)**: ESD 전류 제한 + 고주파 필터용 직렬 저항
- **C51 (100pF)**: RC 저역통과 필터 (fc ≈ 1/(2π × 100 × 100p) ≈ 15.9 MHz)
- **J3**: SCS05-065-10 스프링 핀 커넥터 → 제품 PCB 터치 전극 패드 연결

### 5.3 CH1 (CRX1) — 비활성 채널 (배선 완료)

```
CRX1 (A1) ── C52(100nF/0603) ── R32(0Ω/0603) ── J4
```

- **C52 (100nF)**: CH0(C51=100pF)보다 1000배 큰 값. DC 차단 또는 노이즈 흡수 목적으로 추정
- **R32 (0Ω)**: 필요 시 저항 삽입 가능한 위치
- **J4**: SCS05-065-10 — J3와 동일한 커넥터 규격. SW에서 현재 미사용

> [!NOTE]
> C52가 100nF으로 CH0(100pF)과 값이 크게 다름. 직렬 100nF은 DC 및 저주파 신호 차단 특성이 있어, CH0과 다른 동작 방식으로 설계된 것으로 보임. 실제 사용 전 데이터시트 확인 필요.

### 5.4 CH2 (CRX2) — 미연결

```
CRX2 (C1) ── R33(470Ω/0603) ── No Connect
```

- 470Ω 종단만 있고 전극 연결 없음. 완전 미사용.

## 7. 현재 SW 사용 현황

| 채널 | HW 상태 | SW 상태 | 비고 |
|---|---|---|---|
| CH0 (CRX0) | J3 연결 완료 | **활성** | 터치 감지에 사용 |

## 8. ESD 관련 메모

현재 회로의 ESD 방어 요소:
- **R31 (100Ω)**: CRX0 직렬 저항 — ESD 방전 전류를 제한해 IC 입력 핀 보호
- **C51 (100pF)**: 고주파 노이즈 차단
- **R28 (0Ω)**: 전원 경로 페라이트 비드 미삽입 상태 — 전원 경유 ESD 취약

ESD 누적 문제 맥락:
- 실제 제품에서 2~3회 절전 반복 후 터치 먹통 발생 (GND 쇼트 시 정상 복귀)
- SW RESEED로는 해결 불가 — HW 개선 필요 (상세: [`IQS323-RESEED.md`](IQS323-RESEED.md))
- **향후 개선 검토안**: CH1(J4)을 guard electrode(능동 실드)로 활용 — PCB 상 CH0 전극 주변에 guard ring 패드 추가. TxA는 현재 미사용이므로 TX 구동 연결도 검토 가능.
