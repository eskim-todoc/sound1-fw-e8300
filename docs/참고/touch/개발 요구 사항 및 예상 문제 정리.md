
 **요구 사항 및 사용 시나리오**

1. 터치 센서를 전원 스위치로 사용
2. 절전 모드에서 2~3초 터치를 지속하고 있으면 노말 모드로 부팅 (Ezairo8300 만 워치독 리셋 사용)
3. 노말 모드에서 2~3초 터치를 지속하고 있으면 절전 모드로 진입
4. 노말 모드 및 절전 모드에서는 터치 센서로 공급되는 전원이 중단되는 일이 없음
5. 보드 최초 전원 연결 시에는 터치 센서는 완전한 콜드 부팅

**주의사항**
보드에 충전 케이블을 연결 시 터치 센서로 입력되는 전원에 약 1us 정도 채터링 발생. 이 채터링에 의해 터치 센서가 재부팅 되는지 알 수 없음. 보수적으로, 전원 불안정에 의한 터치센서 재부팅을 고려해야 한다고 사료됨.

**현재 구현된 사항 심플 정리**

1. 현재 셀프 캐패시턴스 방식으로 설정 (CRX0 사용)
2. autoATI 기능 사용하지 않음. MULT, COMP를 FIXED 값으로 고정해서 사용함
3. 셀프 캐패시턴스 방식에 의한 LTA의 드리프트 현상을 방지하기 위해 주기적(200ms)으로 CRX0를 VSS로 설정하자 마자 다시 측정 채널로 설정하는 방식으로 캡 방전을 유도함
4. CRX1을 CalCap으로 설정 (CRX0를 VSS로 설정하려면 활성화된 채널이 하나 이상 필요)
5. 이벤트/스트리밍 모드 중에 스트리밍 모드에서 동작

**예상 되는 이슈 사항**

1. 터치 센서를 전원 버튼으로 사용하니 발생되는 이슈로, 전원 버튼을 눌러서 절전->노말 모드로 재부팅 진입 시, autoATI를 사용하면 전원 버튼을 여전히 누르고 있는 상태에서 ATI가 되는 경우가 생김
2. 이 경우 터치를 해제했다가 다시 터치해도, 터치로 인식되지 않음.
3. 마찬가지로 노말->절전 모드로 진입할 때도 마찬가지다. 터치가 발생한 상태에서 초기화 될 시 터치 먹통 발생 우려.
4. 이를 해결하려고 노말->절전 모드 진입 시 터치 해제 상태 확인 후 설정하려 했지만, 그래도 여전히 설정 시점에 터치 발생에 대한 우려를 피할 수 없음
5. 그래서 autoATI를 사용하지 않고 FIXED 값을 사용하기로 했음.
6. autoATI 사용시 하드웨어 내부적으로 충/방전 효과가 있어 드리프트 현상이 억제되지만, autoATI를 사용하지 않기 때문에 드리프트 현상 발생. 일정 횟수의 터치 이벤트를 처리한 후 터치가 먹통되는 현상이 발생함.
7. 그래서 CRX0를 주기적으로 VSS로 설정하여 자체적인 방전 상태를 만들어 주었음.
8. 이런 식으로 FIXED 값을 사용하니, 초기 터치 세팅시 계산된 카운트 값을 RESEED로 LTA에 적용할 때 마다 카운트 값이 다르게 적용됨. 340대, 660대 등. 매번 켜질 때마다 그 시점의 정전용량에 따라 카운트가 다르게 적용됨. 하지만 MULT, COMP는 고정이라 카운트 값마다 실제 터치시 CUR 값이 많이 달라짐.
9. 스레스홀드는 고정 값으로 설정되었는데, 이런 문제로 CUR 값이 크게 변하거나 작게 변하는 경우 터치가 잘 되거나 안되거나하는 이슈가 발생함.
