터치 임계·계수 레지스터 동작 레퍼런스

Sound1 · IQS323 self-cap 터치 — 코드 상수가 레지스터에서 어떻게 계산·적용되는가 조사·검증 완료

코드 상수(임계·히스테리시스·Beta·ATI)가 IQS323 레지스터로 들어가는 경로와, IC가 그 값을 내부에서 어떻게 실제 터치 임계로 바꾸는지를 정리했습니다. 딱 하나만 기억하면 됩니다 — 터치 절대임계 = 계수 × LTA ÷ 256. 모든 수치·공식은 데이터시트와 소스를 직접 인용했고, 페르소나 4 + 적대적 검증 1로 교차검증했습니다(할루시네이션 0). 상세 근거는 같은 폴더 터치 임계·계수 레지스터 동작.md.

1큰 그림 — 측정값이 흐르는 길

전극의 정전용량을 Counts로 재고, 평상시 기준선 LTA와 비교해 그 차이(delta)로 터치를 판정합니다. 상수들은 이 비교의 임계와 필터 속도를 정합니다.

self-cap이라 터치하면 Counts가 줄고(C 증가) delta가 커집니다. 터치/prox 동안에는 LTA가 얼어붙어(freeze) 기준선이 터치를 흡수하지 않습니다.

2핵심 공식

절대 터치임계 = ( 계수(0x62) × LTA ) ÷ 256
예) 계수 80, LTA 400 → 80 × 400 ÷ 256 = 125 counts · 진입조건: delta > 125
해제임계 = 절대임계 − ( H(0x62 상위니블) ÷ 256 × 절대임계 )
예) H=8, 절대임계 125 → hyst ≈ 3.9 → 해제 하한 ≈ 121

임계가 고정 숫자가 아니라 LTA에 비례하는 게 포인트입니다. 보드마다 기생용량이 달라 LTA가 달라져도 "LTA의 약 31%"라는 상대 감도는 유지됩니다.

4상수별 핵심

Touch Threshold (계수 80)

0x62 LSB에 80 그대로. IC가 매 샘플 80×LTA÷256로 절대임계 재계산. LTA 따라 변동하므로 상대 감도가 일정.

진입: delta > 절대임계

Hysteresis (H 8) — 4비트 한계

(8&0xF)<<4로 bits[15:12]에 위치(과거 bits[11:8] 오기입 버그 수정됨). 실제 hyst ≈ 3.9.

최대 H=15여도 해제임계는 임계의 ~94%까지만 내려감. 터치 stuck은 hysteresis로 못 풉니다(LTA 흡수 문제).

Prox Threshold (255) — touch와 채널 공유

prox 전용 카운터 없음 — 같은 delta를 prox·touch 임계와 각각 비교. LTA freeze가 "touch 또는 prox"라, prox를 255로 무력화해 freeze를 touch에만 맡김.

[실측 게이트] prox 단위(절대/계수) DS 미명시

ATI — baseline 자동 정규화

Full ATI(0x36)가 노터치 Counts를 Target 400으로 맞춰 보드별 기생용량(Cp)을 흡수. MULT/COMP는 IC 자동 산출.

5Beta — 수렴 속도, 그리고 해석 반전 실측 확정

Beta 해석은 두 자료가 정반대입니다.
· 데이터시트 §5.6: damping = Beta/256 → β 클수록 빠름
· 앱노트 AZD004(코드 설계 근거): α = 1/2^β → β 클수록 느림

실기 로그에서 β=16일 때 LTA가 6초에 단 −1(거의 동결) → AZD004 해석(α≈0)과 일치, 데이터시트 해석(−78 예상)과 불일치. → AZD004(β 클수록 느림)가 맞습니다. 그래서 "빠른 수렴"을 위해 β를 줄입니다. 현재 β=6(시정수 ≈12.8초, 롱터치 2.4초의 ~5배)은 터치 중 LTA 흡수를 막으면서 약결합은 결국 흡수하는 절충값.
왜 이게 중요한가 — 수렴이 너무 빠르면(β 작음) 천천히 누르는 터치를 LTA가 흡수해 임계에 못 닿고, 너무 느리면(β 큼) 핀셋 같은 약결합이 영원히 안 빠집니다. β로 그 균형을 잡습니다.

6ATI가 못 맞추는 것 — Grounding

ATI는 노터치 baseline(Cp 산포)만 정규화합니다. 하지만 터치 변화량(delta)은 손가락–대지 결합(grounding)에 의존해서, PC+GND 연결(delta 170)과 독립/배터리(delta 80~96)의 차이는 ATI가 못 잡습니다. → 임계는 반드시 실사용 grounding 환경(독립)에서 측정한 delta로 잡아야 합니다. PC 연결 상태 값으로 잡으면 제품에서 터치가 누락됩니다.
