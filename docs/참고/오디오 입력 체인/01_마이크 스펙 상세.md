# 01. 마이크 스펙 상세

**TL;DR**: **음향 성능은 사실상 같다** — 감도 −26 dBFS · AOP 120 dB SPL · SNR 64.3 vs 64.5 dB(A). 실질 차이는 **전원 잡음 내성뿐이고 Sullivan 이 15 dB 좋다.** 감도가 같으므로 **두 마이크 모두 `0x7FFFFF` = 120 dB SPL** 이고 이 문서 묶음의 모든 환산표가 양쪽에 그대로 적용된다.

## 1. 무엇을 보는 문서인가

| | **Sound1** | **Sullivan 1.5** |
|---|---|---|
| 품번 | **SPH0641LM4H-1** | **SPK0641HT4H-1** |
| 제조 | Knowles Electronics | **Syntiant Corp.** |
| 문서 | FN-없음, **Rev D** (2018) | **Rev D-1** (2024) |
| 원문 | [`../mic/sound1__SPH0641LM4H-1.pdf`](../mic/sound1__SPH0641LM4H-1.pdf) | [`../mic/sullivan1.5__SPK0641HT4H-1.pdf`](../mic/sullivan1.5__SPK0641HT4H-1.pdf) |
| 형식 | PDM 1비트 디지털 · 바텀 포트 · 무지향 · MEMS | 동일 |

> [!NOTE]
> **Knowles 의 MEMS 마이크 사업을 Syntiant 가 인수했다.** 같은 SiSonic™ 계열이고 품번 체계(`0641`)도 이어진다. **회사를 갈아탄 것이 아니라 같은 제품 계보**다. 데이터시트 표 구성과 시험 조건도 거의 같다.

> [!CAUTION]
> **두 데이터시트 모두 스펙 표가 «이미지» 다.** PDF 텍스트 레이어에 표 헤더만 있고 셀 값이 없다. 이 문서의 수치는 **페이지를 190 DPI 로 렌더해 판독**한 것이다. 자동 추출로는 값이 나오지 않으니 다음 사람이 헛수고하지 않도록 적어 둔다.

## 2. 감도 하나가 눈금 전체를 정한다

### 2.1 용어

| 용어 | 뜻 |
|---|---|
| **dB SPL** | 공기 중 실제 소리 크기. 0 = 가청 하한 |
| **dBFS** | 디지털 최대치 대비 비율. 최대치가 0, 그 아래는 전부 음수 |
| **감도** | **94 dB SPL 을 넣으면 몇 dBFS 가 나오나** |

### 2.2 유도

두 마이크 모두 **감도 −26 dBFS @ 94 dB SPL** 이다. 즉,

```
94 dB SPL  →  −26 dBFS
```

dB 는 덧셈이므로 **0 dBFS(디지털 최대치)에 닿으려면 26 dB 를 더 넣어야 한다.**

```
0 dBFS  =  94 + 26  =  120 dB SPL
```

> [!IMPORTANT]
> **`0x7FFFFF` = 120 dB SPL.** 이 문서 묶음 전체의 기준선이다.
>
> 그리고 **이 값이 마이크의 AOP(120 dB SPL)와 정확히 같다.** 마이크가 찌그러지기 시작하는 음압과 24비트가 넘치는 음압이 일치한다 — **어느 한쪽이 먼저 망가지지 않는 잘 맞춰진 설계**다.

### 2.3 감도 편차의 영향

감도 스펙은 **min −27 / typ −26 / max −25 dBFS** 다. 즉 개체차 **±1 dB**.

| 감도 | 0 dBFS 에 해당하는 음압 |
|---|---|
| −27 dBFS (min) | 121 dB SPL |
| **−26 dBFS (typ)** | **120 dB SPL** |
| −25 dBFS (max) | 119 dB SPL |

**모든 환산표에 ±1 dB 의 개체차가 깔려 있다.** 코드값으로는 ±12% 다. 정밀한 절대 음압 측정이 필요하면 개체별 교정이 필요하고, 상대 비교나 AGC 동작 판단에는 무시해도 된다.

전원 전압에 따른 감도 변동은 **±0.25 dB 이내**(양쪽 동일)라 무시할 수 있다.

**저전력 모드에서도 감도·AOP 가 같다.** 모드를 바꿔도 환산표는 유효하다. 대역폭만 8 kHz 로 좁아진다.

## 4. 잡음 바닥 - 실제로 쓸 수 있는 하한

SNR 은 «94 dB SPL 대비 잡음이 몇 dB 아래인가» 다. 따라서 **마이크 자체 잡음을 음압으로 환산**하면:

| | 계산 | 잡음 바닥 |
|---|---|---|
| Sound1 | 94 − 64.3 | **29.7 dB SPL** |
| Sullivan | 94 − 64.5 | **29.5 dB SPL** |

dBFS 로는 **−90.3 / −90.5 dBFS(A)**, 24비트 코드로는 **약 250~256**.

> [!IMPORTANT]
> **AGC 노이즈 게이트가 29.5 dB SPL 에 놓여 있다** ([04](04_AGC%20동작%20상세.md) §2). **마이크 잡음 바닥과 정확히 겹친다.**
>
> 우연으로 보기 어렵다 — **이 마이크에 맞춰 튜닝된 값**이다. 그리고 두 마이크의 잡음 바닥이 0.2 dB 차이라 **어느 쪽을 써도 게이트를 다시 잡을 필요가 없다.**

**동적 범위**(잡음 바닥 ~ AOP) = 120 − 29.7 = **약 90 dB**. 24비트가 담을 수 있는 144 dB 중 90 dB 만 실제로 쓴다.

## 5. 교체 관점

| 항목 | 판정 |
|---|---|
| 감도·AOP·데이터 형식 | **동일** — 소프트웨어 무변경 |
| 전원·부하·단락전류 | **동일** |
| AGC 튜닝 | **재튜닝 불필요** (§4) |
| 저역 특성 | Sullivan 이 10 Hz 낮다. 체감 차이는 작다 |
| 전원 잡음 | **Sullivan 이 명확히 우세** |
| 슬립 복귀 클럭 | **다르다** (§3.3). 지금은 미사용이라 무관 |

> [!CAUTION]
> **패키지 치수·패드 배열은 이 문서에서 대조하지 않았다.** 두 데이터시트의 기계 도면(패키지 아웃라인) 페이지를 비교해야 «핀 호환» 을 말할 수 있다. **전기·음향만 보고 «그대로 바꿔 끼운다» 고 단정하지 않는다.**

## 6. Sound1 에서 잡음이 들린다면

Sound1 마이크의 **PSRR 이 15 dB 낮다**는 것이 두 부품의 유일한 실질 차이다. 조용한 환경에서 잡음이 들린다면 순서는 이렇다.

| # | 확인 | 왜 |
|---|---|---|
| 1 | **PMIC 스위칭 잡음** — ISL9122A 는 약 2.5 MHz 로 스위칭한다 | 마이크 전원에 실리면 그대로 들어온다. [PMIC 문서](../pmic-isl99122a/README.md) |
| 2 | **자극·백텔 주기 성분** (217 Hz 근처) | PSR+N 시험 주파수가 217 Hz 인 것은 우연이 아니다 — 이 대역이 취약하다 |
| 3 | 마이크 전원의 디커플링 | 데이터시트 권장 회로 대조 |
| 4 | I2C 풀업 전압 | 데이터시트: **풀업이 Vdd 보다 낮으면 정지전류가 최대 3 µA 증가** |

**마이크 자체 잡음(29.7 dB SPL)은 AGC 노이즈 게이트가 막아 준다.** 게이트 위로 들리는 잡음이면 마이크가 아니라 **전원이나 기구**를 본다.
