# 03. dB SPL ↔ 코드 환산표

**TL;DR**: **`0x7FFFFF` = 120 dB SPL**, **6 dB 마다 2배**. 아래 표 하나로 «이 소리가 몇 번 코드인가» 와 «이 코드가 몇 dB 인가» 를 양방향으로 읽는다. 두 마이크의 감도가 같아 **양쪽에 그대로 적용**된다.

## 1. 공식

```
dBFS       = dB SPL − 120
마이크 코드 = 8,388,607 × 10^((dB SPL − 120) / 20)
믹스 코드   = 마이크 코드 >> 5            (= ÷32, 소수점 버림)
AGC 내부값  = 10 × log10(마이크 코드 / 2^47)     ← 10log10 이므로 일반 dB의 절반
dB SPL     = 120 + 20 × log10(마이크 코드 / 8,388,607)
```

> [!NOTE]
> **AGC 내부 눈금은 `10·log10`** 이라 일반 dB(`20·log10`)의 **절반**이다. AGC 코드 안의 숫자에 **2를 곱해야** 우리가 아는 dB 가 된다. 예: 코드의 `14.85` = 실제 **29.7 dB**.
>
> `2^47` 이 나오는 이유는 `cfx_as_frac48()` 이 정수를 **Q1.47 소수로 재해석**하기 때문이다.

## 3. 표에서 바로 읽히는 것

### 3.1 24비트를 다 쓰지 못한다

| | 코드 | dB SPL |
|---|---|---|
| 마이크가 만드는 하한 (잡음 바닥) | **256** | 29.7 |
| 마이크가 만드는 상한 (AOP) | **8,388,607** | 120 |
| **실제 사용 범위** | **약 90 dB** | |
| 24비트 이론 범위 | 144 dB | |

> [!IMPORTANT]
> **하위 8비트(코드 256 미만)는 신호가 아니라 마이크 자체 잡음이다.** 24비트 중 실질적으로 의미 있는 것은 **상위 16비트** 정도다.
>
> 유효 비트로 환산하면 SNR 64.3 dB → **약 10.4 비트**(ENOB). 나머지는 헤드룸과 잡음이다.

### 3.2 15 dB SPL 아래는 믹스에서 0 이 된다

`>>5` 때문에 마이크 코드가 **32 미만이면 믹스 코드가 0** 이다. 코드 32 는 **11.6 dB SPL** 이다.

AGC 는 입력이 0 이면 강제로 1 로 올린다.

```c
// agc.c:172
if (agc_input < 1) { agc_input = 1; }
```

**어차피 마이크 잡음 바닥(29.7 dB SPL)보다 한참 아래라 실질적 문제는 없다.** 무음 입력에서 로그가 −∞ 로 발산하는 것을 막는 안전장치다.

### 3.3 6 dB = 2배, 20 dB = 10배

| 음압 차 | 코드 비 |
|---|---|
| +6 dB | ×2 |
| +10 dB | ×3.16 |
| +20 dB | ×10 |
| +40 dB | ×100 |
| +60 dB | ×1000 |

**암산법**: 코드가 10배면 20 dB, 2배면 6 dB.

### 3.4 정현파 기준이라는 점

> [!CAUTION]
> **이 표는 정현파(단일 톤) 기준이다.**
>
> 실제 소리는 순간 최대값이 평균보다 높다(**파고율**). 말소리는 보통 **10~15 dB**.
>
> AGC 는 **피크**를 보므로, «평균 60 dB SPL 대화» 를 AGC 는 표의 **70~75 dB SPL 자리로 읽는다.** 아래 §4 참조.

## 4. 실제 소리 → AGC 가 읽는 자리

파고율 12 dB 가정.

| 실제 소리 (평균 SPL) | AGC 가 보는 피크 | 마이크 코드 | AGC 구간 |
|---|---|---|---|
| 무음 (마이크 잡음만) | ~30 | 265 | **잡음 구간 경계** |
| 아주 조용한 방 25 | ~37 | 590 | 증폭 |
| 조용한 방 40 | ~52 | 3,300 | 증폭 |
| 조용한 사무실 50 | ~62 | 10,500 | 증폭 |
| **보통 대화 60** | **~72** | **33,300** | **증폭 (회전점 바로 아래)** |
| 가까운 대화 70 | ~82 | 105,000 | **감쇠** |
| 큰 목소리 80 | ~92 | 333,000 | 감쇠 |
| 시끄러운 도로 90 | ~102 | 1,053,000 | 감쇠 |
| 지하철 100 | ~112 | 3,330,000 | 감쇠 |
| 110 이상 | ~122 | **포화** | 감쇠 · **클리핑** |

> [!IMPORTANT]
> **회전점 75 dB SPL 은 «보통 대화의 피크» 바로 위**에 놓여 있다. 일상 대화까지는 원음 비율을 지키고, 그보다 커지면 누르기 시작하는 설계다.
>
> 다만 **파고율 12 dB 는 가정값**이다. 실제 값은 `Addr_SharedMem->maxAudioInput` 을 찍으면 바로 확정된다 → [07](07_미확정%20사항과%20측정%20절차.md).

## 5. 역방향 - 코드에서 음압 읽기

디버깅으로 `maxAudioInput`(믹스 도메인) 을 찍었을 때:

```
dB SPL = 120 + 20 × log10(믹스코드 × 32 / 8,388,607)
       = 20 × log10(믹스코드) + 11.63
```

| 믹스 코드 | dB SPL |
|---:|---:|
| 1 | 11.6 |
| 7 | **29.5** (게이트) |
| 10 | 31.6 |
| 32 | 41.7 |
| 100 | 51.6 |
| 262 | 60.0 |
| 1,000 | 71.6 |
| **1,474** | **75.0** (회전점) |
| 10,000 | 91.6 |
| 13,138 | 94.0 |
| 100,000 | 111.6 |
| **262,143** | **120.0** (풀스케일) |

**암산법**: 믹스 코드의 자릿수마다 20 dB. 코드 1 = 11.6, 10 = 31.6, 100 = 51.6, 1000 = 71.6, 10000 = 91.6, 100000 = 111.6.
