# 06. 게인 상호작용과 역전 현상

**TL;DR**: **정적으로는 게인이 역전되지 않는다** — 두 게인 모두 미분값이 항상 양수다. 하지만 **효과가 0 으로 소멸**하는 구간이 있고(볼륨은 120 dB SPL 에서 정확히 0), **동적으로는 «게인을 올렸는데 더 작게 들리는» 상황이 실제로 가능하다**(§4.2). 그리고 **게인이 아예 안 걸리는 조건이 셋**이나 된다(§5).

## 1. 게인이 두 개다

| | **믹서 게인** | **AGC 볼륨** |
|---|---|---|
| 변수 | `gain_table_index_a` (0~255) | `m_audio_volume` (0~9) |
| 위치 | **AGC 앞** (`audioMixer.c:341`) | **AGC 안** (`agc.c`) |
| 범위 | −17.86 ~ +17.86 dB (+뮤트) | 0 ~ +29.7 dB |
| 간격 | 0.1406 dB | 3.3 dB |
| 성격 | **입력을 키운다** → AGC 가 반응한다 | **AGC 곡선 자체를 바꾼다** |
| 적용 조건 | **I2S 스트리밍 중에만** | 항상 |

> [!IMPORTANT]
> **성격이 근본적으로 다르다.**
>
> **믹서 게인은 AGC 앞에 있다.** 키우면 AGC 가 «소리가 커졌다» 고 보고 **되받아 줄인다.**
>
> **볼륨은 AGC 안에 있다.** AGC 가 반응할 대상이 아니라 AGC 자신의 설정이다.
>
> 그래서 **믹서 게인은 압축 구간에서 대부분 상쇄되고, 볼륨은 상쇄되지 않는다.** 대신 볼륨은 큰 입력에서 효과가 사라진다.

## 2. 볼륨 0 → 9 로 올리면

| 입력 dB SPL | 출력 증가 | 왜 |
|---:|---:|---|
| 30 | **+29.70 dB** | 잡음 구간 — 전량 반영 |
| 50 | **+29.70 dB** | 증폭 구간 — 전량 반영 |
| 60 | **+29.70 dB** | 증폭 구간 |
| **75** | **+29.70 dB** | 회전점 — 여기까지 전량 |
| 85 | +23.10 dB | 감쇠 구간 진입 |
| 95 | +16.50 dB | |
| 105 | +9.90 dB | |
| 115 | +3.30 dB | |
| **120** | **0.00 dB** | **효과 완전 소멸** |

> [!CAUTION]
> **볼륨 효과가 회전점 위에서 선형으로 줄어 120 dB SPL 에서 정확히 0 이 된다.**
>
> 10개 볼륨 곡선이 최대 입력에서 **한 점(내부값 −78.267)** 으로 모이도록 `ybias` 와 `slope` 가 짝지어져 있다([04](04_AGC%20동작%20상세.md) §4). 설계 의도다 — **출력 상한을 볼륨과 무관하게 고정**한다.
>
> **사용자 체감**: 조용한 곳에서는 볼륨이 잘 듣지만, **시끄러운 곳에서는 볼륨을 올려도 소리가 안 커진다.** 이것은 고장이 아니라 설계다.

**역전하는가**: 하지 않는다. 증가량이 0 까지 줄지만 **음수가 되지 않는다.** 볼륨을 올려서 소리가 작아지는 일은 정적으로는 없다.

## 3. 믹서 게인 +10 dB 를 걸면

| 입력 dB SPL | 볼륨 0 | 볼륨 3 | 볼륨 6 | **볼륨 9** |
|---:|---:|---:|---:|---:|
| 40 | **+10.00** | +10.00 | +10.00 | +10.00 |
| 60 | **+10.00** | +10.00 | +10.00 | +10.00 |
| 70 | +8.66 | +7.56 | +6.46 | +5.36 |
| **75** | +7.33 | +5.12 | +2.93 | **+0.72** |
| 90 | +7.32 | +5.12 | +2.92 | **+0.72** |
| 120 | +7.32 | +5.12 | +2.92 | **+0.72** |

> [!IMPORTANT]
> **감쇠 구간에서 믹서 게인은 `압축비` 만큼 나눠서 들어간다.**
>
> 출력 증가 = 믹서 게인 × `atten_slope[v]`
>
> **볼륨 9(압축 13.8:1)에서는 +10 dB 를 걸어도 +0.72 dB 밖에 안 나온다.** 93 % 가 AGC 에게 먹힌다.
>
> **믹서 게인 최대(+17.86 dB)를 다 걸어도 볼륨 9 · 큰 소리에서는 +1.29 dB 다.**

### 3.1 게인을 걸면 압축이 일찍 시작된다

믹서 게인은 AGC **앞**이므로, 게인만큼 **회전점이 앞당겨진다.**

| 믹서 게인 | 압축이 시작되는 실제 음압 |
|---|---|
| 0 dB | **75.0 dB SPL** |
| +3 dB | 72.0 |
| +6 dB | 69.0 |
| +10 dB | 65.0 |
| **+17.86 dB (최대)** | **57.1 dB SPL** |

> [!CAUTION]
> **믹서 게인을 최대로 걸면 보통 대화(60 dB SPL)부터 압축에 들어간다.**
>
> 원래는 대화가 «증폭 구간(원음 비율 보존)» 에 있었는데, 게인을 걸면 «감쇠 구간(압축)» 으로 밀려난다. **음질 성격이 바뀐다** — 다이내믹이 줄고 평평해진다.

**역전하는가**: 하지 않는다. 출력 증가가 +0.72 까지 줄지만 **양수다.**

## 4. 「게인이 역으로 줄어드는 현상」 - 결론

### 4.1 정적으로는 일어나지 않는다

감쇠 구간의 출력은

```
출력 = atten_slope[v] × 입력 + atten_ybias[v]
```

**입력에 대한 미분값이 `atten_slope[v]` 이고, 이 값은 0.0724 ~ 0.7324 로 전 볼륨에서 양수**다.

| 조건 | 미분값 | 판정 |
|---|---|---|
| 잡음 구간 | **2.0** | 양수 |
| 증폭 구간 | **1.0** | 양수 |
| 감쇠 구간 (v=0) | 0.7324 | 양수 |
| 감쇠 구간 (v=9) | **0.0724** | 양수 (최소) |

> [!IMPORTANT]
> **입력을 키워서 출력이 줄어드는 일은 수식상 불가능하다.** 기울기가 음수인 구간이 없다.
>
> 볼륨에 대해서도 마찬가지 — 볼륨을 올릴 때 출력은 **단조 증가하거나 같다.** 감소하지 않는다.

### 4.2 그러나 동적으로는 일어난다 - **네 가지 경로**

> [!CAUTION]
> **아래 넷은 «게인을 올렸는데 더 작게 들린다» 를 실제로 만들 수 있다.** 정적 곡선만 보면 안 보인다.

#### 경로_1 - attack/release 비대칭 (**가장 현실적**)

| | 계수 | 시간 |
|---|---|---|
| 게인 **감소** (attack) | 0.95 | **1.1 ms** |
| 게인 **증가** (release) | 0.01 | **100 ms** (정착 500 ms) |

**게인을 올리면 순간 피크가 압축 구간에 더 자주 닿는다.** 닿을 때마다 게인이 **1 ms 만에** 떨어지고 **500 ms 걸려** 돌아온다.

**피크가 0.5초에 한 번꼴로만 발생해도 게인은 계속 눌린 상태로 머문다.** 결과적으로 **평균 게인이 게인을 올리기 전보다 낮아질 수 있다.**

체감: **«볼륨/게인을 올렸더니 오히려 답답하고 작게 들린다.»** 압축기에서 흔한 현상이다.

#### 경로_2 - 파고율 (peak vs RMS)

AGC 는 **피크**를 본다. 사람이 느끼는 크기는 **RMS** 에 가깝다.

말소리 파고율은 10~15 dB 다. 게인을 올려 **피크**가 압축 구간에 들어가면 AGC 가 누르는데, 정작 **RMS(체감 크기)는 별로 안 커진 상태**다.

**게인을 올린 만큼 체감이 안 따라온다.** 압축비가 높을수록(볼륨 9) 심하다.

#### 경로_3 - 마이크 AOP 초과 (120 dB SPL 이상)

**음향 입력 자체가 120 dB SPL 을 넘으면 마이크가 찌그러진다.** 파형 꼭대기가 잘려 **기본파 성분은 더 안 커지고 고조파만 늘어난다.**

AGC 는 잘린 피크를 «최대» 로 읽고 게인을 최소로 내린다. → **소리를 더 키웠는데 출력은 그대로이고 지저분해지기만 한다.**

**이것은 펌웨어가 아니라 마이크의 물리적 한계다.** 믹서 게인으로는 발생하지 않는다(믹서 게인은 마이크 뒤에 있다).

#### 경로_4 - 믹서 게인 인덱스 0 = **뮤트**

```c
#define TDC_GAIN_TABLE_INDEX_MUTE  0
m_tdc_gain_table_q8_16[0] = 0;   // 게인 0 = 무음
```

> [!CAUTION]
> **인덱스 0 은 «최소 게인» 이 아니라 «무음» 이다.** 최소 게인은 인덱스 **1**(−17.86 dB)이다.
>
> 인덱스를 0 으로 내리면 **−17.86 dB 가 아니라 완전 무음**이 된다. 「한 칸 더 내렸을 뿐인데 소리가 사라졌다」 가 여기서 나온다.
>
> 반대로 **범위 밖 인덱스(음수·256 이상)는 유니티(0 dB)로 처리**된다. 즉 **인덱스 −1 을 넣으면 0 dB, 인덱스 0 을 넣으면 무음**이라는 비직관적 배치다.

## 5. 게인이 아예 안 걸리는 조건 셋

> [!CAUTION]
> **「게인을 바꿨는데 아무 일도 안 일어난다」 는 신고가 들어오면 여기부터 본다.**

| # | 조건 | 결과 | 근거 |
|---|---|---|---|
| **1** | **I2S 스트리밍이 아님** | **믹서 게인 완전 무시** | `main.c:434` 분기. 비스트리밍은 `tdc_audio_mix_1_buffer` / 빔포밍을 타는데 **둘 다 게인 인자가 없다** |
| **2** | **매핑 프로그램 연결 중** | **A·B 둘 다 유니티 강제** | `main.c:450` `if (Addr_SharedMem->isMappingProgramConneted != 1)` |
| **3** | I2S 소스가 **스마트폰 스트리밍** | **B(I2S)만 유니티** | `main.c:454` — 폰이 볼륨을 제어하므로 |

> [!IMPORTANT]
> **1번이 가장 중요하다.** 평상시 청취(마이크만, I2S 없음)에서는 **`gain_table_index_a` 가 아무 효과도 없다.** 게인 테이블은 **I2S 와 마이크를 섞을 때의 밸런스 조절 수단**이지 일반 마이크 게인이 아니다.
>
> 일반 청취의 게인 조절은 **AGC 볼륨(`m_audio_volume`)** 이 담당한다.

2번은 의도된 설계다 — 청각사가 자극 레벨을 측정하는 동안 게인이 끼면 측정이 틀어진다. **공유메모리의 인덱스는 그대로 두고 사용 시점에만 무시**하므로 매핑이 끝나면 자동 복귀한다.

## 6. 두 게인을 함께 쓸 때 - 권장

| 목적 | 무엇을 쓰나 |
|---|---|
| **일반 청취 크기** | **AGC 볼륨** (`m_audio_volume`) |
| I2S ↔ 마이크 밸런스 | 믹서 게인 A/B |
| 크래들 마이크 레벨 보정 | 믹서 게인 B |

> [!CAUTION]
> **믹서 게인을 크게 걸어 «볼륨» 대용으로 쓰지 않는다.** 이유 셋.
>
> 1. **I2S 스트리밍 중에만 걸린다** (§5)
> 2. **압축이 일찍 시작되어 음질 성격이 바뀐다** (§3.1)
> 3. **압축 구간에서 대부분 상쇄된다** (§3) — 볼륨 9 에서 93 % 가 먹힌다
>
> 크기는 볼륨으로, 밸런스는 믹서 게인으로 나누는 것이 맞다.

## 7. 요약 표

| 질문 | 답 |
|---|---|
| 볼륨을 올리면 출력이 커지나 | **커진다.** 단 75 dB SPL 위에서 효과가 줄어 **120 에서 0** |
| 믹서 게인을 올리면 커지나 | **커진다.** 단 압축 구간에서 `slope` 배만 — **볼륨 9 면 7 %** |
| **게인이 역으로 줄어드나 (정적)** | **아니다.** 모든 구간에서 기울기가 양수 |
| **게인이 역으로 줄어드나 (동적)** | **가능하다.** attack/release 비대칭·파고율·AOP 초과 (§4.2) |
| 게인이 안 걸리는 경우가 있나 | **있다. 셋** (§5) — 특히 **비스트리밍이면 믹서 게인 무효** |
| 인덱스 0 은 최소 게인인가 | **아니다. 뮤트다** (§4.2 경로_4) |
