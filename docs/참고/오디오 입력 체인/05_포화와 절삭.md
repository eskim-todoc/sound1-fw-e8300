# 05. 포화와 절삭

**TL;DR**: 포화 후보가 **6곳**인데 실제로 걸리는 것은 **①마이크 AOP** 와 **④AGC 출력** 둘뿐이다. **믹서는 어떤 조건에서도 포화하지 않는다**(최대 조합에서도 `INT24_MAX` 의 절반, 여유 6.2 dB). 반면 **`>>5` 절삭은 작은 소리에서 실질적 손실**이라 노이즈 게이트 근처에서 1 LSB 가 **1.16 dB** 나 된다.

## 1. 포화·절삭 지점 전수

| # | 지점 | 한계 | 실제로 걸리나 | 조건 |
|---|---|---|---|---|
| **①** | **마이크 AOP** | 120 dB SPL (10% THD) | **걸린다** | 아주 큰 소리 |
| ② | 데시메이션 → 24비트 | `0x7FFFFF` | ①과 동시 | ①과 같은 음압 |
| ③ | **믹서 INT24 포화** | `INT24_MAX` | **안 걸린다** | §4 참조 |
| **④** | **AGC 출력 INT24 포화** | `INT24_MAX` | **이론상 가능, 실제로는 안 걸린다** | §5 |
| ⑤ | AGC 게인 dB 클램프 | ±128 (내부) | **안 걸린다** | §6 |
| ⑥ | AGC 선형 게인 클램프 | ±2047.99 | **안 걸린다** | §6 |
| ⑦ | `agc_input < 1` 강제 | 1 | **걸린다 (무해)** | 11.6 dB SPL 미만 |
| **⑧** | **`>>5` 절삭** | 하위 5비트 소실 | **항상 걸린다** | §3 — **실질 손실** |

## 2. 최소·최대 입력에서 무슨 일이 나는가

### 2.1 최대 - 아주 큰 소리

| 음압 | 마이크 | 24비트 | 믹서 | AGC |
|---|---|---|---|---|
| 108 dB SPL | THD **1 %** | 2,107,123 | 정상 | 감쇠 |
| 115 dB SPL | THD **2 %** | 4,717,260 | 정상 | 감쇠 |
| **120 dB SPL** | **THD 10 % (AOP)** | **8,388,607 = `0x7FFFFF`** | 정상 | 감쇠 −12.04 dB |
| 125 dB SPL | **심한 왜곡** | **포화 (`0x7FFFFF` 고정)** | 정상 | 게인 최소 |
| 130 dB SPL 이상 | **마이크 파손 위험** | 포화 | 정상 | 게인 최소 |

> [!IMPORTANT]
> **마이크와 24비트가 같은 음압에서 동시에 한계에 닿는다.** 감도 −26 dBFS 가 AOP 120 dB SPL 과 정확히 맞물려 있어 **어느 한쪽이 먼저 망가지지 않는다.** 설계가 잘 맞춰져 있다.
>
> **120 dB SPL 초과에서 일어나는 일**: 파형 꼭대기가 잘려 **고조파가 생긴다.** AGC 는 피크를 보므로 «최대» 로 읽고 게인을 최소로 내린다. **소리는 커지지 않고 지저분해지기만 한다.**

### 2.2 최소 - 아주 작은 소리

| 음압 | 마이크 코드 | 믹스 (`>>5`) | 상태 |
|---|---|---|---|
| 40 dB SPL | 839 | 26 | 정상 |
| 30 dB SPL | 265 | 8 | **게이트 바로 위** |
| **29.5 dB SPL** | **250** | **7** | **노이즈 게이트** |
| 29.7 dB SPL | 256 | 8 | 마이크 잡음 바닥 |
| 20 dB SPL | 84 | 2 | 잡음에 묻힘 · 잡음 구간 |
| 15 dB SPL | 47 | **1** | 믹스 코드 하한 |
| **11.6 dB SPL 미만** | < 32 | **0** | **⑦ 강제 1** |

> [!NOTE]
> **마이크 자체 잡음이 29.7 dB SPL 이므로 그 아래는 «신호» 가 아니다.** 믹스 코드가 0 이 되는 11.6 dB SPL 은 이미 잡음에 20 dB 나 묻혀 있어 **실질적 문제가 없다.**
>
> ⑦(`agc_input < 1 → 1`)은 완전 무음에서 `log(0)` 이 발산하는 것을 막는 안전장치다. 이때 내부값 −132.25 → 게이트보다 한참 아래 → **잡음 구간 최대 감쇠.** 올바른 동작이다.

## 3. `>>5` 절삭 - 가장 실질적인 손실

```c
p_mix[i] = (p_buf1[i] >> AUDIO_INPUT_RSHIFT);   // 하위 5비트를 버린다
```

**되돌릴 수 없다.** AGC 가 `<<5` 로 배율은 복원하지만 **버려진 비트는 0 으로 채워진다.**

| 음압 | 마이크 코드 | 믹스 | AGC 가 복원한 값 | **오차** | **1 LSB 의 dB 값** |
|---|---|---|---|---|---|
| **29.5 dB SPL** | 250 | **7** | 224 | **−0.97 dB** | **1.16 dB** |
| 40 dB SPL | 839 | 26 | 832 | −0.07 dB | 0.33 dB |
| 60 dB SPL | 8,389 | 262 | 8,384 | −0.005 dB | 0.033 dB |
| 75 dB SPL | 47,173 | 1,474 | 47,168 | −0.001 dB | 0.006 dB |
| 94 dB SPL | 420,426 | 13,138 | 420,416 | ~0 | 0.001 dB |
| 120 dB SPL | 8,388,607 | 262,143 | 8,388,576 | ~0 | ~0 |

> [!CAUTION]
> **노이즈 게이트 근처에서 분해능이 나쁘다.**
>
> 게이트가 걸리는 마이크 코드 250 은 믹스에서 **7** 이다. 6 과 7 과 8 사이가 각각 **1.3 dB · 1.16 dB** 씩 벌어져 있다. 즉 **AGC 의 게이트 판정이 약 1.2 dB 단위로 뚝뚝 끊긴다.**
>
> 실제 영향: 아주 조용한 환경에서 **게이트가 열렸다 닫혔다 하는 «떨림»** 이 생길 수 있다. 게이트 근처 입력이 코드 6↔7 을 오가면 판정이 뒤집힌다.
>
> **60 dB SPL(보통 대화) 이상에서는 0.03 dB 이하라 무시해도 된다.** 문제는 오직 게이트 근처다.

### 3.1 왜 이렇게 설계됐나

`>>5` 는 **여러 입력을 더할 때 24비트를 넘지 않게** 하려는 헤드룸 확보다. 그런데 §4 에서 보듯 **실제로는 그만큼의 헤드룸이 필요 없다.**

| 필요한 헤드룸 | 확보한 헤드룸 |
|---|---|
| 2입력 합산 = **6 dB** + 게인 최대 **17.86 dB** = **약 24 dB** | **30.1 dB** (`>>5`) |

**약 6 dB 를 과하게 잡았다.** `>>4`(÷16, −24.1 dB)로 줄이면 헤드룸은 여전히 충분하고 **작은 소리 분해능이 2배(6 dB) 좋아진다.**

> [!CAUTION]
> **다만 지금 바꾸면 안 된다.** `>>5` 와 AGC 의 `<<5` 가 짝이므로 **둘을 함께** 고쳐야 하고, 그러면 AGC 게이트의 실효 음압이 통째로 6 dB 이동한다. **게이트 상수도 같이 다시 잡아야 한다.** 실기 검증이 붙는 변경이다.

## 4. 믹서는 포화하지 않는다 - 계산

```c
gained_value  = gain_a × (mic  >> 5);
gained_value += gain_b × (i2s  >> 5);
gained_value  = gained_value >> 16;
if (gained_value > INT24_MAX) gained_value = INT24_MAX;   // 이 분기에 도달하는가?
```

**최악 조건**: 두 입력 모두 24비트 풀스케일, 두 게인 모두 최대(+17.86 dB).

| 단계 | 값 |
|---|---|
| 마이크 풀스케일 | 8,388,607 |
| `>> 5` | **262,143** |
| × 최대게인(512,211) `>> 16` | **2,048,836** |
| 2입력 합산 | **4,097,672** |
| `INT24_MAX` | **8,388,607** |
| **여유** | **6.22 dB** |

> [!IMPORTANT]
> **믹서의 INT24 포화 분기는 현재 게인 테이블로는 절대 도달하지 않는다.**
>
> 이유: `>>5` 가 **30.1 dB** 를 깎았는데 게인은 최대 **17.86 dB** 밖에 안 올린다. 2입력 합산의 6 dB 를 더해도 30.1 − 17.86 − 6.02 = **6.22 dB** 가 남는다.
>
> **포화 분기는 «죽은 코드는 아니지만 도달 불가» 다.** 게인 테이블 상한을 +24 dB 이상으로 늘리면 그때부터 살아난다. 방어로 남겨 두는 것이 맞다.

## 5. AGC 출력 포화

```c
gained_value = agc_gain_linear × p_mix[i];   // Q12.12 × Q24.0
gained_value = gained_value >> 12;
// INT24 포화
```

**최대 조건**: 회전점 바로 아래(75 dB SPL) 입력에 볼륨 9 게인(+29.7 dB).

| 항목 | 값 |
|---|---|
| 믹스 입력 (75 dB SPL) | 1,474 |
| × 30.55 (=+29.7 dB) | **45,040** |
| `INT24_MAX` | 8,388,607 |
| 여유 | **45.4 dB** |

**최대 입력(120 dB SPL)에서는** 게인이 −12.04 dB 로 떨어져 출력이 **65,535** 다. 역시 한참 아래.

> [!NOTE]
> **AGC 출력은 최대 약 65,535 (믹스 도메인)** 이고 이는 24비트 풀스케일 대비 **−42.1 dBFS** 다. **포화하지 않는다.**
>
> 다만 **입력 샘플 하나하나에 곱하므로 피크가 아닌 개별 샘플이 순간적으로 클 수 있다.** 절대 최대값 기준으로 게인을 정하므로 원리상 초과하지 않지만, **attack 이 늦는 1 ms 동안은 이전 게인이 적용된다.** 급격한 상승 구간에서 이론상 포화 가능하나, 여유가 45 dB 라 현실적으로 발생하지 않는다.

## 6. 도달하지 않는 클램프 둘

| 클램프 | 위치 | 한계 | 실제 최대 | 판정 |
|---|---|---|---|---|
| dB 도메인 | `agc.c:266`·`142` | ±128 (내부) = **±256 실제 dB** | ±30 dB | **도달 불가** |
| 선형 게인 | `agc.c:293` | `INT24_MAX` Q12.12 = **×2047.99 = +66.2 dB** | ×30.55 = +29.7 dB | **도달 불가** |

**둘 다 방어용이다.** dB 클램프의 ±128 은 `m8p16_t` 타입의 표현 한계(`[−128, +128)`)와 정확히 같아, **타입이 넘치는 것을 막는 올바른 값**이다.

## 7. 정리 - 실제로 신경 쓸 것

| 순위 | 항목 | 왜 |
|---|---|---|
| **1** | **`>>5` 절삭** (§3) | 게이트 근처에서 1 LSB = 1.16 dB. **게이트 떨림 가능** |
| **2** | **마이크 AOP 120 dB SPL** (§2.1) | 그 위는 왜곡. 마이크·ADC 가 동시에 한계 |
| 3 | 믹서 포화 (§4) | **현재 도달 불가.** 게인 상한을 늘릴 때만 검토 |
| 4 | 나머지 클램프 | 방어용. 손댈 것 없다 |
