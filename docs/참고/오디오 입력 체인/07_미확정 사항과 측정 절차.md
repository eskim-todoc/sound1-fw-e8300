# 07. 미확정 사항과 측정 절차

**TL;DR**: 이 문서 묶음은 **코드와 데이터시트만으로** 쓴 것이다. **실측으로 확인하지 않은 것이 5건**이고 그중 **1건(데시메이션 게인 −5.17 dB)은 전체 눈금을 흔든다.** 다행히 **`Addr_SharedMem->maxAudioInput` 한 값만 찍으면 대부분 한꺼번에 확정**된다.

> [!CAUTION]
> **이 문서를 먼저 읽고 나머지를 읽는다.** 아래 미확정_1 이 참이면 [03 환산표](03_dBSPL-코드%20환산표.md)의 모든 dB SPL 값이 **5.17 dB 씩 밀린다.**

## 1. 미확정_1 - 데시메이션 게인 (**중요**)

### 무엇이 문제인가

E8300 하드웨어 레퍼런스 **p.445** 는 데시메이션 필터가 **유니티 게인**이 되는 값을 식으로 준다.

```
ADC_DEC_CTRL_ADC_GF = 2^(11 + log2(SFCR)) / (SFCR + 1)
```

현재 설정은 16 kHz, `SFCR = 29`(`ADC_MODDIV_BY30 = 0x1D`)다. 대입하면 **1979.7**.

그런데 펌웨어는 **1092** 를 쓴다.

```c
// lib_cfx/lib_audio_in.h:112
#define LIB_SYS_CALC_GF 1092  // 1092//1979
```

```
1092 / 1979.7 = 0.5516  →  −5.17 dB
```

**주석 `// 1092//1979` 가 두 값을 다 써 봤다는 흔적**이고, `systemControl/main.h:119` 에는 아직 `#define SYS_CALC_GF 1979` 가 남아 있다(현재 미사용 경로).

### 두 가지 가능성

| | 가설 | 함의 |
|---|---|---|
| **가설_A** | **1092 가 DMIC 경로의 실효 유니티다** | 데이터시트 식은 **아날로그 ADC 경로** 기준이고, 1비트 PDM 입력은 데시메이터에서의 스케일이 달라 다른 값이 필요하다. → **이 문서 묶음의 표가 그대로 맞다** |
| **가설_B** | **실제로 −5.17 dB 감쇠돼 있다** | 의도적 감쇠 또는 튜닝 잔재. → **모든 게이트의 실효 음압이 5.17 dB 높다** |

### 어느 쪽이 맞을 것 같은가

**정황은 가설_A 쪽이다.**

| 근거 | 내용 |
|---|---|
| **AGC 게이트가 마이크 잡음 바닥과 일치** | 노이즈 게이트 **29.50 dB SPL** vs Sullivan 마이크 잡음 바닥 **29.5 dB SPL**. **소수점까지 맞는다.** −5.17 dB 가 실재하면 이 일치가 깨진다 |
| 회전점이 딱 떨어진다 | **75.00 dB SPL** — 사람이 고른 값처럼 보인다 |
| `df_maxAudioForLogarithm` | 21,892 → 환산 **98.4 dB SPL**, 주석 «약 100dB SPL» 과 부합 |

**세 값이 모두 «0 dBFS = 120 dB SPL» 전제와 맞는다.** 만약 −5.17 dB 가 있다면 셋 다 5.17 씩 틀어져야 한다.

> [!IMPORTANT]
> **그래도 정황일 뿐이다.** 게이트 값이 데이터시트에서 계산된 것인지 실측에서 나온 것인지 모르기 때문에 순환 논증이 될 수 있다. **§5 측정으로 끝낸다.**

### 가설_B 라면 바뀌는 것

| | 문서상 | 가설_B 에서 실제 |
|---|---|---|
| 0 dBFS | 120 dB SPL | **125.2 dB SPL** |
| 노이즈 게이트 | 29.5 | **34.7 dB SPL** |
| 회전점 | 75.0 | **80.2 dB SPL** |
| 마이크 잡음 바닥 대비 게이트 | 겹침 | **게이트가 5 dB 위** → 작은 소리를 필요 이상으로 막는다 |

## 2. 미확정_2 - 말소리 파고율

[03](03_dBSPL-코드%20환산표.md) §4 의 «실제 소리 → AGC 가 읽는 자리» 표는 **파고율 12 dB 를 가정**했다.

**AGC 는 피크를 보므로 이 값이 틀리면 «어느 소리가 어느 구간에 떨어지는가» 가 통째로 이동한다.** §5 측정으로 확정된다.

## 3. 미확정_3 - 마이크 패키지 호환성

[01](01_마이크%20스펙%20상세.md) §5. **전기·음향 스펙만 대조했고 기계 도면(패키지 아웃라인·패드 배열)은 보지 않았다.** 「그대로 바꿔 끼울 수 있다」 를 말하려면 두 데이터시트의 패키지 페이지를 비교해야 한다.

## 4. 미확정_4·5 - 작은 것 둘

| # | 항목 | 내용 |
|---|---|---|
| 4 | **개체차 ±1 dB** | 감도 스펙이 −27 ~ −25 dBFS. 코드로는 ±12 %. 절대 음압 측정이 필요하면 개체 교정이 필요하다 |
| 5 | **게이트 근처 떨림** | [05](05_포화와%20절삭.md) §3 — 게이트 부근에서 1 LSB 가 1.16 dB 라 판정이 뒤집힐 수 있다. **실제로 떨리는지는 로그로 봐야 안다** |

## 5. 측정 절차 - 10분이면 끝난다

### 5.1 준비

| 필요한 것 | 대안 |
|---|---|
| 음압계 (또는 교정된 스피커) | 스마트폰 SPL 앱 (±3 dB 정도, 상대 비교용으로는 충분) |
| 1 kHz 정현파 음원 | 아무 톤 제너레이터 |
| J-Link RTT 또는 디버거 | |

### 5.2 볼 값 하나

```c
// agc.c:105 — AGC 가 매 블록(1 ms) 기록한다
Addr_SharedMem->maxAudioInput = input_audio_mix_max_value;
```

**이 값은 «믹스 도메인(`>>5` 이후)의 16샘플 절대 최대값» 이다.**

### 5.3 절차

| # | 할 일 |
|---|---|
| 1 | 조용한 곳에서 **무음** 상태의 `maxAudioInput` 을 읽는다 → **잡음 바닥 확인** |
| 2 | 마이크 앞에서 **1 kHz 정현파를 94 dB SPL** 로 낸다 (또는 음압계로 측정된 임의 레벨) |
| 3 | 그때의 `maxAudioInput` 을 읽는다 |
| 4 | 아래 §5.4 로 판정 |
| 5 | (선택) **말소리**를 정상 크기로 내고 `maxAudioInput` 을 읽어 파고율 확인 |

### 5.4 판정

**94 dB SPL 정현파를 넣었을 때 예상되는 `maxAudioInput`:**

| 가설 | 예상 믹스 코드 | 예상 마이크 코드 |
|---|---|---|
| **가설_A** (문서대로, 0 dBFS = 120 dB SPL) | **약 13,138** | 420,426 |
| **가설_B** (−5.17 dB 실재) | **약 7,247** | 231,900 |

**두 값이 1.8배 차이라 헷갈릴 수 없다.**

일반화한 판정식:

```
실측 0 dBFS 음압 = 측정 SPL + 20 × log10(262143 / 읽은값)
```

- 결과가 **120 근처** → **가설_A. 이 문서 묶음 그대로 유효**
- 결과가 **125 근처** → **가설_B. 모든 SPL 값에 +5.17 dB**

### 5.5 무음 상태로도 대략 판정된다

음원 없이 **조용한 방에서 `maxAudioInput` 만 읽어도** 어느 정도 갈린다.

| 읽은 값 | 해석 |
|---|---|
| **7 ~ 10** | 마이크 잡음 바닥(29.7 dB SPL)이 게이트 근처 → **가설_A** |
| **4 ~ 5** | 잡음이 게이트보다 5 dB 아래 → **가설_B** |

> [!NOTE]
> 방이 완전히 조용하지 않으면(보통 30~40 dB SPL) 환경 소음이 마이크 잡음보다 커서 판정이 흐려진다. **가능하면 §5.3 의 음원 방식을 쓴다.**

### 5.6 파고율 확인 (미확정_2)

정상 크기로 말하면서 `maxAudioInput` 의 **최댓값**을 기록하고, 같은 위치에서 음압계로 **평균 SPL** 을 읽는다.

```
파고율 = [20 × log10(읽은값) + 11.63] − 음압계 평균 SPL
```

(괄호 안은 믹스 코드 → dB SPL 환산식, [03](03_dBSPL-코드%20환산표.md) §5)

## 6. 측정 후 할 일

| 결과 | 조치 |
|---|---|
| **가설_A 확인** | 이 문서 묶음에서 §1 CAUTION 을 지우고 «확정» 으로 바꾼다. `main.h:119` 의 죽은 `SYS_CALC_GF 1979` 도 정리 대상 |
| **가설_B 확인** | **[03](03_dBSPL-코드%20환산표.md) 전체를 +5.17 dB 로 재작성.** 그리고 **AGC 게이트를 다시 잡을지 판단**해야 한다 — 게이트가 마이크 잡음 바닥보다 5 dB 위에 있으면 작은 소리를 필요 이상으로 막고 있다는 뜻이다 |
| 파고율 확정 | [03](03_dBSPL-코드%20환산표.md) §4 표를 실측값으로 갱신 |

## 7. 이 분석이 확인한 것 / 못 한 것

| | 항목 |
|---|---|
| **코드로 확인함** | 시프트 배율(`>>5`/`<<5`) · 게인 테이블 전체 · 경로 분기 · AGC 3구간 수식 · 곡선 연속성 · 포화 여부 계산 · 클램프 도달 여부 · attack/release 계수 |
| **데이터시트로 확인함** | 두 마이크 전 스펙 · 유니티 게인 공식 · IOC 구성 |
| **계산으로 확인함** | 게이트의 dB SPL 역산 · 볼륨별 압축비 · 믹서 포화 여유 · 절삭 오차 |
| **확인 못 함 (실측 필요)** | **§1 데시메이션 게인** · §2 파고율 · §3 패키지 호환 · §4 개체차 · §5 게이트 떨림 |

> [!IMPORTANT]
> **«확인 못 함» 5건 중 4건은 정밀도 문제이고, §1 하나만 «전체가 5 dB 틀릴 수 있다» 는 성격이다.** 우선순위가 명확하다.
