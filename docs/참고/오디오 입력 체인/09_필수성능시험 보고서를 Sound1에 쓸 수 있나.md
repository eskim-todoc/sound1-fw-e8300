# 09. 필수성능시험 보고서를 Sound1 에 쓸 수 있나

**TL;DR**: **ADC 판정표는 그대로 쓸 수 있다** — 보고서의 29개 값이 «감도 −26 dBFS + `>>5` 체인» 계산과 **하나도 틀리지 않고 일치**하고, 두 마이크의 감도가 같으며, 두 프로젝트의 신호 체인 상수가 전부 동일하다. **딱 하나 조심할 것은 ID-2 의 7990 Hz** 다 — Sound1 은 2마이크 빔포밍이라 **스피커가 기기 축에서 50° 이상 벗어나면 떨어진다.**

> [!IMPORTANT]
> **전제 정정**: 마이크 입력값을 보는 시험은 **ID-1 과 ID-2 둘뿐**이다. **ID-3·4·5 는 오실로스코프로 자극 펄스를 보는 시험**이라 마이크와 무관하다(§3).

대상 문서: [`../인허가 관련/EPTR-TD23D 필수성능시험 보고서_최종_251208.pdf`](../인허가%20관련/EPTR-TD23D%20필수성능시험%20보고서_최종_251208.pdf) (42쪽, 2025-12-08)

| 시험 | 무엇을 보나 | 마이크 의존 | **Sound1 적용** |
|---|---|---|---|
| **ID-1** | 입력 크기 범위 (1048 Hz) | **예** | **그대로 가능** |
| **ID-2** | 입력 주파수 범위 (100 / 4037 / **7990** Hz) | **예** | **가능. 단 배치 주의** (§6) |
| ID-3 | 자극 펄스 **주파수** | 아니오 | 그대로 |
| ID-4 | 자극 펄스 **위상폭** | 아니오 | 그대로 |
| ID-5 | 자극 펄스 **선행 위상** | 아니오 | 그대로 |
| ID-6~8 | ADC 13~16 이 되도록 음량을 맞춰 진행 | (자기교정) | 그대로 |

## 2. 보고서의 ADC 표 = 우리 계산과 완전 일치

보고서가 «ADC 값» 이라 부르는 것은 **믹스 도메인 값(`>>5` 이후)** 이고, [03 환산표](03_dBSPL-코드%20환산표.md)의 «믹스 코드» 열과 같다.

전수 대조 결과 **29개 값 전부 일치, 불일치 0**.

| dB SPL | 보고서 | 우리 계산 | | dB SPL | 보고서 | 우리 계산 |
|---:|---:|---:|---|---:|---:|---:|
| 29 | 7 | **7** | | 70 | 828 | **828** |
| 30 | 8 | **8** | | 75 | 1,474 | **1,474** |
| 35 | 14 | **14** | | 115 | 147,414 | **147,414** |
| 40 | 26 | **26** | | 119 | 233,636 | **233,636** |
| 65 | 466 | **466** | | **120** | **262,143** | **262,143** |

> [!IMPORTANT]
> **이 표는 Sullivan 실측이 아니라 이론값이다.** 「감도 −26 dBFS → `0x7FFFFF` = 120 dB SPL → `>>5`」 로 유도된다. 120 dB SPL 이 정확히 **262,143 = 2¹⁸−1**(믹서 최대)인 것이 그 증거다.
>
> **따라서 «Sullivan 에서 재서 얻은 값이라 Sound1 과 다를 수 있다» 는 걱정은 성립하지 않는다.** 마이크 감도와 체인이 같으면 같은 표가 나온다.
>
> **부수 효과**: 이 일치가 [02](02_입력%20경로%20-%20IOC에서%20AGC까지.md) 의 체인 해석과 [07](07_미확정%20사항과%20측정%20절차.md) §1 의 «데시메이션 게인 유니티» 를 **인허가 문서로 뒷받침**한다.

### 2.1 실측값은 표보다 1.5~3.3 dB 낮았다

| 시험 | 측정 음압 | 실측 ADC | 표의 값 | 차이 |
|---|---|---|---|---|
| ID-1 최소 | 35.034 | 14 | 14 | **0.0 dB** |
| ID-1 일상 | 70.003 | 620 | 828 | **−2.5 dB** |
| ID-1 최대 | 120.663 | 237,359 | (119→233,636) | **−1.5 dB** |
| ID-2 100 Hz | 70.070 | 670 | 828 | **−1.8 dB** |
| ID-2 4037 Hz | 70.046 | 642 | 828 | **−2.2 dB** |
| **ID-2 7990 Hz** | 70.095 | **564** | 828 | **−3.3 dB** |

전부 **±5 dB 허용 안에서 통과**했다. 적자의 원인은 스피커·마이크 위치, 기구물, 마이크 개체차(±1 dB) 등 음향 환경이다.

> [!CAUTION]
> **이 적자가 Sound1 에서도 그대로 재현된다고 봐야 한다.** 그러면 **7990 Hz 는 여유가 1.7 dB 밖에 안 남는다.** §6 의 근거다.

## 3. 시험 항목별 마이크 의존성

| ID | 시험 설명 (보고서 원문) | 측정 수단 |
|---|---|---|
| **ID-1** | *"마이크의 사운드 입력 크기 범위를 확인한다"* | 개발자용 앱의 **오디오 입력 최대값** |
| **ID-2** | *"사운드 입력의 주파수 범위를 측정한다"* | 동 |
| ID-3 | *"자극 펄스 파형의 주파수를 확인한다"* | **오실로스코프** (맵 2번) |
| ID-4 | *"자극 펄스 파형의 위상폭을 확인한다"* | **오실로스코프** (맵 2번) |
| ID-5 | *"자극 펄스 파형의 선행 위상 모양을 확인한다"* | **오실로스코프** (맵 1번) |

**ID-3·4·5 는 자극 출력을 보는 시험이다.** 마이크가 무엇이든 결과가 같다. 걱정할 대상은 **ID-1·2 둘뿐**이다.

| `NORMALIZE_SHIFT_BIT_NUM_FOR_10DB_LIBRARY` | **5** | **5** | 같음 |

마이크 스펙도 같다 — 감도 **−26 dBFS**, AOP **120 dB SPL**, SNR 64.3 vs 64.5 dB ([01](01_마이크%20스펙%20상세.md)).

## 5. 유일한 차이 - Sullivan 은 1마이크, Sound1 은 2마이크 빔포밍

**Sullivan** `audioMixer.c:15·27` — 내부 마이크 **또는** 외부 마이크 하나를 `>>5` 해서 그대로 쓴다.

**Sound1** `audioMixer.c:415~` — DMIC 2개일 때 **delay-and-sum 빔포밍**을 탄다.

```c
p_mix[i] = ((rear[i] >> 5) + (front[i+1] >> 5)) >> AUDIO_MIX_NORMALIZE_RSHIFT;
```

적용 지연 = **1.025 샘플 @ 16 kHz = 64.06 µs** (정수 1샘플 + 데시메이션 필터 0.025샘플).

### 5.1 각도·주파수별 응답

```
이득 = |cos(π · f · τ · (1 − cos θ))|      τ = 64.06 µs, θ = 빔 축에서 벗어난 각
```

| 주파수 | **정면(축)** | 30° | 90° | 180° |
|---|---:|---:|---:|---:|
| 100 Hz | **0.00 dB** | −0.00 | −0.00 | −0.01 |
| **1048 Hz** (ID-1) | **0.00 dB** | −0.00 | **−0.19** | **−0.80** |
| **4037 Hz** | **0.00 dB** | −0.05 | −3.25 | **−25.33** |
| **7990 Hz** | **0.00 dB** | −0.20 | **−28.58** | −0.02 |

> [!IMPORTANT]
> **정면을 향하면 전 주파수에서 손실이 0 이다.** 빔포머는 축 방향 음원의 음향 지연을 정확히 상쇄하도록 설계돼 있으므로, 축에 있으면 단일 마이크와 레벨이 같다.
>
> **문제는 축에서 벗어날 때이고, 주파수가 높을수록 급격해진다.**
>
> 널(null) 위치: **90° 는 7.8 kHz**, **180° 는 3.9 kHz**.

### 5.2 빔포밍이 켜지는 조건

`system_control.c:85~` — **내부기가 연결되고**(`0 < m_current_isd`) **`isd_location_RL` 이 Left/Right 로 잡혀야** `tdc_audio_set_front_mic()` 이 호출된다.

| 상태 | 믹서 경로 |
|---|---|
| 내부기 연결 + L/R 확정 | **빔포밍** (2마이크) |
| 그 외 | `tdc_audio_mix_1_buffer(DMIC1)` — **단일 마이크** |

> [!NOTE]
> **단일 마이크로 떨어지면 오히려 Sullivan 과 같은 조건**이 되어 ID-2 가 쉽게 통과한다. **시험 시 어느 경로로 동작하는지 먼저 확인해 두는 것이 좋다** — 통과/실패의 해석이 달라진다.

## 6. ID-2 의 7990 Hz - 여유 계산

Sullivan 실측이 이미 **−3.3 dB** 적자였다(§2.1). 허용이 ±5 dB 이므로 **남은 여유는 1.7 dB**.

| 축에서 벗어난 각 | 7990 Hz 빔포밍 손실 | 판정 |
|---:|---:|---|
| 0 ~ 30° | ≤ 0.20 dB | **여유 충분** |
| 40° | −0.63 dB | 여유 있음 |
| **50°** | **−1.52 dB** | **여유 소진 직전** |
| 60° | −3.18 dB | **초과** |
| 70° | −6.19 dB | **실패** |
| 90° | −28.58 dB | **완전 실패** |

> [!CAUTION]
> **스피커가 기기 빔 축에서 50° 이내에 있어야 한다.** 그 밖이면 7990 Hz 항목이 떨어진다.
>
> 4037 Hz 는 90° 에서 −3.25 dB 로 아슬아슬하고 **180°(기기 뒤쪽)에서 −25 dB 로 완전히 죽는다.** 스피커를 기기 **뒤쪽**에 두면 안 된다.

## 7. 권장 조치

| # | 할 일 |
|---|---|
| **1** | **기기 정면(착용 시 사람이 바라보는 방향)이 스피커를 향하도록** 배치한다. 이것만 지키면 전 항목이 손실 0 이다 |
| **2** | 시험 전에 **빔포밍이 켜졌는지 확인**한다(§5.2). 단일 마이크로 떨어졌다면 그 사실을 기록에 남긴다 |
| **3** | **ID-2 를 Sound1 으로 재측정**해 표와 대조한다. 특히 **7990 Hz 가 표의 −5 dB(≈466) 위**에 있는지 |
| 4 | ID-1 은 1048 Hz 라 빔포밍 손실이 최악 0.8 dB 다. **재측정 우선순위가 낮다** |
| 5 | ID-3·4·5 는 마이크 무관이므로 **보고서를 그대로 인용**할 수 있다 |

> [!NOTE]
> **보고서 자체를 고칠 필요는 없다.** ADC 판정표는 이론값이라 Sound1 에도 그대로 성립한다. 필요한 것은 **Sound1 기기로 다시 측정해 «확인 및 측정» 란을 채우는 것**뿐이다.

## 8. 근거

| 주장 | 확인 |
|---|---|
| ADC 표 29개 일치 | **전수 계산 대조** — `8388607 × 10^((SPL−120)/20) >> 5` |
| ID-3·4·5 가 마이크 무관 | 보고서 5.3.3 · 5.4.3 · 5.5.3 «오실로스코프를 사용하여…» |
| 시험 주파수 100 / 1048 / 4037 / 7990 Hz | 보고서 본문 grep |
| 실측값과 표의 차이 | 보고서 «확인 및 측정» 란 |
| 체인 상수 동일 | 두 프로젝트 `1__cfx` grep 대조 |
| Sullivan 이 1마이크 | `Sullivan1_5__CFX/systemControl/audioMixer.c:15·27` |
| 빔포밍 지연 1.025 샘플 | `audioMixer.c:405~413` 주석 · `LIB_ADC_DEC_CTRL_VAL_0_0250` |
| 각도·주파수 응답 | `|cos(π f τ (1−cos θ))|` 계산 |
| 빔포밍 활성 조건 | `system_control.c:85~100` |

> [!NOTE]
> **빔포밍 응답은 이상적 delay-and-sum 모델 계산이다.** 실제로는 기구물 회절·마이크 간 감도 편차(±1 dB)·포트 음향 임피던스가 얹힌다. **50° 라는 경계선은 여유를 두고 해석한다** — 30° 이내로 잡으면 안전하다.
