# BLE 재구조화

**TL;DR**: `2__cm3` `ble/` 재구조화의 **설계 기준 문서** 모음. 2026-07-27 구조 분석의 결론을 실행 가능한 로드맵으로 정리했다. **아직 실행되지 않은 설계안**이며, 후속 리팩토링 작업은 이 문서를 근거로 진행한다.

## 요약

| 단계 | 내용 | 위험 | 바이트 동일 검증 |
|---|---|---|---|
| 단계_0 | 결함 트랙 (구조 변경과 분리) | 낮~중 | - |
| 단계_1a | 파일을 폴더로 이동 | 낮음 | **성립** |
| 단계_1b | 거대 함수 추출 후 파일 분할 | 중 | 불성립 (4중 검증) |
| 단계_2 | 정상 응답 조립 공통화 | 낮음 | 불성립 (로그 대조) |
| 단계_3 | 패킷 디스크립터 테이블 | 중 | 불성립 (`tests/` 필요) |
| 단계_4 | 라이브 상태 층간 계약 명시 | 중 | 불성립 |
| 단계_5 | 파서와 자극 FSM 분리 | **높음** | 별도 판단 |

> [!IMPORTANT]
> **단계_1a 만 하고 멈추면 실익이 거의 없다.** 파일이 폴더로 정리될 뿐 `tdc_ble_mapping.c` 2,196줄은 그대로 남는다.
