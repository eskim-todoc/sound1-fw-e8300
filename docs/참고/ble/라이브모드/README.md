# 라이브모드

**TL;DR**: 라이브 자극(`en__mapping_live_stimulation`, 0x66) 경로의 4층 상태머신을 규명한 영속 사양과 실측 로그 대조 자료를 모은 폴더다. 향후 BLE 프로토콜 리팩토링은 이 폴더의 [상태머신 사양.md](상태머신%20사양.md)를 근거로 진행한다.

## 파일

| # | 파일 | 내용 |
|---|---|---|
| 1 | [상태머신 사양.md](상태머신%20사양.md) | **핵심 문서.** 상태 4층 규명(BLE 최상위 명령·라이브 서브커맨드·ISD 하드웨어 램프업·CFX PCM 출력모드), 서브커맨드 9종 전수표, 층별 Mermaid 상태 다이어그램, 재진입 가드 정밀 기술, 맵 파라미터 분할 수신 안전성, 알람·볼륨 처리 경로, 이름-동작 불일치 경고, 미확인 사항 목록 |
| 2 | [실측 로그 대조.md](실측%20로그%20대조.md) | 실측 RTT 로그 2종(라이브모드 단독, 라이브+알람재생+볼륨변경)의 패킷 시퀀스를 시간순으로 디코드해 상태머신 사양의 전이와 대조. 로그 해석 함정 2건, 회귀 기준선으로서의 근거 |

## 읽는 순서

먼저 [상태머신 사양.md](상태머신%20사양.md)로 구조를 파악한 뒤, [실측 로그 대조.md](실측%20로그%20대조.md)로 실제 패킷 시퀀스가 그 구조와 어떻게 대응하는지 확인하는 순서를 권장한다.
