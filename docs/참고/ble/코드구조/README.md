# BLE 코드 구조

**TL;DR**: `2__cm3` BLE 모듈(`src/2__cm3/source/ble/` 6개 `.c` 파일, 합계 4,637줄)의 현재 구조를 다루는 레퍼런스 3편의 인덱스다. 재구조화 착수 전 이 폴더만 읽으면 디스패치 경로·복잡도 실측치·인접 모듈 결합도를 파악할 수 있다.

## 대상 코드

`src/2__cm3/source/ble/`: `tdc_ble_communication.c` · `tdc_ble_mapping.c` · `tdc_ble_remote.c` · `tdc_ble_remote_sp_para.c` · `tdc_ble_general_debug.c` · `tdc_ble_gain_control.c` (및 대응 헤더).
