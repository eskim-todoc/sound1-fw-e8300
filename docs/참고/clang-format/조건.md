// - 변수가 여러 줄로 나열된다면, 각 변수들의 자료형과 변수명을 모두 줄 맞춤하기

// - if, for, while, switch, case, return 등과 같은 제어문은 모두 {}를 사용하여 블록을 명시적으로 구분

// - switch 문에서 case 라벨은 {} 블록 안에 작성하고, 해당 case의 break와 다음 case 라벨 사이에는 공백 라인을 추가

// - {} 블록의 시작과 끝은 항상 새로운 줄에 작성

// - { 시작에 의미 없는 줄 바꿈을 하지 않음

// - 함수 호출 시 매개변수가 많아서 한 줄의 내용이 길어지면 각 매개변수를 새로운 줄에 작성하고, 각 매개변수의 시작 위치를 맞춤

// - 주석은 1줄이면 //, 여러 줄이면 /* */를 사용하고, 주석의 시작 위치를 코드와 맞춤

// - 단, /* */ 주석 내부에서 /* */ 주석을 중첩해서 사용하지 않음. 이경우에는 // 주석을 사용

// - 배열 선언 시, 배열의 크기와 초기화 값이 길어지면 각 요소를 새로운 줄에 작성하고, 각 요소의 시작 위치를 맞춤

// - if, for, while 등 제어문 바로 위에 코드가 있으면, 제어문과 코드 사이에 공백 라인을 추가

// - if, for, while 등 제어문 바로 위에 주석이 있으면, 제어문과 주석 사이에 공백 라인을 추가
