# 노드 06 — 크기관계 교차검증가

## 검증 결과

### 검증됨
| 주장 | 근거 |
|---|---|
| FFT_SIZE=512, HALF_FFT_SIZE=256 | definitionsForAlgorithm.h L97-98, microcode.h L13-14 |
| FIFO 입력 >>5 shift 적용 | AUDIO_INPUT_RSHIFT=5 (audioMixer.c L15,27,39,51) |
| 게인 논리: FFT_SIZE × 1/2 × 1/2 × 1/4 × 1/2 = FFT_SIZE/32 | FrequencyAnalysis.c L89-98 주석 (코드 자체에 명시) |
| 총 16배 증폭 (512/32=16=2^4) | FrequencyAnalysis.c 주석 확인 |

### 불확실
| 주장 | 이유 |
|---|---|
| >>5 shift → Q6.18 | shift 코드는 있으나 Q6.18 명시 없음 |
| vMag 최종 포맷이 정확히 Q2.22 | HEAR 내부 Q 포맷 정의 부재 |

### **반례 발견 (중요)**
| 문서 주장 | 코드 실제 | 근거 |
|---|---|---|
| `result >> 5` (=result/32) | **`result >> 4`** | `RIGHT_SHIFT_MAX_MAG_FREQ_SCALE=4` (WINDOW 모드) |

**상세**: `definitionsForAlgorithm.h L110-116`
```c
#if (HEAR_FC_DFT_TYPE == HEAR_FC_DFT_TYPE_WINDOW)
#define RIGHT_SHIFT_MAX_MAG_FREQ_SCALE 4   ← 현재 적용값
#elif (HEAR_FC_DFT_TYPE == HEAR_FC_DFT_TYPE_NO_WINDOW)
#define RIGHT_SHIFT_MAX_MAG_FREQ_SCALE 5
```
- 현재 빌드: `HEAR_FC_DFT_TYPE_WINDOW` → **>>4** (기존 문서 ">>5" 는 오류)
- FrequencyAnalysis.c L105: `*scaled_ptr++ = (*freq_rep_ptr++) >> RIGHT_SHIFT_MAX_MAG_FREQ_SCALE;`
