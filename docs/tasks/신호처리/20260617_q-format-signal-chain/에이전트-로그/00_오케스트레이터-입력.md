# 오케스트레이터 입력

**작업**: MIC 1채널 신호처리 Q-포맷 변환 흐름 분석 및 문서화  
**목표**: 1__cfx + 3__hear 소스 기반으로 DMIC 입력→vMag 출력까지 각 처리 단계의 Q-포맷·비트폭·크기 관계를 추적하여 개발진 공유용 문서 작성  
**기존 초안**: `tests/CFX 관점 신호처리 과정 데이터 포맷 정리.md`

## 페르소나 분업

| 노드 | 페르소나 | 탐색 범위 |
|---|---|---|
| 01 | DMIC-입력 분석가 | lib_audio_in, driver_PCM, ISR — DMIC→FIFO 경로·비트폭 |
| 02 | AGC-처리 분석가 | agc.c/h, definitionsForAlgorithm.h — AGC gain·Q 변환 |
| 03 | FFT-입력준비 분석가 | FrequencyAnalysis.c/h, system_control.c — FFT FIFO 삽입 전 포맷 |
| 04 | Win_DFT_R 분석가 | 3__hear microcode.c/h — 윈도우·DFT·BFP 내부 |
| 05 | vMag 분석가 | 3__hear microcode.c/h — vMag 정밀도·출력 포맷 |
| 06 | 크기관계 검증가 | 전체 교차검증 — 입력 대비 출력 크기 수식 검증 |
