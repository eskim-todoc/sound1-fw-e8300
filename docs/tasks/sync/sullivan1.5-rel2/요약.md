# Sullivan1.5 ↔ Sound1 동기화 종합 요약 (Rev.0)

**TL;DR**: 사용자(다) 지시로 `BleCommunication`(13 파일)·`internalDevice`(32 파일)·`signalProcessing`(4 파일) 합계 **49 파일** 의미적 비교 완료. 차이 있는 파일은 **9 개** (Ble 4 + iDev 5 + sigProc 0), 동등은 40 개. **Sullivan에만 있고 Sound1에 미반영된 후보는 총 4 묶음** — ① OTA fatfs 마운트 2회 패치 (Ble), ② OTA DFU 디버그 로그 7 줄 (Ble), ③ FPGA I²C 실패 진단 로그 4 줄 (iDev), ④ ISD FIFO COUNT 실패 진단 로그 1 줄 (iDev). 잠재 의미 변경 1 건 (FPGA_version MAJOR 비트 mask `0x07` → `0x0F`, iDev). **본 문서는 사용자 판단용 — 각 후보별 Sound1 반영 여부 결정 요청.**

> [!IMPORTANT]
> **상세 분석은 폴더별 분석 문서 참조**:
> - [`분석 BleCommunication.md`](분석%20BleCommunication.md) — Ble 4 파일 변경 상세
> - [`분석 internalDevice.md`](분석%20internalDevice.md) — iDev 5 파일 변경 상세
> - [`분석 signalProcessing.md`](분석%20signalProcessing.md) — sigProc 변경 없음 (참조용)

## 2. Sullivan에만 있는 변경 — Sound1 반영 후보 (사용자 판단 요청)

### 후보 A. OTA fatfs 마운트 2회 패치 (Ble, 🟡 검토)
**파일**: `ci_ble_control_ota.c` 8 위치
**Sullivan 측 코멘트**: *"unmount, mount를 2번 수행해야 정상 동작함 (원인 불명)"*

| 패턴 | Sullivan | Sound1 |
|---|---|---|
| 부트 드라이브로 전환 | `snd_fatfs_remount_twice(0)` | `snd_fatfs_remount(SND_FATFS_LDRV_NUM_BOOT)` |
| 사용자 드라이브로 복귀 | `snd_fatfs_remount_twice(1)` | `snd_fatfs_remount(SND_FATFS_LDRV_NUM_USER_DATA)` |

→ **사용자 기억("Sullivan 후속 패치")과 가장 일치하는 후보**. Sound1 측 `snd_fatfs_remount()` 내부 구현 또는 OTA DFU 실기 안정성 확인 후 흡수 여부 결정. 상세: [`분석 BleCommunication.md §3.1`](분석%20BleCommunication.md).

### 후보 B. OTA DFU 디버그 로그 7 줄 (Ble, 🟡 검토)
**파일**: `ci_ble_control_ota.c`
- `[DFU] TRY TO REMOUNT BOOT DRIVE`
- `[DFU] ANOTHER FILE IS BEING WRITTEN, SO CLOSE THE FILE.`
- `[DFU] THERE IS NO '%s' PATH, SO MKDIR`
- `[DFU] FAILED TO MKDIR '%s'`
- `[DFU] FAILED TO OPEN '%s'`
- `[DFU] DATA INDEX INVALID, EXPECT : %d, RECEIVED : %d`
- `[DFU] FAILED TO WRITE, WHEN DATA INDEX : %d`

→ Sound1 service RTT 콘솔 작업 또는 그 이전 로그 정리 단계에서 함께 제거된 것으로 추정. OTA DFU 실패 디버깅에 유용 — RTT 채널로 부활 권고. 상세: [`분석 BleCommunication.md §3.2`](분석%20BleCommunication.md).

### 후보 C. FPGA I²C 실패 진단 로그 4 줄 (iDev, 🟡 검토)
**파일**: `isd_interface_init_FPGA.c`

| # | 위치 | 메시지 |
|---|---|---|
| 1 | `init_FPGA()` — FPGA 리셋 I²C 쓰기 실패 | `[FPGA] I2C WRITE FAIL : FPGA RESET` |
| 2 | `init_FPGA()` — `read_FPGA_version()` 실패 | `[FPGA] I2C READ FAIL : VERSION` |
| 3 | `init_FPGA()` — SYSTEM REGISTER 1ST 읽기 실패 (reset 검증) | `[FPGA] I2C READ FAIL : SYSTEM REGISTER 1ST` |
| 4 | `init_FPGA()` — SYSTEM REGISTER 1ST 읽기 실패 (init 검증) | `[FPGA] I2C READ FAIL : SYSTEM REGISTER 1ST` |

→ Sound1 측에서 깊이 중첩된 `if/else` 의 else 블록 정리하면서 진단 로그까지 함께 제거된 것으로 추정. I²C 통신 실패는 ISD 연결 불가의 직접 원인 — 진단 가치 높음. 상세: [`분석 internalDevice.md §3.1`](분석%20internalDevice.md).

### 후보 D. ISD FIFO COUNT 실패 진단 로그 1 줄 (iDev, 🟡 검토)
**파일**: `isd_interface_init_ISD.c` — `isd_path_Open()` FIFO 카운트 읽기 분기

```c
// Sullivan:
else { ci_printe("[ISD] I2C READ FAIL : FIFO COUNT \r\n"); }

// Sound1:

```

→ 빈 else 블록만 남아있어 진단 누락 — `ci_printe` 부활 권고. 상세: [`분석 internalDevice.md §3.2`](분석%20internalDevice.md).

## 3. 잠재 의미 변경 1 건 — Sound1 측 자체 변경 (확인 권고)

### `isd_interface_init_FPGA.c` — FPGA_version MAJOR 비트 mask 변경

| | Sullivan | Sound1 |
|---|---|---|
| MAJOR mask | `(FPGA_version >> 4) & 0x07` (3-bit) | `(FPGA_version >> 4) & 0x0F` (4-bit) |
| ADDR_MODE 표시 | `(FPGA_version >> 7) & 1` 추가 인자로 출력 | 인자 제거, 표시 안 함 |

표시 디버깅 로그라 동작에는 영향 없으나 디스플레이값이 달라짐. FPGA 버전 사양상 MAJOR 가 3-bit 인지 4-bit 인지 확인 후 정합성 검증 필요. 상세: [`분석 internalDevice.md §4.5`](분석%20internalDevice.md).

## 4. Sound1에만 있는 변경 — 단순 기록 (반영 무관)

본 분석에서 식별된 Sound1 후속 작업 성과. 본 task 범위 밖.

### BleCommunication
- `EN__SND_BT_CMD_SYSTEM_INFO` enum (0x33 BATTERY, 0x34 POWER, 0x35 LED_IND) 신설
- QCC 0x33~0x35 시스템 정보 패킷 처리 (Battery/Power/LED Indication 핸들러)
- ISD 미연결 시 0x30 명령 더미 응답 분기
- `ST__CI_LIB_BOOT_STATUS` / `SDK_CI_BOOT_*` → `snd_boot_status_t` / `SND_BOOT_*` 타입 마이그레이션
- QCC SHUTDOWN 시퀀스 통합 (2200 ms 워치독 리프레시, `snd_qcc_set_mode(SND_QCC_MODE_SHUTDOWN)`)
- 로그 채널 전환 `ci_printw`/`ci_printd` → `ci_printf`/`RTT_printf`
- SPI ERROR 핸들러 디버그 로그

### internalDevice
- QCC ISD 연결 상태 통보 — `snd_qcc_set_isd(SND_QCC_ISD_CONNECTED/DISCONNECTED)` (4 곳)
- 신규 getter `snd_isd_interface_get_state()` + `.h` 선언
- 정적 전역 `s_` prefix 적용 (`isd_state` → `s_isd_state` 등)
- 로컬 로그 매크로 폐기 — `ci_link_print*` (`.h`), `ci_ifc_init_fpga_print*` (`.h`) 6 종씩 전체 제거 → 표준 `ci_print*` 일원화
- 로그 메시지 표현 정리 (`[TX PMIC]` → `[LINK] POWER PMIC` 등)
- 로그 출력 빈도/우선순위 조정 (`ci_printd` → `ci_printv`/`ci_printi`)
- 일부 verbose 로그 코멘트 처리(비활성)
- 주석 정리 (`// 끝, …`, `// 시작, …` 등 제거)

### signalProcessing
- 없음
