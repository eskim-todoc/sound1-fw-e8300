# 요구사항: Sound1 docs 폴더 구조 세분화

**TL;DR**: 루트 repo의 폴더 기반+tasks 레지스트리 컨벤션을 Sound1 docs에 동일 적용. flat+`[프리픽스]` 구조의 22 파일을 참고/·기준/·사용방법/·tasks/<모듈>/<작업>/로 재편하고, 작업 문서는 모듈별 슬러그 폴더에 고정 파일명으로 정리하여 활성·완료 구분을 가능하게 한다. 문서 내용 수정·src/tests 변경은 비목표.

## 1. 배경

루트 repo에서 2026-04-24에 적용된 **폴더 기반 + tasks 레지스트리** 컨벤션을 Sound1에도 동일하게 적용한다.

Sound1 `docs/`는 기존 **flat 구조 + `[카테고리]` 프리픽스** 방식으로 22건(+ `.gitkeep` + 이미지) 누적:
- `[구현계획]` × 3, `[분석]` × 4, `[요구사항]` × 1, `[이력]` × 1
- `[참고]` × 7 (PDF 2 + .md 5), `[기준]` × 1, `[로그]` × 3 (.txt), 이미지 1

작업별 관련 문서가 흩어져 있고, 활성/완료 구분이 없으며, 신규 작업 시 관련 기존 작업을 찾기 어려운 상태.

## 2. 목표

- 루트 신 컨벤션과 **동일한** 폴더 레이아웃 적용
- 기존 작업들을 `tasks/<모듈>/<작업슬러그>/`로 재편
- Sound1 `CLAUDE.md`의 루트 docs 링크 6건 업데이트
- 기존 영속 문서(참고·기준 등)는 `참고/`·`기준/` 폴더로 이전
- 사용자 작업 중 파일(POWER_ON LED 요구사항·분석, 터치 로그)도 포함

## 3. 비목표

- 문서 **내용** 수정 없음 (이 작업은 순수 구조 변경)
- Sound1 src/, tests/ 변경 없음
- 회사 대외 제출용 공식 문서 포멧(`[세대] 코드-FW-모델 ...`)은 그대로 유지 (Dropbox 공유용)

## 4. 새 구조

```
Sound1/docs/
├── 지침/         (없음 — 루트 지침 참조)
├── 참고/         외부 스펙·레퍼런스·도메인 지식 문서
├── 기준/         검증 체크리스트·기준
├── 사용방법/     UI 명령어 사용법 등
└── tasks/
    ├── 작업 목록.md
    ├── meta/
    │   └── docs-restructure/            (본 작업)
    ├── LED/
    │   ├── operation-scheme/            (완료 — 분석·이력+이미지)
    │   └── power-on-early-lighting/     (진행 — 요구사항·분석)
    ├── power/
    │   └── low-power-mode/              (분석·구현계획)
    └── touch/
        ├── layer-separation/            (구현계획)
        └── init-split/                  (구현계획 + 로그/)
```

## 5. 수용 기준

| # | 항목 |
|---|---|
| 1 | 22건 기존 파일이 모두 새 위치로 이동 (tracked 17 + untracked 5 포함) |
| 2 | 구 프리픽스 `[...]` 파일명 패턴 잔존 0건 |
| 3 | Sound1 `CLAUDE.md` 루트 docs 링크 6건 새 경로 |
| 4 | `docs/tasks/작업 목록.md` 생성, 기존 작업·본 작업 등재 |
| 5 | 병합 후 `claude_develop` 위에 새 구조 존재 |
| 6 | 사용자 완료 시그널 범위 내 커밋·병합 (워크플로우 개정 이후 main-dir 브랜치 전환 방식) |
