# 요구사항: Sound1 CLAUDE.md 슬림화 + 루트 강제 강화

**TL;DR**: Sound1 진입점에서 외부 의존(대외 문서·IRS 등·Dropbox 공유) 섹션 제거, 루트 CLAUDE.md 강제 강화, 중복 섹션(루트 지침 참조 표·문서 작성 일부) 제거, 절대 경로(`E:\Claude\...`) 표기 → 상대 경로 일관.

## 1. 사용자 지시 원문

> Sound1 프로젝트에 있는 CLAUDE.md를 수정하자. 대외 제출용 공식 문서 (Dropbox 공유), 외부 의존 문서 (본인이 작성하지 않음), 완성본 공유에 대한 내용은 제거하자. 그리고 루트의 CLAUDE.md를 반드시 따르도록 더 강하게 강제하고. 루트의 CLAUDE.md를 반드시 따른다면, 루트 지침 참조 부분도 중복된 내용이라 생략 가능할 것으로 보이거든? 문서 작성 (프로젝트 고유) 내용도 생략이 가능할거 같네. 어때?
>
> (보정 합의) 작업 목록.md 진입점 한 줄은 보존, CLAUDE.md는 루트 우선 / `docs/지침/`은 프로젝트 우선으로 분리 명시, 절대 경로 표기 → 상대 경로 일관 적용.

## 2. 요구사항

### 요구사항_1 — 외부 의존 섹션 3건 제거

| 대상 섹션 | 제거 사유 |
|---|---|
| §대외 제출용 공식 문서 (Dropbox 공유) | Sound1 코드/펌웨어 작업 컨텍스트와 직교, 회사 운영 규칙이라 진입점에 부적합 |
| §외부 의존 문서 (IRS·IOVM·EPTC·EPTR) | 본인이 작성하지 않으므로 작업 진입점 정보 아님 |
| §완성본 공유 (Dropbox 수동 복사) | 운영 절차이지 Claude 작업 컨텍스트 아님 |

### 요구사항_2 — 루트 CLAUDE.md 강제 강화

| 항목 | 내용 |
|---|---|
| 진입점 강제 | 새 세션 시작 시 루트 CLAUDE.md 명시 Read + 보고 (현행 강제와 일치하되 더 명시) |
| 충돌 정책 | CLAUDE.md 자체 충돌은 **루트 우선** — 본 파일 사항이 루트와 어긋나면 본 파일이 잘못된 것으로 간주, 사용자에게 보고 |
| `docs/지침/` 충돌 | 루트 `문서 작성 규칙.md §2.1`의 "프로젝트 우선" 그대로 — 본 강제와 분리 |
| 표현 강도 | `> [!IMPORTANT]` Alert 블록으로 명시 |

### 요구사항_3 — 중복 섹션 제거 (DRY)

| 대상 | 제거 사유 |
|---|---|
| §루트 지침 참조 표 | 루트 CLAUDE.md가 권위 인덱스, Sound1에서 다시 표로 두면 동기화 부담·유지비용 |
| §문서 작성 (프로젝트 고유) §내부 작업 문서의 docs 레이아웃 다이어그램 | 루트 `문서 작성 규칙.md`의 표준 인스턴스 — 폴더 ls로 확인 가능, 진입점에 다이어그램 불필요 |

### 요구사항_4 — 작업 목록.md 진입점 한 줄 보존

작업 라우팅 첫 동작이 `tasks/작업 목록.md` 조회이므로 진입점 한 줄 링크는 보존.

### 요구사항_5 — 절대 경로 → 상대 경로 일관

| 위치 | 현재 | 목표 |
|---|---|---|
| 헤더 루트 참조 텍스트 | `` `E:\Claude\CLAUDE.md` `` | `` `../../CLAUDE.md` `` |
| URL 부분 | 이미 상대 (`../../CLAUDE.md`) | 유지 |

근거: 루트 `문서 작성 규칙.md §6.1` "파일 간 링크는 상대경로", 루트 CLAUDE.md L8 "이 폴더를 복제하면 다른 환경에서도 컨텍스트 유지 가능".
