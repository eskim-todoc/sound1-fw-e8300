## 2. 변경 사항

### 2.1 구조 (Before / After)

**Before** (flat + `[카테고리]` 프리픽스):
- `[구현계획]` × 3, `[분석]` × 4, `[요구사항]` × 1, `[이력]` × 1
- `[참고]` × 7 (PDF 2 + .md 5), `[기준]` × 1, `[로그]` × 3 (.txt), 이미지 1

**After** (폴더 기반):
```
docs/
├── 지침/     프로젝트 특화 지침
├── 참고/     외부 스펙·도메인 (칩/, LED/, 터치/ 모듈 분할)
├── 사용방법/ UI 명령어 등
└── tasks/
    ├── list.md
    └── <모듈>/<작업슬러그>/{요구사항,분석,구현계획,진행상황,이력}.md
```

### 2.2 산출물

- 영속 문서 10건: `참고/`·`지침/`·`사용방법/` 으로 이동, 프리픽스·저자 suffix 제거
- 작업 문서 7건 (tracked) + 5건 (untracked): `tasks/<모듈>/<작업>/` 구조로 재편, 고정 파일명 적용
- `tasks/list.md` 신설 — 활성/완료/완료(추정) 분류 + 갱신 이력 누적
- `CLAUDE.md` 링크 갱신 (6 건) + 참고/LED 시스템 3 파일 상호참조 (8 건)

### 2.3 머지

`claude_feature_docs-restructure` → `claude_develop` 머지 완료 (commit `129212e`, 2026-04-24).
