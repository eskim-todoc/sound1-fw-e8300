# 요구사항

**TL;DR**: 사용자가 (다) "Sound1만 일괄 소급"을 명시 선택. Sound1 `docs/{지침·사용방법·참고}/` 하위 영속 9개 파일에 frontmatter+TL;DR 일괄 추가하여 §9.1 의무를 충족시킨다. tasks 산출물은 본 작업 외(과거 시점 기록).

## 1. 배경

루트 task [`meta/docs-consistency-audit`](../../../../../docs/tasks/meta/docs-consistency-audit/이력 및 결과.md) 후속 분기 1번 ([`meta/20260507_folder-readmes`](../folder-readmes/이력 및 결과.md))에서 폴더 README는 추가했으나, 그 안 **기존 영속 파일들의 frontmatter 누락**은 점검 대상에서 빠졌다. 사용자가 본 점검 빈틈을 지적하며 **(다) Sound1만 일괄 소급**을 선택 — 일괄 소급은 §9.1·§6.5에 따라 사용자 명시 요청 트리거가 충족됐을 때만 가능.

## 2. 적용 지침 근거

- 루트 [`지침/일반/문서 작성 규칙.md §9.1`](../../../../../docs/지침/일반/문서%20작성%20규칙.md): "신규 작성 시 의무. 기존 문서 소급은 §6.5 원칙대로 — 기존 문서 손댈 때 같이 변경(점진적). **일괄 소급은 사용자 명시 요청 시에만.**"
- §9.1 필수 적용 범위: "지침/, 회고/, 사용방법/, 참고/, 이력/ 하위 전부 + tasks/<모듈>/<작업>/ 하위 전부 + 폴더별 README + 루트 진입점 CLAUDE.md"
- §9.2 TL;DR: "frontmatter 다음, 첫 헤더(`# 제목`) 바로 아래 1-3줄. **굵게 prefix `**TL;DR**:`**"
