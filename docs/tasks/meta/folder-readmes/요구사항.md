# 요구사항

**TL;DR**: 루트 task `meta/docs-consistency-audit`의 후속 분기 권고 1번. Sound1 `docs/` 영속 폴더 4개(`지침/`·`사용방법/`·`참고/`·`tasks/`)에 폴더 README.md 인덱스를 추가해 lazy loading 전제(루트 지침 §9.3)를 충족한다.

## 1. 배경

루트 task [`meta/docs-consistency-audit`](../../../../../docs/tasks/_archive/meta/docs-consistency-audit/이력.md)에서 Sound1 자체는 표준 docs 구조와 `tasks/list.md`를 잘 갖췄으나 **폴더별 README.md가 부재**해 LLM의 폴더 진입 lazy load가 불가능한 상태로 식별됨. 본 task는 그 후속 처리.

## 2. 적용 지침 근거

- 루트 [`지침/일반/문서 작성 규칙.md §9.3`](../../../../../docs/지침/일반/문서%20작성%20규칙.md#93-폴더별-readme): "필수: `지침/`, `회고/`, `사용방법/`, `참고/`. 선택: 서브폴더 — 5+ 파일 시 가치"
- 형식: 폴더 목적 한 줄 + 파일 인덱스 표 (`파일`/`목적`/`사용 시점`)

## 3. 작업 범위

### 3.1 본 task 처리 대상 (필수)

| # | 파일 | 위치 |
|---|---|---|
| 요구사항_1 | `지침/README.md` | `docs/지침/README.md` |
| 요구사항_2 | `사용방법/README.md` | `docs/사용방법/README.md` |
| 요구사항_3 | `참고/README.md` | `docs/참고/README.md` |
| 요구사항_4 | `tasks/README.md` | `docs/tasks/README.md` (이미 list.md 있음 — 별도 README 추가 가치 검토 후 결정) |

### 3.2 본 task 처리 외 (선택 — 추후 검토)

`참고/` 서브폴더(`칩/`·`LED/`·`터치/`) README는 §9.3 "선택" 기준이며 현재 각 서브폴더 파일 수 4개 이하라 본 task 범위 외. LED/만 4-5개 근접이라 후속 검토 가치 있음.

## 4. 검증 기준

- [ ] 4개 README.md 모두 frontmatter+TL;DR 보유
- [ ] 인덱스 표가 실제 폴더 파일과 1:1 매칭
- [ ] 한글 경로 링크는 `%20` 인코딩
- [ ] 루트 [`지침/일반/문서 작성 규칙.md §9.3`](../../../../../docs/지침/일반/문서%20작성%20규칙.md#93-폴더별-readme) 형식 준수
