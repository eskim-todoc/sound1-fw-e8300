# 이력 및 결과 — init 콜트리 errorCodeUpdate 일괄 디바운스

**TL;DR**: `isd_interface()`가 호출하는 `init_txPowerIC`/`init_FPGA`/`init_ISD` 콜트리 안에서 `errorCodeUpdate()`가 불리는 모든 구간에, 산발적으로 흩어진 현재 디바운스를 **통합 카운터 + 상수 임계값**으로 일원화하는 작업. 2026-06-10 분석·문서화 단계. 구현은 은수님 검토 후 결정(보류).
