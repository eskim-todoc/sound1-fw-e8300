# 이력 및 결과 — init 콜트리 errorCodeUpdate 일괄 디바운스

**TL;DR**: `isd_interface()`가 호출하는 `init_txPowerIC`/`init_FPGA`/`init_ISD` 콜트리 안에서 `errorCodeUpdate()`가 불리는 모든 구간에, 산발적으로 흩어진 현재 디바운스를 **통합 카운터 + 상수 임계값**으로 일원화하는 작업. 2026-06-10 분석·문서화 단계. 구현은 은수님 검토 후 결정(보류).

## 완료 요약

`systemControl()` LED 판정에 FPGA 통신 에러 디바운스 추가 — `FPGA_CommunicationErrorFlag`가 연속 `TDC_FPGA_COMM_LED_DEBOUNCE_N`(=10) tick 지속 시에만 빨강 점등, 정상 1회면 즉시 소등. 초반 산발 과도기 에러(3~10회)는 연속 조건 미달로 점등 자체가 차단되어 "파르르르" 제거. 만성 단선만 점등(안전 보존). init 콜트리 `errorCodeUpdate`·기존 산발 카운터 13개·복구 경로·앱 진단 전부 무수정으로 회귀 최소.

- **변경**: `systemControl.c` 1파일 (`#define` 1 + `static` 카운터 1 + 디바운스 로직 + 소등 L169/점등 L425 2곳 동기 치환)
- **검증**: 논리·정적빌드 2 fan-out 전 항목 PASS. 빌드·실기 동작 확인은 은수님 Eclipse 환경 필요.

### 유의점(실기 튜닝)
- `N=10`은 `#define`으로 조정 가능. 초반 과도기 실패 횟수보다 크게 잡을수록 확실히 흡수.
- 디바운스는 "연속" 기준 — 만성 장애가 N 미만 주기로 간헐 성공하면 점등이 지연/회피될 수 있음(은수님 시나리오인 '초반 후 완전 정상'엔 무관).
