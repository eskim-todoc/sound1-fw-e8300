## 목표와 범위

`sullivan-1-5-fw-hw-test-link-pwr-bt-period`에서 사용하는 백텔 링크 확인, PMIC 레벨, FF(feedforward) 기능을 현재 Sound1으로 옮길 방법을 분석하고 계획한다. CFX와 CM3의 역할, 공유 메모리와 상태 전이, 범용 디버깅 프로토콜 헤더 차이를 함께 검토한다. 은수님이 그림과 상태도, 흐름도로 설명하는 문서를 요청했다.

이번 권한은 코드 조사와 계획 문서 작성이다. 펌웨어 구현, 설정값 변경, 장치 접근, NVM 기록, 커밋 및 푸시는 포함하지 않는다. 기존 dirty 코드와 문서는 보존한다. 인허가/DHF 및 SV 문서 자체를 수정하는 작업도 아니다.

### HTML 제작과 검증

사용자용 결과는 [마이그레이션 분석 HTML](마이그레이션%20분석.html)이다. CSS/JavaScript와 반응형 도해를 HTML 한 파일에 포함했으며 실행 중 외부 CDN이나 네트워크를 사용하지 않는다. 본문과 도해의 기본 글꼴은 설치된 KoPubWorld바탕체다. 다른 PC에는 같은 글꼴이 설치되어야 동일하게 표시된다. 코드만 별도 글꼴을 사용한다.

상세 분석은 접기/펼치기로 읽고, 전역 검색에서 해당 탭과 상세 위치를 열 수 있다. 전체 보기는 모든 본문을 펼치며 전체 인쇄는 모든 탭/상세를 출력하고 원래 읽기 상태로 복원한다. 인쇄용 CSS와 화면 렌더를 확인했으며 종이 출력이나 PDF의 전체 페이지 조판을 검증한 것은 아니다.

대화형 FF3 예시는 모든 gate가 유효하다는 가정에서 추가량과 성공 후 P/R/C를 계산한다. 실제 장치 제어나 TTL/세션/I2C 동작 전체의 시뮬레이터가 아니다. 부분 적용 때 C=S로 종결하고 같은 요청을 다시 충전하지 않는 차이를 예시로 확인했다.

[HTML 검증 결과](HTML%20검증.json)에86개 실제 검사 결과를 보존했다. 데스크톱9개 탭과 좁은 화면, 계산 예시, 확대 상태도/흐름도, 인쇄용 표시를 캡처해 육안 확인했다. 자동/수동 확인을 전체 접근성 인증이나 실제 사용자 사용성 시험으로 확대하지 않는다. 검색창의 첫 Esc를 검색 입력이 소비하는 문제는 명시적 닫기로 보완했고, 독립 Mermaid의 중복 ID는 각 SVG의 namespace로 분리한 뒤 재검사했다.

HTML 추가 후 표준 Markdown 링크 검사도 내부 링크53개에서 실패0으로 통과했다. 원본 분석의 링크 추가를 반영한 [문서 검증 결과](문서%20검증.json)는 로컬 링크/이미지108개, 앵커14개, 패킷 예시22개에서 실패0이다.

초기 HTML 제작 당시 기존 소스52개의 해시는 분석 기준과 모두 같았다. 당시 Sound1 HEAD는 `62451078c36c3a34baaa642e025db9426138059e`로 바뀌었으나, 원본 분석 당시 HEAD와 dirty 상태를 담은 [분석 기준](분석%20기준.json)은 역사적 기준으로 보존한다. 재사용한 검증 도구가 해당 JSON의 HEAD/status를 현재값으로 갱신하는 부작용은 원래 기준으로 복원했으며, HTML 해시 검사는 기준 파일을 바꾸지 않는다.

내용 수정은 원본 Markdown에서 수행한 뒤 [HTML 생성기](HTML%20문서%20생성.mjs)를 실행한다. [스타일](HTML%20스타일.css)과 [동작](HTML%20동작.js)은 생성기의 입력이며, 열람에는 HTML 파일만 필요하다. 기능별 도입부의 쉬운 설명과 계산 예시는 생성기에 있으므로 원본의 수치/정책이 바뀌면 함께 대조해야 한다. 생성기는 현재 PC의 bundled Node/marked 경로를 사용한다.

### HTML 도해의 반응형 전환

후속 요청에 따라 고정 SVG 축소 미리보기와 확대 모달을 제거했다. [도해 정의](HTML%20반응형%20도해.mjs), [도해 스타일](HTML%20반응형%20도해.css), [연결선 동작](HTML%20도해%20동작.js)을 생성기에 연결했다. 상자·라벨·조건/목적지는 실제 HTML이고 KoPubWorld바탕체를 사용한다. 기본 진행 연결선만 현재 상자 위치에 맞추어 SVG 경로로 그리며 ResizeObserver로 갱신한다. 연결선의 이전 너비가 순간적으로 문서를 밀어내는 현상은 SVG를 현재 컨테이너 크기에 묶어 보완했다.

도해1은 장치/칩/코어 경계를 유지한 구성도와 전달 경로, 도해6은16개 메시지의 시퀀스로 표현했다. 상태/흐름 도해의 대표 진행은 선으로, 조건 분기/반복/오류 복귀는 각 상자 아래 조건→목적지 링크로 표시한다. 링크는 해당 상태로 스크롤하고 키보드 포커스를 옮긴다. JavaScript 연결선은 장식이며 HTML의 모든 상태·목적지는 본문에 존재한다. 도해9는 과거 전체 로드맵 이미지 대신 개정11.1/11.5절을 따른다. Markdown의 기존 PNG/SVG/Mermaid는 보존했다.
