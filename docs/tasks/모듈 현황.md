- 갱신 트리거: 작업 종료 처리 시 — [`작업 진행 규칙.md §6.1`](../../../../docs/지침/일반/작업%20진행%20규칙.md) 3번 단계가 본 파일 자동 갱신
- 추적 범위: 작업 **신규/완료**. 기존 작업 파일 *수정*은 추적 대상 아님
