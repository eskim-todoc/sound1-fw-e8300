## 1. 결과 요약

- ULP 모드 진입 시 SYSCLK 30.72 MHz → 2.56 MHz 전환 (`ci_power_sleep()` 활성화).
- 500 ms 웨이크업 + 카운터 기반 롱터치 판정으로 ULP 루프 단순화.
- 롱터치 감지 시 즉시 워치독 리셋 (해제 대기 로직 제거).

| ULP 루프 카운터 기반 롱터치 | `func_sleep()` 내부 | 500 ms wakeup + tick 누적 |
