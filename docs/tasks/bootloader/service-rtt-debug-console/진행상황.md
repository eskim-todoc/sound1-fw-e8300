### 사용자 동작 테스트 항목 (보고 받을 것)

1. **일반 부팅** (`DIO_NUM_DMIC_CLK1_CAL` = LOW) — CFX/CM3 정상 boot? RTT 로그 추출 전과 동일?
2. **LED 동작** — bootloader 단계 SKYBLUE fade 정상? (LED 시작 위치가 `NVMSync` + app_name 결정 후로 ~수십 ms 늦춰짐 — AC-1 835 ms 이내 통과?)
3. **service 모드** (`DIO_NUM_DMIC_CLK1_CAL` = HIGH) — auto-rtt-viewer 콘솔 진입? `[SERVICE] RTT debug console ready.` + `Commands: manifest, app0, app1, app2, reboot` 표시?
4. **service 5 명령**:
   - `manifest` ↵ → `/MANIFEST.TXT=<<<<<` ~ `>>>>>` hex 덤프 + `print done.`
   - `app0` / `app1` / `app2` ↵ → 각 APP000~002.FEZ hex 덤프
   - 잘못된 명령 ↵ → `invalid command.`
   - `reboot` ↵ → `[SERVICE] reboot requested. Resetting in 500ms...` + 500 ms 후 `main()` 재진입 (RTT 로그 + 부트 시퀀스 재시작)
5. **service LED tick** — 명령 처리 중에도 ~380 ms 주기로 색 변환?
6. **사이즈 측정** (Step 4) — `arm-none-eabi-size .\src\0__bootloader\Debug\bootloader.elf` 추출 전·후 비교, 수용_6 (≤ +100 B) 통과?
