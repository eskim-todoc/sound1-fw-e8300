# service 모드 RTT 디버그 콘솔 — 구현계획

**TL;DR**: 4 step commit으로 진행 — ① storage init 헬퍼 추출 (회귀 0 검증), ② 부트로더 UART 디버그 모드 코드 삭제, ③ service.c RTT 디버그 콘솔 + LED tick 신설, ④ 사이즈·동작 마무리 검증. 작업 브랜치 `claude_feature_service-rtt-debug-console` (base: claude_develop). 검증 = auto-rtt-viewer로 5개 명령 응답 + LED 색 변환 + 부트로더 회귀 미발생. 사이즈 ≤ +100 B (추정상 -90 B 감소).

작성일: 2026-05-07
Rev: Rev.4 (2026-05-07, 사용자 피드백 4차 반영 — service 는 OTA 슬롯 처리 불필요라 `snd_boot_*`/`tdc_boot_print_boot_file` 호출 안 함. `tdc_boot_get_ohdl()` getter 는 service 의 `_print_fw_file` 에서 부트로더 `ohdl` 재사용용으로만 사용 (별도 `s_tdc_service_fp` 변수 폐기). 부트로더는 `&ohdl` 직접 사용)

## 2. Step 1 — storage init 헬퍼 추출

### 2.1 변경 위치

| 파일 | 변경 |
|---|---|
| [`bootloader.c`](../../../../src/0__bootloader/source/bootloader.c) | `tdc_boot_storage_init()` 함수 신설 + `tdc_boot_get_ohdl()` getter 추가, `bootloader_boot()` 단순화 (LED 가드 + `snd_boot_*`/`tdc_boot_print_boot_file` + `bootloader_load_app_file` 만 남김) |
| [`ci_boot.h`](../../../../src/0__bootloader/include/bootmgr/ci_boot.h) | `tdc_boot_storage_init` + `tdc_boot_get_ohdl` 선언 추가, 필요 헤더 의존 정리 (`bootloader_internal.h` / `ff.h` 등) |

### 2.2 헬퍼 함수 본문 (bootloader.c 내부)

[`bootloader.c`](../../../../src/0__bootloader/source/bootloader.c) `bootloader_boot()`의 다음 블록을 **그대로 잘라내어** `tdc_boot_storage_init()`로 이동:

- `bootloader_error = ...` 초기화
- `NVMInit` ~ `bootloader_read_nvm_boot_info` ~ boot speed 분기 ~ `bootloader_load_manu_table`
- `tdc_uart_init` 재초기화
- `f_mount` ~ `f_chdrive` ~ `f_opendir/f_closedir` ~ `NVMSync`

> **헬퍼 제외 (Rev.4 사용자 확정)**:
> - `TDC_BOOT_LED_ENABLE` 가드 — 부트로더 전용 (LED 동작은 부트로더만)
> - `app_number` / `app_name` 결정 — 부트로더 전용 (service 는 부팅 안 함)
> - **`snd_boot_set_fp(&ohdl)` / `snd_boot_handle_file()` / `tdc_boot_print_boot_file()`** — OTA DFU 이미지 슬롯 선택 영역. **부트로더만 호출** (`bootloader_load_app_file()` 직전, `&ohdl` 직접 사용). **service 는 슬롯 처리 자체 불필요라 3 함수 모두 호출 안 함**.

`out_boot_info` 처리: 헬퍼 내부 `uint32_t buf[128]` 에 NVM read 후 `bootloader_boot_information *boot_info = (bootloader_boot_information *)buf` cast. 함수 끝에서 `out_boot_info != NULL` 시 `memcpy` 로 카피. service 는 NULL 전달.

추가 함수 ([`bootloader.c`](../../../../src/0__bootloader/source/bootloader.c)):

```c
FIL *tdc_boot_get_ohdl(void)
{
    return &ohdl;
}
```

> **getter 용도 (Rev.4)**: service.c 의 `_print_fw_file` 이 `f_open`/`f_read`/`f_close` 시 부트로더 정적 변수 `ohdl` 을 재사용. 부트로더 자신은 `bootloader.c` 안의 같은 정적 변수라 `&ohdl` 직접 사용 (getter 불필요).

[`ci_boot.h`](../../../../src/0__bootloader/include/bootmgr/ci_boot.h) 선언:

```c
int  tdc_boot_storage_init(bootloader_boot_information *out_boot_info);
FIL *tdc_boot_get_ohdl(void);
```

### 2.3 `bootloader_boot()` 변경 후

```c
int bootloader_boot(void)
{
    int                          ret;
    bootloader_boot_information  boot_info;
    char                         app_name[20];

    ret = tdc_boot_storage_init(&boot_info);
    if (ret < 0) return ret;

    /* app_name 결정 (부트로더 전용) */
    uint32_t app_number = *((uint32_t *) SYSVAR_BOOT_APPN);
    tdc_uart_printf("app_number = %u \r\n", app_number);
    if (app_number == 0) {
        ret = get_app_load_ext(&boot_info, app_name);
        tdc_uart_printf("app_name = '%s' \r\n", app_name);
        if (ret <= 0) {
            bootloader_error = BOOTLOADER_EXIT_STATUS_CODE(-1);
            return -1;
        }
    } else {
        int      count           = 0;
        uint32_t app_number_temp = app_number;
        do {
            app_number_temp /= 10;
            ++count;
        } while (app_number_temp != 0);
        strcpy(app_name, "MANIFEST_");
        itoa(app_number, app_name + 9, 10);
        strcpy(app_name + 9 + count, ".TXT");
    }

#if TDC_BOOT_LED_ENABLE
    {
        bool uart_active = (Sys_GPIO_Read(DIO_NUM_UART_ENABLE) == DIO_ACTIVE_LEVEL_UART_ENABLE);
        if (!uart_active) {
            tdc_boot_led_init();
            tdc_boot_led_start();
        }
    }
#endif

    /* OTA DFU 이미지 슬롯 선택 (bootloader_load_app_file 직전 의무) */
    snd_boot_set_fp(&ohdl);
    snd_boot_handle_file();
    tdc_boot_print_boot_file();

    return bootloader_load_app_file(app_name);
}
```

## 4. Step 3 — service.c RTT 디버그 콘솔 + LED tick 신설

### 4.1 변경 위치

| 파일 | 변경 |
|---|---|
| [`service.c`](../../../../src/0__bootloader/source/service/service.c) | LED 루프 폐기 + storage init 호출 + RTT 디버그 콘솔 + LED tick. `_print_fw_file` 은 `tdc_boot_get_ohdl()` getter 로 부트로더 ohdl 재사용 (별도 fp 변수 폐기). OTA 슬롯 처리 미해당 (Rev.4) |

### 4.2 service.c 새 구조

```c
#include <service.h>
#include <main.h>
#include <ci_boot.h>          // tdc_boot_storage_init
#include <rtt_printf.h>       // rtt_printf, rtt_getch
#include <ff.h>               // FATFS

// private 정적 변수 (Rev.4: s_tdc_service_fp 제거 — 부트로더 ohdl 재사용)
static uint32_t s_tdc_service_led_iter  = 0;
static uint8_t  s_tdc_service_led_color = 0;

#define TDC_SERVICE_LED_TICK_ITER 380   // ~380 iter × 1ms ≈ 380 ms

// private 함수
static void s_tdc_service_led_init(void);
static void s_tdc_service_led_tick(void);
static void s_tdc_service_print_fw_file(const char *p_path);

void service_main(void)
{
    s_tdc_service_led_init();

    if (tdc_boot_storage_init(NULL) < 0) {
        rtt_printf("[SERVICE] storage init failed.\r\n");
        while (1) {
            SYS_WATCHDOG_REFRESH();
            s_tdc_service_led_tick();
            tdc_delay_ms(1);
        }
    }

    /* Rev.4: OTA 슬롯 처리 service 미해당 — _print_fw_file 만 tdc_boot_get_ohdl() 로 부트로더 ohdl 재사용 */
    rtt_printf("[SERVICE] RTT debug console ready.\r\n");
    rtt_printf("Commands: manifest, app0, app1, app2, reboot\r\n");

    char buf[64] = {0};
    int  idx     = 0;
    char ch;
    bool running = true;

    while (running) {
        SYS_WATCHDOG_REFRESH();
        s_tdc_service_led_tick();

        if (rtt_getch(&ch) > 0) {
            if (ch == '\r') {
                /* CR 무시 (line_terminator 호환) */
            } else if (ch == '\n') {
                rtt_printf("\r\n");
                if (idx > 0) {
                    if      (strncmp(buf, "manifest", 8) == 0) { s_tdc_service_print_fw_file("/MANIFEST.TXT"); }
                    else if (strncmp(buf, "app0",     4) == 0) { s_tdc_service_print_fw_file("/APP000.FEZ"); }
                    else if (strncmp(buf, "app1",     4) == 0) { s_tdc_service_print_fw_file("/APP001.FEZ"); }
                    else if (strncmp(buf, "app2",     4) == 0) { s_tdc_service_print_fw_file("/APP002.FEZ"); }
                    else if (strncmp(buf, "reboot",   6) == 0) { running = false; }
                    else                                       { rtt_printf("invalid command.\r\n"); }
                }
                idx = 0; buf[0] = 0;
            } else if (ch == '\b') {
                if (idx > 0) { idx--; buf[idx] = 0; rtt_printf("\b \b"); }
            } else if (idx < 62) {
                buf[idx++] = ch; buf[idx] = 0;
                rtt_printf("%c", ch);
            }
        }

        tdc_delay_ms(1);
    }

    rtt_printf("[SERVICE] reboot requested. Resetting in 500ms...\r\n");
    /* 500 ms 동안 LED tick + watchdog refresh 유지 → RTT 출력 버퍼 flush 보장
     * (출력 중이던 hex 덤프 등 마지막 메시지가 auto-rtt-viewer host에 도달할 시간) */
    for (int i = 0; i < 500; i++) {
        SYS_WATCHDOG_REFRESH();
        s_tdc_service_led_tick();
        tdc_delay_ms(1);
    }
    SYS_WATCHDOG_RESET();   /* 즉시 HW reset → main() 재진입 */
    while (1) { ; }         /* unreachable, 안전망 */
}

static void s_tdc_service_led_init(void)
{
    Sys_DIO_Config(DIO_NUM_LED_R_UART_TX_E8300, DIO_CFG_LED);
    Sys_DIO_Config(DIO_NUM_LED_G_UART_RX_E8300, DIO_CFG_LED);
    Sys_DIO_Config(DIO_NUM_LED_B,               DIO_CFG_LED);
}

static void s_tdc_service_led_tick(void)
{
    if (++s_tdc_service_led_iter >= TDC_SERVICE_LED_TICK_ITER) {
        s_tdc_service_led_iter  = 0;
        s_tdc_service_led_color = (s_tdc_service_led_color + 1) & 0x07;
        Sys_GPIO_Write(DIO_NUM_LED_R_UART_TX_E8300, !((s_tdc_service_led_color >> 0) & 0x01));
        Sys_GPIO_Write(DIO_NUM_LED_G_UART_RX_E8300, !((s_tdc_service_led_color >> 1) & 0x01));
        Sys_GPIO_Write(DIO_NUM_LED_B,               !((s_tdc_service_led_color >> 2) & 0x01));
    }
}

static void s_tdc_service_print_fw_file(const char *p_path)
{
    uint8_t  rtt_buffer[64];
    UINT     br;
    FRESULT  res;
    FIL     *fp = tdc_boot_get_ohdl();   /* Rev.4: 부트로더 ohdl 재사용 (별도 fp 변수 안 만듦) */

    res = f_open(fp, p_path, FA_OPEN_EXISTING | FA_READ);
    if (res != FR_OK) {
        rtt_printf("[ERROR] Failed to open '%s' file.\r\n", p_path);
        return;
    }

    rtt_printf("%s=<<<<<\r\n", p_path);

    while (1) {
        SYS_WATCHDOG_REFRESH();
        s_tdc_service_led_tick();   // 큰 파일 출력 중에도 LED 동작

        res = f_read(fp, rtt_buffer, 64, &br);
        if (res != FR_OK) {
            rtt_printf("[ERROR] Failed to read '%s' file.\r\n", p_path);
            f_close(fp);
            return;
        }
        if (br == 0) {
            rtt_printf(">>>>>\r\n");
            rtt_printf("print done.\r\n");
            break;
        }
        for (UINT i = 0; i < br; i++) {
            rtt_printf("%02X ", rtt_buffer[i]);
        }
        rtt_printf("\r\n");
    }

    f_close(fp);
}
```

### 4.3 검증

1. JFlash로 FW 다운로드, `DIO_NUM_DMIC_CLK1_CAL` 핀을 HIGH로 묶고 부팅 → service 모드 진입
2. auto-rtt-viewer 시작 → `[SERVICE] RTT debug console ready.` 메시지 확인
3. 터미널에 `manifest` 입력 → `/MANIFEST.TXT` hex 덤프 확인
4. `app0` ~ `app2` 동작 확인
5. `reboot` 입력 → 안내 메시지 출력 + 500 ms 후 `SYS_WATCHDOG_RESET()`으로 즉시 재부팅 (`main()` 재진입 RTT 로그 + 부트 시퀀스 재시작 확인). 500 ms 동안 LED tick 색 변환 1회 정도 발생. 500 ms 직전에 출력된 hex 덤프 메시지가 auto-rtt-viewer 터미널에 모두 표시되는지 확인 (메시지 손실 없음)
6. LED 색이 명령 처리 중에도 변환되는지 시각 확인

### 4.4 commit

```
feat(service): RTT 입력 기반 디버그 콘솔 + LED tick 신설

service_main 의 LED 8색 순회 루프를 폐기하고 RTT down channel 로 명령을 받아
펌웨어 파일 hex 덤프 (rtt up channel 출력) 를 수행. LED 는 명령 처리 루프
백그라운드로 색 변환. reboot 명령은 워치독 리셋으로 시스템 재부팅.

- service.c: storage init 호출 + RTT 폴링 + 명령 파서 + _print_fw_file (RTT 전용)
- 명령어 셋: manifest, app0, app1, app2, reboot (reboot = 워치독 리셋)
- 호스트 도구: auto-rtt-viewer (stdin → RTT down 0)
```

1. 사용자 승인 후 claude_develop으로 merge:

```powershell
git checkout claude_develop
git merge --no-ff claude_feature_service-rtt-debug-console
git push origin claude_develop
```

2. 사용자 추가 승인 시 claude_develop → claude_main 머지:

```powershell
git checkout claude_main
git merge --no-ff claude_develop
git push origin claude_main
```

3. feature 브랜치 삭제
