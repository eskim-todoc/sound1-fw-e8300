# [단계2·토론 15] 고유 스큐 보정: (0,2)vs(1,3) 1/8 샘플 스큐를 지연 예산에 포함/상쇄하는 방법

## 찬
**포함론 — ch2(Left)에 (기하지연 - 고유스큐) = 0.808 샘플을 직접 부여**

사실 A(HW p.222)·사실 B(HW p.445 §14.4): ch2(DMIC2/Left)가 ch1(DMIC1/Right)보다 1/8 샘플(7.81µs) 먼저 도착하는 고유 스큐가 확정 존재한다. 착용 기하 상 Left(DMIC2)가 정면 음원에 먼저 노출(현재 상태 정리 및 복기.md: "DMIC2[1] == DMIC1[0]")되므로 Right(ch1)가 0.933 샘플 늦게 도달해야 정합이 맞다. 이 때 ch2의 고유 스큐 +0.125 샘플을 활용하면 ch2에 (0.933 - 0.125) = 0.808 샘플만 DELAY로 부여하면 된다. 레지스터 설정: ch2에 DELAY_INTEGER=6(0.750 샘플) + DELAY_FRACTIONAL=14(0.0583 샘플) = 0.808 샘플, ch1은 현행(0) 유지. 이 값은 DELAY_INTEGER 최대 7/8=0.875 샘플 범위 내에 있으며(사실 G), SW 버퍼 시프트 불필요. 레지스터 변경 대상이 ch2 1개뿐이어서 구현·검증 범위가 최소화된다.

## 반
**상쇄론 — 스큐를 먼저 ch2에 INT=1로 상쇄한 뒤, ch1에 기하지연 0.933 샘플을 독립 부여**

사실 C(HW p.219 NOTE): "fractional delay 변경이 ADC 입력 간 동기화에 영향을 준다"는 명시는 스큐 보정과 빔포밍 지연을 분리 적용해야 각 레지스터의 역할이 투명해진다는 설계 근거가 된다. ch2에 DELAY_INTEGER=1(0.125 샘플)로 고유 스큐를 먼저 상쇄해 두 채널을 가상 동기화한 뒤, ch1에 INT=7+FRAC=14(=0.933 샘플)를 부여하면 '스큐 보정'과 '빔포밍 지연'이 분리되어 디버깅 시 각 성분의 기여를 독립 검증할 수 있다. 포함론에서는 ch2 INT=6, FRAC=14라는 단일 설정값이 두 가지 역할을 동시에 수행하므로, 착용 기하가 바뀌거나 스티어링 각도를 변경할 때 계산 오류 위험이 있다. 사실 B(HW p.445): 1/8 스큐는 decimation WDF 시분할 스케줄러가 고정적으로 발생시키는 것으로 빔포밍 지연과 물리적 원인이 다르므로 개념적 분리가 타당하다.

## 수렴 결론
**수렴 결론: 포함론(ch2 단독 설정 INT=6, FRAC=14) 채택 — 단, 착용 기하 재확인 선행 필수**

두 방식의 물리적 최종 효과는 수학적으로 동일하다. 고유 스큐(ch2 선도 +0.125 샘플)는 HW에서 고정 발생하므로 어느 방식이든 순 채널 간 지연 차이는 0.808(레지스터) + 0.125(고유) = 0.933 샘플로 수렴한다.

**실용 결정**: 포함론이 구현 우위. 이유는 세 가지다.
① 레지스터 변경 최소 — ch1=0 유지, ch2만 INT=6/FRAC=14 설정으로 완결. 상쇄론은 ch1·ch2 양쪽에 설정 필요.
② HW 범위 충족 확인 — 0.808 샘플 < DELAY_INTEGER 최대 0.875 샘플(사실 G), 1채널 레지스터로 커버 가능. 상쇄론에서 ch1에 INT=7+FRAC=14(0.933 샘플)를 적용해도 범위(최대 0.9958) 내이지만 레지스터 설정이 2채널로 분산된다.
③ 현재 1-DMIC→2-DMIC 전환 시 추가되는 ch2에만 새 설정을 집중할 수 있어 회귀 위험이 없다.

**결정적 전제 조건(미해결 잔존)**: 포함론이 성립하려면 "Left(DMIC2/ch2)가 정면 음원에 먼저 노출"되는 착용 기하가 확정되어야 한다. 반대로 Right(DMIC1/ch1)가 앞인 경우, ch1에 0.933+0.125=1.058 샘플이 필요하며 DELAY_INTEGER 최대(0.875)를 초과하므로 SW 1샘플 버퍼 오프셋이 추가로 필요하다. 현재 상태 정리 및 복기.md의 "DMIC2[1]==DMIC1[0]" 기술이 Left=앞을 강하게 지지하므로 포함론을 잠정 채택하되, 물리 착용 방향 재확인 후 최종 확정할 것. RE/FE 에지 차이(DMIC 클럭 반주기 ≈130ns = 0.002 샘플)는 FRAC 1 LSB(0.26µs) 미만이며 CIC 필터 통과 후 흡수되므로 별도 보정 불필요(사실 E, HW §18.2 p.563).
