# [단계3·검증 27] 2cm·16kHz에서 필요한 상대 지연은 0.933 샘플(58.3µs)이다

**판정**: `CONFIRMED`

## 근거
물리 산술을 직접 재현한 결과 주장은 수치적으로 정확하다(반올림 범위 내).

정확값: d·fs/c = 0.02 × 16000 / 343 = 0.932945 샘플. 이를 소수점 3자리 반올림하면 0.933 — 주장과 일치. 시간으로는 d/c = 58.309µs이며 소수점 1자리 반올림 58.3µs — 주장과 일치.

단, "정확값"이라는 표현에는 미세한 오해 소지가 있다. 사실 F는 58.3/62.5 = 0.933으로 기술하나, 58.3µs 자체가 이미 반올림된 중간값이므로 58.3/62.5 = 0.9328이 된다(원본 정확값 0.932945와 0.000145 샘플 = 0.009µs 차이). 이 오차는 실용적으로 무시 가능하다.

데이터시트 근거(사실 F, §5): 음속 343m/s·간격 2cm·샘플주기 62.5µs를 모두 그라운딩 문서가 명시적으로 출처 확인하였고, 계산 결과가 주장과 일치한다. DELAY_INTEGER_7(7/8=0.875샘플) + DELAY_FRACTIONAL로 0.933에 도달 가능하다는 추론(사실 D·G)도 수치적으로 정합하다.

## 데이터시트 근거
사실 F (조사_데이터시트-그라운딩.md §5): d/c = 0.02/343 = 58.3µs, 샘플주기 62.5µs, 필요지연 58.3/62.5 = 0.933 샘플. 직접 계산: d·fs/c = 0.02×16000/343 = 0.932945 샘플 → 소수점 3자리 반올림 0.933 (오차 0.000055 샘플). 사실 D (HW p.450-451): DELAY_INTEGER 최대 7/8=0.875, DELAY_FRACTIONAL로 서브-1/8 미세조정 가능. 사실 G: 단일 DEC delay 최대 7/8 < 0.933이지만 fractional 병행 시 도달 가능.
