# [단계1·분석 08] 타이밍 산술 분석가 — E8300 빔포밍 지연 산술 전문 분석

**신뢰도**: high

## 결론
16kHz=62.5µs, 1샘플=2.1438cm, 필요지연 0.932945샘플=58.309µs 모두 정확히 검산됨. FRAC 해상도 0.2604µs (1/240샘플), DELAY_INTEGER=7+FRAC=14로 0.9333샘플 달성 시 양자화 오차 0.0243µs. 온도 0→40°C 구간에서 4.12µs 변동이 발생해 양자화 오차의 약 169배에 달하므로, 음속 오차가 지연 정확도의 지배적 오차원임.

## 발견(근거)
- **T_sample = 62.5µs 정확히 성립**
  - 근거: 1/16000 Hz = 62.5000µs. 소수점 오차 없음. (기본 산술)
- **1샘플 = 2.1438cm (343m/s 기준)**
  - 근거: 343 m/s × 62.5µs = 0.021438m = 2.1438cm. 사실F의 '2.14cm'는 반올림값으로 정확함. (사실 F)
- **필요지연 = 0.932945샘플 = 58.309µs (단순근사 '0.933' 충분히 정확)**
  - 근거: tau = d/c = 0.02/343.0 = 58.3090µs. 샘플수 = 58.309/62.5 = 0.932945. 사실F의 '0.933' 표기는 소수점 6자리까지 정확한 근사. (사실 F)
- **SFCR = 29 (정확값, 근사 없음)**
  - 근거: SFCR = round(3.84MHz / 8 / 16kHz) - 1 = round(30.000) - 1 = 29. f_adcclk/8/f_sample이 정확히 30.0이므로 반올림 오차 없음. (사실 D, HW p.450)
- **FRAC 해상도 = 0.2604µs/LSB (1/(8×30)샘플)**
  - 근거: 1 FRAC LSB = T_sample / (8 × (SFCR+1)) = 62.5µs / 240 = 0.260417µs. 사실D의 '≈0.26µs' 확인. (사실 D, HW p.450-451)
- **DELAY_INTEGER=7, DELAY_FRACTIONAL=14 설정으로 0.932945샘플에 도달 가능**
  - 근거: INT=7 → 7/8 = 0.875샘플(54.6875µs). 잔여 = 0.932945-0.875 = 0.057945샘플 = 3.6215µs. FRAC = 3.6215/0.2604 = 13.91 → 14. 달성값 = 0.875 + 14/240 = 0.933333샘플 = 58.3333µs. (사실 D, G, HW p.450-451)
- **양자화 오차 = +0.0243µs (+0.000389샘플), FRAC 반올림 0.09 LSB**
  - 근거: 달성 0.933333샘플 - 목표 0.932945샘플 = +0.000389샘플 = +0.0243µs. 0.09 LSB 이하로 무시 가능 수준. (사실 D)
- **채널 오프셋 1/8샘플 보정 시: ch1(Right/DMIC1)에는 INT=6, FRAC=14 적용 필요 (INT=7 불가)**
  - 근거: 사실B: ch2(DMIC2/Left)가 ch1(DMIC1/Right)보다 1/8=0.125샘플 먼저 도착. end-fire에서 ch1을 지연해야 하는 경우, 순수 필요 지연 0.932945에서 1/8 선행분을 빼면 ch1 DEC delay = 0.807945샘플 = 50.497µs. INT=7(0.875) 초과→사용 불가. INT=6(0.75) + FRAC=14(=0.05833샘플) = 0.80833샘플, 오차 +0.0243µs. (사실 B, D, HW p.222, p.445)
- **DMIC FE/RE 오프셋(사실E)는 데시메이션 후 0.002083샘플 = 0.130µs로 무시 가능**
  - 근거: DMIC CLK 반주기 = 1/(2×3.84MHz) = 0.1302µs = 0.002083샘플. 1/8샘플(7.8125µs) 대비 1.67% 수준. 데시메이션 필터 통과 후 CIC 위상 응답에 흡수됨. (사실 E, HW §18.2 p.563)
- **온도 0→40°C 구간에서 필요지연 4.12µs(=15.8 FRAC LSB) 변동 발생**
  - 근거: c(T) ≈ 331.3+0.606T [m/s] 적용. 0°C: c=331.30m/s → tau=60.368µs(0.9659샘플). 40°C: c=355.54m/s → tau=56.253µs(0.9000샘플). 차이 = 4.116µs = 15.8 FRAC LSB. 양자화 오차(0.0243µs)의 169배. (사실 F)
- **음속 기준값 선택(343 vs 343.42)에 따른 목표샘플 차이는 0.001141샘플 = 0.071µs**
  - 근거: c=343.0m/s(표준 교과서값) → 0.932945샘플. c=343.42m/s(20°C 공식값) → 0.931804샘플. 차이 0.001141샘플 = 0.071µs = 0.27 FRAC LSB. 실용적으로 무시 가능. (사실 F)

## 미해결 질문
- 채널 오프셋 방향 확인 필요: 사실B는 ch2(Left)가 ch1(Right)보다 '1/8샘플 먼저' 도착한다고 하나, 실제 빔포밍 목표 방향(end-fire 좌/우 구분)에 따라 ch1을 지연할지 ch2를 지연할지가 달라짐. 현재 firmware 의도(어느 방향을 forward로 정의하는가)를 확인해야 최종 레지스터값이 결정됨.
- 사실B/C 상호작용 미확인: 사실C(HW p.219)에서 'fractional delay 변경이 ADC 입력 간 동기화에 영향을 준다'고 명시. DEC delay 레지스터를 ch1에만 적용할 때 ch2의 1/8샘플 선행이 그대로 유지되는지, 아니면 상대적 위상이 재정렬되는지 HW 동작 상세 확인 필요.
- 온도 보상 전략 미정: 0→40°C 구간 4.12µs(15.8 LSB) 변동은 FRAC으로 충분히 커버 가능(FRAC 최대 29 LSB). 단, 온도 센서 없이 고정 레지스터값을 쓸 경우 최악 온도 조건에서 빔 방향이 최대 ~3.3° 틀어질 수 있음 (sin(err) = 4.12µs × c / d 관계). 허용 오차 정의 필요.
- DMIC2(ch2)가 QCC 담당에서 E8300으로 이관될 때 CLK 공유 제약 영향: 사실에서 '클럭 1개만 설정 가능(DIO22 공유)'로 명시. DMIC2의 DEC delay 레지스터를 독립 제어할 수 있는지(CLK 공유와 레지스터 독립성 여부) 확인 필요.
