# [단계3·검증 30] DMIC2(FE)/DMIC1(RE) 반주기 스큐는 출력 샘플 대비 무시 가능하다

**판정**: `CONFIRMED`

## 근거
반주기 스큐의 물리량: f_adcclk=3.84MHz(사실 D, HW p.450) → DMIC 클럭 주기 260.4ns → 반주기=130.2ns=0.1302µs. 출력 샘플 주기(16kHz)=62.5µs. 스큐/샘플주기=0.002083(0.208%). 빔포밍 최대 필요 지연 58.31µs(사실 F) 대비 0.22%. 8kHz 주파수 성분 위상 오차=0.375°. 채널쌍 고유 1/8샘플 스큐(사실 A/B, HW p.222·p.445)=7.8125µs의 1/60 규모로 오차 예산 내 지배적 항목이 아님. DELAY_FRACTIONAL 1step=0.2604µs(사실 D, SFCR=29)보다도 작아 HW 레지스터 보정 최소 단위 미만이지만 잔류 오차 역시 동일 0.002083 샘플에 그침. CIC 선형 위상 특성(사실 E, HW §18.2 p.563)상 위상차가 출력에 선형 전달되나 크기 자체가 1/480 샘플로 고정적. 반증 각도(빔포밍 민감도·HW 보정 가능성·다른 오차 소스 비교) 모두 주장을 지지. 단, 스큐가 FRACTIONAL 1step의 정확히 0.5배이므로 HW로 정밀 보정 불가라는 점은 주의사항이나 반증은 아님.

## 데이터시트 근거
HW p.222(사실 A): 채널쌍 1/8샘플 스큐 명시. HW p.445 §14.4(사실 B): decimation 시분할 짝수/홀수 쌍. HW p.450-451(사실 D): DELAY_FRACTIONAL SFCR=29 → 1step=0.2604µs. HW §18.2 p.563(사실 E): DMIC RE/FE 엣지 캡처 + CIC 6차 Sync 필터. 계산: 반주기=0.5/3.84MHz=130.2ns=0.002083샘플(출력샘플 62.5µs의 1/480). 채널쌍 스큐 대비 1/60.
