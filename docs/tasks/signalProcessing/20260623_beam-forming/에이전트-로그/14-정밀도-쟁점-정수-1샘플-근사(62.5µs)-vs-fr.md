# [단계2·토론 14] 정밀도 쟁점: 정수 1샘플 근사(62.5µs) vs fractional 0.933샘플 정밀 구현(INT=7+FRAC=14, 58.333µs)

## 찬
**찬(정수 1샘플 근사) 논거**

1. **개념적 단순성**: 1샘플 지연은 CFX DSP에서 FIFO 인덱스 오프셋으로 직관적으로 표현된다. 레지스터 필드(DELAY_INTEGER가 실제로 1/8 샘플 단위임을 혼동하는) 네이밍 함정을 피할 수 있다.

2. **빔 패턴 실용적 차이 미미**: 0° 방향 1kHz 응답은 fractional=1.0000, SW 1샘플=0.9999로 0.01% 차이에 불과하다. 4kHz에서도 0.14% 차이(0.9986 vs 1.0000)이며, 착용형 기기의 실제 착용 변동(수mm)이 유발하는 오차가 훨씬 크다.

3. **온도 맥락에서의 상대적 의미**: 0→40°C 구간 음속 변동으로 필요 지연이 4.12µs(15.8 FRAC LSB) 변동한다. 1샘플 오차(4.19µs=16.1 LSB)와 온도 불확실도(15.8 LSB)가 같은 오더다. 즉 고정 지연값 자체의 정밀도를 높여도 온도에 의한 실용 정확도 한계는 동일하다.

4. **비교 오차의 절대값**: SW 1샘플 오차 4.19µs는 약 0.14cm 거리 해상도 오차다. 2소자 end-fire 어레이에서 이 정도 오차가 실사용 집음 성능에 미치는 영향은 착용 기하 불확실도보다 작다.

## 반
**반(fractional 정밀 구현) 논거**

1. **HW 구조상 정수 1샘플은 구현 불가**: DELAY_INTEGER 최대 7/8=0.875샘플, FRAC 최대 추가 29/240=0.1208샘플 → HW 총 최대 0.9958샘플. 1.0샘플은 HW 레지스터 단독으로 달성 불가능하다(사실 G, HW p.450-451).

2. **정수 1샘플은 과보정(over-delay)**: 목표 0.9329샘플(58.309µs)에 대해 1샘플(62.5µs)은 7.19% 과다, 오차 4.191µs=16.1 FRAC LSB다. fractional 구현(0.9333샘플, 오차 0.024µs=0.09 LSB)에 비해 오차가 172배 크다.

3. **fractional은 구현 난이도가 더 낮다**: INT=7+FRAC=14를 lib_audio_in.h 매크로 3줄 수정으로 완결. SW FIFO 오프셋 방식은 CFX 내 인터럽트 동기화 로직(mic1 플래그 복원)과 FIFO 오프셋 알고리즘 추가가 필요해 변경 범위가 크다.

4. **스큐 보정과 통합 가능**: 고유 스큐 1/8샘플(ch2 선행)을 fractional 지연 설정 내에 흡수 가능하다. ch1에 INT=6+FRAC=14 설정 시 실효 상대 지연 = 0.808333+0.125 = 0.9333샘플로, 스큐 보정과 빔포밍 지연이 레지스터 2개 설정으로 동시 완결된다. SW 1샘플 방식은 스큐 보정을 별도로 처리해야 한다.

5. **레지스터 의미의 명확한 대응**: DELAY_INTEGER 값은 실제로 1/8 샘플 단위다(HW p.450-451 명시). 이를 이해하고 사용하는 것이 HW 스펙의 의도에 부합하며, 이름(INTEGER)과 물리 의미(1/8 샘플)의 혼동 방지를 위한 코드 주석 1줄로 충분하다.

## 수렴 결론
**수렴 결론: fractional 정밀 구현 채택, 단 온도 불확실도 맥락 명기**

데이터시트 근거 기준 다음과 같이 수렴한다.

**확정 판정: fractional 구현(INT=7+FRAC=14) 채택**

근거는 세 가지다.

첫째, HW 구조적 제약: 정수 1샘플(1.0) 자체가 DELAY 레지스터로 표현 불가능하다(최대 0.9958샘플). "정수 1샘플 근사"를 구현하려면 SW FIFO 오프셋이 필수이며, 이는 CFX 코드 변경을 수반해 오히려 구현 복잡도가 높다. fractional 방식은 레지스터 설정만으로 완결(CFX 불변).

둘째, 정밀도: fractional 오차 0.024µs(0.09 FRAC LSB) vs 1샘플 오차 4.19µs(16.1 FRAC LSB). 172배 차이.

셋째, 스큐 통합 처리: 고유 채널 스큐(1/8 샘플)를 fractional 설정 내에서 흡수할 수 있어, **최종 레지스터 설정은 ch1(DMIC1/Right)에 DELAY_INTEGER=6, DELAY_FRACTIONAL=14 단일 설정**으로 결론난다. 이 설정이 달성하는 실효 상대 지연은 0.9333샘플(58.333µs)이며, 목표 0.9329샘플(58.309µs) 대비 양자화 오차 0.024µs다.

**온도 맥락 단서**: 0→40°C 음속 변동으로 최적 지연이 4.12µs(15.8 LSB) 변동한다. 이 불확실도는 fractional 양자화 오차(0.024µs)보다 170배 크므로, 온도 보상이 없는 고정 설정 전제 하에서는 두 방식의 실용 성능 차이가 온도 오차에 가려진다는 찬 측 주장은 맥락상 타당하다. 다만 이 사실은 "정수 1샘플을 채택할 이유"가 아니라 "fractional의 이점이 온도 환경에서 일부 희석된다"는 독립적 관찰이다.

**잔여 미결**: 착용 기하 확정(Left=앞 방향 시나리오가 이미지와 복기 문서에서 강하게 시사되나 물리 재확인 권장), QCC DMIC2 공유 SPI 프로토콜 신규 정의, DMIC2 ch2에 AUDIO_ADC_DEC_CTRL을 ch2 번호로 독립 설정할 때 SYS_SET_ADC_DEC_CTRL(AUDIO,2,...) 경로가 DMIC 채널에 실제로 적용되는지 펌웨어 레지스터 레벨 최종 확인.
