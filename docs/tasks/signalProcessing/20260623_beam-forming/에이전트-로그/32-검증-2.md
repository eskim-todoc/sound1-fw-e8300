# [단계3·검증 32] 2-DMIC 활성화(#elif 분기)로 빔포밍용 2채널 데이터 경로가 성립한다

**판정**: `CONFIRMED`

## 근거
검증 대상 주장을 5개 레이어로 분해해 데이터시트 사실 및 코드와 교차 검증했다.

레이어 1(AUDIO_MUX): LIB_DMIC_AUDIO_MUX_CFG_INPUT_CH_SRC는 #if 분기와 무관한 단일 매크로로 이미 ch1=DMIC1_DATA_RE, ch2=DMIC2_DATA_FE를 선언하며, SYS_AUDIOMUX_CONFIG 호출은 분기 이전 공통 경로(c:101)에서 실행된다. AUDIO_MUX 레벨의 2채널 소스 연결은 분기 여부와 무관하게 항상 설정된다.

레이어 2(IOC→FIFO): LIB_IOC_ADC_CFG_VAL=(IOC_INPUT_CFG_IN1_FA0_0 | IOC_INPUT_CFG_IN2_FA0_1)도 lib_init_audio_in_path_common() 내부(c:58), 즉 분기 이전 공통 경로에서 적용된다. IN2(DMIC2 경로)→FA0_1(MIC1) 매핑은 1-DMIC 구성에서도 레지스터에 존재한다.

레이어 3(DEC filter): 1-DMIC 분기는 SYS_SET_ADC_DEC_CTRL(AUDIO,1,...)만 설정하고 ch2는 미설정. #elif(2-DMIC) 분기에서 SYS_SET_ADC_DEC_CTRL(AUDIO,2,...) + SYS_SET_ADC_CFG(AUDIO,2,...)가 추가되어 ch2 decimation filter가 활성화된다.

레이어 4(DIO 핀): 1-DMIC 분기에서 DIO10/DIO17은 DIO_MODE_DISABLE. #elif 분기에서 DIO17=DIO_MODE_INPUT 활성, DIO->SRC_DMIC_DATA에 DMIC2_DATA_SRC_DIO_17 추가, enable_DMIC()에서 DIO10=DIO_MODE_ADCCLK 출력 — DMIC2 물리 수신 경로가 완성된다.

레이어 5(CLK 동기): 코드 주석 "CLK 설정은 하나만 가능"대로 DMIC_CLK_SRC_DIO_22 단일 소스에서 2-DMIC 분기는 DIO10도 DIO_MODE_ADCCLK으로 구동 → 두 DMIC가 동일 ADCCLK 공급을 받아 HW §18.2(사실 E)의 "ADCCLK와 동일 공칭 주파수여야 동기" 조건 충족.

AUDIO_MUX와 IOC→FIFO는 공통 경로에서 이미 2채널 라우팅으로 준비된 상태이므로, #elif 분기(ch2 DEC filter + DIO17 + DMIC2_DATA_SRC + CLK)가 마지막 물리 연결 고리를 완성하는 구조다. 사실 A/B의 ch1/ch2 간 1/8 샘플 고유 스큐는 데이터 경로 성립과는 독립 — 경로 성립 후 빔포밍 지연 설계에서 다뤄야 할 별도 쟁점이다.

단, 현재 DELAY_INTEGER=0, DELAY_FRACTIONAL=0(h:96-98)이므로 2채널 경로는 성립하나 빔포밍에 필요한 0.933 샘플 상대 지연(사실 F)은 아직 미설정이다. 주장이 "데이터 경로 성립"에 한정되어 있으므로 그 범위 안에서 코드와 데이터시트 사실이 주장을 지지한다.

## 데이터시트 근거
코드 근거 — lib_audio_in.c:101(AUDIO_MUX 공통 설정), c:122-139(#elif 2-DMIC 분기: ch2 DEC filter, DIO17 INPUT, DMIC2_DATA_SRC_DIO_17, DIO10 ADCCLK), lib_audio_in.h:50(IOC→FIFO IN2→FA0_1 공통 매핑), h:80(DMIC2_DATA_FE ch2 매핑). 데이터시트 근거 — HW p.445 §14.4(사실 B: ch1/ch2 짝홀 시분할 1/8 샘플 스큐), HW §18.2 p.563(사실 E: DMIC 입력 ADC와 동일 fractional delay 지원, EXTCLK 동기 조건), HW p.450-451(사실 D: DELAY_INTEGER/FRACTIONAL 채널별 설정).
