# [단계2·토론 18] 채널 재배치: DMIC를 어느 입력채널(1/2/0/3)에 두어야 스큐가 유리한가

## 찬
현재 배치(DMIC1=ch1, DMIC2=ch2) 유지 — 고유 스큐가 빔포밍 지연 예산을 절감하여 HW 단독 구현 가능

근거:
- 사실 A(HW p.222)+사실 B(HW p.445 §14.4): 짝수 채널(0,2)이 홀수 채널(1,3)보다 1/8 샘플(7.81µs) 먼저 출력. 현재 DMIC2(Left, 정면 앞)=ch2(짝수) → DMIC1(Right, 정면 뒤)=ch1(홀수)보다 먼저 도착.
- 착용 기하: Left(DMIC2)가 정면 음원에 먼저 노출 → 늦게 도착하는 Right(DMIC1/ch1)를 지연해야 빔 정합.
- 고유 스큐(ch2가 ch1보다 1/8 선행)는 음향 지연 방향과 동일 부호 → 두 효과가 같은 방향으로 작용하여 ch1 필요 추가 지연량이 0.933 - 0.125 = 0.808 샘플로 감소.
- 0.808 샘플은 DELAY_INTEGER=6(0.75) + DELAY_FRACTIONAL=14(≈0.058샘플) = 0.808샘플로 HW 단독 달성 가능. 최대값 7/8=0.875 이내.
- SW 버퍼 시프트 0건, CFX DSP 루프 변경 최소화.

## 반
반배치(DMIC1=ch2, DMIC2=ch1) — 고유 스큐가 빔포밍 지연 예산을 증대시켜 HW 한계 초과

근거:
- 반배치 시 DMIC1(Right, ch2=짝수)가 DMIC2(Left, ch1=홀수)보다 1/8 샘플 먼저 FIFO 도착.
- 그러나 착용 기하상 Left(DMIC2)가 정면에 먼저 닿아야 함 → 이제 ch1(DMIC2/Left)이 1/8 늦게 출력 → 원하는 방향(Left 앞섬)과 반대로 스큐가 작용.
- 보정 필요: ch2(DMIC1/Right)가 이미 1/8 먼저 도착하므로 ch2를 음향 지연(0.933샘플) + 스큐 보정(0.125샘플) = 1.058샘플 지연해야 정합 달성.
- 1.058 샘플은 DELAY_INTEGER 최대 7/8=0.875 샘플을 초과(사실 G) → HW 단독 구현 불가.
- SW 버퍼 1샘플 정수 오프셋 + HW FRAC 조합 필요 → 구현 복잡도 증가, 루프 레이턴시 +1 샘플(62.5µs) 추가.

## 수렴 결론
현재 배치(DMIC1=ch1/홀수, DMIC2=ch2/짝수) 유지가 스큐 측면에서 최적이며 변경 불필요.

핵심 논거:
1. 스큐 방향 일치: 착용 기하(Left=앞 먼저 도달)와 HW 고유 스큐(ch2=짝수 먼저 출력)의 방향이 동일하여 고유 스큐 1/8 샘플이 빔포밍 지연 예산을 자연 흡수한다.
2. HW 단독 구현 가능: ch1에 DELAY_INTEGER=6 + DELAY_FRACTIONAL=14 (= 0.808 샘플 = 50.5µs) 설정만으로 SW 버퍼 없이 end-fire 정합 달성. 양자화 오차 0.024µs.
3. 반배치의 페널티: 반대로 배치하면 필요 지연이 1.058 샘플로 DELAY_INTEGER 최대(7/8=0.875)를 초과 → SW 1샘플 오프셋 필수, CFX 루프 레이턴시 +62.5µs 증가.
4. RE/FE 에지 오프셋(DMIC1=RE, DMIC2=FE, 반주기=130ns)은 출력 샘플 62.5µs 대비 0.002 샘플로 빔포밍 해상도(0.26µs/step)보다 작아 무시 가능.

잔여 불확실성:
- 착용 기하(Left=앞) 전제가 반드시 물리 재확인되어야 한다. 만약 Right가 정면이면 부호가 역전되어 반배치가 유리해지고 현재 배치가 HW 한계 초과 구성이 된다.
- DMIC2(ch2)가 DMIC 경로에서도 정확히 ADC ch2와 동일한 1/8 선행 스큐를 갖는지 데이터시트 직접 확인 권고(사실 B는 ADC 기준 기술).
- 2-DMIC 활성화 시 QCC DMIC2 공유 충돌(DIO10/DIO17) 해소가 채널 배치 결정과 독립적으로 선행 요구됨.
