# [단계1·분석 04] 샘플링 지연 레지스터 분석가

**신뢰도**: high

## 결론
DELAY_INTEGER(0~7, 1/8 샘플 단위) × DELAY_FRACTIONAL(0~29, 1/240 샘플 단위)의 조합으로 총 240 단계, 0~0.9958 샘플(0~62.24 µs)의 지연을 최소 0.2604 µs 해상도로 생성 가능하다. End-fire 빔포밍 목표값(58.31 µs = 0.9329 샘플)은 INTEGER=7, FRACTIONAL=14로 58.33 µs에 도달하며 오차는 목표 대비 0.024 µs(0.09 fractional step)에 불과해 레지스터 설정만으로 end-fire 전 각도 범위 커버가 가능하다. 채널 간 1/8 샘플 하드웨어 오프셋(Fact B)은 한쪽 채널에 DELAY_INTEGER=1을 적용하거나 fractional로 상쇄하는 방식으로 정밀 보정 가능하다.

## 발견(근거)
- **SFCR = 29 (fractional 단계 수 = 30)**
  - 근거: SFCR = round(f_adcclk / 8 / f_sample) - 1 = round(3,840,000 / 8 / 16,000) - 1 = round(30.0) - 1 = 29. 따라서 FRACTIONAL 유효 범위는 0~29, 총 30단계. (HW p.450-451 (Fact D))
- **지연 해상도: 1/240 샘플 = 0.2604 µs**
  - 근거: INTEGER 1단계 = 1/8 샘플 = 7.8125 µs. FRACTIONAL은 그 1/8 샘플을 30분할 → 1/(8×30) = 1/240 샘플 = 62.5 µs / 240 = 0.2604 µs/step. (HW p.450-451 (Fact D))
- **총 지연 범위: 0 ~ 0.9958 샘플 (0 ~ 62.24 µs), 240 단계**
  - 근거: 최솟값: INT=0, FRAC=0 → 0. 최댓값: INT=7 → 7/8 샘플 + FRAC=29 → 29/(30×8) = 29/240 샘플. 합계 = (7×30+29)/240 = 239/240 = 0.99583 샘플 = 62.24 µs. 총 distinct 상태 = 8 × 30 = 240. (HW p.450-451 (Fact D))
- **End-fire 빔포밍 목표(58.31 µs)는 INT=7, FRAC=14로 0.024 µs 오차 내 달성 가능**
  - 근거: 목표 = d/c = 0.02/343 = 58.3090 µs = 0.93294 샘플. INT=7 기여 = 7/8 샘플 = 54.6875 µs. 잔여 = 0.05795 샘플. FRAC 필요값 = 0.05795 × 240 = 13.91 → 14로 반올림. 총 = (7×30+14)/240 = 224/240 = 0.93333 샘플 = 58.3333 µs. 오차 = 0.0243 µs = 0.093 fractional step. (Fact F (기하 산술) + Fact D (레지스터 스펙, p.450-451))
- **DELAY_INTEGER 최대 7/8 샘플이지만 빔포밍 목표(0.933 샘플)는 단일 레지스터로 충족 가능**
  - 근거: DELAY_INTEGER 단독 최대 = 7/8 = 0.875 샘플 < 목표 0.933 샘플. 그러나 FRACTIONAL(최대 29/240 = 0.1208 샘플 추가)과 결합하면 0.9958 샘플까지 도달 가능. INT=7+FRAC=14로 목표 커버 확인. (Fact G + Fact D (p.450-451))
- **채널 간 독립 설정으로 상대 지연 생성 가능 — 1/8 샘플 하드웨어 오프셋 보정도 포함**
  - 근거: AUDIO_ADC_DEC_CTRL는 채널별 독립 레지스터(Fact D). 사실 B: ch2(DMIC2/Left)가 ch1(DMIC1/Right)보다 1/8 샘플(7.8125 µs) 먼저 도착. ch2에 DELAY_INTEGER=1을 가산하면 하드웨어 오프셋 상쇄. 이후 양 채널에 차등 설정을 더해 임의 상대 지연(0~0.9958 샘플) 생성 가능. (HW p.445 §14.4 (Fact B) + p.450-451 (Fact D))
- **DMIC FE/RE 클럭 에지 오프셋(130 ns)은 샘플레이트 기준으로는 미미 — fractional로 흡수 가능**
  - 근거: ADCCLK=3.84 MHz → 반주기 = 130.2 ns = 0.00208 샘플(16 kHz 기준). 1 fractional step = 0.2604 µs이므로 130.2 ns ≈ 0.5 fractional step. 보정이 필요하다면 FRACTIONAL ±1로 흡수 가능하나, 오버샘플링 후 CIC 필터를 통과하면 에지 오프셋이 phase shift로 변환되어 샘플레이트 레벨 영향은 매우 작음. (HW §18.2 p.563 (Fact E))
- **현재 펌웨어(INT=0, FRAC=0)는 지연 보정 전무 — 채널 오프셋 1/8 샘플이 미보정 상태로 존재**
  - 근거: 현재 DELAY_INTEGER=0, DELAY_FRACTIONAL=0 (현재 펌웨어 구성). Fact B에 의해 ch2(DMIC2)가 ch1(DMIC1)보다 1/8 샘플 먼저 출력되고 있으나 레지스터 레벨 보정이 없음. (현재 펌웨어 구성 + HW p.445 §14.4 (Fact B))

## 미해결 질문
- DELAY_FRACTIONAL의 물리적 동작이 '1/8 샘플 내부를 균등 30분할'인지, 아니면 다른 비선형 매핑인지 데이터시트에 수식이 명시되어 있는가? (p.450-451 외 보충 설명 필요)
- DMIC 입력에도 AUDIO_ADC_DEC_CTRL의 DELAY_INTEGER/FRACTIONAL이 실제로 적용되는지 레지스터 맵에서 DMIC 채널 매핑이 명확히 확인되었는가? (Fact E는 'ADC와 동일하게 지원'이라 하나 레지스터 주소 레벨 확인 필요)
- 현재 보드에서 DMIC1(ch1, RE)과 DMIC2(ch2, FE)의 IOC→FIFO 매핑이 AUDIO_ADC_DEC_CTRL 채널 번호와 1:1 대응하는지 확인 필요 (IN1→FA0_0, IN2→FA0_1 경로상 채널 인덱스 일치 여부)
- 빔포밍 방향 설정을 동적으로 변경할 때 레지스터 write 후 settling time(필터 flush latency)이 문서에 명시되어 있는가? 실시간 스티어링 가능 여부에 영향.
