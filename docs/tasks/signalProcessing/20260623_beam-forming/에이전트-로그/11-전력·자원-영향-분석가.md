# [단계1·분석 11] 전력·자원 영향 분석가 — 2nd DMIC/ADC/decimation 활성화 비용 전문 분석

**신뢰도**: medium

## 결론
2번째 DMIC(DMIC2, ch2) 활성화는 E8300 내부 decimation 필터 1개·ADC_CFG 레지스터 1개·DIO 드라이버 2개(CLK2·DATA2) 추가 활성화를 수반하며, FIFO FA0_1과 CFX 인터럽트는 이미 현재 펌웨어에서 설정 완료 상태이다. 클럭(ADCCLK 3.84MHz)은 공유 단일 소스이므로 추가 발생하지 않는다. 전력 비용은 decimation 필터 디지털 로직과 U9 DMIC 센서 자체 소비 전류가 전부이며, 절대값 수치는 데이터시트에 명시되지 않아 정량화 불가능하다.

## 발견(근거)
- **ADCCLK 3.84MHz는 DMIC1·DMIC2 공유 단일 소스(DIO22) — 2-DMIC 전환 시 클럭 추가 비용 없음**
  - 근거: lib_audio_in.c L120: `DIO->SRC_DMIC_CLK = DMIC_CLK_SRC_DIO_22` (공통). L138도 동일 소스 유지. lib_audio_in.h L119 주석: '클럭 설정은 하나만 가능(DMIC_CLK1/CAL을 기본으로 사용)'. 2-DMIC 경로에서 DIO10(CLK2)을 ADCCLK 출력으로만 추가 설정(L154), 동일 3.84MHz 분기 드라이브 1개 증가. (현재 펌웨어 lib_audio_in.c L119-139, lib_audio_in.h L23-24)
- **추가로 활성화되는 HW 블록: decimation 필터 ch2 1개(SYS_SET_ADC_DEC_CTRL ch2), ADC_CFG ch2 1개(SYS_SET_ADC_CFG ch2), DIO 드라이버 2개(DIO10 ADCCLK 출력 + DIO17 입력)**
  - 근거: 2-DMIC 분기(lib_audio_in.c L122-139): 1-DMIC 대비 추가 호출은 `SYS_SET_ADC_CFG(AUDIO,2,...)` L125, `SYS_SET_ADC_DEC_CTRL(AUDIO,2,...)` L129, `Sys_DIO_Config(DIO10, DIO_MODE_INPUT)` L134(configure) + `Sys_DIO_Config(DIO10, DIO_MODE_ADCCLK)` L154(enable), `Sys_DIO_Config(DIO17, DIO_MODE_INPUT)` L135. 이상 5호출이 1-DMIC 대비 순증분. (lib_audio_in.c L106-158)
- **FIFO FA0_1(MIC1)과 CFX 인터럽트 INT_A0_1은 1-DMIC 현재 펌웨어에서도 이미 설정 완료 — 2-DMIC 전환 시 추가 비용 없음**
  - 근거: lib_audio_in.h L50: `IOC_INPUT_CFG_IN2_FA0_1` (IN2→FA0_1 매핑 상시 설정됨). lib_audio_in.c L50: `SYS_FIFO_CFXINTCONFIG(1, FIFO_INT_A0_1)` (MIC1 인터럽트 상시 설정됨). L64: `FIFO_A0_1_DBL_ACC_EN` (double-access 상시 설정됨). 1-DMIC 분기(L106)에서도 이 설정들은 `lib_init_audio_in_path_common()`을 통해 실행된다. (lib_audio_in.c L41-67, lib_audio_in.h L50, 60)
- **decimation 필터 ch2 추가는 HW time-multiplex 엔진 부하 증가 — 단 짝수 채널(0,2) 쌍 내 처리이므로 기존 ch1(홀수)과 독립 레인**
  - 근거: 사실 B(HW p.445 §14.4): '4 ADC 입력은 두 쌍(ch0,1)·(ch2,3)으로 time-multiplexed'. ch1은 홀수 쌍 처리, ch2는 짝수 쌍 처리. DMIC2(ch2)는 짝수 레인에 합류하므로 ch1 처리 타이밍에 직접 경쟁하지 않는다. 단 짝수 레인(ch0·ch2) 내부 처리량은 기존 ch0(ADC0, 현재 NONE으로 매핑됨)와 공유 — ch0 실제 활성 여부에 따라 레인 포화 가능성 존재. (사실 B (HW p.445 §14.4), lib_audio_in.h L70 LIB_ADC_AUDIO_MUX_CFG_INPUT_CH_SRC)
- **U9 DMIC 센서 자체 소비 전류 및 DIO10 ADCCLK 출력 드라이버 전류가 실질 전력 증가의 주요 원인 — E8300 내부 decimation 디지털 로직 추가분은 2차적**
  - 근거: 사실 E(HW §18.2 p.563): DMIC는 6th-order Sync(CIC) pre-decimation 필터이며 ADC와 동일한 decimation factor 적용. 디지털 CIC는 낮은 정적 전력을 가지나, U9 물리 DMIC 센서 전원은 별도 VCC 계통. DIO10을 DIO_MODE_ADCCLK로 설정하면(enable_DMIC L154) 3.84MHz 클럭 출력 드라이버가 상시 스위칭 — 이 DIO 드라이버 동적 전력이 측정 가능 수준의 전력 증가를 초래할 가능성이 높다. (사실 E (HW §18.2 p.563), lib_audio_in.c L154)
- **IOC ch2 매핑(IN2→FA0_1)은 오디오 MUX에 DMIC2_DATA_FE가 ch2 소스로 항상 설정되어 있어 데이터 경로는 이미 준비됨 — 2-DMIC 전환은 DEC_CTRL 활성화와 DIO 설정 변경만으로 완결**
  - 근거: lib_audio_in.h L80-84: `LIB_DMIC_AUDIO_MUX_CFG_INPUT_CH_SRC = (ADC3_OUT | DMIC2_DATA_FE | DMIC1_DATA_RE | ADC0_OUT)` — DMIC2_DATA_FE가 ch2 소스로 선언됨. lib_audio_in.c L101: `SYS_AUDIOMUX_CONFIG(AUDIO, LIB_DMIC_AUDIO_MUX_CFG_VAL)` — 1-DMIC 분기(L106)에서도 이 MUX 설정이 먼저 실행된다. 즉 MUX 레벨에서 DMIC2는 이미 연결되어 있으며 DEC_CTRL 비활성과 DIO 비활성만이 차단 요소. (lib_audio_in.c L99-117, lib_audio_in.h L80)
- **CFX DSP 처리 부하: MIC1(FA0_1) FIFO 인터럽트는 상시 설정되어 있으나, 실제 CFX 코드가 MIC1 데이터를 처리하는지는 현재 코드에서 확인 불가 — 빔포밍 알고리즘 추가 시 CFX 사이클 소모가 핵심 부하**
  - 근거: lib_audio_in.c L50: `SYS_FIFO_CFXINTCONFIG(1, FIFO_INT_A0_1)` 상시 설정. microcode.h L23-26: HEAR_MIC1_FIFO_START_ADDR_BIAS=32, SIZE=32 — MIC1 FIFO는 정의됨. 그러나 CFX 알고리즘 코드(delay-and-sum 등)가 실제 MIC1 데이터를 소비하는 연산을 수행하는지 여부는 CFX 마이크로코드(.hct 원본) 내부 분기 확인 없이는 판단 불가. (lib_audio_in.c L50, microcode.h L23-26)

## 미해결 질문
- U9(DMIC2) 물리 센서의 공급 전류(IDD) 수치: 데이터시트에 명시되지 않았으므로 U9 부품 데이터시트 직접 확인 필요.
- E8300 decimation 필터 1채널 추가 활성화에 따른 전류 증가분: HW 데이터시트에 채널별 전력 분리 수치 미제공. ON Semi 전력 계산 툴 또는 전류 측정 없이 정량 불가.
- DIO10 ADCCLK 출력 드라이버(DIO_1X_DRIVE, 3.84MHz)의 동적 전력: 부하 커패시턴스(PCB 배선·U9 CLK 입력 핀 용량)에 따라 달라지며 회로도·레이아웃 데이터 없이 산정 불가.
- 현재 CFX 마이크로코드(microcode.hct 원본)가 MIC1(FA0_1) 데이터를 실제 소비하는지 여부: FIFO 인터럽트는 설정되어 있으나 CFX 알고리즘 처리 여부 미확인 — 빔포밍 알고리즘 추가 시 CFX 사이클 예산 영향 판단에 필요.
- ch0(ADC0)의 현재 활성 상태: LIB_DMIC_AUDIO_MUX_CFG_INPUT_CH_SRC에서 ADC0_OUT이 ch0 소스로 선언되어 있으나, SYS_SET_ADC_CTRL ch0 활성화 호출이 없어 ch0이 실제 활성인지 불명확. DMIC2(ch2)가 짝수 레인에 합류할 때 ch0과의 time-multiplex 경합 존재 여부에 영향.
