## 완료 요약 (2026-06-23)

### 결론 — 은수님 두 핵심 가설 모두 데이터시트로 확인 ✅

1. **입력 패스 채널 간 고유 지연 존재**: decimation 시분할로 **짝수 채널(ch0·2)이 홀수(ch1·3)보다 1/8 샘플(7.81µs) 선행** (HW p.222·445). 은수님의 "채널 0,2 동시 / 1,3 동시" 가설 방향·구조 정확.
2. **SW 시프트 없이 HW 내부 샘플링 지연 가능**: `AUDIO_ADC_DEC_CTRL`의 `DELAY_INTEGER`(1/8 샘플 단위, 0~7/8) + `DELAY_FRACTIONAL`(0~SFCR, 1/240 샘플 해상도)로 채널별 독립 부여. DMIC도 ADC와 동일 지원(HW p.563).

### 핵심 통찰

- 2cm·16kHz end-fire 필요 지연 = **0.933 샘플(58.3µs)**. HW로 0.024µs 오차 내 구현.
- **고유 스큐는 보정 자산** — front mic을 **홀수 채널**에 배치하면 필요 레지스터 지연이 **0.808 샘플(`INT=6, FRAC=14`)**로 HW 단독 범위.
- **지연 대상 = front mic**, 착용 귀(Left/Right)에 따라 DMIC1/DMIC2로 바뀜 → 귀별 설정 필요.
- RE/FE 반주기 스큐(0.13µs) 무시 가능. WDF bulk group delay는 동일대역 상쇄.

### 남은 변수 (후속 작업)

- AUDIO_MUX 임의 DMIC→채널 재배치 가능성, 착용 귀 식별 소스, QCC DMIC2 공유 정책.
