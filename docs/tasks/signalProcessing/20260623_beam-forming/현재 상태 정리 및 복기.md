* **I2S_FLAG** (DIO29)가 **1이면 QCC로부터 I2S 신호 입력**되는 상태. I2S: E8300 ← QCC
* QCC가 E8300으로 I2S 신호를 입력하는 경우는 **3가지 상황**이 있음.
	* 1. **핸드폰 BT** 클래식 연결 (미디어)
	* 2. **크래들 BT** 클래식 연결 (마이크)
	* 3. **전화 통화** 시 오디오 신호
* 여기서 전화 통화 시 상황이 중요함. **전화 통화 시 QCC가 DMIC2를 사용**함.
* 문제는 E8300 입장에서 **I2S_FLAG 만으로는 I2S가 어떤 상황을 위해 사용되는지 알 수 없음**.
	* 문제 해결을 위해 QCC에서 전화 통화를 위해 **DMIC2를 사용한다는 SPI 프로토콜이 필요함**
	* 또한 SPI 프로토콜 **명령 처리에 대한 대기 시간**도 필요함. (**10msec 이내**로 예상)
