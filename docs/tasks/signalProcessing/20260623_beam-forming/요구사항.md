# 빔포밍 구현 타당성 — 요구사항

**TL;DR**: 현재 cfx가 DMIC 1개만 쓰는 상황에서 2개(U7 Right·U9 Left, 각 귀 앞 방향)로 빔포밍 구현 요구가 들어왔다. 물리 간격 2cm·16kHz 샘플링에서 약 1샘플 지연으로 end-fire 빔포밍이 성립한다는 가설을 데이터시트로 검증하고, **(1) 입력 패스의 채널 간 고유 지연 유무**와 **(2) SW 버퍼링 없이 HW 내부 샘플링 지연을 줄 수 있는지**를 이론적으로 분석한다.

---

## 1. 배경

- 현재 cfx 프로젝트는 **DMIC 1개만 사용** (`lib_audio_in.h`의 `LIB_AUDIO_IN_DMIC_ENABLE_COUNT == 1`).
  - 보드에는 마이크가 **물리적으로 2개** 실장 — 원래 QCC 측 1개, E8300 측 1개 분담 의도.
- 마이크 구성 (`Sound1 마이크 위치.png`, `착용 시 앞 방향 마이크 위치 정보.png`):
  - **U7 = DMIC1** — CLK1/CAL(DIO22), OUT1(DIO23) — **Right ear, Front mic**, E8300 담당.
  - **U9 = DMIC2** — CLK2(DIO10), OUT2(DIO17) — **Left ear, Front mic**, 원래 QCC 담당.
- 빔포밍 구현 요구가 신규 인입.

## 2. 핵심 가설 (은수님 제시)

- 실제 제품에서 두 마이크 **물리 거리 ≈ 2cm**.
- E8300 DMIC 입력 샘플링 주기를 고려할 때 **딱 1샘플 오차**를 두면 빔포밍이 성립한다는 분석.
  - 예: `DMIC2[1] == DMIC1[0]` (앞 방향 마이크 샘플을 1개 느리게).
- 우려: E8300 오디오 입력 패스에 **경로별 입력 딜레이**가 존재할 가능성.
  - 예시 가설 — "채널 0·2는 동일 시점에 IOC 전달, 채널 1·3은 동일 시점에 IOC 전달" (사실 여부 미확정, 분석 대상).

## 3. 분석 목표 (요구사항)

- [ ] **요구사항_1**: DMIC 2채널이 decimation 필터 → IOC → FIFO를 거치는 경로에서 **채널 간 고유(intrinsic) 지연/스큐가 존재하는지** 데이터시트 기반으로 규명.
- [ ] **요구사항_2**: 오디오 입력 샘플을 SW에서 1개 버퍼-시프트하지 않고, **HW 내부에서 채널별 샘플링 지연을 줄 수 있는지** 규명(가능하면 레지스터·범위·해상도 명시).
- [ ] **요구사항_3**: 2cm·16kHz 기하에서 실제로 필요한 **상대 지연량을 정량 산출**(정확값 vs 정수 1샘플 근사).
- [ ] **요구사항_4**: 현재 1-DMIC 구성에서 2-DMIC 빔포밍 구성으로의 **이론적 전환 방향** 제시(코드 변경은 본 작업 범위 밖, 후속 계획으로만).

## 4. 제약·범위

- 본 작업은 **이론 분석·문서화**에 한정. **제품 소스 코드 변경 없음**(후속 작업에서 별도 승인).
- 모든 결론은 `docs/참고/e8300`의 HW/FW Reference 데이터시트로 **그라운딩**(추측 금지, 페이지 인용).
- 분석 방법: 은수님 지시에 따라 **각 단계 10개 이상 페르소나**로 **분석 → 토론 → 검증** 3단계 오케스트레이션.
