# [분석 10] 빔포밍 성능·지향성 분석가

**신뢰도**: high

## 결론
2-mic 22mm delay-and-sum 구현의 이론적 전후비는 협대역 최적(2.8kHz~)에서 약 6dB, 1kHz 이하에서 2dB 미만으로 급감한다. 현재 구현은 지연 정합 오차 0.0012샘플(0.08µs)로 매우 양호하나, 블록 내 인덱스 순서 미검증이 잠재적 치명 결함이다. white-noise L/R 음량차 관측은 지향성 측정이 아니라 지연 부호 정합 확인 수단이다. 정량 DI 측정은 회전판 스피커 + FFT 밴드 파워 비교 또는 두 마이크 교차상관 방식으로 가능하다.

## 발견(severity·근거)
- **[info]** 이론적 전후비: 주파수 의존 — 1kHz 이하 2dB 미만, 2.8kHz에서 6dB 피크
  - 근거: 2-mic delay-and-sum의 전후비(Front-to-Back Ratio, FBR)는 d=22mm, c=343m/s, 순음 주파수 f에 대해 합산 신호 진폭 비 |H_front/H_back| = |1 + e^{j2π f τ}| / |1 - e^{j2π f τ}| (τ=64.14µs). f=1kHz → τ/T=0.064rad → 진폭비≈2.0dB. f=2kHz → 약 4.0dB. f=1/(2τ)=7.8kHz에서 이론 최대(∞)이지만 실제 DMIC 응답(약 10kHz 유효대역) 내에서 약 6dB plateau는 2.8kHz~7kHz 구간. 22mm는 λ/2 주파수 = 7.8kHz로 16kHz 내에 있어 grating lobe 없음.
- **[info]** 유효 빔포밍 대역: 약 1.5kHz~7kHz. 1kHz 이하 이득 거의 없음
  - 근거: τ=64.14µs 기준 1kHz에서 위상 회전 = 2π×1000×64.14e-6 = 0.403rad = 23.1°. cos(23.1°/2) 합산 이득 ≈ 1.97 → FBR ≈ 2.0dB. 500Hz에서는 1.0dB 미만. 언어 주파수(250~3kHz) 중 1.5kHz 이상만 실질 지향성 기대 가능. 이는 인공와우 대상에서 자음 명료도(2~4kHz) 구간과는 잘 맞지만 모음(250~1kHz) 구간은 개선 없음.
- **[info]** 지연 정합 오차 0.0012샘플(0.08µs) — 무시 가능 수준
  - 근거: 그라운딩: 합계 지연 = HW fractional LIB_ADC_DEC_CTRL_VAL_0_0250(0.025샘플) + SW 1샘플 = 1.025샘플 = 64.06µs. 목표 22mm/343=64.14µs=1.0262샘플. 잔여 오차=0.0012샘플. 이 오차가 유발하는 7.8kHz에서의 위상 오차 = 2π×7800×0.08e-6 = 0.0039rad → FBR 열화 <0.1dB. 실질 영향 없음.
- **[critical]** 블록 내 인덱스 순서(index 0=최신 vs 오래됨) 미검증 — 잠재적 치명 결함
  - 근거: 그라운딩: 믹서 audio_mix_2_buffers_for_beamforming에서 경계 처리 시 p_mix[15] = (no_delay[15] + delay_buf1[0]) >> 1 + 4. delay_buf1은 '직전 블록'이고 index 0을 사용. 만약 index 0=최신이면 delay_buf1[0]은 직전 블록의 최신 샘플 = 현재 블록 직전 샘플 → 정상. 만약 index 0=오래됨이면 delay_buf1[0]은 직전 블록의 가장 오래된 샘플 → 약 15샘플(0.94ms) 추가 오지연 발생 → 신호가 역위상 더하기에 가까워질 수 있음. 그라운딩에 '이 가정의 검증 필요'로 명시. audioMixer.c 실제 FIFO 충전 방향 소스 미확인 상태.
- **[minor]** LIB_ADC_DEC_CTRL_VAL_0_9958 데드코드 — 1.026샘플 달성 불가 경로 잔존
  - 근거: 그라운딩: LIB_ADC_DEC_CTRL_VAL_0_9958(INT=7, FRAC=29 = 7+29/240 = 7.121샘플 오프셋? 혹은 별도 해석)이 정의만 있고 호출 없음. 이 값이 원래 22mm를 HW만으로 근사하려던 시도였다면(HW max ≤0.9958샘플 → 이미 1.026 불가 확인됨), 현재 하이브리드 방식(0.025+1)이 올바른 대안. 다만 데드코드는 향후 혼동 유발 가능. lib_audio_in.h 내 매크로 정의 위치 근거.
- **[info]** white-noise L/R 음량차 관측의 의미: 지연 부호 확인 수단이지 지향성 수치 측정 아님
  - 근거: white noise는 광대역 비상관 신호. delay-and-sum에서 front 방향 입력 시 두 채널은 τ 지연 외 동일 → 가산 시 스펙트럼 의존 FBR. 단순 RMS 음량차 관측으로는: (1) 어느 쪽이 front인지 지연 부호 극성 확인 가능 (정상: front 음량 > back 음량 차이 관측), (2) 지연이 완전 역(back에 지연 부여됨)이면 음량 역전 → 즉각 탐지 가능. 한계: 광대역 평균이라 FBR의 주파수 의존성 숨겨짐. 0dB에 가까운 저주파 비중이 크면 실제 지향성보다 낮게 보임. 정량 지향성 수치(dB/octave 대역별) 측정 불가.
- **[info]** QCC I2S 점유 시 빔포밍 자동 비활성화 — 통화 중 지향성 손실
  - 근거: 그라운딩: normal_loop에서 I2S_FLAG 액티브 시 enable_1_DMIC() 호출. system_control.c 맵변경에서 I2S이면 1-DMIC 고정. PCM_LiveStimulation_Mode에서 I2S 스트리밍이면 audio_mix_2_buffers(빔포밍 아님)로 분기. 즉 BLE 통화 중에는 단일 마이크로 폴백 → FBR=0dB. 사용 시나리오에서 이 trade-off 인지 필요.
- **[minor]** HW fractional 지연이 init 시 0으로 초기화됨 — 맵변경 전 구간 지연 미적용
  - 근거: 그라운딩: init configure_audio_path_all은 ch0/ch2 모두 delay 0 설정. HW fractional(_0_0250)은 system_control.c 맵변경 switch에서만 설정. 즉 부팅 후 첫 맵변경 이전 구간은 SW 1샘플 지연만 적용(HW fractional 0) → 총 지연 = 1.0샘플 = 62.5µs, 목표 64.14µs 대비 1.64µs 오차. 이 구간이 짧으면 무시 가능이나 확인 필요.
- **[info]** 정량 측정 방법 1 — 회전판 스피커 FBR 측정 (권장)
  - 근거: 방법: 무향실 또는 반무향실에서 단일 스피커를 DUT 중심 1m 반경 회전. front(0°)·back(180°)에서 각각 pink noise 또는 1/3 octave swept tone 재생. 빔포밍 출력 RMS를 1/3 octave 밴드별 기록. FBR[f] = 20log10(RMS_front[f]/RMS_back[f]). 기대값: 2kHz→약 4dB, 4kHz→약 6dB. 재현성 확보 위해 SPL 보정 필요(스피커→DUT 거리 일정 유지). 이 수치가 grounding에서 예측된 수 dB 수준과 정합하는지 검증 포인트.
- **[info]** 정량 측정 방법 2 — 두 마이크 교차상관으로 실효 지연 검증
  - 근거: 방법: 빔포밍 적용 전 원시 DMIC0·DMIC2 신호를 RTT/UART로 캡처. GCC(Generalized Cross-Correlation) 또는 단순 시차 추정으로 실효 지연 τ_measured 계산. 목표: τ_measured ≈ 64.14µs. 편차가 1샘플(62.5µs) 이면 HW fractional 미적용 상태, 편차가 ~15샘플이면 블록 인덱스 순서 반전 확인. 이 방법이 블록 내 인덱스 순서 미검증 결함 해소에 직결됨. 구현 비용 낮음(Python numpy.correlate).
- **[info]** 정량 측정 방법 3 — Directivity Index(DI) 추정 (등방 잡음 기준)
  - 근거: 방법: 등방 잡음 근사를 위해 스피커 6~8개로 DUT 사방 배치 또는 단일 스피커 24점 이상 회전 평균. DI[f] = 10log10(G_front[f] / (1/N Σ G_θ[f]). 2-mic DAS 이론 DI 상한 = 10log10(N=2) = 3dB (저주파) ~ d/λ에 따라 변동. 22mm 구성에서 7kHz 근방에서 일시적 고 DI 발생 이론 예측 가능. 실제 측정 시 3~5dB DI 확인되면 구현 정상으로 판단.

## 개선 제안
- 블록 내 인덱스 순서 즉시 검증 필요: FIFO 충전 방향을 lib_audio_in.c DMIC ISR에서 확인하거나, RTT로 단조 증가 tone 캡처 후 index 0이 최신인지 오래됨인지 단정. audioMixer.c 경계 처리(delay_buf1[0]) 정합성 확정 전까지 빔포밍 FBR 수치 신뢰 불가.
- LIB_ADC_DEC_CTRL_VAL_0_9958 데드 매크로를 lib_audio_in.h에서 제거하거나 주석에 '22mm HW-only 불가 확인됨, 하이브리드로 대체' 명시해 혼동 방지.
- configure_audio_path_all에서도 front 채널에 LIB_ADC_DEC_CTRL_VAL_0_0250를 적용하거나, 적어도 맵변경 전 구간 지연 미적용 상태를 주석으로 문서화.
- 두 마이크 원시 교차상관 측정(방법 2)을 개발 단계 회귀 테스트로 정착: 맵변경 후 τ_measured = 64±5µs 이내를 pass 기준으로 설정.
- 1kHz 이하 FBR 거의 없음을 시스템 요구사항에 명시. 저주파 풍잡음 억제 목적이라면 추가 고역통과 필터(HPF, fc≈800Hz) 또는 고차 빔포밍(superdirective) 검토 필요.
