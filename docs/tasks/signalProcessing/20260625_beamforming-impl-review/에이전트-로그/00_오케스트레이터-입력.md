# 오케스트레이터 입력 — 빔포밍 구현 리뷰

**TL;DR**: `조사_구현-그라운딩.md` 공통 입력으로 분석 12 + 검증 5 페르소나 fan-out. 결론만 구조화 반환, `01~NN-<페르소나>.md` 기록.

## 분석 페르소나 (12)
1. HW 채널·SEL·패리티 검증가 — ch0/ch2 짝수, SEL/엣지, IOC
2. 지연 분해 분석가 — SW1+HW0.025=1.025 vs 22mm 1.026 정확도
3. 버퍼·믹서 데이터흐름 분석가 — 인덱스 순서·i+1 방향·경계 delay_buf1[0]
4. L/R 재조향 로직 분석가 — front mic 스왑·ISD location·HW/SW 일치
5. QCC 공유·모드전환 분석가 — I2S/Mapping 폴백·1↔2 전환
6. 게인 스테이징 분석가 — >>1 halving·상관/비상관·1↔2 음량 연속성
7. 런타임 전환 글리치 분석가 — DEC_CTRL live·클럭 토글·mute 부재
8. 이론 정합 비교가 — 20260623 분석/계획 대조
9. 코드 품질·유지보수 분석가 — 데드 매크로·16줄 하드코딩·매직 오프셋·결합
10. 빔포밍 성능·지향성 분석가 — delay-sum 2mic 지향성·white-noise 해석·전후비
11. 초기화·적용시점 분석가 — fractional 맵변경 한정·init 0-delay 창
12. 개선 우선순위 종합가 — 개선 항목 랭킹

## 검증 페르소나 (5, adversarial)
1. "믹서 i+1 오프셋이 front mic를 실제로 지연(방향 정확)" 반증
2. "SW1+HW0.025=1.025샘플이 22mm에 정합" 반증
3. "블록 경계 delay_buf1[0] 이어붙임이 시간 연속적" 반증
4. "L/R 재조향(front mic 스왑)이 forward 빔 정렬" 반증
5. "빔포밍 게인이 단일 마이크와 연속적(>>1 정규화 타당)" 반증
