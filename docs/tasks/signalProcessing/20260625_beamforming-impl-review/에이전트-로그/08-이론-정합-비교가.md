# [분석 08] 이론 정합 비교가

**신뢰도**: high

## 결론
20260623 분석·계획 대비 실구현 정합률은 높다. 핵심 설계 결정(하이브리드 채택·귀별 front mic 조향·QCC 폴백)은 모두 구현됐다. 단 이탈 2건(HW fractional 목표값 불일치·1-DMIC 초기화 채널 번호 불일치)과 위험 미반영 1건(AUDIO_MUX 재배치 미검증에도 재배치 없이 하이브리드 적용), 추가 구현 2건(tdc_copy_DMIC_buffers SW 1샘플 인덱스 오프셋 + 블록 경계 처리)이 확인됐다.

- **[info]** [정합] 하이브리드 전략 채택(SW 1샘플 + HW fractional) — 이론 '위험_1' 대응 ✅
  - 근거: beam-forming 계획.md §4 위험_1: 'AUDIO_MUX 재배치 불가 시 Left 귀 1.058 샘플 > HW 상한 → 하이브리드(SW FIFO 1샘플 시프트 + HW fractional 0.058)'. 실구현: SW 1샘플 = audioMixer.c:59-74 p_delay_buf0[i+1] (인덱스 오프셋), p_delay_buf1[0] (블록 경계). - **[major]** [이탈-major] HW fractional 목표값 불일치 — 이론 FRAC=14(0.0583샘플)≠구현 FRAC=6(0.025샘플)
  - 근거: beam-forming 계획.md §2: 'front mic 홀수 채널 배치 시 DELAY_INTEGER=6, FRAC=14 = 0.8083샘플'. 실구현은 홀수 채널 재배치 없이 짝수 ch0/ch2 유지 + 하이브리드 채택. 하이브리드 시 HW fractional 목표는 위험_1에서 '0.058샘플(FRAC≈14)'로 명시됨. 그러나 lib_audio_in.h:112-113: LIB_ADC_DEC_CTRL_VAL_0_0250 = ADC_INTEGER_DELAY_0 | (6 << DELAY_FRACTIONAL_Pos) = 0.025샘플(FRAC=6, 1/40). 이론 하이브리드 권고값(0.058≈FRAC=14)과 실구현값(0.025≈FRAC=6) 불일치. 실구현 총 지연 1.025샘플 vs 이론 필요 1.0262샘플, 차이 0.0012샘플(0.08µs)로 오차는 HW 해상도(0.26µs) 이내이나, FRAC 수치 자체의 근거가 이론 문서에 없다.
- **[minor]** [이탈-minor] configure_audio_path_all 1-DMIC 분기 채널 번호 불일치 — 이론 ch0/ch2 기대, 구현 ch1

- **[info]** [이탈-info] AUDIO_MUX 재배치 미검증 상태로 하이브리드 채택 — '위험_1' 대응 경로 선택은 타당하나 전제 검증 미완

## 개선 제안
- HW fractional 목표값 근거 문서화: lib_audio_in.h의 LIB_ADC_DEC_CTRL_VAL_0_0250(FRAC=6=0.025샘플) 선택 근거를 소스 주석 또는 작업 문서에 명시. 이론 문서(위험_1)의 '0.058샘플≈FRAC=14'와 차이가 있으므로, 22mm 기하에서 하이브리드 총합 1.025 vs 필요 1.0262 오차가 허용 기준 내임을 설계 노트로 확정.
- 블록 인덱스 방향 가정 검증: audioMixer.c의 p_delay_buf0[i+1] / p_delay_buf1[0] 블록 경계 처리는 'index 0=최신 샘플, index 15=오래된 샘플'을 전제. tdc_copy_DMIC_buffers에서 g_lib_dmic_in_buffers[mic][0]=신규 FIFO, [1]=직전 블록임을 RTT 덤프로 실측 확인 권고.
- AUDIO_MUX 재배치 가능성 확인(후속_1 미완): 현재 하이브리드가 실용적으로 동작하더라도, Left 귀 홀수 채널 재배치 경로(순 지연 0.808샘플, HW 단독)의 가능성을 데이터시트 §13 mux 소스 인코딩으로 확인해두면 향후 설계 자유도 확보.
- LIB_ADC_DEC_CTRL_VAL_0_9958 데드코드 정리: 탐색 목적으로 정의된 0.9958샘플 매크로는 미사용 상태. 주석으로 '검토 후 미채택' 이력을 남기거나 제거하여 혼란 방지.
- 1-DMIC 분기 채널 일관성 수정(잠재적): lib_audio_in.c #if ENABLE_COUNT==1 분기에서 ch1 설정이 IOC 선언(ch0)과 불일치. 현재 비활성이나, 향후 1-DMIC 모드 복귀 시 오동작 가능성이 있으므로 ch0로 정렬 권고.
