# 빔포밍 실구현 리뷰 — 요구사항

**TL;DR**: 은수님이 CFX에 구현해 동작 확인(화이트노이즈 L/R 차이)한 2채널 빔포밍을 분석하고, 우리가 논의한 이론([`20260623_beam-forming`](../20260623_beam-forming/)·[`dmic-sel-edge-match`](../20260623_dmic-sel-edge-match/))과 대조하며, 개선점을 도출한다. 다중 페르소나 분석·검증·문서화.

---

## 1. 배경
- 은수님이 우리 논의 기반으로 CFX 빔포밍 구현 → 기능 동작(화이트노이즈로 ISD 착용 L/R에 따라 DMIC1/2 방향 음량 차 확인).
- 구현: 하이브리드 지연(SW 1샘플 + HW FRAC=6), 동일 패리티 ch0/ch2, L/R 재조향, QCC 공유 폴백 (상세: [`조사_구현-그라운딩.md`](조사_구현-그라운딩.md)).

## 2. 목표
- [ ] **요구사항_1**: 구현의 정확성 분석(지연 분해·방향·버퍼/믹서 데이터흐름·L/R 조향·QCC 전환).
- [ ] **요구사항_2**: 우리 논의 이론과 대조(정합/이탈 항목).
- [ ] **요구사항_3**: 개선점 도출·우선순위화(정확성·글리치·게인·코드품질·성능·테스트).
- [ ] **요구사항_4**: adversarial 검증으로 핵심 주장(방향·정합·게인) 교차 확인.

## 3. 제약
- **분석·문서화 한정**. 제품 코드 변경은 후속(별도 승인). 본 리뷰는 변경 권고까지만.
- 모든 결론은 실코드·데이터시트·기존 작업 문서로 그라운딩.
- 방법: 다중 페르소나(분석·검증·개선) + 문서화.
