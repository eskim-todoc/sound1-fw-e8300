# NofM 기능 병합 — 요구사항 (Rev.1)

**TL;DR**: 같은 팀원 다니엘이 CFX 측 (`src/1__cfx/`) 에 추가한 **NofM 신호처리 기능** 을 사용자(다) 가 본인 직접 working tree 병합 (빌드 OK, 9 파일 unstaged). 본 task = 변경 파악 + 알고리즘 구현 분석 문서화 (Sullivan task 패턴). 구현·코드 작성은 본 task 범위 외 (이미 병합 완료). 산출물 = [`분석.md`](분석.md) (Rev.0, 함수별 walk-through 심화) + [`이력 및 결과.md`](이력 및 결과.md) (Rev.0). NofM 핵심 파일 = CFX 측 7 파일 (`signalProcessing/{definitionsForAlgorithm.h, stimulationStrategy.{c,h}, nonlinearMapping.c, FrequencyAnalysis.c}` + `systemControl/{main.c, system_control.c}`). CM3 측 2 파일 (`ci_ble_control_boot.c` OTA 후 QCC 절전 딜레이, `LedOutput.c` 팩토리 리셋 default) 은 NofM 무관 — 사용자 명시 별도 task 분리 권고.

## 2. 목적·범위

### 2.1 분석 대상 영역

- **NofM 핵심 (CFX 측 7 파일)**:
  - `src/1__cfx/signalProcessing/definitionsForAlgorithm.h` — 매크로 정규화 + NofM 상수
  - `src/1__cfx/signalProcessing/stimulationStrategy.h` — 함수 시그니처 + extern
  - `src/1__cfx/signalProcessing/stimulationStrategy.c` — NofM 본체 (6 신규 함수)

  - `src/1__cfx/signalProcessing/FrequencyAnalysis.c` — 포인터 부수 최적화
  - `src/1__cfx/systemControl/main.c` — CIS/NofM 호출 위치 이동
  - `src/1__cfx/systemControl/system_control.c` — NofM Phase 초기화 트리거

## 3. 요구사항

### R-1. 분석 방법

- `git diff HEAD -- <파일>` 으로 변경 hunk 식별.
- working tree (변경 후) 의 전체 파일 라인 번호 기준으로 인용.
- 함수별 walk-through 심화 — `stimulationStrategy.c` 의 신규 6 함수 각각 ① 시그니처 ② 알고리즘 의도 ③ 라인별 핵심 ④ 변경 전 (`nOFm`) 대비 차이.
- 부수 최적화 (`nonlinearMapping.c`, `FrequencyAnalysis.c`) 는 1~2 단락 간략. 본 task 의 깊이 목적은 NofM 알고리즘 이해.

### R-2. 산출물 형식

- 분석.md Rev.0 — 8 절 구성: ① 변경 통계, ② NofM 알고리즘 개요(CIS 와의 차이), ③ 2 단계 Phase 사이클, ④ 파일별 변경 분석(§4.1~§4.7), ⑤ NofM 통합 인터페이스(매크로 분기·전역 변수 라이프사이클·main loop 결합), ⑥ NofM 무관 변경 분별(CM3 측 2 파일), ⑦ 흐름도(Mermaid 2 개), ⑧ 결론·후속 권고 + 갱신 이력.
