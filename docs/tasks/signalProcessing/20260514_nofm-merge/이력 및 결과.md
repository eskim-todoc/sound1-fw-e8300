### 2.3 원본 (`nOFm`) 대비 다니엘 구현 주요 개선

1. **매크로/심볼명 정규화** — `nOFm` → `NofM` (가독성).
2. **Peak Selection 알고리즘 재설계** — packed score `(amp << 5) | (31 - idx)` 로 정렬 키 + tiebreak 통합 / `int present[32]` 배열 → `unsigned long` 단일 비트마스크 (RAM 32× 절약).
3. **Interleaving 일반화** — 명시적 16 줄 매핑 → `half_ch = N/2` stride 패턴 (N 가변성).
4. **Packet 최적화** — modulo wrap 제거 (loop peeling) + 거리 비교 16→2 슬롯 (first/last 만, O(N) → O(1)).
5. **PCM_Write 통합** — `_Phase0` / `_Phase1` 별도 함수 (NOP + 8 자극 명시 매핑) → 단일 `PCM_Write` (NOP pre-fill + strided overwrite + Case A/B 1ms 한도).
6. **dispatch 책임 정리** — `stimulationStrategy()` switch 안의 Phase 분기 + 테스트 #if 0 코드 제거 → 마스터 함수 `stimulationStrategy_NofM()` 안으로 캡슐화.

### 4.3 NofM 실기 검증

본 분석은 코드 정합성·알고리즘 흐름까지. 다음 단계는 별도:
- 실기 청취 평가 (NofM 모드 음질, CIS 와의 비교).
- 자극 안정성 (T-level 묵음 처리 + crosstalk 측정).
- 사이클 부하 측정 (Phase 0 의 신호처리 총 사이클 vs CIS 단일 함수, 1 ms 한도 여유).
- Case B 다중 사이클 분산 전송 시 음향 끊김 여부.
