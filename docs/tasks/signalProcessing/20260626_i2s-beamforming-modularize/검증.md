## 3. ⚠️ 기존 코드 잠재 버그 (제 변경 무관 — 보고)

- **`lib_i2s.c:82`**: 전처리기 `#else`가 아닌 C 키워드 `else`가 `#if (I2S_BUFFER_UNDERRUN_CNT == 5)` 블록 끝에 위치. 현재 `I2S_BUFFER_UNDERRUN_CNT != 5`라 해당 블록 전체가 전처리기 skip되어 **휴면**이나, **값이 5가 되면 `else` 구문 오류 + `#error` 발동으로 빌드 실패**.
- 페르소나가 git diff로 **본 모듈화 변경 이전부터 존재**함을 확인. 본 작업 범위 밖이라 정정하지 않음 — **후속에서 `#else`로 교체 권고**(은수님 판단).
