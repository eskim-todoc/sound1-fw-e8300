## 노트
- beamforming_das_kernel 순수화 리팩터: 현재 출력지 HEAR_ADDR_AUDIO_MIX가 하드코딩(audioMixer.c:111). int _XMEM *p_out 파라미터로 추출하면 behavior-preserving 순수 함수로 전환 가능 — 온타깃 테스트 벡터 주입 용이.
- SW 1샘플 지연 정렬(delay[i+1])과 블록경계 이어붙임(delay_buf1[0] at i=15)은 beamforming_das_kernel 내부에 완전 내재화(audioMixer.c:113-128) — 별도 함수 없음. 로직 설명으로 갈음.
- dmic_count_switch_decision이 normal_loop(main.c:167-188)과 Normal_PowerMode_event_mapChange(system_control.c:70-77) 두 곳에 동일 판정 패턴 중복. 단일 순수 인라인 판정 함수로 통합 시 중복 제거 가능.
- i2s_fade_gain_kernel은 src 배열 in-place 수정(lib_i2s.c:351, 403). 유닛 테스트 시 원본 src 복사본 필요 — 함수 시그니처에 const src + 별도 out 파라미터 추가 권장.
- I2S_handle()(main.c:355-415)은 현재 normal_loop에서 호출되지 않음(주석 처리). 액티브 I2S 복사 경로는 normal_loop 직접 복사(main.c:144-163) + PCM_LiveStimulation_Mode 믹싱. lib_i2s_copy_data_from_fifo는 I2S_handle 경로용으로만 남아있음.
- audio_mix_2_buffers(audioMixer.c:43-54)의 ÷2 생략은 의도적 설계: 독립 음원(DMIC+I2S) 합산이므로 상관 없음 — beamforming_das_kernel의 >>AUDIO_MIX_NORMALIZE_RSHIFT(÷2)와 구분 필요.
- g_lib_dmic_in_buffers 인덱스 규약([mic][block][sample], 모두 0=최신)은 lib_audio_in.h:146-150 주석에 명시. beamforming 인수 매핑 시 BUF_MAX_CNT-2=0(현재), BUF_MAX_CNT-1=1(직전) 참조(main.c:457,462).
