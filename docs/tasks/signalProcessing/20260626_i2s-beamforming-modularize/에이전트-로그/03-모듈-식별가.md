## 노트
- audio_mix_internal_mic_only(audioMixer.c:7), audio_mix_external_mic_only(audioMixer.c:19)는 AMIC 레거시 경로 심볼 — 현 DMIC/I2S 활성 경로에서 미호출, 4모듈 범위 외.
- I2S_update_state(lib_i2s.c:184)는 정의되어 있으나 PCM_LiveStimulation_Mode:419에서 주석 처리됨(// I2S_update_state()). 현재 활성 경로 아님. normal_loop_i2s_dmic_branch가 대신 state를 직접 전환.
- lib_init_audio_in_path_common(lib_audio_in.c:21)은 configure_audio_path_all / lib_init_audio_in_path_ADC 양쪽의 static 공통 내부 함수. 외부 노출 없음 — configure_audio_path_all 유닛 내부로 포함.
- normal_loop_i2s_dmic_branch 내 HCT_A0_5→lib_g_i2s_buffers 인라인 복사(main.c:144-161)는 i2s_fifo_ring_copy(lib_i2s_copy_data_from_fifo)와 로직 중복. 향후 i2s_fifo_ring_copy 단일화 리팩터 권고.
- i2s_handle_dispatch(I2S_handle, main.c:355)는 PCM_LiveStimulation_Mode:422에서 현재 주석 처리(// I2S_handle())되어 있으나 심볼 자체는 정의됨. 모드전환 모듈 유닛으로 포함.
- 모듈 통합 테스트 순서 권고: 오디오 입력 모듈 → I2S 모듈 → 빔포밍 모듈 → 모드전환 모듈 (의존 방향 역순 없이 상향식).
