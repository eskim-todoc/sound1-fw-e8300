## 노트
- 테스트 순서(비순환 DAG): ① mixer_arithmetic + mic_routing (병렬, 상호 무관) → ② hw_audio_path (mic_routing 통과 전제) → ③ dmic_fifo_capture + i2s_state_machine (병렬, 둘 다 hw_audio_path 전제) → ④ signal_dispatch → ⑤ 시스템 통합(PCM_LiveStimulation_Mode 엔드투엔드)
- das_arithmetic 테스트 벡터 필수 케이스: (a) 내부 샘플 i=0..14 — no_delay[i]+delay[i+1]; (b) 블록 경계 i=15 — no_delay[15]+delay_buf1[0]. 2-버퍼 링(LIB_AUDIO_IN_BUF_MAX_CNT=2)이 자명하게 드러나는 유일 지점
- beamforming_dispatch의 NONE 폴백(main.c:466-468, audio_mix_1_buffer로 DMIC1 단독 사용)은 독립 케이스로 분리 검증 필요 — front_mic 미설정 상태에서 잘못된 지연 적용 방지
- hw_fractional_delay_config는 Normal_PowerMode_event_mapChange 안에 인라인 — 독립 추출 없이 m_current_isd=1, mapChangeFlag.cm3Command_mapChange=1, isd_location_RL=Left_Ear/Right_Ear 조합으로 온타깃 자극·검증
- dmic_count_state의 enable_1_DMIC / enable_2_DMICs는 s_enabled_dmic_cnt 쓰기(단순) + Sys_DIO_Config DIO22·DIO10(HW). 카운트 상태 전이(1→2, 2→1)는 logic-explanation; DIO ADCCLK 출력 확인은 hw_audio_path 통합 테스트에 병합
- i2s_dmic_count_switch(main.c:131-189)는 독립 함수 없이 normal_loop에 인라인 — 분리 없이 온타깃 I2S FLAG GPIO 자극(DIO29 low/high 전환)으로 DMIC 수 자동 전환 동작 검증
- signal_dispatch 통합 후 시스템 테스트 핵심 시나리오: Left귀 ISD 연결 → 2-DMIC 빔포밍(DMIC2=front/delay, DMIC1=rear) → I2S 스트리밍 시작 → 1-DMIC 전환 + I2S 혼합 → I2S 종료 → 2-DMIC 복귀
- AUDIO_MIX_NORMALIZE_RSHIFT=1(audioMixer.h:24)과 AUDIO_INPUT_RSHIFT(=5, definitionsForAlgorithm.h 유래)는 das_arithmetic 테스트 벡터 기대값 계산 시 양쪽 모두 적용 확인 필수
