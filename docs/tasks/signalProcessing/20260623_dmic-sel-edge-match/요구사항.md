# 마이크 SEL ↔ E8300 캡처 엣지 정합 — 요구사항

**TL;DR**: 현재 사용 중인 Knowles **SPH0641LM4H-1** PDM 마이크는 SELECT 핀(VDD/GND)에 따라 데이터 유효 클럭 구간(엣지)이 달라진다. 이를 E8300 DMIC 인터페이스의 캡처 엣지 설정(`DMIC*_DATA_RE`/`_FE`)과 비교 분석하여 **어떤 SEL+엣지 조합이 올바른지** 규명한다. 여러 페르소나 분석·검증 + 문서화.

> [!NOTE]
> 본 작업은 [`signalProcessing/20260623_beam-forming`](../20260623_beam-forming/)의 미해결 **포인트_3(RE/FE 통일)**를 해소하는 후속 분석이다.

---

## 1. 배경

- 빔포밍 분석(`20260623_beam-forming`)에서 현재 펌웨어가 **DMIC1=RE(rising), DMIC2=FE(falling)**로 두 마이크를 서로 다른 엣지로 캡처함을 확인. 이 RE/FE 분리의 정당성·정확성이 미해결로 남음(포인트_3).
- 은수님이 실제 사용 마이크 데이터시트(`docs/참고/e8300/knowles ... .pdf` = **SPH0641LM4H-1**)를 첨부. SELECT 핀 설정에 따라 출력 데이터가 클럭의 어느 레벨/엣지에서 유효한지가 명시되어 있음.

## 2. 분석 목표 (요구사항)

- [ ] **요구사항_1**: 마이크 SELECT 핀(VDD/GND)별 데이터 유효 엣지/구간을 데이터시트로 확정.
- [ ] **요구사항_2**: E8300 DMIC 캡처 엣지(`DMIC*_DATA_RE`/`_FE`, low/high data channel)의 의미를 데이터시트로 확정.
- [ ] **요구사항_3**: 둘을 대조하여 **올바른 (SEL, 캡처엣지) 조합표**를 도출.
- [ ] **요구사항_4**: 현재 펌웨어(DMIC1=RE, DMIC2=FE)가 요구하는 **각 마이크의 SEL 스트랩 조건**을 규명하고, 미스매치 시 영향(High-Z/잘못된 데이터)을 분석.
- [ ] **요구사항_5**: 빔포밍 관점에서 RE/FE 통일(both-RE 등) 가능성·조건을 판정(포인트_3 해소).

## 3. 제약·범위

- **이론·문서 분석**에 한정. 제품 소스/회로 변경 없음(후속 별도 승인).
- 실제 보드의 SEL 스트랩(VDD/GND)은 **회로도 확인 필요 항목**으로 식별만(데이터시트로는 단정 불가).
- 모든 결론은 마이크 데이터시트(SPH0641) + E8300 HW Reference로 그라운딩(페이지 인용).
- 방법: 여러 페르소나 분석 + adversarial 검증 + 문서화.
