# 오케스트레이터 입력 — SEL-엣지 정합

**TL;DR**: 그라운딩(`조사_SEL엣지-그라운딩.md`)을 공통 입력으로 분석 7 + 검증 4 페르소나 fan-out. 각 노드 결론만 구조화 반환, `01~NN-<페르소나>.md`로 기록.

---

## 공통 입력
- `조사_SEL엣지-그라운딩.md` 전문(마이크 SPH0641 §5 p.7 + E8300 §18.2 p.563 + 펌웨어 h:80 대조).
- 목표: 올바른 (SEL, 캡처엣지) 조합 + 현재 펌웨어 정합 조건 + 빔포밍 RE/FE 통일 판정.

## 분석 페르소나 (7)
1. PDM 전기 인터페이스 분석가 — SPH0641 SEL/엣지/유효구간/High-Z 멀티플렉싱
2. E8300 캡처 엣지 분석가 — low/high data channel ↔ `_RE`/`_FE` 정의
3. SEL↔엣지 정합 매핑 분석가 — 올바른 조합표 도출·논리 검증
4. 현재 펌웨어 정합성 분석가 — DMIC1=RE/DMIC2=FE ↔ 요구 SEL 스트랩
5. 미스매치 영향 분석가 — 잘못된 조합 시 High-Z/stale 캡처 결과·증상
6. 회로 스트랩 의존성 분석가 — SEL 풀다운 기본값·회로도 확인 항목·QCC 기준 가능성
7. 빔포밍 연계 분석가 — 별도 DATA선이므로 both-RE 통일 가능성·조건(포인트_3)

## 검증 페르소나 (4, adversarial)
1. "SEL=VDD↔`_FE`, SEL=GND↔`_RE`가 올바른 조합" 반증
2. "현재 DMIC2=`_FE`는 U9 SEL=VDD를 강제 요구" 반증
3. "SEL 미스매치 시 High-Z/잘못된 데이터 캡처" 반증
4. "별도 DATA선이라 both-RE 통일 가능" 반증
