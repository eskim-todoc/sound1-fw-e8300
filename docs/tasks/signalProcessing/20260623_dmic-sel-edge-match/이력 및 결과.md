# 마이크 SEL-엣지 정합 — 이력 및 결과

## 완료 요약 (2026-06-23)

### 결론 — 올바른 조합 확정 ✅

| 마이크 SEL | 올바른 E8300 캡처 | 근거 |
|---|---|---|
| **GND (Low)** | **`DMIC*_DATA_RE`** (rising) | 마이크 LOW 구간 유효 = E8300 low data channel |
| **VDD (High)** | **`DMIC*_DATA_FE`** (falling) | 마이크 HIGH 구간 유효 = E8300 high data channel |

- 역조합(GND+FE / VDD+RE)은 마이크 **High-Z 반주기**를 캡처 → 데이터 손상.
- 마이크 §5·§6 p.7 + E8300 HW §18.2 p.563 원문 양방향 정합, 검증 4/4 confirmed.

### 현재 펌웨어 진단

- **U7 DMIC1** = `_RE` → SEL=GND 요구. 내부 풀다운 기본과 일치 → **안전**.
- **U9 DMIC2** = `_FE` → SEL=VDD **능동 스트랩 필수**. 미스트랩(GND/floating) 시 Left 채널 손상 → **빔포밍 불성립**. → **급소**.

### 최우선 후속

- **회로도에서 U7·U9 SELECT 스트랩 실측 확인** (특히 U9=VDD 여부). U9가 원래 QCC 담당이라 QCC 기준 결정 가능성 → 교차 확인.

### 빔포밍 연계

- `20260623_beam-forming` 포인트_3(RE/FE 통일) 해소: RE/FE 분리는 SEL 스트랩에 강제된 설정. 통일 이득 한계적 → **U9 정합 확인이 빔포밍 1차 관문**.
