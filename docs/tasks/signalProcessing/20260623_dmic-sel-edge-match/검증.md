# 검증 종합 (4 adversarial)

**TL;DR**: 핵심 주장 4건을 데이터시트로 **반증 시도** — **confirmed 4 / refuted 0 / uncertain 0**. SEL↔엣지 정합 조합, U9 SEL=VDD 강제 요구, 미스매치 시 High-Z 손상, both-RE 통일 가능성 모두 데이터시트 원문으로 지지됨.

> 페르소나 원본: [`에이전트-로그/인덱스.md`](에이전트-로그/인덱스.md) 08~11.

## 검증 결과표

| # | 주장 | 판정 | 핵심 근거 |
|---|---|---|---|
| 1 | SEL=GND↔`_RE`, SEL=VDD↔`_FE`가 유일하게 올바른 조합 | ✅ confirmed | 마이크 §5·§6 p.7 + HW §18.2 p.563 원문 직접 대조 |
| 2 | DMIC2=`_FE`는 U9 SEL=VDD 능동 스트랩 강제 요구 | ✅ confirmed | SEL=GND+FE 반증 시도 실패 — High-Z 구간 캡처로 귀결 |
| 3 | 미스매치 시 High-Z 구간 샘플 → 데이터 손상 | ✅ confirmed | §6 p.7 타이밍도 t_DZ(3~16ns) 후 "High Z" 명시, 3각도 반증 모두 실패 |
| 4 | DATA선 분리이므로 both-RE 통일 가능 | ✅ confirmed | 멀티플렉싱 제약은 1-pad 공유 시만 성립, 본 보드는 pad 분리 |

## 총평

- **반증 0건.** 마이크 데이터시트(SPH0641 §5·§6 p.7)와 E8300 HW Reference(§18.2 p.563)가 정합 논리를 양방향으로 명확히 지지.
- **확정 결론**:
  - 올바른 조합은 **SEL=GND↔rising(`_RE`)**, **SEL=VDD↔falling(`_FE`)** 두 가지뿐.
  - 현재 펌웨어는 **U7=GND, U9=VDD** 스트랩을 전제로 동작하며, **U9 SEL=VDD 능동 스트랩이 정합의 급소**.
  - both-RE 통일은 HW상 가능하나 빔포밍 이득은 한계적(스큐 0.22%).
- **유일한 잔여 불확실성은 데이터시트로 답할 수 없는 항목** — 실제 보드의 SEL 스트랩 값(회로도 확인 필요). 분석·검증 모두 이를 미해결로 일관 지목.
