## 핵심 결정

- **cherry-pick 회피 → `git show origin/<브랜치>:<원본> > <신경로>` 방식**: 옛 commit 2건(`dd83f13`, `68407bb`)에 Co-Authored-By 트레일러가 포함되어 있어 cherry-pick 시 트레일러가 따라오고, 같은 브랜치의 src/ 173 files 회귀 변경(2026-04-24 이전 옛 코드)도 회피해야 했다. 파일 단위 추출이 가장 깔끔.
- **본문 무변경 + 옛 prefix/suffix 제거**: 본문은 *작성 시점의 사실 기록*이라 사후 편집 시 원본성 훼손. 신 컨벤션 의무 항목(frontmatter+TL;DR)은 본문 외부 메타라 추가해도 무변경 원칙 위반 아님. 파일명 prefix·suffix는 컨벤션상 부적합한 *외부* 메타라 정리 대상.
- **활성 등재 없이 즉시 archive**: 분석 결과는 *이미 완료된 과거 산출물*이라 활성 잔존 단계가 무의미. 본 task 산출물 5종도 함께 archive로 옮겨 분석 3편 첨부와 동행.
- **원본 브랜치 보존**: force-push 회피, Co-Auth 잔존 5 commit (2026-05-14 갱신 이력 참조) 결정과 같은 정책. 사용자 사후 판단 영역.
