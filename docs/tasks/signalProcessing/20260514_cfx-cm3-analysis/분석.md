## 5. 결정 사항

| 결정 | 내용 | 근거 |
|---|---|---|
| 결정_1 | cherry-pick 안 함 | 옛 commit의 AI 트레일러 회피 + src/ 옛 코드 회귀 회피 |
| 결정_2 | `git checkout origin/<브랜치> -- <파일>` 방식 | 단일 commit으로 깔끔, 트레일러 없는 신 commit 생성 |
| 결정_3 | 본문 무변경 | 옛 분석 결과는 *작성 시점의 사실 기록*, 사후 편집 시 원본성 훼손 |
| 결정_4 | frontmatter `type = tasks/분석` | task 첨부 산출물이므로 (참고/가 아님) |
| 결정_5 | 작업 흐름 = 활성 등재 → 즉시 archive | 분석 결과는 *과거 완료된 분석*이므로 활성 잔존 불필요. 본 task의 작업 완료 시점 = 이전 완료 시점 |
| 결정_6 | 신 파일명 | `[분석]` · `by 김은수` 제거, 핵심 주제만 — 예: `첨부_분석_CFX 프로젝트 구조 및 시퀀스 Rev.0.md` |
