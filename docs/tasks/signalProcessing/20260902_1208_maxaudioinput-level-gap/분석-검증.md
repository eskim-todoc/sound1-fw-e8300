# 분석 검증

**TL;DR**: 검증 3축 통과. 핵심 주장(«AGC·HEAR·스케일이 양쪽 동일»)은 `agc.c` **diff 0 줄**이라는 기계적 근거로 확인됐고, «빔포밍 `>>1` 은 정면에서 0 dB»는 수식과 선행 리뷰 양쪽에서 교차 확인됐다. 다만 **-6dB 를 정확히 설명하는 가설이 2개(가설_1·가설_2) 남아 코드만으로는 확정 불가**하며, 이 한계를 실험_1 이 해소하도록 설계되어 있음을 확인했다.

## 축_2 논리 정합성

| 검토 항목 | 판정 | 근거 |
|---|---|---|
| «다른 곳은 믹싱뿐»과 «가설_2(마이크 감도)»가 모순 아닌가 | ✅ 정합 | 마이크 감도는 **코드 밖(HW)** 변수다. 코드 경로가 같아도 입력 `A` 자체가 작으면 결과가 작다 - 모순이 아니라 §2 수식의 `A ≠ M` 경우 |
| 배율 1.00 주장과 실측 0.50 의 충돌 | ✅ 해소 | 배율 1.00 은 «두 채널 동일 진폭 · 정면 정렬» 전제. 실측은 그 전제가 깨졌음을 시사 - §3 가설로 연결 |
| 가설_1 과 가설_2 가 상호배타적인가 | ⚠️ 부분 | 동시 성립 가능(DMIC2 무기여 **이면서** 감도도 낮음). 실험_1 은 **주된 쪽**을 가리키므로 실험_2 로 정량 보강하도록 설계함 |
| -6.02dB 라는 정확도를 실측 «약 절반»에 요구하는가 | ✅ 아님 | `요구사항-검증.md` 에서 -4~-8dB 허용으로 해석 고정. 가설_3·가설_5 도 «부분 설명»으로 남겨 둠 |
| 실험_1 이 두 가설을 실제로 가르는가 | ✅ | 1-DMIC 경로는 `mix = mic>>5` 로 1.5세대와 동일 식 → DMIC2 변수를 제거한 상태의 순수 비교 |

### 계산 재확인

| 값 | 계산 | 결과 |
|---|---|---|
| 1 샘플 (16 kHz) | 1/16000 | 62.5 µs |
| HW FRAC=6 | 6/240 샘플 × 62.5 µs | 1.56 µs |
| 총 지연 | 62.5 + 1.56 | **64.06 µs** |
| 22 mm 음향 지연 | 0.022 / 343 | **64.14 µs** (오차 0.08 µs) |
| 측면 null | 1 / (2 × 64.06 µs) | **7.81 kHz** |
| 후방 null | 1 / (2 × 128.2 µs) | **3.90 kHz** |
| 한 채널 무신호 | 20·log10(0.5) | **-6.02 dB** |

## 판정

- **확정**: 코드 상수·수식·HEAR 체인·AGC 는 원인이 **아니다**(가설_6 배제).
- **미확정**: 가설_1(DMIC2 무기여) vs 가설_2(마이크 감도·패키징) - **코드만으로는 가를 수 없다.** 실험_1 이 필요하다.
- **조건부**: 가설_3(시험 신호·방향) 은 은수님 시험 셋업 정보가 있어야 판정 가능하다.
