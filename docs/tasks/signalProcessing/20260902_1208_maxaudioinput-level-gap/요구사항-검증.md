## 해석 고정

- **«약 절반»** = 진폭비 0.5 = **-6.02 dB**. 실측 표현이 어림이므로 분석은 -6dB 를 중심으로 하되, -4 ~ -8dB 를 같은 현상으로 취급한다.
- **«기본, 왼쪽방향 상태»** = `tdc_audio_get_front_mic() == LIB_AUDIO_FRONT_MIC_LEFT`, 즉 **front = DMIC2(QCC/U9), rear = DMIC1(EZ/U7)** (`systemControl/system_control.c:88-92`).
