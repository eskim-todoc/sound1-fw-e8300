# maxAudioInput 레벨 격차 - 이력 및 결과

**TL;DR**: 1.5세대 대비 Sound1 의 `maxAudioInput` 이 70 dBSPL 에서 약 절반으로 관측되는 건에 대해, 양 저장소 신호 경로를 전 구간 대조하고 스케일 수식을 도출했다. **코드는 원인이 아님**을 확정하고, 남은 두 가설(DMIC2 무기여 / 마이크 감도)을 가르는 판별 실험을 설계했다.

---

## 시계열 로그

### 2026-09-02

- **12:08 착수**: 은수님 지시 - CFX 마이크 입력 -> FIFO 인터럽트 -> 빔포밍(기본·왼쪽 방향) -> `Addr_ShareMem->maxAudioInput` 경로에서, 1.5세대(`sullivan-1-5-fw-hw-test-link-pwr-bt-period`) 대비 70 dBSPL 입력 시 **약 절반** 크기로 관측되는 원인 분석. 패키징·코드·빔포밍 중 어디인지 미상.
- **경로 대조**: 양 저장소의 `agc.c`·`microcode.hct`·`lib_audio_in.h`·`audioMixer.c`·믹서 디스패치를 전수 비교.
  - `agc.c` **diff 0 줄**(CRLF 정규화 후) - AGC 계수·`maxAudioInput` 대입 모두 동일.
  - `microcode.hct` 의 `vAbsolute(K=16)` -> `MaxElement(K=16)` 동일. 차이는 DAC0·I2S FIFO 활성화뿐.
  - `AUDIO_INPUT_RSHIFT`=5, decimation GF=1092, ADC CFG/CTRL 모두 동일.
  - **차이는 마이크 구성(1개 -> 2개)과 믹싱 식 단 두 곳.**
- **수식 도출**: 빔포밍 `((rear>>5)+(front>>5))>>1` 은 정면 정렬 시 **1.5세대와 배율 1.00(0 dB)**. 선행 리뷰(`20260625_beamforming-impl-review/분석.md:52`)와 일치.
- **가설 수립·교차 검토**: 가설_1~가설_6. **-6.02 dB 를 정확히 설명하는 것은 가설_1(DMIC2 무기여)·가설_2(마이크 감도) 둘뿐**, 가설_6(코드 오류)은 배제.
- **선행 작업 승계**: `20260623_dmic-sel-edge-match`(SEL 엣지 정합 확정, U9 SEL=VDD 요구) 및 `20260625_beamforming-impl-review`(회로도 확인 완료) 결론을 반영. 단 «회로도 기준»이라는 한계를 명시.
- **판별 실험 설계**: 실험_1(매핑 Live = 1-DMIC, **코드 변경 없음**) -> 실험_2(DMIC2 단독) -> 실험_3(정면 1 kHz 순음).
- **산출**: `요구사항.md` · `요구사항-검증.md` · `분석.md` · `분석-검증.md` · 본 문서.

## 완료 요약 (2026-09-02)

### 결론

| 구분 | 판정 |
|---|---|
| **코드(상수·수식·HEAR·AGC)** | **원인 아님** - `agc.c` diff 0줄, 스케일·decimation 이득 동일 |
| **빔포밍 `>>1` 정규화** | **정상** - 정면 정렬 시 단일 마이크와 0 dB 등가 |
| **DMIC2(QCC/U9) 무기여** | **미확정 · 최유력** - 성립 시 정확히 -6.02 dB |
| **마이크 감도·음향 패키징** | **미확정 · 동등 유력** - 성립 시 역시 -6.02 dB |
| **시험 신호·음원 방향** | **조건부** - 광대역·비정면이면 고역 손실로 피크 하락 |

### 다음 행동 (은수님)

1. **실험_1** - 매핑 앱 Live 연결 상태에서 같은 70 dBSPL 재측정. 코드 변경 없이 1-DMIC 경로가 된다.
   - 1.5세대와 같으면 -> DMIC2 문제

2. 시험 신호 종류(순음/광대역)와 음원 방향을 알려 주시면 가설_3 판정까지 확정 가능하다.
