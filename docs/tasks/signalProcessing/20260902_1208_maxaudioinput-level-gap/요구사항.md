# maxAudioInput 레벨 격차 - 요구사항

**TL;DR**: 동일한 70dBSPL 음압에서 Sound1 의 `Addr_ShareMem->maxAudioInput` 이 1.5세대(`sullivan-1-5-fw-hw-test-link-pwr-bt-period`) 대비 약 절반(-6dB)으로 관측된다. 신호 경로를 양쪽 저장소에서 대조해 **패키징(HW) · 코드 · 빔포밍** 중 어디에서 격차가 발생하는지 규명하고, 원인을 가르는 판별 실험을 설계한다.

---

## 배경

은수님이 수행 중인 시험은 다음 경로의 말단 값을 무선으로 연속 관측한다.

```
마이크 입력 -> FIFO 인터럽트 -> 빔포밍(기본·왼쪽 방향) -> 믹싱 버퍼
  -> HEAR vAbsolute -> HEAR MaxElement -> Addr_ShareMem->maxAudioInput
```

1.5세대와 Sound1 사이에 다음이 바뀌었다.

- 마이크가 1개(DMIC + 이어피스 AMIC) -> **2개(DMIC1=EZ/U7, DMIC2=QCC/U9)**
- 믹싱에 **DAS 빔포밍**이 추가됨
- 코드 구조가 모듈 단위로 재정리됨

## 요구사항

| 라벨 | 내용 | 수용 기준 |
|---|---|---|
| 요구사항_1 | `maxAudioInput` 에 값이 도달하기까지의 경로를 양쪽 저장소에서 **전 구간 대조** | 각 구간의 동일/상이 여부를 `파일:라인` 근거와 함께 표로 제시 |
| 요구사항_2 | 스케일(이득) 관점에서 **1.5세대 대비 Sound1 의 이론 배율**을 수식으로 도출 | 정면 정렬·한쪽 무신호·오정렬 등 경우별 배율과 dB 를 산출 |
| 요구사항_3 | 실측 -6dB 를 설명할 수 있는 **원인 가설을 3개 이상** 세우고 교차 검토 | 각 가설이 -6dB 를 정확히 설명하는지 판정 |
| 요구사항_4 | 가설을 가르는 **판별 실험**을 설계 | 코드 변경 없이 가능한 것을 우선하고, 각 실험의 예상 결과별 결론을 명시 |

## 범위

- **포함**: CFX 측 마이크 입력 -> 믹싱 -> HEAR AGC 전처리 -> 공유 메모리 기록 경로, 양 저장소 HW 오디오 경로 설정(ADC/DEC/IOC/MUX), 기존 빔포밍 작업 문서의 결론 승계
- **제외**: 실기 계측 수행(은수님 담당), 회로도 실물 확인, AGC 이후 자극 출력 경로, 코드 수정(원인 확정 전까지 금지)
