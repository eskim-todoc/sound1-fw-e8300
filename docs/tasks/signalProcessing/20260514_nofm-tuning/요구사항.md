# 요구사항: NofM 튜닝 (프레임 3 고정·백텔 강제·가용 조건)

**TL;DR**: 사용자(다)가 NofM 본체 통합([`signalProcessing/20260514_nofm-merge`](../../signalProcessing/20260514_nofm-merge/)) 이후 실제 동작 검토 중 직접 적용한 5 변경(CFX 2 / CM3 2 / + 임시 테스트 벡터 2)을 정리·문서화·커밋·머지·푸시한다. 핵심 = ① 백텔 수신 안정화 (COLA TX 1 프레임 종료 race 회피), ② NofM 프레임 수 3 고정 (CM3 공유메모리에서 강제), ③ NofM 가용 조건 16ch ≥ 가드, ④ 출력 파형 확인용 임시 테스트 벡터 2건 (후속 삭제 대상).

## 1. 배경

- 선행 작업 [`signalProcessing/20260514_nofm-merge`](../../signalProcessing/20260514_nofm-merge/) 에서 다니엘이 작성한 NofM 본체 6 함수 통합 + 사용자 본인 직접 working tree 머지 (commit `efbe067`).
- 그 후 사용자(다)가 실제 동작 검증 중 시스템 안정성·튜닝 사항 5건을 직접 코드에 반영 (워킹트리에 4 파일 변경 잔존).
- 본 task = *사용자 코드를 정리·문서화 + git 정식 사이클 (분기·커밋·머지·푸시·archive) 통합 처리*. 코드 본체 작성은 본 task 외 (사용자 본인 수행 완료).

## 4. 범위

### 4.1 포함

- 4 워킹트리 파일 (CFX 2 + CM3 2) 의 의미 변경 5건 + 부수 포매팅 정리
- 본 task 산출물 5종 작성 + archive + 작업 목록.md 갱신
- src commit + docs commit (2 commit) → develop·main 머지 + push

### 4.2 제외

- **NofM 본체 알고리즘 변경·재분석**: [`nofm-merge`](../../signalProcessing/20260514_nofm-merge/) 에서 종결. 본 task 는 그 위 튜닝.
- **임시 테스트 벡터 삭제**: 사용자(다) 검증 완료 후 별도 후속 task. 본 task 에서는 적용·기록까지만.
- **사용자 빌드·실기 검증**: 본 task 외 (사용자 단계).
- **`stimulationStrategy.c` 의 NofM 함수 내 코드 포매팅 변경 의미 해석**: clang-format 적용 결과이고 본 task 가 의미 평가 대상이 아님.
