# 요구사항: CFX·CM3 분석 3편 신 컨벤션 이전

**TL;DR**: 2026-04-18 작성된 CFX·CM3 분석 3편(`origin/claude_docs_cfx-cm3-analysis` 원격 브랜치, `claude_main` 미머지)을 신 컨벤션 `tasks/signalProcessing/cfx-cm3-analysis/`에 task 첨부 형태로 이전한 뒤 frontmatter+TL;DR 추가, 이력.md 작성, `_archive/` 즉시 이동, main 머지까지 완수한다. 본문 무변경·AI 트레일러 잔존 5 commit 정책과 동일하게 원본 브랜치는 보존.

## 1. 배경

- 사용자(다)가 "전에 CM3·CFX 초기화 분석 했던 거 있지 않아? 다른 PC였는지 기억 안 난다" 문의.
- 검색 결과: Sound1 `origin/claude_docs_cfx-cm3-analysis` 원격 브랜치에 2026-04-18 작성된 분석 3편이 `claude_main` 미머지 상태로 약 한 달 묵힘.
- 옛 `docs/[분석] ...md by 김은수.md` flat 컨벤션 + AI Co-Authored-By 트레일러 포함 (2026-04-24 docs 재구조화 + 2026-05-14 AI 트레일러 시정 정책 이전).
- 그대로 두면 검색·재참조 어려움. 신 `tasks/<모듈>/<작업>/` 구조로 이전 시 향후 NofM·signalProcessing 후속 작업의 참조 인벤토리로 가치 보존.
