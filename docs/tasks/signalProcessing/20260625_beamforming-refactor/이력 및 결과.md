## 시계열 로그

### 2026-06-25
- **착수**: 은수님 지시 — 기능 정확성 검증된 빔포밍 구현을 동작 보존 리팩토링(상수화·복사/루프 효율·주석). 다중 페르소나, 할루시네이션 0·계획대로 검증 최우선.
- **요구사항 작성**: 동작 보존 절대 제약, 범위=빔포밍 관련 코드, 4단계 준수.
- **②분석 (Workflow)**: 9 페르소나(인벤토리 7 + 검증 2), 54만 토큰, 6.4분. 인벤토리 76항목(상수19·주석27·데드코드11·네이밍8·루프11).
  - **할루시네이션 검증 `all_real`(창작 0)**, **동작보존 검증 `some_unsafe`(위험 3건 적발)** → 믹서 언롤→루프·I2S XOR·mic복사 삼항 **제외**.
  - **catch**: 한 페르소나 제안 주석에 지연값 오기(6/32·1.1875·25mm) → 검증값(6/240·1.025샘플·22mm)으로 교정 명시.
  - `분석.md` 작성, 에이전트 로그 01~09 + 인덱스 생성.
- **③계획 작성**: include 가시성 확인(lib_audio_in.h엔 df_ 미가시→배열 16 리터럴 유지, audioMixer.h엔 가시→NORMALIZE 상수 가능). 안전 항목만 적용 스펙 확정. `계획.md` 작성 → **승인 대기**.

- **승인**: 은수님 "승인 — 구현 진행", tdc_ rename "보류".
- **④구현**: 6개 파일에 상수화·주석·데드코드 제거 적용(위험 3건 제외). 편집 모두 Edit 도구로 정밀 적용(CRLF 무이슈).
  - 상수: `LIB_AUDIO_DMIC_COUNT_SINGLE/DUAL`·`LIB_DMIC_IDX_DMIC1/2`·`AUDIO_MIX_NORMALIZE_RSHIFT`·배열 첫 차원→`LIB_AUDIO_IN_DMIC_ENABLE_COUNT`.
  - 데드코드: `_0_9958`·`g_enabled_mic_count`·구버전 주석호출·`//20` 제거.
  - 주석: 버퍼 규약·doxygen·÷2 의도·하이브리드 지연(검증값)·L/R·낡은 주석 정정.
- **단계_4 검증**: 기계 검증(상수=리터럴·데드심볼 0·믹서16곳·include 가시성) + 5 페르소나(상수등가·로직불변·빌드안전·동작·회귀).
  - **preserved 4 / regression 1(오탐)**. 오탐은 `git diff HEAD`로 은수님 구현을 리팩토링에 오귀속 → 라인 증거로 반증(편집하지 않은 라인).
