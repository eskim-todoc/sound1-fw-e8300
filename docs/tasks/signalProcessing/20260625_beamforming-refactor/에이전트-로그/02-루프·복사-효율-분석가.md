## 결론
대상 2개 함수에서 동작 보존(behavior-preserving) 리팩토링 가능 지점 5건 식별. tdc_copy_DMIC_buffers의 내부 루프는 LIB_AUDIO_IN_BUF_MAX_CNT=2 고정이므로 j=0 단 1회만 실행되어 루프가 불필요하고, 외부 i루프도 mic 블록 2개를 한 루프로 통합 가능. audio_mix_2_buffers_for_beamforming의 16줄 수동 언롤은 i=0..14 구간을 chess_loop_range 루프로 처리하고 i=15 경계 처리를 분리하면 출력 동일 유지 가능. chess_loop_range 힌트는 기존 패턴 그대로 유지 필요.
