# [분석 05] 동작보존 위험 감별가 — CFX 임베디드 DSP 리팩토링 위험 심사자. chess_loop_range/DSP 스케줄러 제약, 빔포밍 샘플 인덱스, volatile 제거 위험 등 HW-DSP 특화 위험을 우선 식별.

## 결론
6개 파일에서 총 11개 리팩토링 후보를 식별. 핵심 위험군은 3개: (1) audio_mix_2_buffers_for_beamforming 언롤→루프 전환 시 p_mix[15]의 p_delay_buf1 경계 인덱스 오기 가능성(high), (2) tdc_copy_DMIC_buffers 중첩 루프를 루프 교환 시 chess_loop_range DSP 스케줄러 충돌(medium), (3) g_enabled_mic_count 데드코드 제거 시 향후 사용 목적 말소(low). 나머지 8개는 none/low 위험으로 보존 가능. high-risk 항목은 보류 권고.
