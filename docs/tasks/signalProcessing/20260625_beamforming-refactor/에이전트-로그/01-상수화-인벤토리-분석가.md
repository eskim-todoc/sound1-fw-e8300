# [분석 01] 상수화 인벤토리 분석가 — 실파일 Read 검증 기반, 동작 보존 전용

## 결론
6개 실파일 전수 Read 후 매직 리터럴 19건 식별. 신규 상수 제안 10종(lib_audio_in.h에 추가 권장), 기존 상수 재사용 권고 6건, deadcode(주석 잔존 구버전 인덱스) 3건. >> 1 정규화(AUDIO_MIX_NORMALIZE_RSHIFT), 마이크 수 비교(LIB_AUDIO_DMIC_COUNT_1/2), 버퍼 차원 [2][16](LIB_AUDIO_IN_DMIC_COUNT/LIB_AUDIO_IN_BUF_SAMPLE_COUNT), 마이크 버퍼 인덱스(LIB_DMIC_IDX_DMIC1/2), fifo_fill_zero 내 블록 절반 크기(LIB_AUDIO_IN_BUF_HALF_LEN), 지연 오프셋 i+1은 이미 파라미터화된 패턴으로 상수화 불필요 판정. 모든 제안값은 원 리터럴과 완전 동일 검증 완료.
