# 리팩토링 계획 (③ — 승인 게이트)

**TL;DR**: 안전(동작보존)으로 검증된 항목만 적용 — **상수화·주석·데드코드 제거·낡은 주석 정정**. 위험 3건(믹서 언롤→루프·I2S XOR·mic복사 삼항)·블록인덱스 상수화는 **제외**. 모든 상수값=원 리터럴 동일, 주석은 **검증값**으로 작성. include 가시성 확인 완료. **승인 후** ④구현 → 동작보존 전수 검증.

> [!IMPORTANT]
> **본 계획 승인 전 제품 소스 코드 변경 금지.** 아래는 적용 스펙이며, 승인 시 그대로 ④구현한다.

## B. 주석 추가/정정 (검증값으로 직접 작성 — 페르소나 오기 교정)

> [!WARNING]
> 페르소나 제안 주석에 지연값 오기(6/32·0.1875·25mm) 있었음. **아래 검증값만 사용**: HW `FRAC=6 = 6/240 = 0.025샘플`(스텝 1/240), SW 1샘플(믹서 i+1), 합 `1.025샘플 ≈ 64.06µs ≈ 22mm/16kHz`.

1. **버퍼 인덱스 규약** (`lib_audio_in.c` 배열 정의 위 / `lib_audio_in.h:136`):
   `g_lib_dmic_in_buffers[mic][block][sample]` — mic: 0=DMIC1(EZ/U7), 1=DMIC2(QCC/U9) / block: 0=최신 프레임, 1=직전 / sample: 0=최신 … 15=오래됨. (빔포밍 i+1 지연·블록경계가 이 순서에 의존.)
2. **`tdc_copy_DMIC_buffers`** doxygen: FIFO(16샘플)→링버퍼, block[0]→[1] 시프트 후 [0]에 신규.
3. **`audio_mix_2_buffers_for_beamforming`** doxygen: delay-and-sum. 인수(지연 현재/지연 직전/기준 현재), `i+1`=SW 1샘플 지연, `p_mix[15]`=블록 경계(직전 블록[0]), `>> AUDIO_MIX_NORMALIZE_RSHIFT`=2채널 평균 정규화.
4. **`audio_mix_2_buffers`** (`audioMixer.c:43/50`): "독립 음원(mic+I2S) 단순 합산, **의도적 ÷2 생략**" — 빔포밍과의 차이 명시(은수님 검토 반영).
5. **하이브리드 지연**(`lib_audio_in.h:112-113` `_0_0250` 매크로): "HW FRAC=6 = 6/240 = 0.025샘플. SW 1샘플과 합쳐 1.025샘플(≈22mm 음향 경로차). front mic 채널에 적용."
6. **L/R 조향**(`system_control.c:85/91`, `main.c:450/457`): Left→front=DMIC2(ch2), Right→front=DMIC1(ch0); front mic을 지연 채널로.
7. **정정**: `lib_audio_in.h:55` `IN1`→`IN0` / `main.c:88` `ADC1/DMIC1`→`ADC2/DMIC2`.

## F. ④구현 후 검증 계획 (동작보존 전수)

1. **상수 등가**: 각 신규 상수값 == 원 리터럴(빌드 전 grep 대조).
2. **diff 의미 검토**: 변경이 상수치환·주석·데드코드 삭제뿐, 로직 토큰 변화 0(서브에이전트 전수).
3. **빌드**: 은수님 Eclipse 빌드(상수 미가시·오타 0 확인). _빌드 환경은 은수님 측._
4. **할루시네이션 재검증**: 추가/수정 주석의 값이 검증값과 일치.
5. 실패 시 단계 재진입(상한 3회).
