# Gain Conversion Table 기능 — 이력 및 결과

**TL;DR**: Q8.16 게인 테이블(cfx audioMixer) + 0x8C 런타임 설정 + CRADLE 판별 전달 + ISD별 파일 영속화 구현. 빌드·실행 확인 후 `claude_develop` 병합 완료(2026-07-21). 잔여: 앱 연동 E2E(은수님 진행).

## 완료 요약 (2026-07-21)

### 구현 결과

| 영역 | 내용 |
|---|---|
| **게인 테이블** | 256엔트리 Q8.16 룩업 테이블(`audioMixer.c` U13). 인덱스별 나열로 임의 값 교체 가능(확장성 요구). 문서 대조 불일치 0건 |
| **게인 적용** | 신규 믹서 U14 — 48비트 누산 후 1회 시프트, 24비트 초과분은 **절삭(포화)**. 유니티 게인 시 기존 동작과 비트 단위 동일 |
| **적용 매트릭스** | I2S 없음 → 바이패스 / Streaming → Gain_A만 / Mic(Case) → Gain_A+Gain_B / **매핑 중 → 전부 유니티** |
| **런타임 설정** | 0x8C Gain control 프로토콜(`tdc_remote_gain_control.c`). Read/Write 5워드 응답, 저장 실패는 `rsp_code=0`으로 통보 |
| **CRADLE 판별** | 0x36 CLASSIC_STATE에서 공유메모리에 기록 → CFX가 I2S 소스 구분 |
| **ISD별 영속화** | `/GAIN_TBL` 단일 파일(40바이트)로 4슬롯 관리. 매직+CRC와 슬롯별 범위의 **2단 무결성**, 손상 시 부분 복구 |
| **로드/저장 시점** | 로드는 기존 사용자 설정과 같은 지점(`changeConnected_isd_num_CFX()`), 저장은 0x8C Write 시 즉시 |
| **공장 초기화** | 2경로(앱 0x71/0x57, UI·디버그) 모두 게인 초기화 포함. 부팅 경로는 미영향 |

### 주요 설계 판단

- **게인 전용 파일 신설**(기존 `userSettingValue` 확장 기각) — 쓰기 함수의 `(data%16)+4+padding==16` 정렬 불변식 때문에 `int` 하나만 더해도 쓰기가 즉시 실패하고, 기존 저장 파일이 무효화되어 **사용자 볼륨 설정이 초기화될 위험**이 있었다.
- **단일 파일**(ISD별 4파일 기각) — 파일 하나가 4KB 클러스터를 점유하므로 16KB → 4KB.
- **매핑 중 유니티는 적용 시점에서 무시**(공유메모리 덮어쓰기 기각) — 상태를 파괴하지 않아 0x8C Read 일관성이 유지되고 매핑 해제 시 복원 로직이 불필요하다.
- **정렬 불변식 컴파일 타임 검사** — 구조체 확장 시 런타임 무음 실패를 원천 차단.

- 조사 위임 2노드 인용 전수 재확인, **할루시네이션 0건**.

### 잔여
