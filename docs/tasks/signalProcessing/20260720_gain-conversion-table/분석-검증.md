# Gain Conversion Table — 분석 검증 (④)

**TL;DR**: 분석.md 인용 20건 전수 재확인, 오류 0건. 다만 §3.3 초기화 순서 근거에 **정정 1건** — cm3 `Initialize()` 내부 `initialize.c:452`에서 이미 CFX 트리거를 활성화하므로, 기본값 기록은 "Initialize() 내부 아무 곳"이 아니라 **`enable_CFX_trigger_for_iteration()`(:452) 이전**이어야 한다. 결론(3필드 append + Initialize 기본값)은 유지.

## 2. 논리 정합성

- **게인 적용 지점 유일성**: "U3 라이브 호출부 1곳"은 U3 전수 grep 결과(`main.c:381`·`:409`·`:440`) 중 앞의 둘이 DEAD 함수 내부라는 사실로 도출 — 논리 타당. ✅
- **Streaming 시 gain_b=유니티**: 곱셈 항등(65,536 곱 후 >>16 = 원값)에 근거하므로 "Streaming은 I2S 무게인" 요구와 동치. 분기 없이 경로 통일 가능. ✅
- **오버플로 계산**: 최대 입력 2^18 × 최대 게인 2^19 = 2^37, 2항 합 2^38 < 2^47(long 부호 여유). ✅
- **cradle 정의**: `classic_state==1 && classic_type==1`로 좁힌 것은 DISCONN 잔존 오적용을 막음. 요구사항(§2 매트릭스)과 상충 없음. ✅
- **index 0 함정**: "0=미설정" 관례 불가 → 명시 초기화 필요. §3.3 결론과 정합. ✅

## 4. 정정 사항

> [!IMPORTANT]
> **정정_1 (초기화 시점 정밀화)**: 분석 §3.3은 "`Initialize()` 내부에서 기본값을 기록하면 안전"이라고 서술했으나, `Initialize()`는 그 내부 `initialize.c:452`에서 `enable_CFX_trigger_for_iteration()`(CFX_0·FIFO_5 인터럽트 활성화)을 호출한다. CFX 메인 루프의 `normal()` 진입 자체는 `is_enabled_CFX_iteration==1`(`2__cm3/main.c:597`, Initialize 반환 후) 게이트에 걸리지만, **여유를 두어 기본값 기록은 `initialize.c:452` 이전 지점**(예: 공유메모리 초기화가 모여 있는 `:344` `CFX_EEPROM_data_is_Loaded = 1` 인근 또는 `:463` powerButton 초기화 직전)에 배치한다. ⑤계획에서 정확한 삽입 라인을 지정한다.

> [!NOTE]
> **관찰_1 (범위 밖 기록)**: cfx `shared_memory.h`의 `EN__SYSTEM_OP_MODE`에 trailing comma가 있고 cm3 판본에는 없는 등 두 미러 헤더에 사소한 서술 차이가 존재하나, **필드 레이아웃은 동일**하므로 본 작업에 영향 없음. 정리는 범위 밖.

## 7. 설계 결정의 논리 정합성

- **전용 파일 채택의 필연성**: 기존 `userSettingValue` 확장 방안은 기각_1(공유메모리 중간 삽입 → 전 필드 오프셋 이동)·기각_2(28→36바이트로 기존 파일 무효화 → 사용자 설정 초기화)·기각_3(PRAM3 여유 잠식)에 더해, **정렬 불변식으로 인해 `int` 1개만 추가해도 쓰기가 즉시 실패**(28→32에서 `0+4+0=4≠16`)한다는 치명적 사유가 추가됐다. 4개 단위로 맞추면 통과하지만 "우연히 맞는" 상태라 더 위험하다. **전용 파일이 유일한 안전 선택**이며 논리 일관. ✅
- **8바이트 데이터 선택**: Gain_A·Gain_B 2개면 `8%16=8`, padding 4로 성립. 맵 스탬프와 동일 패턴이라 검증된 경로. 향후 필드 1개 확장 시 12바이트(padding 0)로도 성립하므로 확장 여유도 있다. ✅
- **로드 훅 위치**: 기존 사용자 설정이 로드되는 바로 그 함수·그 블록이므로 시점 정합이 구조적으로 보장된다(위험_8 해소). 별도 폴링·플래그 불필요. ✅
- **`normalMode` 가드**: 매핑 모드의 임시 슬롯 번호로 인한 오기록을 막는다. 기존 6개 `change*()` 함수와 동일 관행이라 일관성도 확보. ✅
- **부팅 초기화 생략**: 연결 시 자기수복으로 충분하다는 판단은, ISD 미연결 구간에서는 게인이 쓰이지 않는다는 사실(공유메모리 기본값이 이미 유니티)에 근거한다. 단 **ISD 미연결 상태에서도 오디오는 동작**하므로, 그 구간은 `tdc_remote_gain_control_init()`의 유니티 기본값이 계속 유효하다. 모순 없음. ✅
