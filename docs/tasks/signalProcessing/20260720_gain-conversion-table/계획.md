# Gain Conversion Table 기능 — 계획 (⑤)

**TL;DR**: 6단계로 구현한다. Step1 cfx 게인 테이블·게인 믹서 유닛 → Step2 공유메모리 3필드(양쪽 미러) → Step3 cm3 기본값 초기화 → Step4 cfx 디스패치 게인 결정 → Step5 0x36 cradle 플래그 → Step6 0x8C 핸들러(신규 `tdc_remote_gain_control.c/.h`). 테이블 값은 생성 규칙 `round(10^((i-128)*0.140625/20)*65536)`(i=0은 0)이 문서 256엔트리와 **전수 일치 검증 완료(불일치 0건)**. 승인 필요 결정 2건: 기본 인덱스 값, 공유메모리 멤버 네이밍.

## 1. 구현 단계 (테스트 순서 = 의존성 순서)

### Step 1 — cfx 게인 테이블 + 게인 믹서 유닛 (`audioMixer.c/.h`)

**검증 라벨**: `유닛_게인테이블`, `유닛_게인믹서` (전제: 없음)

`audioMixer.h`:
```c
#define TDC_GAIN_TABLE_SIZE          256
#define TDC_GAIN_TABLE_INDEX_UNITY   128   // 0 dB (Q8.16 = 65536)
#define TDC_GAIN_Q8_16_SHIFT         16

int  tdc_audio_gain_lookup_q8_16(int gain_table_index);
void tdc_audio_mix_2_buffers_with_gain(int _XMEM *p_mic_buf, int _XMEM *p_i2s_buf,
                                       int gain_a_q8_16, int gain_b_q8_16);
```

`audioMixer.c`:
- `int chess_storage(XMEM) m_tdc_gain_table_q8_16[TDC_GAIN_TABLE_SIZE] = { ... }` — 256엔트리, agc.c 테이블 배치 관행(`agc.c:24`) 동일.
- **인덱스별 한 줄 + `[인덱스] dB` 주석**으로 배치한다(결정_4). 임의 인덱스의 값을 개별 교체할 수 있어야 하므로 루프·수식 생성 금지.
- `tdc_audio_gain_lookup_q8_16()`: 범위 밖 인덱스는 유니티(65536) 반환(방어적).
- `tdc_audio_mix_2_buffers_with_gain()`: U3(`tdc_audio_mix_2_buffers`)의 게인 적용판.
  ```
  acc = ((long) gain_a * (p_mic_buf[i] >> AUDIO_INPUT_RSHIFT))
      + ((long) gain_b * (p_i2s_buf[i] >> AUDIO_INPUT_RSHIFT));   // Q24.0 * Q8.16 = Q32.16
  acc >>= TDC_GAIN_Q8_16_SHIFT;                                    // Q32.0
  p_mix[i] = sat24(acc);                                           // INT24_MAX/MIN 클램프
  ```
  - 두 항을 **합산 후 1회 시프트**(항별 시프트보다 반올림 오차 작음). 오버플로 여유는 [`분석.md §1.4`](분석.md) 검증 완료.
  - 포화 클램프는 `apply_agc_gain()`(`agc.c:324~331`) 관행 그대로.
- **U3(`tdc_audio_mix_2_buffers`)는 정의·선언 유지**(라이브 호출부만 교체 — Step 4). DEAD `I2S_handle()`이 계속 참조하므로 삭제 시 컴파일 에러.

**테이블 생성·검증 방법**: 생성 규칙 `q(i) = round(10^((i-128)*0.140625/20) * 65536)`, `q(0)=0`. 스크립트로 C 배열 초기화자를 생성하고, 동시에 `Gain Table.md`의 256개 Q8.16 값과 대조한다. **본 계획 수립 시점에 사전 검증 완료 — 불일치 0건**(⑧에서 최종 소스 대상 재실행).

### Step 2 — 공유메모리 3필드 (양쪽 미러)

**검증 라벨**: `유닛_공유메모리레이아웃` (전제: 없음)

두 헤더 **구조체 맨 끝**에 동일 순서로 append:
- cm3 `src/2__cm3/Cortex-M3-src/systemControl/cfx_cm3_sharedMemory.h` (`ST__CFX_CM3_SharedMemory_ALL`, `:240` 뒤)
- cfx `src/1__cfx/environment/shared_memory.h` (`:218` 뒤)

```c
/* 일시: 2026-07-20
 * 작성: 김은수
 * 내용: Gain Conversion Table 적용 - 앱 0x8C 로 설정되는 게인 인덱스와 I2S 소스 종류 */
int gain_table_index_a;    // 0~255, 마이크 경로 게인 (128 = 0 dB)
int gain_table_index_b;    // 0~255, I2S 크래들 마이크 경로 게인 (128 = 0 dB)

```

### Step 3 — cm3 기본값 초기화

**검증 라벨**: `유닛_기본값초기화` (전제: Step 2)

`src/2__cm3/Cortex-M3-src/systemControl/initialize.c` — **`enable_CFX_trigger_for_iteration()`(`:452`) 이전**([`분석-검증.md §4 정정_1`](분석-검증.md)). 삽입 위치: `:344`(`CFX_EEPROM_data_is_Loaded = 1`) 직후, 기존 공유메모리 초기화 구문 인근.

```c
cfx_cm3_sharedMemoryAll.gain_table_index_a   = TDC_GAIN_TABLE_INDEX_DEFAULT_A;  // 128 (0 dB)
cfx_cm3_sharedMemoryAll.gain_table_index_b   = TDC_GAIN_TABLE_INDEX_DEFAULT_B;  // 128 (0 dB)
cfx_cm3_sharedMemoryAll.is_i2s_source_cradle = 0;
```
기본값 상수는 신규 `tdc_remote_gain_control.h`에 정의(Step 6과 단일 출처 공유).

### Step 4 — cfx 디스패치 게인 결정 (`main.c` M6)

**검증 라벨**: `모듈_게인디스패치` (전제: Step 1·2·3)

`PCM_LiveStimulation_Mode()` I2S 활성 분기(`main.c:436~453`)에서 `main.c:440`의 U3 호출을 교체:

```c
int gain_a = tdc_audio_gain_lookup_q8_16(Addr_SharedMem->gain_table_index_a);
int gain_b = (Addr_SharedMem->is_i2s_source_cradle == 1)
                 ? tdc_audio_gain_lookup_q8_16(Addr_SharedMem->gain_table_index_b)
                 : tdc_audio_gain_lookup_q8_16(TDC_GAIN_TABLE_INDEX_UNITY);  // Streaming: I2S 무게인

tdc_audio_mix_2_buffers_with_gain((int _XMEM *) &g_lib_dmic_in_buffers[LIB_DMIC_IDX_DMIC1][0][0],
                                  p_buffer, gain_a, gain_b);
```
- **I2S 비활성 분기(U1/U2)는 미수정** — 바이패스 요구 그대로.
- Streaming에서 유니티 게인은 비트 정확(항등)이므로 분기 없는 경로 통일이 안전.

### Step 5 — cm3 0x36 CLASSIC_STATE에서 cradle 플래그 기록

**검증 라벨**: `모듈_cradle플래그` (전제: Step 2)

`ble_communication.c:216`의 "향후 크래들과 I2S 게인 테이블 적용" 주석 자리에 기록 코드 삽입(주석은 해소되었으므로 제거):
```c
cfx_cm3_sharedMemoryAll.is_i2s_source_cradle =
    ((classic_state == 1) && (classic_type == 1)) ? 1 : 0;
```
(상수 `1`은 기존 핸들러의 로그 판정과 동일한 리터럴 관행 유지. 매직넘버 대신 enum 도입은 프로토콜 전반 리팩터링이라 범위 밖.)

### Step 6 — cm3 0x8C Gain control 핸들러

**검증 라벨**: `유닛_0x8C핸들러` (전제: Step 2·3)

1. **enum 추가** — `ble_commonProtocol.h:115~118` `EN__SND_BT_CMD_80_RANGE`에:
   ```c
   EN__SND_BT_CMD_GAIN_CONTROL = 0x8C,
   ```
2. **라우팅** — `ble_communication.c:357` 0x8F else-if 옆에 추가:
   ```c
   else if (p_Rx_dataPacket[0] == EN__SND_BT_CMD_GAIN_CONTROL)  // 0x8C 게인 제어 프로토콜
   {
       fetch_remoteControlPacket(p_Rx_dataPacket);
   }
   ```
   `fetch_remoteControlPacket()`의 `default:`(`remoteControl.c:619~624`)가 페이로드를 `remoteDataPacket.data[]`로 복사 — 0x8F와 동일 경로.
3. **신규 파일** `src/2__cm3/Cortex-M3-src/BleCommunication/tdc_remote_gain_control.c/.h` (0x8F 분리 선례 미러):
   ```c
   int tdc_remote_gain_control_handle(const ST__REMOTECONTROL_PACKET *packet, int *tx_buf, int tx_index);
   ```
   - 입력: `data[0]`=Control type(0 Read/1 Write), `data[1]`=Gain type(1 Gain_A/2 Gain_B), `data[2]`=index(0~255).
   - Write: 유효하면 해당 공유메모리 인덱스 갱신 → 응답 index는 **갱신 후 실제 값** 회신.
   - Read: 현재 값 회신.
   - 실패 조건(rsp_code=0): Control type ∉ {0,1}, Gain type ∉ {1,2}(0 Invalid 포함), index ∉ [0,255].
   - 응답(5워드): `[0]=0x8C`, `[1]=rsp_code`, `[2]=Control type`, `[3]=Gain type`, `[4]=index`. 실패 시 수신값 에코(index는 실패 시 현재 저장값이 아니라 수신값 에코 — 앱이 무엇이 거부됐는지 알 수 있게).
   - 기본값 상수 `TDC_GAIN_TABLE_INDEX_DEFAULT_A/B`(=128)를 헤더에 정의.
4. **처리 케이스** — `remoteControl.c:1353` `#endif` 뒤에 0x8F 케이스와 동형으로 추가:
   ```c
   case EN__SND_BT_CMD_GAIN_CONTROL:
   {
       tx_index = tdc_remote_gain_control_handle(&remoteDataPacket, bufferForSPI_tx, tx_index);
       writeDataToSpiTxBuff(bufferForSPI_tx, tx_index);
       clearRemoteColtrolCommand();
   }
   break;
   ```

**빌드 등록**: cm3 `.cproject`는 폴더 단위 등록이라 신규 파일 추가 시 수정 불필요(2026-07-01 선례). Eclipse Refresh로 픽업.

## 3. 위험 대응 (분석 §5 연계)

- 위험_1(전사 오류) → 스크립트 생성 + ⑧ 전수 대조로 해소.
- 위험_2(미러 불일치) → Step 2를 한 커밋에서 양쪽 동시 수정 + ⑧ 대조.
- 위험_3·4(XMEM·사이클) → 빌드·실기 게이트(은수님 환경). 실패 시 롤백 지점 = Step 1·4 커밋.
- 회귀 안전판: 기본값 유니티(결정_1)이므로 앱이 게인을 바꾸기 전까지 **현행과 비트 동일** 동작.

## 6. 설계 확정

| 항목 | 결정 | 근거 |
|---|---|---|
| 저장 방식 | **게인 전용 파일 신설** (기존 파일·구조체 무수정) | [`분석.md §5-2.2`](분석.md) 기각_1~3 + 정렬 불변식 |

| CRC/패딩 | CRC16-CCITT 사용, AES 미사용, padding **4바이트** | 맵 스탬프와 동일 구성(`ci_map.c:104`) |
| RAM 버퍼 | cm3 **static** 버퍼 (PRAM3 미사용) | PRAM3 98.83% 사용 중, 포인터는 인자로 전달 가능 |
| 로드 훅 | `changeConnected_isd_num_CFX()`의 `if (0 < isd_num)` 블록 | 기존 사용자 설정 로드와 동일 시점 |
| 저장 훅 | 0x8C Write 성공 시, `normalMode` + `1 <= isd_num`일 때만 | 기존 `change*()` 관행 |

## 7. 구현 단계 (2차)

### Step 7 — 게인 영속화 모듈 신설 (`tdc_gain_storage.c/.h`)

**검증 라벨**: `유닛_게인파일IO` (전제: 없음)

위치: `src/2__cm3/Gen1_5/FS/`(FS 계층 모듈이므로 `ci_*` 형제 자리). 신규 심볼은 `tdc_` 접두어.

```c
/* 파일명 템플릿: '/','I','S','D','*','_','G','A','I','N','\0' = 11바이트 */
#define TDC_GAIN_FILE_INIT_NAME  { '/', 'I', 'S', 'D', '*', '_', 'G', 'A', 'I', 'N', '\0' }
#define TDC_GAIN_FILE_NAME_LEN   11
#define TDC_GAIN_FILE_INDEX_ISD_NUM 4

typedef struct
{
    int gain_table_index_a;   // 0~255
    int gain_table_index_b;   // 0~255
} ST__TDC_GAIN_SETTING;       // 8바이트 - 정렬 불변식 (8%16)+4+4 == 16

int tdc_gain_storage_load(int isd_num, ST__TDC_GAIN_SETTING *p_out);   // 실패 시 기본값 채워 반환
int tdc_gain_storage_save(int isd_num, const ST__TDC_GAIN_SETTING *p_in);
```

- static 버퍼: `ST__TDC_GAIN_SETTING m_tdc_gain_setting;` + `uint32_t m_tdc_gain_crc_ccitt;` + `uint32_t m_tdc_gain_aes128_padding[1];`
- `load()`: 파일명 치환 → `ci_filesystem_read_with_crc_and_aes128(name, &m_..., sizeof(...), &m_crc, m_padding, 4, true, false)` → **읽기 실패 또는 인덱스 범위(0~255) 위반이면 기본값(128/128)으로 채우고 그 자리에서 `save()` 호출**(자기수복).
- `save()`: `1 <= isd_num <= MaxNumUser` 가드 → 버퍼 채우고 write 호출. 실패는 로그만(결정_6).
- 은수님 지적 사항 반영: `ci_stim_mute`의 `FA_OPEN_APPEND` 오용은 답습하지 않는다(고수준 래퍼만 사용하므로 해당 없음).

### Step 8 — 연결 시 로드 연결

**검증 라벨**: `모듈_연결시로드` (전제: Step 7)

`cfx_cm3_sharedMemory.c` `changeConnected_isd_num_CFX()`의 `if (0 < isd_num)` 블록 끝(`:346` `fn_copy_userSettingParameters_toCM3()` 직후)에:

```c
/* 게인 설정도 해당 ISD 것으로 복원한다.
 * 파일이 없거나 손상됐으면 tdc_gain_storage_load() 가 기본값(유니티)을 돌려준다. */
{
    ST__TDC_GAIN_SETTING gain_setting;

    tdc_gain_storage_load(isd_num, &gain_setting);
    cfx_cm3_sharedMemoryAll.gain_table_index_a = gain_setting.gain_table_index_a;
    cfx_cm3_sharedMemoryAll.gain_table_index_b = gain_setting.gain_table_index_b;
}
```

이로써 요구사항_8(자동 적용)과 요구사항_10(Read 일관성)이 동시 충족된다 — 0x8C Read는 이미 공유메모리를 읽는다.

### Step 9 — 0x8C Write 시 저장

**검증 라벨**: `모듈_Write시저장` (전제: Step 7·8)

`tdc_remote_gain_control.c`의 `gc_write_index()` 이후 저장 경로 추가:

```c
static void gc_save_to_file(void)
{
    ST__TDC_GAIN_SETTING gain_setting;
    int                  isd_num = read_connected_ISD_Num();

    // 매핑 모드에서는 슬롯 번호가 임시값이라 엉뚱한 ISD 에 쓸 수 있다.
    if (cfx_cm3_sharedMemoryAll.systemShare.system_opMode != en__normalMode)
    {
        ci_printw("[GAIN] SKIP SAVE (NOT NORMAL MODE) \r\n");
        return;
    }

    if ((isd_num < 1) || (MaxNumUser < isd_num))
    {
        ci_printw("[GAIN] SKIP SAVE (ISD NOT CONNECTED) \r\n");
        return;
    }

    gain_setting.gain_table_index_a = cfx_cm3_sharedMemoryAll.gain_table_index_a;
    gain_setting.gain_table_index_b = cfx_cm3_sharedMemoryAll.gain_table_index_b;

    tdc_gain_storage_save(isd_num, &gain_setting);
}
```

Write 분기에서 `gc_write_index()` 직후 호출. 응답은 결정_5에 따라 저장 여부와 무관하게 Success.
