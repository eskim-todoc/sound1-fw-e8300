# 계획: UI 명령어로 프로그램(맵) 변경

**TL;DR**: 설계 A 채택. 3 파일 변경 — `tdc_ui_command.h` setter 선언 1 줄, `tdc_ui_command.c` setter 정의 + `handle_program()` 핸들러 + 등록 entry + `isd_interface.h` include, `main.c` setter 호출 1 줄 (`tdc_ui_command_poll()` 직전, `ENABLE_UI_CMD` 가드 안). 단일 commit. 사용자 Eclipse 빌드 + 실기 RTT 검증.

## 1. 변경 디테일

### 1.1 `tdc_ui_command.h`

기존 Override hooks 블록 뒤 (line 19 부근) 에 신규 setter 선언 추가:

```c
/* 실 상태 입력 hook — main.c 매 cycle 호출 */
void tdc_ui_command_set_mapping_connected(bool connected);
```

### 1.2 `tdc_ui_command.c`

**(a) include 추가** (line 14 부근, 다른 ci_* include 와 함께):

```c
#include "isd_interface.h"
```

**(b) static 캐시 변수** (line 60 부근, 기존 override 블록 뒤):

```c
/* main.c 가 매 cycle 갱신 — 실 mapping 연결 상태 */
static bool s_tdc_actual_mapping_connected;
```

**(c) setter 정의** (line 80 부근, 기존 getter 묶음 뒤):

```c
void tdc_ui_command_set_mapping_connected(bool connected)
{
    s_tdc_actual_mapping_connected = connected;
}
```

**(d) `handle_program()` 신규 정적 함수** (line 590 부근, `handle_volume` 뒤):

```c
/* ======================================================================== */
/*  --prog handler                                                          */
/* ======================================================================== */

static int handle_program(int argc, char *argv[])
{
    if (argc < 2) return -1;

    /* 정수 파싱 */
    int n = 0;
    const char *p = argv[1];
    while (*p >= '0' && *p <= '9')
    {
        n = n * 10 + (*p - '0');
        p++;
    }

    if (*p != '\0' || n < 1 || n > MaxNumMap)
    {
        output_printf("invalid: 1~%d\r\n", MaxNumMap);
        return -1;
    }

    /* 가드 1: ISD 연결 */
    ST__ISD_STATUS isd = snd_isd_interface_get_state();
    if (!isd.conneded_ISD)
    {
        output_printf("denied: ISD not connected\r\n");
        return 0;
    }

    /* 가드 2: 자극 10V 정상 (LiveStimulationStandAlone 진입 조건) */
    if (isd.isd_controlState != en__isdStatus_stimul_10V_Ok)
    {
        output_printf("denied: ISD not in stimulation 10V state\r\n");
        return 0;
    }

    /* 가드 3: 매핑 앱 미연결 */
    if (s_tdc_actual_mapping_connected)
    {
        output_printf("denied: mapping app connected\r\n");
        return 0;
    }

    /* 모든 가드 통과 — 호출 */
    changeProgramMapNum(n);
    output_printf("OK: program = %d\r\n", n);
    return 0;
}
```

**(e) 등록 entry 추가** (line 640 부근, `s_tdc_commands[]` 배열):

```c
    {"prog",               handle_program,                "--prog <1~4>"},
```

기존 entry 순서상 `handle_volume` 뒤 `handle_init_all_map` 앞이 자연스럽다.

> [!NOTE]
> `MaxNumMap` 매크로가 `cfx_cm3_sharedMemory.h` 전이로 보이지 않으면 `#include "processorDirective.h"` 명시 추가. 빌드 시 1 차 검증.

### 1.3 `main.c`

기존 `tdc_ui_command_poll()` 호출 블록 (line 560~562) 안에 setter 호출 1 줄 추가:

```c
#ifdef ENABLE_UI_CMD
            tdc_ui_command_set_mapping_connected(BLE_communicationState.mappingConnection);
            tdc_ui_command_poll();
#else
            ...
#endif
```

setter 호출 위치 근거 (분석.md §4): `bleCommunication()` 이 `BLE_communicationState.mappingConnection` 을 갱신한 line 444 이후, 같은 iteration 내에서 호출되어 캐시 최신성 보장.

## 3. 검증 (AC)

| AC | 절차 | 통과 기준 |
|---|---|---|
| AC-1 | ISD 연결 + StandAlone 상태에서 `--prog 1` | `OK: program = 1` 출력 + 맵 1 적용 (자극 변경) |
| AC-2 | `--prog 2/3/4` 각각 입력 | 각 맵 적용 |
| AC-3 | `--prog 0` / `--prog 5` / `--prog abc` / `--prog 99` | `invalid: 1~4` (호출 안 함) |
| AC-4 | ISD 미연결 상태에서 `--prog 1` | `denied: ISD not connected` |
| AC-5 | 매핑 앱 연결 상태에서 `--prog 1` | `denied: mapping app connected` |
| AC-6 | `--help` 출력 | `--prog <1~4>` 라인 자동 노출 |
| AC-7 | `--led show` / `--vol 5` 등 기존 명령 동작 | 회귀 없음 |
| AC-8 | 빌드 | 신규 경고 0, 신규 에러 0 |
