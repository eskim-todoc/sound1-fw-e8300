# LED Fade-Off 비차단(Non-Blocking) 변환 — 요구사항

**TL;DR**: LedOutput.c의 `turnOffLED()`/`led_force_fade_off()`가 폴링(30/40 ms) 패턴으로 main core를 블로킹하는 LED 시스템 설계 원칙(ISR 전담) 위반을 ISR 상태머신 기반 비차단 fade-off로 변환. 호출자 즉시 return, 외부에서 본 fade 시각·소요시간 동작은 보존. 직전 commit `5240bf2`로 15→30 ms 두 배가 되어 시급도 상승.

## 1. 배경

[`src/2__cm3/Cortex-M3-src/systemControl/LedOutput.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/LedOutput.c) 의 두 함수가 폴링 패턴으로 LED fade-off 를 수행하면서 main core 를 블로킹한다.

| 함수 | 위치 | 블로킹 |
|---|---|---|
| `turnOffLED()` | `:632-662` | **30 ms** (`LED_DIMMING_FADE_MAX_MS`) |
| `led_force_fade_off()` | `:363-391` | **40 ms** (`LED_DIMMING_FADE_MAX_MS + 10`) |

공통 패턴:

```c
s_led_isr_suspended = true;
for (...) {
    LED_OUT();
    delay_ms(1);
}
```

→ 진입 시 LED 타이머 ISR 을 **꺼두고** 본인이 직접 폴링.

LED 시스템의 핵심 설계 원칙은 다음과 같다.

> **모든 LED 출력은 타이머 ISR (`CFX_0_IRQHandler` → `led_arbiter_tick` → `LED_OUT`) 에서만 수행한다. main core 는 LED 처리에 갇히지 않는다.**

위 두 함수의 폴링 구현은 이 원칙의 정면 위반이며, **ISR 을 멈춰놓고 직접 폴링**하는 거꾸로 된 구조다.

직전 commit `5240bf2 cm3(led): Fade max 15 → 30ms` 로 블로킹 시간이 15 → 30 ms 로 두 배가 되어 시급도 상승.

---

## 2. 목표

두 함수를 **ISR 상태머신 기반 비차단 fade-off** 로 변환하여:

- 호출자(main loop · sleep 진입 코드 · LED initialize 등) 가 즉시 return — fade 종료를 기다리지 않음.
- LED 상위 출력은 기존 설계 그대로 타이머 ISR 만으로 진행.
- 외부에서 본 fade-off **시각·소요시간 (30 ms / 40 ms) 동작은 보존**.

---

## 3. 수용 기준 (Definition of Done)

| ID | 기준 |
|---|---|
| AC-1 | `turnOffLED()`, `led_force_fade_off()` 호출 직후 호출자는 ≤ 1 ISR tick 이내에 다음 명령으로 진행 |
| AC-2 | Fade-off 동안 LED 출력 갱신은 **ISR 만** 수행, main core 는 다른 작업 가능 |
| AC-3 | Fade-off 외부 관측: 종료까지 총 시간 30 ms / 40 ms ± ISR 한 tick 오차 |
| AC-4 | ISR 비활성 컨텍스트 (Initialize-time — CFX FIFO IRQ 미활성) 에서 호출 시 **즉시 LED OFF 1 회** (fade 의미 없음). 회귀 금지 |
| AC-5 | Fade-off 중 재호출 / 다른 LED 요청 진입 시 안정 동작 (재진입 안전 · arbiter 충돌 없음) |
| AC-6 | 회귀 없음: 정상 부팅 · sleep 진입 · POWER_OFF burst 시퀀스 등 기존 LED 동작 동일 |

## 4. 범위

### 4.1 In-scope

- `LedOutput.c` 의 `turnOffLED()`, `led_force_fade_off()` 두 함수
- `s_led_isr_suspended` 플래그 (제거 또는 의미 재정의)
- 필요 시 `led_arbiter_tick()` 에 fade-off step 분기 추가
- 신규 fade-off 상태 enum / 정적 변수

### 4.2 Out-of-scope

- LED G 미스터리 검증 (B 작업: [bootloader-power-on-indicator/진행상황.md §3.1](../bootloader-power-on-indicator/진행상황.md))
- 부트로더 LED 조기 점등 본 작업 (C 작업: 동상 §3.3 이후)
- LED arbiter 의 다른 로직 · 우선순위 · 색 매핑 변경
- LED 색감, PWM dimming 파라미터 변경
- `LED_DIMMING_FADE_MAX_MS` 값 변경 (현재 30 ms 그대로)
