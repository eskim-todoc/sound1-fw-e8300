# 계획 (Rev.1)

**TL;DR**: 변경 파일 5개, 커밋 4개. data[2] → setter → carryingCaseCoverOpen 갱신 → systemControl 첫 감지 → func_cradle_lid_closed_loop() 약 절전 루프. 뚜껑 열림은 BLE 패킷 수신으로만 감지 후 워치독 리셋. ISD 연결 시 루프 진입 차단.

> [!IMPORTANT]
> **사용자 승인 대기** — 본 파일 확인 후 승인 시 Step 1부터 구현 진입.

---

## 배경

크래들 뚜껑 닫힘 첫 감지 시 FPGA·nRF·QCC·PMIC OFF, CFX 유지, LED OFF → BLE 폴링 최소 루프 대기 → 뚜껑 열림 감지 → 워치독 리셋 재부팅.

---

## 주요 설계 결정

> [!NOTE]
> **충전기 연결 시 QCC 동작**: 충전기 연결 상태에서 QCC_CTRL=0이어도 QCC는 절전모드 미진입. SPI 패킷 수신 유지. 뚜껑·배터리·충전 상태를 이벤트 발생 시 즉각 패킷 전송. QCC_CTRL이 다시 1이 되는 순간 즉각 상태 패킷 재송신.
>
> **뚜껑 열림 감지**: GPIO 폴링 방식 폐기. **무조건 BLE 패킷 수신으로만 감지.** `bleCommunication()` 루프에서 0x34 data[2] 수신 후 `tdc_cradle_get_cover_state()` 확인.
>
> **CFX 유지**: `enter_ULP_mode_Command_CM3_to_CFX = 1` 신호 생략 → CFX 정상 동작 유지.
>
> **QCC 셧다운 딜레이**: 충전기 연결 상태에서 QCC_CTRL=0이어도 QCC가 꺼지지 않으므로 2.2초 딜레이 불필요. `snd_qcc_set_mode(SND_QCC_MODE_SHUTDOWN)` 직후 다음 시퀀스 진행.

```c
{
    if (state == 2)  // 닫힘
    {
        s_tdc_cradle_cover_state = df_Disconnected;  // == df_Closed == 2
    }
    else  // 1=열림, else=열림 처리
    {
        s_tdc_cradle_cover_state = df_Connected;     // == df_Opened == 1
    }
    cfx_cm3_sharedMemoryAll.chargerState.carryingCaseCoverOpen = s_tdc_cradle_cover_state;
    ci_printd("[CRADLE] COVER STATE: %s\r\n", (s_tdc_cradle_cover_state == df_Connected) ? "OPENED" : "CLOSED");
}

int tdc_cradle_get_cover_state(void)
{
    return s_tdc_cradle_cover_state;
}
```

## Step 4 — main.c (약 절전 루프 신설)

### 4-1. func_cradle_lid_closed_loop() 구현

> [!NOTE]
> **충전기 연결 상태에서 QCC_CTRL=0이어도 QCC는 SPI 패킷 계속 수신.** 따라서 약 절전 루프의 `bleCommunication()` 호출이 실질적으로 동작하며, 뚜껑 열림 패킷 수신 시 즉각 감지 가능. 뚜껑 열림 감지는 GPIO 폴링이 아닌 **BLE 패킷 수신으로만** 처리.

`func_sleep()` 이전 위치에 추가:

```c
static void func_cradle_lid_closed_loop(void)
{
    ci_printi("[CRADLE] ENTERING LIGHT SLEEP MODE\r\n");

    SYS_WATCHDOG_REFRESH();

    /* 1. FPGA 리셋 */
    if (write_FPGA_reset())
    {
        ci_printi("[CRADLE] FPGA SW RESET OK\r\n");
    }

    /* 2. nRF 리셋/끄기 (시퀀스 유지, 실효 없음) */
    ResetNRF();
    NRF_Off_Command();

    /* 3. QCC_CTRL = 0 (충전기 연결 시 QCC는 절전 미진입, SPI 패킷 수신 유지) */
    snd_qcc_set_mode(SND_QCC_MODE_SHUTDOWN);

    /* 4. FPGA 슬립 */
    Sys_GPIO_Set_Low(DIO_PIN_INDEX_for_FPGA_SLEEP);

    /* 5. PMIC 끄기 신호 (1.5세대에서 실질 효과 미미, 시퀀스 유지) */
    OnOff_3V_PMIC_CM3_to_CFX(false);

    /* 6. LED 끄기 */
    turnOffLED();

    /* ※ CFX 유지: enter_ULP_mode 신호 보내지 않음 */

    ci_printi("[CRADLE] LIGHT SLEEP ACTIVE. WAITING FOR LID OPEN PACKET...\r\n");

    /* 약 절전 루프 — BLE 패킷 수신으로 뚜껑 열림 감지 */
    ST__ISD_STATUS dummy_isd = {en__isdStatus_NA, false};

    while (1)
    {
        SYS_WATCHDOG_REFRESH();

        /* BLE 통신: 충전 중 QCC는 SPI 패킷 계속 수신 가능 */
        bleCommunication(dummy_isd);
        /* bleCommunication() 내부에서 0x34 수신 시 tdc_charger_set_cradle_cover_state() 호출 */

        /* 뚜껑 열림 패킷 감지 (data[2]=1 또는 else → setter가 df_Connected으로 갱신) */
        if (tdc_cradle_get_cover_state() == df_Connected)  /* df_Connected == df_Opened == 1 */
        {
            ci_printi("[CRADLE] LID OPENED PACKET RECEIVED - WATCHDOG RESET FOR REBOOT\r\n");
            delay_ms(20);  /* 로그 드레인 */
            SYS_WATCHDOG_RESET();
            /* 이후 도달 불가 — 재부팅 후 QCC_CTRL=1 복귀 시 QCC가 즉각 상태 패킷 재전송 */
        }

        /* ULP가 아닌 normal 모드 — delay 없이 인터럽트 기반 iteration */
        SYS_WAIT_FOR_INTERRUPT;
    }
}
```

### 4-2. func_normal() 내 분기 추가

`func_normal()` 메인 루프의 `systemState.systemOff` 체크 블록(라인 737~764) **이전**에 추가:

```c

    /* 도달 불가 (루프 내 SYS_WATCHDOG_RESET()으로 재부팅) */
}
```

## 위험 및 주의사항

| 항목 | 위험도 | 설명 | 대응 |
|---|---|---|---|
| QCC 2.2초 딜레이 | **불필요** | 충전기 연결 시 QCC_CTRL=0이어도 QCC 절전 미진입 | 딜레이 제거, 즉시 다음 시퀀스 |
| carryingCaseCoverOpen GPIO 덮어쓰기 | 중간 | `readUsbConnectorState()` 주기 호출 시 BLE 값 소실 | `snd_charger_set_state()` 수정으로 완화 |
| 워치독 타임아웃 (3.28초) | 낮음 | SYS_WAIT_FOR_INTERRUPT 사용 — 인터럽트 발생마다 반복, 매 반복 리프레시 | normal 모드와 동일 방식 |
| ISD 연결 중 루프 진입 | 낮음 | 프로그램 로직상 진입 불가하나 방어 조건 추가 | `!isd_state.conneded_ISD` 조건으로 차단 |
| EN__SYSTEM_STATE 구조체 미확인 | 중간 | `cradleLidClosed` 필드 추가 가능 여부 | 구현 시 구조체 정의 확인 후 결정 |
| 뚜껑 닫힘 상태에서 재진입 방지 | 중간 | 재부팅 후 QCC가 즉각 data[2]=2(닫힘) 패킷 전송 → 약 절전 재진입 | systemControl.c 엣지 플래그로 처리됨 |
| func_sleep() vs func_cradle_lid_closed_loop() 충돌 | 낮음 | 둘 다 종료 없는 루프 | 함수 진입 전 기존 루프 탈출 확인 |
