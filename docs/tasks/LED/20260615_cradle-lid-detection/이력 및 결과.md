- 뚜껑 열림 감지: BLE 패킷 수신만 (GPIO 폴링 폐기)
- 약 절전 루프: SYS_WAIT_FOR_INTERRUPT 기반 (delay 없음)
- CFX 유지: enter_ULP_mode 신호 생략
- ISD 연결 차단: !isd_state.conneded_ISD 조건
- LED 드라이버: 수정 없음 (turnOffLED() 직접 호출)
