# 요구사항

**TL;DR**: 크래들 충전 중 + 뚜껑 닫힘 첫 감지 시 FPGA·nRF·QCC·PMIC를 끄고 CFX만 살린 채 BLE 폴링 루프 진입 → 뚜껑 열림 패킷 수신 시 워치독 리셋으로 재부팅. `data[2]`(1=열림, 2=닫힘)를 `snd_charger_set_state()` 확장으로 `carryingCaseCoverOpen` 갱신 후 `systemControl.c` 뚜껑 블록에서 감지.

- 2__cm3 프로젝트에서 구현할 것이다.
- EN__SND_BT_CMD_SYSTEM_INFO_POWER 패킷에 대한 내용이다.
- ble_communication.c의 119라인, else if (bleSettingPacket.command == EN__SND_BT_CMD_SYSTEM_INFO_POWER) 블록이 주요 코드 블록이다.
- "bleSettingPacket.data[2]; // 크래들 뚜껑 상태" 를 구현해야 한다.
- 1 : 열림, 2 : 닫힘, else : Invalid. Invalid 상태는 열림 상태로 처리한다.
- charger_connected가 EN__SND_CHARGER_STATE_CONNECTED 상태일 때만 유효하다.
- EN__SND_CHARGER_STATE_CONNECTED 상태가 아니면 크래들 뚜껑 상태 값은 의미가 없다.
- 이 상태 정보를 토대로 패턴이 아닌 LED 기능 자체에 대한 enable/disable을 제어한다.
- 완전한 disable은 아니고, 전체 기능은 동작하지만, 플래그 등의 정보로 LED GPIO를 OFF로 유지하고 있으면 된다.
- 즉, !EN__SND_CHARGER_STATE_CONNECTED 는 항상 LED 정보 표시, EN__SND_CHARGER_STATE_CONNECTED && 크래들 뚜껑 닫힘은 LED 정보 표시 OFF, 이 외에는 전부 LED 정보 표시로 하면된다.
- 내 요구사항을 정리해서 논리적인 로직으로 구성해서 알맞은 코딩 패턴을 구현해라.

## Rev.1 — 약 절전 모드 (크래들 뚜껑 닫힘 시 시스템 처리)

- 크래들 뚜껑이 닫히면 FPGA, ISD 제어가 불필요하므로 약 절전 모드로 진입한다.
- `systemControl.c`의 `else if (chargerState.chargerConnectorPluggedIn == df_Connected)` → `if (carryingCasePluggedIn == df_Connected)` → `if (carryingCaseCoverOpen == df_Connected)` 블록을 활용한다.
- 3분 대기 없이 뚜껑 닫힘 첫 감지 시 즉시 아래 시퀀스를 실행한다 (`func_sleep()`과 유사하나 CFX 제외):
  1. `write_FPGA_reset()`
  2. `ResetNRF()` + `NRF_Off_Command()`
  3. `snd_qcc_set_mode(SND_QCC_MODE_SHUTDOWN)`
  4. `Sys_GPIO_Set_Low(DIO_PIN_INDEX_for_FPGA_SLEEP)`
  5. `OnOff_3V_PMIC_CM3_to_CFX(false)`
  6. `turnOffLED()`
  - **CFX는 끄지 않는다** (FIFO 이벤트 수신 필요)
- 진입 후 `main()`에서 `BLE_communicationState = bleCommunication(isd_state);` 만 지속 반복 호출.
- 뚜껑 열림 패킷 수신(data[2] != 2) 감지 즉시 `SYS_WATCHDOG_RESET()`으로 시스템 재부팅.
