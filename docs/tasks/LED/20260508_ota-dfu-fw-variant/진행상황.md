## 4. 검증 대기 항목

V1. 디폴트 (App) 빌드 — `TDC_FW_VARIANT` 미정의 상태에서 컴파일 통과, 동작 시 `LED_ST_IN_USE` = WHITE / `LED_ST_POWER_ON` 버스트 = SKYBLUE.
V2. Factory Reset 빌드 — 본 파일 디폴트 한 줄을 `#define TDC_FW_VARIANT TDC_FW_VARIANT_FACTORY_RESET` 로 변경 후 컴파일 통과, 동작 시 `LED_ST_IN_USE` = PURPLE / `LED_ST_POWER_ON` 버스트 = WHITE.
V3. (선택) 잘못된 매크로 값 — `#define TDC_FW_VARIANT 99` 시 `#error` 로 빌드 실패.
V4. 디스크립터 표 다른 항목 색·타이밍 동일 (BATT_READY 녹색, BATT_MID 노랑, error 빨강 점멸 등).
