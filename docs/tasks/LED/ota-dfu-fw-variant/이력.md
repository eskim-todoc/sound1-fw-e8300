## 3. 주요 설계 결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | 매크로 위치 = `LedOutput.c` 자체 | 변종이 LED 색만 영향 → 관심사 응집. `#ifndef` 외부 override 가능 |
| 2 | 디폴트 = APP | App 이 정식 운용 시나리오, 안전한 출고 default. Factory Reset 은 명시적 opt-in |

| 4 | 색 매크로 추상화 (`TDC_FW_LED_*_COLOR`) | 디스크립터 표 행이 단일 토큰 → 표 가독성 보존 |
| 5 | 잘못된 값 = `#error` | 즉시 빌드 실패로 silent failure 방지 |
| 6 | 패턴 재사용 | 보드 변종 작업(`TDC_BOARD_VARIANT`) 도 동일 형태로 정리 (`touch/board-variant-iqs323-ati`) |

## 5. 호출자 영향

- 디스크립터 표 (`k_led_patterns[]`) 의 두 항목 (`LED_ST_IN_USE`, `LED_ST_POWER_ON`) 만 매크로 경유로 변경. 외부 인터페이스(`led_request`/`led_arbiter_tick`/`LED_OUT` 등) 무변경.
- 운용 빌드(매크로 미정의) 시 디폴트 APP → 기존 baseline (en__LED_WHITE / en__LED_SKYBLUE) 와 동등.
- Factory Reset 빌드는 본 파일 디폴트 한 줄 변경 또는 `-DTDC_FW_VARIANT=TDC_FW_VARIANT_FACTORY_RESET` 빌드 옵션.
