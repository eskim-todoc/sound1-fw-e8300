# OTA DFU FW 이미지 변종별 LED 색상 정리 — 이력

**TL;DR**: 2026-05-08 당일 완료. LedOutput.c 디스크립터 표 안의 `en__LED_PURPLE/*en__LED_WHITE*/` 코멘트-스왑 형태를 빌드 매크로 `TDC_FW_VARIANT` (APP / FACTORY_RESET) 분기로 정리. 디폴트 = APP. 사용자 빌드 + 실기 검증 통과 ("다 잘 빌드 된다. 동작도 정상이야"). LedOutput.c +38/-2 단일 commit. 동일 패턴이 [`touch/board-variant-iqs323-ati`](../../touch/board-variant-iqs323-ati/) 에도 적용됨.

작업 슬러그: `LED/ota-dfu-fw-variant`
브랜치: `claude_feature_ota-dfu-fw-variant-led` (base: `claude_develop`) — 보드 변종 작업과 공유
기간: 2026-05-08 (당일 완료)
상태: **완료** (사용자 검증 통과)

## 1. 결과 요약

- 사용자 검증: **빌드·동작 정상** (디폴트 APP + 사용자 로컬 FACTORY_RESET 토글 양쪽). "다 잘 빌드 된다. 동작도 정상이야."
- 회귀: 없음 (디스크립터 표 외 동작 무변경, dimming/fade/GPIO 매핑 모두 보존)

- 부수: `ci_ble_control_boot.c` 의 QCC SHUTDOWN 시퀀스 변경(working tree 잔존)은 별도 작업

## 3. 주요 설계 결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | 매크로 위치 = `LedOutput.c` 자체 | 변종이 LED 색만 영향 → 관심사 응집. `#ifndef` 외부 override 가능 |
| 2 | 디폴트 = APP | App 이 정식 운용 시나리오, 안전한 출고 default. Factory Reset 은 명시적 opt-in |
| 3 | 매크로 명 = `TDC_FW_VARIANT` | `tdc_` prefix 일관 + 도메인(FW 이미지) 정확 |
| 4 | 색 매크로 추상화 (`TDC_FW_LED_*_COLOR`) | 디스크립터 표 행이 단일 토큰 → 표 가독성 보존 |
| 5 | 잘못된 값 = `#error` | 즉시 빌드 실패로 silent failure 방지 |
| 6 | 패턴 재사용 | 보드 변종 작업(`TDC_BOARD_VARIANT`) 도 동일 형태로 정리 (`touch/board-variant-iqs323-ati`) |

## 5. 호출자 영향

- 디스크립터 표 (`k_led_patterns[]`) 의 두 항목 (`LED_ST_IN_USE`, `LED_ST_POWER_ON`) 만 매크로 경유로 변경. 외부 인터페이스(`led_request`/`led_arbiter_tick`/`LED_OUT` 등) 무변경.
- 운용 빌드(매크로 미정의) 시 디폴트 APP → 기존 baseline (en__LED_WHITE / en__LED_SKYBLUE) 와 동등.
