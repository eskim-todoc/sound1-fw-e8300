# ISD 연결/해제 LED 제어 요구사항

**TL;DR**: 내부기(ISD) 연결 중에는 그 ISD의 사용자 설정 정보(LED 표시값 1=켜기/2=끄기)를 따라 LED를 켜거나 끄고, 연결 해제 시에는 사용자 설정을 무시하고 배터리 레벨에 맞는 LED를 켠다. 본 문서는 7개 상태 전이 시나리오를 수용 기준으로 정의한다.

## 1. 용어

| 용어 | 의미 |
|---|---|
| ISD (내부기) | 인공와우 내부 자극기 (Implantable Stimulation Device). 외부기에 연결/해제됨 |
| 사용자 설정 정보 (userSettingValue) | ISD별 사용자 설정. 공유메모리 `cfx_cm3_sharedMemoryAll.userSettingValue` |
| LED 표시값 (indicatorLED_OnOff) | 사용자 설정 중 LED on/off. **1=켜기, 2=끄기**. `readLED_indicatorOnOff()` 반환 |
| 배터리 레벨 LED | 배터리 잔량에 따른 표시 — 정상=백색(IN_USE)·중간=주황(BATT_MID)·위급=주황 깜박(BATT_CRITICAL) |

## 2. 핵심 원칙

> **연결 중**에는 그 ISD의 *사용자 설정 정보(LED 표시값)*를 따르고, **연결 해제 시**에는 사용자 설정을 무시하고 *배터리 레벨*을 따른다.

- 켜질 때 색은 배터리 레벨에 종속: 평상시 백색, 배터리 위급 시 주황 깜박.
- 연결 해제 시 직전 ISD의 사용자 설정값이 공유메모리에 잔존하더라도(초기화되지 않음) 이를 무시해야 한다.

## 3. 수용 기준 (시나리오)

| # | 상황 | 기대 LED |
|---|---|---|
| AC-1 | 전원 인가 직후, ISD 미연결 | **배터리 레벨** LED 켜짐 (배터리 정보 미수신 시 판정 보류) |
| AC-2 | ISD 연결, 사용자 설정 LED=1 | **켜짐** (배터리 정상=백색 / 위급=주황 깜박) |
| AC-3 | ISD 연결, 사용자 설정 LED=2 | **꺼짐** |
| AC-4 | AC-3 상태에서 연결 해제 (설정값 2 잔존) | **배터리 레벨** LED 켜짐 (설정 무시) |
| AC-5 | AC-4에서 동일 ISD(LED=2) 재연결 | 다시 **꺼짐** |
| AC-6 | AC-5에서 다시 연결 해제 | 다시 **배터리 레벨** LED 켜짐 |
| AC-7 | AC-6에서 새 ISD(LED=1) 연결 | **켜짐** |

## 4. 검증·수정 방침 (사용자 확정)

- **검증 방식**: 정적 분석(시나리오별 `led_request` → arbiter → 최종 색 추적) 후, 이상 없으면 실보드 확인.
- **수정 범위**: 검증 중 문제 발견 시 검증 리포트와 함께 구체적 수정안(diff)까지 제시. **적용은 사용자 승인 후.**

## 5. 범위

- **포함**: ISD 연결/해제에 따른 LED arbiter 동작(`main.c` LED 판정 + `LedOutput.c compute_best_state`).
- **제외(별개 변경)**: working tree에 함께 있는 ble 0x36 CLASSIC_STATE 추가, remoteControl passkey 우회 디버그, 배터리 임계 테스트값은 본 작업과 분리하여 커밋 시 별도 취급.
