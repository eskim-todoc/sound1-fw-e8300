## 3. 호출자 영향

`turnOffLED()` 4 호출 사이트, `led_force_fade_off()` 1 호출 사이트 모두 **시그니처·코드 변경 없음**.

| 호출자 | 위치 | 비차단 변환 후 동작 |
|---|---|---|
| `Uninitialize()` | `initialize.c:179` | ISR 비활성 (NVIC disable + `led_isr_active_set(false)`) → 즉시 OFF |
| `Initialize()` 후반 | `initialize.c:304` | `enable_CFX_trigger_for_iteration` 호출 전 → ISR 비활성 → 즉시 OFF |
| `systemControl()` charger detach | `systemControl.c:211` | ISR 활성 → **비차단 fade (30 ms 절약 효과)** |
| `func_sleep()` | `main.c:691` | `s_led_isr_suspended == true` (`led_force_fade_off` 가 set) → 즉시 OFF |
| `func_normal()` sleep 진입 | `main.c:638` | ISR 활성 → **비차단 fade (40 ms 절약 효과)** |

## 4. 부수 효과 — 잠재 버그 자연 해소

[분석.md §4.1](분석.md) 에서 식별한 `s_led_isr_suspended` 풀림 잠재 버그가 본 변환으로 해소:

```text
[기존]
led_force_fade_off()  → suspended = true (영구 의도)
…
turnOffLED()          → set true (no-op) → fade → clear false  ★ 풀림
ci_power_sleep        → IRQ 시 LED 갱신 가능 (의도 위반)

[변환 후]
led_force_fade_off()  → fade-off state ACTIVE + suspended = true
…
turnOffLED()          → !led_arbiter_can_run() (suspended) → 즉시 OFF, suspended 손대지 않음 ✓
ci_power_sleep        → IRQ 시 가드 1 (fade-off IDLE) → 가드 2 (suspended) → 즉시 return ✓
```

## 5. 설계 결정 사항 (사용자 승인)

| 항목 | 결정 |
|---|---|
| ISR 활성 검사 방법 | 정적 플래그 (`s_led_isr_active`), `led_isr_active_set()` 로 외부 통지 |
| Sleep 진입 LED 보호 | `s_led_isr_suspended` 영구 set 유지 + `led_arbiter_tick` 가드 순서 변경 (fade-off step → suspended) |
| Fade-off 중 high-priority 진입 | `compute_best_state() != LED_ST_IDLE` 검사 → 즉시 중단, cross-fade 메커니즘이 새 패턴 fade-in 자연 처리 |
