# 부트로더 단계 LED 조기 점등 — 구현계획

**TL;DR**: 사용자 결정 D-1~D-9 반영. Timer2 + 자체 SW PWM(SKYBLUE k_led_mix 비율 차용)으로 부트로더 T-B(`Sys_Trims_SetOperatingFrequency()` 직후) 점등 시작·`bootloader_boot_cm3()` 직전 정리. 신규 `tdc_boot_led_*` 모듈을 `0__bootloader/{include,source}/led/`에 추가, `TDC_BOOT_LED_ENABLE` 빌드 가드 + UART 검증 핀(`DIO_NUM_UART_ENABLE`) 2단 분기로 디폴트 OFF·기존 동작 100% 유지.

작성일: 2026-04-30
Rev: Rev.1 — 사용자 피드백 반영 (네이밍 지침 적용 + ISR IRQ Clear 제거)

관련: [요구사항.md Rev.3](요구사항.md), [분석.md Rev.2](분석.md), [진행상황.md](진행상황.md)

## 0. 사용자 결정 사항 (분석.md §2.8 D-1~D-9)

| ID | 결정 |
|---|---|
| D-1 | 타이머 = **Timer2** (CM3 미점유 — F-10) |
| D-2 | LED 엔진 = **자체 구현** (SKYBLUE 단색 SW PWM, k_led_mix[en__LED_SKYBLUE] G:B=30:40 비율 차용) |
| D-3 | 점등 시작 시점 = **T-B** = `Sys_Trims_SetOperatingFrequency()` 직후 ([bootloader.c:643](../../../../src/0__bootloader/source/bootloader.c)). 통합은 caller 측 [bootloader.c:1496](../../../../src/0__bootloader/source/bootloader.c) 직후 (계층 깔끔) |
| D-4 | main.c:16-24 디버그 GPIO 블록을 빌드 가드로 무력화 → GPIO `DIO_MODE_DISABLE` (hi-Z) 유지 → 풀다운 자연 OFF → T-B 시 SW PWM fade-in 자연 점등 |
| D-5 | Fade = 30 + **300** + 30 + 180 = **540 ms / cycle** |
| D-6 | `bootloader_boot_cm3()` 직전 wait — total ≥ 540 ms 보장 후 SW PWM 정리 |
| D-7 | 빌드 가드 + 런타임 UART 검증 핀 (`DIO_NUM_UART_ENABLE`, [main.c:59](../../../../src/0__bootloader/main.c)) 2 단 분기. 가드 ON + UART 비활성에서만 LED 활성 |
| D-8 | LED 극성 = **active HIGH**. ON = GPIO HIGH, OFF = GPIO LOW or hi-Z+풀다운 |
| D-9 | Phase 1 의무 O-1 (PRAM5 배치) / O-2 (NVIC enable) / O-3 (종료 정리) / O-4 (ISR 우선순위) 모두 적용 |

### 1.2 호출자 영향

- `main.c` 동작 — 빌드 가드 OFF (`TDC_BOOT_LED_ENABLE=0`, 디폴트) 시 기존 부트로더 동작 100% 유지 (디버그 LED + UART + service mode 분기 모두 그대로).
- 빌드 가드 ON (`=1`) + UART 활성 시: SW PWM 시작 안 함, LED 동작 없음.
- 빌드 가드 ON (`=1`) + UART 비활성 시: T-B 도달부터 540 ms 동안 SKYBLUE fade cycle 1 회 + 540 ms 보장 후 CM3 점프.

## 2. 신규 모듈 — `tdc_boot_led`

### 2.1 인터페이스 (`tdc_boot_led.h`)

```c
#ifndef __tdc_boot_led_h__
#define __tdc_boot_led_h__

#include <stdbool.h>
#include <stdint.h>

/* 본 모듈은 TDC_BOOT_LED_ENABLE 가드 활성 시에만 빌드된다.
 * 외부 (bootloader.c) 는 자기 측 가드 안에서 본 API 호출. */

/* GPIO config (G/B = active HIGH output) + Timer2 init + NVIC IRQ enable.
 * 호출 후 ISR 가 동작 가능 상태. start() 가 호출되어야 phase 진입.
 * 멱등 — 중복 호출 안전 (이미 init 됐으면 no-op). */
void tdc_boot_led_init(void);

/* FADE_IN phase 진입 — ISR tick 으로 카운터 증가, 540 ms 진행.
 * init() 선행 필요. */
void tdc_boot_led_start(void);

/* 즉시 정지 — Timer2 stop + NVIC IRQ disable + LED 핀 GPIO LOW write (OFF).
 * O-3 의무 사항. CM3 점프 직전 호출. */
void tdc_boot_led_stop(void);

/* Phase == DONE 도달 여부 — bootloader.c 의 wait 로직에 사용.
 * 540 ms (fade-in 30 + peak 300 + fade-out 30 + off 180) 경과 시 true. */
bool tdc_boot_led_is_done(void);

/* (디버그·검증용) start() 이후 경과 시간 ms. ISR-safe 한 read.
 * wait 로직에서 start() 호출 여부 판단에도 사용 (== 0 이면 미시작). */
uint32_t tdc_boot_led_elapsed_ms(void);

#endif /* __tdc_boot_led_h__ */
```

### 2.2 내부 데이터 (`tdc_boot_led.c`)

```c
/* SW PWM 매개변수 — 분석.md D-2/D-5 기반 */
#define TDC_BOOT_LED_PWM_RESOLUTION   100   /* 한 PWM 주기 = 100 bin */
#define TDC_BOOT_LED_PWM_BIN_US       10    /* 1 bin = 10 us → PWM 주기 = 1 ms = 1 kHz */
#define TDC_BOOT_LED_TIMER_RELOAD     (...)  /* SDK 함수 인자에 맞춰 30.72 MHz × 10 us 환산값으로 Step 2 에서 확정 */

/* k_led_mix[en__LED_SKYBLUE] = {R=0, G=30, B=40} (LedOutput.c:820-912 참조) — 비율 차용.
 * PWM_RESOLUTION = 100 이라 G duty 30/100 = 30%, B duty 40/100 = 40%. */
#define TDC_BOOT_LED_DUTY_G_MAX       30
#define TDC_BOOT_LED_DUTY_B_MAX       40

/* Phase 시간 (ms) — D-5 */
#define TDC_BOOT_LED_T_FADE_IN_MS     30
#define TDC_BOOT_LED_T_PEAK_MS        300
#define TDC_BOOT_LED_T_FADE_OUT_MS    30
#define TDC_BOOT_LED_T_OFF_MS         180
#define TDC_BOOT_LED_T_TOTAL_MS       (TDC_BOOT_LED_T_FADE_IN_MS \
                                     + TDC_BOOT_LED_T_PEAK_MS \
                                     + TDC_BOOT_LED_T_FADE_OUT_MS \
                                     + TDC_BOOT_LED_T_OFF_MS)  /* 540 */

typedef enum {
    TDC_BOOT_LED_PHASE_IDLE = 0,
    TDC_BOOT_LED_PHASE_FADE_IN,
    TDC_BOOT_LED_PHASE_PEAK,
    TDC_BOOT_LED_PHASE_FADE_OUT,
    TDC_BOOT_LED_PHASE_OFF,
    TDC_BOOT_LED_PHASE_DONE,
} tdc_boot_led_phase_t;

/* ISR <-> main 공유 — volatile 필수. ISR 는 본 모듈 내부에서만 갱신. */
static volatile tdc_boot_led_phase_t s_tdc_boot_led_phase       = TDC_BOOT_LED_PHASE_IDLE;
static volatile uint32_t             s_tdc_boot_led_pwm_bin     = 0;   /* 0 ~ PWM_RESOLUTION-1 */
static volatile uint32_t             s_tdc_boot_led_elapsed_ms  = 0;   /* start 이후 누적 ms */
static volatile uint8_t              s_tdc_boot_led_duty_g      = 0;   /* 0~DUTY_G_MAX */
static volatile uint8_t              s_tdc_boot_led_duty_b      = 0;   /* 0~DUTY_B_MAX */
static          bool                 s_tdc_boot_led_initialized = false;
```

### 2.3 ISR (Timer2)

```c
/* Timer2 ISR 핸들러 — 10 us 주기 (100 kHz).
 *
 * Cortex-M3 NVIC 는 ISR entry/exit 시 IRQ active bit 자동 set/clear.
 * peripheral pending bit 도 RSL10 Timer 는 hardware auto-clear (또는 read-to-clear)
 * 라 ISR 본문에서 명시적 ack 호출 불필요 — Step 2 빌드/측정에서 재확인.
 *
 * 부트로더 외 다른 ISR 없음 (분석 §1 F-3, F-4) → uninterrupted.
 * 처리 시간 ~30 cycles @ 30.72 MHz ≈ 1 us — 충분 여유. */
void TIMER2_IRQHandler(void)
{
    /* PWM bin 증가 (0~99 cycle) */
    uint32_t bin = s_tdc_boot_led_pwm_bin + 1;
    if (bin >= TDC_BOOT_LED_PWM_RESOLUTION) bin = 0;
    s_tdc_boot_led_pwm_bin = bin;

    /* PWM 출력 — active HIGH (D-8). bin < duty 면 ON (HIGH), else OFF (LOW). */
    Sys_GPIO_Write(DIO_NUM_LED_G_UART_RX_E8300, (bin < s_tdc_boot_led_duty_g) ? 1 : 0);
    Sys_GPIO_Write(DIO_NUM_LED_B,               (bin < s_tdc_boot_led_duty_b) ? 1 : 0);

    /* PWM 한 주기 완료 (bin == 0) → 1 ms 경과 → phase tick */
    if (bin == 0) {
        s_tdc_boot_led_elapsed_ms++;
        phase_tick();  /* ISR 컨텍스트에서 호출 */
    }
}
```

> [!NOTE]
> Step 2 측정 시 IRQ 가 한 번만 들어오고 멈추거나, latch 가 풀리지 않아 즉시 재진입하는 현상이 보이면 peripheral 측 read-to-clear 호출 (예: `Sys_Timer_Clear(TIMER_2)` 또는 STATUS 레지스터 read) 을 ISR 첫 줄에 추가. RSL10 SDK 표준 동작 확인 후 결정.

### 2.4 Phase 진행 로직

```c
/* ISR 컨텍스트 호출 — bin == 0 시 1 ms 마다 1 회.
 * 본 함수가 phase, duty_g, duty_b 를 갱신. static — prefix 불필요. */
static void phase_tick(void)
{
    uint32_t t = s_tdc_boot_led_elapsed_ms;

    switch (s_tdc_boot_led_phase) {
        case TDC_BOOT_LED_PHASE_FADE_IN: {
            /* t = 1 ~ 30. duty 0 → max 선형 증가 */
            if (t >= TDC_BOOT_LED_T_FADE_IN_MS) {
                s_tdc_boot_led_phase  = TDC_BOOT_LED_PHASE_PEAK;
                s_tdc_boot_led_duty_g = TDC_BOOT_LED_DUTY_G_MAX;
                s_tdc_boot_led_duty_b = TDC_BOOT_LED_DUTY_B_MAX;
            } else {
                s_tdc_boot_led_duty_g = (uint8_t) ((TDC_BOOT_LED_DUTY_G_MAX * t) / TDC_BOOT_LED_T_FADE_IN_MS);
                s_tdc_boot_led_duty_b = (uint8_t) ((TDC_BOOT_LED_DUTY_B_MAX * t) / TDC_BOOT_LED_T_FADE_IN_MS);
            }
            break;
        }
        case TDC_BOOT_LED_PHASE_PEAK: {
            /* t = 31 ~ 330 동안 duty 유지 */
            if (t >= TDC_BOOT_LED_T_FADE_IN_MS + TDC_BOOT_LED_T_PEAK_MS) {
                s_tdc_boot_led_phase = TDC_BOOT_LED_PHASE_FADE_OUT;
            }
            break;
        }
        case TDC_BOOT_LED_PHASE_FADE_OUT: {
            /* t = 331 ~ 360. duty max → 0 선형 감소 */
            uint32_t fo_t = t - (TDC_BOOT_LED_T_FADE_IN_MS + TDC_BOOT_LED_T_PEAK_MS);
            if (fo_t >= TDC_BOOT_LED_T_FADE_OUT_MS) {
                s_tdc_boot_led_phase  = TDC_BOOT_LED_PHASE_OFF;
                s_tdc_boot_led_duty_g = 0;
                s_tdc_boot_led_duty_b = 0;
            } else {
                s_tdc_boot_led_duty_g = (uint8_t) ((TDC_BOOT_LED_DUTY_G_MAX
                                                  * (TDC_BOOT_LED_T_FADE_OUT_MS - fo_t))
                                                  / TDC_BOOT_LED_T_FADE_OUT_MS);
                s_tdc_boot_led_duty_b = (uint8_t) ((TDC_BOOT_LED_DUTY_B_MAX
                                                  * (TDC_BOOT_LED_T_FADE_OUT_MS - fo_t))
                                                  / TDC_BOOT_LED_T_FADE_OUT_MS);
            }
            break;
        }
        case TDC_BOOT_LED_PHASE_OFF: {
            /* t = 361 ~ 540. duty 0 유지 */
            if (t >= TDC_BOOT_LED_T_TOTAL_MS) {
                s_tdc_boot_led_phase = TDC_BOOT_LED_PHASE_DONE;
            }
            break;
        }
        case TDC_BOOT_LED_PHASE_DONE:
        case TDC_BOOT_LED_PHASE_IDLE:
        default:
            /* 추가 진행 없음 */
            break;
    }
}
```

### 2.5 공개 API 구현

```c
void tdc_boot_led_init(void)
{
    if (s_tdc_boot_led_initialized) return;

    /* GPIO config — G/B 만 output 활성. R 핀은 hi-Z 유지 (UART TX 와 공유, 본 작업 미사용).
     * D-8: active HIGH 라 디폴트 LOW write 면 LED OFF.
     * 풀다운 자연 OFF 상태에서 정확히 OFF 출력으로 전환 — 스파이크 없음. */
    Sys_GPIO_Set_Low(DIO_NUM_LED_G_UART_RX_E8300);  /* OFF (active HIGH) */
    Sys_GPIO_Set_Low(DIO_NUM_LED_B);                /* OFF */
    Sys_DIO_Config(DIO_NUM_LED_G_UART_RX_E8300, DIO_CFG_LED);
    Sys_DIO_Config(DIO_NUM_LED_B,               DIO_CFG_LED);

    /* Timer2 setup — 10 us 주기 (Step 2 에서 SDK 함수 시그너처 확정).
     * 분석 §1.4 O-1 (PRAM5 배치) — 본 .c 가 부트로더 sections.ld 로 link 되므로 자동. */
    Sys_Timer_Set(TIMER_2, TDC_BOOT_LED_TIMER_RELOAD, ...);  /* 가설 — Step 2 확정 */

    /* O-2: NVIC IRQ enable (부트로더 main.c:40 의 Sys_NVIC_DisableAllInt 이후 명시적 enable).
     * init 시점의 pending clear 는 잔여 pending 보호 차원으로 1 회 수행 — ISR 본문 ack 와 별개. */
    NVIC_ClearPendingIRQ(TIMER_2_IRQn);
    NVIC_SetPriority(TIMER_2_IRQn, 0);  /* O-4: 부트로더에 다른 ISR 없음, 우선순위 무관 */
    NVIC_EnableIRQ(TIMER_2_IRQn);

    s_tdc_boot_led_initialized = true;
}

void tdc_boot_led_start(void)
{
    /* 상태 초기화 + Timer2 가동 */
    s_tdc_boot_led_phase      = TDC_BOOT_LED_PHASE_FADE_IN;
    s_tdc_boot_led_pwm_bin    = 0;
    s_tdc_boot_led_elapsed_ms = 0;
    s_tdc_boot_led_duty_g     = 0;
    s_tdc_boot_led_duty_b     = 0;

    Sys_Timer_Start(TIMER_2);  /* 가설 — Step 2 확정 */
}

void tdc_boot_led_stop(void)
{
    /* O-3: NVIC disable + Timer 정지 + LED OFF + 상태 초기화 */
    NVIC_DisableIRQ(TIMER_2_IRQn);
    Sys_Timer_Stop(TIMER_2);

    /* LED OFF — active HIGH 라 LOW write */
    Sys_GPIO_Set_Low(DIO_NUM_LED_G_UART_RX_E8300);
    Sys_GPIO_Set_Low(DIO_NUM_LED_B);

    s_tdc_boot_led_phase       = TDC_BOOT_LED_PHASE_DONE;
    s_tdc_boot_led_initialized = false;
}

bool tdc_boot_led_is_done(void)
{
    /* volatile read — ISR 가 갱신 */
    return (s_tdc_boot_led_phase == TDC_BOOT_LED_PHASE_DONE);
}

uint32_t tdc_boot_led_elapsed_ms(void)
{
    return s_tdc_boot_led_elapsed_ms;
}
```

> [!NOTE]
> Timer2 SDK 함수 시그너처 (`Sys_Timer_Set`, `Sys_Timer_Start`, `Sys_Timer_Stop` 등) 와 IRQ 핸들러 이름 (`TIMER2_IRQHandler`) / IRQ 번호 (`TIMER_2_IRQn`) 는 **Step 2 (build smoke test)** 에서 1 차 확정. SDK 가용성에 따라 직접 레지스터 manipulation 으로 fallback 가능 (분석 §2.1 D-1 결정).

 * =0: 비활성 (디폴트, 기존 부트로더 동작 유지)

### 3.2 `main.c` — 디버그 LED 블록 가드

`main.c:16-24` 의 `#if 1` 블록을 빌드 가드 분기로 변경:

```c
#if !TDC_BOOT_LED_ENABLE
    /* 부팅 시간 체크용 디버그 LED (가드 OFF 시 기존 동작 그대로) */
    Sys_DIO_Config(DIO_NUM_LED_R_UART_TX_E8300, DIO_CFG_LED);
    Sys_DIO_Config(DIO_NUM_LED_G_UART_RX_E8300, DIO_CFG_LED);
    Sys_DIO_Config(DIO_NUM_LED_B, DIO_CFG_LED);

    Sys_GPIO_Write(DIO_NUM_LED_R_UART_TX_E8300, 0);
    Sys_GPIO_Write(DIO_NUM_LED_G_UART_RX_E8300, 1);
    Sys_GPIO_Write(DIO_NUM_LED_B, 1);
#endif  /* !TDC_BOOT_LED_ENABLE */
```

> [!NOTE]
> 가드 ON 시 LED 핀 (DIO8/15/12) 는 DIO_MODE_DISABLE (hi-Z) 유지 → 풀다운으로 자연 OFF (D-4, 사용자 명시). T-B 도달 시 `tdc_boot_led_init()` 가 G/B 핀만 GPIO output 으로 활성. R 핀은 hi-Z 유지.

### 3.3 `bootloader.c` — T-B 진입 (init + start)

`bootloader_boot()` 안 `bootloader_load_manu_table()` 호출 직후 (line 1496 근처):

```c
ret = bootloader_load_manu_table(boot_info->boot_manu_off);
/* T-B 도달: 클럭 30.72 MHz 안정 (Sys_Trims_SetOperatingFrequency 직후) */

#if TDC_BOOT_LED_ENABLE
    {
        /* 런타임 UART 검증 핀 read — main.c:59 와 동일 매크로 사용.
         * UART 활성이면 G 핀 (UART RX 와 공유) 점유 불가 → LED 비활성. */
        bool uart_active = (Sys_GPIO_Read(DIO_NUM_UART_ENABLE) == DIO_ACTIVE_LEVEL_UART_ENABLE);
        if (!uart_active) {
            tdc_boot_led_init();
            tdc_boot_led_start();
        }
        /* uart_active == true 이면 본 작업 미가동, GPIO disable 유지 */
    }
#endif
```

`bootloader.c` 상단 include 에 `<tdc_boot_led.h>` 추가.

### 3.4 `bootloader.c` — `bootloader_boot_cm3()` 호출 직전 wait + stop

`bootloader.c:1374` 직전에 wait + stop 로직 삽입:

```c
if (cm3_boot_flag == SHOULD_BOOT)
{
#if TDC_BOOT_LED_ENABLE
    /* start() 가 호출됐을 때만 (= 가드 ON + UART 비활성) wait. elapsed_ms == 0 면 미시작. */
    if (tdc_boot_led_elapsed_ms() > 0)
    {
        while (!tdc_boot_led_is_done()) {
            /* SW PWM ISR 가 LED 출력 갱신, 본 main loop 는 단순 wait */
        }
        tdc_boot_led_stop();
    }
#endif
    /* Doesn't return */
    bootloader_boot_cm3(cm3_boot_data.stack_pointer, cm3_boot_data.init_pointer);
}
```

## 4. 단계별 구현 순서

| Step | 작업 | 검증 | 가드 빌드 |
|---|---|---|---|
| 1 | `tdc_boot_led.h/.c` 골격 (빈 함수) + `main.h` 매크로 정의 + `main.c` `#if !TDC_BOOT_LED_ENABLE` 가드 + `bootloader.c` 통합 지점 가드 (모두 `#if TDC_BOOT_LED_ENABLE { }` 안에 빈 호출). 빌드 path 추가 (Eclipse `source/led/`, `include/led/`). | 가드 OFF 빌드 → 기존 부트로더 동작 100% 동일 회귀 확인 (UART, 디버그 LED, CM3 부팅) | `=0` |
| 2 | `tdc_boot_led_init()` 만 구현 — Sys_DIO_Config + Timer2 setup + NVIC_EnableIRQ. ISR 는 빈 본체 (PWM 출력만, phase 미진입). RSL10 SDK 의 Timer2 함수명 / IRQ 번호 / IRQ 핸들러 이름 확정. **IRQ 누락·이중 진입 없는지 측정** — 필요 시 ISR 첫 줄에 peripheral ack 추가. | 가드 ON 빌드 → ISR tick 발생 확인 (DIO33 토글 또는 RTT 카운터). PWM 주기 = 1 kHz 확인 | `=1` |
| 3 | ISR 본문에 PWM 출력 추가 (phase = PEAK 고정 duty G_MAX/B_MAX). `tdc_boot_led_start()` = phase 만 set. | 오실로 측정 — G 핀 30% duty, B 핀 40% duty PWM 1 kHz 확인 (AC-2 일부) | `=1` |
| 4 | `phase_tick()` 추가 + `tdc_boot_led_start()` 가 IDLE → FADE_IN 전이. | 오실로 측정 — fade-in 30 ms ramping (AC-3) → peak 300 ms (AC-4) → fade-out 30 ms (AC-5) → off 180 ms (AC-6) → DONE | `=1` |
| 5 | `tdc_boot_led_stop()` 본체 + `bootloader.c` wait 로직 활성화. | 오실로 측정 — DONE 도달 후 `bootloader_boot_cm3()` 호출 직전 LED OFF 안정 (AC-7) → CM3 정식 LED 진입 | `=1` |
| 6 | UART 활성 검증 핀 분기 동작 검증 — UART_ENABLE 핀을 UART 활성 레벨로 short → SW PWM 안 시작, UART 정상. UART_ENABLE 핀 풀업 디폴트 (UART 비활성) → SW PWM 정상 시작. | 두 케이스 모두 회귀 없음 | `=1` |
| 7 | `진행상황.md` 갱신 + 전체 회귀 (가드 OFF + 가드 ON × UART 두 상태) | 모든 AC-1~AC-7 통과 | `=0/=1` |

## 5. 검증·테스트

### 5.1 측정 환경

- **DIO33** (`DIO_NUM_ELAPSE_TIME_CHECK`) — main.c:13-14 에서 GPIO output + main 진입 직후 HIGH. 본 측정 시 `bootloader_boot_cm3()` 직전 LOW write 추가 (구현 단계 옵션) 로 부트로더 진입~CM3 점프 시간 측정.
- **DIO15 (G LED)** + **DIO12 (B LED)** — 직접 측정 → fade duty / phase 진행 가시화.
- **DIO_NUM_UART_ENABLE (DIO32)** — 풀업 디폴트 HIGH (= UART 비활성). short to GND 시 LOW (= UART 활성).

### 5.2 검증 항목 (요구사항 §4 AC-1~AC-7 매핑)

| AC | 시나리오 | 측정 / 기대 | 통과 기준 |
|---|---|---|---|
| AC-1 | 가드 ON + UART 비활성, 정상 부팅 | DIO33 HIGH 시점 ↔ G/B 핀 첫 PWM 활성 시점 차이 | T-B = 수십 ms (분석 §2.3, NVMReadBytes 영향). 약 **500 ms 이내 LED 점등 가시** |
| AC-2 | 동일 | 0~99 bin 중 G ON 비율 = 30/100, B ON 비율 = 40/100 | duty 비율 ±5% 이내 |
| AC-3 | 동일, fade-in 구간 | G/B duty 가 0 → max 선형 증가 (30 ms) | ramping 형태 시각 확인 |
| AC-4 | 동일, peak 구간 | duty max 안정 유지 (300 ms) | 안정성 확인 |
| AC-5 | 동일, fade-out 구간 | G/B duty max → 0 선형 감소 (30 ms) | ramping 형태 시각 확인 |
| AC-6 | 동일, off 구간 | G/B 핀 LOW 안정 (180 ms) | LOW 안정 확인 |
| AC-7 | 동일, CM3 점프 직전 | `bootloader_boot_cm3()` 호출 직전 G/B = LOW + Timer2 IRQ 미가동 | LED OFF 안정 + CM3 정식 LED 진입 자연 cross-fade |
| 회귀 | 가드 OFF | UART 정상, 디버그 LED (G+B 풀밝기) 정상, CM3 부팅 정상 | 기존 동작 100% 일치 |
| 회귀 | 가드 ON + UART 활성 (DIO32 short to GND) | UART 정상 (`tdc_uart_printf` 출력 확인), G 핀 hi-Z 유지 (LED 안 켜짐) | UART 정상 + LED 안 켜짐 |

### 5.3 사용자 인지 패턴 검증

분석 §2.5 의 '삑—, __, 삑×5' 패턴 (부트로더 SKYBLUE → OFF → CM3 정식 LED_ST_POWER_ON):

```
시간 (ms):  0          T-B    T-B+360  T-B+540  CM3-진입+30  CM3-진입+390 ...
            │          │      │        │        │             │
            (부팅 시작) (skyblue 시작) (skyblue 끝, OFF 시작) (CM3 정식 fade-in 시작) ...
            전원 OFF   OFF    SKYBLUE  OFF       OFF           SKYBLUE (정식)
                       (풀다운)        (180 ms+)               (LED_ST_POWER_ON)
```

오실로로 G 핀 / B 핀 / DIO33 동시 캡처 → 사용자 인지 패턴 일치 확인.

## 6. 위험·롤백

| 위험 | 대응 |
|---|---|
| Timer2 SDK 함수 (`Sys_Timer_*`) 부트로더 link 실패 | Step 2 단계에서 발견 → 직접 레지스터 manipulation 으로 fallback (분석 §2.1 D-1). RSL10/Onsemi SDK 의 Timer 레지스터 직접 setup 코드를 부트로더 PRAM5 안에 작성. |
| `TIMER2_IRQHandler` 이름 / `TIMER_2_IRQn` 식별자가 SDK 와 다른 형태 | Step 2 단계에서 SDK 헤더 grep 으로 확정 (`include` 폴더의 RSL10 SDK 헤더). |
| Timer2 reload 값 30.72 MHz 기준 계산 오류로 PWM 주기가 1 ms 가 아닌 다른 값 | DIO15/DIO12 오실로 측정 1 회로 PWM 주파수 검증. 1 kHz ±10% 이내가 아니면 reload 값 보정. |
| ISR 진입 시 peripheral pending bit 자동 clear 안 되어 즉시 재진입 또는 누락 | Step 2 측정에서 발견. ISR 첫 줄에 read-to-clear (예: STATUS 레지스터 read) 또는 SDK ack 함수 추가. NVIC level 의 IRQ active bit 는 Cortex-M3 가 자동 처리. |
| ISR 가 너무 자주 (10 us) 호출되어 부트로더 polling 흐름 (UART, DMA, NVMReadBytes) 영향 | 분석 §1 F-4/F-6: 부트로더 polling 은 ISR 가 끼어들어도 무관. 그러나 측정 중 이상 시 ISR 주기를 20 us 또는 50 us 로 증가 + bin 수 50/20 으로 감소 (분해능 trade-off). |
| 풀다운 가정이 보드별로 다름 — 풀다운 없는 보드에서 GPIO disable 시 hi-Z 가 floating → 약하게 점등 가능 | Step 1 (가드 OFF 빌드) 에서 LED 핀의 디폴트 상태를 오실로로 확인. 풀다운 없으면 `tdc_boot_led_init()` 에 명시 풀다운 추가. |
| 가드 ON + UART 비활성 시 부트로더 `tdc_uart_printf` 호출이 R 핀 (DIO8) 을 토글 — R LED 가 깜빡일 수 있음 | R 핀은 본 작업 SKYBLUE 와 무관. 시각적으로 R (적색) 깜빡임이 사용자 인지에 영향 시 가드 ON 시 `tdc_uart_set_enable(false)` 강제 호출 추가 (별도 통합 지점). 본 Rev 에서는 옵션. |
| T-B 시점이 fade-in 30 ms 미만 (예: NVMReadBytes 가 빠르게 끝나 T-B = 5 ms) | T-B 자체가 30.72 MHz 안정 시점이라 영향 없음. |
| `bootloader.c` 의 `bootloader_boot_cm3()` 호출이 두 곳 이상 — 잘못된 곳에 wait 로직 추가 | grep 으로 `bootloader_boot_cm3` 호출 사이트 모두 확인 → 정확히 한 곳 (line 1374) 만 통합. cfx 부팅 분기 (line 1364 `bootloader_boot_cfx`) 에는 통합 안 함. |

**롤백**: 각 step commit 분리이므로 `git revert <step-commit>` 로 부분 롤백. 전면 롤백 시 가드 OFF 빌드로 되돌리면 본 작업 코드가 컴파일에서 제외 → 기존 동작 100% 복원.

## 8. 영향 받지 않는 영역

- CM3 LED 엔진 (`LedOutput.c`, `k_led_mix`, `LED_OUT()`) — 본 작업은 자체 구현, CM3 코드 수정 없음
- 부트로더 service mode 분기 (`main.c:64-74`) — 본 작업은 `bootloader_main()` path 만 통합
- 부트로더 기존 UART 인터페이스 (`tdc_uart.c/h`) — 가드 OFF 시 100% 동일, 가드 ON + UART 활성 시 100% 동일
- 부트로더 NVM, DMA, 부팅 시퀀스 (`bootloader.c` 의 `bootloader_load_*`, `bootloader_transfer_*`) — 본 작업은 호출 시점 전후에 한 줄씩 추가만
