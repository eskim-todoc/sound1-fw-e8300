## 2. README 본문 설계 결정

### 결정_1: `tasks/README.md` 신설 가치

루트 `tasks/README.md`는 폴더 구조·`list.md`·새 작업 시작 절차를 안내하는 가이드 역할. Sound1도 동일 구조로 하되, **루트 본문을 그대로 베끼지 않고 Sound1 특화 모듈 정의와 list.md 링크 위주로 작성**.

### 결정_2: 서브폴더 README는 본 task 외

`참고/칩·LED·터치`는 §9.3 기준 5+ 미만(각 1·4·2)이므로 본 task 외. `참고/LED/`만 4파일이라 5+에 근접하지만 가치 검토는 후속 task로 분리(현재 4 파일이라 충분히 한 시야에 들어옴).

### 결정_3: 인덱스 표 형식 통일

루트의 표 컬럼(`파일`/`목적`/`사용 시점`)을 그대로 따름.
