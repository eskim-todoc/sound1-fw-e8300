# 요구사항: 내부 링크 경로 정정

**TL;DR**: `meta/docs-restructure` 후 파일 자체 이동·재명명은 정확했지만 다른 문서가 그 파일을 가리키는 markdown 링크 25+건이 구 프리픽스·구 경로를 그대로 사용 중. 본 작업은 Sound1 docs 하위 모든 .md의 깨진 내부 링크를 새 폴더 구조에 맞춰 정정하고 lint·grep으로 잔여 0건을 확인한다.

## 1. 배경

[`meta/docs-restructure`](../docs-restructure/) (2026-04-24 완료) 에서 Sound1 docs 폴더를 flat 구조 + `[프리픽스]` 방식 → 폴더 기반 + `tasks/<모듈>/<작업>/` 구조로 재편했다. 파일 자체는 정확히 이동·재명명됐지만, **다른 문서에서 그 파일을 가리키는 markdown 링크 25+ 건이 구 프리픽스·구 경로를 그대로 사용**하고 있다.

콘텐츠는 정상. markdown preview 에서 클릭 시 404 만 발생. tech debt 로 본 작업 분리.

## 2. 목표

- Sound1 `docs/` 하위 모든 markdown 파일의 깨진 내부 링크를 새 폴더 구조에 맞춰 정정.
- 정정 후 lint·grep 으로 잔여 깨진 링크 0 건 확인.
