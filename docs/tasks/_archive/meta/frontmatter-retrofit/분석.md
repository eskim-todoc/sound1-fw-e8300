## 2. frontmatter 형식

```yaml
---
name: <파일 제목 — 본문 첫 # 헤더 사용>
purpose: <위 표 purpose 컬럼 값>
type: <위 표 type 컬럼 값>
applies_to: [Sound1]
tags: <위 표 tags 컬럼 값>
---
```

## 3. TL;DR 작성 원칙

- 위치: frontmatter 닫는 `---` 다음, 첫 `#` 헤더 바로 아래
- 형식: `**TL;DR**: <내용>` (굵게 prefix 필수)
- 길이: 1~3줄
- 내용: 본문 핵심 결론 — `purpose`보다 더 구체적·실행 가능
- 톤: 명사구·서술형 혼용 가능, 마침표 정상 사용
