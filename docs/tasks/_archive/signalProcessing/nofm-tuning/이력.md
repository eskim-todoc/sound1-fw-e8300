## 핵심 결정

- **src 4 파일 단일 commit + docs 별도 commit (2 commit 분할)** — 5 변경이 NofM 튜닝 단일 주제라 src cherry-pick·revert 단위 유지, docs 분리로 src git blame 정밀도 보존. clang-format 부수 변경은 의미 변경 hunk 와 영역 혼재라 분리 시 비용 큼 → 통합.
- **임시 테스트 벡터 (③④) 본 commit 포함** — 사용자 명시 "정리하고 커밋" 흐름. `#if 1` + `NOTE: 테스트 후 삭제할 것` 코멘트로 후속 가시성 보장. 별도 후속 삭제 task 는 사용자 검증 완료 후 등재 (본 task 외).
- **`#else stride=3` 가지 보존** — 사용자 명시 의도 = backup. `#if 1` 가지가 활성 (공유메모리 사용), `#else` 가지는 사용 빈도 0 이지만 의도 보존.
- **16ch 미만 맵 → 에러 메시지만, 자동 fallback 없음** — NofM 의 의미 (다중 채널 동시 자극) 보존. 사용자 맵 재구성 유도가 의도된 동작.
- **AI 트레일러 절대 부재 + claude_feature 분기 + `--no-ff` 두 단계 머지** — Sound1 Git Identity 정책 (`Co-Authored-By` 등 금지) + Git 워크플로우 규칙 일관.
