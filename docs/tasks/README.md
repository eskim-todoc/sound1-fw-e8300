# tasks (Sound1 작업 스코프)

**TL;DR**: Sound1 프로젝트 작업의 모음. 레지스트리는 [`list.md`](list.md), 폴더 컨벤션은 루트 [`문서 작성 규칙.md §3·§4·§5`](../../../../docs/지침/일반/문서%20작성%20규칙.md) 참조. 활성 작업은 `<모듈>/<작업슬러그>/`, 완료 작업은 `_archive/<모듈>/<작업슬러그>/` 구조.

| 항목 | 위치 | 용도 |
|---|---|---|
| **레지스트리** | [`list.md`](list.md) | 모든 작업의 활성/완료 상태·태그·연계 표 (항상 먼저 조회) |
| 활성 작업 | `<모듈>/<작업슬러그>/` | 진행 중 작업 (요구사항·분석·계획·진행상황) |
| 완료 작업 | `_archive/<모듈>/<작업슬러그>/` | 완료된 작업 + `이력.md` (1페이지 요약) |

## 폴더 구조

```
tasks/
├── list.md                       ← 항상 먼저 조회 (활성/완료 상태)
├── <모듈>/<작업슬러그>/          활성 (요구사항·분석·계획·진행상황)
└── _archive/<모듈>/<작업슬러그>/ 완료 (+ 이력.md)
```

## 모듈 (Sound1 도메인)

| 모듈 | 범위 |
|---|---|
| `LED` | LED 운용·밝기·dimming·패턴·표시 상태 |
| `touch` | 터치 센서·레이어·초기화·이벤트 처리 |
| `power` | 저전력 모드·전원 관리 |
| `meta` | 문서·워크플로우 등 프로젝트 메타 작업 |
| (추가 예정) | `comms`, `audio`, `calibration` 등 필요 시 |

## 새 작업 시작 시

1. [`list.md`](list.md) 활성 섹션 조회 → 관련 작업 있으면 사용자에게 이어갈지 확인
2. 신규 폴더 `<모듈>/<작업슬러그>/` 생성, `요구사항.md`/`분석.md`/`계획.md`/`진행상황.md` 작성 (루트 [`작업 진행 규칙.md`](../../../../docs/지침/일반/작업%20진행%20규칙.md) 4단계)
3. `list.md` 활성 섹션에 등재 + 갱신 이력에 한 줄

## 완료 처리 (사용자 *"작업 끝났어. 마무리해"* 시그널 시)

1. `이력.md` 작성 (1페이지 요약, 형식은 루트 [`문서 작성 규칙.md §3.4.2`](../../../../docs/지침/일반/문서%20작성%20규칙.md))
2. `git mv tasks/<모듈>/<작업>/ tasks/_archive/<모듈>/<작업>/`
3. `list.md` 활성 → 완료 섹션 이동, 폴더 링크 `_archive/...`로 갱신
4. 커밋 → 사용자 승인 → `--no-ff` 병합

> [!NOTE]
> 코딩 작업의 `구현계획.md`는 루트 컨벤션상 `계획.md`의 alias로 호환된다.
