# tasks (Sound1 작업 스코프)

**TL;DR**: Sound1 작업 폴더 모음. 루트 지침(`작업 규칙.md §3`)의 **2계층 tasks 모델**을 따른다 — tasks 루트는 [`모듈 현황.md`](모듈 현황.md)로 **모듈 현황만** 파악하고, 실제 작업 목록은 **모듈별 `<모듈>/작업 목록.md`**가 관리한다. 작업 폴더는 완료 후에도 `<모듈>/<작업슬러그>/`에 영구 보존. 8단계 산출물·완료 처리 등 절차는 루트 지침을 따른다.

> [!IMPORTANT]
> **2계층 전환 (2026-07-14~)**: 기존 단일 통합 [`작업 목록.md`](작업 목록.md)는 **deprecated·동결**(과거 이력 참조용). 신규 작업은 아래 2계층으로 등재한다. 지침은 프로젝트 자체 `docs/지침/`(비활성)이 아니라 **루트 헌법/지침**(`~/.claude/CLAUDE.md`가 지정하는 `E:\workspace\rules\`)을 따른다.

| ~~통합 작업 목록~~ | ~~[`작업 목록.md`](작업 목록.md)~~ | **deprecated·동결** — 과거 이력 참조용 |

## 폴더 구조

```
tasks/
├── 모듈 현황.md              ← tasks 루트 인덱스 (모듈별 최신 상태만)
├── 작업 목록.md              ← deprecated·동결 (과거 이력)
└── <모듈>/
    ├── 작업 목록.md          ← 모듈별 작업 레지스트리 (신규 작업 등재)
    └── <작업슬러그>/         요구사항·분석·계획·이력 (영구 위치)
```

## 새 작업 / 완료 처리

절차는 **루트 지침 `작업 규칙.md §3`(8단계 프로세스)**를 따른다. 요약:

1. [`모듈 현황.md`](모듈 현황.md) → 해당 `<모듈>/작업 목록.md` 조회 → 기존 폴더 이어가기 or 신규 분리 (사용자 확인)
2. 신규 폴더 `<모듈>/YYYYMMDD_<슬러그>/` 생성, 8단계 산출물 작성, `이력 및 결과.md`를 단계 ① 시작과 동시에 생성
3. 해당 `<모듈>/작업 목록.md`에 행 추가 (상태=`진행`). 해당 모듈에 `작업 목록.md`가 없으면 새로 생성
4. 완료 시: `이력 및 결과.md` 완료 요약 + `<모듈>/작업 목록.md` 상태=`완료` + [`모듈 현황.md`](모듈 현황.md) 갱신 → 커밋 → 사용자 승인 → `--no-ff` 병합

> [!NOTE]
> 작업 폴더는 완료 후에도 위치 영구(`_archive/` 없음). 활성/완료 식별은 모듈별 `작업 목록.md`의 `상태` 컬럼. 코딩 작업의 `구현계획.md`는 `계획.md`의 alias로 호환.
