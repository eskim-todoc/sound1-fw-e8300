## 축_2 — 논리 정합성

### 결함_1 (발견 · 수정) — 측정 불가한 수용 기준

요구사항_2 의 수용 기준이 "최대 중첩 깊이가 현재의 절반 이하"였다. 현재 깊이가 "7~8단계"로 **범위 추정치**라 절반이 3.5인지 4인지 불명확하다. 측정 불가한 기준은 ⑧ 구현 검증에서 판정 불능이 된다.

**수정**: 분석 단계(③)에서 현재 최대 깊이를 **정확히 측정**한 뒤, 계획(⑤)에서 목표 깊이를 정수로 확정한다. 요구사항 단계에서는 "중첩 깊이를 유의미하게 낮춘다"로 두고 수치는 ⑤에 위임한다.

### 결함_2 (발견 · 수정) — 근거 없는 그룹 수

요구사항_1 이 `static` 10개를 "성격별로 묶는다"고 했으나, 몇 개 그룹인지·그 경계가 무엇인지 근거가 없다. `요구사항.md §2` 의 성격 분류(부팅 2 / 파워오프 2 / 크래들 2 / ISD 1 / 배터리 1 / 충전기 1 / 정상 1)는 **변수명에서 유추한 것**이지 사용처 분석 결과가 아니다.

**수정**: 그룹 경계는 ③ 분석에서 **사용처 전수 조사 후** 확정한다. 요구사항은 "소유 단계가 이름으로 드러난다"는 성질만 요구하고, 구체적 그룹핑은 분석에 위임한다. (요구사항.md §2 의 분류표는 "현황 유추"임을 명시)
