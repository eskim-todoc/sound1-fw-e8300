## 축_2 — 논리 정합성

### 결함_1 (발견 · 정정) — 단계_5 가 단계_2 와 중복

`계획.md §2.5` 는 단계_5 를 "이름 정정"이라 했으나, §2.2 의 구조체 필드가 이미 `prev_carrying_case_state` 로 명명돼 있다. 즉 **단계_2 에서 이름이 바뀐다**. 단계_5 는 실체가 없다.

**정정**: 실질 단계는 **4개**(dead 제거 → 상태 구조체 → 핸들러 추출 → 조립). 이름 정정은 단계_2 에 흡수된다. §2.5 는 "§5 질의_1 결과 처리"만 남으며, 이는 단계가 아니라 **승인 대기 항목**이다.

> 커밋 단위도 5 → **4** 로 정정.

### 결함_2 (발견 · 반영) — 미배정 구간

§3 핸들러 5개 + 조립부가 원본 281줄을 포괄하는지 라인 단위 대조:

| 원본 구간 | 배정 |
|---|---|
| `:131~151` 선언부 | 조립부 (구조체로 대체) |
| `:153~162` 에러 분기 + `led_request(ERROR, NONE)` | 조립부 (분기 골격) |
| `:169~207` 충전 처리 | `tdc_sysctl_handle_charging()` |
| `:209` 충전기 미연결 분기 | 조립부 |
| **`:211` `systemStatus.BLE_Off = false;`** | ⚠️ **미배정** |
| `:213~215` `prev` 비교 · `StartFlag` 분기 | 조립부 |
| `:217~226` 부팅 첫 진입 | 조립부 (짧고 상태 1개만) |
| `:233~238` burst 게이트 + `enable_ISD`/`enablePMIC` | 조립부 |
| `:241~254` 버튼 게이팅 | `tdc_sysctl_gate_power_button()` |
| `:256~289` 배터리 판정 + 파워오프 트리거 | 조립부 |
| `:291~318` 파워오프 진행 | `tdc_sysctl_handle_poweroff()` |
| `:319~360` 정상 운영 | `tdc_sysctl_handle_running()` |
| `:365~373` 재연결 | 조립부 |
| `:376~378` 빈 else | **삭제** (단계_1) |
| `:379` `prev` 갱신 | 조립부 |
| `:384~405` 에러 처리 | `tdc_sysctl_handle_error()` |
| `:408~410` 출력 반영 + return | 조립부 |

**`:211` 이 어느 핸들러에도 배정되지 않았다.** 충전기 미연결 시 `BLE_Off = false` 를 설정하는 1줄이다.

**반영**: 조립부 귀속. `:169~207`(충전) 이 `BLE_Off = true`(`:172`)를 설정하듯, `:211` 은 미연결 축의 대칭 동작이므로 **조립부의 축 분기 직후**에 둔다.

### 정합 확인 (통과 항목)

| 검사 | 결과 |
|---|---|
| 위임 3건(`분석-검증.md §종합`) 반영? | ✅ §1 표 — 시그니처(§3) · 초기값(§2.2) · 검증 라벨(§6) 전부 |
| 검증 라벨이 요구사항 수용 기준을 포괄? | ✅ 요구사항_1→검증_3, _2→검증_7, _3→검증_1, _4→검증_7/8 |
| 단계 의존성에 순환? | ✅ 없음 — 단선 DAG (§4 Mermaid) |
| 핸들러가 상태를 배타적으로 소유? | ⚠️ **부분 위반** — `isd_disconnection_counter` 를 `gate_power_button`(읽기 `:248`) · `handle_poweroff`(쓰기 `:300`) · `handle_running`(쓰기 `:344/348/353`) 3개가 공유. **원본 구조가 그러하므로 동작 보존상 불가피**. 상태 구조체가 파일 static 1개이므로 접근은 가능하나, **소유는 `handle_running` 으로 문서화**하고 나머지는 "읽기/리셋만" 주석 명시 |
| `:367` 미확인이 구현을 막는가? | ❌ 막지 않음 — 동작 보존 방침이므로 코드는 그대로 옮긴다. 답변은 별도 작업 분기 판단용 |
| 예상 결과(§7) 근거? | ⚠️ "~60줄"은 **추정치**. ⑧에서 실측 보고 (추정임을 §7 에 명시 권고) |
