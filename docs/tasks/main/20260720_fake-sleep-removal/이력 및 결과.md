# 이력 및 결과 — fake sleep mode 제거

**TL;DR**: 터치센서 계측을 위해 "클럭을 안 내리는 가짜 절전"으로 만든 체인을 제거한다. BLE 0x8F option 4(진입) + option 1(계측값 조회)이 한 세트였으나, **option 1 의 데이터는 정상 폴링 경로가 별도로 채우고 있어** 계측 기능은 살아남는다.

> **⑤ 계획을 ①~④ 없이 단독 작성했다.** 루트 지침 `작업 규칙.md §3` 은 모든 작업에 8단계 산출물 + `이력 및 결과.md` 를 요구한다. 직전 작업(`20260715_systemcontrol-fsm-decompose`)은 ①~⑥ 을 갖췄으므로 일관성도 없었다.

> **원인**: 은수님 지시문의 "계획 좀 짜봐"를 문면 그대로 받아 산출물을 계획 1건으로 좁혔다. 지시의 표현이 아니라 **작업의 성격**(5개 파일 · 약 300줄 제거)으로 판단했어야 한다. 단순 수정(오타 · 설정값 · 자명한 한 줄) 면제 대상이 아니다.

## 완료 요약

- ⑦ 구현: 커밋 `cc5e4e5` — fake 체인 약 300줄 제거 (`main.c` 1397 → 1161, `tdc_touch.c` 446 → 416). 방안_A 로 BLE 0x8F option 4 통째 제거.
- BLE option 1(터치 디버깅)은 보존 — 공급원이 `tdc_touch_process()` 로 독립임을 실증한 뒤 setter 7개만 제거.
- 연계: 커밋 `4a0f272` — `main_counter` → `s_cm3_heartbeat`(static) / `update_CM3Status_toCFX()` → `tdc_shared_publish_cm3_heartbeat()`, 미사용 래퍼 `update_CM3tempValue1/2_toCFX` 제거. `CM3_tempValue1/2` **필드**는 CFX AGC 실사용(`agc.c` 7곳)이라 존치 — 공유 메모리 ABI 무변경.
- ⑧: 정적 검증 라벨 7개 PASS. **잔여 게이트**: 검증_7(BLE option 1/2/3 실기) · 검증_9(Eclipse 빌드 + AGC 동작) — 은수님 환경. 통과 확인 후 `claude_develop` 병합 예정.
