# 이력 및 결과: 배터리 레벨 enum 단순화 분석

**TL;DR**: `snd_batt_get_level()`이 산출하는 `EN__BATTERY_LEVEL`(7단계 enum)이 실제로 `systemControl()` 외에 쓰이는 곳이 있는지, 특히 BLE 패킷 전송에 관여하는지 전수 조사하고, `systemControl()` 내부에서 enum 대신 배터리 percent를 직접 비교하도록 개선 가능한지 분석한다. 서브에이전트 fan-out으로 조사·검증. 분석까지 진행, 계획·구현은 은수님 결정 후 별도.

- **선행 조사(직접)**:
  - `snd_batt_get_level()` 호출처 = **`main.c:577` 단 1곳**(`batteryLevel = snd_batt_get_level()`). 그 값은 `func_normal` 지역변수 `batteryLevel`로 `systemControl()`에 전달(`main.c:618`).

## 완료 요약

**분석 결론(검증 통과)**: `snd_batt_get_level()`/`EN__BATTERY_LEVEL`은 `systemControl()` 2곳(<40% 강제전원종료·<20% 저배터리 자극알림)에서만 실소비되고, **BLE 배터리 송·수신 5경로는 전부 raw percent라 enum 무관**. 두 비교는 `percent<40`·`percent<20`으로 100% 동치 → **percent 직접사용으로 동작 불변 대체 가능**. `snd_batt_get_level`·enum·고아 전역·유령 선언은 이미 dead라 삭제 안전(10사이트).

- **은수님 가설 참 확정** — systemControl 외 사용처 없음.
- **개선**: 옵션 A(시그니처만, 3파일 ~15줄) / 옵션 B(enum·getter·고아·유령 정리) — A+B 동시 권장.
- **잔여**: 계획·구현 착수 여부·옵션 선택은 은수님 결정. 코드 변경 0.
