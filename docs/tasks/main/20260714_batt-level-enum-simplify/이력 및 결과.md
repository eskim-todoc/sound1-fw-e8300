# 이력 및 결과: 배터리 레벨 enum 단순화 분석

## 완료 요약

**분석 결론(검증 통과)**: `snd_batt_get_level()`/`EN__BATTERY_LEVEL`은 `systemControl()` 2곳(<40% 강제전원종료·<20% 저배터리 자극알림)에서만 실소비되고, **BLE 배터리 송·수신 5경로는 전부 raw percent라 enum 무관**. 두 비교는 `percent<40`·`percent<20`으로 100% 동치 → **percent 직접사용으로 동작 불변 대체 가능**. `snd_batt_get_level`·enum·고아 전역·유령 선언은 이미 dead라 삭제 안전(10사이트).

- **은수님 가설 참 확정** — systemControl 외 사용처 없음.
- **구현 완료(옵션 A+B)**: systemControl percent 직접사용 전환(동작 불변) + enum·getter·고아 전역·유령 선언 삭제. 정적 검증 전수 PASS.
