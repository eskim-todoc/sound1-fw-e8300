# 계획: 배터리 레벨 enum 단순화 (옵션 A+B)

**TL;DR**: 분석(§4)에서 확정한 옵션 A+B를 실행한다. `systemControl()` 파라미터를 `EN__BATTERY_LEVEL batteryLevel` → `int battery_percent`로 바꾸고 두 비교(<40%·<20%)를 percent 직접 비교로 전환(동작 불변), `main.c` 호출부를 `snd_batt_get_percent()` 직접 전달로 정리한 뒤, dead가 된 `snd_batt_get_level()`·`EN__BATTERY_LEVEL` enum·고아 전역(`batteryLevelStatus`/`prev_batteryLevelStatus`)·유령 선언(`debugging_for_monitoring`)을 삭제한다. 은수님 승인(A+B)·공유메모리 무관 확인 후 구현. **worktree `batt-level-simplify`에서 진행**(은수님 메인 체크아웃 비침해).

## 0. 전제 (승인·확인 완료)
- 은수님 승인: 옵션 **A+B**(전체 정리), baseline 확인 후 진행.
- **공유메모리 확인**: `ST__CFX_CM3_SharedMemory_ALL`의 배터리 레벨 필드는 `batteryLevel_CfX_to_CM3`(제외 지정·미사용 레거시) 뿐, `batteryCalibrationValue`는 무관한 int 보정값, enum 타입 필드 0 → **enum 제거 공유메모리 영향 없음**.
- 실행 위치: git worktree `E:\...\.claude\worktrees\batt-level-simplify`(브랜치 `claude_feature_batt-level-simplify`). 공유 작업트리가 은수님 `claude_feature_docs-guideline-align`으로 전환돼 있어 격리.

## 2. 동작 등가성 (동작 불변)
- `battery_percent < 40` ≡ 구 `0per‖0btw20‖20btw40`(0~39%), `battery_percent < 20` ≡ 구 `≤0btw20`(0~19%) — 분석 §3·검증 06에서 전 구간 발산 0 확인.
- 부수효과(강제 전원종료·10분 저배터리 자극알림) 보존. RESET(percent=0)은 `chargerState==Disconnected` 가드 안이라 무관.
