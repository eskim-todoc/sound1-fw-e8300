## 4. 발견 사항 - 프로덕션 경고 11건

**인프라 도입의 첫 성과다.**

호스트 빌드의 `-Wall -Wextra` 가 `tdc_ble_map_stim.c:759-772` 의 미사용 지역 변수 11개를 잡아냈다. 단계_1b-3b 에서 0x66 하위 명령을 static 함수로 추출하면서 **진입점의 선언을 정리하지 않은** 것이다.

특히 `max_C_uA`·`min_T_uA` 는 하위 5 함수에도 static 이 생겨 **중복**이고, 진입점 것은 쓰이지 않으면서 `.bss` 8바이트를 차지한다.

**고치지 않았다.** `src/` 무변경이 이 작업의 불가침이기 때문이다(수용_5). [`알려진 결함 목록.md`](../../../참고/ble/재구조화/알려진%20결함%20목록.md) **결함_14** 로 기록했고 별도 커밋으로 처리한다.

> [!NOTE]
> **ARM 빌드에는 `-Wall` 이 없다.** 이 경고들은 그동안 존재했지만 보이지 않았다. 앞으로 러너가 매번 `src/` 경고 건수를 보고하므로 같은 종류의 누락이 즉시 드러난다.
