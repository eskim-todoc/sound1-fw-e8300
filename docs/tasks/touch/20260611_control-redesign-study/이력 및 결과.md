# 이력 및 결과 — IQS323 터치 제어 zero-base 재설계 탐구

**TL;DR**: HW·SW·데이터시트 3축 분석 완료를 기반으로, **현재 구현에 얽매이지 않는 zero-base**로 다관점 제어 설계를 발산→토론→현재 비교→타당성 검증→종합하여 더 나은 개선안을 도출한다. 과정 전반을 `개선/생각정리/`에 다수 문서로 남기는 다중 에이전트 토론 오케스트레이션.

## 요구사항 요지

- **목표**: ① 요구사항(전원 스위치 UX·이슈 9건) 해결 가능성 판정 ② zero-base 재설계로 현재보다 더 나은 개선안 도출·검증.
- **방법**: 다중 에이전트가 다양한 시각으로 발산 → 서로 토론·비판 → 현재 구현과 비교 → HW/데이터시트/코드 근거로 타당성 검증 → 종합.
- **산출**: `개선/생각정리/`에 과정 문서 다수(발산·비판·비교·검증·종합) + `개선/`에 결과 권고 문서.
- **원칙**: 근거 기반(HW 회로·데이터시트·실제 코드), 할루시네이션 0. **현재 방식을 출발점 삼지 않는 zero-base**. 본 단계는 설계·평가까지(코드 구현은 후속).

## 진행 로그

- **2026-06-11 Phase 1~2 완료** — 6 설계안(P1~P6) 발산 + 18 비판(3렌즈). 워크플로 24에이전트/2.1M토큰. 산출: `생각정리/1_설계안_*` 6 + `2_비판_*` 6.
  - **만장일치 합의**: FIXED→ATI Full 복귀(이슈6·8·9 해소 가장 확실), Release UI 활용(order 001), SW 우회책(200ms 방전·CalCap·폴링) 폐지, Auto No ULP, Event+RDY.
  - **핵심 쟁점(미해결)**: 이슈1~4(진입 LTA 오염)는 Release UI로 못 풂 → 부팅 비의존 경로 필요. "MCLR 직후 auto-ATI 선행" 함정. Reference UI(CRX1) 회로 부적합 → 채택 불가.
  - **권고**: 단계적 도입(zero-base 전면 재작성 반대).
- **2026-06-11 Phase 4 + 쟁점해결 완료** — 검증 6(B1~B6) + 해법 4(S1~S4) + 교차검증 4. 산출: `4_타당성검증.md`·`3_쟁점해결토론.md`. (해법 라운드 schema 한글 키 API 오류 → 영문화 후 `resume`로 복구, Verify 캐시 재사용)
  - **결정적 반증 B4**: 웜부트도 `mclr_reset()` 무조건 실행 → IC POR(상태 보존 거짓) → [펌웨어 분석 §11] 정정.
  - **만장일치 수렴**: 진짜 오염원 = `Reseed`(auto-ATI 아님), 해법 = Reseed 노터치 게이트 + ATI Full 복귀.
- **2026-06-11 Phase 5 종합 완료** — `5_종합결론.md` + **`개선/제어 재설계 분석·권고.md`**(정식). 단계적 로드맵(Phase 0~4) + 실측 게이트 3종. 라인 참조·링크 정합 검증 통과(할루시네이션 0).

## 완료 요약

**산출물** (생각정리/ 13문서 + 정식 권고 1 + 정정/갱신)
- `생각정리/`: 00 방법론·01 문제정의·1_설계안×6·2_비판×6·3_쟁점해결·4_타당성검증·5_종합결론.
- **`개선/제어 재설계 분석·권고.md`** (정식 의사결정 문서). `개선/README.md` 갱신. [펌웨어 분석 §11] B4 반증 정정.

**탐구 규모**: 다중 에이전트 워크플로우 — 발산·비판 24 + 검증·해법 14(+resume) 에이전트, 누적 ~3.3M 토큰.

**핵심 결론**
- **진짜 문제 = `Reseed` 시점 baseline 오염**(이슈 1~4) — autoATI도 Release UI 부재도 아님(B1).
- **권고 = Reseed 노터치 게이트(Phase1·SW only·데이터시트 비의존) + FIXED→ATI Full 복귀(Phase2, 이슈 6·8·9)**. 전면 재작성 불요.
- **결정적 반증 B4**: 웜부트도 MCLR POR → "IC 보존" 거짓.
- **실측 게이트 3종**: ① 오염 실채널(auto-ATI vs Reseed) ② self-cap 1ch 전류·절전예산 ③ 0x30 LSB Linearise.
- **메타 결론**: 현재 구현이 틀린 게 아니라 "Reseed 시점이 비어 있었다". 6관점 독립 발산이 한 점(Reseed)으로 수렴 → 문제 본질이 국소·단순함을 입증.

**검증**: 워크플로우 내 18비판 + 6 blocking 검증 + 4 교차검증(근거 기반) + 최종 라인 참조·링크 정합 spot check 통과(라인 6/6 일치, 할루시네이션 0).

**AC 충족**: AC-1~5 전부. **다음**: 실측 1·2 후 Phase 0~1을 4단계 프로세스로 별도 작업화. (산출물 커밋은 사용자 승인 시 별도)
