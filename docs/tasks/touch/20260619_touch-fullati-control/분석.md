# Full ATI 터치 제어 분석

**TL;DR**: FullATI 단순안을 11노드(effort xhigh)로 분석. **본질 = 0x36 LSB 0x08→0x0C(1비트) + FIXED MULT/COMP write 폐기 + CRX1 더미·CRX0 방전 폐기 + `(void)ati_error` 제거**. adversarial 검증이 2건을 정정·적출: **[09 단위오류]** Touch Threshold는 raw가 아니라 `계수×LTA/256` 비율계수 → 부등식 **계수<32**, Base 상향 무관, **계수 12~24 하향이 본질**. **[10 신규회귀 5건]** 부팅 Re-ATI 부재·reseed 감도 동반·절전 이중 write·read 실패 hold-last·auto-ATI 3-상태 미구분 → 선행 수정 필수(원자적 3쌍·신규 API 2종). 급소(검토_2) = "터치 중 Re-ATI 보류" 게이트 필수. 상세 설계는 [`에이전트-로그/99_종합_설계수렴.md`](에이전트-로그/99_종합_설계수렴.md)(정본).

## 1. 분석 방법

- **구조**: Workflow 11노드 — 분석 8(FullATI전환·ReATI·SW타임아웃·Beta·임계·전력·단일채널·부팅) → adversarial 검증 2(정량 할루시네이션·회귀 충돌) → 종합 1. 전 노드 effort `xhigh`, Opus 4.8. 1.47M 토큰.
- **검증 신뢰도**: 09 정량 대조 [확인됨] 54·[단위오류] 9·[과장/근거없음] 0. 10 회귀 [해소] 16·[잔존위험] 19·[신규회귀] 5. 검증 적출은 분석 원안보다 우선 반영.
- **노드 로그**: `에이전트-로그/01~10 + 99` (전수 생성, 한자 0).

## 2. 핵심 발견 — 4대 축 (확정)

| 축 | 내용 |
|---|---|
| **자동 캘리 부활** | ATI Mode=Full(0x36 `0x040C`), FIXED MULT/COMP(0x38·0x39) write·공장 캘리 폐기 → IC 자율 게인 + 자동 Re-ATI |
| **에러 능동 처리** | System Status bit6(ATI Error) 폴링 → 게이트 통과 시 수동 Re-ATI. `(void)ati_error`(tdc_touch.c:393) 제거 |
| **단일채널 단순화** | CRX0 단독. CRX1 CalCap 더미·CRX0 주기 방전 폐기 → 단일채널 정지 이슈 원천 소멸 |
| **SW stuck 처리** | IC Channel Timeout 미사용 → SW 터치 지속 30초 → 3단계 에스컬레이션(reseed_only→Re-ATI→MCLR) |

## 3. 검증이 바꾼 것 (반드시 반영)

### 3.1 [09 단위오류 정정] — Touch Threshold 계수 기준 (핵심)

- 05 원안 "Threshold 100 > ATI Band 50, raw 직접 비교"는 **차원 불일치**. Touch Threshold 레지스터값은 raw count가 아니라 `(계수×LTA)/256` 비율계수 [06 A.17·현코드 tdc_drv_iqs323.h:391·적용가이드 §4.4].
- 올바른 부등식(LTA≈Target): `(계수×Target)/256 < Target/8` → **계수 < 32**.
- **Base 상향(Target 800)은 부등식과 무관**(LTA·Target 비례 소거) → **계수 12~24 하향이 본질**. 05 권고 50~80 폐기.

### 3.2 [10 신규회귀 5건] — 선행 수정 필수

| # | 회귀 | 처리 |
|---|---|---|
| 1 | 부팅 운용 `apply_settings()`에 수동 Re-ATI 없음 → FIXED 제거 시 auto-ATI 실패하면 ATI_Error 영구 잔류 | 부팅 1회 Re-ATI 또는 READY-후 ATI_Error clear 보장 |
| 2 | `reseed()`(:931)가 순수 RESEED 아님(절전 감도 동반) → 노말 재활용 시 오염 | **`reseed_only()`(순수 bit3) 신설** |
| 3 | 절전 진입 시 감도 이중 write(255,255 → 100,80) | 절전 감도 단일화 |
| 4 | read 실패 시 NOT_TOUCH 미강제(hold-last) → ATI burst로 stuck 오발 | NOT_TOUCH 강제 + N회 hold 조합 규칙 |
| 5 | `is_auto_ati_done` 통신실패↔ATI진행 미구분 | 3-상태 구분 |

- **원자적 3쌍**: ① Full 전환↔임계 계수 하향, ② FIXED 제거↔부팅 Re-ATI 보장, ③ 방전 폐기↔CH1 폐기. **신규 API 2종**: `reseed_only()`·`re_ati_trigger` 공개화.

## 4. 결정 8항목 결론

| 검토 | 결론 |
|---|---|
| 검토_1 SW 타임아웃 후 동작 | **3단계 에스컬레이션** reseed_only(bit3)→Re-ATI(bit2)→MCLR, 각 30초 재카운트 |
| 검토_2 터치 중 Re-ATI (급소) | **게이트 필수**. LTA halt는 경로_1(자동)만 막음. 경로_2(SW 강제)는 `노터치 AND ATI Active==0 AND 쿨다운` 게이트 |
| 검토_3 CRX1 폐기 ESD | **조건부 폐기 가능**. ESD는 자동 Re-ATI + human-in-the-loop. ESD 복구 실효 [실측 게이트] |
| 검토_4 Full ATI I²C 무응답 | **안전 가능**. 과거 80%는 CH1 더미 수렴 실패 → CH1 폐기로 소멸 |
| 검토_5 Beta vs 약터치 | **Fast Filter Band 비대칭**. LTA Normal 느리게+LTA Fast 빠르게+Band 8~15cnt |
| 검토_6 부팅 MCLR vs ATI 체크 | **MCLR 항상** 1순위(현 코드 이미 무조건 MCLR, 직전 상태 완전 소거) |
| 검토_7 Max Counts 안전망 | **MCLR 유지 필수**. 포화형은 Re-ATI 못 풀어 MCLR만 회복 |
| 검토_8 Re-ATI burst | **쿨다운 N초 + Band 확대 + 노터치 RESEED**. 부등식 위반(§3.1)이 burst 트리거 |

## 5. 정량 권고값 (검증 반영)

| 항목 | 권고 | 비고 |
|---|---|---|
| ATI Mode (0x36) | `0x040C` (Full, Large Band, Res 64) | 1비트 변경 |
| ATI Base (0x37) | 200 → Target 800, Band 100 | 부등식과 무관 |
| **Touch Threshold 계수** | **12~24** (32 미만 + SNR≥5 raw 20) | [09] 본질 |
| Touch Hysteresis | Threshold 계수의 ~50% (비율) | 비율값, raw 아님 |
| Beta (0xB0/B1/B2/B4) | Counts α≈0.125~0.25 / LTA Normal α≈0.004~0.008 / LTA Fast α≈0.125~0.25 / Band 8~15cnt | 레지스터 정수 [실측 게이트] |
| 컨버전 (0x31) | 1MHz 유지 (0x057F 방어 write) | self-cap 상한 |
| Power Mode (0xC0) | Automatic No ULP (101) | LP 유지, 완전 저전력 미진입 |

## 6. 실측 게이트 (14항목 — 99 §6)

핵심: ① Beta 레지스터 정수 해석(A/B), ② 계수↔raw LTA 환산, ③ Hysteresis 비트폭, ④ t_ati(N 산정), ⑦ ESD 복구 자동 Re-ATI 실효, ⑨ Re-ATI burst 시간, ⑩ 단일채널·1MHz 전류, ⑬ 절전 30초 vs ULP 2.2초 충돌(설계 결정 필요). 전체는 [99 §6].

## 7. 계획 연결

99 §7이 Phase P0~P6 골격 제시 — P0 안전망·API 선행 → P1 단일채널 폐기 → P2 Full ATI 전환(원자적) → P3 Re-ATI 게이트 → P4 Beta·Power → P5 SW 타임아웃 → P6 게이트·절전 정리. 계획.md에서 정식화.

## 8. 동작 분석 — 콜스택·타이밍·이벤트·순서도 (구현 후 정적, 8노드 xhigh)

> 정본: [`에이전트-로그/동작분석/B99_동작분석종합.md`](에이전트-로그/동작분석/B99_동작분석종합.md). 순서도 5개 Mermaid valid. 빌드 전 정적 예측(빌드·실기는 다음주).

### 8.1 선언/호출 정합 재검증 (은수님 1차 지시)
- **빌드 차단 0건**. 신규 API 시그니처 6/6 일치, 가드 대칭 3/3, orphan static·미정의 참조·중복정의 0.
- [실측 게이트 2건]: `SYS_WATCHDOG_RESET` SDK 헤더 접근성(REFRESH 기존 컴파일·bootloader 혼용 선례로 성립 추정-강, 빌드 1회 판명), `-Werror` 시 비기본 조합(FULL_ATI=1 AND RE_ATI_GATE=0)만 `s_last_ati_*` set-but-unused 경고(기본 빌드 무해).

### 8.2 핵심 정정 — 폴링 200ms·롱터치 2400ms 🔧
- **코드 정본: `POLL_INTERVAL=200ms`, `LONG_TOUCH_MS=2400ms`**(`tdc_touch.h:25·26`). 요구사항_9·설계 §3.2의 "100ms"·"3초" 표기는 코드와 불일치 → **200ms·2.4초로 정정**. (30초 stuck은 `ci_timer_get_tick()` ms 절대시간 차분이라 폴링 간격과 무관 — 임계 무영향)

### 8.3 콜스택·타이밍
- **부팅**: MCLR 51ms → auto-ATI 비블로킹 폴링(최악 2500ms 타임아웃) → apply_settings 1tick(내부 부팅 Re-ATI `wait_re_ati_done` 최악 약 1.3초 블로킹) → READY. **최악 1tick 약 3.8초+α**(WDT refresh 사이사이라 리셋 위험 없음, WDT 마진 [실측 게이트]).
- **노말**: 200ms 폴링 → get_state → 게이트 → stuck → 롱터치. read 실패 N=10 hold(burst 흡수) → 초과 시 NOT_TOUCH 강제.
- **절전**: func_sleep에 신규 로직(`proc_*`·`wait_re_ati_done`) **호출 0건** — 완전 미관여. ULP 2.2초 리셋 전담(은수님 결정과 정합).

### 8.4 이벤트→상태·순서도
- 이벤트 13종(E1~E10 노말 + S1~S3 stuck) 상태천이표. 순서도 5개(부팅 시퀀스·노말 1tick·Re-ATI 게이트·SW 3단계·process 상태머신) Mermaid valid.
- 급소 재확인: 터치 중 게이트 no-op(경로_2 차단), read 실패 캐시 무효화로 stale 누출 차단(급소 수정 핵심).

### 8.5 추가 확인 필요 (은수님 — 빌드 후)
- **폴링 200ms vs 100ms**: 요구사항_9는 "100ms 측정"이나 현 코드 200ms. 100ms 변경(응답성↑·전류↑) vs 200ms 유지 — 결정 필요.
- **절전 SW 30초 미적용**: 절전은 ULP 2.2초 리셋만(은수님 결정과 정합). 요구사항_4("3초+이후 터치 유지 체크")의 절전 stuck 처리 의도 재확인.
