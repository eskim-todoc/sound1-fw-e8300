# 05 분석 임계카운터 — ATI Target/Base/Band/Threshold 정량 관계

**TL;DR**: Full ATI 전환 시 ATI Target=Base×(Res/16), ATI Band(Large)=Target/8. 핵심 부등식 **Touch Threshold < ATI Band 폭**이 성립해야 터치가 밴드이탈(Re-ATI)보다 먼저 잡힌다. 그러나 현 설정(Base 100·Res 64 → Target 400·Band 50)에서 Touch Threshold=100 > Band 50으로 **부등식이 깨져 있다**. Base를 200으로 올려 Target 800·Band 100을 확보(Threshold 50~80 < Band 100)하는 것이 권고. 온도 드리프트 −18cnt/°C 기준 약 5.5°C마다 Re-ATI가 발동하므로 Band 100이 마진상 합당. 모든 수치는 raw count 단위(IC 내부 판정), SNR≥5 raw 20cnt 충족.

---

## 1. 분석 목표와 단위 정합 (가장 중요)

핵심질문: **"드리프트는 ATI Band 안에 있고, 터치는 Threshold를 넘는다"가 동시 성립하는 파라미터 영역**을 계산한다. 이를 위해 먼저 네 양(Target·Base·Band·Threshold)이 같은 단위인지 확정해야 한다.

### 1.1 IC 내부 판정은 raw count 단위 — 펌웨어 계수와 분리

- 데이터시트 터치 진입 조건: $(LTA - Counts) > \text{Touch Threshold}$ [02_proxfusion §5.7]
- Re-ATI 발동 조건: LTA가 $\text{ATI Target} \pm \text{ATI Band}$ 밖으로 drift [02_proxfusion §5.10]
- ATI Error 조건: ATI 완료 시 Counts가 Re-ATI Boundary 밖 [02_proxfusion §5.11]

위 세 판정은 **모두 IC 내부에서 raw count로 직접 계산**된다. 현 펌웨어 코드에서 터치 상태는 IC의 System Status `ch0_touch` 비트를 읽는 것이고(`tdc_touch.c:395` `pressed`), 펌웨어의 `(LTA−Counts)×256/LTA` 계수는 **RTT 마진 로그 전용**(`tdc_touch.c:404~416`, `tdc_drv_iqs323_read_touch_margin`)이다 [현코드].

> [!IMPORTANT]
> **단위 정합 결론**: Touch Threshold·ATI Band·ATI Target·LTA·Counts는 **전부 raw count 단위로 동일 축**에 있다. 적용가이드 §4.4 NOTE의 "계수 단위 변환 필요" 우려는 **RTT 로그 표시값에 한정**되며, IC 임계 판정 자체는 raw count이므로 본 분석은 raw count 단위로 일관 계산한다. [현코드 §tdc_touch.c, 02_proxfusion §5.7]

## 2. ATI Target / Base / Band 정량 공식

### 2.1 ATI Target

$$\text{ATI Target} = \text{ACTUAL ATI Base} \times \frac{\text{ATI Resolution Factor}}{16}$$

[06_레지스터레퍼런스 §A.12, 02_proxfusion §5.9]

- ATI Base 레지스터(0x37) 기본값 = 0x0064 = **100** [06 §A.12 표 +7행]
- ATI Resolution Factor (ATI Setup bit15-4) 현 설정 = **64** [06 §A.12]
- → ATI Target = 100 × (64/16) = 100 × 4 = **400 cnt**

### 2.2 ATI Band 폭

ATI Setup bit3 = ATI Band 선택 [06 §A.12]:
- 0 = Small ATI Band = (1/16) × ATI Target
- 1 = Large ATI Band = (1/8) × ATI Target

현 설정 bit3=1 (Large) [현코드 `ATI_SETUP_LSB 0x08` 주석 "ATI Band=1", 06 §A.12]:

$$\text{ATI Band 폭(Large)} = \frac{1}{8} \times \text{ATI Target} = \frac{400}{8} = \mathbf{50\ cnt}$$

Re-ATI Boundary = Target ± Band = 400 ± 50 → LTA가 **350 미만 또는 450 초과**일 때 Re-ATI [02_proxfusion §5.10 공식].

### 2.3 현 레지스터 비트맵 확인 (Full 전환 변경점)

| 항목 | 현재(Disabled) | Full 전환 후 | 비트 위치 |
|---|---|---|---|
| ATI Setup LSB | 0x08 | **0x0C** | bit2-0: 000→100 |
| ATI Setup MSB | 0x04 | 0x04 (불변) | bit15-4 Res Factor=64 |
| 전체 16비트 | 0x0408 | **0x040C** | = IC reset 기본값 |

- Full 전환은 **하위 3비트만 000→100** 변경(0x0408→0x040C). 데이터시트 reset 기본값 0x040C와 정확히 일치 [06 §A.12]. 코드에도 절전 측정 경로에 `0x0C` write 선례 존재(`tdc_drv_iqs323.c:882`) [현코드].
- Resolution Factor 64·ATI Band Large(1/8)는 **그대로 유지**되므로 Target 400·Band 50도 불변.

## 3. 동시 성립 부등식 — 핵심 계산

### 3.1 부등식 유도

두 요구가 동시에 성립해야 한다:

1. **터치는 Threshold를 넘는다**: 진짜 터치 delta $\Delta_{touch} > \text{Touch Threshold}$
2. **드리프트는 ATI Band 안**: 노터치 환경 드리프트 $|\Delta_{drift}| < \text{ATI Band 폭}$ (밴드 이탈 = Re-ATI)

여기서 터치가 **밴드 이탈(Re-ATI)보다 먼저 감지**되려면, 터치로 인한 count 변화가 Re-ATI 발동(Band 폭) 전에 Threshold를 넘어야 한다:

$$\boxed{\text{Touch Threshold} < \text{ATI Band 폭}}$$

> [!IMPORTANT]
> **이 부등식이 안 지켜지면**: 손가락을 천천히 가까이 가져가는 동안 LTA가 동결되기 전에 counts가 먼저 Band 경계(Target−Band)를 넘어버리면, 터치 진입(Threshold) 이전에 LTA 밴드이탈 → Re-ATI가 터치를 노터치로 학습할 위험이 있다. (터치 중 Re-ATI 급소는 노드 02에서 별도 분석.) 안전하게는 **터치 진입 임계를 밴드 폭보다 작게** 두어 터치가 항상 먼저 잡히게 한다. [02_proxfusion §5.7·§5.10 종합, 추정]

### 3.2 현 설정 적용 — 부등식이 깨져 있음

| 양 | 현재 값 | 비교 |
|---|---|---|
| Touch Threshold | **100** [현코드 `TOUCH_THRESHOLD 100`] | |
| ATI Band 폭 | **50** (Target 400 / 8) | |
| 판정 | 100 > 50 → **부등식 위반** | ❌ |

현 설정은 **Touch Threshold(100)가 ATI Band 폭(50)의 2배**다. 즉 진짜 터치가 Threshold를 넘기 한참 전에 이미 Band(50)를 이탈한다. ATI Mode=Disabled인 현 펌웨어에서는 Re-ATI가 봉쇄되어 문제가 표면화되지 않았으나, **Full ATI 전환 시 자동 Re-ATI가 살아나면 이 위반이 직접 회귀 위험**이 된다 [추정 — 노드 02·10 교차검증 필요].

## 4. 온도 드리프트 vs ATI Band 마진

### 4.1 온도 드리프트로 인한 Re-ATI 빈도

- 온도 드리프트: 약 **−18 cnt/°C** (센서 채널, ATI 후 1000cnt 기준 예시) [적용가이드 §4.1, AZD125 §8.2.4]
- 우리 Target은 400cnt(1000cnt 예시와 절댓값 다름) → 드리프트 절댓값은 [실측 게이트]. 방향(온도↑→count↓)은 공통.

ATI Band 폭을 드리프트로 소진하는 데 걸리는 온도 변화:

$$\Delta T_{\text{Re-ATI}} = \frac{\text{ATI Band 폭}}{|{-18}|\ \text{cnt/°C}}$$

| ATI Band 폭 | Re-ATI 발동 온도폭 | 평가 |
|---|---|---|
| 50 (현 Target 400, 1/8) | 50/18 ≈ **2.8 °C** | 너무 잦음 — 실내 변동에도 빈번 Re-ATI |
| 100 (Target 800, 1/8) | 100/18 ≈ **5.6 °C** | 합당 — 일상 온도변동 흡수, 큰 변화만 Re-ATI |
| 50 (Target 400, 1/8) + Reseed 병행 | — | Re-ATI 전에 노터치 Reseed로 LTA 동기화 가능 [노드 02·03] |

> [!NOTE]
> -18cnt/°C는 1000cnt 기준 예시값이므로 우리 Target에 비례 환산이 필요할 수 있다(드리프트가 절대 cnt인지 상대 %인지 [자료 미명시]). 보수적으로 절대 −18cnt/°C 그대로 적용하면 위 표가 worst-case다. **실측으로 우리 보드의 cnt/°C 확정 필요** [실측 게이트].

### 4.2 드리프트가 터치를 침범하지 않을 조건

드리프트가 Touch Threshold를 우발적으로 넘기면 오탐이다. 단 LTA가 드리프트를 추종(노터치 시)하므로 정상 동작에서는 delta가 0 근처 유지. 문제는 **LTA 동결 중 드리프트**(stuck touch 또는 느린 추종):

$$\text{안전 마진} = \text{Touch Threshold} - \text{(LTA 동결 동안 누적 드리프트)}$$

LTA 추종이 정상이면 드리프트는 Threshold를 못 넘는다. 따라서 본 부등식의 실효 제약은 §3.1 (Threshold < Band)이 지배적이다.

## 5. SNR 기준 적용 (하한 게이트)

### 5.1 SNR≥5 터치 임계 하한

[적용가이드 §4.4, AZD125 §10.1]:

| 기능 | 최소 SNR | 임계값 최소 (노이즈밴드 4cnt 기준) |
|---|---|---|
| 임계(터치) | ≥ 5 | **raw 20 cnt** (전형 신호 최소 25cnt) |

- Touch Threshold ≥ 20 cnt여야 SNR≥5 충족 (노이즈 밴드 4cnt 가정).
- 우리 후보 Threshold 50~80은 **20cnt를 충분히 상회** → SNR 기준 통과. ✓
- 단 노이즈 밴드 4cnt는 EV-Kit 가정이므로 우리 보드 실측 peak-to-peak 노이즈로 재확인 필요 [실측 게이트].

### 5.2 임계 상·하한 종합

$$20\ \text{cnt}\ (\text{SNR하한}) \le \text{Touch Threshold} < \text{ATI Band 폭}\ (\text{밴드상한})$$

이 구간이 **유효 파라미터 영역**이다. 현 설정(Band 50)은 구간이 [20, 50)으로 좁고 Threshold 100은 구간 밖. Band 100으로 넓히면 구간 [20, 100)으로 여유 확보.

## 6. 권고 Target / Band / Threshold 범위

### 6.1 권고안 (Base 상향으로 Band 확대)

| 파라미터 | 현재 | **권고** | 근거 |
|---|---|---|---|
| ATI Base (0x37) | 100 (0x0064) | **200 (0x00C8)** | Target·Band 2배 확대, §6.2 |
| ATI Resolution Factor | 64 | 64 (유지) | Target=Base×4 유지 |
| ATI Target (계산) | 400 | **800** | 200×(64/16) |
| ATI Band | Large 1/8 | **Large 1/8 유지** | bit3=1 |
| ATI Band 폭 (계산) | 50 | **100** | 800/8 |
| Touch Threshold | 100 | **50~80** | 20 ≤ Th < 100, §5.2·§3.1 |
| Touch Hysteresis | 80 | 40~64 | Threshold의 ~80% [추정] |

권고 핵심: **Base를 200으로 올려 Band 폭을 100으로 키우고, Threshold를 Band 폭(100)보다 작은 50~80으로 내려** 부등식 `Threshold < Band`를 성립시킨다.

### 6.2 Base 상향의 트레이드오프

- 민감도 ∝ Target/Base [적용가이드 §2.1, AZD004 §4.4]. Base를 올리면 Target도 비례로 올라 **민감도 비(Target/Base=4)는 불변** → 민감도 손실 없음.
- Base 상향은 ATI MULT 단계가 더 큰 noTouch counts를 만들도록 수렴시키는 것 → counts 절대 해상도가 올라가 Band·Threshold의 cnt 여유가 커짐.
- 단 Base 200이 우리 회로 기생용량에서 ATI 수렴 가능 범위인지는 [실측 게이트] (MULT 포화 시 ATI Error).

### 6.3 대안: Band Small(1/16) 회피

ATI Band를 Small(1/16)로 바꾸면 Band 폭이 더 작아져(Target 400 → 25cnt) 부등식이 더 악화된다. **Small 채택은 금지**, Large(1/8) 유지가 필수.

### 6.4 Hysteresis 정합

터치 이탈 조건 $(LTA-Counts) > (\text{Threshold} - \text{Hysteresis})$ [02_proxfusion §5.7]. Hysteresis가 Threshold보다 크면 이탈 임계가 음수가 되어 터치가 안 풀린다. **Hysteresis < Threshold 필수** → Threshold 50~80에 맞춰 Hysteresis 40~64로 동반 하향(현재 80은 Threshold 50보다 커서 위험).

## 8. 설계 함의 요약

- **레지스터**: ATI Setup(0x36) = 0x040C(Full), ATI Base(0x37) = 0x00C8(200 권고). Touch Settings(0x62) Threshold=50~80, Hysteresis=40~64.
- **부등식 게이트**: 펌웨어/캘리 단계에서 `Touch Threshold < ATI Band 폭(=Target/8)` 및 `Touch Threshold ≥ 20(SNR)` 및 `Hysteresis < Threshold`를 컴파일타임 static_assert 또는 부팅 검증으로 강제 권고.
- **Re-ATI 빈도**: Band 100 → 온도 5.6°C마다 Re-ATI. 노터치 Reseed(노드 03)와 병행하면 Re-ATI 빈도를 더 낮출 수 있음.
- **검증 의존**: 노드 09(정량 할루시네이션)에 ATI Target/Band 공식·SNR 수치 원문 대조, 노드 02(Re-ATI 급소)에 터치-중-밴드이탈 타이밍, 노드 10(회귀)에 Threshold>Band 위반의 회귀 위험을 넘김.
