# 00 오케스트레이터 입력 — Full ATI 터치 제어 분석

**TL;DR**: FullATI 타임아웃 단순안을 펌웨어로 구현하기 위한 정량 분석·설계 결정·adversarial 검증 fan-out. **분석 8 → 검증 2 → 종합 1**(ultracode, effort xhigh). 페르소나 상세는 [`페르소나-정의.json`](페르소나-정의.json). 한자 절대 금지.

---

## 1. 설계 방향 (확정 — 모든 노드 공유)

브레인스토밍 수렴안 = **FullATI 타임아웃 단순안**:
- **Full ATI** 전환 (ATI Mode=Full, 자동 Re-ATI 활성). **Fixed MULT/COMP·공장 캘리·CRX1 CalCap 폐기**.
- **ATI 에러(밴드 이탈) 시 Re-ATI** — 상태 레지스터 폴링. 드리프트는 밴드 이탈 시 Re-ATI로 자동 커버.
- **IC 타임아웃 미사용 → SW 터치 지속 카운트(30초)**로 stuck 처리. (IC Channel Timeout은 ULP 충돌·동작 Reseed·인지 불가로 기각 — 20260618 §6)
- **CRX0 단일 채널**. 내부기 연결·크래들 충전 중 터치 미사용.
- **human-in-the-loop** 복구 전제(안 되면 사용자가 손/물체 뗌).

## 2. 핵심 미해결·결정 (분석 목표)

- 정량: Beta/Fast Filter Band(수렴), ATI Target/Base/Band/Threshold(밴드 안 threshold), 컨버전 1MHz·100ms·auto ULP·전력.
- 결정: SW 타임아웃 30초 후 동작, 터치 중 Re-ATI 경계(급소), CRX1 폐기 ESD, Full ATI I²C 무응답, 부팅 MCLR vs ATI 에러 체크, Max Counts 안전망.
