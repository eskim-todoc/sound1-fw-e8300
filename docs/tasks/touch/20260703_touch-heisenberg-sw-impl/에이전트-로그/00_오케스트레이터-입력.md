# 00 · 오케스트레이터 입력 (구현 계획 fan-out)

**TL;DR**: 조사 결론(SW-only 회피 가능, P0~P5)을 구현-레디 스펙으로. P0~P5 각 스펙 에이전트 6이 실제 코드+선행 S노드를 읽고 (파일·라인·값·시퀀스·불변식 회귀·fake_func_sleep 반영) 스펙 노드를 쓰고 구조화 반환 → 통합/회귀 검증 노드가 레버 간 충돌·C2 불변식 위반을 점검 → 오케스트레이터가 마스터 `계획.md`로 fan-in.

## 확정 전제

- **재현 경로 = `fake_func_sleep()`**(main.c:810~1031, BLE General Debug op_mode==1) — 은수님 확정. func_sleep()과 분리 복제 코드, 재부팅 호출 주석처리(no-op).
- **0xC0 write 사이트 6곳**(tdc_touch_iqs323.c): 237(ack 0x01), 318(base 0x50), 447(re_ati 0x54), 453(reseed 0x58), 465(0x54), 471(0x58). base 318 `0x50→0xD0`(bit7 set)이 P3 착지점. INV-X-1: Power Mode·CH timeout 비트 동반 보존.
- **C2 불변식**: INV-①~⑧ + INV-X (선행 [`../../20260703_touch-heisenberg-sw-mitigation/에이전트-로그/02_C2_기존기능인벤토리.md`] 참조).

## 편성 — Phase Integrate (검증 1~2)

- **통합/회귀 검증**: P0~P5 스펙을 모아 (a) 레버 간 충돌·중복(main.c·tdc_touch_iqs323.c 다중 수정 순서), (b) C2 불변식(INV-①~⑧·INV-X) 위반 0건, (c) fake_func_sleep 경로 반영 누락, (d) 롤아웃 순서 정합을 점검. refuted/충돌 반환.

## Fan-in 계획 (오케스트레이터 직접)

P0~P5 스펙 6 + 검증 → `99_종합.md`(레버별 구현 요약·충돌 해소) → 마스터 `계획.md`(P0 프로토콜 + P1~P5 구현-레디 스텝 + 롤아웃·검증·불변식 매트릭스) → `이력` 갱신 → 승인 요청. 승인 후 ④ 구현.
