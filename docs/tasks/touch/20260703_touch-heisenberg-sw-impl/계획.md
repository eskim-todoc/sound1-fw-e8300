# 계획 — SW-only 하이젠베르크 회피 마스터 구현 계획

**TL;DR**: 조사 결론(SW-only 회피 가능) → 재현경로 `fake_func_sleep()` 확정 → P0~P5를 **구현-레디 스펙**(파일:라인·before→after·불변식 회귀·롤아웃)으로 확정. 통합 검증 **논리충돌 0·확정 불변식 위반 0**. **P0 실측이 선결**이며 H1(I2C 5배)은 재현경로에서 코드로 반증됨. 승인 시 롤아웃 6단계 순서로 ④ 구현 착수. 근거: [`에이전트-로그/99_종합.md`](에이전트-로그/99_종합.md)·[`인덱스`](에이전트-로그/인덱스.md).

> [!IMPORTANT]
> 본 문서는 구현 계획(③)이다. **제품 소스 코드 변경은 승인 후 ④에서** 롤아웃 순서대로 진행한다(각 단계 후 빌드·회귀·실측 게이트). 현재 소스 변경 0 확인.

## 1. 목표·전제

- 현 셀프캡·현 HW·기존기능(C2 불변식 INV-①~⑧·INV-X) 유지, **SW 운영만으로** 절전 프로파일링(`fake_func_sleep()`, SYSCLK 30.72MHz·BLE 상시·QCC on) 클럭/SPI 결합 교란 회피.
- **재현경로 = `fake_func_sleep()`**(main.c:810~1031) 확정. func_sleep()과 분리 복제 코드.
- **H1(I2C 5배) 재현경로 반증[코드]**: fake_func_sleep은 I2C prescale 240(128kHz) 유지 → 애그레서 무게가 H2(read_debug)·물리결합으로 이동.

## 2. P0 — 실측 프로토콜 (선결, 은수님 환경 실행)

RTT 로그 + 4애그레서 단독 스윕으로 지배 애그레서·H2·재현경로를 이분 판별. **코드 미수정 임시 diagnostic**(측정 후 git diff 완전 원복이 P1~P5 착수 전제).

| 스윕 | 토글 | 판별 |
|---|---|---|
| DBG | `tdc_touch_config.h:22` DEBUG_PRINT_ENABLE 1→0 | **H2**(read_debug 자체 애그레서) — 끄면 증상 사라지면 H2 확정 |
| QCC | `main.c:828` 셧다운 주석해제 | QCC 결합 기여 |
| NRF | `main.c:826` 다음 ResetNRF()+NRF_Off_Command() 삽입 | SPI/NRF 기여(최후순위, 가드 미확인 리스크) |
| CLK | `main.c:861~862` 주석스왑(2.56MHz) | SYSCLK 기여(2변수 동반저하 교란 주의, 최후순위) |

- 로그: P0-LOG-1(main.c:908~909 감싸기) 매틱 `t/dt/ok/ati_error/ati_active/pressed/prox/카운터` 1줄 + 기존 로그 재사용.
- **재현경로 판정**: 재부팅 직전 RTT 마지막 줄이 main.c:951 "ATI ERROR → REBOOT"인지 → YES=C1 경로 단일원인, NO=별도 실패모드.
- 상세: [`에이전트-로그/01_P0_실측프로토콜.md`](에이전트-로그/01_P0_실측프로토콜.md).

| P | 변경 | 파일:라인 (before→after) | 불변식 |
|---|---|---|---|
| **P1** 관측 탈침습 | 안A `read_combined()` 신규(read_status+read_debug 통합, 레지스터 불변) / 안B `DEBUG_PRINT_ENABLE 1→0` | iqs323.c:398후 신규+호출부 3곳(tdc_touch.c:305/316, main.c:909·1233) / config.h:22 | INV-④ 파싱 바이트 이식검증·INV-⑦-1 3경로 회귀 |
| **P2** 드라이브·프리스케일 | I2C0 8X→4X·SPI1 2X→1X · prescale ÷6→÷21 | DIO_PIN_Config.h:54·13, main.c:1222 | ③④⑦ 주의(글리치·마진). prescale은 **재현경로 무관** |
| **P3** 0xC0 bit7 | 0x50→0xD0·0x54→0xD4(×2)·0x58→0xD8(×2), Streaming→Events | iqs323.c:318·447·453·465·471(237 ack 제외) | INV-X-1 bit7 확장·⑤⑦ 주의. **원자적 동시 반영** |

## 4. 롤아웃 6단계 (통합 검증 권장)

0. **P0 실측**(DBG→QCC→NRF→CLK) → git diff 완전원복.
1. **P2-prescale + P4** 병행 — 다른 파일, 부팅1회, 최저위험.
2. **P2-드라이브** 단독 → 글리치율 실측(원인분리).
3. **P1**(combined_read) — P0 완전원복 후, 적용 후 P3 라인앵커 grep 재확인.
4. **P3**(0xC0 bit7, 5사이트 원자적 커밋) — P1 위 안정화 후.
5. **P0 재실측** — 1~4 누적효과 검증.
6. **P5**(카운터 확장, 안전망) — **반드시 최후**(관찰 마스킹 회피).

각 단계: 빌드 → 회귀(C2 불변식) → 실측 게이트 통과 후 다음 단계.

## 5. 통합 전제조건 (4건)

1. **P0↔P1 시간분리**(main.c 908~909·917 공유).
2. **INV-④·⑦ 누적 분리 측정**(P1~P4 단계별).
3. **P5 최후 배치**(마스킹 회피).
4. **main.c:1011 `SYS_WATCHDOG_RESET()` 주석 복원 여부** — P3·P5 교차 결정, **은수님 확인 선행**(현재 touch측 재부팅 no-op).

## 6. 은수님 결정 요청

1. **본 마스터 계획 승인** 여부(롤아웃 6단계·전제 4건 포함).
2. **P0 실측 먼저 실행**하시겠는지 — 지배 애그레서·H2 확정이 이후 레버 효과 판정의 근거입니다. (P0는 은수님 RTT 환경 실행. 필요한 로그/토글은 [`01_P0`](에이전트-로그/01_P0_실측프로토콜.md)에 구현-레디로 정리됨.)
3. **main.c:1011 재부팅 복원**(전제 4) — touch측 재부팅을 되살릴지(P5 즉시효과와 직결).
4. **P1 안 선택**(안A read_combined 구조통합 vs 안B DEBUG_PRINT_ENABLE=0 최소변경) — 취향/리스크 선호.

승인 후, 롤아웃 순서대로 별도 구현 작업(④)으로 착수하겠습니다. P0 실측은 은수님 실행이 필요해 항목을 정리해 드리겠습니다.
