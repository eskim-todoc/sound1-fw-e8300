# 요구사항 — SW-only 하이젠베르크 회피 재탐색 (넓힌 스코프)

**TL;DR**: 은수님이 "기존 기능 유지"의 의미를 정정했다 — 불변은 **제어 3거동(Full ATI·ATI 에러 처리·첫 터치 해제 감지)뿐**이고, **센서 설정(레지스터)·채널 수(CH1 병용)·측정 방식은 자유 변수**다(SW 운영·HW 무수정 범위). 이 넓힌 스코프로 하이젠베르크(클럭/SPI 결합) 회피를 재탐색한다. **1순위 후보는 reference tracking(CH1)** — mutual(HW·기하로 No-go)이 아닌, IQS323의 공통모드 상쇄 전용 채널타입으로 SW-only. 검증을 최우선으로 사실(데이터시트·코드) 대조해 아닌 후보를 조기에 죽인다.

> [!NOTE]
> 선행: 상호용량 검토(No-go) → SW-only 조사(drive/I2C 등) → **스코프 정정으로 재탐색**. 은수님 지시(2026-07-03): "제어 3거동만 유지, 채널 둘 다 쓰든 측정방식 바꾸든 상관없다. 페르소나 빡세게, 할루시네이션 절대 없게 검증 빡세게 — 검증이 가장 중요."

## 1. 정정된 불변식 (반드시 유지)

- **INV-CTRL-1**: **Full ATI 사용** 유지 (IC 자동 게인 계산 방식).
- **INV-CTRL-2**: **ATI 에러 처리(Re-ATI)** 유지 (에러 시 재-ATI 트리거 경로).
- **INV-CTRL-3**: **첫(최초) 터치 해제 감지** 유지 (노말/절전 부팅 후 첫 릴리즈까지 무시).
- (당연 전제) 제품이 **터치를 정상 감지·롱터치·절전 진입/기상**하는 최종 기능은 유지되어야 함 — 단 그 **구현 방식(설정·채널·측정)**은 자유.

## 2. 자유 변수 (바꿔도 됨)

- **센서 레지스터 설정** 전면(변환·필터·ATI 밴드·Beta·이벤트·파워·채널모드 등).
- **채널 수**: CH1(현재 disable, 외부 CRX1·C52 배선 존재) 병용 가능.
- **측정 방식**: IQS323가 SW-only(레지스터)로 지원하는 범위 내 변경(예: reference tracking, 채널 구성, 오버샘플/동기 등).

## 3. 제약 (엄수)

- **HW 무수정**: PCB·소자·배선 변경 불가. SW/설정(e8300 FW + IQS323 레지스터)만.
- **mutual 제외**: 상호용량 전환은 선행 검토서 조건부 No-Go(HW·전극기하). 단 reference tracking은 **별개**(SW-only 채널모드)라 포함.
- **재현 경로 = fake_func_sleep()**(확정): 여기서 회피되면 완전 sleep(애그레서 적음)은 자동 성립(은수님 논리).
- **검증 최우선·할루시네이션 0**: 모든 핵심 주장(레지스터·비트·데이터시트 페이지·물리 원리)은 adversarial-verify로 **사실 대조** 후에만 확정. 특히 "이 후보가 클럭/스위칭(AC) 노이즈를 실제로 상쇄/저감하는가"를 데이터시트 근거로 엄격 판정 — 아니면 조기 기각.

## 4. 탐색 후보 (초안)

- **1순위 reference tracking(CH1)**: Channel Mode=Reference로 공통모드 교란 상쇄. **핵심 검증 질문: DC 드리프트만 상쇄하나, AC 클럭/스위칭 노이즈도 상쇄하나?** (make-or-break)
- **dual-channel(SW 차동)**: CH1을 노이즈 기준 채널로 살려 FW에서 CH0-CH1 차감.
- **측정 모드 재구성**: IQS323 SW-only 측정방식 변경 범위.
- **공격적 필터·ATI·임계 재설정**: 설정 자유화로 노이즈 면역 재튜닝(이전엔 제약).
- **센서레벨 동기·리포트레이트**: 변환 타이밍을 애그레서에서 이격.
- (보조 유지) 선행 P1~P5(read_debug·drive·0xC0·변환주파수·FSM 라이드스루).
