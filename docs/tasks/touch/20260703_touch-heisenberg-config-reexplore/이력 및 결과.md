## 완료 요약
- **결론(fact-verified)**: **config/channel/measurement 레벨로는 코히런트 AC 클럭/SPI 노이즈 상쇄 불가**. 1순위 reference tracking 데이터시트 기각(DC 드리프트만·touch 게이팅·LTA전용, 반증 4갈래 전부 실패). SW 차동(C-DUAL)은 **CH0-CH1 순차측정 확정(p.15·21)으로 공통모드 전제 붕괴**. C-MEAS(평균화 무력)·C-SYNC(외부동기 불가)·C-FILT(Threshold 헤드룸 소진) 전부 기각/약함.
- **완전성 비평(V6)**: IQS323 전체 레지스터맵+AZD004+AZD125 재탐색 → 상쇄 기능 전무, **Azoteq도 "SNR 마진 확보"만 제시**. 할루시네이션 0.
- **부수 발견**: 참고문서 오류 3건(데이터시트 md §5.6 "Beta 4비트" 오기·§5.7 Touch Debounce 과잉·main.c TIMER3 주석 모순).
