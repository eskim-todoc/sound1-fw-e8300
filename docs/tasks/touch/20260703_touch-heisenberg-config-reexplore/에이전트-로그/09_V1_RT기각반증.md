# 09 · V1 — C-RT(reference tracking) 기각 반증 시도

**TL;DR**: G1·C-RT의 모든 핵심 인용(문장·레지스터·비트·기본값·페이지·코드라인)을 데이터시트 원문 PDF와 `tdc_touch_iqs323.c` 코드에 **직접** 대조한 결과 **할루시네이션 0건**. 뒤집기(반증) 시도는 실패했고, 오히려 "Reference UI는 LTA만 다루고 raw Counts는 못 건드린다"는 **더 강한 독립 논거**를 추가로 발견했다. **기각 확정** — 게이팅 조건은 정의문 자체(예시 아님)임을 PDF 문단 구조로 직접 확인.

## 판정 요약

| 항목 | 판정 |
|---|---|
| G1·C-RT 핵심 인용 원문 일치 여부 | **전부 확인 — 할루시네이션 없음** |
| 반증(뒤집기) 시도 결과 | **실패** — 시도할수록 기각 논거가 강화됨 |
| AC 클럭/SPI 노이즈 실제 저감 근거 | **없음(확립)** — 어휘 부재 + 구조적 불가(신규 논거) |
| 살아날 여지 | **없음** |
| 최종 판정 | **기각 확정(강화)** |

## 3. 반증(뒤집기) 시도 — 4갈래, 전부 실패

과업 지시대로 "정말 여지가 없는지" 적극적으로 뒤집어 보았다.

### 3-1. 게이팅이 예시일 뿐이라는 재해석 시도 → 실패

PDF 원문을 육안으로 문단 구분까지 확인. "This subtraction is done when..." 문장은 정의 문단(2번째 문단) 안에 있고, "For example, in wear detect..."는 **명백히 새 문단**으로 시작한다. 조건절을 예시로 격하할 문헌적 근거가 없다 — G1의 원래 논거가 그대로 성립.

### 3-2. "LTA만 봐서 그렇지, 게이팅이 없었다면 잡았을 것" 가정 시도 → 실패 (더 강한 반박 발견)

게이팅을 잠시 무시하고 "상시 작동했다면?"을 가정해도, 진입 판정 공식(§5.7) 자체가 `(LTA − Counts) > Threshold`로 **raw Counts**를 직접 비교한다. Reference UI는 **LTA만** 조정하는 기능이다(§7.3 "adjusts the LTA... subtracting the change in LTA"). 순간적 노이즈가 raw Counts에 실리는 그 샘플에서 판정이 이루어지므로, LTA를 사후 보정하는 메커니즘은 **그 판정 시점에 원리적으로 개입할 통로가 없다** — 게이팅 유무와 무관하게 성립하는 **독립적이고 더 근본적인 반박**이다. Beta 상한(5.9%/샘플) 논거보다 한 단계 더 강하다: "느리게 반영된다"가 아니라 "애초에 판정에 쓰이는 신호(raw Counts) 자체를 건드리지 않는다."

### 3-3. "quasi-DC 재해석"(순간 스파이크가 아니라 fake_func_sleep 지속 중 준-DC 오프셋이라면?) 시도 → 실패

노이즈를 "지속적 오프셋"으로 재해석해도 실패 지점(재현 경로)은 **fake_func_sleep 진입 시점의 전이(idle→오인식)**다. Reference UI 게이팅은 "왜 드리프트가 생기는가(AC냐 DC냐)"가 아니라 "primary가 **이미** touch/prox 상태인가"만 본다. 오인식은 정의상 "아직 non-touch"인 순간에 일어나므로, 노이즈의 시간적 성질을 어떻게 재해석해도 게이팅 조건 자체를 통과하지 못한다. **AC/DC 논쟁과 무관하게 성립하는 결론**이라는 점이 이번 재검토로 새로 확인됐다.

### 3-4. "CH1 추가 자체가 타이밍/멀티플렉싱을 바꿔 우연히 유리해질 수 있다" 가설 → 근거 없음(방향 불확실)

CH0·CH1 동시/순차 변환 여부는 데이터시트 p.14-28·49-58 범위에서 확인 안 됨(G1·C-RT가 이미 미확인으로 명시, 본 세션도 재확인 못 함). 채널을 늘리면 오히려 순차 변환 시간이 늘어나 SPI/클럭 충돌 노출 창이 **넓어질 수도** 있어 방향성 자체가 불확실 — 지시된 원칙("불확실하면 refuted 쪽")에 따라 구제 근거로 채택 불가.

**종합**: 4갈래 모두 실패. 반증 시도가 오히려 §3-2에서 원래 문서보다 강한 독립 논거를 만들어냈다 — 뒤집기가 아니라 **보강**으로 귀결.

## 4. 부차적 발견 — 인용 재구성 이슈 1건 (경미, 핵심 판정 비영향)

G1 §1: "상호용량 검토 노드(`06_P6_대안트레이드오프결정.md#L51`)가 지적한 **'준-DC에서만 유리, 빠른 스위칭엔 근거 약함'** 논리와 방향이 일치"

원문 L51 직접 대조 결과, P6는 이렇게 말하지 않는다. 실제 L51: "디퍼런셜 프로브는 경로_1만 상쇄한다는 서술은 **외부 계측 프로브**에 대한 것이지 IQS323 **내장 mutual-cap 센싱**에 대한 것이 아니다... 이는 mutual이 경로_2를 잡는다는 steelman에도, 못 잡는다는 반론에도 **동일하게 적용되는 제약**"이다 — 즉 P6는 mutual-cap 내장 센싱에 대해 "**양방향 모두 근거 밖(불가지론)**"이라고 말하는 것이지, "준-DC엔 유리"라는 방향성 있는 결론을 낸 것이 아니다.

**판정**: 인용이 원문보다 단정적으로 재구성됨(경미한 과장). 단, 이는 **보조 유비(analogy) 링크**일 뿐 — reference tracking 자체의 핵심 판정은 §1의 직접 원문 인용(p.26 "This subtraction is done when...")에 전적으로 의존하며 이는 100% 확인됨. 이 재구성 이슈가 핵심 판정을 흔들지 않는다.

## 5. 최종 판정

**C-RT(reference tracking) 기각 확정.** 뒤집을 여지 없음. 근거 3층 독립 확립:

1. **어휘 부재**(§7.3·5.1 전문에 clock/switching/SPI/noise 없음, 원문 재확인)
2. **게이팅 불일치**(상쇄가 primary already-touch/prox 상태에서만 작동 — 오인식은 정의상 그 이전 순간에 발생, PDF 문단 구조로 확인)
3. **신규 — 신호 계층 분리**(Reference UI는 LTA만 조정, 판정에 쓰이는 raw Counts는 건드리지 않음 — 게이팅 유무와 무관하게 성립하는 독립 논거)

세 논거 모두 서로 다른 근거(어휘·문단구조·신호계층)에서 나와 상호 보강되며, 하나가 틀려도 나머지 둘이 결론을 지탱한다. SW-only 구현 가능성(§3, G1) 자체는 사실이나 목적(하이젠베르크 회피) 부적합은 변하지 않는다.

**미확인(실측 게이트, 잔존 — 판정에 영향 없음)**: CRX1/C52 물리조건 충족 여부, CH0·CH1 동시/순차 변환, 0xC0 Re-ATI 전체/부분 재실행 범위, 터치 해제 시 상쇄 종료 거동. 이들은 "C-RT를 살릴 근거"가 아니라 "C-RT를 채택할 경우 별도로 남는 리스크"이므로, 이미 기각된 후보에 대해 추가 실측 우선순위 낮음.
