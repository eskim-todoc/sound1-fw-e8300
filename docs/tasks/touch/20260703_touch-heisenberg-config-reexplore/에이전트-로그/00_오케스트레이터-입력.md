# 00 · 오케스트레이터 입력 (재탐색 fan-out)

**TL;DR**: 제어 3거동(Full ATI·ATI 에러 처리·첫 터치 해제)만 불변, 설정·채널·측정방식 자유로 하이젠베르크 회피 재탐색. **2단 워크플로우** — WF1: 그라운드 3(reference tracking 실능력·IQS323 SW측정변경 능력·3불변식 코드훅) + 후보 5 생성 → 오케스트레이터 선별 → WF2: 후보별 **빡센 adversarial 검증**(사실 대조·할루시네이션 0). 검증이 최우선.

## 문제 정의

> 현 셀프캡·현 HW를 두고, **제어 3거동만 유지**하며 설정·채널(CH1)·측정방식을 자유롭게 바꿔, SW 운영만으로 fake_func_sleep(30.72MHz·QCC on·BLE·SPI) 클럭/SPI 결합 교란을 회피할 수 있는가? 특히 reference tracking(CH1)이 이 노이즈를 실제로 상쇄하는가?

## 공통 컨텍스트

- **불변식**: INV-CTRL-1(Full ATI)·2(ATI 에러 Re-ATI)·3(첫 터치 해제). 그 외(레지스터·채널수·측정방식) 자유. 최종 터치감지·롱터치·절전동작은 당연 전제.
- **CH1 현황**: 현재 disable(0x40=0x0000). 외부 CRX1·C52 배선 존재(과거 CalCap 더미 이력).
- **재현경로 = fake_func_sleep()**. H1(I2C 5배)은 이 경로에서 코드 반증됨(prescale 240 유지). 애그레서 무게 = H2(read_debug)·물리결합(SPI/SYSCLK/QCC).
- **핵심 검증질문(make-or-break)**: reference tracking이 **DC 드리프트만** 상쇄하나, **AC 클럭/스위칭(경로_2)도** 상쇄하나? 데이터시트 근거로 판정 — 아니면 조기 기각.

## WF1 — Phase Ground (병렬 3, 배리어)

| 노드 | 페르소나 | 과업 | 근거 |
|---|---|---|---|
| G1 | **reference tracking 실능력** | Channel Mode=Reference의 데이터시트 정확 메커니즘: 무엇을 어떻게 상쇄하나(DC 드리프트 vs AC 스위칭), 참조 채널이 무엇을 감지하나, SW-only 설정법, Full ATI/ATI에러/첫터치해제와 상호작용. **AC 노이즈 상쇄 여부를 근거로 못박기** | 데이터시트/02·04·06, 레퍼런스/동작원리·레지스터맵, 상호용량 검토 노드 |
| G2 | **IQS323 SW 측정·채널 변경 능력** | SW-only(레지스터, HW무수정)로 가능한 측정방식·채널구성 전수: 채널모드(Independent/Follower/Reference), dual-channel 활용, 오버샘플/동기/리포트레이트. 현 CH1(C52) 실채널화 SW 가능성 | 데이터시트/02·03·06, 레퍼런스, 예제코드/03 |
| G3 | **3불변식 코드훅** | INV-CTRL-1~3가 현 코드 어디에 걸려 있는지(Full ATI 0x36·부팅Re-ATI, ATI에러→Re-ATI 경로, 첫터치해제 boot_ignore/sleep_ignore). 후보가 반드시 보존할 최소 계약. 그 외는 자유임을 명확화 | 현 코드 tdc_touch_iqs323.c·tdc_touch_logic.c·main.c, 선행 C2 노드 |

## WF1 — Phase Generate (병렬 5)

| 후보 | 초점 | 근거 |
|---|---|---|
| **C-RT** reference tracking(CH1) | G1 근거로 CH1을 Reference 채널화해 공통모드 교란 상쇄. 레지스터·시퀀스·3불변식 보존·한계 | G1·G2, 데이터시트 |
| **C-DUAL** SW 차동 | CH1을 노이즈 기준으로 살려 FW에서 CH0-CH1 차감(IC reference와 별개 SW 접근) | G2·G3, 현 코드 |
| **C-MEAS** 측정모드 재구성 | IQS323 SW-only 측정방식 변경(변환구조·오버샘플 등)으로 노이즈 강건 | G2, 데이터시트/02·03 |
| **C-FILT** 공격적 필터·ATI·임계 | 설정 자유화로 필터/ATI밴드/Beta/임계를 노이즈 면역 재튜닝 | 데이터시트/04, 터치 임계·계수 문서 |
| **C-SYNC** 센서레벨 동기·리포트 | 변환 타이밍/리포트레이트를 애그레서에서 이격(센서 자체 설정) | 데이터시트/02·06, 관측교란.md |

각 후보: SW-only·HW무수정, 3불변식 보존, 실제 저감 근거, 레지스터·시퀀스 구체화, 한계·미확인 표기.

## WF2 — 빡센 adversarial 검증 (오케스트레이터 선별 후)

생존 후보별 **다중 회의론자**(사실 대조·반증 우선): (a) 물리/데이터시트 — AC 노이즈 실제 상쇄하나? (b) SW-only·HW무수정 진위, (c) INV-CTRL-1~3 보존, (d) **할루시네이션 감사** — 인용한 레지스터·비트·데이터시트 페이지를 원문 대조. 불확실하면 refuted. 사실로 아닌 게 밝혀지면 조기 기각(엄한 고생 방지).
