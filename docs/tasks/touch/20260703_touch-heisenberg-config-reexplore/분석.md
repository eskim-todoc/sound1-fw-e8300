# 분석 — config/channel/measurement 재탐색 (넓힌 스코프)

**TL;DR**: 제어 3거동만 불변·설정/채널/측정 자유로 넓혀 재탐색했으나, **fact-verified 결론은 부정** — config/channel/measurement 레벨에 코히런트 AC(클럭/SPI) 노이즈를 상쇄하는 SW 해법이 없다. 1순위 **reference tracking은 데이터시트로 기각**(DC 드리프트만·touch 게이팅), **SW 차동은 순차측정으로 기각**. 완전성 비평이 IQS323 전체 레지스터맵+Azoteq 앱노트로 "상쇄 기능 전무"를 확정. 검증이 헛된 방향을 사실로 차단했다. 상세: [`에이전트-로그/99_종합.md`](에이전트-로그/99_종합.md).

> [!NOTE]
> 워크플로우 14에이전트(그라운드 3·후보 5·검증 6). 은수님 지시 "할루시네이션 절대 없게 검증 빡세게"에 따라 모든 핵심 주장을 데이터시트 원문 대조 — **하드 할루시네이션 0건**(단 참고문서 오류 3건 별도 발견).

## 1. 정정된 스코프

- **불변**: 제어 3거동만 — Full ATI(0x36·부팅 Re-ATI) / ATI 에러 처리(ati_error→re_ati, 3사이트) / 첫 터치 해제(boot_ignore·sleep_ignore). (G3가 코드훅 특정.)
- **자유**: 센서 레지스터 설정·채널 수(CH1 병용)·측정 방식.
- **제약**: SW-only·HW 무수정. mutual 제외(단 reference tracking은 별개=포함).

## 2. 그라운드 사실 (G1·G2·G3)

- **G1 reference tracking 실능력(make-or-break)**: 데이터시트 §7.3(p.26)·§5.1(p.15) 원문 — 상쇄 대상은 **count drift·온도·습도(DC)뿐**, clock/switching/SPI/noise 어휘 전무. 상쇄가 **"primary가 touch/prox 상태일 때만" 작동**(정의 게이팅) → idle 오인식(fake_func_sleep)에 원리적 무관. LTA(느린 IIR)만 조정.
- **G2 SW 측정/채널**: 채널모드(Independent/Follower/Reference)는 LTA 드리프트 보정만. CH0+CH1 raw counts FW 병행 읽기는 항상 가능. **외부 클럭/SPI 위상 동기 레버 없음**(IQS323 자유구동 오실레이터). CH1 실채널화는 물리전극(HW) 미확인.
- **G3 3불변식 코드훅**: 후보가 보존할 건 3거동 코드훅뿐, 나머지 자유. fake_func_sleep은 분리 복제라 3사이트 모두 대상.

## 4. 완전성 비평 (V6) — 결정적 확정

IQS323 전체 레지스터맵(A.1~A.37)+AZD004+AZD125 재탐색 → **코히런트 AC 상쇄 register·기능 전무**. **Azoteq 자신도 "상쇄"가 아닌 "SNR 마진 확보"(AZD125 §10)만 제시**. → config/channel/measurement 레벨로는 불가 확정. 할루시네이션 0.

## 5. 근본 이유

코히런트(클럭 유래) 노이즈라 평균화·필터로 안 지워지고, IQS323가 AC용 차동/참조 상쇄 회로를 제공하지 않으며(reference tracking=DC 전용), 채널을 둘 써도 순차측정+비대칭결합이라 상쇄 불성립. mutual(HW/기하 No-go)과 함께 **"차동으로 클럭노이즈 상쇄"라는 접근 자체가 이 IC·보드에선 SW로 성립 불가**.
