# 계획: func_sleep() 구조 정리

**TL;DR**: [분석.md](분석.md) 5노드 + 검증([21](에이전트-로그/21_검증_동작보존.md)·[22](에이전트-로그/22_검증_스타일정합.md)) 결과를 종합한 최종안. `main.c`의 `func_sleep()`(1033~1219행)에서 **ULP while 루프 바디만** 5개 정적 함수로 분리, 진입부는 변수·주석·print만 정리. **동작 100% 동일**이 최우선 제약이며, 아래 모든 항목은 이 제약을 최우선 검토 기준으로 삼는다.

> [!IMPORTANT]
> 본 계획은 [11_계획_통합설계.md](에이전트-로그/11_계획_통합설계.md)(1차 통합안)에 adversarial 검증(21·22)의 발견 7건을 전부 반영한 **최종본**이다. 구현은 반드시 본 문서 기준으로 진행한다.

## 1. 변경 범위

- 파일: `src/2__cm3/Cortex-M3-src/main.c`, `func_sleep()` 함수(1033~1219행)만.
- **비변경**: `fake_func_sleep()`, 모든 드라이버 함수(`tdc_touch_iqs323_*`) 시그니처·구현, FSM 로직(`tdc_touch_logic.c`).
- 동작(로직)은 리팩토링 전후 **100% 동일**해야 한다 — 이번 작업은 순수 구조정리다.

## 2. 신규 정적 함수 5종

전부 `static`, `tdc_` 접두어, `func_sleep()` 바로 앞(또는 `main.c` 내 적절한 위치)에 정의. 상태(카운터·게이트)는 **비-const 포인터**로 전달해 `func_sleep()`이 계속 소유한다(헬퍼 내부 `static`으로 은닉 금지). 호출 순서는 원본 그대로 유지.

| 함수 | 시그니처 | 역할(if 분기 + **반드시 포함할 else/else-if 리셋 분기**) |
|---|---|---|
| `tdc_touch_sleep_log_debug` | `static void tdc_touch_sleep_log_debug(bool ok, const tdc_touch_iqs323_status_t *st, tdc_touch_state_t state)` | 계측 로그 1줄 출력. 전체가 `#if (TDC_TOUCH_DEBUG_PRINT_ENABLE)` 캡슐화(§3). |
| `tdc_touch_sleep_handle_ati_error` | `static void tdc_touch_sleep_handle_ati_error(bool ok, const tdc_touch_iqs323_status_t *st, int *ati_error_reboot_cnt)` | `if (ok && st->ati_error && !st->ati_active)`: 5회 이하 재시도(`re_ati()`+카운트 증가) / 초과 시 리부팅. **+ `else if (ok && !st->ati_error && !st->ati_active) { *ati_error_reboot_cnt = 0; }`을 반드시 함께 이식** — 조건에서 `!ati_active`를 빠뜨리면 ATI burst 진행 중에도 카운터가 리셋되어 임계값 의미가 바뀜(21 발견_1). |
| `tdc_touch_sleep_handle_notouch_gate` | `static void tdc_touch_sleep_handle_notouch_gate(bool ok, tdc_touch_state_t state, bool *sleep_ignore, int *notouch_cnt, int *ignore_elapsed)` | `sleep_ignore` true일 때만 호출(호출부에서 `if`). 노터치 확정→RESEED+게이트 해제, 10초 타임아웃→강제 RESEED. **+ `notouch_cnt` 리셋 else 분기(TOUCH 또는 read 실패 시) 반드시 포함**(21 발견_1). |
| `tdc_touch_sleep_handle_touch_reboot` | `static void tdc_touch_sleep_handle_touch_reboot(bool ok, tdc_touch_state_t state, int *touch_cnt)` | `sleep_ignore` false일 때만 호출(호출부에서 `else`). TOUCH 연속 감지 시 카운트, 임계 도달 시 LED+리부팅. **+ `else { *touch_cnt = 0; }` 리셋 분기 반드시 포함**(21 발견_1). |
| `tdc_touch_sleep_log_state_transition` | `static void tdc_touch_sleep_log_state_transition(bool ok, tdc_touch_state_t state, tdc_touch_state_t *ulp_state_prev)` | 상태 천이 시 로그 1줄(현재 printv → printd, §4). |

`sleep_ignore`에 따른 `if/else` 분기 자체(어느 함수를 호출할지)는 `func_sleep()`의 루프 바디에 남겨 상태 배타성을 호출부에서 드러낸다.

## 3. 변수 재배치 최종안

`func_sleep()` 최상단(선언만, 매 iteration 재초기화 아님을 주석으로 명시):

```c
int ret;

/* 루프 진입 전 1회 초기화 — 영속 상태. 매 iteration 재초기화 금지(상태머신 붕괴) */
bool              sleep_ignore         = true;
int               notouch_cnt          = 0;
int               ignore_elapsed       = 0;
int               touch_cnt            = 0;
tdc_touch_state_t ulp_state_prev       = TDC_TOUCH_STATE_RESET;
int               ati_error_reboot_cnt = 0;

/* 매 iteration 갱신 — 선언만 여기, 대입(read_status 등)은 루프 내부에 그대로 유지 */
tdc_touch_iqs323_status_t st;
bool                      ok;
tdc_touch_state_t         state;
```

> [!CAUTION]
> `st`/`ok`/`state`는 **선언만** 최상단으로 옮긴다. `ok = tdc_touch_iqs323_read_status(&st); state = st.pressed ? ... ;` **대입문은 반드시 루프 바디 안, 매 iteration 그대로 실행**되어야 한다(21 발견_2). 대입문까지 루프 밖으로 끌어올리면 2번째 iteration부터 터치 상태가 영구 고정(stale)되는 치명적 회귀다.

`dbg`/`delta`/`abs_thr`/`pabs_thr`는 `tdc_touch_sleep_log_debug()` **내부**(그 함수 자신의 최상단, `#if` 게이트 안)로 이관한다(01 채택안 — "게이트를 선언까지 확장").

`ok` 게이트는 아래 **5곳 전부**를 보호해야 하며, 구현 후 이 5곳 모두 원본과 동일한 `ok &&` 조건인지 diff 대조 확인한다(21 발견_3, 원본 3곳이 아닌 5곳으로 정정):
1. `tdc_touch_sleep_log_debug` 내부 `if (ok)`
2. `tdc_touch_sleep_handle_ati_error` 내부 `if (ok && ...)`
3. `tdc_touch_sleep_handle_notouch_gate` 내부 `if (ok && ...)`
4. `tdc_touch_sleep_handle_touch_reboot` 내부 `if (ok && ...)`
5. `tdc_touch_sleep_log_state_transition` 내부 `if (ok && ...)`

## 4. ci_print 최종 매핑표

판정 기준: **이 라인 실행 후 `SYS_WATCHDOG_RESET()`으로 칩이 강제 리셋되는가** — 이 축만이 "최대 에러 상태"에 부합하는 유일한 objective 경계선.

| 메시지 | 현재 | 최종 |
|---|---|---|
| CM3 IS PREPARING TO ENTER SLEEP MODE | printi | printd |
| FIRST OF ALL, TRY TO POWER OFF FPGA BACKTRL H/W | printi | **삭제**(바로 다음 줄의 결과 출력과 중복) |
| FPGA reset : %s | printi | printd |
| CFX : sleep | printi | printd |
| LTA=... 계측 한 줄 | printd | printd(유지) |
| ATI ERROR -> REBOOT (recover in normal) | printw | printw(유지 — 직후 `SYS_WATCHDOG_RESET()`) |
| ATI ERROR -> RECOVER (in sleep) | printw | **printd**(재시도 중, 최종 아님) |
| notouch confirmed -> RESEED, gate open | printi | printd |
| notouch timeout 10s -> forced RESEED | printw | **printd**(비치명 자동복구 — 리부팅으로 이어지지 않음, 최종 확정) |
| touch detected -> REBOOT | printi | **printw**(직후 `SYS_WATCHDOG_RESET()` — 승격) |
| ULP STATE 천이 | printv | printd |

**결과: `printw` 정확히 2건**(ATI ERROR REBOOT, touch detected REBOOT — 둘 다 직후 `SYS_WATCHDOG_RESET()` 호출), 나머지 전부 `printd`. `printi`/`printv`/`printe` 0건.

## 5. 주석 방침

[04_분석_주석정리.md](에이전트-로그/04_분석_주석정리.md) 판정 그대로 채택:
- **삭제**: 함수/변수명 재서술형 WHAT 8건 + 중복 1건(총 9건)
- **정리(죽은 코드 제거)**: 주석 처리된 비활성 코드 3건(`Uninitialize()`, `ci_fake_power_sleep()`, `delay_ms(20)`/중복 `SYS_WATCHDOG_RESET()`) — 존치 근거 없어 이번 정리에서 함께 제거
- **유지(최우선, 절대 삭제 금지)**: 게이트 철학(90-94행 4개 불릿), 워치독 refresh 순서 근거(105행), ATI 예외조건 근거(126-127행, `!ati_active` 이유)
- **축약**: CFX 대기 루프 주석, 10초 타임아웃 주석 2건

> [!IMPORTANT]
> 함수 분리 시 **주석은 원본 코드와 함께 새 함수로 이관**한다(22 발견 — WHY 주석이 원위치에 고아로 남지 않도록). 예: ATI 예외조건 근거(126-127행)는 `tdc_touch_sleep_handle_ati_error()` 함수 위/내부로 그대로 이동.

## 6. func_sleep() 최종 구조 개요

```c
int func_sleep(void)
{
    /* 변수 선언부(§3) */
    int ret;
    bool sleep_ignore = true;
    /* ... (§3 전체) ... */

    /* 진입부 — 구조 변경 없음(05 근거), 변수만 위로, 주석·print만 정리 */
    ...

    while (1)  // ULP loop
    {
        SYS_WAIT_FOR_INTERRUPT;
        SYS_WATCHDOG_REFRESH(); /* 순서 불변 — 워치독 3.28s 대비 */

        ok    = tdc_touch_iqs323_read_status(&st);   /* 대입은 루프 내부 유지(§3 CAUTION) */
        state = st.pressed ? TDC_TOUCH_STATE_TOUCH : TDC_TOUCH_STATE_NOT_TOUCH;

        tdc_touch_sleep_log_debug(ok, &st, state);
        tdc_touch_sleep_handle_ati_error(ok, &st, &ati_error_reboot_cnt);

        if (sleep_ignore)
        {
            tdc_touch_sleep_handle_notouch_gate(ok, state, &sleep_ignore, &notouch_cnt, &ignore_elapsed);
        }
        else
        {
            tdc_touch_sleep_handle_touch_reboot(ok, state, &touch_cnt);
        }

        tdc_touch_sleep_log_state_transition(ok, state, &ulp_state_prev);
    }

    return 0;  /* 도달 불가 — 컴파일러 만족용 */
}
```

`if (sleep_ignore) { ... } else { ... }`는 중괄호 필수(단일 문이어도, 프로젝트 규칙). 이는 원본에도 이미 있던 분기라 신규 분기는 아니지만, 구현 시 형태를 그대로 유지한다(22 발견 대응).

## 7. 구현 순서

1. 5개 정적 함수 선언·본문 이식(원본 로직 문자 그대로 복사 + §2의 else/else-if 리셋 분기 반드시 함께 포함, 관련 주석도 §5 방침대로 함께 이관)
2. `func_sleep()` 변수 최상단 재배치(§3), `st`/`ok`/`state` 대입문은 루프 내부 잔류 확인
3. 루프 바디를 §6 호출 시퀀스로 교체
4. ci_print 레벨 표(§4) 일괄 적용 + 중복 메시지 삭제
5. 주석 정리(§5) 적용 — 삭제 9건, 죽은 코드 3건 제거, 축약 2건
6. `#if (TDC_TOUCH_DEBUG_PRINT_ENABLE)` 비활성 빌드 컴파일 확인(미사용 변수/파라미터 경고 0건 — §3 게이트 확장안 적용 여부 재확인)
7. 원본 대비 diff 대조 — §3의 `ok` 게이트 5곳, §2의 리셋 분기 3곳, watchdog refresh/reset 순서 전수 확인

| `st`/`ok`/`state` 대입문까지 루프 밖으로 끌어올림(stale 값 고착) | §3 CAUTION 명문화, 구현 후 대입문 위치 재확인 |
| 헬퍼 함수 추출 중 `ok` 게이트 누락 | §3에 5곳 체크리스트 명시, 원본 조건식 그대로 복사 |

| printw→printd 격하(ATI RECOVER)·printw 격하(notouch timeout)로 실제 운영 로그 가시성 저하 우려 | 순수 표시 레벨 변경이며 로직 미변경 확인(21 발견_4, `ci_printf.h` 매크로 확인 완료) |

| 함수 분리로 주석(WHY)이 원위치에 고아로 남음 | §5 IMPORTANT — 주석은 코드와 함께 새 함수로 이관 |

## 9. 승인 후 진행

본 계획 승인 시 §7 순서대로 `main.c`를 수정한다(단계 ④). 구현 후 정적 검증(중괄호·tdc_ 접두어·printe 0건·§8 diff 대조)을 진행하며, 빌드·실기 확인은 은수님 환경에서 진행한다.
