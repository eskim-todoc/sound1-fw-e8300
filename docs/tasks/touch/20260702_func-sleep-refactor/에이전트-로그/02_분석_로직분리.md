# 분석_로직분리

## 논리블록 5분해 (원본 `main.c:104~214` 기준)

| 블록 | 원본 라인 | 책임 |
|---|---|---|
| (분리 안 함) 웨이크업·상태읽기 | 104~109 | `SYS_WAIT_FOR_INTERRUPT`/`SYS_WATCHDOG_REFRESH`/`tdc_touch_iqs323_read_status` — 모든 후속 블록의 입력(`ok`, `st`, `state`)을 생산하므로 함수로 뽑지 않고 루프에 남긴다 |
| 계측출력 | 111~124 | `#if TDC_TOUCH_DEBUG_PRINT_ENABLE` 게이트 계측 한 줄(`ci_printd`) |
| ATI에러처리 | 126~153 | `ati_error_reboot_cnt` 증감·재부팅 분기 |
| sleep_ignore게이트 | 155~182 | `sleep_ignore`/`notouch_cnt`/`ignore_elapsed` 3변수로 노터치 확정·강제 RESEED |
| 터치리부팅 | 183~207 | `touch_cnt` 증감·재부팅 트리거 (게이트 해제 후에만 도달) |
| 상태천이추적 | 209~214 | `ulp_state_prev` 갱신·`ci_printv` 로그 |

`sleep_ignore게이트`와 `터치리부팅`은 원본에서 동일 `if (sleep_ignore) {...} else {...}` 의 상호배타 분기(155, 183)이므로, 각각 별도 함수로 추출하되 **분기 자체는 `func_sleep()`에 남긴다** — 두 상태(게이트 중/해제 후)가 동시에 실행되지 않는다는 사실이 호출부에서 한눈에 보여야 하기 때문.

## 제안 시그니처

```c
static void tdc_touch_sleep_log_debug(bool ok, const tdc_touch_iqs323_status_t *st, tdc_touch_state_t state);

static void tdc_touch_sleep_handle_ati_error(bool ok, const tdc_touch_iqs323_status_t *st, int *ati_error_reboot_cnt);

static void tdc_touch_sleep_handle_notouch_gate(bool ok, tdc_touch_state_t state, bool *sleep_ignore, int *notouch_cnt, int *ignore_elapsed);

static void tdc_touch_sleep_handle_touch_reboot(bool ok, tdc_touch_state_t state, int *touch_cnt);

static void tdc_touch_sleep_log_state_transition(bool ok, tdc_touch_state_t state, tdc_touch_state_t *ulp_state_prev);
```

- 전부 `void` 반환: 순수 부수효과(카운터 갱신·로그·경우에 따라 재부팅)만 수행하고 루프 흐름 제어(break/continue)에 관여하지 않는다. 재부팅 경로(130~146, 188~199)는 `SYS_WATCHDOG_RESET()`으로 실제 칩 리셋되어 "도달 불가"이므로 함수 내부에 그대로 남겨도 무방 — 반환 후 로직 영향 없음.
- `ok`/`state`/`st`는 매 iteration 105~109에서 새로 계산되는 **읽기 전용 입력**이라 값 전달(값 또는 `const` 포인터)로 충분. `st`만 구조체라 포인터(`const tdc_touch_iqs323_status_t *`)로, 나머지는 값.
- 카운터·게이트(`ati_error_reboot_cnt`, `sleep_ignore`, `notouch_cnt`, `ignore_elapsed`, `touch_cnt`, `ulp_state_prev`)는 전부 **비-`const` 포인터**로 전달 — 요구사항대로 `func_sleep()` 지역변수 소유를 유지하고, 헬퍼 내부 `static` 은닉을 금지한다(호출 간 상태가 정적 저장이면 재진입·테스트·리셋 안전성이 깨짐).
- 함수명은 `tdc_touch_sleep_*` 접두 통일 — 모듈(`tdc_touch`) + 컨텍스트(`sleep`, 즉 ULP 절전 루프 전용) + 동작(`log_debug`/`handle_ati_error`/...) 순으로 그룹핑되어 `fake_func_sleep()`(제외 대상)과 헬퍼를 공유하지 않는다는 점도 명확해진다.

## `func_sleep()` 잔존 루프 바디 (호출 시퀀스만)

```c
while (1)  // ULP loop
{
    SYS_WAIT_FOR_INTERRUPT;
    SYS_WATCHDOG_REFRESH();

    tdc_touch_iqs323_status_t st;
    bool                      ok    = tdc_touch_iqs323_read_status(&st);
    tdc_touch_state_t         state = st.pressed ? TDC_TOUCH_STATE_TOUCH : TDC_TOUCH_STATE_NOT_TOUCH;

    tdc_touch_sleep_log_debug(ok, &st, state);
    tdc_touch_sleep_handle_ati_error(ok, &st, &ati_error_reboot_cnt);

    if (sleep_ignore)
    {
        tdc_touch_sleep_handle_notouch_gate(ok, state, &sleep_ignore, &notouch_cnt, &ignore_elapsed);
    }
    else
    {
        tdc_touch_sleep_handle_touch_reboot(ok, state, &touch_cnt);
    }

    tdc_touch_sleep_log_state_transition(ok, state, &ulp_state_prev);
}
```

12줄(선언 2줄 포함)로 축약 — 원본 111줄(104~214) 분기·계측·카운터 로직이 전부 5개 명명 함수로 이동한다.

## 순서·회귀 위험 메모

- `SYS_WATCHDOG_REFRESH()`(105)는 반드시 루프 최상단, 어떤 헬퍼 호출보다도 먼저 — 헬퍼로 이동 금지(오케스트레이터 확정 컨벤션).
- ATI에러처리(3번째 호출)가 sleep_ignore게이트/터치리부팅(4번째)보다 먼저 실행되어야 원본 128~153 → 155/183 순서와 동일 — 호출 순서 재배열 금지.
- `tdc_touch_sleep_log_debug`는 `#if TDC_TOUCH_DEBUG_PRINT_ENABLE`를 함수 **내부**로 옮기면 호출부가 항상 무조건 호출되어 매크로 값과 무관하게 컴파일되지만, 비활성 시 함수 바디가 비어 런타임 비용은 사실상 0. `#if`를 호출부에 남기는 대안도 가능(정보만 제공, 최종 판단은 계획 노드).
