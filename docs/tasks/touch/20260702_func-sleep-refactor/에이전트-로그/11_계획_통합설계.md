# 11_계획_통합설계 — func_sleep() 최종 리팩토링 계획

전제: 동작 100% 동일이 최우선 제약. 분리 대상은 ULP while(1) 루프(main.c:1101~215)만이며, 진입부(1037~1099)는 변수 이동·주석 정리·print 재분류만 적용한다(05 근거).

## ① 신규 정적 함수 목록

모두 `static`, `tdc_` 접두어, 상태는 비-const 포인터로 전달(02 근거). 호출 순서는 원본 그대로 유지.

| 함수 | 시그니처 | 역할 |
|---|---|---|
| `tdc_touch_sleep_log_debug` | `static void (bool ok, const tdc_touch_iqs323_status_t *st, tdc_touch_state_t state)` | 계측 로그(`#if TDC_TOUCH_DEBUG_PRINT_ENABLE` 내부에 전부 캡슐화, `dbg`/`delta`/`abs_thr`/`pabs_thr`는 이 함수 자신의 최상단 지역변수) |
| `tdc_touch_sleep_handle_ati_error` | `static void (bool ok, const tdc_touch_iqs323_status_t *st, int *ati_error_reboot_cnt)` | ATI 에러 복구/재부팅 판단 |
| `tdc_touch_sleep_handle_notouch_gate` | `static void (bool ok, tdc_touch_state_t state, bool *sleep_ignore, int *notouch_cnt, int *ignore_elapsed)` | sleep_ignore 게이트 유지·해제·강제 RESEED |
| `tdc_touch_sleep_handle_touch_reboot` | `static void (bool ok, tdc_touch_state_t state, int *touch_cnt)` | 게이트 해제 후 터치 재부팅 판단 |
| `tdc_touch_sleep_log_state_transition` | `static void (bool ok, tdc_touch_state_t state, tdc_touch_state_t *ulp_state_prev)` | 상태 천이 verbose 로그 |

`sleep_ignore`에 따른 `if/else` 분기 자체는 `func_sleep()`에 남겨 상태 배타성을 호출부에서 드러낸다(02).

## ② 변수 재배치 최종안

`func_sleep()` 최상단(선언만, 값 없는 것은 미초기화 유지):

```c
int ret;

/* 루프 진입 전 1회 초기화 — 영속 상태 (매 iteration 재초기화 아님, 주의) */
bool              sleep_ignore         = true;
int               notouch_cnt          = 0;
int               ignore_elapsed       = 0;
int               touch_cnt            = 0;
tdc_touch_state_t ulp_state_prev       = TDC_TOUCH_STATE_RESET;
int               ati_error_reboot_cnt = 0;

/* 매 iteration 갱신 — 여러 헬퍼가 공유하므로 func_sleep() 소유 유지 */
tdc_touch_iqs323_status_t st;
bool                      ok;
tdc_touch_state_t         state;
```

`dbg`/`delta`/`abs_thr`/`pabs_thr`는 `tdc_touch_sleep_log_debug()` 내부(자신의 함수 최상단, `#if` 게이트 안)로 이관 — 01의 "게이트를 선언까지 확장" 채택. `ok` 게이트가 `state`/`st` 소비부 3곳 전부를 보호하므로 stale 값 이슈 없음(01 확인 완료).

## ③ ci_print 최종 매핑표

| 메시지 | 현재 | 변경 |
|---|---|---|
| CM3 IS PREPARING TO ENTER SLEEP MODE | printi | printd |
| FIRST OF ALL, TRY TO POWER OFF FPGA BACKTRL H/W | printi | **삭제**(50행 결과 출력과 중복) |
| FPGA reset : %s | printi | printd |
| CFX : sleep | printi | printd |
| LTA=... 계측 | printd | printd(유지) |
| ATI ERROR -> REBOOT (recover in normal) | printw | printw(유지) |
| ATI ERROR -> RECOVER (in sleep) | printw | **printd**(재시도 중, 최종 아님) |
| notouch confirmed -> RESEED | printi | printd |
| notouch timeout 10s -> forced RESEED | printw | printd(비치명 자동복구) |
| touch detected -> REBOOT | printi | **printw**(재부팅 직전, 최종 상태) |
| ULP STATE 천이 | printv | printd |

결과: `printw` 2건(ATI REBOOT, touch REBOOT — 둘 다 직후 `SYS_WATCHDOG_RESET()`), 나머지 전부 `printd`, `printi`/`printv`/`printe` 0건.

## ④ 주석 방침

04 판정 그대로 채택: 삭제 8건(53·55·56·57·58·60·142·47-48행 1행) + 중복 1건(84행), 정리 대상 죽은 코드 3건(76·79·147-148행)은 이번 순수 구조정리 범위에서 **함께 제거**(존치 근거 없음), 핵심 WHY 3대장(90-94 게이트 철학, 105 워치독 순서, 126-127 ATI 예외조건)은 절대 보존. 63·174행은 축약 유지.

## ⑤ 최종 구조 개요

```
func_sleep() {
  진입부(1037~1099, 구조 변경 없음, 변수만 최상단)
  while(1) {  // ULP loop
    SYS_WAIT_FOR_INTERRUPT; SYS_WATCHDOG_REFRESH();
    ok = tdc_touch_iqs323_read_status(&st); state = ...;
    tdc_touch_sleep_log_debug(ok, &st, state);
    tdc_touch_sleep_handle_ati_error(ok, &st, &ati_error_reboot_cnt);
    if (sleep_ignore) tdc_touch_sleep_handle_notouch_gate(ok, state, &sleep_ignore, &notouch_cnt, &ignore_elapsed);
    else               tdc_touch_sleep_handle_touch_reboot(ok, state, &touch_cnt);
    tdc_touch_sleep_log_state_transition(ok, state, &ulp_state_prev);
  }
  return 0;
}
```

## ⑥ 구현 순서

1. 5개 정적 함수 선언·본문 이식(원본 로직 문자 그대로 복사, 리네이밍만)
2. `func_sleep()` 변수 최상단 재배치
3. 루프 바디를 호출 시퀀스로 교체
4. ci_print 레벨 표 일괄 적용 + 중복 메시지 삭제
5. 주석 정리(삭제/축약) 적용
6. 컴파일 확인(미사용 변수·경고 0건) → 21/22 검증 페르소나 이관

## ⑦ 회귀 위험과 완화책

| 위험 | 완화책 |
|---|---|
| 영속 상태 6종을 루프 바디 안으로 잘못 이동(매회 재초기화) | ①/②에 "루프 진입 전 1회"임을 주석·선언 위치로 명시, 21이 재확인 |
| 헬퍼 함수 추출 중 `ok` 게이트 누락 | 원본 조건식 그대로 복사, 21이 조건식 diff 대조 |
| `SYS_WATCHDOG_REFRESH()`/`RESET()` 순서·위치 변경 | 헬퍼 이식 시 delay_ms/refresh/reset 시퀀스 라인 순서 불변 확인 |
| dbg 게이트 변수 이관 시 `#if` 경계 오류로 릴리즈 빌드 컴파일 실패 | `tdc_touch_sleep_log_debug()` 전체를 게이트 안에 두거나 게이트 비활성 시 빈 함수로 남겨 컴파일 확인 |
| printw→printd 격하(ATI RECOVER)로 실제 운영 로그 가시성 저하 우려 | 순수 표시 레벨 변경이며 로직 미변경임을 확인, RTT 필터 레벨 조정은 별도 이슈 |
| 메시지 삭제(중복 1건)로 필드 로그 분석 시 정보 손실 | 삭제 대상은 직후 줄에 결과가 재출력되는 순수 중복만 한정 |
