## 완료 요약

**기간**: 2026-07-02(당일) · **커밋**: 미진행(사용자 확인 후 커밋 예정)

**무엇을 했는가**: `main.c`의 `func_sleep()`을 순수 구조정리(동작 100% 동일 유지)로 리팩토링. ULP while 루프 바디를 5개 `static tdc_` 함수로 분리(상태는 포인터 전달, 함수 소유는 `func_sleep()` 유지), 전 지역변수를 함수 최상단으로 재배치, `ci_print` 레벨을 printw(칩 리셋 유발 최종 이벤트 2건)/printd(그 외 전부) 2단으로 통일, 주석 30여 건 중 21건 유지·9건 삭제·2건 축약. 진입부는 요구사항·회귀위험 근거로 함수 분리 대상에서 제외.

**핵심 결정**: 페르소나 8노드(Workflow, 분석5·계획1·검증2) fan-out. adversarial 검증에서 실질 로직 버그 0건, 문서 완결성 이슈 7건(else 리셋분기 명시 등) 발견 → 전부 최종 계획.md에 반영 후 구현.

**후속(실측 게이트)**: 은수님 Eclipse 빌드 + 실기 확인 — ① 절전 진입/ULP 루프 동작이 리팩토링 전과 동일한지 ② 컴파일 경고 0건(특히 `TDC_TOUCH_DEBUG_PRINT_ENABLE=0` 빌드) ③ RTT 로그 레벨(printw 2건만) 실측 확인.

**라운드 2 추가 결정 필요**: `i2c_set_master_prescale(I2C_MASTER_PRESCALE_6 ...)` — 절전 중 실제 SCL이 주석 의도(122kHz)와 달리 426.7kHz로 설정되고 있음을 발견(코드는 미변경, `[FIXME]` 주석만 추가). `I2C_MASTER_PRESCALE_21`로 되돌릴지, 현재 `_6` 값을 의도적으로 유지할지 은수님 판단 필요.
