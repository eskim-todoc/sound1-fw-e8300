# 요구사항 — 터치 임계·히스테리시스 파일 영속화

**TL;DR**: 터치센서(IQS323)의 touch threshold·hysteresis 값을 파일(NVM 파일시스템)에 저장하고, 부팅 시 `Initialize()`에서 읽어 적용한다. 저장 방식은 기존 설정 영속화 레퍼런스인 `ci_stim_mute.c`를 토대로 설계한다. **BLE 쓰기 명령(파일 값 갱신)은 이번 범위 밖** — 추후 general debug handle(option)로 구현 예정.

## 배경

현재 터치 임계값(threshold)·히스테리시스(hysteresis)는 펌웨어에 하드코딩되어 있다(예: `public_touch_settings(255, TDC_TOUCH_IQS323_HYSTERESIS)`). 이를 파일로 영속화하면 재빌드·재플래싱 없이 값을 조정할 수 있고, 무선(BLE)으로 현장에서 튜닝하는 길이 열린다. 대표 설정 영속화 패턴인 `ci_stim_mute.c`가 존재하므로 이를 레퍼런스로 삼는다.

## 요구사항 목록

- **요구사항_1**: 터치 threshold·hysteresis 값을 NVM 파일시스템의 파일에 저장하는 저장/로드 API를 신설한다 (`tdc_` 접두어).
- **요구사항_2**: 부팅 시 `Initialize()`에서 파일을 읽어 threshold·hysteresis를 적용한다. 파일이 없거나 손상 시 **기본값(현재 하드코딩 값)** 으로 안전하게 fallback한다.
- **요구사항_3**: 저장 포맷·파일명·무결성 검증(있다면)·기본값 처리 방식은 `ci_stim_mute.c`의 관례를 따르되, 터치 도메인에 맞게 설계한다.
- **요구사항_4**: 적용 지점은 기존 터치 설정 경로(`public_touch_settings` / `tdc_touch_iqs323` 계열)와 정합되게 연결한다.
- **요구사항_5**: 신규 심볼·모듈은 `tdc_` 접두어, 기존 tdc_ 파일 컨벤션(snake_case·Allman·한글 주석) 준수.

## 비범위 (Out of scope)

- **BLE(무선 프로토콜) 파일 값 쓰기 명령은 구현하지 않는다.** 아직 무선 프로토콜 명령이 없으며, 추후 `tdc_remote_general_debug` handle의 새 option으로 별도 구현 예정. 본 작업은 **파일 저장/로드 인프라 + 부팅 로드 적용**까지만.
- 값 쓰기 트리거(언제 파일에 쓸지)의 무선 경로는 설계에서 "확장 지점"으로만 표시하고 구현하지 않는다.
