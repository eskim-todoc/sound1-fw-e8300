# 분석 — 현황 및 설계 기반

**TL;DR**: 5페르소나 병렬 조사로 ci_stim_mute 영속화 패턴, FS wrapper 계층, 터치 threshold/hysteresis 세팅 경로, Initialize 흐름, 무결성 관례를 규명했다. 핵심 발견: 터치 값은 `#define` 컴파일 상수이고 실제 적용은 `Initialize()` **밖에서 비동기**(auto-ATI 후)로 일어난다. 따라서 "매크로 → 런타임 변수 전환 + 파일 로드로 변수 세팅 + apply_settings가 변수 참조" 구조가 필요하다.

## 1. ci_stim_mute 영속화 패턴 (레퍼런스 뼈대)

- 위치: `Gen1_5/FS/ci_stim_mute.c/.h`. 공개 API: `int ci_stim_mute_init(void)`(부팅 로드), `int ci_stim_mute_update(uint32_t enable, uint32_t level)`(런타임 갱신).
- 저장 포맷: 고정 크기 구조체 raw R/W.
  ```c
  typedef struct {
      uint32_t file_ident_begin;   // 매직 0x12345678
      uint32_t is_enabled_...;      // 값
      uint32_t mute_..._offset;     // 값 (0~255)
      uint32_t file_ident_end;      // 매직 0x87654321
  } CI_STIM_MUTE_T;                 // 16바이트
  ```
- 무결성: **매직넘버 2개(begin/end) + 길이 검사 + 값 범위 검사**. CRC/버전 없음.
- 파일명: `#define CI_STIM_MUTE_FILE_NAME "STIM_MUTE.TXT"` (8.3, 사용자 드라이브 `"1:"`).
- I/O: FatFs 저수준 직접 호출(`f_open FA_OPEN_ALWAYS|FA_READ|FA_WRITE` → `f_lseek(4096)`→`f_lseek(0)` 4KB 확보 트릭 → `f_read`/`f_write` → `f_sync` → `f_close`), 전역 핸들 `g_ci_filesystem_ohdl` 공유. 사이사이 `SYS_WATCHDOG_REFRESH()`.
- fallback: 파일 없음/크기불일치/매직불일치/범위초과 중 하나라도 → `is_validated_file=false` → 구조체 전체를 **기본값으로 리셋 후 즉시 파일 재기록**(all-or-nothing, clamp 없음). 기본값은 매크로 상수.
- 상태: 자체 static 캐시 없음. 성공 시 전역 공유메모리(`cfx_cm3_sharedMemoryAll`)에 반영. update 하나가 파일쓰기+캐시갱신 원자 처리.
- 갱신 호출: `remoteControl.c`의 BLE 커맨드 핸들러에서 `ci_stim_mute_update(...)`.

## 2. FS API 계층

- `Gen1_5/FS/` wrapper 계층이 FatFs를 감쌈. 신규 설정 파일엔 두 선택지:
  - **ci_stim_mute처럼 FatFs 저수준 직접**(단일 구조체+매직넘버 패턴에 최적) ← 권장
  - `ci_filesystem_read/write(char*, uint8_t*, int)` 범용 wrapper(CRC/AES 없는 단순 버전)
- 마운트: `initialize.c:315 snd_fatfs_remount(1)` 이후 사용자 드라이브 완전 가용.
- NVM 관례: 4KB 확보 트릭·`f_sync` flush·watchdog refresh는 전 파일 공통. wear-leveling은 하위 NVM 드라이버(저장소 밖) 위임 — 앱 레이어엔 쓰기 제한 없음. **빈번한 쓰기 대비 "값이 실제 바뀔 때만 write" 가드 권장**.

## 3. 터치 threshold/hysteresis 세팅 경로·값

| 항목 | 값 |
|---|---|
| threshold | `uint8_t` 0~255, 기본 **80** (`TDC_TOUCH_IQS323_THRESHOLD`, tdc_touch_iqs323.h) |
| hysteresis | 실질 4비트 0~15, 기본 **8** (`TDC_TOUCH_IQS323_HYSTERESIS`) |
| 적용 함수 | `static touch_settings(thr, hys)` → `REG_CH0_TOUCH(0x62)`에 LSB=thr, MSB=(hys&0x0F)<<4 |
| 공개 진입점 | `public_touch_settings(uint8_t, uint8_t)` (static과 동일 body 복제) |
| 적용 지점 | 부팅: `apply_settings()` 내 `touch_settings(80,8)` (tdc_touch_iqs323.c:416) / 절전: `main.c:850 public_touch_settings(255,8)` |

- **값은 현재 `#define` 컴파일 상수** → 파일값 반영하려면 런타임 변수화 필요.
- ⚠️ **설계 이슈(절전 오버라이드)**: `main.c:850`(fake_func_sleep)이 절전 진입 시 threshold=255로 덮어씀. 주석은 "절전 전용 설정 제거됨"이라는데 코드는 잔존(불일치). 파일 기반 설정과 충돌 소지 → 본 작업 범위(부팅 로드) 밖이나 계획에서 처리 방침 명시 필요.

## 4. Initialize 흐름·삽입 지점

순서: `(a) FS 마운트 315` → `(c) 설정로드 클러스터 333(ci_stim_mute_init)~336(event_log)` → `(b) 터치 init 시작 448(tdc_touch_init_begin=MCLR만)` → **[Initialize 리턴]** → 터치 값 실제 적용(`apply_settings`, main loop 비동기, ~1.5s 후).

- **로드 삽입 후보**: A) `ci_stim_mute_init()` 직후(333, 설정 클러스터 응집) / B) `tdc_touch_init_begin()` 직전(448, 터치 서브시스템 응집).
- 두 후보 모두 시간적으로 안전(실제 적용이 훨씬 뒤 비동기). B가 "터치 설정 로드→터치 init" 의도를 코드로 더 명확히 드러냄.
- 핵심: Initialize의 로드 함수는 **값을 런타임 변수에 준비**만, 레지스터 쓰기는 `apply_settings`가 그 변수를 참조.

## 5. 무결성·기본값·fallback 관례

- 관례 2종: ci_stim_mute(소형 스칼라) = 매직넘버+범위검사 / ci_map(대형 민감 데이터) = CRC16-CCITT+AES128. **터치 설정은 소형 스칼라라 ci_stim_mute 방식이 관례 정합**.
- 기본값: 매크로 상수로 헤더 상단 정의(ci_stim_mute 방식이 ci_map의 리터럴 하드코딩보다 우수). 터치는 기존 `TDC_TOUCH_IQS323_THRESHOLD/HYSTERESIS`를 fallback 기본값으로 재사용하면 하드웨어 안전마진과 일치.
- 처리: all-or-nothing 리셋 + 즉시 파일 실체화. clamp/재시도 선례 없음.
- ⚠️ **ci_stim_mute 결함(반면교사)**: `f_open` 완전 실패 시 공유메모리에 기본값을 안 넣고 `-1` 반환 → 극단 상황서 값 미정의 gap. 호출부(initialize.c)도 반환값 미검사. **신규 코드는 어떤 실패 경로에서도 런타임 변수를 기본값으로 세팅한 뒤 반환하도록 보완**.

## 종합 결론 (설계 입력)

1. **신규 모듈**: `ci_stim_mute` 복제 기반의 터치 설정 파일 모듈(init + update). update는 파일 저장 인프라만 만들고 BLE 트리거는 이번 범위 밖.
2. **저장 포맷**: `{ ident_begin, threshold, hysteresis, ident_end }` 구조체, 매직넘버+범위검사.
3. **아키텍처 핵심**: `#define THRESHOLD/HYSTERESIS` → 런타임 변수(setter/getter)로 전환, `apply_settings`가 변수 참조. 파일 로드가 변수 세팅.
4. **삽입**: Initialize 315~448 사이(후보 B: 448 직전 권장).
5. **fallback**: 모든 실패 경로에서 기본값(80/8) 변수 세팅 보장(ci_stim_mute gap 보완).
6. **범위 밖**: BLE 쓰기 트리거, 절전 threshold=255 오버라이드 재설계.
