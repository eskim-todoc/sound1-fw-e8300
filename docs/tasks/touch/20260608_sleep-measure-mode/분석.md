> **TL;DR**: func_normal RTT 폴링(594-635라인)에서 's' 감지 → 플래그 → while 탈출 → func_sleep 호출. func_sleep은 736라인(i2c prescale 직후)에서 측정 루프 분기.

## 코드 구조 분석

### func_normal() — main.c:316-678

| 항목 | 위치 | 내용 |
|---|---|---|
| while(1) | 363-675 | 메인 폴링 루프 |
| RTT 폴링 | 594-635 | `do { SEGGER_RTT_Read } while(false)` — `#else`(ENABLE_UI_CMD 비활성) 경로 |
| sleep 탈출 | 670 | `systemState.systemOff == true` + map/pair/ota 미활성 → `break` |
| WFI | 674 | `SYS_WAIT_FOR_INTERRUPT` |

**'s' 키 처리 설계**:
- RTT poll do-while(false) 내부에서 `s_sleep_measure_mode = true` 설정
- do-while 탈출 후, SYS_WFI 직전(673라인)에 `if (s_sleep_measure_mode) { break; }` 추가
- break → func_normal 리턴 0 → 메인루프가 func_sleep() 호출

### func_sleep() — main.c:694-770

| 항목 | 위치 | 내용 |
|---|---|---|
| 주변장치 OFF | 704-720 | FPGA·NRF·QCC·PMIC·LED 순차 종료 |
| ci_power_sleep() | 735 | SYSCLK 30.72M → 2.56M (12배 감속) |
| I2C prescale | 736 | `i2c_set_master_prescale(I2C_MASTER_PRESCALE_21)` — 저속 클럭 보정 |
| ULP 타이머 | 737-742 | WFI 주기 타이머 초기화 |
| while(1) | 744-767 | ULP 루프 — 매 WFI 후 터치 샘플링 |
| WFI | 746 | `SYS_WAIT_FOR_INTERRUPT` |

**측정 루프 삽입 위치**: 736라인(i2c prescale) 직후 → ULP 타이머 초기화(737) 이전
- 주변장치 OFF + 저클럭 환경 재현됨 (I2C 동작 보장)
- WFI 없이 CM3 활성 상태 유지 → RTT/I2C 사용 가능

### 클럭 감속 영향

`ci_power_sleep()` 후 `delay_ms()`는 NOP 기반이면 12배 느려짐. 측정 루프 간 추가 딜레이는 넣지 않고, `wait_re_ati_done()` 내부 완료 대기가 자연적 페이싱 역할을 한다. (ATI 완료에 수백 ms 소요 — 측정 도구 용도에서 타이밍 정밀도 불필요)
