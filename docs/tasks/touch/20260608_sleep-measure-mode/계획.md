## 변경_1 — tdc_touch_config.h

기존 마지막 플래그(TDC_TOUCH_ATI_CALIB_MODE) 블록 다음에 추가:

```c
/* 절전 모드 ATI 측정 모드 (개발용)
 *   0 = 비활성 (운용 모드, 기본값)
 *   1 = 활성 — RTT 's' 커맨드로 func_sleep 진입 후 ATI 덤프 반복 출력 */
#ifndef TDC_TOUCH_SLEEP_MEASURE_MODE
#define TDC_TOUCH_SLEEP_MEASURE_MODE 0
#endif
```

## 변경_3 — tdc_drv_iqs323.c

ATI_CALIB_MODE 함수 블록(`tdc_drv_iqs323_calib_re_ati` 끝, 약 704라인) 다음에 추가:

```c
#if TDC_TOUCH_SLEEP_MEASURE_MODE
void tdc_drv_iqs323_sleep_measure_dump(void)
{
    uint8_t lsb, msb;

    re_ati_trigger();
    wait_re_ati_done();

    ci_printi("[SLEEP-MEAS] ===========================\r\n");
    if (read_register(TDC_DRV_IQS323_REG_ADDR_SENSOR0_ATI_SETUP, &lsb, &msb))
        ci_printi("[SLEEP-MEAS] ATI_SETUP(0x36): LSB=0x%02X MSB=0x%02X\r\n", lsb, msb);
    if (read_register(TDC_DRV_IQS323_REG_ADDR_SENSOR0_ATI_MULT, &lsb, &msb))
        ci_printi("[SLEEP-MEAS] ATI_MULT (0x38): LSB=0x%02X MSB=0x%02X\r\n", lsb, msb);
    if (read_register(TDC_DRV_IQS323_REG_ADDR_SENSOR0_ATI_COMP, &lsb, &msb))
        ci_printi("[SLEEP-MEAS] ATI_COMP (0x39): LSB=0x%02X MSB=0x%02X\r\n", lsb, msb);
    ci_printi("[SLEEP-MEAS] ===========================\r\n");
}
#endif
```

## 변경_4 — main.c

### 4-A. 파일 스코프 플래그 (func_normal 직전)

```c
#if TDC_TOUCH_SLEEP_MEASURE_MODE
static bool s_sleep_measure_mode = false;
#endif
```

### 4-B. func_normal RTT 폴링 내부 (byte 처리 로직 끝부분)

기존 RTT poll do-while(false) 내, byte 처리 블록 맨 끝에 추가:

```c
#if TDC_TOUCH_SLEEP_MEASURE_MODE
                if (byte == 's')
                {
                    s_sleep_measure_mode = true;
                    ci_printi("[SLEEP-MEAS] Scheduled. Entering sleep...\r\n");
                }
#endif
```

### 4-C. func_normal while(1) 하단 (SYS_WATCHDOG_REFRESH 직전, 약 673라인)

```c
#if TDC_TOUCH_SLEEP_MEASURE_MODE
        if (s_sleep_measure_mode)
        {
            break;
        }
#endif
```

### 4-D. func_sleep() 내, i2c_set_master_prescale() 직후 (약 736라인)

```c
#if TDC_TOUCH_SLEEP_MEASURE_MODE
    if (s_sleep_measure_mode)
    {
        ci_printi("[SLEEP-MEAS] === Sleep Measure Mode ===\r\n");
        ci_printi("[SLEEP-MEAS] Peripherals OFF. RTT 'q' to reset.\r\n");
        while (1)
        {
            SYS_WATCHDOG_REFRESH();
            if (SEGGER_RTT_HasKey())
            {
                int key = SEGGER_RTT_GetKey();
                if (key == 'q')
                {
                    ci_printi("[SLEEP-MEAS] Reset.\r\n");
                    delay_ms(20);
                    SYS_WATCHDOG_RESET();
                }
            }
            tdc_drv_iqs323_sleep_measure_dump();
        }
    }
#endif
```

## 동작 흐름

```
부팅 → func_normal (정상)
          ↓ RTT 's' 입력
          s_sleep_measure_mode = true
          while 탈출 → func_sleep 호출
                          주변장치 OFF (FPGA·NRF·QCC·PMIC·LED)
                          ci_power_sleep() [SYSCLK 감속]
                          i2c prescale 보정
                          ↓ [SLEEP_MEASURE_MODE = 1]
                          [SLEEP-MEAS] 측정 루프:
                            WDT refresh
                            'q' 감지 시 WDT reset
                            re_ati_trigger → wait → RTT 출력
                            반복
```

## 회귀 위험 분석

| 위험 | 영향 | 완화 |
|---|---|---|
| `TDC_TOUCH_SLEEP_MEASURE_MODE 0` 빌드 | 없음 | `#if` 분리로 코드 자체가 컴파일 안 됨 |
| `s_sleep_measure_mode` 미초기화 | 없음 | `static bool` → 자동 0 초기화 |
| func_sleep 후 func_normal 복귀 불가 | 해당 없음 | 측정 종료는 WDT 리셋 설계 |
| wait_re_ati_done() 무한 블로킹 | IQS323 I2C 무응답 시 | 기존 함수 타임아웃 로직 그대로 활용 |
