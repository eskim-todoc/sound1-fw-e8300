> **TL;DR**: RTT 커맨드('s')로 func_sleep 진입, 내부 while 루프에서 IQS323 ATI 값을 반복 RTT 출력. LED 없음. 'q'로 WDT 리셋.

## 요구사항

| ID | 항목 | 내용 |
|---|---|---|
| 요구사항_1 | 진입 트리거 | RTT 단일 문자 `'s'` — func_normal 동작 중 언제든 입력 시 func_sleep 진입 |
| 요구사항_2 | 측정 위치 | func_sleep() while 루프 내부 — 주변장치(FPGA·NRF·QCC·PMIC) OFF 상태에서 반복 측정 |
| 요구사항_3 | 출력 채널 | RTT만 (LED 출력 없음) |
| 요구사항_4 | 측정 내용 | IQS323 ATI_SETUP(0x36)·ATI_MULT(0x38)·ATI_COMP(0x39) 레지스터 값 |
| 요구사항_5 | 측정 방식 | re-ATI 트리거 → 완료 대기 → 레지스터 읽기 → RTT 출력, 반복 |
| 요구사항_6 | 종료 방법 | RTT `'q'` 입력 → WDT 리셋 (재부팅) |
| 요구사항_7 | 빌드 플래그 | `TDC_TOUCH_SLEEP_MEASURE_MODE` (기본값 0) — 운용 코드 영향 없이 분리 |
| 요구사항_8 | 회귀 | 플래그 0 시 func_normal·func_sleep 기존 동작 완전 보존 |

## 배경

절전 모드 진입 시 주변장치가 꺼지며 정전 용량 환경이 변화한다. 이로 인해 터치 임계값 대비 정전 용량이 가까워져 스스로 터치가 인식되는 현상이 발생한다. 정상 동작 vs 절전 환경의 ATI 보상값(MULT/COMP) 차이를 직접 측정해 정량적 데이터를 수집한다.
