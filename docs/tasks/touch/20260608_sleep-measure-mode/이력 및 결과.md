## 완료 요약

- **신규 빌드 플래그**: `TDC_TOUCH_SLEEP_MEASURE_MODE` (기본값 0)
- **동작**: func_normal에서 RTT 's' 입력 → func_sleep 진입 → 주변장치 OFF + 저클럭 환경에서 re-ATI 반복 → ATI_SETUP/MULT/COMP RTT 출력 → 'q' 입력 시 WDT 리셋
- **수정 파일**: `tdc_touch_config.h`(플래그), `tdc_drv_iqs323.h`(선언), `tdc_drv_iqs323.c`(구현), `main.c`(include + 's' 핸들러 + func_sleep 측정 루프)
- **기존 운용 코드**: `#if` 완전 분리, 플래그 0 빌드 시 영향 없음

### 측정 결과 분석 요약 (`측정결과-분석.md`)

- **핵심 발견**: 절전 진입 시 COMP −996 하락 방향이 터치 방향과 동일 → LTA 고정 상태에서 false touch 유발
- **MULT_MSB 분포**: 절전 노터치=0x5C, 정상 노터치=0x5E, 터치(공통)=0x64
- **권장 ATI**: `MULT=0x5C82, COMP=0x6000` (Option A, 절전 노터치 기준) 또는 `MULT=0x6082, COMP=0x6000` (Option B, SNR 중간값)
