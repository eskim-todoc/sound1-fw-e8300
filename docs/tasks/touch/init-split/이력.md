# 터치 센서 초기화 분할 — 이력

작업 슬러그: `touch/init-split`
기간: ~2026-04-21 (사후 정리: 2026-05-07)
상태: **완료** (코드 적용 확인)

---

## 1. 결과 요약

부팅 시 IQS323 Auto-ATI 대기 (~1.5 s POR / ~165 ms 워치독 리셋) 를 POWER_ON LED 버스트와 **병렬 진행**하여 체감 부팅 시간을 최대 1.5 s 단축.

단일 호출 `tdc_iqs323_init()` (블로킹) 을 두 단계로 분리:

- **`tdc_touch_init_begin()`** — 1 회 호출. MCLR 리셋만 트리거 후 즉시 리턴 (논블로킹).
- **`tdc_touch_process()`** — 매 tick 호출. 초기화 미완 시 상태머신 진행 (Auto-ATI 폴링 → 설정 일괄 적용), 완료 후 폴링·롱터치 판정.

## 2. 변경 사항

### 2.1 적용 위치

| 항목 | 위치 |
|---|---|
| `tdc_touch_init_begin()` | [`tdc_touch.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.c) `tdc_touch_init_begin` |
| `tdc_touch_process()` | [`tdc_touch.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.c) `tdc_touch_process` |
| 초기화 상태머신 enum | `tdc_touch_init_state_t` (NONE / MCLR_DONE / READY) |
| 초기화 타임아웃 | `TDC_TOUCH_INIT_TIMEOUT_MS = 2500` (터치 누른 채 부팅 대비) |

### 2.2 UX 전제 (구현계획 §1.4)

3 s 롱터치 = 전원 OFF 트리거. 부팅 직후 0.5~1 s 터치 초기화 지연은 사용자 체감 영향 없음. POWER_ON LED 버스트 (1.5 s) 동안 롱터치 기능 불필요.
