# B02 — 물리 메커니즘 adversarial 검증자

> **TL;DR**: 은수님 M4의 "C51 때문에 IC 내부 드리프트가 주원인"이라는 추론은 인과 연결이 없다 — C51은 AC를 통과시키므로 드리프트와 무관. M5의 충전기 연결 복귀는 POR·VDD 안정화·SW Re-init 세 경로 모두 C51 논거와 독립적이어서 "DC블로킹이 패드 주원인 아님의 증거"라는 논리 점프가 성립하지 않는다. M6·M7의 기구 GND 쇼트 방전은 물리적으로 가능하나 SW LTA 고착은 해소 불가이므로 주원인 판단은 SW 드리프트 지배 가정 하에 조건부 수용. 이전 분석 "SW 드리프트(주) + 물리 누적(부) 가산 모델"과의 정합성은 전반적으로 유지된다.

## 1. 검증 대상 명제

| 명제 | 내용 |
|---|---|
| M4 | DC 블로킹 캡(C51 100pF) 때문에 터치패드보다 IC 내부 드리프트가 주원인 예상 |
| M5 | 먹통 상태 + 충전기 연결 → 터치 복귀 (DC 블로킹 캡 있어 터치패드 주원인 아님) |
| M6 | 기구 GND 쇼트 → 터치패드 방전 가능성 있으나 주요 원인 아님 |
| M7 | (M6 재확인: 기구 GND 쇼트가 주요 원인 아님) |

## 2. 회로 전제 확인

분석 전 회로 토폴로지를 명확히 한다.

```
CRX0 (B2) ── R31(100Ω) ── C51(100pF) ── J3 ── 터치 전극 패드
```

- VDD: 1.8V_QCC, R28(0Ω) 점퍼 (전원 경로 무필터), C54(4.7µF) + C55(100pF) 디커플링
- C51: CRX0(IC 핀 측)과 J3(전극 측) 사이에 직렬 삽입된 100pF 커패시터
- 현재 방전 코드: 레지스터 0x30에 0x02 기록 (이전 분석: Linearise 가능성, VSS 아닐 수 있음)
- CRX1: C52(100nF) → J4, SW상 CalCap

## 3. M4 adversarial 검증 — "C51 때문에 IC 내부 드리프트가 주원인"

### 3.1 은수님 추론의 구조

은수님 M4의 추론 구조를 재구성하면:

1. C51이 DC를 차단한다
2. 따라서 전극(터치패드) 측과 IC 측이 DC적으로 분리된다
3. 그러므로 전극 측 물리 변화가 IC 내부 drrift에 영향을 주기 어렵다
4. **결론: IC 내부 드리프트가 전극보다 주원인**

### 3.2 추론 반론 — 인과 사슬 비약 점검

**반론_1: C51의 AC 투과성 — self-cap 측정은 AC 메커니즘**

IQS323 self-cap 측정은 CRX0 핀에서 전하를 충방전(AC 전하 전달)하여 정전용량을 적산하는 방식이다. C51이 직렬에 있더라도 AC 전하 이동은 통과한다.

$$Z_{C51} = \frac{1}{2\pi f \cdot C_{51}} = \frac{1}{2\pi \times 1\text{MHz} \times 100\text{pF}} \approx 1.59\ \text{k}\Omega$$

이는 높은 임피던스이지만 "완전 차단"이 아니며, 측정 동작 자체를 방해하지 않는다. 직렬 합성 정전용량:

$$C_{meas} = \frac{C_{51} \times C_{touch}}{C_{51} + C_{touch}}$$

Ctouch ≈ 2~10pF, C51 = 100pF이면 C51 >> Ctouch이므로 Cmeas ≈ Ctouch (측정값의 98% 이상이 전극 정전용량으로 결정). **C51은 측정을 가능하게 하며 측정값은 여전히 전극 변화를 반영한다.**

**반론_2: C51이 IC 내부 드리프트와 연관되는 직접 경로가 없음**

C51의 역할은 J3 전극과 CRX0 핀을 DC적으로 분리하는 것이다. IC 내부 드리프트의 물리적 원인(온도 변화에 따른 내부 기준전압 이동, 내부 샘플링 커패시터의 dielectric absorption, 공급전압 변동)은 C51의 존재와 무관하게 발생한다.

**C51 DC차단 → IC 내부 드리프트 증가**라는 직접 인과 경로는 없다.

**반론_3: IC 내부 드리프트의 실제 원인은 ATI 보정 부재**

Self-cap 드리프트의 주요 물리 원인:

| 드리프트 원인 | 메커니즘 | C51과의 관계 |
|---|---|---|
| 온도 변화 | IC 내부 Vref 온도 계수, 내부 캐패시터 온도 계수 | 무관 |
| 내부 ADC 누설 | 샘플링·적산 커패시터의 dielectric absorption | 무관 |
| 전압 변동 | VDD 변동 → 내부 기준 이동 | 무관 |
| 전극 환경 변화 | 습기·오염·손 근접 → Ctouch 변화 | C51 통과(AC)로 측정됨 |
| **ATI 보정 부재(주)** | FIXED MULT/COMP → LTA가 자동 추적 없음 | 무관 |

FIXED MULT/COMP 사용 시, 이 모든 드리프트가 누적되어 LTA 기준에서 벗어나도 **자동 재보정이 없다.** 이것이 드리프트 먹통의 주원인이며, C51과 인과 관계가 없다.

### 3.3 M4 판정

| 부분 명제 | 판정 | 근거 |
|---|---|---|
| C51이 DC를 차단한다 | ✅ 사실 | 소자 특성 그대로 |
| C51이 전극과 IC를 DC 분리한다 | ✅ 사실 | 회로 토폴로지 |
| **"C51 때문에" IC 내부 드리프트가 주원인** | ❌ 인과 비약 | C51이 IC 내부 드리프트를 유발하는 메커니즘 없음 |
| "터치패드보다 IC 내부 드리프트가 주원인" (결론) | △ 조건부 수용 | ATI 보정 부재가 진짜 주원인. 결론 방향은 맞으나 이유(C51 때문)가 틀림 |

> [!WARNING]
> **C51은 이유가 아니다.** "IC 내부 드리프트가 주원인"이라는 결론은 이전 분석과 일치하지만, 그 이유는 "FIXED MULT/COMP로 ATI 보정이 없기 때문"이지 C51의 DC차단 때문이 아니다. 이유와 결론을 분리해야 한다.

### 3.4 C51의 실제 역할 — IQS323 데이터시트 관점

IQS323 데이터시트 Fig 2.3(self-cap 슬라이더 레퍼런스)에서 CRX 핀에 직렬 커패시터(C6 100pF)를 사용하는 구성이 표준으로 등장한다. C51은 **비표준 이상 징후가 아니라 표준 self-cap 구성**이다. 이전 분석(J3 전하누적 가설 평결)에서 이 오류가 이미 정정되었다.

## 4. M5 adversarial 검증 — "충전기 연결 → 터치 복귀"의 물리 메커니즘

### 4.1 관측 사실과 은수님 추론

관측: 먹통 상태에서 충전기 연결 → 터치 복귀

은수님 추론:
1. C51이 있어 전극과 IC가 DC 분리됨
2. 충전기 연결로 GND 경로가 생겨도 전극의 전하가 IC 쪽으로 방전될 수 없음
3. 따라서 전극(터치패드)의 물리 전하 누적이 원인이 아니다
4. **결론: IC 내부가 주원인**

### 4.2 충전기 연결 시 발생 가능한 물리 메커니즘 전수 열거

**메커니즘_1: VDD 리플 → POR(Power-On Reset)**

충전기 연결 시 1.8V_QCC 전원 라인에 과도 전압/노이즈가 인가될 수 있다.

- R28이 0Ω(페라이트 비드 없음)이라 전원 경로 무필터
- VDD 디커플링: C54(4.7µF) + C55(100pF)만으로 µs급 과도 흡수
- 데이터시트 §4.1 기준: 전원 레벨이 power-down 임계(~0.9V) 이하로 순간 떨어졌다 복귀하면 POR 발생
- POR 후 IC 전체 초기화 → ATI 재실행 → baseline 재보정 → 터치 복귀

**가능성: 높음.** R28 0Ω 무필터 구조에서 충전기 연결 과도가 VDD에 직접 전달된다.

**메커니즘_2: I²C SW Re-initialization**

충전기 연결 이벤트를 E8300가 감지하여 터치 IC를 SW로 재초기화하는 루틴이 존재할 경우.

**가능성: 조건부.** SW 코드에 charger detection → touch reinit 경로가 있는지 여부에 따라 다름. 현재 코드 확인 필요.

**메커니즘_3: VDD 안정화 → IC 내부 재안정화**

배터리 전압이 충전으로 안정화되며 1.8V_QCC → VDD가 안정화되고 IC 내부 ADC 기준전압이 재안정화.

**가능성: 낮음.** 이 경우 점진적 회복이 예상되며, 즉각 복귀와 정합하지 않음.

**메커니즘_4: GND 경로 변화 → 전극 방전 (C51 경유)**

충전기 연결로 시스템 GND가 강화되고, 기구물을 통한 전극-GND 경로가 생성될 경우.

이 경로의 물리:
- J3 전극 패드 → 기구물 GND 접촉 → GND
- 전극이 GND에 연결되면 C51 양단 전압 불균형 발생
- C51을 통해 CRX0 핀(B2) 측 전하가 방전: τ = R31 × C51 = 100Ω × 100pF = **10ns** — 매우 빠른 방전

**가능성: 중간.** 기구물 GND 접촉 여부에 따라 다름. 단, 은수님 M6에서 "기구 GND 쇼트는 주원인 아님"이라 했으므로 이 경로도 주효과가 아닐 것.

### 4.3 은수님 추론의 논리 구조 검증

은수님 추론: "충전기 연결로 복귀 + C51 DC차단 → 전극 물리 전하가 주원인 아님"

**반론: 이 추론에 논리 점프가 있다**

메커니즘_1(POR)이 실제 원인이라면:
- POR은 IC 내부를 완전 초기화한다
- 전극 물리 전하 누적이 원인이었어도 POR 후 ATI 재실행으로 해소된다
- 전극 물리 전하 누적이 원인이 아니었어도 역시 POR로 해소된다
- **즉, 충전기 연결로 복귀했다는 사실만으로는 전극 물리 전하가 주원인인지 아닌지를 판별할 수 없다.**

"충전기 연결 → POR → 복귀"가 맞다면, C51의 DC차단 여부와 무관하게 어떤 원인의 먹통도 해소될 수 있다. C51이 증거가 되려면 "C51을 단락해도 충전기 연결 시 여전히 복귀한다" 실험이 필요하다.

### 4.4 M5 판정

| 부분 명제 | 판정 | 근거 |
|---|---|---|
| 충전기 연결 → 터치 복귀 관측 | ✅ 사실 (은수님 관측) | |
| POR이 가장 유력한 메커니즘 | ✅ 지지 | R28 0Ω 무필터 + 데이터시트 §4.1 기준 |
| GND 경로 변화 가능성 | △ 중간 가능성 | 기구물 설계 의존 |
| **"C51이 있어 전극이 주원인 아님"의 논리** | ❌ 논리 점프 | POR로도 동일 설명 가능 → C51이 판별 증거 안 됨 |
| 결론 방향 (IC 내부 우세) | △ 간접 지지 | POR 주 메커니즘이면 IC 내부 드리프트 지배 해석은 간접 지지 |

> [!IMPORTANT]
> **M5의 관측은 맞다. 그러나 "C51 때문에 전극이 주원인 아님"의 논거는 성립하지 않는다.** 충전기 연결 복귀는 POR에 의해 어떤 원인의 먹통도 해소될 수 있어서 전극 기원과 IC 기원을 판별하지 못한다. M5는 현상 관측으로서 가치가 있으나, "C51 논거로 전극을 배제"하는 추론 사슬은 오류다.

## 5. M6·M7 adversarial 검증 — 기구 GND 쇼트 방전 가능성

### 5.1 "기구 GND 쇼트"의 물리 모델

기구 GND 쇼트: 터치 전극 패드(J3 측)를 제품 케이스의 도전성 부품(금속 케이스·나사·GND 연결 구조물 등)에 접촉시켜 GND에 연결하는 행위.

**시나리오_A: J3 측 전극 → 기구물 GND 직접 쇼트**

```
기구물(GND) ── 전극 패드(J3 측) ── C51 ── R31 ── CRX0(B2)
```

전극이 강제로 0V가 되면:
- C51 양단 전압: V(B2측) - V(J3측) = V(B2측) - 0 = V(B2측)
- C51이 방전 경로: B2측 전하 → C51 → J3측(GND) 방향으로 방전
- 방전 시정수: τ = R31 × C51 = 100Ω × 100pF = **10ns**

**물리적으로 가능하다. 10ns 내에 C51 양단 전압 평형 → B2 핀 근방 전하 해소.**

**시나리오_B: IC 내부 LTA 고착은 방전으로 해소 불가**

그러나 SW 드리프트(LTA 고착)는 레지스터 값이다. 전극의 물리 전하를 GND로 방전해도 LTA 레지스터는 변하지 않는다. **LTA 고착 해소는 IC 리셋(POR or SW) 또는 ATI 재실행이 필요하다.**

### 5.2 M6·M7 "주요 원인 아님" 판단의 타당성 검증

은수님: "기구 GND 쇼트 → 방전 가능하나 주요 원인이 아님"

**반론: 이 판단의 논리가 역전될 수 있다**

> [!WARNING]
> **역전 논리**: 만약 기구 GND 쇼트로 먹통이 복귀했다면, 이는 **물리 전하 누적이 주원인**임을 시사한다 (SW LTA 고착은 쇼트로 해소 불가이므로). 반대로 GND 쇼트를 해도 복귀하지 않으면 SW 드리프트가 주원인. 은수님이 "가능성 있다"고 한 것은 GND 쇼트 복귀를 경험한 것처럼 보이는데, 그렇다면 오히려 물리 누적의 부차적 기여를 시사한다.

이전 분석(J3 전하누적 가설 평결)에서도 이 역전 논리를 지적했다:
- "GND 쇼트 복귀 = 물리 전하 누적 기여 시사"
- "어디서든(J3 직접 아닌 다른 경로) GND 쇼트로 복귀 = SW LTA 고착"

### 5.3 C51이 있는 경우 GND 쇼트의 실제 방전 경로

C51이 있을 때 전극을 GND에 쇼트하면:

1. J3측 전위: 강제 0V
2. B2(CRX0) 측 전위: IC 내부 회로에 의한 전위 (ATI 후 기준전위)
3. C51 양단 전압차 발생 → C51을 통해 방전 전류 흐름
4. 방전 완료 시 C51 양단 전압 = 새로운 평형
5. **B2 핀 주변의 전하 상태 변화 → IC가 "기준 변화"를 측정**

이후 IC가 이 변화를 어떻게 처리하는지는 IC 내부 로직에 달려 있다. 단순히 전극을 GND에 쇼트하는 것이 "터치 인식"이 될 수도 있고 (전극 정전용량 급증 → 터치 카운트 급증 → threshold 초과), 이것이 LTA 재기준화를 유발할 수 있다.

**물리 경로는 성립한다. 다만 이 과정이 SW 관점에서 "터치 복귀"로 보이는지는 IC 내부 처리에 달렸다.**

### 5.4 M6·M7 판정

| 부분 명제 | 판정 | 근거 |
|---|---|---|
| 기구 GND 쇼트 → 전극 방전 물리 가능 | ✅ 성립 | C51 통과 방전, τ≈10ns |
| B2(CRX0) 측 전하도 방전 가능 | ✅ 성립 | C51 양단 전압차로 방전 |
| GND 쇼트로 SW LTA 고착 해소 | ❌ 불가 | LTA는 레지스터 값, 물리 방전으로 변경 불가 |
| **"주요 원인 아님"** 판단 | △ 조건부 | SW 드리프트 지배 가정 시 성립. GND 쇼트 복귀 경험이 있다면 물리 누적 부차 기여 시사 |

## 6. C51 물리 누적과 SW 드리프트 가산 모델 정합성

### 6.1 이전 분석 가산 모델 요약

이전 분석(J3 전하누적 가설 평결):
- **SW 드리프트(주)**: FIXED MULT/COMP + ATI Disabled → LTA 자동보정 없음 → counts 드리프트 누적 → LTA 고착 (증거 높음)
- **C51 물리 누적(부)**: GND 쇼트 복귀가 물리 전하 제거 가능성 시사 (증거 낮음·미실측)
- **방전 무력 1차**: 방전 코드 0x30 0x02가 Linearise(VSS 아님)이어서 실제 방전이 안 됐을 가능성

### 6.2 은수님 M4~M7과 가산 모델 정합성

| 명제 | 가산 모델과의 정합 | 비고 |
|---|---|---|
| M4: IC 내부 드리프트 주원인 | ✅ 정합 (결론) | 이유(C51 때문)는 불정합 |
| M4: C51이 이유 | ❌ 불정합 | C51은 드리프트와 인과 없음 |
| M5: 충전기 복귀 | △ 부분 정합 | POR 기원이면 정합, C51 논거는 불정합 |
| M6·M7: GND 쇼트 가능하나 주원인 아님 | △ 조건부 정합 | SW 드리프트 지배 가정 시 정합 |

### 6.3 방전 코드 0x30 0x02 물리적 함의

이전 분석에서 "0x30 0x02 = Linearise(VSS 아닐 수 있음) → 실측 필요"라고 했다.

Linearise 모드라면:
- B2(CRX0) 핀이 GND(VSS)에 연결되지 않음
- 전극 방전은 물리적으로 이루어지지 않음
- IC 내부 ADC 적산 상태를 기준점으로 주기적 리셋하는 효과만 발생

이것이 실제로 "방전 유사 효과"를 냈다면, 그 의미는:
- 200ms 주기의 "IC 내부 기준 재설정"이 SW 드리프트를 주기적으로 억제
- 물리 전하 누적에 대한 효과는 없었다
- **즉 방전 코드가 실제로 Linearise라면, 기존 "방전" 효과는 SW 드리프트 억제이지 물리 방전이 아님**

이 경우 M4의 "IC 내부 드리프트 주원인"은 오히려 더 강하게 지지된다 — 물리 방전 없이도 (IC 내부 기준 재설정만으로) 증상이 완화됐다는 증거이기 때문이다.

> [!NOTE]
> **역설적 지지**: 방전 코드가 VSS 연결이 아닌 Linearise라면, 기존 "방전" 운영이 물리 전하를 건드리지 않고도 효과가 있었다는 의미다. 이는 **물리 누적보다 IC 내부 드리프트가 지배적**이라는 M4 결론 방향을 지지한다. 단 C51이 그 이유인 것과는 여전히 무관하다.

## 9. B02 최종 결론

> **C51(100pF)의 DC차단·AC통과 특성은 회로 토폴로지로 정확하나, "C51 때문에 IC 내부 드리프트가 주원인"이라는 인과 연결은 성립하지 않는다 — IC 내부 드리프트의 원인은 C51의 DC차단이 아니라 FIXED MULT/COMP로 인한 ATI 보정 부재다. M5의 충전기 연결 복귀는 POR이 가장 유력한 메커니즘이며, C51 DC차단이 "전극 주원인 아님의 증거"가 되는 논리 점프는 성립하지 않는다. M6·M7의 기구 GND 쇼트 방전은 C51을 통한 방전(τ≈10ns)으로 물리적으로 가능하나, SW LTA 고착은 물리 방전으로 해소 불가이므로 "주요 원인 아님"은 SW 드리프트 지배 가정 하에 조건부 수용이다. 이전 분석의 "SW 드리프트(주) + 물리 누적(부) 가산 모델"과 결론 방향은 정합하며, C51이 이유라는 연결고리만 제거하면 은수님의 직관("IC 내부 우세")은 유효하다.**
