# A04 — 신뢰성·품질 엔지니어 분석

> **TL;DR**: 은수님 M8("autoATI + Beta만으로 모든 문제 해결 가능")은 실측 미완 상태에서 내린 조기 결론이다. M4~M7은 대부분 추론이며, 인공와우 특성상 "손 안 떼는" 엣지 케이스와 온습도·진동 환경이 겹치면 자기정상화 구조가 무너질 위험이 있다. 안전망(노터치 게이트·I²C 통신관리) 없이 출하하면 현장 재현 불가 불량이 발생할 가능성이 높다.

---

## 1. M8 위험도 평가 — "autoATI + Beta만으로 모든 문제 해결 가능"

### 1-1. M8이 성립하는 전제 조건

M8이 실제로 모든 문제를 해결하려면 다음 전제가 **동시에** 성립해야 한다.

| 번호 | 전제 | 현재 검증 상태 |
|---|---|---|
| 전제_1 | 부팅 후 사용자가 반드시 손을 뗀다 | **가정만** — 인공와우 착용 특성상 보장 불가 |
| 전제_2 | 손 뗀 후 LTA 수렴 시간 내 재터치 없다 | **미실측** — 수렴 과도구간 시간 불명 |
| 전제_3 | LTA가 자기정상화 방향으로 단조 수렴한다 | **조건부** — 온도·습도 변화 시 droop 발산 가능 |
| 전제_4 | Beta 조정이 약터치를 흡수하지 않는다 | **미검증** — Fast Filter Band 비대칭 여부 불명 |
| 전제_5 | ATI Full 재활성 시 I²C 정상 작동 | **기지 위험** — 이전 분석에서 무응답 재현 이력 |
| 전제_6 | 드리프트 원인이 LTA 오염(SW)이지 물리누적(HW)이 아니다 | **미실측** — ESD 실체 미구분 |

**→ 전제 6개 중 현재 실측으로 확인된 것은 0개.** M8은 전제가 모두 성립할 때에만 옳다.

### 1-2. M8이 실패하는 조건별 분류

| 실패 조건 | 증상 | 심각도 |
|---|---|---|
| 부팅 후 손 안 떼는 경우 | LTA가 터치값에 영구 고착 → 이후 모든 터치 무반응 | 🔴 치명 |
| LTA 수렴 과도구간 중 재터치 | 터치 미인식(delta < threshold) → 사용자 반복 터치 → LTA 재오염 | 🟠 높음 |
| 온도 상승(귀 밀착·체온) → droop | LTA가 노터치 방향으로 과도 추적 → threshold 초과 → 오터치 | 🟠 높음 |
| Beta 단일 상향 시 약터치 흡수 | 약하게 또는 천천히 터치 시 LTA가 흡수 → 미인식 | 🟠 높음 |
| ATI Full I²C 무응답 | SDA stuck-low → MCU-IC 통신 단절 → 영구 먹통 | 🔴 치명 |
| ESD 물리누적(HW)이 주원인인 경우 | autoATI로 LTA 정규화해도 counts 오염 반복 → 주기적 먹통 | 🔴 치명 |
| 진동 환경(자전거·교통) 중 Re-ATI | 진동이 ATI 트리거 → 수렴 중 먹통 | 🟡 중간 |

## 2. 실측 여부 분류 — M4~M7은 실측인가 추론인가

| 명제 | 내용 | 실측/추론 | 근거 |
|---|---|---|---|
| **M4** | DC 블로킹 캡(C51 100pF) 때문에 터치패드보다 IC 내부 드리프트가 주원인 | **추론** | C51이 고주파 경로를 차단한다는 회로 원리에서 유도한 가설. 실칩에서 드리프트 원인을 IC vs 패드로 구분 측정한 데이터 없음 |
| **M5** | 먹통 + 충전기 연결 → 터치 복귀 (C51 덕분에 패드 주원인 아님) | **관찰 있으나 해석은 추론** | "터치가 복귀했다"는 현상은 실측. 그러나 복귀 원인(IC 내부 리셋? VDDHI 재공급? GND 경로 안정화?)은 실측 미분리. C51 역할 결론은 부차 추론 |
| **M6** | 기구 GND 쇼트 → 터치패드 방전 가능성 | **추론** | 기구가 GND 쇼트될 경우를 가정한 논리. 실제 기구 조건·쇼트 저항 측정 데이터 없음 |
| **M7** | 기구 GND 쇼트가 주요 원인 아님 | **추론(M6 기반)** | M6 추론 위에 쌓인 2차 추론. 실측 없는 배제 |

> [!WARNING]
> **M5의 "충전기 연결 → 복귀" 현상은 실측이지만 그 해석은 추론이다.** 이 복귀가 IC POR(전원재인가 리셋) 때문이라면 "드리프트 소멸" 현상이 아니라 "IC 재부팅"일 수 있어 드리프트 원인 분석 자체가 흔들린다.

## 3. 인공와우 사용 환경 엣지 케이스

인공와우(Cochlear Implant) 외부기는 일반 소비 전자와 다른 특수 사용 패턴을 가진다.

### 3-1. 착용 중 배터리·기기 교체

- **행동 패턴**: 사용자가 귀 뒤 기기를 손으로 쥔 채 분리 → 배터리 교체 → 재장착 후 즉시 손 놓음 또는 위치 잡기 위해 수 초간 파지 유지
- **위험**: 부팅(배터리 재삽입) 직후 손이 터치면에 닿은 채 수 초 유지 → M8 전제_1 위반 → LTA 영구 고착
- **심각도**: 🔴 치명 — 배터리 교체는 가장 빈번한 조작 중 하나

### 3-2. 케이스(건조함) 보관 후 착용

- **행동 패턴**: 야간 건조 케이스 보관 → 다음날 아침 꺼내 즉시 착용 → 귀에 부착하는 동작 중 터치면 접촉
- **위험**: 부팅 + 즉시 터치 접촉 → 동일 고착 위험. 게다가 건조 케이스 보관 중 온도·습도 변화가 누적된 상태에서 부팅
- **추가 위험**: 건조 케이스 내 정전기 환경 → ESD 누적 상태로 부팅 시 baseline 더 오염될 가능성

### 3-3. 진동 환경 (보행·교통·운동)

- **행동 패턴**: 착용 중 걷기, 버스·지하철 진동, 스포츠
- **위험**: 진동이 self-cap 전극에 기계적 변위 야기 → counts 미세 fluctuation → ATI Band 기준에 따라 자동 Re-ATI 트리거 가능 → 수렴 중 터치 무반응 구간 반복
- **M8 관련**: autoATI 상시 활성 시 진동 환경에서 Re-ATI 빈도 증가 → 단발성이 아닌 반복 먹통
- **심각도**: 🟠 높음 (인공와우 사용자의 활동성 제약이 다양함)

### 3-4. 귀 밀착으로 인한 체온 전달

- **온도 영향**: 귀 후면 피부온도 약 34~36°C가 IC에 전달 → 온도 변화에 따른 정전용량 드리프트 발생
- **특수성**: 일반 핸드셋과 달리 인공와우는 하루 종일 피부 밀착 → 온도는 안정적이지만 높은 온도 오프셋 유지
- **위험**: IC 내부 온도계수로 인한 LTA 기준 오프셋 → 특정 온도 범위에서만 먹통 발생하는 간헐 불량

## 4. 온도·습도 변화 시 IC 내부 드리프트 특성

### 4-1. 온도 변화 시나리오

| 시나리오 | 변화 | 예상 영향 |
|---|---|---|
| 착용 전→후 (실온→체온) | +10~15°C 급격 상승 | LTA 기준 이동 → 부팅 직후 잘못된 baseline이 온도 의존성으로 가변 |
| 냉방 실내→외출 | 온도 편차 ±10°C | 노터치 상태에서도 LTA 단계적 이동 → 임계 threshold와의 margin 축소 |
| 겨울 외출 | 극단 저온 (<0°C) | self-cap 정전용량 감소 → counts 레인지 변화 → ATI 재보정 필요 증가 |

### 4-2. 습도 변화 시나리오

- 땀·고습도 환경: 전극 주변 수분막 형성 → self-cap 절대값 상승 → LTA가 노터치를 "높은 값"으로 추적 → 건조 환경으로 복귀 시 relative 변화 기준 흐트러짐
- **M4 추론과의 충돌**: C51이 DC 블로킹한다 해도 AC 경로의 습도 영향은 차단 불가 → 환경 변화 시 드리프트가 IC 내부만으로 설명 안 될 수 있음

### 4-3. 신뢰성 공학 관점 결론

- IQS323 계열 self-cap 방식은 온습도에 민감하며, **autoATI의 자기정상화 속도(BETA 의존)가 환경 변화 속도보다 느리면** 과도구간 중 오터치·미인식이 발생한다.
- "BETA 빠른 수렴"(M3)은 환경 스트레스 대응에는 유리하지만, 약터치 흡수(약점)와 트레이드오프가 있다.

## 5. 자기정상화 과도구간 중 재터치 미인식 위험

### 5-1. 과도구간 정의

부팅 직후 터치 손 뗌 → LTA가 노터치 counts로 수렴 완료까지의 구간. 이 구간의 길이는 BETA 값과 LTA 오염 크기에 의존.

### 5-2. 재터치 시 발생 과정

```
부팅 (LTA=터치값=높은 counts)
    ↓ 손 뗌
LTA가 서서히 노터치 방향으로 하강 중
    ↓ 이때 재터치
delta = counts_터치 - LTA_과도구간 ← LTA가 아직 높은 상태
delta가 threshold 미달 → 터치 미인식
```

### 5-3. 인공와우에서 특히 위험한 이유

- 사용자는 볼륨·프로그램 변경을 위해 빠른 연속 터치를 시도 (응답 없으면 반복)
- 반복 터치 → 미인식 반복 → 사용자 혼란 → LTA 재오염 악순환
- 청각 장애인은 "터치 먹통" 피드백(소리로 인식 못함)을 진동 피드백에만 의존 → 장시간 눈치 못 채는 사용성 문제

### 5-4. 과도구간 길이 추정 필요성

- 이전 분석 및 은수님 정리 어디에도 과도구간 실측값 없음
- BETA 설정에 따라 수십ms ~ 수 초 범위일 수 있음
- **M8 채택 전 반드시 실측 필요**: "손 뗀 후 몇 초간 터치 무반응 허용 가능한가" → UX 요구사항과 대조

## 7. 품질 엔지니어링 권고

### 7-1. M8 채택 전 필수 실측 게이트

| 우선순위 | 실측 항목 | 목적 |
|---|---|---|
| 1순위 | 과도구간 길이 실측 (손 뗌~수렴까지 RTT 캡처) | M8 UX 허용 여부 결정 |
| 1순위 | ATI Full I²C 무응답 재현 테스트 | 치명 위험 사전 차단 |
| 2순위 | 배터리 교체 시나리오 부팅 행동 실측 | 고착 빈도 정량화 |
| 2순위 | 온도 범위(15~40°C) counts 변동 측정 | 환경 스트레스 드리프트 정량화 |
| 3순위 | 0x30 0x02 방전 물리효력 실측 | ESD vs 드리프트 원인 분리 |

### 7-2. 안전망 없이 출하 시 예상 불량 패턴

1. **배터리 교체 후 먹통** — 현장 재현 어려움 (사용 패턴 의존) → CS 대응 어려운 간헐 불량
2. **착용 직후 수 초 무반응** — 사용자 반복 터치 → CS 불만
3. **여름철/땀 환경 먹통** — 계절 의존 불량 → 계절성 반품

### 7-3. 최소 안전망 제언

M8을 채택하더라도 다음 두 가지는 반드시 결합 필요:
- **노터치 게이트**: 부팅 후 Reseed를 `ch0_touch==0` N tick 확인 후 발행 (이전 분석 권고 A 동일)
- **I²C 통신관리**: ATI Full 재활성 시 RDY 핸드셰이크·타임아웃 (이전 분석 검증 V3 동일)

이 두 가지가 없으면 M8은 "호조건 랩 환경"에서만 작동하는 취약한 해결책이 된다.

## 8. 한 줄 결론

> **M8은 실측 미완 상태에서의 조기 낙관이다. M4~M7은 전부 추론이며, 착용 중 배터리 교체·과도구간 재터치·온습도 변화·I²C 무응답이라는 치명적 엣지 케이스를 고려하지 않은 채 "모든 문제 해결"이라 단정할 수 없다. 노터치 게이트와 I²C 통신관리를 안전망으로 결합한 하이브리드만이 신뢰성 관점에서 출하 가능한 수준이다.**
