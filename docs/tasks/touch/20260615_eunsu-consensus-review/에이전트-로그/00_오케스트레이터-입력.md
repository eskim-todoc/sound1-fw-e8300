# 오케스트레이터 입력 — 20인 회의 설계 전문

> **TL;DR**: 은수님 터치 1차 정리를 20인 회의 형태로 검토하는 오케스트레이션. 분석 7 → 검증 6 → 토론 4 → 합의 3 순으로 진행. 공통 배경, 역할 설계, 20개 프롬프트 전문, 워크플로우 스크립트를 모두 포함.

---

## 1. 오케스트레이션 설계

### 구조

```
Phase 1 (분석) — 7개 페르소나 병렬
  A01 IC/데이터시트 전문가
  A02 펌웨어 SW 개발자
  A03 아날로그 회로·HW 엔지니어
  A04 신뢰성·품질 엔지니어
  A05 절전·전력 전문가
  A06 제품 UX·사용자 경험 담당자
  A07 5Why 근본원인 분석가
    ↓ (Phase 1 결과 요약 → Phase 2 컨텍스트)
Phase 2 (검증) — 6개 adversarial 검증자 병렬
  B01 데이터시트 기반 검증자 (M1~M4 반론)
  B02 물리 메커니즘 검증자 (M4~M7 반론)
  B03 SW 구현 가능성 검증자 (M2·M3 구현 반론)
  B04 이전 결론 대조 검증자 (충돌 발굴)
  B05 실측 게이트 검증자 (미실측 결론 반론)
  B06 누락 항목 발굴자 (빠진 것 발굴)
    ↓ (Phase 1+2 결과 요약 → Phase 3 컨텍스트)
Phase 3 (토론) — 4개 조율 에이전트 병렬
  C01 쟁점 목록 작성자
  C02 중재자
  C03 은수님 안 최종 옹호자
  C04 이전 결론 최종 옹호자
    ↓ (Phase 1+2+3 결과 요약 → Phase 4 컨텍스트)
Phase 4 (합의) — 3개 합의 에이전트 병렬
  D01 기술 최종 합의 도출자
  D02 실행 로드맵 설계자
  D03 최종 서기 (공식 회의록 작성)
```

### 흐름

- `parallel()` 내 각 phase 병렬 실행
- 각 에이전트: 분석 수행 + 결과 파일 Write + structured JSON 반환
- phase 간: 결과 요약 문자열로 다음 phase에 컨텍스트 전달
- 최종: 인덱스.md 갱신

## 2. 공통 배경 컨텍스트 (모든 에이전트에 제공)

```
[Sound1 IQS323 터치 IC 문제 분석 — 은수님 1차 정리 2026-06-15]

은수님의 문제 정리:
P1. autoATI + 터치된 채 부팅 완료 → 터치 먹통 (autoATI가 터치 상태로 진행)
P2. 해결: Fixed MULT/COMP 사용 (autoATI 포기)
P3. Fixed 사용 → IC 자동 드리프트 보정 기능 상실
P4. 드리프트 누적 → 일정 횟수 후 먹통
P5. 해결: CRX0 → VSS 방전 (200ms 주기)
P6. 방전 부작용: 부팅 시 터치 상태 카운터 → LTA 적용 → 부팅마다 감도 다름

근본 해결 분석:
M1. autoATI는 LTA→카운터 수렴 구조 → 터치된 채 부팅이어도 손 떼면 수렴함
M2. 터치 중 LTA 업데이트 안 됨 → 부팅 터치 인식 시 터치 해제 대기 코드로 해결
M3. Beta 값 조정으로 빠른 수렴 가능
M4. DC 블로킹 캡(C51 100pF) 때문에 터치패드보다 IC 내부 드리프트가 주원인 예상
M5. 먹통 상태 + 충전기 연결 → 터치 복귀 (DC 블로킹 캡 있어 터치패드 주원인 아님)
M6. 기구 GND 쇼트 → 터치패드 방전 가능성 있으나 주요 원인 아님
M7. (M6 재확인: 기구 GND 쇼트가 주요 원인 아님)
M8. 결론: autoATI + Beta 빠른 수렴만으로 모든 문제 해결 가능 예상
M9. 추가: 카운터 최대값 4096보다 크게 하면 더 안정적일까?

이전 분석 결과(docs/참고/touch/개선/):
- 진짜 뿌리: Reseed(apply_settings drv.c:1134 / func_sleep main.c:880)가 부팅 시 터치 counts로 LTA seed → baseline 오염 (autoATI 자체가 아님)
- 권고 A(최우선): Reseed를 노터치 게이트(ch0_touch==0 N tick) 뒤로 지연
- 권고 B: FIXED → ATI Full 복귀 + 터치중 Re-ATI 차단
- 은수님 안 검증(이전): 방향 옳음, "frozen 덕분" 설명은 반대("frozen 부재 덕분"이 맞음)
- 안전망: 손 안 떼면 LTA 고착 → 노터치 게이트 필수
- BETA: Fast Filter Band 비대칭 설계가 올바른 구현 (단일 상향 금지: 약터치 흡수)
- I²C: ATI Full 재활성 시 무응답 위험 → 통신관리 선행 필수
- 방전 코드: 0x30 0x02 = Linearise (VSS 아닐 수 있음) → 실측 필요
- 하이브리드 최적: ATI Full + 노터치 게이트 + 비대칭 BETA + Re-ATI 차단 + I²C 관리
```
