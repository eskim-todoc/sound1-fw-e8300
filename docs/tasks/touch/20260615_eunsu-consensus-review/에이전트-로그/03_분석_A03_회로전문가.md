# A03 — 아날로그 회로·HW 엔지니어 분석

> **TL;DR**: C51(100pF)은 DC를 차단하지만 self-cap 측정 AC 성분은 통과하므로 전극 전하누적이 "단독 먹통 원인"이기는 어렵다. 드리프트의 1차 원인은 FIXED MULT/COMP로 인한 IC 내부 LTA 보정 상실이며, 충전기 연결 복귀는 VDD 리플→POR 리셋이 가장 유력하다. 방전 코드 0x30 0x02가 Linearise(VSS 아님)이라면 B2 핀은 VSS에 연결되지 않아 전극 방전은 이뤄지지 않는다.

---

## 1. 분석 대상 명제

| 명제 | 내용 |
|---|---|
| M4 | DC 블로킹 캡(C51 100pF) 때문에 터치패드보다 IC 내부 드리프트가 주원인 예상 |
| M5 | 먹통 상태 + 충전기 연결 → 터치 복귀 (DC 블로킹 캡 있어 터치패드 주원인 아님) |
| M6·M7 | 기구 GND 쇼트 → 방전 가능성 있으나 주요 원인 아님 |
| P5 해석 | 방전 코드(0x30 0x02) — Linearise 가능성 → 실제 전기 동작이 무엇인가 |
| 공통 | self-cap 구조에서 드리프트가 발생하는 물리 이유 |

## 2. 회로 구성 기본 확인 (분석 전제)

```
CRX0 (B2) ── R31(100Ω) ── C51(100pF) ── J3 ── 터치 전극 패드
```

- VDD: 1.8V_QCC, R28(0Ω) 점퍼, 디커플링 C54(4.7µF) + C55(100pF)
- 방전 코드 현재: 레지스터 0x30에 0x02 기록
- CRX1: C52(100nF) → R32(0Ω) → J4, SW상 CalCap으로 설정
- CRX2: R33(470Ω) 종단, NC

## 3. M4 — C51(100pF DC 블로킹)과 드리프트 주원인

### 3.1 C51의 전기적 특성 분석

**C51은 "DC 차단·AC 통과" 소자다.**

IQS323 self-cap 측정 방식: IC는 CRX0 핀을 구동(전하 주입)하고 돌아오는 전하를 적산해 정전용량을 측정한다. 이 과정은 AC 전하 이동이며, C51은 이 AC 성분을 통과시킨다.

- 측정 주파수 가정(1MHz): C51 임피던스 Z = 1/(2π × 1e6 × 100e-12) ≈ **1.59 kΩ**
- 측정 주파수 더 낮을 경우(100kHz): Z ≈ **15.9 kΩ** — 무시 불가

C51이 직렬로 삽입됨에 따라 측정되는 정전용량은 C51과 Ctouch(전극 정전용량)의 직렬 합성:

$$C_{measured} = \frac{C_{51} \times C_{touch}}{C_{51} + C_{touch}}$$

Ctouch ≈ 2~10pF(전형적 self-cap 전극), C51 = 100pF이라면:

- Ctouch = 2pF: Cmeasured ≈ 1.96pF (측정값 ~98%가 전극 정전용량)
- Ctouch = 10pF: Cmeasured ≈ 9.09pF

**C51은 직렬이지만 C51 >> Ctouch이므로 측정 정전용량은 주로 전극 정전용량으로 결정된다.** C51이 측정값을 왜곡하는 효과는 크지 않다.

### 3.2 "DC 블로킹" 표현의 의미와 한계

"DC 블로킹"이란 직류 전류를 차단한다는 의미이다. 즉:

- **AC 전하 이동**: 통과 — self-cap 측정에는 영향 없음 (측정 동작 가능)
- **DC 전류 경로**: 차단 — 전극 패드(J3 측)와 CRX0 핀(IC 측)이 DC적으로 분리됨

이 DC 분리가 "전하 누적"의 근거로 제시됐지만:

**J3 전극 패드 측 전하 누적 분석:**

전극 패드는 C51을 통해 IC에 AC적으로 연결되고, 패드 자체는 주변 GND 면·기구물 등을 통해 고저항 누설 경로가 존재한다. 전하 방전 시정수 τ = R_leak × C_electrode. 전형적 PCB 절연 저항이 1GΩ 이상이고 C_electrode를 10pF로 가정하면 τ ≈ 10ms — 상당히 빠른 방전이 일어난다.

**IC 내부(CRX0 핀 측) 전하 누적:**

IC 내부 아날로그 프론트엔드의 샘플링 커패시터, 내부 시그마-델타 변환기의 적산 용량 등이 드리프트의 실제 위치다. 이는 전극 측이 아니라 IC 내부다.

### 3.3 self-cap 드리프트의 물리 원인

Self-cap 드리프트의 주요 물리 원인:

| 원인 | 메커니즘 | 규모 |
|---|---|---|
| **온도 변화** | 캐패시터 온도 계수, IC 내부 기준전압 드리프트 | 수십 ppm/°C |
| **내부 아날로그 드리프트** | IC 내부 샘플링 적산 용량의 dielectric absorption, leakage | 낮지만 누적 |
| **전극 환경 변화** | 습기, 오염, 기구물 접촉 변화 → Ctouch 변화 | 환경 의존 |
| **C51 충전상태** | DC 기준점 변화 시 초기 충전전달로 드리프트 발생 | 일시적 |

**FIXED MULT/COMP 사용 시**: ATI가 이 드리프트를 자동 추적·보정해주지 않으므로, 작은 드리프트라도 LTA 기준에서 벗어나 counts가 한쪽으로 치우친다. autoATI는 이를 지속적으로 재보정하는 기능이다.

### 3.4 M4 판정

| 판정 | 내용 |
|---|---|
| **C51 역할 기술**: ✅ 맞음 | DC를 차단하고 전극을 IC에서 DC 분리하는 것은 사실 |
| **"터치패드보다 IC 내부 드리프트 주원인"**: △ 조건부 | FIXED MULT/COMP로 ATI 보정이 없다면 IC 내부·온도·전압 드리프트 누적이 주원인이 된다는 추론은 합리적. 단 C51이 그 이유의 직접 근거는 아님 |
| **C51이 이유**: ⚠️ 불충분 | C51 직렬 삽입이 드리프트를 일으키는 것이 아니라 ATI 보정 부재가 드리프트 누적의 주원인 |

> [!NOTE]
> C51의 역할: self-cap 레퍼런스(IQS323 데이터시트 Fig 2.3 슬라이더 레퍼런스)에서도 CRX에 직렬 캐패시터가 사용되는 것은 표준 구성이다. C51 자체가 드리프트 원인이 아니다.

## 4. M5 — 충전기 연결 시 터치 복귀의 물리 메커니즘

### 4.1 시나리오 분석

먹통 상태: LTA 고착으로 counts가 임계를 벗어나지 못하는 상태 (SW 드리프트 기원) 또는 전하 누적(물리 기원)으로 터치 인식 불가.

충전기 연결 시 발생하는 전기적 이벤트:

**가설_1: VDD 리플 → POR(Power-On Reset)**

충전기 연결 시 1.8V_QCC 전원 라인에 스위칭 노이즈나 과도 전압이 인가될 수 있다. R28이 0Ω(페라이트 비드 미삽입)이므로 전원 필터링이 없어 이 노이즈가 VDD에 그대로 전달된다.

- IQS323 POR 임계: 전원 오프(~0.9V) → 온(~1.65V) 트랜지션 시 POR 발생
- VDD가 POR 임계 이하로 순간 떨어졌다가 복귀하면 IC 전체 리셋
- POR 후 ATI 수행 → baseline 재보정 → 터치 복귀

가능성: **높음**. 특히 R28이 0Ω이라 전원 경로 무필터 상태에서 충전기 연결 시 급격한 전압 변동이 POR를 유발할 수 있다. 데이터시트 §4.1: 전원 dV/dt > 100V/s가 리셋 트리거.

**가설_2: GND 경로 변화 → 전극 방전**

충전기 연결로 기기 GND가 충전기 GND에 연결될 수 있다. 이 경우 기구물을 통한 전극의 방전 경로가 생성됨.

- 단, C51이 DC 차단 역할을 하므로 J3 전극 측의 전하가 C51을 통해 IC로 방전되지 않음
- 기구물 → 전극 → 직접 GND 경로는 기구물 설계에 따라 다름
- M6·M7(기구 GND 쇼트)이 주원인이 아니라는 은수님 판단이 맞다면, GND 경로 변화는 충분한 설명이 아님

가능성: **중간**. 기구물 GND 경로 설계에 따라 다름.

**가설_3: VDD 상승 → 내부 레귤레이터 재안정화**

충전기 연결로 배터리 전압이 안정화되면서 1.8V_QCC가 안정화 → IC 내부 VREG가 재안정화 → 아날로그 프론트엔드 리셋 효과.

가능성: **낮음**. 이 경우 점진적 회복이 예상되며, 즉각적 복귀와 정합하지 않음.

**가설_4: I²C 통신 재개 계기**

충전기 연결 이벤트를 E8300가 감지하고 터치 IC를 재초기화하는 SW 루틴이 트리거될 경우.

가능성: **조건부**. SW 루틴 존재 여부에 따라 다름.

### 4.2 M5의 "DC 블로킹 캡 있어 터치패드 주원인 아님" 추론의 타당성

이 추론의 논리:
- 충전기 연결로 터치가 복귀했다
- 만약 터치패드(전극)의 물리 전하 누적이 원인이었다면, 충전기 연결로 전극이 방전되는 경로가 열린 것
- 그런데 C51이 있어서 충전기 GND와 전극 사이에 DC 경로가 없다
- 따라서 전극의 물리 전하 누적이 이유가 아니라, IC 내부가 주원인

**이 추론에는 논리적 점프가 있다:**

충전기 연결 → 터치 복귀의 원인이 POR(가설_1)이라면, IC 내부 드리프트가 주원인이라는 결론(M4)에 일치한다. 그러나 충전기 연결이 반드시 C51을 통한 방전을 해야만 전극 문제를 해결하는 것은 아니다. POR 후 ATI 재실행으로 어떤 원인의 먹통도 해소될 수 있다.

**판정**: M5의 관측 사실(충전기 연결 시 복귀)은 맞지만, 그로부터 "터치패드가 주원인이 아님"이라는 결론은 POR 가설로도 설명 가능하므로 논리적으로 단정할 수 없다. **다만 POR이 주 메커니즘이라면 SW 드리프트와 물리 누적 모두를 해소하므로 M5 결론의 방향(IC 내부 우세)은 간접 지지한다.**

## 5. M6·M7 — 기구 GND 쇼트 → 방전

### 5.1 물리적 실현 가능성

기구 GND 쇼트란: 터치 전극 패드(J3 연결 전극)를 기구물의 도전성 부품에 접촉시켜 GND에 단락하는 행위.

전극 → 기구 GND 직접 접촉 경로:

```
터치 전극 패드 ── (J3 측) ── C51 ── (IC 측 B2) ── R31 ── CRX0
                     ↕
              기구물 도전 부품 ── GND
```

만약 전극 패드 자체를 GND에 연결하면 (J3 측), C51의 IC 쪽 전하가 방전되는가?

- 전극을 GND에 쇼트하면 J3 측 전압이 강제로 0V
- C51 양단 전압: V(B2쪽) - V(J3쪽) = V(B2쪽) - 0
- C51을 통해 B2쪽 전하가 방전될 수 있음 — **AC 경로로 방전 가능**
- 단, C51의 DC 차단 특성으로 인해 방전은 RC 시정수에 따라: τ = R31 × C51 = 100 × 100e-12 = **10ns** — 매우 빠른 방전

**물리 실현 가능성**: 기구 GND 쇼트로 전극을 GND에 연결하면 B2(CRX0)측 전하도 C51을 통해 매우 빠르게 방전된다. 물리적으로 가능하다.

### 5.2 "주요 원인이 아님" 판단의 타당성

은수님의 M6·M7: "기구 GND 쇼트 → 방전 가능성 있으나 주요 원인이 아님"

회로 관점에서의 분석:

기구 GND 쇼트가 "먹통 해소"의 주 원인이 아닌 이유:
1. **GND 쇼트 효과의 범위**: 전극-GND 단락 시 C51 양단 전하가 방전되어 물리 누적 전하를 해소한다. 그러나 IC 내부 LTA 고착은 물리 전하 방전으로 해소되지 않는다. LTA는 레지스터 값이므로 IC 리셋(POR)이 있어야 초기화된다.
2. **"주요 원인"의 기준**: SW 드리프트(LTA 고착)가 주원인이라면 GND 쇼트로는 해소 불가 → 즉 GND 쇼트 복귀는 그 자체가 물리 누적 기여가 있음을 시사한다. 그러나 이 경우 물리 누적이 주원인이 된다.

> [!WARNING]
> 논리 역전 주의: "GND 쇼트로 터치가 복귀했다면" → 물리 전하 누적이 주원인. "복귀 안 했다면" → SW 드리프트가 주원인. GND 쇼트 복귀의 실측 여부와 의미 해석이 중요하다.

**판정**: M6·M7 물리적 가능성은 있다. "주요 원인이 아님"이라는 판단은 SW 드리프트가 더 지배적이라는 해석에 기반하며, 이는 이전 분석("SW 드리프트 주, 물리 누적 부")과 일치한다. 단 실측 없이 단정하기는 어렵다.

## 6. 방전 코드 0x30 0x02 — Linearise 가능성과 전기 동작

### 6.1 이전 분석 컨텍스트

이전 분석(개선/ 문서)에서: "0x30 0x02 = Linearise (VSS 아닐 수 있음) → 실측 필요"

### 6.2 레지스터 0x30 해석

IQS323 데이터시트 기준으로 레지스터 0x30의 의미:

**If 0x30 = Inactive Channel Setup 레지스터:**
- 비트 0x02: 특정 비트 설정값
- Inactive Rx VSS: 비활성 채널을 VSS(회로 GND)에 연결
- Linearise 모드: 비활성 채널을 내부 linearisation 구조로 연결

**전기적 차이:**

| 설정 | B2(CRX0)의 전기 상태 | C51 방전 여부 |
|---|---|---|
| **VSS 연결** | B2 핀이 IC 내부를 통해 GND에 연결 | C51 방전 가능 (τ = R31 × C51 ≈ 10ns) |
| **Linearise** | B2 핀이 linearisation 회로에 연결 (GND 아님) | C51 방전 **안 됨** |

만약 0x30 0x02가 Linearise라면:
- CRX0 핀(B2)은 GND가 아닌 내부 참조 회로에 연결됨
- J3 전극 측 전하는 C51 → B2 경로로 방전되지 않음
- **방전 동작이 의도와 다를 수 있다**

### 6.3 실제 회로 동작 예상

Linearise 모드에서:
- IC는 CRX0 채널을 비활성화하되 linearisation을 적용하는 내부 동작 수행
- 이 과정에서 내부 적산 용량이 특정 기준 상태로 수렴될 수 있음
- 이것이 "방전 효과"처럼 보이는 이유: 내부 counts가 기준값으로 복귀하는 SW 효과

**200ms 주기 방전의 실제 효과 해석:**
- 만약 Linearise라면: IC 내부 ADC 적산 상태를 주기적으로 기준점으로 리셋하는 효과 → 이것이 실제로 LTA 드리프트를 억제하는 메커니즘
- 물리적 전극 방전은 일어나지 않음

## 7. 회로 판정 종합표

| 명제 | 회로 판정 | 근거 |
|---|---|---|
| M4 DC블로킹이 IC 내부 드리프트 주원인 이유 | ⚠️ 수정 필요 | C51은 AC 통과·DC 차단. 드리프트 주원인은 FIXED MULT/COMP로 인한 ATI 보정 부재. C51이 그 이유는 아님 |
| M4 "터치패드보다 IC 내부 드리프트 주원인" | △ 조건부 | ATI 보정 부재 시 IC 내부 드리프트 누적이 지배적이라는 결론은 합리적 |
| M5 충전기 연결 복귀 물리 메커니즘 | ⚠️ 단정 불가 | POR(가설_1)이 가장 유력. GND 경로 변화 가능성 중간. "DC블로킹이 증거"라는 추론에 논리 점프 있음 |
| M6·M7 기구 GND 쇼트 가능성 | △ 물리 가능, 주원인 아님 | 전극→GND 쇼트 시 C51을 통한 방전은 물리 가능(τ≈10ns). 그러나 SW LTA 고착은 해소 불가 |
| 방전 코드 0x30 0x02 | ⚠️ 확인 필요 | Linearise라면 B2 핀이 VSS 비연결 → 전극 방전 아님. 내부 ADC 상태 리셋 효과로 드리프트 억제 가능 |
| self-cap 드리프트 물리 이유 | ✅ 명확 | 온도·전압 드리프트 + IC 내부 적산 용량 누설 + ATI 보정 부재의 복합. FIXED 사용 시 누적 불가피 |

## 8. 이전 분석과의 정합성

| 이전 분석 결론 | 본 분석 정합성 |
|---|---|
| "SW 드리프트(주) + 물리 누적(부) 가산 모델" | ✅ 일치 — C51 전하 누적보다 FIXED로 인한 SW 드리프트가 지배적 |
| "방전 0x30 0x02 = Linearise → 실측 필요" | ✅ 일치 — Linearise라면 전극 방전 없음, 내부 ADC 리셋 효과로 해석 |
| "GND 쇼트 복귀 시 물리 누적 가능성 시사" | ✅ 일치 — M6·M7 물리 경로는 있으나 주원인 판단 보류 |
| "C51 단락 후 먹통 재현 여부가 판별 실측" | ✅ 지지 — 회로 분석으로도 C51 역할 규명에 가장 결정적 |

## 9. HW 관점 권고 사항

> [!IMPORTANT]
> 아래는 회로 관점의 분석 기반 권고이며 실측 전 확정이 아니다.

**즉시 확인 가능:**
1. **방전 코드 실측**: 오실로스코프로 방전 코드(0x30 0x02) 실행 전후 B2(CRX0) 핀 파형 측정 → VSS 연결인지 Linearise인지 확인
2. **POR 여부**: 충전기 연결 시 VDD 파형 측정 → POR 레벨 이하 딥 발생 여부 확인

**C51 관련:**
3. **C51 단락 시험**: C51을 점퍼로 단락 후 먹통 재현 시험 → C51 기여도 확인
4. **전극-GND 절연저항 측정**: J3 전극 패드와 GND 사이 절연저항 → 전하 누설 경로 규모 확인

**ESD/노이즈:**
5. **R31 교체 검토**: 100Ω → 470Ω(데이터시트 권장)으로 교체 시 ESD 보호 개선, 감도 영향 동시 평가 필요

## 10. 한 줄 결론

> **C51(100pF)은 AC 통과·DC 차단 소자로 self-cap 측정을 가능하게 하되 전극의 DC 격리를 만든다. 드리프트 주원인은 FIXED MULT/COMP로 ATI 보정이 없는 SW 구조이며, C51이 그 이유는 아니다. 충전기 연결 복귀는 VDD 리플→POR 리셋이 가장 유력하다. 방전 코드 0x30 0x02가 Linearise라면 B2 핀은 VSS 비연결이므로 전극 방전은 없고 내부 ADC 리셋 효과만 있는 것으로 해석된다. 은수님의 회로 직관(C51 DC차단·전극 격리)은 토폴로지는 정확하나 "C51 때문에 내부 드리프트가 주원인"이라는 연결 고리는 논리 비약이 있다.**
