# 오케스트레이터 입력

**TL;DR**: 조사 4(코드매핑·DS공식·계수출처·데이터흐름) + adversarial 검증 1. 모든 결론은 데이터시트/코드 인용. 할루시네이션 0.

## 목표
코드 상수(THRESHOLD·HYSTERESIS·PROX_THRESHOLD 등)가 IQS323 레지스터로 어떻게 들어가고 IC가 어떻게 계산·적용하는지, 연관 계수(LTA·Counts·ATI Target/Band·Beta·Fast Filter Band)의 출처·계산·상수 변환 여부 전수 정리.

## 대상 상수·계수 (확인된 출발점 — 페르소나가 재검증)
- `TDC_TOUCH_IQS323_THRESHOLD` (현 80): 0x62 LSB. 절대임계 = 계수×LTA/256 (DS A.17).
- `TDC_TOUCH_IQS323_HYSTERESIS` (8): 0x62 MSB bits[15:12]. touch_settings에서 `(H&0x0F)<<4`로 위치. 실제 hyst=(H/256)×임계.
- `TDC_TOUCH_IQS323_PROX_THRESHOLD` (255): 0x61 LSB. prox 진입 = delta > Prox Threshold.
- Beta: 0xB0 Counts(2/2)·0xB1 LTA Normal(6)·0xB2 LTA Fast(2/2). AZD004 해석 α=1/2^β(실측 확정).
- Fast Filter Band 0xB4(10), ATI Setup 0x36(0x040C Full)→ATI Target≈400·Band Large(1/8≈50).
- LTA(0x14)·Filtered Counts(0x13) read-only(IC 산출).
