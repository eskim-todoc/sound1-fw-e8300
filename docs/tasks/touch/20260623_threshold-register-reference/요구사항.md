# 요구사항: 터치 임계·계수 레지스터 동작 레퍼런스

**TL;DR**: 은수님 지시(2026-06-23) — 터치 관련 코드 상수가 IQS323 레지스터로 어떻게 들어가고 IC 내부에서 어떻게 계산·적용되는지, 연관 계수들이 어디서 어떻게 구해지는지를 **할루시네이션 0**으로 전수 정리. 과정은 md, 최종 기술 정리는 Claude 스타일(베이지+주황) html. 코드 수정 없음 — 조사·분석·검사·검증만.

## 1. 목표 (조사·정리 대상)

1. **상수 → 레지스터 매핑**: `TDC_TOUCH_IQS323_THRESHOLD`·`TDC_TOUCH_IQS323_HYSTERESIS`·`TDC_TOUCH_IQS323_PROX_THRESHOLD` 등 코드 상수가 어느 레지스터(0x62 Touch Settings·0x61 Prox Settings 등)에 **어떻게 write**되는지. 상수 **그대로** 쓰이는지, 코드에서 **변환(비트 시프트 등)** 되는지.
2. **IC 내부 계산**: 레지스터 값을 IC가 **어떻게 해석·계산**해 실제 동작 임계로 쓰는지 (예: 절대 터치임계 = 계수 × LTA / 256, 히스테레시스 = (H/256) × 임계, prox 진입 = delta > Prox Threshold).
3. **연관 계수 출처·계산**: 계산에 쓰이는 다른 값들 — **LTA·Filtered Counts·ATI Target·ATI Band·Beta(Counts/LTA Normal/Fast)·Fast Filter Band** 등 — 이 어디서 어떻게 구해지는지(IC 자동 ATI 산출 / 코드 설정 / 실시간 측정). 상호 연관성.
4. **전체 데이터 흐름**: raw 측정 → Counts → LTA → delta → 임계 비교 → touch/prox 판정의 전 경로.
5. **상수 그대로 vs 내부 변환 검사**: 각 값이 코드에서/IC에서 변형되는 지점 전수 명시.
