### 무엇을 했는가

### 핵심 정리
- **절대 터치임계 = 계수(0x62) × LTA / 256** (계수 80 → ≈125 @LTA400). LTA 비례라 상대 감도 일정.
- 분류: THRESHOLD/PROX/Beta=**그대로**, HYSTERESIS=**코드변환**`(H&0xF)<<4`, 절대임계·hyst·ATI Target=**IC 내부계산**.
- **Beta 해석 AZD004(α=1/2^β, β클수록 느림) 실측 확정** — β=16서 LTA 동결 로그가 근거. DS(Beta/256)와 반대.
- ATI는 baseline(Cp 산포)만 정규화, **grounding에 의한 터치 delta 차이는 못 보정** → 임계는 독립 환경 기준.
- 실측 게이트 4종(prox 단위·Beta 공식·ATI Base 보존·Hysteresis 상한).
