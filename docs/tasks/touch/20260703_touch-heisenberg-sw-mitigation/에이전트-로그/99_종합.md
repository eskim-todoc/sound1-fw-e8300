# 99 · 종합 — SW-only 하이젠베르크 회피

**TL;DR**: **결론은 "SW-only 회피 가능"** — HW 무수정·기존기능 무손상으로 쓸 수 있는 회귀안전 레버가 여럿 확인됐다(mutual No-go와 대조). 다만 **지배 애그레서(SPI/QCC/SYSCLK 중 무엇)가 미확정**이라 최종 확정엔 RTT/스코프 실측 게이트가 선결이며, 무엇보다 **실제 재현 경로가 `fake_func_sleep()`**(별도 복제 코드, 재부팅 호출 주석처리됨)라는 특성화 발견이 모든 후속의 전제다.

## 1. 특성화 핵심 (C1·C2)

- **두 재부팅 트리거**(절전 ULP): ATI 에러 7연속(~700ms) · false touch 24연속(2400ms). Normal(무한재시도/30~90초)보다 문턱이 훨씬 짧아 **구조적 취약**.
- **★ 실제 재현 경로 = `fake_func_sleep()`**(main.c:810~1031, BLE 'General Debug' op_mode==1): SYSCLK 30.72MHz 유지 + BLE 상시 서비스 + QCC 셧다운 주석처리 → 은수님 프로파일링 시나리오와 코드 사실 일치. **func_sleep()과 분기된 복제 코드**라, 이쪽을 안 고치는 레버는 재현 경로에 반영 안 됨(은수님 확인 필요).
- **H1**(점검): 절전 I2C 프리스케일 ÷6이 30.72MHz 유지 중 재사용되면 SCL≈5.12MHz(I2C 상한 5배) → 조용한 비트오류. (단 S6 검증에서 "fake_func_sleep 경로엔 H1 반박" — 실측으로 확정.)
- **H2**(유력): 계측 `read_debug()`가 기존 미해결 latch 버그(20260622 문서 39/40)를 보유, ULP마다 CRX0 인접에 추가 0xFF 주입 = **"관측 자체가 애그레서"**. `TDC_TOUCH_DEBUG_PRINT_ENABLE=1` 기본.

|---|---|---|---|---|---|
| **S1** 변환주파수(1M→500k) | ✗ | ✅ | ✅ | 약~중(에일리어싱만) | 조건부 채택 — 저위험 시험, **389kHz(최악 근접) 회피** |
| **S2** 필터·Beta·ATI밴드 | ✗ | ✅ | ✅ | 중 | 조건부 — 전제 "ATI가 Beta 우회"를 [가설-강]으로 정정, 실측 3게이트 |
| **S3** 내장 노이즈/전력/동기 | ✔ | ❌ | ✅ | 약 | 대부분 기각 · Report Rate만 조건부 · Events모드 I2C Lock-Up 에라타 위험 |
| **S4** e8300 타이밍 협조 | ✔ | ✅ | ✅ | 약 | 기각 — 'SPI-조건부' 차별성 반박, **무조건 스로틀=H2 완화로 수렴** |

## 3. 권고 포트폴리오 (회귀안전 + 근거 우선순)

> 지배 애그레서 미확정이므로 "무엇이 원인이든 유효한" **저위험 포트폴리오** + **실측 게이트**로 접근.

- **P0 (선결·실측 게이트)**: RTT 로그로 ① 재현이 `fake_func_sleep()` 경로 맞는지 ② 지배 애그레서 식별 ③ H1/H2 참 여부 확인. **모든 코드 착수 전 이분법 검증.**
- **P1 (관측 탈침습 — H2)**: `read_debug()` latch 버그 수정(combined_read 적용) 또는 프로파일링 중 스로틀/비활성 → "관측이 대상을 흔드는" 부분 제거. (S4가 여기로 수렴)
- **P2 (물리 결합 저감 — S5)**: GPIO 드라이브 하향(I2C0 8X→4X, SPI1 2X→1X) + 절전 I2C 프리스케일 의도값(122kHz) 복귀 검토.
- **P3 (배경 교란 제거 — S8/R7)**: 0xC0 bit7 Interface Selection로 IQS323 자가 RDY 토글 제거. **0xC0 write 사이트 재grep 선결**(인용사슬 4/5/6곳 불일치) + INV-X-1(Power Mode·CH timeout 비트 동반) 준수.
- **P4 (샘플링 이격 — S1)**: 변환주파수 조정(389kHz 회피) — 저위험 시험.
- **P5 (안전망 — S6)**: F0-게이팅 라이드스루(카운터 기반)로 프로파일링 구간 재부팅 억제 — 근본해결 아닌 완충.

## 4. 기존기능 무손상 (회귀)

- 회귀안전 판정 레버(S1·S2·S5·S8): C2 불변식(INV-①~⑧·INV-X) 위반 **0건** 확인.
- 주의 레버: **S6-4**(시간원 정지 시 Re-ATI 영구중단 → 카운터화 필수), **S7 후보_1**(FSM 100× 둔화 → 기각), **S3 Events모드**(I2C Lock-Up 에라타).
- 공통: 새 0xC0 write는 반드시 `0x50|trigger, 0x07`(INV-X-1) 유지.

## 5. 정직한 한계

- **지배 애그레서 미확정** — 레버 효과는 대부분 [가설-강/실측게이트]. "저감 확정"이 아니라 "개연성 높고 저위험". 실측 없이 배포하면 효과 미확인.
- **fake_func_sleep 전제** — 이 경로가 실제 재현이 아니면 P1·P5 대상이 달라짐(은수님 확인 필요).
- 부수 정정: `tdc_touch_time.h` 재부팅 카운트 주석(200ms) 낡음, IQS323-RESEED.md·적용가이드 문서 Full ATI 이전 세대(설계 근거로 부적합).
