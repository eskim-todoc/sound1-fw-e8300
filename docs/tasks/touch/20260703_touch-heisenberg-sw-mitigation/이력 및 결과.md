- **결론**: 현 셀프캡·현 HW·기존기능 유지, **SW 운영만으로 하이젠베르크 회피 가능**(회귀안전 레버 다수 — mutual No-go와 대조).

- **레버 판정**: 채택 유력 = S5 드라이브 하향(중~강)·S8/R7 0xC0 bit7. 조건부 = S1 변환주파수·S2 필터. 기각/보류 = S3 Events(에라타)·S4(H2 완화로 수렴)·S7 후보_1(100× 둔화)·S6-4(카운터화 필수).

- **산출물**: 요구사항·분석·계획·이력 + 에이전트-로그(00·C1·C2·S1~S8·V1~V8·인덱스·99).
