# 계획 — CalCap 더미 채널 구현

> **TL;DR**: 실패한 Internal Reference 방식(`0x43=0x0020`, reserved 위반)을 제거하고, CH1을 **내부 CalCap 부하**로 살리는 더미 채널로 재구현한다. 3개 레지스터(`0x40`·`0x44`·`0x43`)를 reset value 기준으로 설정하며, 모든 쓰기는 reset 베이스로 산출해 reserved 비트를 보존한다. ATI 수렴은 실측으로 확정한다.

근거·데이터시트 상세: [[crx1-esd-guard-분석]], [[iqs323-register-map]]

---

## 1. 목표

- CH1을 측정 사이클에 참여시켜, CH0 일시 disable(CRX0 방전) 중에도 IC measurement cycle을 유지한다.
- 외부 CRX1 핀의 C52(100nF) 유무·쇼트 여부와 **무관**하게 동작한다.
- CH1 ATI가 수렴해 `ATI_ERROR`를 유발하지 않는다.
- 기존 `TDC_TOUCH_CRX1_REF_ENABLE` / `TDC_TOUCH_CRX1_VSS_ENABLE` 분기와 상호 배타로 공존한다.

## 2. 비목표

- CH1의 측정값을 실제 환경 보정·터치 판정에 사용하지 않는다(순수 더미).
- HW 수정(C52 제거 등)을 전제하지 않는다.

---

## 3. 설계 — 레지스터 설정값 (reset 기준 산출)

| 주소 | 레지스터 | reset | 쓸 값 LSB/MSB | 변경 비트 |
|---|---|---|---|---|
| 0x40 | Sensor1 Setup | 0x0101 | **0x01 / 0x60** | Enable(bit0)=1, CalCap Rx(bit14)=1, CalCap Tx(bit13)=1, 외부 CTx0(bit8)=0 |
| 0x44 | Pattern1 Def | 0x030A | **0x2A / 0x03** | CalCap size(bit7-4)=2→1.0pF, Inactive Rxs=VSS 유지, Wav Pattern 0 유지 |
| 0x43 | Prox Input1 | 0x01CF | **건드리지 않음** | reset 유지(reserved 보존). CalCap Select(bit11)=0 |

> [!IMPORTANT]
> `0x43`은 **쓰지 않는다**. reset value가 이미 reserved 비트를 올바르게 설정(`0x01CF`)하고 CalCap Select=enabled(bit11=0) 상태다. 이전 먹통은 이 레지스터에 reset을 무시한 값을 써서 발생했으므로, 1차 구현에서는 0x43 쓰기를 배제한다.

### 불확실성 대응 (실측 분기)

- **CalCap size**: N=2(1.0pF) 출발 → ATI 미수렴 시 N 조정(최대 7).
- **CalCap Select 모순**: 1차는 reset(bit11=0) 유지. CalCap 측정 무반응 시 bit11 토글 실험.
- **외부 CRx0(0x43 bit8) 충돌**: 1차는 reset 유지. 측정 이상 시 CRx 비트 차단 실험.

## 4. 변경 파일

### 4.1 `tdc_touch_config.h`
- 기존 `TDC_TOUCH_CRX1_DUMMY_ENABLE` 주석을 **CalCap 방식**으로 갱신(Internal Reference 설명 제거).
- 상호 배타 `#error`는 그대로 유지(VSS·REF·DUMMY 3종 중 1개).

### 4.2 `tdc_drv_iqs323.h`
- 실패한 `PROX_INTERNAL_REF_MSB(0x20)` 상수 **제거**.
- `SENSOR1_PROX_INPUT(0x43)` 상수는 향후 실험용으로 유지하되 주석 보강(또는 제거 — 4.5 검토).
- CalCap 관련 상수 추가:
  ```c
  #define TDC_DRV_IQS323_REG_ADDR_SENSOR1_PATTERN_DEF  0x44
  #define TDC_DRV_IQS323_SENSOR_CALCAP_RX_TX_MSB       0x60  /* bit14|bit13 */
  #define TDC_DRV_IQS323_PATTERN_CALCAP_SIZE_1PF_LSB   0x2A  /* size=2 + Inactive Rxs VSS */
  #define TDC_DRV_IQS323_PATTERN_DEF_MSB               0x03  /* Wav Pattern 0 self-cap 유지 */
  ```

### 4.3 `tdc_drv_iqs323.c` — `sensor_setup()` DUMMY 분기 교체
```c
#elif TDC_TOUCH_CRX1_DUMMY_ENABLE
    /* CalCap 더미 채널 — 내부 CalCap을 변환 부하로 사용, 외부 CRX1 핀 완전 무관
     * (C52 유무·쇼트 무관). 목적: CH1 활성 유지 → CH0 discharge 시 measurement cycle 보존 */
    ci_printv("[TOUCH] SETUP PATTERN DEF 1 (CALCAP 1pF) \r\n");
    if (!write_and_verify(TDC_DRV_IQS323_REG_ADDR_SENSOR1_PATTERN_DEF,
                          TDC_DRV_IQS323_PATTERN_CALCAP_SIZE_1PF_LSB,
                          TDC_DRV_IQS323_PATTERN_DEF_MSB))
    {
        return false;
    }
    ci_printv("[TOUCH] SETUP SENSOR 1 (DUMMY, CALCAP RX/TX) \r\n");
    if (!write_and_verify(TDC_DRV_IQS323_REG_ADDR_SENSOR1_SETUP,
                          TDC_DRV_IQS323_CHANNEL_ENABLE,            /* LSB 0x01 */
                          TDC_DRV_IQS323_SENSOR_CALCAP_RX_TX_MSB))  /* MSB 0x60 */
    {
        return false;
    }
    /* 0x43(Prox Input)은 쓰지 않음 — reset 0x01CF가 reserved 비트·CalCap Select 올바름 */
    ci_printv("[TOUCH] SETUP CHANNEL 1 (INDEPENDENT) \r\n");
    if (!write_and_verify(TDC_DRV_IQS323_REG_ADDR_CHANNEL1_SETUP,
                          TDC_DRV_IQS323_CH_MODE_INDEPENDENT, 0x00))
    {
        return false;
    }
```
- 기존 `0x43`/`PROX_INTERNAL_REF` 쓰기 라인 제거.

## 5. 검증 계획

| 단계 | 방법 | 합격 기준 |
|---|---|---|
| 빌드 | 컴파일 | 에러·경고 0 |
| 초기화 | RTT 로그 | `0x40`·`0x44` write 성공, SENSOR/TOUCH/EVENTS/ATI/RESEED **FAIL 없음** |
| ATI 수렴 | RTT `ATI_ERROR` 미발생 | CH1 ATI 정상 |
| 오감지 | 무접촉 시 NOT_TOUCH 유지 | 자동 절전 진입 없음 |
| 터치 동작 | 실제 터치 시 TOUCH·LONG TOUCH | 정상 |
| 방전 동작 | `0x30` discharge write timeout 없음 | CH0 방전 + CH1 유지 양립 |
| ESD 먹통 | J 패드 문지른 후 회복 | 방전 효과 확인 |

미수렴/이상 시: §3 실측 분기(CalCap size·Select·CRx)대로 조정 후 재측정(상한 3회). 구조 변경 필요 시 재승인.

## 6. 롤백

문제 시 `TDC_TOUCH_CRX1_DUMMY_ENABLE=0`로 즉시 비활성(기존 동작 복귀). `CRX0_DISCHARGE_ENABLE`도 0이면 완전 원복.
