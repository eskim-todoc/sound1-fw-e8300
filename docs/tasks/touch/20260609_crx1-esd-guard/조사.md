# 조사 — CRX1 ESD 방전 경로 활용 가능성

**TL;DR**: IQS323은 전용 guard/shield 채널을 지원하지 않는다. 그러나 **"Inactive Rxs = VSS" 설정**으로 비활성 CRX 핀을 GND에 고정하거나, **Reference Channel 모드**로 환경 보정 기준값에 쓸 수 있다. 단, CRX1 경로에 직렬 C52(100nF)가 있어 DC 방전 경로를 만들려면 HW 수정 필수.

---

## 1. 가설 검증 결과

| 가설 | 결론 | 근거 |
|---|---|---|
| CRX1을 guard/shield 전극으로 설정 | ❌ 불가 | 데이터시트 전체에 guard/shield 레지스터 없음 |
| CRX1을 Reference 채널로 설정 | ✅ 가능 | Channel Setup 0x60~0x80 bits[3:0] = 0x02 (Reference 모드) |
| 비활성 CRX 핀을 GND(VSS)에 고정 | ✅ 가능 | Sensor Setup 0x30~0x50 — "Inactive Rxs" = VSS 설정 가능 |
| TxA를 Active Shield로 사용 | ❌ 불가 | TxA는 TX 구동 출력만 지원. 반전 구동(active shield) 미지원 |
| C52(100nF)를 통한 DC 방전 경로 | ❌ 불가 | 직렬 캐패시터는 DC 차단 → 정전기(DC) 방전 불가 |

---

## 2. 관련 레지스터 상세

### 2.1 Sensor Setup (채널별 0x30 / 0x40 / 0x50)

```
Bit 0   : Enable Channel — 0: disabled, 1: enabled
Bit 1   : Linearise Counts
Bit 2   : Dual Direction
Bit 3   : Invert
Bit 4   : Vbias
Bit 5   : FOSC Tx Frequency
Bit 11  : TxA enable
Bit 10-8: CTx0/CTx1/CTx2 enable
```

- **Inactive Rxs**: 비활성화된 CRX 핀의 전기적 상태 설정
  - `0x00`: Floating (기본값) — ⚠️ ESD에 취약
  - `0x05`: Bias voltage
  - `0x0A`: **VSS (GND)** — ✅ 정전기 방전 경로 생성 가능
  - `0x0F`: VREG

> [!IMPORTANT]
> **현재 기본값(Floating)은 비활성 CRX 핀을 플로팅 상태로 둔다.** 플로팅 핀은 ESD가 오히려 더 쉽게 누적된다. 최소한 VSS로 고정하는 것이 필요하다.

### 2.2 Channel Setup (채널별 0x60 / 0x70 / 0x80)

```
Bits [3:0] : Channel Mode
  0x00 : Independent  — 독립 채널 (현재 방식)
  0x01 : Follower     — 다른 채널 추종
  0x02 : Reference    — 환경 기준값 채널
Bits [7:4] : Reference Sensor ID (Reference 모드 시 기준 채널 선택)
```

### 2.3 Prox Input and Control (채널별 0x33 / 0x43 / 0x53)

```
Bits [10:8] : CRx0/CRx1/CRx2 enable (채널별 수신 핀 활성화)
Bit  13     : Internal Reference 활성화
```

## 3. 방법별 분석

### 방법 A — SW만으로 처리: Inactive Rxs = VSS

**동작 원리:**
- `sensor_setup()` 에서 CH1을 disable 상태로 두되, Inactive Rxs 필드를 `0x0A`(VSS)로 설정
- CRX1 핀이 IC 내부에서 GND에 고정됨

**현재 회로 경로:**
```
J4 패드 ── R32(0Ω) ── C52(100nF) ── CRX1(VSS)
```

**한계:**
- C52(100nF)가 직렬 → DC 차단
- 정전기(DC 성분)는 방전 불가
- 고주파 ESD(빠른 펄스)는 C52를 통해 일부 방전 가능하지만 효과 미미

**효과 평가:** ⚠️ 부분적 — 플로팅보다 낫지만 근본 해결 안 됨

---

### 방법 B — SW + HW 소규모 수정: C52 제거 또는 단락

**동작 원리:**
- C52(100nF)를 0Ω으로 교체(또는 제거 후 점프)
- 그 후 SW에서 CRX1을 VSS에 고정

**변경 후 회로 경로:**
```
J4 패드 ── R32(0Ω) ── [0Ω/NC] ── CRX1(VSS) ── GND
```

**효과:**
- J4 패드 → GND의 DC 방전 경로 생성
- J4 패드에 정전기가 쌓이면 즉시 GND로 방전
- J4 패드를 J3(터치 전극) 근처 PCB에 배치하면 J3의 ESD 흡수 효과 기대 가능

**HW 변경 범위:** C52 한 개 부품 변경 (0603 패드 그대로 사용)

**효과 평가:** ✅ 유망 — DC 방전 경로 실질적으로 생성됨

---

### 방법 C — SW만으로 처리: CRX1 Reference 채널 모드

**동작 원리:**
- CH1을 Reference 모드로 활성화 (Channel Mode = 0x02)
- CH1은 실제 터치 전극 없이 J4 패드의 환경 용량(온도·습도)을 측정
- CH0의 LTA 추적에 CH1 값을 반영해 환경 변화 보정

**한계:**
- Reference 모드는 **느린 환경 변화(온도·습도)** 보정용 — ESD 같은 급격한 변화에는 효과 없음
- ESD 자체를 방전하지 못하고, ESD 후 counts 드리프트를 빠르게 복구하는 효과만 기대 가능
- J4 패드가 J3 근처에 있어야 의미 있는 보정 가능 (동일 환경 노출)

**효과 평가:** ⚠️ 간접적 — ESD 발생 자체는 막지 못하나 회복 보조 가능

---

### 방법 D (권장 조합) — B + C 복합

1. **HW**: C52를 0Ω으로 교체 → J4 패드를 GND 방전 경로로 만듦
2. **HW**: J4 패드를 PCB 상에서 J3 터치 전극 주변(GND ring 형태)에 배치 → ESD를 J3 대신 J4가 흡수
3. **SW**: CRX1을 Reference 모드로 활성화 → 느린 환경 변화 CH0 보정
4. **SW**: apply_sleep_settings()에서도 CH1 Reference 모드 유지

---

## 4. 현재 회로 제약 요약

```
현재 상태:
  J4 ── R32(0Ω) ── C52(100nF) ── CRX1 (Floating/비활성)
                      ↑
                  DC 차단 장벽 — ESD 방전 불가

필요한 HW 변경:
  J4 ── R32(0Ω) ── [C52 → 0Ω] ── CRX1 (VSS 고정)
                                      ↓
                                  GND 방전 경로 생성
```

## 5. 결론 및 권장 방향

| 방법 | SW 변경 | HW 변경 | ESD 방전 효과 | 권장 순위 |
|---|---|---|---|---|
| A. Inactive Rxs = VSS | ✅ 최소 | ❌ 없음 | ⚠️ 미미 | 3위 |
| B. C52 제거 + CRX1 VSS | ✅ 최소 | ✅ 부품 교체 1개 | ✅ 실질적 | **1위** |
| C. Reference 채널 모드 | ✅ 보통 | ❌ 없음 | ⚠️ 간접 | 2위 |
| D. B + C 복합 | ✅ 보통 | ✅ 부품 교체 1개 | ✅✅ 최고 | **0위** |

**최종 권장:**
- 단기(즉시): 방법 A — SW만으로 Inactive Rxs = VSS 적용 (플로팅 방지, 효과 제한적)
- 중기(PCB 수정 시): 방법 D — C52 제거 + Reference 모드 + PCB J4 위치 재배치

> [!NOTE]
> IQS323은 guard/shield 전용 기능이 없다. 방법 D는 이 IC의 한계 내에서 가능한 최선이다. 근본적 ESD 보호는 J3 전극 근처에 ESD 보호 소자(TVS 다이오드 등) 추가가 필요하다.
