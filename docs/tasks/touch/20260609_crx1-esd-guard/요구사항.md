# 요구사항 — CRX1 ESD 방전 경로 활용 조사

**TL;DR**: 실제 제품에서 반복 절전 후 터치 먹통(ESD 누적)이 소프트웨어로 해결 불가능하다는 결론 이후, IQS323의 미사용 채널 CRX1(J4 연결 완료)을 활용해 HW·SW 복합 방법으로 문제를 완화할 수 있는지 조사한다.

---

## 배경 및 문제

- 실제 제품에서 2~3회 절전 모드 반복 후 터치 먹통 발생
- 먹통 상태 = 정전기 누적 → counts drift → delta > THRESHOLD → 항시 TOUCH 판정
- GND 쇼트 시 방전되어 정상화 → ESD가 원인으로 확인
- SW RESEED 3회 시도해도 해결 불가 (항시 TOUCH 상태이므로 비터치 구간 없음)
- **결론**: 하드웨어 보완 필요 (참고: `IQS323-RESEED.md`, `IQS323-회로-구성.md`)

현재 HW 상태:
- CRX1(A1) → C52(100nF) → R32(0Ω) → J4 (배선 완료, SW 비활성)
- TxA(B6) → R30(0Ω) → NC (미연결)

---

## 조사 목표

1. **IQS323 데이터시트 기반**: CRX1 채널을 guard electrode, 기준 채널(reference), 또는 차동 측정 채널로 구성하는 것이 가능한지 확인
2. **ESD 방전 원리 확인**: CRX1을 GND 방향으로 설정하거나 정적 방전 경로를 만들 수 있는지 확인
3. **SW 구현 가능성**: 기존 코드 변경 없이 또는 최소 변경으로 CRX1 활용 가능한지 평가
4. **HW 변경 필요 여부**: PCB 수정이 필요한지, 어느 범위인지 명확히 정리

---

## 범위

- **포함**: IQS323 채널 구성 레지스터 분석, guard/shield 관련 기능 확인, 차동 모드 확인
- **포함**: C52(100nF) 직렬 특성이 ESD 방전 경로로 적합한지 검토
- **제외**: PCB 레이아웃 직접 수정 (제안까지만, 실제 수정은 HW 팀)
- **제외**: 코드 구현 (조사 결과에 따라 별도 작업으로 분리)
