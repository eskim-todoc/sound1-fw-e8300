# 49 — v3 종합-재검증1 (30_종합-1차 + 41~48 통합 정제)

**TL;DR**: 30_종합-1차를 8개 adversarial 노드(41~48)로 공격한 결과를 통합 정제. 치명 결함 6건(회귀_1 ATI_SETUP 덮어쓰기·사후검증 race 방향 역전·충전 중 Re-ATI 구현 누락·MCLR POR 완전성 미검증·EEPROM 로드 경로 부재·Phase 3→1 #error 누락)을 수렴에 반영하고, 아키텍처 원리는 유지하되 구현 설계를 실질적으로 정제한다. 수렴도: **부분 수렴** — 아키텍처 원리는 확립됐으나 구현 전 해소 필수 항목이 6건 추가됐다.

---

## 1. 아키텍처 원리 재확인 (불변)

> **"공장 절대 기준으로 노터치를 판별하고, 노터치가 확인된 순간에만 Re-ATI를 허용한다."**

이 원리는 8개 adversarial 노드를 통해서도 **기각되지 않았다.** 원리 자체가 아닌 구현 세부에서 결함이 발굴됐다. 층위 구조는 30_종합-1차 §1-1을 유지하되 아래 정제 사항을 반영한다.

### 1-1. 층위 구조 (정제)

| 층위 | 담당 | 현재 상태 | 재검증 정제 |
|---|---|---|---|
| **층위 0 — Fixed 기저** | 공장 MULT/COMP를 매 부팅 적용 | 현재 존재(단일 고정값) | `write_ati_compensation()` 내 ATI_SETUP write 분기 필수(회귀_1 반영) |
| **층위 1 — 노터치 게이트** | Cold-Start Ambiguity 해소 | 미구현 | Phase 2(EEPROM) 선행 필수. GATE_ENABLE=1 + COUNTS=0 #error 강제(신규_A 반영) |
| **층위 2 — 조건부 Re-ATI** | 게인+baseline 전체 재보정 | 미구현 | EEPROM 로드→부팅 시 MULT/COMP 대체 경로 설계 필수(회귀_1·6 반영) |
| **층위 3 — 자기치유** | 손뗌 후 LTA IIR 수렴 | **Beta POR 미확정으로 동작 보장 불가** | 블로킹_D를 Phase 1 착수 전으로 격상(약점_2·약점_3 반영) |
| **층위 4 — 크래들 race 소멸** | 뚜껑 닫힘 = 노터치 보장 | 미구현 | 진입 시점 노터치 재확인 게이트 필요(공격_1 반영) |

### 1-2. 절전/부팅 통합 유지 (조건부 확정)

절전 복귀 = WDT 리셋 재부팅 → MCLR → Auto-ATI → 노터치 게이트.
**단**: MCLR이 IC LTA 레지스터를 포함한 전 레지스터를 POR 초기화하는지 데이터시트 §4.1/§5.5 미확인 → 절전 진입 RESEED 오염이 다음 부팅 게이트와 독립임을 근거 없이 단정 불가. **블로킹_G(신규)로 추가** — Phase 1 착수 전 확인 필수.

## 2. 치명 결함 6건 반영 (아키텍처 수정)

재검증1 8개 노드에서 새로 발굴된 치명/심각 결함 중, 아키텍처를 실질 변경하는 6건을 반영한다.

### 2-1. [치명] write_ati_compensation() ATI_SETUP 덮어쓰기 — Phase 3 무력화 (회귀_1)

**발굴**: 45_회귀. `iqs323.c:700` `write_ati_compensation()` 내부 선두에 `ATI_SETUP=0x08(Mode=Disabled)` write가 포함돼 있다. Phase 3에서 ATI Full을 활성화해도 매 재부팅 시 이 함수가 덮어쓴다 → Re-ATI 무력화.

**수정**: `write_ati_compensation()` 내 ATI_SETUP write를 빌드가드로 분기한다.

```c
/* iqs323.c:700 근방 수정 */
#if TDC_TOUCH_ATI_FULL_ENABLE
    /* ATI_SETUP: Mode=Full(bits[2:0]=011 또는 데이터시트 확인 후) */
    write_register(SENSOR0_ATI_SETUP, ATI_SETUP_FULL_LSB, ATI_SETUP_MSB);
#else
    /* ATI_SETUP: Mode=Disabled(0x08) — Fixed 기저 유지 */
    write_register(SENSOR0_ATI_SETUP, TDC_DRV_IQS323_ATI_SETUP_LSB, ATI_SETUP_MSB);
#endif
/* MULT/COMP는 항상 write (Fixed 기저 or EEPROM 로드값) */
```

> [!IMPORTANT]
> ATI_FULL_ENABLE=1일 때 ATI Mode Full 레지스터값은 데이터시트 §5.9 확인 후 확정 [확정 필요]. 코드 포함 전 실측 선행.

### 2-2. [치명] 사후 검증 재시도 3회 로직 역전 — 즉시 제거 (42_race·46_할루시)

**발굴**: 42·46. RESEED 완료 후 counts가 윈도우 이탈 = 정상 터치 진행 중 = LTA는 올바르게 noTouch로 seed된 상태. 재RESEED 3회는 오염을 반복하는 역효과.

**수정**: 사후 검증 재시도 3회 로직 전면 제거.

```
올바른 사후 검증 설계:
  RESEED 발행 완료 → counts 1회 재읽기
  → 윈도우 이탈(counts < lo): RTT 경보만 발행 ("race 가능성 있음. LTA IIR 자기치유 위임")
  → 재RESEED 없음. LTA IIR(Beta POR 확정 후)에 복구 위임.
  → 재시도 루프 구조 자체 삭제.
```

**추가 정정**: FACTORY_NOTOUCH_COUNTS=0 기본값 시 "단일 RESEED"라고 30_종합이 기술한 것은 GATE_ENABLE=0 경로(기존 무조건 RESEED 보존)를 설명한 것이지만, 코드 흐름 설명이 모순 가능하다. 명확화:
- `GATE_ENABLE=0`: 기존 무조건 RESEED 코드(`write_register(0xC0, 0x08, 0x00)`) 그대로 — gate_check() 호출 자체 없음.
- `GATE_ENABLE=1` + `COUNTS=0`: #error로 차단 필수 (신규_A 반영, 아래 §3 빌드가드 세트 참조).

### 2-3. [치명] EEPROM 로드 경로 부재 — Phase 2·3·4 무의미화 방지 (회귀_6)

**발굴**: 45_회귀. Phase 2에서 개별 보드 MULT/COMP를 EEPROM에 저장해도, 부팅 시 이를 로드해 `write_ati_compensation()` 내 컴파일 타임 상수를 대체하는 코드 경로가 30_종합-1차 설계 어디에도 없었다.

**수정**: Phase 2 설계에 EEPROM 로드 경로를 명시 추가한다.

```c
/* tdc_drv_iqs323_apply_settings() 내 수정 흐름 */
#if TDC_TOUCH_FACTORY_CALIB_ENABLE == 0  /* 공장 공정 아닌 일반 부팅 */
  if (tdc_touch_calib_load_eeprom(&calib)) {  /* EEPROM 유효 데이터 있으면 */
    s_mult_lsb = calib.mult_lsb;
    s_comp_lsb = calib.comp_lsb;
    /* write_ati_compensation()이 이 값을 사용하도록 전달 */
  }
  /* else: 컴파일 타임 고정 상수 사용 (현재 동작 유지) */
#endif
write_ati_compensation();  /* 항상 실행, 위 분기로 인자 결정 */
```

> [!IMPORTANT]
> 이 경로 없이 Phase 2 EEPROM 저장·Phase 4 Re-ATI 결과 저장은 모두 사문이다. Phase 2 착수 시 이 로드 경로를 함께 구현해야 한다.

### 2-4. [치명] 충전 중 Re-ATI 구현 경로 완전 누락 (41_repro·43_완전성·46_할루시)

**발굴**: 41·43·46. 달성도 "환경 드리프트 ✅"는 충전 중 주기 Re-ATI 구현을 전제하나, 코드 삽입 위치·타이머·트리거 경로가 전혀 기술되지 않았다.

**수정**:
- §4 달성도 표 "환경 드리프트" → **"△ (R3_CHARGING 구현 + Beta 실측 후)"**로 하향.
- Phase 3 계획에 R3_CHARGING 구현 최소 명세 추가:

```
R3_CHARGING: df_Connected=true 상태에서 30초 주기 Re-ATI
  트리거 위치: tdc_touch_process() 내 타이머(ci_timer_elapsed or 정적 카운터)
  구조: 비블로킹 선호 — re_ati_trigger() 발행 후 다음 폴링에서 ATI_Active 확인
        (블로킹 wait_re_ati_done()은 1초 race 창으로 사용 금지 — 42_race 공격_4)
  노터치 게이트: 30초 주기 도달 시 현재 counts로 게이트 통과 확인 후 트리거
  충전 중 터치 race: Re-ATI 도중 터치 → ATI_Error 핸들러 발동
```

> [!NOTE]
> R3_CHARGING 구현 위치는 Phase 3 착수 시 코드 read로 실제 라인 확정 필요.

### 2-5. [치명] MCLR 완전 POR 미검증 — 새 블로킹_G (42_race·43_완전성·45_회귀)

**발굴**: 42·43·45. 절전 진입 시 write된 레지스터(THRESHOLD=255 등)가 MCLR 후 완전 초기화되는지 데이터시트에서 확인되지 않았다. 잔존 시 부팅 게이트 counts 해석이 틀어진다.

**수정**: 블로킹_G(신규) 추가 — **Phase 1 착수 전 필수**:

| ID | 항목 | 해소 방법 |
|---|---|---|
| **블로킹_G** | IQS323 MCLR 후 전 레지스터(LTA·THRESHOLD 포함) POR 완전 초기화 여부 | 데이터시트 §3.4/§4.1/§5.5 확인 + 필요시 MCLR 후 THRESHOLD read 실측 |

### 2-6. [치명] Phase 3→1 #error 가드 누락 (47_엣지)

**발굴**: 47. `REATI_ON_NOTOUCH_ENABLE=1` + `NOTOUCH_GATE_ENABLE=0` 조합이 차단되지 않아 게이트 없이 Re-ATI가 실행되는 아키텍처 원리 파괴 경로가 가능하다.

**수정**: §3 빌드가드 세트에 추가:

```c
#if TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE && !TDC_TOUCH_NOTOUCH_GATE_ENABLE
#error "REATI_ON_NOTOUCH_ENABLE requires NOTOUCH_GATE_ENABLE (gate must precede Re-ATI)"
#endif
#if TDC_TOUCH_NOTOUCH_GATE_ENABLE && (TDC_TOUCH_FACTORY_NOTOUCH_COUNTS == 0u)
#error "NOTOUCH_GATE_ENABLE requires FACTORY_NOTOUCH_COUNTS != 0 (GATE_ENABLE=1+COUNTS=0 is invalid)"
#endif
```

## 3. 정제된 빌드가드 최종 세트 (tdc_touch_config.h)

```c
/* ===== Phase 0: 포화 감지 stub ===== */
#define TDC_TOUCH_SATURATE_DETECT_ENABLE     1u
#define TDC_TOUCH_SATURATE_MAX_COUNTS        0u  /* [확정 필요] 데이터시트+실측_E 후 교체 */

/* ===== Phase 1: 노터치 게이트 ===== */
#define TDC_TOUCH_NOTOUCH_GATE_ENABLE        0u  /* 블로킹_A+B+G 완료 후 1로 */

/* 단일 소스 기준값 (실측_A+방전실측_B 완료 전 0 유지) */
#define TDC_TOUCH_FACTORY_NOTOUCH_COUNTS     0u  /* [확정 필요] RTT 실측 후 */
#define TDC_TOUCH_NOTOUCH_MARGIN_STRICT      0u  /* [확정 필요] 하한, 수치 제안 금지(실측 기반만) */
#define TDC_TOUCH_NOTOUCH_MARGIN_UP          0u  /* [확정 필요] 상한, 드리프트 실측 후 */

/* ===== Phase 2: 공장 캘리브레이션 EEPROM 저장 (공장 공정 전용) ===== */
#define TDC_TOUCH_FACTORY_CALIB_ENABLE       0u

/* ===== Phase 3: Re-ATI + ATI_Error 핸들러 (항상 쌍) ===== */
#define TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE    0u  /* Phase 2 검증 + Beta POR 실측 후 */
#define TDC_TOUCH_ATI_FULL_ENABLE            0u  /* 위와 항상 동일값 */

/* ===== Phase 4: 크래들 Re-ATI + EEPROM 저장 ===== */
#define TDC_TOUCH_CRADLE_REATI_ENABLE        0u

/* ===== 컴파일 타임 의존성 강제 (전체 세트) ===== */
#if TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE && !TDC_TOUCH_ATI_FULL_ENABLE
#error "REATI_ON_NOTOUCH_ENABLE requires ATI_FULL_ENABLE"
#endif
#if TDC_TOUCH_CRADLE_REATI_ENABLE && !TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE
#error "CRADLE_REATI_ENABLE requires REATI_ON_NOTOUCH_ENABLE"
#endif
#if TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE && !TDC_TOUCH_NOTOUCH_GATE_ENABLE
#error "REATI_ON_NOTOUCH_ENABLE requires NOTOUCH_GATE_ENABLE"
#endif
#if TDC_TOUCH_NOTOUCH_GATE_ENABLE && (TDC_TOUCH_FACTORY_NOTOUCH_COUNTS == 0u)
#error "NOTOUCH_GATE_ENABLE requires FACTORY_NOTOUCH_COUNTS != 0"
#endif
```

> [!NOTE]
> 신규 6개 빌드가드와 기존 13개 define(`ATI_CALIB_MODE`, `CRX0_DISCHARGE_ENABLE` 등)의 네이밍 충돌 검토 필요. `FACTORY_CALIB_ENABLE`과 기존 `ATI_CALIB_MODE`의 역할 분리: ATI_CALIB_MODE는 "RTT 덤프 + 수동 캘리브", FACTORY_CALIB_ENABLE은 "공장 공정에서 자동 저장" — 별개 경로로 구분 유효.

## 4. 정제된 Phase 계획 (30_종합-1차 §2-1 수정판)

### Phase 0 — counts 포화 감지 stub (항상 ON)

- 위치: `tdc_touch_process()` 내 counts 읽기 후
- 임계 define: `TDC_TOUCH_SATURATE_MAX_COUNTS` (실측_E 전 데이터시트 값으로 초기화)
- 빌드가드: SATURATE_DETECT_ENABLE=1

### Phase 1 — 노터치 게이트 + RESEED 조건부

**삽입점**: `write_ati_compensation()` 항상 실행 유지, 이후 RESEED만 게이트화 (30_종합 §2-3 유지).

**단, 회귀_1 반영으로 `write_ati_compensation()` 내부 ATI_SETUP write 분기 필수** — Phase 1 구현 전 `iqs323.c:L696~` 전체 write 목록 확인(블로킹_F 해소) 선행.

**게이트 판별 (정제)**:
```c
static bool tdc_notouch_gate_check(uint16_t counts)
{
    /* GATE_ENABLE=1 + COUNTS=0 조합은 #error로 차단 — 이 경로는 비호출 */
    uint32_t lo = (uint32_t)TDC_TOUCH_FACTORY_NOTOUCH_COUNTS
                  - TDC_TOUCH_NOTOUCH_MARGIN_STRICT;  /* 터치 방향 엄격 */
    uint32_t hi = (uint32_t)TDC_TOUCH_FACTORY_NOTOUCH_COUNTS
                  + TDC_TOUCH_NOTOUCH_MARGIN_UP;
    return ((uint32_t)counts >= lo && (uint32_t)counts <= hi);
}
```

**사후 검증 (정제 — 재시도 3회 제거)**:
```
RESEED 발행 → counts 1회 재읽기
  → 윈도우 이탈: RTT 경보 발행 only ("race 추정, LTA IIR 자기치유 위임")
  → 재RESEED 없음
```

**MARGIN_STRICT 수치 제안 금지**: `TDC_TOUCH_NOTOUCH_MARGIN_STRICT` 초기값 0 유지. "Threshold의 40%=40" 제안은 단위 오용(delta 단위 vs counts 단위) — 실측_A 완료 전 임의 수치 설정 금지.

**선행 블로킹**: 실측_A(noTouch counts) + 실측_B(방전 효과, 실측_B → 실측_A 순서 의존) + **블로킹_G(MCLR POR 확인)** 완료 후.

**기존 `s_boot_touch_ignore`와의 공존**:
- 두 가드 역할 분리: 노터치 게이트는 RESEED 시점 사전 방어, `s_boot_touch_ignore`는 READY 전이 후 폴링 이벤트 사후 억제. 상보적으로 동작.
- 충돌 시나리오: 게이트 통과 후 올바른 RESEED 완료 → `s_boot_touch_ignore` 여전히 활성(직전 READY 전이 시 터치 이벤트 있었다면) → 터치 억제 구간 발생 가능. Phase 1 구현 시 상호 해제 조건 정합성 확인 필요 (확인_10 신규).

### Phase 2 — 공장 캘리브레이션 + EEPROM 저장·로드

**신규 추가**: 저장과 반드시 쌍으로 로드 경로 구현 (`tdc_drv_iqs323_apply_settings()` 내 EEPROM 로드 우선 적용).

**공장 치구 불량 감지**: `calib_store()` 내 noTouch counts 확인 외 추가로 ATI 완료 후 counts가 ATI Target 근방(±허용폭)인지 확인 — 터치 상태 공장캘리 결과를 EEPROM에 저장하는 오조작 차단.

선행 블로킹: 블로킹_C(CFX 파서 크기 확인) — 변경 없음.

### Phase 3 — Re-ATI + ATI_Error 핸들러

**신규 필수 추가**:
1. `write_ati_compensation()` 내 ATI_SETUP write 분기(§2-1 치명 결함 반영).
2. `wait_re_ati_done()` 내 SYS_WATCHDOG_REFRESH() 추가 — "명시 필요" 수준이 아닌 **함수 수정 필수 선행 사항**으로 격상. 기존 ATI_CALIB_MODE 경로도 동시 영향.
3. R3_CHARGING 최소 명세(§2-4) 포함 — 비블로킹 구조 선호.
4. ATI_Error 핸들러: `wait_re_ati_done()` 레이어와 상위 폴링 루프 레이어 중 어느 쪽에서 처리할지 명시. 재귀 호출 차단 구조 설계(ATI_Error 중 재트리거 차단 플래그).

**블로킹 격상**: 블로킹_D(Beta POR 실측)를 **Phase 1 착수 전**으로 격상 — Beta POR=0이면 자기치유 층 무효화 → 게이트 race 치명도 재평가 필수.

**wait_re_ati_done() 블로킹 시간 정정**: Sys_Delay 기준 최대 1초 + force_window_open 포함 최악 **~1.9초** (44_통신전력 발굴). 기존 "1초 확정"은 새로운 환각.

### Phase 4 — 크래들 Re-ATI + EEPROM 저장

- 삽입점 라인 번호 확인: "main.c:742" 환각 가능성 — 착수 전 `func_cradle_lid_closed_loop()` 호출 위치 grep 재확인 (확인_8 신규).
- 진입 시점 노터치 게이트 재확인: 크래들 진입 직전 counts 게이트 통과 확인 후 Re-ATI 수행.
- EEPROM write 완료 확인 후 뚜껑 열림 처리 또는 원자 write 보장.
- Phase 3와 동일하게 wait_re_ati_done() 내 WDT 갱신 포함.

## 10. 핵심 10줄

1. **아키텍처 원리 유지**: "공장 절대 기준 → 노터치 게이트 → Re-ATI"는 8 adversarial 노드를 통해 기각되지 않았다. 구현 세부에서 결함이 발굴됐을 뿐이다.
2. **치명 회귀_1 (write_ati_compensation ATI_SETUP 덮어쓰기)**: Phase 3 Re-ATI를 활성화해도 매 부팅 `write_ati_compensation()`이 ATI_SETUP을 Disabled로 덮어쓴다 — ATI_FULL_ENABLE 분기를 함수 내부에 추가하지 않으면 Phase 3 전체가 무의미하다.
3. **치명 EEPROM 로드 경로 부재**: Phase 2에서 보드별 MULT/COMP를 EEPROM에 저장해도 부팅 시 로드해 적용하는 코드 경로가 30_종합에 없었다 — 저장과 로드를 반드시 쌍으로 구현해야 "보드 편차 ✅"가 의미를 갖는다.
4. **사후 검증 재시도 3회 역전 제거**: RESEED 완료 후 counts 윈도우 이탈 = 정상 터치 진행 중 = 재RESEED 3회는 오염 반복. RTT 경보만 발행하고 LTA IIR 자기치유에 위임이 유일하게 올바른 설계다.
5. **블로킹_D Phase 1 착수 전 격상**: Beta POR=0이면 자기치유 층 전무 → RESEED 오염 후 delta 역전 상태 복구 불가 → 게이트 race 치명도가 "저확률"에서 "장시간 영향"으로 격상된다. 블로킹_D 해소 없이 Phase 1을 시작할 수 없다.
6. **블로킹_G 신규 (MCLR POR 완전성)**: 절전 진입 시 write된 THRESHOLD=255 등이 MCLR 후 잔존하면 부팅 게이트 counts 해석 전체가 틀어진다 — 데이터시트 §3.4/§4.1 확인 + 실측이 Phase 1 착수 전 필수.
7. **충전 중 Re-ATI 구현 방향**: R3_CHARGING은 비블로킹 구조(trigger → 다음 폴링에서 ATI_Active 확인)로 설계해야 1초 blocking race를 피한다. wait_re_ati_done() 블로킹 최악 ~1.9초(Sys_Delay 1초 + force_window_open ~0.9초)는 충전 중 터치 race 창으로 허용 불가다.
8. **#error 가드 3종 추가**: REATI_ON_NOTOUCH + !NOTOUCH_GATE 조합, NOTOUCH_GATE + COUNTS=0 조합 차단이 추가됐다 — 아키텍처 원리를 컴파일 타임에 강제하는 완전한 세트가 됐다.
9. **달성도 하향 2건**: "환경 드리프트 ✅" → "△ (R3_CHARGING 구현 후)", "게이트 race ✅" → "△ (블로킹_D 해소 전 미확정)"로 현실적 수준으로 정정.
10. **수렴도 판정**: 부분 수렴 — 아키텍처 원리는 확립됐으나 Phase 1 착수 전 필수 해소 항목(블로킹_D·G·F + ATI_SETUP 분기 설계 + EEPROM 로드 경로)이 6건 잔존한다. 2차 재검증에서 `TDC_TOUCH_RTT_TUNING` 분기 + stuck-touch 가드 + 비블로킹 Re-ATI 설계를 추가 공격 대상으로 삼을 것.
