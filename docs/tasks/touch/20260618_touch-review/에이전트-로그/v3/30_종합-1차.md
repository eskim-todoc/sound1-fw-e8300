# 30 — v3 1차 종합 (Fixed+Auto-ATI 하이브리드 아키텍처 초안)

**TL;DR**: 분석8·계획8·검증8을 통합해 단일 아키텍처 원리(공장 절대 기준 노터치 게이트 + 조건부 Re-ATI)를 확정하고, 검증8이 발굴한 결정적 결함·환각·실측 부재 항목을 모두 반영한 수정 Phase 계획과 블로킹 미지수 목록을 도출한다. 100% 달성은 물리적 불가이며 "ESD·부분 터치·CFX 미확인을 제외한 전 SW 층위 문제를 다층 방어로 실사용 무시 가능 수준으로 수렴"이 현실적 목표다.

---

## 1. 단일 아키텍처 원리 (분석8 수렴점)

> **"공장 절대 기준으로 노터치를 판별하고, 노터치가 확인된 순간에만 Re-ATI를 허용한다."**

이 조건 하나가 Fixed(부팅 안전·결정론적)와 Auto-ATI(보드 편차·환경 드리프트 흡수)의 약점을 교차 보완한다. 나머지 층위는 이 원리를 보완하는 방어막이다.

### 1-1. 층위 구조 (분석8 합의)

| 층위 | 담당 | 현재 상태 |
|---|---|---|
| **층위 0 — Fixed 기저** | 공장 캘리브 MULT/COMP를 항상 적용 → 최소 동작 보장 | 현재 존재(단일 고정값, 보드별 개별화 미완) |
| **층위 1 — 노터치 게이트** | Cold-Start Ambiguity 해소 · RESEED/Re-ATI 오염 방지 | **미구현. 공장 캘리브 EEPROM 선행 필수** |
| **층위 2 — 조건부 Re-ATI** | 게인(MULT/COMP)+baseline을 그 시점 환경으로 전체 재보정 | 미구현. 층위 1 선행 + ATI_Error 핸들러 동시 필수 |
| **층위 3 — 사후 검증·자기치유** | race 사후 검출·재시도 + 손뗌 LTA IIR 수렴 | 자기치유는 현재 내장(Beta POR [확정 필요]). 사후검증 미구현 |
| **층위 4 — 크래들 race 소멸** | 뚜껑 닫힘 = race-free 기회, 노터치 절대 보장 | 미구현. 공장 캘리브+EEPROM 저장 선행 |

### 1-2. 공장값의 역할 (핵심 제약 재확인)

- RESEED는 **현재 counts로만 seed 가능**(데이터시트 §5.5.1). 공장 저장값으로 LTA 직접 초기화 불가.
- 공장 noTouch counts는 "지금 터치 중인가"를 판별하는 **절대 잣대**로만 사용.
- 공장값 없으면 어떤 SW도 Cold-Start Ambiguity를 근본 해소할 수 없음.

### 1-3. 절전/부팅 통합 단순화 (04_절전재부팅통합 확정)

절전 복귀 = WDT 리셋 재부팅 → 별도 절전 복귀 핸들링 불요. 부팅 게이트 하나로 통합 처리.
절전 진입 RESEED(`iqs323.c:931~948`)는 ULP 루프 전용 — 복귀 후 baseline에 무관.

## 2. 정제된 Phase 계획 (검증8 전체 반영)

검증8(21~28)에서 발굴한 결정적 결함을 반영해 계획8(11~18)의 Phase 정의를 통합·정제한다.
**18_통합아키텍처가 마스터 Phase 정의** — 11·14 간 삽입점 이중 충돌(결함_1@22)을 해소한 단일 설계.

### 2-1. 수정 Phase 계획 (5단계)

```
Phase 0 — counts 포화 감지 stub (독립, 항상 ON)
  위치: tdc_touch_process() 내 counts 읽기 후
  크기: ~5줄 신설
  빌드가드: TDC_TOUCH_SATURATE_DETECT_ENABLE=1
  블로킹 실측: 실측_E(Max Counts) — Phase 0 이후 즉시

Phase 1 — 부팅 노터치 RESEED 게이트 (삽입점 통합)
  위치: tdc_drv_iqs323_apply_settings() 내
         write_ati_compensation() 실행 후, RESEED 무조건 write(L1147) 대체
  [!] 11번(write_ati_compensation 이전 삽입)과 14번(이후 삽입) 충돌 해소:
       → write_ati_compensation()은 항상 실행(Fixed 기저 유지)
       → 이후 RESEED만 게이트로 조건부 실행 (단순화, 보안)
  [!] write_ati_compensation() 스킵 시 운용 설정 누락 위험(결함_5@22): 함수 내부
       write 목록 전체 확인(L696~) 후 스킵 불가 레지스터 재검토 선행 필수
  기능:
    - FACTORY_NOTOUCH_COUNTS 범위 확인(레이어_1만, N샘플 레이어_2 제거 — race 창 확대 방지)
    - 통과 시 RESEED + 사후 검증(counts 재확인 1회, 재시도 max 3회)
    - 실패 시 RESEED 보류 → counts 회복 대기(timeout: BOOT_WAIT_MS)
    - timeout 시 저신뢰 폴백 RESEED + RTT 경보
  빌드가드: TDC_TOUCH_NOTOUCH_GATE_ENABLE=0 (기본)
  선행 블로킹: 실측_A(noTouch counts 절대값) + 실측_B(방전 효과) 완료 후 활성화
  [!] FACTORY_NOTOUCH_COUNTS 단일 define 소스: tdc_touch_config.h (11·14·18 분산 통합)
       — 실측 전 기본값 0, GATE_ENABLE=0 상태에서는 참조 안 됨
  [!] uint16_t overflow 방어: lo/hi 계산 시 uint32_t 캐스트 + Max Counts 상한 clamp
  [!] 부분 터치 방어: MARGIN_STRICT(하한) < Threshold/2 설정 — 하한을 상한보다 엄격히
       (결함_1@25: MARGIN=80이면 부분터치 counts가 윈도우 통과하여 LTA 오염)
  [!] FACTORY_NOTOUCH_COUNTS=0 기본값 시 사후검증 skip 및 단일 RESEED — 3회 retry 방지
       (결함_6@22: I2C 실패 시 RESEED 최대 3회 연속 발행 회귀)

Phase 2 — 공장 캘리브레이션 + EEPROM 저장·로드
  위치: 공장 공정 트리거(TDC_TOUCH_FACTORY_CALIB_ENABLE 확장)
  기능: Auto-ATI 1회 → MULT/COMP 읽기(calib_read_ati() 재활용,
         단 TDC_TOUCH_ATI_CALIB_MODE 동일 #if 가드 필수 — 결함_3@27: 런타임 미존재)
         → noTouch counts 읽기(apply_settings()+RESEED 완료 후 N×폴링 주기 대기)
         → 3값(MULT·COMP·Counts) + 매직넘버 0xCA1B EEPROM write
  구조체 타입: int×4(CFX 파서 호환) — uint16_t×4 사용 금지(결함_7@27: 12·18 불일치)
  빌드가드: TDC_TOUCH_FACTORY_CALIB_ENABLE=0 (공장 공정 전용)
  [!] 선행 블로킹 — CFX_확인 완료 전 cfx_cm3_sharedMemory.h 수정 절대 금지:
       CFX 파서 크기 확인 → 구조체 확장(옵션_A) vs nvmctrl 독립 저장(옵션_B) 결정
  [!] calib_store() 내부에 저장 전 noTouch Counts 정상 범위 확인 코드 필수
       (공정 작업자 오조작 방지)
  [!] 공장캘리 모드에서 노터치 게이트 RESEED bypass 빌드가드 분리
       (게이트 대기 최대 5초가 공장 저장 타이밍을 오염하는 결함_8@22 방지)

Phase 3 — 노터치 게이트 후 Re-ATI 활성 + ATI_Error 핸들러
  [!] TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE=1 시 TDC_TOUCH_ATI_FULL_ENABLE=1 동시 의무:
       tdc_touch_config.h에 #error 컴파일 타임 강제 필수 (결함_15@22, 결함_18_B@21)
  ATI_Error 핸들러: (void) ati_error 제거 → pressed==false 시 re_ati_trigger() 발행
                    pressed==true 시 s_ati_error_pending=true → 손뗌 후 재트리거
  Re-ATI 채택: write_ati_compensation() 이후 RESEED 대신 re_ati_trigger() + wait_re_ati_done()
  [!] wait_re_ati_done() 블로킹 = 최대 1초(10×100ms, 코드 확정):
       1.5초 기술은 환각(결함_2@27 — 13·18번 문서의 "1.5초" 전부 1초로 정정)
  [!] 블로킹 루프 내 SYS_WATCHDOG_REFRESH() 명시 삽입 필수 (결함_13_B@21, 결함_9@22)
  [!] Beta 레지스터(0xB0~0xB4) 실측 선행 필수 (결함_17@22, 결함_5@27):
       - Beta 레지스터 주소 [추정]값 코드 포함 금지 (결함_17@22: 틀리면 기존 레지스터 덮어씀)
       - POR default 미확인 상태로 write_filter_betas() 코드 포함 금지
       - Beta POR default 실측 후 드리프트 LTA 계획(15번) 재검토
  [!] s_auto_ati_timeout 상태 전달 방법 명시(결함_16@22):
       tdc_touch.c → tdc_drv_iqs323.c 레이어 경계 위반 없이 파라미터·반환값으로 전달

Phase 4 — 크래들 Re-ATI 연결
  위치: main.c:742 앞, led_force_fade_off() 직후
  [!] Phase 1 최소 RESEED 삽입은 뚜껑 닫힘 기간 I2C 중단으로 실질 이득 없음 (결함_3@22):
       → Phase 1 크래들 훅 구현 폐기, Phase 4로 통합
  [!] Re-ATI 결과는 WDT 리셋 재부팅 시 write_ati_compensation()에 덮어씌워짐:
       → Phase 4 = Re-ATI 실행 + 결과 EEPROM 저장 반드시 쌍으로 구현
  [!] SYS_WATCHDOG_REFRESH() 위치 확인 필수
  [!] wait_re_ati_done() 내 WDT 갱신 여부 확인 필수(결함_9@22): 크래들 진입 전 1초 블로킹
```

### 2-2. 빌드가드 최종 세트 (tdc_touch_config.h)

```c
/* Phase 0: 포화 감지 stub (항상 ON) */
#define TDC_TOUCH_SATURATE_DETECT_ENABLE     1u

/* Phase 1: 노터치 게이트 + RESEED 조건부 */
#define TDC_TOUCH_NOTOUCH_GATE_ENABLE        0u  /* 실측_A + 실측_B 완료 후 1로 */

/* Phase 2: 공장 캘리브레이션 EEPROM 저장 (공장 전용) */
#define TDC_TOUCH_FACTORY_CALIB_ENABLE       0u  /* 공장 공정에서만 1로 */

/* Phase 3: Re-ATI 조건부 활성 + ATI_Error 핸들러 (항상 쌍으로) */
#define TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE    0u  /* Phase 2 검증 후 1로 */
#define TDC_TOUCH_ATI_FULL_ENABLE            0u  /* 위와 항상 동일값 */

/* Phase 4: 크래들 Re-ATI + EEPROM 저장 (Phase 3 선행 필수) */
#define TDC_TOUCH_CRADLE_REATI_ENABLE        0u

/* 컴파일 타임 의존성 강제 */
#if TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE && !TDC_TOUCH_ATI_FULL_ENABLE
#error "REATI_ON_NOTOUCH_ENABLE requires ATI_FULL_ENABLE"
#endif
#if TDC_TOUCH_CRADLE_REATI_ENABLE && !TDC_TOUCH_REATI_ON_NOTOUCH_ENABLE
#error "CRADLE_REATI_ENABLE requires REATI_ON_NOTOUCH_ENABLE"
#endif

/* 단일 소스 기준값 (세 파일 분산 통합 — 11·14·18 기본값 512/450/400 모두 폐기) */
#define TDC_TOUCH_FACTORY_NOTOUCH_COUNTS     0u  /* [확정 필요] RTT 실측 후 교체 */
#define TDC_TOUCH_NOTOUCH_MARGIN_STRICT      0u  /* [확정 필요] 하한(부분터치 방어, <Threshold/2) */
#define TDC_TOUCH_NOTOUCH_MARGIN_UP          0u  /* [확정 필요] 상한(드리프트 허용폭) */
/* GATE_ENABLE=0이면 위 세 값은 참조 안 됨 — 0값 언더플로 위험 없음 */
```

### 2-3. apply_settings() 삽입점 통합 설계 (결함_1@22·결함_4@27 해소)

```
현재 iqs323.c:1141~1158 (tdc_drv_iqs323_apply_settings 말미):
  write_ati_compensation()         ← 항상 실행 유지 (Fixed 기저)
  write_register(RESEED, 0x08, 0x00) ← 이 줄만 아래로 교체 (결함_4@27: 삽입점은 write_ati_compensation 이후)

수정 후:
  write_ati_compensation()         ← 항상 실행 유지
#if TDC_TOUCH_NOTOUCH_GATE_ENABLE
  tdc_drv_iqs323_notouch_gate_reseed()  ← RESEED 게이트(레이어_1 + 사후검증)
#else
  write_register(0xC0, 0x08, 0x00)     ← 기존 무조건 RESEED 보존 (결함_6@22: 단일 발행)
```

## 3. 게이트 노터치 판별 메커니즘 정제 (검증8 반영)

### 3-1. 레이어_2·3 제거 결정

- 검증(결함_11_C@21, 결함_18_A@21): N샘플 안정성 확인이 race 창을 **오히려 확대**.
  레이어_2·3의 실익은 "race 감소"가 아닌 "노이즈 오통과 방지"이나, 노이즈 오통과보다 race 창 확대 위험이 크다.
- **채택**: 레이어_1(공장 기준 절대 윈도우) + 사후 검증(RESEED 직후 1회 재확인) 조합.

### 3-2. 부분 터치 방어 (결함_1@25 반영)

```c
/* 레이어_1 단방향 하한 강화: noTouch 방향(counts 높음)은 여유있게, 터치 방향(counts 낮음)은 엄격하게 */
static inline bool tdc_notouch_gate_check(uint16_t counts)
{
    if (TDC_TOUCH_FACTORY_NOTOUCH_COUNTS == 0u) { return false; }  /* 미캘리브 안전 거부 */
    uint32_t lo = (TDC_TOUCH_FACTORY_NOTOUCH_COUNTS > TDC_TOUCH_NOTOUCH_MARGIN_STRICT)
                  ? (uint32_t)TDC_TOUCH_FACTORY_NOTOUCH_COUNTS - TDC_TOUCH_NOTOUCH_MARGIN_STRICT
                  : 0u;
    uint32_t hi = (uint32_t)TDC_TOUCH_FACTORY_NOTOUCH_COUNTS + TDC_TOUCH_NOTOUCH_MARGIN_UP;
    /* MARGIN_STRICT < Threshold/2: 부분 터치를 노터치로 오판 방지 (결함_1@25) */
    return ((uint32_t)counts >= lo && (uint32_t)counts <= hi);
}
```

- `NOTOUCH_MARGIN_STRICT`(하한): Threshold(100)의 40% = 40 제안 [추정 — 실측_A 후 조정]
- `NOTOUCH_MARGIN_UP`(상한): 환경 드리프트 허용폭 [확정 필요 — 실측_A]
- uint32_t 캐스트로 overflow/underflow 방어 (결함_14_A@21 해소)
- MARGIN 80 = "Threshold의 80%" 근거는 무효(결함_2@23: Threshold는 delta값, MARGIN은 absolute counts 허용폭 — 단위·층위 다름)

### 3-3. 사후 검증 구현 명세 (결함_11_B@21 정정)

사후 검증의 목적: **RESEED 발행 전 노터치 판별~발행 사이 race 검출**
- race 방향: RESEED 발행 이전에 터치가 시작되면 LTA가 터치 counts로 오염.
- 사후 검증: RESEED 직후 counts를 재읽어 윈도우 이탈 시 → 재시도 필요(LTA IIR이 다시 오염됐으므로).
- 재시도 3회, 10ms 딜레이(Sys_Delay 시 WDT 갱신 여부 확인 필요 — 결함_16_B@21).
- FACTORY_NOTOUCH_COUNTS=0 기본값일 때: 사후검증 skip + 단일 RESEED (3회 retry 금지 — 결함_6@22).

## 4. 100% 근접 달성도 종합 평가

| 문제 | 해결 경로 | 달성도 |
|---|---|---|
| 부팅 터치 모호성(Cold-Start Ambiguity) | 공장 noTouch 절대 기준 → 부팅 즉시 판별 | ✅ (Phase 1·공장캘리 완료 후) |
| 보드 편차(감도 불균일) | 공장 개별 캘리브 MULT/COMP + Phase 3 Re-ATI | ✅ (Phase 2·3 완료 후) |
| 환경 드리프트(온도·경년) | Phase 3 Re-ATI + LTA IIR 런타임 추적 | ✅ (Phase 3 + Beta 실측 후) |
| 게이트 race | 크래들(소멸) · 사후 검증 · 자기치유 다층 | ✅ 충분히 낮은 확률 [추정] |
| ATI_Error 영구먹통 | Phase 3 ATI_Error 핸들러(re_ati_trigger()) | ✅ (Phase 3 완료 후) |
| counts 포화 침묵 실패 | Phase 0 포화 감지 stub + Phase 3 Re-ATI | ✅ (Phase 0 즉시 + Phase 3) |
| 부분 터치 모호성 | 절대 윈도우 단방향 엄격화 + timeout 완화 | △ 확률적 완화만 가능 |
| 물리 ESD 전하 누적 | 독립 트랙 (실측_B 후 결정) | 별도 — 이 아키텍처 범위 밖 |

**현실적 달성 목표**: ESD·부분 터치·CFX 미확인을 제외한 SW 층위 문제 전체를 다층 방어로 실사용 무시 가능 수준으로 수렴.

## 8. 핵심 결론 (10줄)

1. **단일 원리**: 공장 절대 기준으로 노터치 판별 후 Re-ATI 허용 — 이 조건 하나가 Fixed(안전)와 Auto-ATI(적응)를 결합한다.
2. **공장 캘리브레이션 EEPROM 저장이 전 아키텍처의 공통 선행 조건**: CFX 파서 확인 전 cfx_cm3_sharedMemory.h 수정 절대 금지. calib_read_ati()는 ATI_CALIB_MODE 가드 전용임을 인지하고 공장캘리 함수도 동일 가드로 묶어야 한다.
3. **Phase 1 삽입점 통합**: write_ati_compensation() 항상 실행 유지, 이후 RESEED만 게이트화 — 11·14번 이중 충돌 및 27번 삽입점 모순(결함_4@27) 해소.
4. **레이어_2·3(N샘플 안정성) 제거 + 부분터치 단방향 엄격화**: race 창을 줄이는 것이 아니라 늘린다 — 레이어_1 하한엄격(MARGIN_STRICT) + 사후 검증 1회로 단순화.
5. **ATI_Error 핸들러와 Re-ATI 활성은 항상 쌍**: #error 컴파일 타임 강제로 단독 활성화 차단.
6. **wait_re_ati_done() = 최대 1초(10×100ms, 코드 확정)**: 1.5초 기술은 환각(결함_2@27) — 모든 블로킹 루프에 SYS_WATCHDOG_REFRESH() 명시 필요.
7. **Beta POR default 실측이 Phase 3 전 블로킹**: 0이 아니면 자기치유·드리프트 전 분석 재검토. Beta 레지스터 주소도 추정값 코드 포함 금지(결함_17@22).
8. **구조체 타입·기준값 단일화 3건**: ① ST__CFX_CM3_TouchCalib = int×4(결함_7@27), ② FACTORY_NOTOUCH_COUNTS = tdc_touch_config.h 단일 소스 0값 기본, ③ MARGIN = 실측 기반(Threshold 80% 근거 무효 — 결함_2@23).
9. **크래들 Phase 1 RESEED 삽입 폐기**: 뚜껑 닫힘 기간 I2C 중단으로 dead code — Phase 4 Re-ATI+EEPROM와 쌍으로만 구현.
10. **100% 불가, 다층 방어로 충분히 낮음 수렴**: ESD·부분 터치·race 원천 제거는 물리 한계 — 크래들(race 소멸) × 사후 검증 × 자기치유 × ATI_Error 핸들러 조합으로 실사용 무시 가능 수준 달성 가능.
