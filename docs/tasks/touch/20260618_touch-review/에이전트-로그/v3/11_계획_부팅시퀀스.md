# 11 — 계획: 부팅 baseline 시퀀스 재설계

**TL;DR**: 매 부팅(MCLR→Auto-ATI 완료) 직후 공장 noTouch 절대 기준으로 노터치를 판별하고, 노터치 확정 시 Auto-ATI 산출 MULT/COMP를 채택(또는 RESEED 허용), 터치 의심 시 고정값 폴백+RESEED 보류→손뗌 대기 순서로 흐른다. 핵심 삽입점은 `tdc_drv_iqs323.c`의 `apply_settings()` 내 `write_ati_compensation()` 호출 직전이며, 빌드가드 `TDC_TOUCH_BOOT_GATE_ENABLE`로 단계 분리한다.

## 1. 설계 목표

**단기(Phase 1 — 현 Sprint)**:
- 부팅 시 noTouch 여부 판별 후 RESEED 게이트 적용
- 공장 절대 기준 없이 현행 고정 MULT/COMP 기준으로 1차 구현(RTT 실측으로 기준값 추후 확정)
- ATI Mode = Disabled 유지 (ATI Full 전환은 Phase 2 이후)

**중기(Phase 2 — 다음 Sprint)**:
- 공장 캘리브레이션 EEPROM 저장·로드 + FACTORY_NOTOUCH_COUNTS 확정
- Re-ATI 게이트 활성화 (RESEED 대신 Re-ATI로 업그레이드)
- ATI_Error 핸들러 `TDC_TOUCH_ATI_FULL_ENABLE` 빌드가드로 준비

**장기(Phase 3 이후)**:
- 크래들 뚜껑 닫힘 Re-ATI 훅 삽입
- 충전 중 주기 Re-ATI 기회창 활용

## 3. 코드 위치 및 삽입 계획

### 3-1. 핵심 삽입점 — `tdc_drv_iqs323.c`

**현재 흐름** (`iqs323.c:1141~1158` 추정, apply_settings 말미):

```c
/* 현재 */
write_ati_compensation();                          /* 고정 MULT/COMP + ATI_SETUP write */
write_register(0xC0, 0x08, 0x00);                 /* RESEED 무조건 (iqs323.c:1147) */
write_register(0xC0, TDC_..._CH_TIMEOUT_OFF, 0x00); /* CH timeout 비활성 (iqs323.c:1155) */
```

**변경 후**:

```c
#if TDC_TOUCH_BOOT_GATE_ENABLE
    /* [노터치 게이트] Auto-ATI 결과 조건부 채택 */
    if (!s_auto_ati_timeout && !s_auto_ati_error) {
        uint16_t counts = read_ch0_filtered_counts();   /* 0x13 레지스터 */
        if (tdc_notouch_gate_check(counts)) {
            /* 채택 경로: ATI_SETUP(Mode=Disabled)만 write, MULT/COMP 유지 */
            write_register(ATI_SETUP_ADDR, ATI_SETUP_LSB, ATI_SETUP_MSB);
            ci_printi("[TOUCH] BOOT-GATE: Auto-ATI 채택 counts=%u\r\n", counts);
            s_boot_gate_result = TDC_BOOT_GATE_ADOPTED;
        } else {
            /* 폴백 경로: 고정값 전체 write */
            write_ati_compensation();
            ci_printw("[TOUCH] BOOT-GATE: Fixed 폴백 counts=%u\r\n", counts);
            s_boot_gate_result = TDC_BOOT_GATE_FALLBACK;
        }
    } else {
        /* Auto-ATI 실패: 고정값 전체 write */
        write_ati_compensation();
        ci_printw("[TOUCH] BOOT-GATE: Auto-ATI 실패(timeout/err) → Fixed\r\n");
        s_boot_gate_result = TDC_BOOT_GATE_FALLBACK;
    }

    /* RESEED 게이트 */
    if (s_boot_gate_result == TDC_BOOT_GATE_ADOPTED) {
        tdc_drv_iqs323_reseed_with_verify();       /* 사후검증 포함 RESEED */
    } else {
        tdc_drv_iqs323_reseed_with_wait_recovery(); /* 손뗌 대기 → 회복 시 RESEED */
    }
#else
    /* 기존 동작 보존 */
    write_ati_compensation();
    write_register(0xC0, 0x08, 0x00);
#endif

    write_register(0xC0, TDC_..._CH_TIMEOUT_OFF, 0x00); /* CH timeout 비활성 — 항상 유지 */
```

### 3-2. 신규 함수 목록 (tdc_drv_iqs323.c)

| 함수명 | 역할 | 근거 노드 |
|---|---|---|
| `read_ch0_filtered_counts()` | 0x13 레지스터 CH0 Filtered Counts 읽기. `tdc_drv_iqs323_check_touch_margin()`(`:1208`)에서 이미 동일 레지스터 접근 — 공통 함수로 추출 | 02_공장캘리 §2-2 |
| `tdc_notouch_gate_check(uint16_t counts)` | counts ∈ [FACTORY_NOTOUCH ± MARGIN] 판별. Phase 1에서 고정값 기반, Phase 2에서 EEPROM값으로 교체 | 05_노터치게이트메커 §1·§5 |
| `tdc_drv_iqs323_reseed_with_verify()` | RESEED 발행 후 즉시 counts 재확인(사후검증). 이탈 시 최대 3회 재시도 | 07_사후검증자기치유 §2 |
| `tdc_drv_iqs323_reseed_with_wait_recovery()` | RESEED 보류 → counts 윈도우 복귀 폴링 → 복귀 시 RESEED. N초 timeout 시 저신뢰 폴백 RESEED | 01_부팅ATI게이트 §3-4, 05_노터치게이트메커 §4 |

### 3-3. 상수·파라미터 (tdc_touch_config.h 또는 tdc_drv_iqs323.h)

```c
/* [Phase 1 임시값 — 실측5 후 확정 필요] */
#define TDC_TOUCH_FACTORY_NOTOUCH_COUNTS   (512U)   /* ATI Target 기준 추정 [추정] */
#define TDC_TOUCH_NOTOUCH_MARGIN           (80U)    /* TOUCH_THRESHOLD(100)의 80% [추정] */
#define TDC_TOUCH_BOOT_WAIT_RECOVERY_MS    (5000U)  /* 손뗌 대기 최대 시간 */
#define TDC_TOUCH_RESEED_VERIFY_RETRY      (3U)     /* 사후검증 재시도 횟수 */
#define TDC_TOUCH_RESEED_VERIFY_DELAY_MS   (10U)    /* 재시도 간 딜레이 */
```

> [!IMPORTANT]
> **`FACTORY_NOTOUCH_COUNTS = 512`는 추정값이다.** ATI_SETUP_MSB=0x04(ATI Base=100)에서 ATI Target = ATI Base × (ATI_Resolution_Factor/16) 계산이 필요하며 [확정 필요]. RTT 실측(`tdc_drv_iqs323_check_touch_margin()` 로그의 Counts 값 확인)으로 실제 noTouch counts를 측정한 뒤 이 값을 교체해야 한다.

## 4. 빌드가드 체계

| 빌드가드 | 활성 조건 | 역할 |
|---|---|---|
| `TDC_TOUCH_BOOT_GATE_ENABLE` | Phase 1 활성(기본 OFF) | 부팅 노터치 게이트 전체 활성화 |
| `TDC_TOUCH_FACTORY_CALIB_ENABLE` | Phase 2 공장 캘리브레이션 구현 후 | EEPROM 저장·로드, FACTORY_NOTOUCH_COUNTS를 런타임 로드로 교체 |
| `TDC_TOUCH_ATI_FULL_ENABLE` | Phase 2+ Re-ATI 활성화 시 | RESEED → Re-ATI 업그레이드, ATI_Error 핸들러 활성화 |

**단계별 빌드 구성**:

```
Phase 1: BOOT_GATE_ENABLE=1, FACTORY_CALIB_ENABLE=0, ATI_FULL_ENABLE=0
          → 고정값 기준 노터치 게이트 + RESEED 조건부 실행
Phase 2: BOOT_GATE_ENABLE=1, FACTORY_CALIB_ENABLE=1, ATI_FULL_ENABLE=0
          → EEPROM 공장값 기준 게이트 + RESEED
Phase 2+: BOOT_GATE_ENABLE=1, FACTORY_CALIB_ENABLE=1, ATI_FULL_ENABLE=1
           → 공장값 게이트 + Re-ATI + ATI_Error 핸들러
```

`tdc_touch_config.h`에 3개 define을 신설하고, 현재는 **전부 0(기존 동작 보존)**으로 시작해 검증 후 순차 활성화한다.

## 5. 절전 경로와의 관계 (04_절전재부팅통합 수렴)

절전 복귀 = WDT 리셋 재부팅이므로:

- **절전 복귀 부팅은 일반 부팅과 동일 경로로 처리** — 위 §2 시퀀스가 그대로 적용된다.
- **절전 진입 RESEED(`iqs323.c:945`)는 변경 불요** — ULP 루프 전용이며 복귀 후 baseline에 무관함.
- 절전 전용 baseline 복원 로직, EEPROM LTA 저장 등 별도 핸들링이 불필요하다는 것이 단순화의 핵심.

## 6. 크래들 연동 (향후 Phase 4)

03_크래들기회·05_노터치게이트메커 수렴:

- **현재 스프린트 범위 밖** — Phase 4로 분리

## 9. 위험 및 완화

| 위험 | 설명 | 완화 |
|---|---|---|
| `FACTORY_NOTOUCH_COUNTS` 오설정 | 실측 전 추정값으로 구현 시 게이트가 항상 실패 또는 항상 통과 | Phase 1은 `TDC_TOUCH_BOOT_GATE_ENABLE=0`(기존 동작) 기본값으로 시작, RTT 실측 후 값 확정 → 플래그 활성화 |
| RESEED 사후검증 tolerance 오설정 | 너무 좁으면 정상 드리프트를 race로 오판 → 불필요 재시도 | `MARGIN`의 50% 수준에서 보수적 출발, 실측 후 조정 |
| 게이트 race (μs~수 ms) | 노터치 판별~RESEED 사이 터치 시작 | 사후검증(즉시 재확인) + 자기치유(LTA IIR 손뗌 후 수 초 내 수렴) + 저확률(μs 간격) |
| write_ati_compensation() 내 ATI_SETUP만 write 분리 | 기존 함수 내부를 조건부로 갈라야 함 — 오선택 시 MULT/COMP가 덮어써짐 | 신규 `write_ati_setup_only()` 함수 분리, 기존 `write_ati_compensation()`은 유지 |
| 회귀: 기존 동작 파괴 | 빌드가드 OFF 시에도 기존 코드가 실행돼야 함 | `#else` 분기에 기존 코드 원본 그대로 유지 |

## 11. 핵심 결론 (7줄)

1. **삽입점 확정**: `tdc_drv_iqs323.c` `apply_settings()` 내 `write_ati_compensation()` 호출 직전이 유일한 노터치 게이트 삽입 기회창이며, 이 지점 이후 RESEED(`iqs323.c:1147`)를 조건부로 교체한다.
2. **채택 경로**: Auto-ATI 완료 + counts ∈ [FACTORY_NOTOUCH±MARGIN] → `ATI_SETUP`(Mode=Disabled)만 write하고 MULT/COMP는 Auto-ATI 산출값 그대로 유지 → RESEED 허용(사후검증 포함).
3. **보류 경로**: Auto-ATI timeout / ATI_Error / counts 이탈(터치 의심) → `write_ati_compensation()` 전체 실행(고정값 폴백) → RESEED 보류 → counts 회복 대기(N초 timeout 시 저신뢰 폴백 RESEED).
4. **빌드가드**: `TDC_TOUCH_BOOT_GATE_ENABLE=0` 기본값 → 기존 동작 완전 보존. 실측으로 `FACTORY_NOTOUCH_COUNTS`·`NOTOUCH_MARGIN` 확정 후 활성화.
5. **절전 통합**: 절전 복귀=WDT 리셋 재부팅이므로 위 시퀀스 하나로 두 경우 모두 처리, 절전 전용 baseline 복원 로직 불요.
6. **사후 방어 유지**: `s_boot_touch_ignore`(tdc_touch.c:46)는 변경 없이 유지 — 사전 방어(게이트) + 사후 방어(ignore) 이중 구조.
7. **선행 실측 필수**: `FACTORY_NOTOUCH_COUNTS` 절대값은 RTT로 노터치 확정 환경의 Counts 분포를 측정해야 확정 가능 — 이것 없이 게이트를 활성화하면 항상 폴백하거나 항상 채택하는 극단이 발생한다.
