# 12_계획_공장캘리저장 — 공장 캘리브값 EEPROM 저장/로드 구현 설계

**TL;DR**: 공장초기화 시 노터치 Auto-ATI로 MULT(16b)·COMP(16b)·noTouch Counts(16b)·매직넘버 0xCA1B를 획득하고, `cfx_cm3_sharedMemory`의 `userSettingValue` 구조체를 확장해 기존 CFX EEPROM 경로(`setReadWriteMapDataFlashCommand`)로 저장한다. 매 부팅에서 `tdc_touch_init_begin()` 진입 시점에 이미 공유 메모리 로드가 완료돼 있으므로(`initialize.c:345` → `:449` 순서 보장) 즉시 참조 가능하다. 저장값의 유효성은 매직넘버로 판별하고, 없으면 기존 무조건 RESEED로 폴백한다.

---

## 1. 구현 전제 재확인

| 전제 | 코드 위치 | 함의 |
|---|---|---|
| CFX_EEPROM 로드(`CFX_EEPROM_data_is_Loaded=1`) → touch init 순서 | `initialize.c:344~345` (EEPROM 로드), `:449` (touch init) | touch init 진입 시 공유 메모리 값 유효 |
| MULT/COMP 읽기 함수 기구현 | `tdc_drv_iqs323.c:820` — `tdc_drv_iqs323_calib_read_ati()` | 신규 구현 불필요, 재활용 |
| noTouch Counts 읽기 경로 존재 | `tdc_drv_iqs323.c:1208` — `read_register(REG_ADDR_CH0_FILTERED_COUNTS, ...)` | 동일 패턴으로 신규 helper 추가 |
| CFX EEPROM write 경로 | `cfx_cm3_sharedMemory.h:335~336` — `setReadWriteMapDataFlashCommand()` + `isReadWriteMapDataFlashCommandDone()` | 기존 경로 그대로 활용 |
| `userSettingValue` 구조체 | `cfx_cm3_sharedMemory.h:89~98` — `int` 7필드 | 3필드(`int` 3개) 확장 또는 별도 touch calib 구조체 신설 |
| `TDC_TOUCH_ATI_CALIB_MODE` 빌드 플래그 | `tdc_touch_config.h:46` | 공장캘리 실행 분기로 확장 가능 |

## 2. 저장 데이터 포맷 설계

### 2-1. 저장 구조체 (신규)

```c
/* cfx_cm3_sharedMemory.h — 추가 위치: ST__CFX_CM3_SharedMemory_userSettingValue 아래 */
typedef struct
{
    int touch_calib_magic;          /* 완료 판별: 0x_CA1B, 미캘리브=0 */
    int touch_mult;                 /* Auto-ATI MULT (16b little-endian, int로 저장) */
    int touch_comp;                 /* Auto-ATI COMP (16b little-endian, int로 저장) */
    int touch_noTouch_counts;       /* noTouch 절대기준 CH0 Filtered Counts */
} ST__CFX_CM3_TouchCalibValue;
```

> [!IMPORTANT]
> **int 타입 사용 이유**: `userSettingValue` 구조체의 기존 7필드 모두 `int`다. CFX 측 파서가 필드 단위 `int` 배열로 처리할 가능성이 높으므로 `uint16_t` 대신 `int`를 사용해 정렬 불일치를 방지한다. [확정 필요: CFX 측 파서 코드 리뷰]

### 2-2. 매직넘버 선택

- 값: `0xCA1B` (CALiBration 약어 — 한자 없음)
- POR default는 플래시 미기록 시 `0x0000` 또는 `0xFFFF` — 어느 쪽과도 충돌 안 함 [추정: 플래시 erase default=0xFF → `0xFFFF`와 충돌 없음 확인 필요]
- 유효성 체크: `touch_calib_magic == 0x0000CA1B` 이면 유효, 그 외 무효 → 폴백

### 2-3. 범위 유효성 체크 (무효 판별 보완)

```c
/* 정상 범위 [추정 — 실측5 후 조정] */
#define TDC_TOUCH_CALIB_MAGIC         0x0000CA1BU
#define TDC_TOUCH_CALIB_COUNTS_MIN    50    /* noTouch counts 하한 [추정] */
#define TDC_TOUCH_CALIB_COUNTS_MAX    950   /* noTouch counts 상한 [추정] */
```

### 3-1. 옵션 비교

| 옵션 | 방법 | 권고 여부 |
|---|---|---|
| **옵션_A (권고)**: `userSettingValue` 구조체에 touch calib 필드 추가 | `cfx_cm3_sharedMemory.h:89~98`에 `ST__CFX_CM3_TouchCalibValue` 필드 직접 추가 또는 멤버 변수 추가 | **권고** — CFX EEPROM 기존 경로 재사용, write 1회로 전체 저장 |

## 4. 저장 트리거 — 공장초기화 시퀀스

### 4-1. 트리거 조건

- BLE 공장초기화 패킷 수신 (수술위치=3, `remoteControl.c:171` 분기)
- 또는 `TDC_TOUCH_ATI_CALIB_MODE=1` 빌드 플래그 하 전용 캘리브레이션 루프

**전제**: 공장 치구 또는 크래들 닫힘 환경에서 **노터치 보장** 상태에서만 실행.

### 4-2. 저장 시퀀스 (신규 함수 `tdc_drv_iqs323_calib_store()`)

```c
/* 구현 위치: tdc_drv_iqs323.c (TDC_TOUCH_ATI_CALIB_MODE 블록 내) */
bool tdc_drv_iqs323_calib_store(void)
{
    /* 1. MCLR 리셋 → Auto-ATI 완료 대기 (기존 init 시퀀스 그대로) */
    /* → 이 시점에서 MULT/COMP는 Auto-ATI 산출값이 레지스터에 존재 */

    /* 2. MULT/COMP 읽기 (기존 함수 재활용) */
    uint16_t mult, comp;
    if (!tdc_drv_iqs323_calib_read_ati(&mult, &comp))
    {
        ci_printe("[TOUCH] FACTORY CALIB: MULT/COMP READ FAIL\r\n");
        return false;
    }

    /* 3. apply_settings() 실행 (운용 설정 적용 + RESEED) */
    /* → 고정값 write → ATI Disabled 설정 */

    /* 4. 안정화 대기 (~50ms) */
    {
        int t0 = ci_timer_get_tick();
        while ((ci_timer_get_tick() - t0) < 50)
        {
            SYS_WATCHDOG_REFRESH();
        }
    }

    /* 5. noTouch Counts 읽기 */
    uint8_t lsb, msb;
    if (!read_register(TDC_DRV_IQS323_REG_ADDR_CH0_FILTERED_COUNTS, &lsb, &msb))
    {
        ci_printe("[TOUCH] FACTORY CALIB: COUNTS READ FAIL\r\n");
        return false;
    }
    uint16_t no_touch_counts = ((uint16_t)msb << 8) | lsb;

    ci_printw("[TOUCH] FACTORY CALIB: mult=0x%04X comp=0x%04X counts=%u\r\n",
              mult, comp, no_touch_counts);

    /* 6. 공유 메모리에 기록 → CFX EEPROM write */
    cfx_cm3_sharedMemoryAll.userSettingValue.touch_calib_magic      = (int)TDC_TOUCH_CALIB_MAGIC;
    cfx_cm3_sharedMemoryAll.userSettingValue.touch_mult             = (int)mult;
    cfx_cm3_sharedMemoryAll.userSettingValue.touch_comp             = (int)comp;
    cfx_cm3_sharedMemoryAll.userSettingValue.touch_noTouch_counts   = (int)no_touch_counts;

    ST__CFX_CM3_SharedMemory_ReadWriteCommand_ForFlash cmd = {
        .flashCommand = flash_Command_Write,
        .isd_index    = 0,   /* [확정 필요: ISD 인덱스 결정] */
        .map_index    = 0
    };
    setReadWriteMapDataFlashCommand(cmd);

    /* 완료 폴링 (최대 TDC_TOUCH_INIT_TIMEOUT_MS) */
    int t0 = ci_timer_get_tick();
    while (!isReadWriteMapDataFlashCommandDone())
    {
        SYS_WATCHDOG_REFRESH();
        if ((ci_timer_get_tick() - t0) > TDC_TOUCH_INIT_TIMEOUT_MS)
        {
            ci_printe("[TOUCH] FACTORY CALIB: EEPROM WRITE TIMEOUT\r\n");
            return false;
        }
    }

    ci_printw("[TOUCH] FACTORY CALIB: EEPROM WRITE OK\r\n");
    return true;
}
```

> [!NOTE]
> `TDC_DRV_IQS323_REG_ADDR_CH0_FILTERED_COUNTS` 레지스터 주소(0x13)는 `tdc_drv_iqs323.c:1208`에서 이미 사용 중. `read_register()` static 함수이므로 동일 파일 내 구현 가능.

### 4-3. MULT/COMP 읽기 최적 타이밍

```
MCLR → Auto-ATI 완료(is_auto_ati_done 폴링) → [★ 여기서 MULT/COMP 읽기]
  → apply_settings() (고정값으로 덮어씀) → RESEED → [★ 50ms 후 noTouch Counts 읽기]
```

- MULT/COMP: `apply_settings()` 이전이 유일한 기회. `tdc_touch.c:try_finish_init()` 내 Auto-ATI 완료 직후.
- noTouch Counts: RESEED 완료 후 50ms 안정화 후. [추정: 50ms는 LTA IIR 1스텝 이상 대기]

## 5. 부팅 로드 경로 — 매 부팅 RESEED 게이트 적용

### 5-1. 로드 순서 (코드 확인됨)

```
initialize.c:344~345  — ci_filesystem_copy_isd_info...() + CFX_EEPROM_data_is_Loaded=1
  (이 시점에서 cfx_cm3_sharedMemoryAll.userSettingValue 유효)
initialize.c:449      — tdc_touch_init_begin() 호출
  → tdc_touch.c:try_finish_init() 내에서 공유 메모리 참조 가능
```

**부팅 로드 순서가 이미 보장됨** — 추가 순서 제어 불필요.

### 5-2. 로드 함수 (신규 `tdc_drv_iqs323_calib_load()`)

```c
/* 구현 위치: tdc_drv_iqs323.c */
typedef struct {
    bool     valid;               /* 매직넘버 + 범위 체크 통과 여부 */
    uint16_t mult;
    uint16_t comp;
    uint16_t no_touch_counts;
} tdc_touch_calib_data_t;

bool tdc_drv_iqs323_calib_load(tdc_touch_calib_data_t *p_out)
{
    const int magic  = cfx_cm3_sharedMemoryAll.userSettingValue.touch_calib_magic;
    const int mult   = cfx_cm3_sharedMemoryAll.userSettingValue.touch_mult;
    const int comp   = cfx_cm3_sharedMemoryAll.userSettingValue.touch_comp;
    const int counts = cfx_cm3_sharedMemoryAll.userSettingValue.touch_noTouch_counts;

    /* 매직넘버 확인 */
    if (magic != (int)TDC_TOUCH_CALIB_MAGIC)
    {
        ci_printw("[TOUCH] CALIB LOAD: no factory data (magic=0x%08X)\r\n", magic);
        p_out->valid = false;
        return false;
    }

    /* 범위 체크 [추정값 — 실측5 후 조정] */
    if (counts < TDC_TOUCH_CALIB_COUNTS_MIN || counts > TDC_TOUCH_CALIB_COUNTS_MAX)
    {
        ci_printw("[TOUCH] CALIB LOAD: counts out of range (%d)\r\n", counts);
        p_out->valid = false;
        return false;
    }

    p_out->valid           = true;
    p_out->mult            = (uint16_t)mult;
    p_out->comp            = (uint16_t)comp;
    p_out->no_touch_counts = (uint16_t)counts;

    ci_printi("[TOUCH] CALIB LOAD OK: mult=0x%04X comp=0x%04X counts=%u\r\n",
              p_out->mult, p_out->comp, p_out->no_touch_counts);
    return true;
}
```

### 5-3. RESEED 게이트 적용 흐름 (`tdc_touch.c:try_finish_init()` 수정 지점)

```
apply_settings() 완료 (고정 MULT/COMP write + ATI Disabled)
  → tdc_drv_iqs323_calib_load(&calib)  ← 신규 호출
  │
  ├─ calib.valid == false (미캘리브레이션 보드)
  │     → 기존 무조건 RESEED 유지 (현 동작 보존, 회귀 없음)
  │
  └─ calib.valid == true (공장값 존재)
        → CH0 Filtered Counts 읽기 (현재 부팅 상태)
        ├─ counts ∈ [calib.no_touch_counts − WINDOW, + WINDOW]
        │     → RESEED 허용 ✅ (노터치 판정)
        └─ counts ≪ calib.no_touch_counts (터치 의심, self-cap 터치 시 감소)
              → RESEED 보류 → 회복 대기 (최대 timeout)
              → 회복 시 RESEED ✅ / timeout 시 폴백 RESEED + 경보
```

**WINDOW 값**: ±50 counts [추정 — 실측5 후 조정]

```c
#define TDC_TOUCH_CALIB_RESEED_WINDOW  50   /* [추정] */
```

## 8. 핵심 결론 (7줄)

1. **MULT/COMP 읽기는 기구현** — `tdc_drv_iqs323_calib_read_ati()`(`iqs323.c:820`)를 공장캘리 저장 함수에 그대로 재활용한다.
2. **EEPROM 저장 경로는 옵션_A 권고** — `cfx_cm3_sharedMemory.h:89` `userSettingValue` 구조체에 touch calib 4필드(`int` × 4) 추가, `setReadWriteMapDataFlashCommand` 기존 경로로 write.
3. **부팅 로드 순서가 이미 보장됨** — `initialize.c:345`(EEPROM 로드) → `:449`(touch init) 순서로 `tdc_touch.c` 진입 시점에 공유 메모리 값 유효.
4. **게이트 로직은 `try_finish_init()` 내 RESEED 직전** — `calib.valid==false`이면 기존 동작 그대로(회귀 없음), `valid==true`이면 counts 윈도우 비교 후 조건부 RESEED.
5. **저장 데이터**: MULT 16b + COMP 16b + noTouch Counts 16b + 매직넘버 0xCA1B — `int`형 4필드, 총 16바이트.
6. **WINDOW(±50 counts)와 안정화 타이밍(50ms)은 [추정]** — 실측5(RTT Counts 장기 로깅) 후 조정 필수.
7. **CFX 파서 크기 제약이 선행 확인 필수** — 구조체 확장 전 CFX 측 `userSettingValue` 직렬화 코드 리뷰가 옵션_A 실행의 게이트 조건이다.
