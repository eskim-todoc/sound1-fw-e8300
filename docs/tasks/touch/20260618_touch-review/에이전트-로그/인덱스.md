## v2 추가 판정 (명제 G~J)

| 명제 | 판정 | 핵심 |
|---|---|---|
| **명제_G** (통신 윈도우 비용 큼) | **참** | force×2 = 최악 130 ms, 폴링 예산 대비 비중 큼 |

| **Event Mode** | 우선순위 격상 | 통신 비용 근본 해법; Phase 3 재검토 권고 |
