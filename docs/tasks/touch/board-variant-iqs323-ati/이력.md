# IQS323 ATI 보상값 보드 변종 매크로 정리 — 이력

**TL;DR**: 2026-05-08 당일 완료. tdc_drv_iqs323.c L502~517 의 `#if 1 // Sound1 Mini Board` / `#else // Sound1 Develop Board` 형태를 빌드 매크로 `TDC_BOARD_VARIANT` (MINI / DEVELOP) 분기로 정리. 디폴트 = MINI (현 활성 변종 보존). LED `TDC_FW_VARIANT` 와 동일 패턴. 사용자 빌드 + 실기 터치 검증 통과 ("다 잘 빌드 된다. 동작도 정상이야"). tdc_drv_iqs323.c +45/-7 단일 commit.

작업 슬러그: `touch/board-variant-iqs323-ati`
브랜치: `claude_feature_ota-dfu-fw-variant-led` (base: `claude_develop`) — LED 작업과 공유
기간: 2026-05-08 (당일 완료)
상태: **완료** (사용자 검증 통과)

---

## 1. 결과 요약

- 사용자 검증: **빌드·동작 정상** (Mini 디폴트). "다 잘 빌드 된다. 동작도 정상이야."
- 회귀: 없음 (ATI 6 매크로 이름·사용처 무변경 → `write_ati_compensation()` 호출 경로·동작 동등)
- 잔존 이슈: 없음
- 동시 검증 사이클: LED `TDC_FW_VARIANT` 작업과 함께 1회의 빌드/실기 사이클로 검증

## 3. 주요 설계 결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | 매크로 위치 = `tdc_drv_iqs323.c` 자체 | 변종이 IQS323 ATI 만 영향 → 관심사 응집. LED 와 동일 file-local 패턴 |
| 2 | 디폴트 = MINI | 현재 `#if 1 // Mini` 활성과 동등 → 동작 보존 |
| 3 | 매크로 명 = `TDC_BOARD_VARIANT` | 사용자 명시 + LED `TDC_FW_VARIANT` 와 명명 일관 (`TDC_<도메인>_VARIANT`) |
| 4 | `Board_is_*` 와 의도적 분리 | 결정 시점·범위 다름 (핀 매핑 vs 캘리브레이션). Mini/Develop ↔ OTE/TD_DEV 매핑 미확인 → 자동 매핑 시 가정 위험. Hybrid 빌드 자유 보존 |
| 5 | 잘못된 값 = `#error` | LED 와 동일 — 즉시 빌드 실패로 silent failure 방지 |
| 6 | ATI 6 매크로 이름·사용처 무변경 | `write_ati_compensation()` 호출 경로·동작 동등성 보장 |

---

## 5. 호출자 영향

- ATI 6 매크로 이름·사용처 무변경 → `write_ati_compensation()` 호출 경로·동작 동등.
- Mini 빌드(매크로 미정의) 시 디폴트 MINI → 기존 baseline 과 동등.
- Develop 빌드는 본 파일 디폴트 한 줄 변경 또는 `-DTDC_BOARD_VARIANT=TDC_BOARD_VARIANT_DEVELOP` 빌드 옵션.
- `processorDirective.h` 의 `Board_is_*` 매크로 체계는 무변경 (의도적 분리).

---

## 6. 후속 작업

- 보드 분기가 다른 드라이버에 확대되면 → 공용 헤더 (예: `tdc_variant.h`) 로 승격 검토 (현 단계 비파괴).
- `Board_is_*` ↔ `TDC_BOARD_VARIANT` 매핑이 명확해지면 → 자동 분기 (예: `Board_is_TD_DEV_*` → DEVELOP) 로 통합 검토.
