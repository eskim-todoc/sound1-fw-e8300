# 00 · 오케스트레이터 입력 (fan-out 설계)

**TL;DR**: 셀프캡 관측교란을 상호용량으로 돌파 가능한지 검토. 전문가 6 페르소나(원리·노이즈EMC·IC능력·전극물리·현설계이력·대안결정)를 병렬 기동해 각자 노드 파일을 쓰고 구조화 반환 → 핵심 주장 4건을 adversarial-verify 4 노드로 반증 검증 → 오케스트레이터가 종합평결·분석·계획으로 fan-in.

## 문제 정의 (한 줄)

> 셀프캡(CRX0 단일전극) 터치의 하이젠베르크(클럭 스위칭이 sub-pF 측정에 전하 주입) 교란을, 두 전극 차동인 상호용량(CRX0↔CRX1)이 회피할 수 있는가? 현 IQS323·D패드 HW로 가능한가? 도입해야 하는가?

## 공통 컨텍스트 (모든 노드 전제)

- **하이젠베르크 3메커니즘**(관측교란.md): ① 결합 임피던스 `Z=1/(2πfC기생)`, ② 샘플링 윈도우 일치, ③ 에일리어싱/맥놀이. 두 경로 — 경로_1 접지(준-DC), 경로_2 스위칭(AC). **디퍼런셜 프로브는 경로_1만 상쇄, 경로_2는 못 잡는다**(급소).
- **절전 시** SYSCLK 12× 하강(30.72→2.56MHz), I2C 426.7kHz 버스트, PMIC/FPGA/QCC/nRF OFF → 노이즈 스펙트럼이 통째로 바뀜.
- **CRX1 이력**: 원래 CRX1은 단일채널 방전 불능 회피용 **CalCap 내부 더미**(외부 C52 부착). CH0=CRX0=중앙 채움(현 셀프캡 활성), CH1=CRX1=외곽 링(현 더미). auto-ATI가 sensor_setup보다 먼저 도는 타이밍 급소 존재.
- **패드**: "D"자. 회로도에 J1=RX, J2=TX, J3=Touch_PAD→GND 분리.
- **현 펌웨어**: FullATI 셀프캡 제어(claude_feature_touch-fullati-control, 미빌드). 순수 FSM + 직접 I2C + 얇은 연결층 3파일.

## 검증 주장 (adversarial-verify · 반증 우선)

- **주장_1**: 상호용량(CRX0↔CRX1 차동)이 셀프캡 하이젠베르크(클럭 스위칭·에일리어싱)를 실질 회피/저감한다.
- **주장_2**: IQS323가 현 HW(CRX0 중앙+CRX1 외곽, C52)에서 CRX0-CRX1 상호용량 페어링을 레지스터 설정만으로 지원한다.
- **주장_3**: D패드 형상이 상호용량 감지에 충분한 프린징 필드 결합·터치 감도를 제공한다.
- **주장_4**: CRX1 실전극화(CalCap 더미 폐기) 시 과거 ESD 전하누적·단일채널 방전 문제가 재발하지 않는다.

각 주장에 독립 회의론자 1명 배정 — "반증 우선(불확실하면 refuted)" 지침으로 refuted 여부·근거·잔여 불확실성 반환.
