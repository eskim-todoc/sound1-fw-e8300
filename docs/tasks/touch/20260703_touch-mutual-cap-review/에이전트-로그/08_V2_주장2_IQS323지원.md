# 08 · V2 — 주장_2 반증 검증 (IQS323 현 HW 지원 여부)

**TL;DR**: 레지스터 비트 구조(PXS Mode·Wav Pattern·CTx/CRx 선택)는 P3 주장대로 실재하며 데이터시트 원문으로 재확인했다. 그러나 P3를 포함한 6개 전문가 노드 전원이 데이터시트 §3.2 전기적 특성표(Cm 0.2~9pF·Cp Rx-VSS ≤100pF·Cx/Cm비 10~20)를 놓쳤다. 이 정량 제약을 Sound1 실제 D패드(치수 미확인)·C52 특이 위상(직렬 커패시터, RCx 스펙 미해당)과 대조한 근거가 전무하다. "레지스터 설정만으로 지원한다"는 미검증 정량 게이트를 건너뛴 과확신 — **반증(refuted=true), 신뢰도 중간**.

---

## (a) 주장 재기술

> 주장_2: IQS323가 현 HW(CRX0 중앙+CRX1 외곽, C52)에서 CRX0-CRX1 상호용량 페어링을 레지스터 설정만으로 지원한다.

핵심 술어는 "지원한다"(확립된 사실처럼 서술)이며, 범위는 추상적 IC 일반 능력이 아니라 **"현 HW"(C52 명시 포함)로 명시적으로 좁혀져 있다** — 이 보드의 실제 소자값·전극 형상 위에서 성립하는지를 묻는 주장이다.

---

## (b) 반증 시도와 결과

### (b-1) 레지스터 비트 차원 — 원 근거 문서 직접 대조 (반증 실패, 주장 지지)

P3가 인용한 값을 1차 데이터시트 원문과 개별 대조했다.

| P3 인용 | 대조 결과 | 근거 |
|---|---|---|
| PXS Mode 0x10=Self · 0x13=Mutual | **일치** | `데이터시트/06_레지스터레퍼런스.md` A.7 원문 직접 확인 |
| Wav Pattern0 Self=0x03·Mutual=0x0E | **일치** | `데이터시트/02_proxfusion동작.md` §5.12.1 Table 5.2 원문 직접 확인 |
| Invert = bit3 (Sensor Setup) | **일치** | A.5 원문 직접 확인 |
| TX_SELECT bit8=CTx0 / RX_SELECT bit9=CRx1 | **일치** | A.5·A.9 원문 직접 확인 |
| 예제 `S0_PRX_CTRL_0=0x93`→PXS=0x13 등 6개 필드값 | **일치** | `IQS323_3PROJ_BUTTONS_EV_KIT.h` 원본 파일 직접 Read해 바이트 재확인 |
| 0x70 Channel Mode는 self/mutual과 무관 | **일치** | A.15 원문 직접 확인 |

→ P3의 비트 단위 서술은 할루시네이션이 아니다. 이 축에서는 반증 실패(주장을 지지).

### (b-2) 겸용 CTx(=CRX0)를 Tx로 쓰는 패턴 — 실증 선례 부재 재확인 (반증 성공)

Azoteq 공식 예제(`IQS323_3PROJ_BUTTONS_EV_KIT.h`) 원문을 직접 Read해 재확인: S0/S1/S2 세 센서 **전부** `TX_SELECT=0x08`(bit3=TxA만 set, CTx0/1/2=0) — 유일한 실증 선례는 "전용 TxA 고정 Tx + CRx0/CRx1/CRx2를 센서별 순환"이다. Sound1은 TxA가 R30=0Ω→NC로 미배선이므로 이 패턴을 그대로 재현 불가하고, Sound1에 필요한 "CRX0 겸용 CTx0→Tx" 조합은 예제 어디에도 실증 선례가 없다. P3도 §5.3-3에서 이를 "참조례 공백"으로 인정 — 이 점은 본 검증과 P3가 일치한다.

### (b-3) 데이터시트 §3.2 전기적 특성표 — 6개 전문가 노드 전원 누락 (반증 핵심, 신규 발견)

`데이터시트/01_개요·전기·타이밍.md` §3.2 "Recommended Operating Conditions" 원문을 직접 확인한 결과, mutual-cap 전용 정량 스펙이 별도로 존재한다:

| 항목 | Min | Nom | Max | 단위 | 비고 |
|---|---|---|---|---|---|
| Cm Tx-Rx (Rx↔Tx 전극 결합용량) | 0.2 | | 9 | pF | mutual 결합이 이 범위 내여야 함 |
| Cp Rx-VSS (mutual, @fxfer=1MHz) | | | 100 | pF | 각주: **RCx=0Ω 기준** |
| Cx_Rx-VSS / Cm_Tx-Rx (SNR 최적비) | 10 | | 20 | n/a | Rx 전극 대지용량이 결합용량의 10~20배 권장 |
| RCx Rx/Tx (mutual, 직렬저항) | 0 | 0.47 | 10 | kΩ | 각주: 470Ω 공칭은 EMI/ESD 보호 목적 |

이 표는 **P1~P6 6개 노드 중 어느 곳에서도 인용되지 않았다**(각 노드 본문·근거 목록 직접 확인, P3는 근거 목록에 "데이터시트/06"만 명시하고 "데이터시트/01"은 미포함). 반면 **동일 저장소의 다른 작업 산출물**(`개선/생각정리/2_비판_P2_측정방식재검토.md` §렌즈A, `1_설계안_P2_측정방식재검토.md` §3.2)은 이미 이 표를 인용해 "C51=100pF가 Cp Rx-VSS 상한과 정확히 일치하고, RCx=0Ω 전제인데 R31=100Ω이 있어 이미 그 전제를 벗어난다"고 지적했다(단, 이는 "CRX0를 **Rx**로 쓰는" 다른 시나리오에 대한 지적이라 주장_2의 "CRX0=Tx·CRX1=Rx" 배치엔 그대로 재적용되지 않는다 — 아래에서 재계산).

**주장_2 배치(CRX0=Tx·CRX1=Rx)에 이 표를 직접 대입하면**:

1. **Cm(CRX0↔CRX1) 실측값 — 완전 미확인.** D패드 치수(전체 크기·링 폭·링-필 갭·오버레이 두께)가 P4에서 "치수 전무"로 확인됨 → Cm이 0.2~9pF 범위 안인지 밖인지 판단 근거 자체가 없다. P4가 지적한 "단일 경계선·비해칭·면적비 역전" 구조는 결합밀도가 낮다는 정성적 우려와 정합적이므로, Cm이 하한(0.2pF)에도 못 미쳐 유효 신호가 안 나올 가능성조차 배제 못 한다(가설).
2. **Cp(CRX1-VSS) 실측값 — 완전 미확인.** 외곽 링(CRX1)의 대지 기생용량 실측치가 없다. R32=0Ω이라 각주 "RCx=0Ω 기준" 전제는 저항 관점에서 충족되나, **C52(100nF)가 직렬로 끼어 있다는 사실은 이 스펙 표 어느 카테고리에도 대응 항목이 없다** — RCx는 저항(R) 스펙이지 직렬 커패시터 스펙이 아니다. C52의 실제 전기적 영향(특히 charge-transfer의 DC성 성분에 대한 영향)은 이 표로도, P1~P6 어느 노드로도 규명되지 않은 모델링 공백이다.
3. **비율(Cx/Cm 10~20)** — 두 항 모두 미확인이라 계산 자체가 불가능.
4. Sound1은 신체 착용 기기(인공와우 외부기)로 전극이 두피·머리카락 근접 환경에 상시 노출된다 — Cp Rx-VSS가 데이터시트의 이상적 조건과 다른 부하를 받을 가능성(가설, 미확인)까지 고려하면 불확실성은 더 커진다.

→ **이 축에서 반증 성공**: "레지스터 설정만으로 지원한다"는 서술은, 데이터시트가 mutual 모드에 명시적으로 요구하는 정량 전기 스펙(Cm·Cp·비율)을 Sound1 현 HW 실측치와 전혀 대조하지 않은 채 내려진 결론이다. 미확인 사항을 가능으로 단정한 사례에 해당한다.

### (b-4) C52의 원 설계 의도와의 정합성 재확인

`IQS323-회로-구성.md` §5.3: "C52(100nF)... **DC 차단 또는 노이즈 흡수 목적으로 추정**... 실제 사용 전 데이터시트 확인 필요"(원 프로젝트 문서 스스로도 미확정 표시). 오케스트레이터 공통 컨텍스트도 "CRX1은 원래 CalCap 내부 더미용" 이력을 명시한다. C52는 애초에 mutual-Rx 결합 신호 경로가 아니라 **다른 목적**(더미/DC차단)으로 결정된 소자값이며, 이 원 설계 의도와 "레지스터만으로 mutual Rx 전환"이 상충하지 않는다는 근거는 어디에도 없다. P3도 이를 미검증으로 인정했으나(§5.3-1), 그 인정이 TL;DR·답변요약표의 "레지스터 설정만으로 시도 가능" 단정과 나란히 놓이면서 확신도가 실제 근거보다 부풀려진 인상을 준다.

### (b-5) 반증 실패한 부분 (주장에 유리하게 남는 지점)

- 배선 자체(HW 개조)는 불필요하다는 P3 주장은 사실이다 — CRX0·CRX1 모두 이미 D패드에 연결되어 있다(회로도 직접 확인). "새 커넥터·트레이스가 필요 없다"는 의미로는 참.
- 채널 자원 1개 소모(항목 e)·Channel Mode 무관(항목 a)·레지스터 주소 정정(항목 b) 등 P3의 나머지 기술적 정정은 모두 원문 대조로 유지된다.

## (c) refuted 판정 및 신뢰도

**판정: refuted = true (반증됨)**
**신뢰도: 중간(medium)**

- 반증의 근거는 "레지스터 아키텍처가 이 조합을 원천적으로 금지한다"는 강한 의미가 아니라, "**현재 HW에서 지원된다고 단정할 근거가 없다**"는 의미다 — 데이터시트가 명시한 정량 전기 스펙(Cm 0.2~9pF·Cp≤100pF·비율 10~20)을 Sound1 실측치와 대조한 근거가 전무하고, C52의 특이 위상(직렬 커패시터)은 그 스펙 체계 밖에 있어 별도 미확인 상태다.
- 신뢰도를 "높음"이 아닌 "중간"으로 둔 이유: (i) 레지스터 비트 자체의 존재·정합성은 강하게 확립되어 있어 주장의 메커니즘적 가능성 골격은 무너지지 않았고, (ii) 실측이 이루어지면 Cm·Cp가 우연히 범위 안에 들어 성립할 가능성도 논리적으로 배제되지 않는다 — "확정적으로 불가능"이 아니라 "확정적으로 가능하다고 말할 근거가 없다"는, 반증치고는 다소 약한 유형이나 지침상 "미확인=반증 원칙"에 정확히 부합한다.

## (e) 도입결정 함의

- 주장_2가 반증됨에 따라, P6의 "조건부 No-Go" 권고 중 "HW 전제 자체는 없다"는 blocking 사유는 **일부 완화**(배선은 확실히 불필요)되지만, "핵심 편익·성립 여부가 미확정"이라는 사유는 **오히려 강화**된다 — 단순 미확정이 아니라 명시적·정량적 데이터시트 게이트(Cm·Cp·비율)가 존재하는데 아무도 대조하지 않았다는 더 구체적인 공백이 드러났기 때문이다.
- 실측 게이트 우선순위에 신규 항목 추가 권고: **Cm(CRX0↔CRX1)·Cp(CRX1-VSS) 벤치 실측**을 "D패드 치수 확보"(P4 권고)와 함께 mutual 재검토의 선행 조건으로 승격. 이 실측 없이는 "레지스터 설정만으로 지원한다"는 표현을 계획·문서에서 쓰지 말고 "레지스터 설정으로 시도는 가능하나 전기적 성립 여부는 미검증"으로 정정 권고.
- P3 노드의 TL;DR·답변요약표는 본문 §5.3의 신중한 단서와 어조가 어긋난다 — fan-in 종합 시 TL;DR만 인용되는 사고를 막기 위해, 종합평결에는 "레지스터 아키텍처 확립 + 전기적 성립 미검증"이라는 두 문장 분리 서술을 권고한다.

## 핵심 결론 (5줄)

1. P3가 인용한 레지스터 비트(PXS Mode·Wav Pattern·Invert·TX/RX_SELECT)는 데이터시트 원문·Azoteq 예제 원본과 개별 대조해 전부 사실로 확인됐다 — 이 부분은 반증되지 않는다.
2. "겸용 CTx0(=CRX0)를 Tx로 쓰는" Sound1 필요 조합은 Azoteq 실증 예제 어디에도 선례가 없다(P3도 인정) — 검증된 것은 "전용 TxA + 개별 CRx" 패턴뿐이다.
3. **6개 전문가 노드 전원이 데이터시트 §3.2 전기적 특성표(Cm Tx-Rx 0.2~9pF·Cp Rx-VSS ≤100pF·Cx/Cm비 10~20)를 인용하지 않았다** — 본 검증에서 직접 확인한 결과, 이 정량 게이트를 Sound1 D패드 실측치(전량 미확인)나 C52의 특이 직렬-커패시터 위상(스펙 카테고리 자체가 없음)과 대조한 근거가 전무하다.
4. 따라서 "IQS323가 현 HW에서 CRX0-CRX1 상호용량 페어링을 레지스터 설정만으로 지원한다"는 **미확인 정량 스펙을 가능으로 단정한 과확신**으로 판정한다 — refuted=true, 신뢰도 중간.
5. 배선 자체가 불필요하다는 점(HW 개조 없이 시도 가능)은 사실로 남으나, "지원한다"는 서술은 "시도 가능하나 전기적 성립은 미검증"으로 하향 정정돼야 한다.

## 이 페르소나가 본 리스크·불확실성

- 본 반증의 핵심 증거(§3.2 표)는 원 데이터시트 PDF가 아니라 프로젝트가 마크다운으로 재정리한 `데이터시트/01_개요·전기·타이밍.md`를 근거로 삼았다 — 재정리 과정의 전사 오류 가능성은 낮다고 보되(수치·각주가 별개 독립 작업인 `1_설계안_P2`에서도 동일하게 인용되어 교차 일치), 최종 확정 전 원본 PDF 대조를 권고한다.
- "미확인 = 반증" 원칙을 엄격히 적용했으나, 이는 "성립 불가"를 뜻하지 않는다 — 실측 결과에 따라 재평가 여지가 크며, 본 판정을 "영구적 No"로 오독하지 않도록 fan-in 단계에서 명확히 해야 한다.
- C52의 DC성 동작 영향(§(d)-3)은 본 검증도 결론을 내리지 못한 순수 신규 질문으로, 회로 레벨 데이터시트 응용회로도 추가 열람이나 실측 없이는 어느 방향으로도 단정할 수 없다.
