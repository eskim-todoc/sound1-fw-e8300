# 이력 및 결과 — auto-ATI 중 CRX0 수동방전 공존 검토

**TL;DR**: 하이브리드 권고에서 ESD 물리누적이 미지수라 보수적으로 수동방전(CRX0 VSS 200ms + CRX1 CalCap 더미)을 유지하고 싶을 때, auto-ATI Full과의 공존 가능성을 다관점 + adversarial 검증으로 따지고, 어려우면 대안을 도출한다. 과정은 `개선/방전·autoATI 공존 검토/`, 결과는 `개선/`.

## 요구사항 요지

- **질문**: ESD 물리누적 미지수 → ① CRX1 CalCap 살리고 ② CRX0 수동방전을 **auto-ATI 사용 중에도** 할 수 있나 ③ 어려우면 어떻게 하는 게 좋은가.
- **방법**: 다관점(데이터시트·코드통합·adversarial·대안설계·이전결론정합) + adversarial 독립 검증.
- **산출**: `개선/방전·autoATI 공존 검토/` 과정, `개선/`에 결과(공존 평결·대안 권고).
- **원칙**: 근거 기반(데이터시트·코드), 공정, 할루시네이션 0.

## 핵심 쟁점

- auto-ATI/Re-ATI(측정 보정 레이어)와 200ms CRX0 채널 토글(0x30, 물리 방전 레이어)이 충돌하나 — Re-ATI 재트리거·ATI 수렴 방해·측정 공백.
- "ESD 물리누적 방전"과 "auto-ATI 드리프트 보정"은 다른 레이어인가 — 공존 필요/가능?
- 어려우면 대안: 시간분리·빈도조정·Re-ATI 억제·ESD 실측 후 제거·HW 방전·방전 경로 변경.

## 완료 요약

**산출물**
- `개선/방전·autoATI 공존 검토/` 8문서 — 00 입력·1_분석 C1~C5(5)·2_검증·3_종합평결.
- **`개선/방전·autoATI 공존 권고.md`**(정식 결과). `개선/README` 갱신.

**검증 규모**: 워크플로우 9 에이전트(5 페르소나 + 4 adversarial), 550K 토큰.

**평결**
- 직접 공존(**auto-ATI Full 상시 + 200ms 방전**)은 **조건부불가** — 충돌 4축(0x30 비트 공유·Re-ATI 진동·ATI 수렴 교란·I²C 무응답). 치명: I²C hang 중 방전 disable만 들어가고 복원 막히면 CH0 영구 disable.
- **충돌 근원은 "런타임 자율 Re-ATI" 하나 → auto Re-ATI만 끄면(부팅 1회 ATI + Disabled 고정 + LTA 추적) 공존 가능.**
- **🔴 라이브 발견**: 현재 방전 `0x30 0x02`는 데이터시트상 **Linearise(VSS 아님)** — 방전 물리효력 미검증(VSS는 0x34, 핀 enable은 0x33). **방전 진위(0x30=VSS?) 실측 최우선.**
- **레이어 분리 참**: 방전(핀 물리전하)은 auto-ATI(IC 내부 보정)로 대체 불가 — 단 ESD가 물리누적 AND 방전 실효 시만.

**대안 권고**: 0)통신관리 → 1)방전 진위·ESD 정체 실측 → 2)auto Re-ATI 억제 → 3a)드리프트면 방전 폐기 / 3b)물리누적이면 방전 안전화(0x30 RMW/0x34·verify·빈도) → 4)HW 방전. **CRX1 CalCap은 방전 유지 시 그대로, 폐기 시 불요.**

**검증 방식**: 5 페르소나 + adversarial 독립 검증(코드 grep 라이브 확정 — 0x30 비트·ATI Disabled config·라인 942/947/1142/h:89). 라인 참조 검증 통과.
