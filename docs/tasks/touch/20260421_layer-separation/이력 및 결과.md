**TL;DR**: `tdc_iqs323.c` 단일 파일의 두 책임을 `tdc_touch.c`(기능 레이어 — IC 독립, 초기화 상태머신·100 ms 폴링·3 s 롱터치 판정) 와 `tdc_drv_iqs323.c`(드라이버 레이어 — IQS323 고유 MCLR·Auto-ATI·레지스터 맵·I2C·RDY 윈도우) 로 분리. IC 교체 시 수정 범위가 드라이버 파일로 한정되어 리뷰·유지보수 비용 감소. 2026-04-21 코드 적용 후 2026-05-07 사후 정리.

## 1. 결과 요약

`tdc_iqs323.c` 단일 파일에 섞여 있던 두 책임을 분리:

- **기능 레이어** ([`tdc_touch.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.c)) — IC 독립. 초기화 상태머신, 100 ms 폴링, 3 s 롱터치 판정.
- **드라이버 레이어** ([`tdc_drv_iqs323.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_drv_iqs323.c)) — IQS323 고유. MCLR, Auto-ATI, 레지스터 맵, I2C, RDY 윈도우.

IC 교체 시 수정 범위가 드라이버 파일로 한정됨.

## 2. 변경 사항

### 2.1 적용 위치

| 항목 | 파일 | 비고 |
|---|---|---|
| 기능 레이어 헤더 | [`tdc_touch.h`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.h) | 공개 API: `tdc_touch_init_begin`, `tdc_touch_process`, `tdc_touch_get_state` |
| 기능 레이어 구현 | [`tdc_touch.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.c) | 상태 enum 일반화 (`TDC_TOUCH_STATE_*`), 드라이버 에러도 IC 중립 |
| 드라이버 레이어 헤더 | [`tdc_drv_iqs323.h`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_drv_iqs323.h) | 저수준 공개 API: `tdc_drv_iqs323_mclr_reset` 등 |
| 드라이버 레이어 구현 | [`tdc_drv_iqs323.c`](../../../../src/2__cm3/Cortex-M3-src/systemControl/tdc_drv_iqs323.c) | I2C·RDY·레지스터 헬퍼 |

### 2.2 결정 사항 (구현계획 §1.3 제약)

- HAL 함수 포인터 테이블 미도입. 기능 레이어가 드라이버 헤더를 `#include`로 직접 호출.
- 네이밍: `tdc_<feature>` (기능) / `tdc_drv_<chip>` (드라이버) 컨벤션 적용.
