> **TL;DR**: 4개 파일 수정. ATI_SETUP_LSB 0x08→0x0C, write_ati_compensation() 제거, tdc_drv_iqs323_reseed() 공개 API 추가, func_sleep ULP 첫 반복 후 RESEED 호출, Threshold 80 복원.

## 수정 파일 목록

| 파일 | 변경 수 | 내용 |
|---|---|---|
| `tdc_drv_iqs323.c` | 3곳 | ATI_SETUP_LSB 상수 변경, write_ati_compensation 호출 제거, reseed 공개 함수 추가 |
| `tdc_drv_iqs323.h` | 2곳 | Threshold 80 복원, tdc_drv_iqs323_reseed() 선언 추가 |
| `main.c` | 1곳 | func_sleep ULP 루프 첫 반복 후 RESEED |

## 상세 변경 계획

### 변경_1: ATI_SETUP_LSB 0x08 → 0x0C (tdc_drv_iqs323.c)

```c
/* 전 (3개 변종 모두) */
#define TDC_DRV_IQS323_ATI_SETUP_LSB 0x08  /* ATI Mode=Disabled(000) */

/* 후 */
#define TDC_DRV_IQS323_ATI_SETUP_LSB 0x0C  /* ATI Mode=Full(100) — 부팅 시 자동 캘리브레이션 */
```

**이유**: bits[2:0]=100 → ATI Mode=Full. 부팅 시 HW auto-ATI 결과를 MULT/COMP에 반영.
**안전성**: CH timeout 비활성화(행 856-860)가 그대로이므로 운용 중 auto-reATI 트리거 경로 차단.

### 변경_2: write_ati_compensation() 호출 제거 (tdc_drv_iqs323.c, 운용 모드 분기)

```c
/* 제거 대상 (apply_settings 운용 모드, #else 분기) */
if (!write_ati_compensation())
{
    ci_printe("[TOUCH] FAIL: WRITE ATI COMPENSATION \r\n");
}
```

**이유**: auto-ATI가 산출한 MULT/COMP를 하드코딩값으로 덮어쓰지 않도록.
**참고**: 덤프 모드(#if TDC_DRV_IQS323_ATI_DUMP_ENABLE) 분기는 영향 없음.

### 변경_3: tdc_drv_iqs323_reseed() 공개 함수 추가 (tdc_drv_iqs323.c)

```c
void tdc_drv_iqs323_reseed(void)
{
    if (!write_register(TDC_DRV_IQS323_REG_ADDR_SYSTEM_CONTROL, 0x08, 0x00))
    {
        ci_printe("[TOUCH] FAIL: RESEED \r\n");
    }
}
```

**위치**: 기존 `tdc_drv_iqs323_is_auto_ati_done()` 근처 공개 API 영역.

### 변경_4: Threshold 100 → 80 복원 (tdc_drv_iqs323.h)

```c
/* 전 */
#define TDC_DRV_IQS323_TOUCH_THRESHOLD  100

/* 후 */
#define TDC_DRV_IQS323_TOUCH_THRESHOLD   80
```

### 변경_5: tdc_drv_iqs323_reseed() 선언 추가 (tdc_drv_iqs323.h)

```c
void tdc_drv_iqs323_reseed(void);
```

### 변경_6: func_sleep ULP 루프 첫 반복 RESEED (main.c)

```c
int touch_cnt = 0;
bool reseed_done = false;  /* 추가 */

while (1)  // ULP loop
{
    SYS_WAIT_FOR_INTERRUPT;
    SYS_WATCHDOG_REFRESH();

    if (!reseed_done)  /* 추가 */
    {
        reseed_done = true;
        tdc_drv_iqs323_reseed();  /* 절전 환경 LTA 재설정 */
        continue;
    }

    tdc_touch_state_t state = TDC_TOUCH_STATE_RESET;
    ...
```

**이유**: 절전 진입 후 첫 ≈500ms 대기 → 환경 안정화 → RESEED로 LTA를 절전 환경 counts로 재설정.

## 검증 계획

1. 빌드 — 컴파일 에러·경고 없음
2. 동작 — 부팅 후 ATI 완료 → 터치 정상 반응 확인
3. 절전 — func_sleep 진입 후 false touch 없음 (또는 첫 500ms 이후 없음)
4. 장기 — 반복 재부팅 시 터치 정상 유지 (ATI 오염 없음)
