## 완료 요약

- **auto-ATI 활성화**: ATI_SETUP_LSB 0x08→0x0C (3개 변종 모두). 부팅 시 기기별 기생 정전용량 자동 캘리브레이션.
- **MULT/COMP 하드코딩 제거**: write_ati_compensation() 폐기 → write_ati_setup()으로 대체 (ATI_SETUP만 설정, MULT/COMP는 auto-ATI 결과 사용).
- **func_sleep RESEED 추가**: ULP 루프 첫 반복(≈500ms 후) tdc_drv_iqs323_reseed() 호출. 절전 환경 변화를 LTA에 흡수.
- **Threshold 복원**: 130→80. auto-ATI 환경 적응 후 원래 감도 사용.
- **수정 파일**: `tdc_drv_iqs323.c`, `tdc_drv_iqs323.h`, `main.c`
