> **TL;DR**: 현재 코드는 부팅 시 HW auto-ATI를 실행하지만 write_ati_compensation()이 결과를 덮어쓰는 구조. ATI_SETUP_LSB 1바이트 변경 + write_ati_compensation 제거 + func_sleep RESEED 추가로 목표 달성 가능.

## 현재 코드 구조

### ATI 초기화 흐름

```
리셋 → IQS323 HW auto-ATI (칩 내부 자동)
     → tdc_touch_process() 폴링
     → is_auto_ati_done() == true
     → tdc_drv_iqs323_apply_settings()
          ├─ ack_reset_event()
          ├─ confirm_reset_event()
          ├─ sensor_setup()           ← ATI_SETUP 레지스터 씀 (ATI_SETUP_LSB=0x08=Disabled)
          ├─ touch_settings()         ← Threshold/Hysteresis 설정
          ├─ events_enable()
          ├─ write_ati_compensation() ← ⚠ auto-ATI 결과 MULT/COMP 덮어씀
          └─ RESEED                   ← 덮어쓴 값 기준 LTA 설정
```

**문제**: write_ati_compensation()이 auto-ATI가 산출한 MULT/COMP를 하드코딩값으로 덮어씀
→ 기기마다 다른 기생 정전용량이 반영되지 않음

### ATI_SETUP_LSB 현재값

```
tdc_drv_iqs323.c:515-538 — 3개 변종 모두 0x08
bits[2:0] = 000 → ATI Mode = Disabled
```

- 이전에 0x0C(Full)를 사용했다가 stuck-touch→auto-reATI→ATI_ERROR 경험
- CH timeout 비활성화(행 856-860)로 auto-reATI 트리거 경로는 이미 차단되어 있음

### RESEED 현재 위치

```
tdc_drv_iqs323.c:851 — apply_settings() 내부만
main.c func_sleep — 없음
```

### func_sleep ULP 루프

```
main.c:793-815
while(1) {
    SYS_WAIT_FOR_INTERRUPT;   // ≈500ms
    SYS_WATCHDOG_REFRESH();
    터치 샘플링;
    ULP_LONG_TOUCH_COUNT 연속 → WDT 리셋;
}
```

- 복귀 없음 — 오직 WDT 리셋만
- 절전 진입 후 환경 변화 → counts 변화 → LTA 고정 → false touch 발생
- RESEED 없으므로 LTA 재설정 불가

## 변경 영향 분석

| 변경 | 영향 | 위험 |
|---|---|---|
| ATI_SETUP_LSB 0x08→0x0C | auto-ATI 활성화 | CH timeout 비활성화로 운용 중 auto-reATI 트리거 경로 차단 → 저위험 |
| write_ati_compensation() 제거 | auto-ATI 결과 MULT/COMP 사용 | ATI 실패 시 MULT/COMP 미설정 → RESEED 결과 불확실. 단, ATI 완료 폴링 후 호출이므로 실패 시 이전에 차단됨 |
| func_sleep RESEED 추가 | 첫 ULP 반복 후 LTA = 절전 환경 counts | 첫 500ms 동안은 false touch 가능. ULP_LONG_TOUCH_COUNT가 1이상이면 1회 false touch는 무해 |
| Threshold 100→80 복원 | 감도 증가 | auto-ATI 환경 적응 후 false touch 재발 위험. 테스트 후 재조정 가능 |

## RESEED 공개 API 필요성

현재 RESEED는 apply_settings() 내부에 write_register() 직접 호출:
```c
write_register(TDC_DRV_IQS323_REG_ADDR_SYSTEM_CONTROL, 0x08, 0x00)
```

func_sleep(main.c)에서 호출하려면 공개 함수가 필요:
→ `tdc_drv_iqs323_reseed()` 신규 추가
