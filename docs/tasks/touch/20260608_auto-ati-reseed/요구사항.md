> **TL;DR**: 하드코딩 MULT/COMP 방식 → auto-ATI 방식 전환. 기기별 기생 정전용량 자동 보정, func_sleep ULP 루프에 RESEED 추가하여 절전 환경 변화 흡수.

## 배경

- 이전 작업(20260608_sleep-measure-mode)에서 절전 노터치 기준 MULT/COMP + Threshold=100 적용
- 적용 후 터치 무반응 — 원인 불명 (false touch 고착 또는 Threshold 과도)
- 근본 문제: 기기마다 다른 기생 정전용량 → 하드코딩값으로 모든 기기 커버 불가

## 기능 요구사항

| 번호 | 요구사항 |
|---|---|
| FR-1 | ATI Mode를 Full(0x0C)로 설정하여 부팅 시 자동 캘리브레이션 실행 |
| FR-2 | `write_ati_compensation()` 호출 제거 — auto-ATI 결과를 덮어쓰지 않음 |
| FR-3 | func_sleep ULP 루프 최초 반복(≈500ms 대기) 후 RESEED 실행 |
| FR-4 | Threshold를 원래 값(80)으로 복원 — auto-ATI 환경 적응 후 감도 충분 |
| FR-5 | CH timeout 비활성화 유지 — 운용 중 auto-reATI 트리거 경로 차단 |

## 비기능 요구사항

| 번호 | 요구사항 |
|---|---|
| NFR-1 | 기존 `TDC_TOUCH_SLEEP_MEASURE_MODE` 분기 영향 없음 |
| NFR-2 | MINI/DEVELOP/PACKAGE 3개 변종 모두 적용 |
| NFR-3 | func_normal 초기화 RESEED(apply_settings 내)는 그대로 유지 |
