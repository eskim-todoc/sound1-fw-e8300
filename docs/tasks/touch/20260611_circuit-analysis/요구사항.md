# 요구사항 — IQS323 터치 회로 구성·분석

**TL;DR**: IQS323 터치(전원 스위치 겸용)의 대규모 개선 스터디 착수. 첫 단계로 `참고/touch/개선/`에 실제 회로(JPG ground truth)를 풍부하게 문서화 — 앞으로 스터디·참조의 기반.

## 배경

- IQS323001CSR을 **전원 스위치 겸 터치**로 사용. 은수님이 `개발 요구 사항 및 예상 문제 정리.md`로 사용 시나리오·현재 구현·이슈 9건·해결방안 요구를 정리.
- 핵심 통증: 충전 케이블 ~1µs 채터링 재부팅 우려, autoATI 미사용(FIXED)에 따른 드리프트·카운트 변동·터치 들쭉날쭉, 전원 버튼 겸용 초기화 시 먹통.
- 회로 ground truth = `Touch Sensor Schematic.JPG`.

## 목표

1. `참고/touch/개선/` 신설, **회로 정보를 풍부하게 문서화**(회로 사실 + 데이터시트 대조 + 현재 구현/이슈의 회로적 해석 + 개선 검토 포인트).
2. 앞으로 Claude가 참조할 수 있는 스터디 기반 + 향후 로드맵.

## 수용 기준 (AC)

- **AC-1**: `개선/README.md`(인덱스·로드맵) + `회로 구성·분석.md` 생성.
- **AC-2**: 회로 사실(부품값·패키지·핀 좌표·연결)이 JPG와 100% 일치. **C54=4.7µF** 반영.
- **AC-3**: 데이터시트 §2.5/§3.4 인용 정확, 현재 구현 5종·이슈 9건 서술이 요구사항 문서와 정합(할루시네이션 0, 추정은 추정 표기).
- **AC-4**: 기존 `레퍼런스/IQS323-회로-구성.md` C54 정정(4.7nF→4.7µF).
- **AC-5**: frontmatter/TL;DR·broken link 0. 검증 에이전트 치명·중 0.
