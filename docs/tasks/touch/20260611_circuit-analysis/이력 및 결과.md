## 결정 사항

- 위치: `참고/touch/개선/` (README + 회로 구성·분석.md). 기존 `레퍼런스/IQS323-회로-구성.md`는 보존·링크.

**핵심 발견·정정**: 실제 회로도 JPG·데이터시트 §2.5 양쪽 근거로 **C54 = 4.7µF** 확정(요구사항 ASCII·기존 문서의 4.7nF는 오기).

**검증** — 서브에이전트 4개 fan-out, 전부 PASS(치명·중 0, 경미 3건):
- ① 회로 사실(JPG ground truth) — 부품값·핀좌표·연결·커넥터·신호명 전수 일치, C54 4.7µF 확인.
- ② 데이터시트 인용 — 전류(171/50/9 = Mutual 2ch @1.8V)·디커플링·저항·RDY pull-up·PXS/ATI/Interface 코드·reset 임계·RC fc(15.9MHz) 정확.
- ③ 구현·이슈 정합 — 시나리오·구현5·이슈·수치(340/660·200ms·1µs·2~3초) 일치, **추정 표기 적절·할루시네이션 0**.
- ④ 구조 — frontmatter·TL;DR·broken link 0·C54 정정 반영·Mermaid 유효.

**분석 부가가치**(데이터시트 권장 대비 차이 포착): I²C 풀업 회로측 부재(마스터측 추정)·CRX0 직렬 100Ω(권장 470Ω 미달)·전원경로 무필터 → 채터링/ESD 이슈와 연결. 개선 검토 후보: guard electrode(CRX1/TxA)·전원 페라이트·R31 재검토.
