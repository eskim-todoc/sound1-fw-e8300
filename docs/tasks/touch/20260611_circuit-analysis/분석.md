# 분석 — IQS323 터치 회로 구성·분석

**TL;DR**: 회로도 JPG를 ground truth로 대조한 결과 C54 오기(4.7nF→4.7µF) 발견. 기존 회로-구성.md와 중복이나 사용자 확정으로 별개 스터디 신규. 데이터시트 §2.5 권장 대비 I²C 풀업 부재·CRX0 직렬저항 100Ω(권장 470Ω) 차이가 분석 포인트.

## 3소스 대조

| 소스 | 성격 | C54 |
|---|---|---|
| `개발 요구 사항…md` (요구사항 ASCII) | 사용자 작성 회로·구현·이슈 | 4.7nF ✗ |
| `Touch Sensor Schematic.JPG` | **실제 회로도 (ground truth)** | **4.7µF ✓** |
| `레퍼런스/IQS323-회로-구성.md` | 기존 정리(2차) | 4.7nF ✗ |

- **C54 정정 근거**: JPG `4.7µF/0603` + 데이터시트 §2.5 VDD 권장(100pF+4.7µF) 양쪽 일치 → 4.7µF 확정. 나머지 부품값(R28·C55·C56·C57·C58·R30~R33·C51·C52)은 3소스 일치.

## 데이터시트 §2.5 권장 대비 차이 (분석 포인트)

| 항목 | 데이터시트 권장 | 실제 회로 | 해석 |
|---|---|---|---|
| I²C 풀업(SDA/SCL/RDY) | 4.7kΩ → VDD | **회로에 없음** | E8300 마스터 측 풀업 추정 — 확인 필요 |
| CRx 직렬 저항 | 470Ω (EMI/ESD) | CRX0 **100Ω**, CRX2 470Ω | CRX0가 권장보다 작음 → ESD/EMI 여유 분석 |
| VDD 디커플링 | 100pF + 4.7µF | C55 100pF + C54 4.7µF | 일치 |
| VREG 디커플링 | 100pF + 2.2µF | C57 100pF + C56 2.2µF | 일치 |
| RDY 커패시터 | 1nF | C58 1nF | 일치 |

## 현재 구현 ↔ 회로/데이터시트 연결

- self-cap CRX0 → PXS Mode 0x10, CRX0/CTx0 동일 채널([데이터시트 02·06]).
- autoATI 미사용·FIXED MULT/COMP → ATI Mode 'Compensation Only' 또는 divider/multiplier 고정([06 A.12]).
- 200ms CRX0→VSS 주기 방전 → Inactive Rxs(VSS) 활용한 self-cap 드리프트 억제.
- CRX1 CalCap → "CRX0를 VSS로 두려면 활성 채널 ≥1 필요" → 내부 CalCap(데이터시트 §5.12.3)을 더미 활성 채널로. **외부 C52 100nF/J4 배선과는 별개**(추정 명시).
- 스트리밍 모드 → Interface Selection=0([06 A.30]).

## 리스크

- JPG 해상도/판독 오류 → 검증 에이전트가 JPG 재판독 대조.
- 현재 구현·이슈의 회로적 해석에 추정 개입 → "추정" 명시, 단정 회피(할루시네이션 차단).
- 기존 회로-구성.md와 중복 → 역할 분리(레퍼런스 vs 스터디) + 링크.
