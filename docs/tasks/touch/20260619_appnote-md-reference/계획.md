## 2. Workflow 구성

- **phase 정리**: `parallel`(16) — 각 노드가 원문(job tmp txt / 코드)에서 담당 범위를 데이터시트 형식 md로 작성해 결과 폴더에 직접 Write. `model: sonnet, effort: high`.
- **phase 검증**: `parallel`(3, 자료별) — 작성된 md를 Read해 원문과 전수 대조, 할루시네이션(원문 부재·과장·섹션오류·방향오류) 적출. `effort: high`.
- 정리 노드는 서로 다른 파일이라 병렬 쓰기 충돌 없음.

## 3. 후처리 (오케스트레이터)

1. 검증 적출 항목 정정(원문 재확인 후).
2. 각 폴더 `README.md`(파일 인덱스) 작성.
3. 상위 `참고/touch/README.md`에 3개 폴더 링크 추가.
4. 기계 검증: 析 0 / broken link / frontmatter 전수.

## 4. 자율 진행 근거

은수님 "네가 알아서 정하고, 나 밥먹고 온다" = 폴더명·구조 재량 위임 + 승인 게이트 없이 완료까지. 제품 코드 비변경이라 H-2.5 저촉 없음.
