## 공통 컨텍스트

3종 자료(AZD004·AZD125·IQS323 예제코드)를 데이터시트 폴더식 중립 전체 레퍼런스 md로 정리. 원문 근거만(할루시네이션 금지), 데이터시트 형식(frontmatter+TL;DR+GFM+표+Alert), 析 금지. Workflow `agent({effort:"high"})` 경로 — effort 실제 적용.
