# 계획 — IQS323 터치 센서 RTT 런타임 튜닝 (v2)

**TL;DR**: 4개 파일 최소 수정. `tdc_drv_iqs323.c` 오버라이드 변수 삽입 + `tdc_ui_command.c` `--touch` 핸들러 + `main.c` 절전 루프 poll 1줄. 플래그=0이면 기존 코드 zero diff. 초기 thr/hyst=255(터치 무반응)로 시작, set 명령 후 apply로 적용.

---

## 변경 이력
- v1 → v2: ① thr/hyst 독립 오버라이드(valid와 분리), 초기값 255 / ② 입력 포맷 hex(0x 제외) / ③ 절전 전환 시 자동 적용 동작 명시 / ④ apply 구현 방식 명확화

---

## 1. 신규 심볼 정의

### 컴파일 플래그 (`tdc_drv_iqs323.h`)
```c
#define TDC_TOUCH_RTT_TUNING  0   // 1로 변경 시 RTT 튜닝 활성
```

### 오버라이드 구조체 (`tdc_drv_iqs323.h`, `#if TDC_TOUCH_RTT_TUNING` 내)

```c
typedef struct {
    uint8_t mult_lsb;
    uint8_t mult_msb;
    uint8_t comp_lsb;
    uint8_t comp_msb;
    uint8_t threshold;   // 항상 사용 (초기값=255)
    uint8_t hysteresis;  // 항상 사용 (초기값=255)
    bool    ati_valid;   // true = mult/comp도 override, false = 컴파일 상수
} tdc_iqs323_tuning_t;
```

> [!NOTE]
> `valid` → `ati_valid`로 분리. **thr/hyst는 TDC_TOUCH_RTT_TUNING 활성 시 항상 struct 값을 사용** — `ati_valid` 여부 무관. 초기값 255이므로 set 전까지 터치 무반응.

### 공개 API (`tdc_drv_iqs323.h`, `#if TDC_TOUCH_RTT_TUNING` 내)
```c
void tdc_drv_iqs323_set_normal_tuning(const tdc_iqs323_tuning_t *p);
void tdc_drv_iqs323_set_sleep_tuning(const tdc_iqs323_tuning_t *p);
void tdc_drv_iqs323_apply_tuning(void);   // 현재 모드 재초기화
void tdc_drv_iqs323_clear_tuning(void);   // thr/hyst=255 복귀 + ati_valid=false
void tdc_drv_iqs323_show_tuning(void);    // 현재값 RTT 출력
```

## 2. 파일별 변경 상세

### 파일_1: `tdc_drv_iqs323.c`

#### 2-1. 오버라이드 변수 초기화 (파일 상단)
```c
#if TDC_TOUCH_RTT_TUNING
static tdc_iqs323_tuning_t s_tdc_normal_tuning = { .threshold = 255, .hysteresis = 255, .ati_valid = false };
static tdc_iqs323_tuning_t s_tdc_sleep_tuning  = { .threshold = 255, .hysteresis = 255, .ati_valid = false };
#endif
```
→ 부팅 직후 thr=255, hyst=255이므로 터치 무반응. `--touch set ... + --touch apply` 후 비로소 반응.

#### 2-2. `write_ati_compensation()` — MULT/COMP 오버라이드
각 보드 변종 `#if` 블록(MINI/DEVELOP/PACKAGE) 모두에 동일하게 적용:
```c
#if TDC_TOUCH_RTT_TUNING
    uint8_t m_l = s_tdc_normal_tuning.ati_valid ? s_tdc_normal_tuning.mult_lsb : TDC_DRV_IQS323_ATI_MULT_LSB;
    uint8_t m_h = s_tdc_normal_tuning.ati_valid ? s_tdc_normal_tuning.mult_msb : TDC_DRV_IQS323_ATI_MULT_MSB;
    uint8_t c_l = s_tdc_normal_tuning.ati_valid ? s_tdc_normal_tuning.comp_lsb : TDC_DRV_IQS323_ATI_COMP_LSB;
    uint8_t c_h = s_tdc_normal_tuning.ati_valid ? s_tdc_normal_tuning.comp_msb : TDC_DRV_IQS323_ATI_COMP_MSB;
    write_register(0x38, m_l, m_h);
    write_register(0x39, c_l, c_h);
#else
    write_register(0x38, TDC_DRV_IQS323_ATI_MULT_LSB, TDC_DRV_IQS323_ATI_MULT_MSB);
    write_register(0x39, TDC_DRV_IQS323_ATI_COMP_LSB, TDC_DRV_IQS323_ATI_COMP_MSB);
#endif
```

#### 2-3. `tdc_drv_iqs323_apply_settings()` — THRESHOLD/HYSTERESIS
```c
// 기존: touch_settings_impl(TDC_DRV_IQS323_TOUCH_THRESHOLD, TDC_DRV_IQS323_TOUCH_HYSTERESIS);
#if TDC_TOUCH_RTT_TUNING
    touch_settings_impl(s_tdc_normal_tuning.threshold, s_tdc_normal_tuning.hysteresis);
#else
    touch_settings_impl(TDC_DRV_IQS323_TOUCH_THRESHOLD, TDC_DRV_IQS323_TOUCH_HYSTERESIS);
#endif
```

#### 2-4. `tdc_drv_iqs323_apply_sleep_settings()` — SLEEP MULT/COMP + THRESHOLD
```c
// MULT/COMP
#if TDC_TOUCH_RTT_TUNING
    {
        uint8_t m_l = s_tdc_sleep_tuning.ati_valid ? s_tdc_sleep_tuning.mult_lsb : TDC_DRV_IQS323_SLEEP_ATI_MULT_LSB;
        uint8_t m_h = s_tdc_sleep_tuning.ati_valid ? s_tdc_sleep_tuning.mult_msb : TDC_DRV_IQS323_SLEEP_ATI_MULT_MSB;
        uint8_t c_l = s_tdc_sleep_tuning.ati_valid ? s_tdc_sleep_tuning.comp_lsb : TDC_DRV_IQS323_SLEEP_ATI_COMP_LSB;
        uint8_t c_h = s_tdc_sleep_tuning.ati_valid ? s_tdc_sleep_tuning.comp_msb : TDC_DRV_IQS323_SLEEP_ATI_COMP_MSB;
        write_register(0x38, m_l, m_h);
        write_register(0x39, c_l, c_h);
    }
#else
    write_register(0x38, TDC_DRV_IQS323_SLEEP_ATI_MULT_LSB, TDC_DRV_IQS323_SLEEP_ATI_MULT_MSB);
    write_register(0x39, TDC_DRV_IQS323_SLEEP_ATI_COMP_LSB, TDC_DRV_IQS323_SLEEP_ATI_COMP_MSB);
#endif

// THRESHOLD/HYSTERESIS (기존 touch_settings_impl(255, 255) 대체)
#if TDC_TOUCH_RTT_TUNING
    touch_settings_impl(s_tdc_sleep_tuning.threshold, s_tdc_sleep_tuning.hysteresis);
#else
    touch_settings_impl(255, 255);
#endif
```

#### 2-5. `tdc_drv_iqs323_apply_tuning()` — apply 명령 구현

```c
void tdc_drv_iqs323_apply_tuning(void)
{
    if (tdc_is_iqs323_in_ulp_mode())
    {
        // 절전 모드: apply_sleep_settings 재호출 → 저장된 sleep tuning 값으로 재초기화
        ci_printi("[TOUCH-TUNE] apply: sleep mode re-init\r\n");
        tdc_drv_iqs323_apply_sleep_settings();
    }
    else
    {
        // 노말 모드: re-ATI 방식 — 새 MULT/COMP 레지스터 쓰기 후 ATI 재트리거
        ci_printi("[TOUCH-TUNE] apply: normal mode re-ATI\r\n");
        write_ati_compensation();    // 저장된 normal tuning 값으로 0x38/0x39 쓰기
        // touch_settings_impl은 ATI 재실행 없이도 즉시 반영됨 (레지스터 직접 쓰기)
        touch_settings_impl(s_tdc_normal_tuning.threshold, s_tdc_normal_tuning.hysteresis);
        re_ati_trigger();            // re-ATI 신호 → 새 MULT/COMP로 ATI 재보정
        wait_re_ati_done();          // 완료 대기 (~100ms)
    }
}
```

> [!NOTE]
> 노말 모드에서 `apply_settings()` 전체를 재호출하면 ACK/Confirm/reseed 등 부가 단계가 포함돼 부작용 가능. **MULT/COMP/THRESHOLD만 레지스터에 직접 쓰고 re-ATI**가 안전. `re_ati_trigger`·`wait_re_ati_done`·`write_ati_compensation`·`touch_settings_impl` 모두 같은 .c 파일 내 static이므로 호출 가능.

#### 2-6. 나머지 API 구현

```c
void tdc_drv_iqs323_set_normal_tuning(const tdc_iqs323_tuning_t *p)
{
    s_tdc_normal_tuning = *p;
    s_tdc_normal_tuning.ati_valid = true;
    ci_printi("[TOUCH-TUNE] normal: MULT=%02X%02X COMP=%02X%02X THR=%u HYST=%u\r\n",
              p->mult_lsb, p->mult_msb, p->comp_lsb, p->comp_msb, p->threshold, p->hysteresis);
}

void tdc_drv_iqs323_set_sleep_tuning(const tdc_iqs323_tuning_t *p)
{
    s_tdc_sleep_tuning = *p;
    s_tdc_sleep_tuning.ati_valid = true;
    ci_printi("[TOUCH-TUNE] sleep:  MULT=%02X%02X COMP=%02X%02X THR=%u HYST=%u\r\n",
              p->mult_lsb, p->mult_msb, p->comp_lsb, p->comp_msb, p->threshold, p->hysteresis);
}

void tdc_drv_iqs323_clear_tuning(void)
{
    s_tdc_normal_tuning = (tdc_iqs323_tuning_t){ .threshold = 255, .hysteresis = 255, .ati_valid = false };
    s_tdc_sleep_tuning  = (tdc_iqs323_tuning_t){ .threshold = 255, .hysteresis = 255, .ati_valid = false };
    ci_printi("[TOUCH-TUNE] cleared: thr/hyst=255, MULT/COMP=compile constants\r\n");
}

void tdc_drv_iqs323_show_tuning(void)
{
    ci_printi("[TOUCH-TUNE] normal ati_valid=%d MULT=%02X%02X COMP=%02X%02X THR=%u HYST=%u\r\n",
              s_tdc_normal_tuning.ati_valid, ...);
    ci_printi("[TOUCH-TUNE] sleep  ati_valid=%d MULT=%02X%02X COMP=%02X%02X THR=%u HYST=%u\r\n",
              s_tdc_sleep_tuning.ati_valid, ...);
}
```

### 파일_2: `tdc_ui_command.c`

#### 명령어 등록
```c
#if TDC_TOUCH_RTT_TUNING
    {"touch", handle_touch_tuning,
     "--touch show|clear|apply|set normal|sleep <ml> <mh> <cl> <ch> <thr> <hyst>"},
#endif
```

#### 핸들러 — hex 파싱 포함

```c
#if TDC_TOUCH_RTT_TUNING
// 0x 없는 hex 문자열 → uint8_t (예: "5E" → 0x5E, "200" 같은 10진도 허용)
static uint8_t parse_hex_byte(const char *s)
{
    return (uint8_t)strtol(s, NULL, 16);
}

static int handle_touch_tuning(int argc, char **argv)
{
    if (argc < 2) { return -1; }

    if (strcmp(argv[1], "show") == 0)
    {
        tdc_drv_iqs323_show_tuning();
    }
    else if (strcmp(argv[1], "clear") == 0)
    {
        tdc_drv_iqs323_clear_tuning();
    }
    else if (strcmp(argv[1], "apply") == 0)
    {
        tdc_drv_iqs323_apply_tuning();
    }
    else if (strcmp(argv[1], "set") == 0 && argc == 9)
    {
        // --touch set normal|sleep <ml> <mh> <cl> <ch> <thr> <hyst>
        // 모두 hex (0x 없이): 예) 82 6E E4 63 C8 C8
        tdc_iqs323_tuning_t t;
        t.mult_lsb   = parse_hex_byte(argv[3]);
        t.mult_msb   = parse_hex_byte(argv[4]);
        t.comp_lsb   = parse_hex_byte(argv[5]);
        t.comp_msb   = parse_hex_byte(argv[6]);
        t.threshold  = parse_hex_byte(argv[7]);
        t.hysteresis = parse_hex_byte(argv[8]);
        t.ati_valid  = true;

        if (strcmp(argv[2], "normal") == 0)
        {
            tdc_drv_iqs323_set_normal_tuning(&t);
        }
        else if (strcmp(argv[2], "sleep") == 0)
        {
            tdc_drv_iqs323_set_sleep_tuning(&t);
        }
        else { return -1; }
    }
    else { return -1; }

    return 0;
}
#endif
```

## 3. UI 명령어 사용법 (v2: hex 포맷)

```
--touch show
  → 저장된 파라미터 + ati_valid 상태 출력

--touch set normal 82 6E E4 63 C8 C8
  → 노말 모드: MULT=0x826E COMP=0xE463 THR=0xC8(200) HYST=0xC8(200)
  (모든 인자: 0x 없는 hex, 대소문자 무관)

--touch set sleep 82 62 E4 63 C8 C8
  → 절전 모드 파라미터 저장 (노말→절전 전환 시 자동 사용)

--touch apply
  → 현재 모드에 즉시 재초기화
  - 노말 모드: write_ati_compensation + touch_settings + re_ati_trigger (블로킹 ~100ms)
  - 절전 모드: apply_sleep_settings 재호출

--touch clear
  → thr/hyst=255 복귀, MULT/COMP=컴파일 상수 복귀
```

### 동작 흐름 (은수님 피드백 반영)

```
부팅
 └─ s_tdc_normal_tuning.threshold = 255 → 터치 무반응 (apply 전까지)
 
노말 모드
 ├─ --touch set normal 82 6E E4 63 50 50   ← 파라미터 저장
 ├─ --touch apply                          ← 즉시 재초기화 (re-ATI ~100ms)
 └─ 롱터치로 절전 진입
      └─ apply_sleep_settings() 호출 시 s_tdc_sleep_tuning 자동 사용
      
절전 모드 (200ms 주기 루프에서 RTT 폴링)
 ├─ --touch set sleep 82 62 E4 63 50 50    ← 절전 파라미터 수정
 └─ --touch apply                          ← apply_sleep_settings 재호출

절전 중 터치로 깨어남 → 워치독 리셋 → 부팅부터 다시 시작
 └─ 파라미터 RAM 초기화 → 사용자가 명령어 재입력
```

## 4. 구현 순서

1. `tdc_drv_iqs323.h`: 플래그 + `tdc_iqs323_tuning_t` + API 선언
2. `tdc_drv_iqs323.c`: 변수 초기화 + 2-2~2-6 수정 + API 구현
3. `tdc_ui_command.c`: `parse_hex_byte` + `handle_touch_tuning` + 테이블 등록
4. `main.c`: ULP 루프 poll 1줄 추가
5. 정적 검증: `TDC_TOUCH_RTT_TUNING=0` 경로 diff 없음, 괄호 균형, strtol 가용성

## 5. 위험 및 대응

| 위험 | 대응 |
|---|---|
| `re_ati_trigger`/`wait_re_ati_done`가 static이라 `apply_tuning` 내부에서만 호출 가능 | `apply_tuning` 함수를 같은 .c 파일 내 구현하면 해결 |
| `wait_re_ati_done()` 블로킹 ~100ms — main loop 지연 | 튜닝 용도로만 사용 (dev 빌드), 허용 수준 |
| `strtol` 미포함 환경 가능성 | `stdlib.h` 포함 여부 확인 필요 (구현 시 grep) |
| 절전 ULP 루프에서 `apply_sleep_settings()` I2C 호출 | 기존 절전 진입 경로와 동일 함수 → 이미 검증된 경로 |
