# 분석 — IQS323 터치 센서 RTT 런타임 튜닝

**TL;DR**: RTT UI는 `tdc_ui_command.c`의 `--<cmd>` 명령 테이블 구조, IQS323 파라미터는 `write_ati_compensation()`(노말)과 `apply_sleep_settings()`(절전) 두 지점에서 레지스터에 적용. 플래그로 오버라이드 변수를 삽입하면 두 함수 최소 수정으로 구현 가능.

---

## 1. RTT UI 시스템 요약

| 항목 | 내용 |
|---|---|
| 핵심 파일 | `src/2__cm3/Gen1_5/ui/tdc_ui_command.c` + `tdc_ui_command.h` |
| 입력 포맷 | `--<명령> [인자1] [인자2] ...` (센티널 `--` 필수) |
| 최대 라인 | 128바이트, 인자 최대 8개 |
| 핸들러 등록 | `s_tdc_commands[]` 테이블 (`name`, `fn`, `help` 구조체) |
| 폴링 호출 위치 | `func_normal()` L608: `tdc_ui_command_poll()` (ENABLE_UI_CMD 활성 시) |
| 절전 중 RTT | 현재 없음 — 측정 모드(`TDC_TOUCH_SLEEP_MEASURE_MODE`) 전용 's'키만 존재 |
| 파싱 방식 | 공백 기준 토큰화 → 선형 탐색 → 핸들러 콜백 |

## 2. IQS323 파라미터 적용 경로

### 노말 모드

```
tdc_drv_iqs323_apply_settings()          ← func_normal 경로에서 호출
  ├─ touch_settings_impl(THRESHOLD, HYSTERESIS)    ← L1040 영역
  └─ write_ati_compensation()
       ├─ write_register(0x38, MULT_LSB, MULT_MSB)  ← 보드별 #if 분기
       └─ write_register(0x39, COMP_LSB, COMP_MSB)
```

### 절전 모드

```
tdc_drv_iqs323_apply_sleep_settings()    ← func_sleep 진입 직전
  ├─ touch_settings_impl(255, 255)                  ← 임시 큰값 (터치 비반응)
  ├─ write_register(0x38, SLEEP_MULT_LSB, SLEEP_MULT_MSB)
  └─ write_register(0x39, SLEEP_COMP_LSB, SLEEP_COMP_MSB)
```

> [!NOTE]
> 절전 `touch_settings_impl(255, 255)` 하드코딩 이유: 수면 중 잘못된 터치 이벤트 방지 목적으로 보임. 튜닝 기능에서는 사용자가 SLEEP_THRESHOLD를 설정하면 그 값으로 대체.

### 재초기화(Re-ATI)

- `tdc_drv_iqs323_calib_re_ati()` — 캘리브레이션 모드용 공개 API
- `re_ati_trigger()` + `wait_re_ati_done()` — 내부 static (직접 호출 불가)
- **결론**: apply 명령 시 `apply_settings()` / `apply_sleep_settings()` 재호출이 가장 안전. Re-ATI보다 전체 재초기화가 파라미터 완전 적용 보장.

## 4. 변경 영향 분석

| 파일 | 변경 성격 | 회귀 위험 |
|---|---|---|
| `tdc_drv_iqs323.h` | 플래그 정의 + 구조체/함수 선언 추가 (`#if` 내) | 없음 (플래그=0이면 zero diff) |
| `tdc_drv_iqs323.c` | `write_ati_compensation()` + `apply_sleep_settings()` 내 `#if TDC_TOUCH_RTT_TUNING` 블록 삽입 | 낮음 (플래그=0이면 기존 경로 동일) |
| `tdc_ui_command.c` | `--touch` 핸들러 + s_tdc_commands 항목 추가 (`#if` 내) | 없음 |
| `main.c` (func_sleep) | `tdc_ui_command_poll()` 1줄 추가 (`#if` 내) | 없음 |

## 5. 절전 모드 RTT 입력 가능 여부

절전 ULP 루프:
```c
while (1) {
    SYS_WATCHDOG_REFRESH();
    SYS_WAIT_FOR_INTERRUPT;  // ~200ms wakeup
    // 터치 상태 체크
}
```
`SYS_WAIT_FOR_INTERRUPT` 이후 `tdc_ui_command_poll()` 호출 → 비블로킹 RTT 폴링 가능. 200ms 주기 간격이라 응답성은 낮지만 튜닝 목적으로 충분.
