# 요구사항 — IQS323 터치 센서 RTT 런타임 튜닝

**TL;DR**: 매번 하드코딩+재빌드 없이 RTT UI 명령어로 MULT·COMP·THRESHOLD·HYSTERESIS를 입력하고 터치 센서를 즉시 재초기화. 노말/절전 모드 각각 독립 파라미터 세트, 컴파일 플래그로 활성화.

---

## 기능 요구사항

| 번호 | 요구사항 | 우선순위 |
|---|---|---|
| 요구사항_1 | RTT UI 명령어로 노말 모드 ATI 파라미터(MULT_LSB, MULT_MSB, COMP_LSB, COMP_MSB, THRESHOLD, HYSTERESIS) 입력 가능 | 필수 |
| 요구사항_2 | RTT UI 명령어로 절전 모드 ATI 파라미터(동일 6개) 입력 가능 | 필수 |
| 요구사항_3 | "apply" 명령 실행 시 저장된 파라미터로 터치 센서 즉시 재초기화 | 필수 |
| 요구사항_4 | 노말 모드(func_normal)와 절전 모드(func_sleep) 양쪽에서 UI 명령 입력 가능 | 필수 |
| 요구사항_5 | 현재 저장된 파라미터와 적용 상태를 RTT로 조회 가능 | 필수 |
| 요구사항_6 | 파라미터 미설정(clear) 시 컴파일 상수(기존 하드코딩 값)로 자동 복귀 | 필수 |
| 요구사항_7 | 기존 터치 센서 함수(`tdc_drv_iqs323_apply_settings`, `apply_sleep_settings` 등) 로직 최대한 보존 | 필수 |
| 요구사항_8 | `#define TDC_TOUCH_RTT_TUNING` 플래그가 0일 때 본 기능 코드 전체 컴파일 제외(바이너리 영향 없음) | 필수 |

## 비기능 요구사항

- 절전 모드에서 RTT 폴링 추가는 `TDC_TOUCH_RTT_TUNING` 플래그 조건부로만 수행
- 신규 심볼은 `tdc_` 접두어
- 기존 `tdc_ui_command.c`의 명령어 등록 구조(s_tdc_commands 테이블) 활용

## 범위 외

- NVM/EEPROM 저장 (런타임 RAM 저장만)
- 다중 채널 독립 파라미터 (CH0만)
- ATI_SETUP 값 튜닝 (사용자 요청 없음)
