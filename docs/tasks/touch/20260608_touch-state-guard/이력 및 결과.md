## 완료 요약

- **auto-ATI 롤백**: ATI_SETUP_LSB 0x0C→0x08, write_ati_compensation() 복원 (SETUP+MULT+COMP)
- **정상 ATI 값**: PACKAGE MULT=0x5E82, COMP=0x63E4 (정상 노터치 실측)
- **절전 ATI 분리**: SLEEP_ATI 상수 추가 (MULT=0x5C82, COMP=0x6000), tdc_drv_iqs323_apply_sleep_ati() 신규
- **부팅 터치 무시**: READY 전이 즉시 터치 감지 → s_boot_touch_ignore=true → 해제 시 자동 복귀. 5초 지속 시 보라 깜빡임
- **절전 진입 시 터치 해제 대기**: func_sleep에서 ci_timer_init_prescaled 이전, 손 뗌 확인 후 apply_sleep_ati() 호출
- **수정 파일**: `tdc_drv_iqs323.c`, `tdc_drv_iqs323.h`, `tdc_touch.c`, `main.c`
