> **TL;DR**: 이전 auto-ati-reseed 변경 롤백 + 정상/절전 ATI 분리 + 부팅 터치 무시(5초 보라 깜빡임) + 절전 진입 전 터치 해제 대기 후 절전 ATI 적용.

## 수정 파일 목록

| 파일 | 내용 |
|---|---|
| `tdc_drv_iqs323.c` | auto-ATI 롤백, 정상/절전 ATI 상수 분리, 절전용 API 추가 |
| `tdc_drv_iqs323.h` | 절전용 reseed/ATI 함수 선언 추가, Threshold 80 유지 |
| `tdc_touch.c` | 부팅 직후 터치 무시 + 5초 보라 깜빡임 로직 추가 |
| `main.c` | func_sleep 터치 해제 대기 + 절전 ATI 적용, ULP reseed 제거 |

## 상세 변경 계획

### 그룹 A — 이전 변경 롤백 (auto-ati-reseed 작업)

**A1. ATI_SETUP_LSB 0x0C → 0x08** (tdc_drv_iqs323.c)
- ATI Mode=Full 롤백 → Disabled. 부팅 시 HW auto-ATI는 완료를 기다리지만, apply_settings() 이후 재실행 없음.

**A2. write_ati_setup() → write_ati_compensation() 복원** (tdc_drv_iqs323.c)
- ATI_SETUP + MULT + COMP 모두 쓰는 원래 함수 복원.
- apply_settings()에서 호출 복원.

**A3. func_sleep ULP 루프 reseed_done 제거** (main.c)
- 첫 반복 RESEED 블록 제거. 절전 ATI 전환 후 RESEED로 대체.

### 그룹 B — 정상/절전 ATI 상수 분리

**B1. 정상 모드 MULT/COMP 값 수정** (tdc_drv_iqs323.c, PACKAGE 변종)
```c
/* 정상 노터치 실측 기준 (2026-06-08) */
#define TDC_DRV_IQS323_ATI_MULT_MSB  0x5E
#define TDC_DRV_IQS323_ATI_COMP_LSB  0xE4
#define TDC_DRV_IQS323_ATI_COMP_MSB  0x63
```

**B2. 절전 모드 MULT/COMP 상수 추가** (tdc_drv_iqs323.c)
```c
/* 절전 노터치 실측 기준 (2026-06-08) — 변종 공통 위치 */
#define TDC_DRV_IQS323_SLEEP_ATI_MULT_LSB  0x82
#define TDC_DRV_IQS323_SLEEP_ATI_MULT_MSB  0x5C
#define TDC_DRV_IQS323_SLEEP_ATI_COMP_LSB  0x00
#define TDC_DRV_IQS323_SLEEP_ATI_COMP_MSB  0x60
```

**B3. 절전용 ATI 적용 공개 함수 추가** (tdc_drv_iqs323.c + .h)
```c
/* ATI를 절전 환경 기준으로 재설정하고 RESEED 실행 */
void tdc_drv_iqs323_apply_sleep_ati(void);
```
내부 동작:
1. SENSOR0_ATI_MULT에 SLEEP_ATI_MULT 기록
2. SENSOR0_ATI_COMP에 SLEEP_ATI_COMP 기록
3. RESEED (SYSTEM_CONTROL LSB=0x08)

### 그룹 C — 부팅 직후 터치 무시 + 5초 디버깅

**구현 위치**: tdc_touch.c — `tdc_touch_process()` 내부 상태머신

**동작**:
- READY 상태 진입 직후, 첫 번째 터치 상태 확인 시
- 터치 중이면 `s_boot_touch_ignore = true` 설정
- `s_boot_touch_ignore == true` 동안: 터치 이벤트 외부로 전달 안 함 (false 반환)
- 터치 해제 감지 → `s_boot_touch_ignore = false`
- 5초 경과 (READY 진입 시점 기준) 동안 `s_boot_touch_ignore`가 유지되면:
  → `led_request(LED_SRC_DBG, LED_ST_DBG_LONG_TOUCH_IGNORE)` 호출
  → 이후에도 계속 무시 유지 (해제 대기)

**추가 변수**:
```c
static bool    s_boot_touch_ignore   = false;
static int32_t s_boot_ready_tick     = 0;
static bool    s_boot_5s_warned      = false;
```

### 그룹 D — func_sleep 터치 해제 대기 + 절전 ATI 전환

**위치**: main.c, func_sleep() 내부 — ci_power_sleep() + i2c_set_master_prescale() 직후, ULP 루프 직전

```c
/* 절전 진입 시 3초 롱터치에서 손을 떼길 기다린 후 절전 ATI 적용 */
{
    tdc_touch_state_t state = TDC_TOUCH_STATE_RESET;
    while (tdc_touch_get_state(&state) &&
           state == TDC_TOUCH_STATE_TOUCH)
    {
        SYS_WATCHDOG_REFRESH();
    }
    tdc_drv_iqs323_apply_sleep_ati();  /* MULT/COMP 절전 기준 + RESEED */
}
```

## 검증 계획

1. 빌드 — 경고 없음
2. 부팅 터치 무시 — 손가락 누른 채 부팅 → 터치 이벤트 발생 안 함
3. 5초 디버깅 표시 — 5초 이상 누른 채 유지 → 보라색 깜빡임 확인
4. 정상 터치 — 손 뗀 후 터치 정상 반응
5. 절전 진입 — 3초 롱터치 → 절전 진입 → 손 떼면 LTA 절전 기준으로 재설정
6. 절전 false touch 없음 — 절전 모드에서 자연 해제로 재부팅 없음
