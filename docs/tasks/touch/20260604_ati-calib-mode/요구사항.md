> **TL;DR**: 조립 완제품에서 디버그 포트 없이 IQS323 최적 ATI 보상값 후보를 LED로 읽어내는 1회성 개발 도구 요구사항.

## 배경

Sound1 패키지 보드에서 자석·배터리가 터치 패드 주변에 근접 배치됨. 기생 정전 용량 증가로 인해 기존 하드코딩 ATI 보상값(MULT/COMP)이 새 조립 조건에 맞지 않을 수 있음. 조립 후에는 SWD 디버그 포트 사용 불가.

## 기능 요구사항

### F-1. 빌드 플래그 제어
- `TDC_TOUCH_ATI_CALIB_MODE` 컴파일 플래그로 모드 활성화
- 해당 플래그 미정의 시 기존 운용 코드와 완전히 동일하게 동작
- 프로덕션 빌드에 포함되지 않음

### F-2. ATI 자동 읽기
- 전원 ON 후 IQS323 초기 auto-ATI 완료를 기다림 (기존 로직과 동일)
- auto-ATI 직후, `apply_settings()` 호출 전에 IC가 자체 결정한 MULT·COMP 값을 I2C로 읽어옴
- ATI 타임아웃 시에도 동일한 흐름 진행

### F-3. 후보 테이블 매칭
- 미리 정의된 10개 (MULT_MSB, COMP_MSB, COMP_LSB) 후보 테이블 보유
- 읽어온 실제값과 테이블 후보 간 거리 계산 → 최근접 후보 인덱스 (1~10) 반환
- 거리 계산: COMP 16비트 값 기준 (MULT_MSB 보조 가중치 적용)

### F-4. LED 결과 출력
- 최근접 후보 인덱스 N에 대해:
  - 녹색 LED N회 점멸 (ON 400ms / OFF 200ms)
  - 800ms 정지
  - 빨간 LED 점등 유지 (완료 신호)
- 이후 무한 루프 (watchdog 리프레시 포함)

### F-5. 후보 테이블 범위
- MINI·DEVELOP·PACKAGE 기존 3개 값 포함
- 기존 PACKAGE보다 더 높은 정전 용량(자석·배터리 더 근접) 조건까지 커버
- 범위: COMP_MSB 0x48 ~ 0xA0 (10단계)

## 비기능 요구사항

- 기존 운용 로직 코드 경로에 영향 없음 (`#if` 완전 분리)
- LED arbiter 우선순위 충돌 없도록 직접 GPIO 제어 사용 (`LED_black()` 즉시 OFF)
- Watchdog 타임아웃 방지 (블로킹 delay 내 `SYS_WATCHDOG_REFRESH()` 삽입)
