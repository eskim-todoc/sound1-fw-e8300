## 완료 요약

- **신규 빌드 플래그**: `TDC_TOUCH_ATI_CALIB_MODE`
- **동작**: 전원 ON → auto-ATI 완료 → MULT/COMP I2C 읽기 → 10개 후보 최근접 인덱스 N 결정 → 녹색 N회 점멸 → 빨간 점등 → while(1)
- **수정 파일**: `tdc_drv_iqs323.h` (구조체·extern·API 선언), `tdc_drv_iqs323.c` (후보 테이블+`calib_find_candidate()`), `tdc_touch.c` (helper 함수+`try_finish_init()` 분기)
- **기존 운용 코드**: `#if`로 완전 분리, 영향 없음
