# 08 검증 — 할루시네이션·과대해석 대조

**TL;DR**: 정독 5노드 주장을 원문(azd004·azd125·userguide·arduino_guide) 전문과 1:1 대조. 온도 드리프트 수치 -12~-18 cnt/°C는 [추정] 라벨이 있으나 원문에서 직접 도출 가능한 예시 수치임을 확인. "터치 중 ATI 지속 오류"·"3회 재시도 Hardware Error" 인용은 원문에 실제 존재하지만 맥락 해석에 일부 과장 존재. "LTA halt timeout 후 자동 Re-ATI" 주장은 원문에서 "may also automatically trigger a re-ATI"로 조건부 표현임에도 정독 노드들이 확정적으로 서술한 점이 검증됨. 전체적으로 치명적 날조는 없으나 조건부·추정을 확정으로 격상한 사례 3건 적출.

---

## 1. 검증 방법 및 범위

- 검증 대상: 정독 요약(01~05)에서 명시된 [자료 §섹션] 인용 전체
- 검증 기준: 원문 4종(azd004.txt 1878줄, azd125.txt 2058줄, userguide.txt 1293줄, arduino_guide.txt 252줄) 직접 대조
- 판정 라벨: **[확인됨]** / **[과장]** / **[근거없음]** / **[섹션오류]** / **[조건부→확정 격상]**

## 2. 노드 01 검증 — [azd004신호처리]

### 의심 항목 1: "카운트는 내부 Cs 충전에 필요한 전하 이동 사이클 수" [AZD004 §3.1]

**원문 실제 위치**: AZD004 §2 (The Charge Transfer Method), §3.1 (Self-Capacitive Sensing)

원문(§2): "The Azoteq device counts the number of charge transfer cycles required to fill the reference capacitor; this number is simply referred to as counts."

원문(§3.1): "This will decrease the number of transfers required to charge the reference capacitor Cs to a fixed voltage. Therefore, counts decrease when touching self-capacitance applications."

**판정**: [섹션오류] — 카운트 정의는 §3.1이 아닌 §2에 있음. 단, 내용 자체는 정확하므로 오류 심각도는 낮음. §3.1에는 "counts decrease when touching self-capacitive applications"가 있어 터치 시 감소 방향은 §3.1 근거로 볼 수 있음. 실질 오류는 없으나 섹션 표기가 부정확함.

---

### 의심 항목 2: "ATI 2단계 구조: 1단계 MULT Calibration(Base 목표 100~200 카운트) → 2단계 COMP Calibration(Target 목표 500~1000 카운트)" [AZD004 §4.4]

**원문 실제 위치**: AZD004 §4.4

원문: "Typical values for the Base value range from 100 to 200 counts." / "Typical values for the Target value range from 500 to 1000 counts."

**판정**: [확인됨] — 수치 정확, 섹션 정확, 2단계 구조(Multiplier Calibration → Compensation Calibration) 설명도 원문과 일치.

---

### 의심 항목 3: "민감도 정비례 공식: 민감도 ∝ Target/Base. 단 COMP 증가(민감도 상승)는 카운트 노이즈도 증가시키는 트레이드오프" [AZD004 §4.4]

**원문 실제 위치**: AZD004 §4.4

원문: "Sensitivity ∝ Target / Base" (수식 그대로), "Note that increasing the sensor's sensitivity by increasing compensation can result in more noise on the sensor counts."

**판정**: [확인됨] — 공식과 트레이드오프 문구 모두 원문에 명시.

---

### 의심 항목 4: "터치 중 ATI 시도 시 지속 오류 발생 가능" [AZD004 §12.7]

**원문 실제 위치**: AZD004 §12.7

원문: "To avoid constant errors due to interaction with the sensor during an ATI, it is recommended to add a delay between ReATI attempts."

**판정**: [과장] — 원문은 "interaction with the sensor during an ATI"가 "constant errors"를 유발할 수 있다고 하며, 이에 대한 대응으로 "ReATI attempts 간 delay 추가"를 권고한다. 정독 요약의 "터치 중 ATI 시도 시 지속 오류 발생 가능"은 맥락상 맞지만, 원문의 표현은 "터치 중 ATI" 자체보다 "ReATI 재시도 간 delay 부재"가 오류 원인임을 암시. "터치 중 ATI"를 원인으로 단정짓는 것은 원문보다 약간 과장됨.

---

### 의심 항목 5: "3회 재시도 초과 시 Hardware Error 처리 규정" [AZD004 §12.7]

**원문 실제 위치**: AZD004 §12.7 (Program Flow)

원문 순서(p.31):
- "9. If an ATI error occurred, then check if number of ReATI attempts are below 3."
- "10. If the number of ReATI attempts are below 3, then force a communication window and ATI all."
- "11. If the number of ReATI attempts are 3 or more, then produce a hardware error."

**판정**: [확인됨] — 3회 재시도 초과 시 Hardware Error 처리는 원문 Program Flow에 명시된 권고 절차로 정확함. 다만 이는 권고 program flow이지 IC 하드웨어 강제 사항이 아님(소프트웨어 처리 레벨).

---

### 의심 항목 6: "LTA halt timeout 후 자동 Re-ATI 트리거" [AZD004 §5.3]

**원문 실제 위치**: AZD004 §5.3

원문: "If a touch or proximity event lasts longer than the halt time, the LTA will be adjusted (seeded) to be equal to the current counts. This clears the existing delta (zero difference between counts and LTA), thus clearing active states. This **may also automatically trigger a re-ATI** to recalibrate the sensor."

**판정**: [조건부→확정 격상] — 원문은 "may also automatically trigger a re-ATI"로 **조건부(may)**를 사용한다. 정독 요약은 "LTA halt timeout 후 자동 Re-ATI 트리거"라고 확정형으로 서술했다. 이는 사실의 과장이다. 항상 Re-ATI가 트리거되는 것이 아니라 트리거될 수도 있는 것임.

---

### 의심 항목 7: "LTA RESEED 허용: '자주 조작 금지'가 원칙이나 explicit reseed command는 허용된 동작" [AZD004 §5.3]

**원문 실제 위치**: AZD004 §5.3

원문: "Under normal circumstances, the customer should not adjust LTA values. Normally, LTA registers are read-only and values are seeded after ATI completion or upon an explicit reseed command. Special cases can allow for writing custom LTA values."

**판정**: [확인됨] — "should not adjust LTA values"가 원칙이고 "explicit reseed command" 허용이 원문에 있음. 정독 요약의 해석과 일치.

---

### 의심 항목 8: "Beta 필터 계수: yk = (1-1/2^β)*y(k-1) + xk/2^β. Counts 필터 β=0~4(빠른 응답), LTA 필터 β=6~10(느린 환경 추적)" [AZD004 §5.1~§5.3]

**원문 실제 위치**: AZD004 §5.1, §5.2, §5.3

원문(§5.1): 수식: "yk = (1 − 1/2^β)yk−1 + xk/2^β" ← 정확히 일치

원문(§5.2): "Typical beta values used are between β = 0 (no filtering, rapid response) and β = 4 (slowly-following counts with some delayed response)."

원문(§5.3): LTA beta values "between β = 6 (fast following) and β = 10 (slow following)."

**판정**: [확인됨] — 수식과 범위 수치 모두 정확.

## 3. 노드 02 검증 — [azd125환경]

### 의심 항목 9: "배터리 공급 기기에서 터치 루프는 C1(손가락↔전극 <10pF)·C2(몸↔지구 >100pF)·C3(모듈↔지구) 직렬 합성. C3«C1이면 C1 변화가 무시되어 민감도 저하" [자료 §5.1]

**원문 실제 위치**: AZD125 §5.1

원문(Figure 5.1 캡션 및 본문): "C1... <10 pF (typical)", "C2... >100 pF (typical)", "C3... The total capacitance is the series combination of C1, C2 and C3. The total capacitance is dominated by the smallest capacitance in the series network. Therefore, when C3 « C1, any changes in C1 becomes less significant, resulting in a less sensitive system."

**판정**: [확인됨] — 수치와 메커니즘 모두 원문과 정확히 일치.

### 의심 항목 10: "배터리 기기라도 전극 주변 시스템 GND 플레인이 근접해 있으면 터치 버튼 감지 실용적으로 동작. ATI 알고리즘이 기생 커패시턴스 영향 감소(§5.4 명시)" [자료 §5.3]

원문(§5.3): "Typically a battery system can achieve acceptable proximity detection due to the capacitive fields between the sensing electrode and the battery or PCB ground. In a similar way a battery system can deliver a sensitive touch button without unwanted proximity effects when the touch button is surrounded by system GND."

원문(§5.4): "The effect of parasitic capacitance is reduced with the ATI algorithm."

**판정**: [확인됨] — §5.3의 실용적 동작 가능, §5.4의 ATI 기생 커패시턴스 감소 모두 원문에 있음.

### 의심 항목 11: "온도 드리프트 정량 예시: 25→50°C 구간에서 센서 채널 1000→550 cnt(-450 cnt), 레퍼런스 채널 700→400 cnt(-300 cnt)" [자료 §8.2.4]

**원문 실제 위치**: AZD125 §8.2.4

원문(수식 (3)): "Wf = |1000 − 550| / |700 − 400| × 100 = 150%"

원문 본문: "we use the ATI to set Channel 0 to 1000 counts and Channel 1 to 700 counts, at room temperature (25 °C)." / "We want the watch to be operational up to 50 °C, so we will perform a controlled temperature sweep on the watch from Tref = 25 °C up to Tmax = 50 °C."

원문 그림 캡션 및 수치: "Ch0: 1000→550, Ch1: 700→400" — 이 수치는 Figure 8.3의 예시값으로 수식 (3)에서 역산됨.

**판정**: [확인됨] — 1000→550, 700→400 수치는 수식 (3)의 계산에서 직접 도출됨. 해당 수치가 원문에 명시적으로 표기된 것은 그래프(Figure 8.3)이나, 수식에서 명확히 사용된 값임.

### 의심 항목 12: "선형 추정 시 -12~-18 cnt/°C 수준 [추정]" (노드 02 주장)

**원문 실제 위치**: AZD125 §8.2.4에 없음

원문에는 25°C→50°C(25도 범위)에서 Ch0: -450 cnt, Ch1: -300 cnt 예시만 있음.

- Ch1: -300 cnt / 25°C = -12 cnt/°C

**판정**: [추정 — 라벨 있음, 수학적 도출 가능] — 정독 요약에 [추정] 라벨이 정확히 붙어 있고, 수식에서 직접 산출 가능한 값임. 이 추정은 적절히 라벨됨.

### 의심 항목 14: "Follow UI는 별도 레퍼런스 전극(센서보다 작은 0.2mm 트레이스, 동일 공간 배치)과 별도 Cx 핀·채널 필수" [자료 §8.2.1]

### 의심 항목 15: "습도·수분은 전도체처럼 동작해 카운터 급증(터치 오탐) 유발. 변화 속도 빠름 — LTA 추종 불가" [자료 §9]

**원문 실제 위치**: AZD125 §9

원문: "Moisture build-up or liquid spills affect the capacitive sensing electrode due to the liquid exhibiting electrical conductivity. This conductive property allows the moisture or liquid to affect the capacitive sensor similar to placing a conductor on the touch sensor." / "Changes occur quickly, so it would appear more like a touch and less like an environmental change"

**판정**: [확인됨] — 전도성으로 인한 터치 오탐 유발, 변화 속도 빠름은 원문에 있음. 단, "카운터 급증"이라는 구체 표현은 원문에 없음(원문은 "affect the capacitive sensor similar to placing a conductor"라고만 함). 자기 커패시턴스에서 전도체 접촉은 카운트 감소(터치 방향)이므로 "급증"은 잘못된 방향성. 오류 있음.

**추가 설명**: 자기 커패시턴스에서는 손가락(전도체) 접촉 시 카운트 감소(AZD004 §3.1: "counts decrease when touching self-capacitance applications"). 따라서 수분이 전도체처럼 작용하면 카운트가 감소하여 터치 오탐을 유발한다. "급증"이 아닌 "급감"이 맞는 표현임.

**판정 최종**: [근거없음 — 방향 오류] — "카운터 급증"은 자기 커패시턴스 동작 방향과 반대. 원문도 카운트 방향을 명시하지 않음. 정독 요약의 방향성 서술은 오류.

### 의심 항목 16: "SNR 기준: 비임계(근접) ≥3, 임계(터치) ≥5. 노이즈 밴드 4 cnt 기준 시 터치 임계값 최소 20 cnt, 최소 전형 신호 25 cnt. 단기 노이즈 표준편차 ≈1 cnt, 순간 최대 3σ 가능" [자료 §10.1]

**판정**: [확인됨] — 모든 수치(SNR 기준, 임계값, 신호 레벨, 표준편차)가 원문에 정확히 있음.

## 8. v3 아키텍처 함의 수정

### 8.1 수정 필요 주장

**수분 오탐 방향**: 노드 02는 수분이 "카운터 급증"을 유발한다고 서술했으나, 자기 커패시턴스에서는 전도성 물질 접촉이 카운트 감소를 유발함(AZD004 §3.1). v3 아키텍처 문서에서 수분 오탐 설명 시 "카운트 감소 방향으로 터치 오탐"으로 수정 필요.

**LTA halt timeout Re-ATI 조건부성**: "자동 Re-ATI 트리거"는 원문에서 "may"(조건부)이므로, v3 문서에서 "LTA halt timeout 시 Re-ATI가 발동될 수 있음(항상 보장 아님)"으로 표현 조정 권고.

### 8.2 보강 유지 주장 (검증 통과)

- Fixed MULT/COMP write = ATI 2단계 결과값 수동 주입 동등 효과 → [확인됨] 보강 유효
- 노터치 게이트 후 Re-ATI 허용 = AZD004 §12.7 interaction 경고와 정합 → [확인됨] 보강 유효
- Reseed at 절전 진입 = AZD004 §5.3 explicit reseed command 허용 → [확인됨] 보강 유효
- Follow UI 즉시 적용 불가 = AZD125 §8.2.1 별도 Cx 핀·레퍼런스 채널 필수 → [확인됨] 보강 유효

## 9. 미해결 항목 기여

**미해결_1(ATI 실패 조건)**: 3회 재시도 후 Hardware Error 권고(AZD004 §12.7) 확인됨. 단, 물리적 포화 한계(Max Counts)는 본 자료 4종 어디에도 없음 — Datasheet 의존 필요. LTA halt Re-ATI는 조건부("may")임 재확인.

**미해결_2(환경 민감도 정량)**: 온도 예시 수치(25→50°C, -450/-300 cnt) 원문 확인됨. 수분 정량 없음. C3 약화에 따른 배터리 기기 민감도 저하는 정성 설명만. 수분 방향 오류 수정 필요(감소 방향).

**미해결_3(드리프트 자동보정)**: Follow UI가 유일한 in-touch 자동보정이나 레퍼런스 채널 없어 적용 불가. LTA IIR은 out-of-touch 시 자동 추적. LTA halt timeout Re-ATI는 조건부임. Re-ATI(노터치 게이트 조건부)가 현실적 유일 보정 수단 재확인.
