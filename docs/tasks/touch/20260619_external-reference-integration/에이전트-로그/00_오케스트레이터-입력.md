# 00 오케스트레이터 입력 — 외부 레퍼런스 통합 분석

**TL;DR**: Azoteq 외부 자료 4종(예제코드·AZD004·AZD125·User Guide)을 **정독 5 → 매핑 2 + 검증 2(adversarial) → 종합 1** 구조로 분석한다. 각 노드는 현 제어 운영 방향(v3 Fixed+Auto-ATI 하이브리드)을 기준으로 유효 발췌하고, 모든 인용은 자료 내 실제 문구·섹션 근거를 명시한다(할루시네이션 금지). 한자 절대 금지(한글만).

---

## 1. 현 제어 운영 방향 (모든 노드 공유 컨텍스트)

- **v3 아키텍처(수렴)**: 공장 절대 기준으로 노터치를 판별하고, 노터치가 확인된 순간에만 Re-ATI를 허용한다 — 5층 방어(Fixed base → no-touch gate → conditional Re-ATI → self-healing → cradle race elimination).
- **현 펌웨어 사실**: 부팅 시 MCLR → Auto-ATI 1회 → 사전측정 고정 MULT/COMP write → ATI Mode=Disabled + CH timeout 비활성(이중 차단). 절전 진입 시 RESEED. 절전 복귀=WDT 리셋 재부팅.
- **직전 확정(20260618)**: ATI_Error는 conversion 정지 안 함(Fixed write로 무해화). Max Counts 포화만 conversion 정지 → MCLR 필요 → MCLR 조건부화 방향.
- **회로 제약(확정)**: CRX1 ESD 더미채널, C52 100nF DC-block(레퍼런스 UI 드리프트 보정법 사용 불가), 크래들 뚜껑 닫힘=터치 폴링 완전 중단(노터치 구간).
- **미해결 3항목(본 작업 핵심 목표)**:
  - 미해결_1: ATI가 실패하는 정확한 조건·경계
  - 미해결_2: 환경 드리프트(온도·배터리 잔량·터치 접촉) 카운터 변화 정량
  - 미해결_3: 드리프트 자동보정(Re-ATI 외) 메커니즘 유무
