# 외부 레퍼런스 통합 분석

**TL;DR**: 외부 자료 4종을 정독 5 + 매핑 2 + adversarial 검증 2 + 종합 1(10노드 Workflow)으로 분석했다. **최대 성과**: 그동안 "데이터시트 미명시"였던 온도 드리프트가 AZD125 §8.2.4에 정량 실측(25→50°C에서 센서 -450cnt, 약 -18cnt/°C, **방향=카운트 감소**)으로 존재함을 확인. v3 아키텍처 5대 결정은 전부 **보강** 판정(반증 0). 드리프트 자동보정 Follow UI는 우리 회로(더미채널+C52)로 **적용 불가** 확정 → 노터치 게이트 조건부 Re-ATI가 유일 능동 수단. 잔여 4항목은 IQS323 데이터시트 확인 필요.

---

## 1. 분석 방법

- **입력**: `iqs323-example-code`(.ino+드라이버+EV_KIT.h+addresses.h), `azd004`(센싱 일반론), `azd125`(설계 가이드), `IQS323 User Guide v1.1`.
- **구조**: Workflow 10노드 — 정독 5(자료별) → 매핑 2(제어방향·미해결질문) + adversarial 검증 2(할루시네이션·적용타당성) → 종합 1. 전 노드 `effort:high`, model:sonnet.
- **검증 신뢰도**: 08 할루시네이션 노드가 정독 인용 50여 건을 원문 1:1 대조 → [확인됨] 42·[과장] 3·[근거없음] 1·[섹션오류] 4. 적출 8건은 모두 종합(99)에 반영·정정.
- **노드 로그**: `에이전트-로그/01~09 + 99` (전수 생성, 한자 0).

## 2. 핵심 발견 (검증 통과분)

### 2.1 신호 처리 [AZD004]

- **카운트 정의·방향**: 카운트 = Cs 충전 전하이동 사이클 수 [§2]. 자기 커패시턴스 = 터치 시 카운트 **감소** [§3.1]. 현 펌웨어 `(LTA−Counts)×256/LTA` 판정과 정합.
- **ATI 2단계**: ① MULT Calibration(Base 100~200cnt 전형) → ② COMP Calibration(Target 500~1000cnt 전형) [§4.4]. **현 Fixed MULT/COMP write는 ATI 2단계 결과값 수동 주입과 수학적 동등**.
- **민감도 공식**: `민감도 ∝ Target/Base` [§4.4]. 민감도↑ = 노이즈↑ 트레이드오프.
- **Beta 필터**: `yk=(1−1/2^β)·y(k−1)+xk/2^β`. Counts β=0~4(빠름), LTA β=6~10(느림) [§5.2~§5.3].

### 2.2 환경 드리프트 정량 [AZD125] — 미해결_2 핵심

- **온도(유일한 정량 자료) [§8.2.4]**: ATI 후 카운터 고정 + ATI 비활성 상태에서 25→50°C 실험 → 센서 1000→550cnt(−450), 레퍼런스 700→400cnt(−300). 약 −18cnt/°C(센서, 추정). **방향=온도↑ → 카운트↓ = 고온에서 미탐(민감도 저하) 위험** (오탐 아님).
- **배터리/들고 있음 [§5.1]**: C1·C2·C3 직렬 합성, 배터리 기기는 C3↓ → 터치 delta↓. **방향만 확인, 정량 미명시**.
- **수분/습도 [§9 + AZD004 §3.1]**: 전도체로 작용 → 카운트 **감소** → 터치 오탐. 변화 빠름 = LTA 추종 불가. 정량 미명시. ※ 08 검증이 정독의 "카운트 급증" 서술을 [방향 오류]로 적출 → **감소로 정정**.
- **SNR 기준 [§10.1]**: 터치 SNR≥5(노이즈밴드 4cnt 기준 raw 20cnt 이상). 단 현 펌웨어 계수(delta×256/LTA) 단위 변환 검증 필요.

### 2.3 드리프트 자동보정 [AZD125 §8 / AZD004 §5] — 미해결_3 핵심

| 메커니즘 | 작동 | 현 회로 |
|---|---|---|
| LTA IIR 추적 | 노터치 시 자동(β 6~10) | **동작 중** — 1차 자동보정 |
| Follow UI | 인터치 중, 별도 레퍼런스 전극 필수 | **적용 불가** (CRX1 더미채널+C52 DC-block) |
| LTA halt timeout Re-ATI | stuck-touch 후 조건부("may") | **의도적 비활성**(이중 차단) |
| Reseed(수동) | 명시 명령(절전 진입) | **사용 중** |

→ **결론: 인터치 중 드리프트 보정인 Follow UI가 하드웨어 제약으로 불가 → 노터치 게이트 조건부 Re-ATI가 유일 능동 수단**. AZD125 §8.1 "when the device is not in touch" 원칙과 정확히 일치.

### 2.4 운영·코드 [User Guide / Arduino]

- **명령 의미**: ACK Reset(파워온 첫 단계, SYSTEM_CONTROL bit0=1) [§3.5.1] / ATI All=Re-ATI(re_ati 비트 → 전 채널 캘리브) [§3.5.3] / Reseed(LTA=현재 counts, ATI Target과 크게 다르면 ATI 트리거 "may") [§3.5.4].
- **현 드라이버 정합**: MCLR→Auto-ATI 대기→ACK Reset→Fixed write 순서가 자료 권고와 일치.
- **Filter Beta 미설정**: 현 펌웨어가 Filter Beta 레지스터를 명시 write 안 함 → IC 기본값 사용. EV-Kit 값(NP_LTA=5)과 동일 여부 미확인 = **잠재 튜닝 포인트**.
- **Event Mode 미채택**: streaming 추정. Arduino 예제의 `setEventMode()` 단계 없음 → 주기적 RDY로 통신/전류 증가 가능(최적화 여지, 단기 낮음).

## 3. 미해결 3항목 최종 결론

| 미해결 | 결론 | 잔여 |
|---|---|---|
| **_1 ATI 실패 조건** | 물리 경계값(Max Counts 포화) **자료 미명시**. 간접 근거 3개: 터치 중 ATI=constant errors[§12.7, 단 08이 "원인은 재시도 delay 부재"로 [과장] 적출]·3회 재시도 후 HW Error 권고·halt timeout 조건부 Re-ATI. 실용 치환: ATI Disabled로 부팅 1회 Auto-ATI에만 해당 → Max Counts 포화 감지+MCLR 조건부화로 관리 | 데이터시트: 포화 한계 정량 |
| **_2 환경 민감도 정량** | 온도만 정량 확보(−18cnt/°C, 감소 방향). 배터리·수분은 방향만, 정량 미명시 | 우리 카운트 기준 실측 |
| **_3 드리프트 자동보정** | Re-ATI 외 LTA IIR(노터치 1차 보정) 존재. Follow UI는 적용 불가 → 노터치 게이트 Re-ATI가 유일 능동 수단 | ATI Disabled에서 halt timeout Re-ATI 발동 여부 |

## 4. v3 아키텍처 함의

### 4.1 보강 확정 (변경 불필요) — 반증 0

| v3 결정 | 판정 | 최강 근거 |
|---|---|---|
| D1 Fixed MULT/COMP + ATI Disabled | 보강 | ATI 2단계 수동주입 동등 [AZD004 §4.4] |
| D2 노터치 게이트 조건부 Re-ATI | **보강(최강)** | AZD004 §12.7 + AZD125 §8.1 **두 자료 독립으로 노터치 원칙 명시** |
| D3 RESEED at 절전 진입 | 보강 | explicit reseed = 허용 동작 [§5.3] |
| D4 MCLR 조건부화 | 보강(부분) | ATI_Error=플래그, conversion 정지 없음(5노드 반증 0) |
| D5 CH timeout 이중 차단 | 보강 | halt timeout=자동 Re-ATI 경로[§5.3] → 이중 방어 정당 |
| Follow UI 미채택 | 보강(올바른 선택) | 회로 제약으로 채택 불가 확정 |

### 4.2 아키텍처 수정 불필요 — 구현 세부 정정 2건 (문서·주석만, 코드 무관)

- **정정_1**: 수분 오탐 방향 "카운트 급증"→"**감소**" (자기 커패시턴스 전도체 접촉 [AZD004 §3.1]).
- **정정_2**: "halt timeout 후 자동 Re-ATI 트리거"→"트리거**될 수 있음**(may, 항상 보장 아님)" [AZD004 §5.3].

### 4.3 신규 개선 포인트 (즉시 필수 아님)

| 항목 | 우선순위 |
|---|---|
| Filter Beta 검증(IC 기본값 vs NP_LTA=5) → 필요 시 명시 write | 중 |
| SNR≥5 기준 현 임계값 충족 검증(계수 환산) | 중 |
| 고온 환경 미탐 검증(카운트 감소가 임계 침범하는지) | 중 |
| Event Mode 전환(전류·노이즈 절감) | 낮 |
| 레이아웃 감사(CRX1 이격·I2C 4mm·오버레이 밀착) | 낮 |

### 4.4 데이터시트 확인 잔여 (외부 자료 4종으로 해소 불가)

1. MULT/COMP 포화 한계(Max Counts 발생 경계)
2. ATI Disabled에서 Reseed→ATI 자동 트리거 차단 효과
3. ATI Disabled에서 halt timeout→Re-ATI 발동 여부
4. Filter Beta IC reset 기본값

## 5. 산출 방향 (계획.md로 연결)

종합 노드(99)가 **단일 영속 참고 문서 골격**(§1 개요~§8 레이아웃 감사 + 개발 체크리스트)을 제안. 계획 단계에서 ① 영속 문서 위치·파일명 확정, ② 99 골격을 영속 문서로 정제, ③ 직전 작업(20260618) 분석.md §10·v3 99에 보강·정정 2건 반영 여부를 단계화한다.
