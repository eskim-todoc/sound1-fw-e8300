# 외부 레퍼런스 통합 분석 — 요구사항

**TL;DR**: 은수님이 `docs/참고/touch`에 추가한 Azoteq 외부 자료 4종(예제코드·AZD004·AZD125·IQS323 User Guide)을 **현 제어 운영 방향(v3 Fixed+Auto-ATI 하이브리드·노터치 게이트·MCLR 조건부화)** 관점에서 정독·매핑하여, 개발/구현에 직접 참조 가능한 영속 문서로 정리한다. 특히 그동안 "데이터시트 미명시"로 남았던 ATI 실패 조건·온도/전압/터치 민감도 정량·드리프트 자동보정 메커니즘을 자료에서 추출하는 것이 최대 가치.

---

## 1. 배경

- 직전까지 진행한 `20260618_touch-review`에서 v3 아키텍처(Fixed+Auto-ATI 하이브리드 + 노터치 게이트 + MCLR 조건부화)를 수렴했으나, **다음 항목이 "데이터시트 미명시"로 미결**:
  - ATI가 실패하는 정확한 조건·경계
  - 환경 드리프트(온도·배터리 잔량·터치 접촉)에 따른 카운터 변화 정량
  - 드리프트 자동보정(Re-ATI 외) 메커니즘 유무
- 은수님이 그 공백을 메우려 **외부 앱노트 4종을 신규 추가**(2026-06-19). AZD004/AZD125 앱노트는 이전 작업에서 "프로젝트에 없음"으로 확인됐던 바로 그 자료.

## 3. 요구사항

- **요구사항_1 (정독·근거)**: 4종 자료를 정독하되 현 제어 방향에 유효한 부분만 발췌. 모든 인용은 자료 내 실제 문구·섹션 번호 근거 명시(할루시네이션 금지).
- **요구사항_2 (미해결 질문 해소)**: 직전 미결 3항목(ATI 실패 조건·환경 민감도 정량·드리프트 자동보정)을 자료에서 추출. 자료에도 없으면 "자료에서도 미명시"로 명확히 표기.
- **요구사항_3 (제어방향 매핑)**: 각 발견을 v3 아키텍처(Fixed+Auto-ATI·노터치 게이트·MCLR 조건부화·Phase −1 버그)와 교차 — 보강/수정/반증 판정.
- **요구사항_4 (적용 타당성)**: 자료 권고가 우리 회로 제약(CRX1 ESD 더미채널, C52 100nF DC-block, 크래들 뚜껑 노터치 구간 등 기존 확정 사실)과 충돌하지 않는지 검토.
- **요구사항_5 (영속 문서)**: 결과를 `docs/참고/touch` 아래 적절한 위치에 개발 참조용 영속 문서로 정리. 폴더 신설 여부는 계획 단계에서 확정. frontmatter+TL;DR·GFM·Mermaid·한글 전용(한자 금지) 준수.
- **요구사항_6 (코드 비변경)**: 본 작업은 분석·문서화에 한정. 제품 소스 코드 변경 없음(Phase −1 버그 수정 등은 별도 작업으로 유지).

## 4. 산출물

- 4단계 산출: 본 `요구사항.md` → `분석.md` → `계획.md` → 단계 ④ 영속 문서
- `에이전트-로그/`: `00_오케스트레이터-입력.md` + 각 노드 `NN_<페르소나>.md` + `인덱스.md` + `99_종합.md`
