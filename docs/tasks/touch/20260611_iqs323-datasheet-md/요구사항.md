# 요구사항 — IQS323 데이터시트 원문 md 정리

**TL;DR**: 68p PDF 데이터시트를 매번 읽으면 컨텍스트 소모가 크다. `참고/touch/데이터시트/`에 빠짐없이·참조 쉬운 구조로 md 정리하고, 서브에이전트 교차검증으로 누락·오류·할루시네이션을 차단한다.

## 배경

- IQS323 데이터시트 = `docs/참고/touch/iqs323_datasheet.pdf` (Azoteq, v1.11, 68p, A4).
- 펌웨어 작업 중 레지스터·임계값·동작 확인 시 PDF Read → 매회 대용량 컨텍스트 소모.
- 기존 `참고/touch/레퍼런스/` 6개 md는 전부 2차 해설(개념·Sound1 적용). **원문 1차 정리물 부재**.

## 목표

1. 데이터시트 원문을 **빠짐없이** md로 정리 (값·비트·주소·공식·표 보존).
2. **참조하기 쉬운** 분할 구조 (논리 그룹 8파일 + 인덱스 README).
3. 정리 정확성을 **서브에이전트 다수 fan-out 교차검증**으로 보증 (누락/오류/할루시네이션 0).

## 수용 기준 (AC)

- **AC-1**: `참고/touch/데이터시트/`에 README + 01~08 md 생성, 데이터시트 §1~11 + 부록 A~C 전 구간 커버.
- **AC-2**: 각 파일 frontmatter 5필드 + TL;DR 구비. 내부 링크 broken 0.
- **AC-3**: `06_레지스터레퍼런스`가 §9 주소표 + 부록 A(A.1~A.37) 비트필드를 주소순 전수 수록.
- **AC-4**: 검증 에이전트 보고에서 치명·중 결함 0건 (전수 PASS).
- **AC-5**: `참고/touch/README.md`가 3축(데이터시트/레퍼런스/이슈해결)으로 확장, 데이터시트/ 8파일 등록.
- **AC-6**: 기존 `레퍼런스/IQS323-레지스터-맵.md` 무변경.
