# 분석 — IQS323 데이터시트 원문 md 정리

**TL;DR**: 기존 `참고/touch/` 6개 md는 전부 2차 해설이라 데이터시트 원문 1차 정리물이 부재. 신규 `데이터시트/`는 보완 관계(SSOT). 데이터시트 68p는 §1~11+부록 A~C 구조로 논리 그룹 8파일에 매핑된다.

## 기존 문서 현황 (서브에이전트 조사)

| 폴더 | 파일 | 성격 |
|---|---|---|
| 레퍼런스/ | 동작원리·개념-종합가이드·RESEED | 2차 해설(개념·비유·Sound1 실측) |
| 레퍼런스/ | 회로-구성 | Sound1 하드웨어 전용(데이터시트 무관) |
| 레퍼런스/ | 레지스터-맵 | 원문 부분 발췌 + Sound1 함정 혼합(전수 아님) |
| 이슈해결/ | 2026-06_CRX1-ESD-더미채널 | 트러블슈팅 로그 |

- **결론**: 원문을 빠짐없이 옮긴 1차 정리물 없음. 신규 `데이터시트/`와 중복 아닌 **보완** 관계.
- 유일 부분중복 = `레지스터-맵.md` → 사용자 지시로 **건드리지 않음**.
