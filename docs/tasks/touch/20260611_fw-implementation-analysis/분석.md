# 분석 — IQS323 터치 펌웨어 구현·시퀀스 분석

**TL;DR**: Explore 3개 + Claude 직접 Read로 코드 매핑. 2계층 구조, init→apply_settings(9단계), CH1 CalCap 더미, ATI FIXED(보드변종), 200ms 방전, 노말 2.4s/절전 2.2s. 직접 Read로 서브에이전트 누락·코드 내부 불일치 다수 포착.

## 코드 매핑 (ground truth)

| 영역 | 파일:라인 | 핵심 |
|---|---|---|
| 기능 레이어 | `tdc_touch.c` | init_begin(289)·process(301)·get_state(379)·proc_long_touch(78)·try_finish_init(216) |

## 직접 Read로 포착한 사실 (서브에이전트 누락/코드 내부 불일치)

1. **apply_sleep_settings 255/255 → reseed 100/80 (2단계)**: `apply_sleep_settings()`(line 965)는 threshold/hysteresis를 **255/255**(둔감)로 쓰고, `ci_power_sleep()` 후 `reseed()`(line 921)가 **100/80**으로 복원하며 RESEED. 서브에이전트는 reseed의 100만 포착.
2. **PACKAGE ATI define = 0x5C82/0x63EF**(line 667~670)인데 **바로 위 주석 표(line 640)는 0x5E/0xE4** — 코드 내부 주석↔define 불일치.
3. **prox_settings no-op**: `apply_settings`가 `prox_settings(120)` 호출하나 `PROX_THRESHOLD_ENABLE=0`이라 내부에서 `(void)threshold; return true`(레지스터 미기록).
4. **INACTIVE_RXS_CRX0_VSS=0x02**: 데이터시트 A.10 표(0x00/05/0A/0F)에 없는 **핀별 2비트 해석**(bits[1:0]=CRX0). 코드 주석 기반.
5. **코드 주석↔상수 불일치**: `tdc_touch.h` "2.8초 롱터치", `tdc_touch.c:76` "3초", `tdc_touch.c:334` "100ms 폴링" ≠ 실제 LONG_TOUCH 2400ms·POLL 200ms.

## 대조 축

- 요구사항 현재구현 5종(self-cap·FIXED·200ms 방전·CalCap·스트리밍) ↔ 코드 ↔ 데이터시트 권장.
- 이슈 9건 ↔ 코드 대응(autoATI 미사용·고정 threshold·ati_error 무시 등).

## 리스크

- 코드 라인 환각 → 검증 에이전트가 실제 코드 재대조(레지스터 값·라인 1건 불일치=치명).
