## 결정 사항

- 위치: `참고/touch/개선/펌웨어 구현·시퀀스 분석.md` (회로 문서의 SW 짝). 회로 문서와 별개.
- 코드 사실 = 직접 Read한 라인 ground truth. 추정은 명시.
- 개선안 도출 아님 — 현재 구현 정확 정리 + 쟁점 제기(적정성 검토는 후속).

## 완료 요약

**산출물**
- `참고/touch/개선/펌웨어 구현·시퀀스 분석.md`(14절+부록) — 2계층 구조·빌드설정·초기화·apply_settings 9단계·sensor_setup·ATI FIXED·200ms 방전·터치 판정·롱터치 FSM·전원모드 연계·통신 + 요구사항/데이터시트 대조 + SW 쟁점 9건.
- `개선/README.md` 펌웨어 문서 등록(회로 문서 짝).

**작성 방식**: Explore 3개로 코드 매핑 → **핵심 구간 Claude 직접 Read로 확정**(라인 환각 배제). 레지스터값 데이터시트 06 교차. 추정·미확인 명시.

**검증** — 서브에이전트 5개 fan-out, 전부 PASS(치명·중 0, 할루시네이션 0):
- tdc_touch/tdc_drv/main 코드정합 — 함수·라인·**레지스터 write 값**(apply_settings 9단계·sensor_setup·ATI 0x5C82/0x63EF·discharge 0x02/0x01·RESEED 0x08·CH timeout 0x07)·상수(100/80·200·2400·2200·11) 전부 코드 일치.
- 데이터시트 대조 — **§8 쟁점(코드 INACTIVE_RXS↔데이터시트 A.5 비트정의 불일치) 객관적 타당 독립 확인**, PXS/ATI/CalCap 인용 정확.
- 추정 표기 적절(단정 둔갑 0), 개선안 미도출 준수, 구조 무결.

**직접 Read 부가가치**: 서브에이전트 누락분 포착 — ① **절전 threshold 255/255→reseed 100/80 2단계** ② **PACKAGE ATI define 0x5C82/0x63EF ≠ 주석표 0x5E/0xE4**(코드 내부 불일치) ③ prox_settings no-op ④ write_and_verify 값 미검증 ⑤ 코드 주석↔상수 불일치(2.8초/3초/100ms).

**SW 쟁점(분석·후속 검토)**: autoATI 포기→FIXED+주기방전 우회 인과, 고정 threshold의 카운트변동 취약, write_and_verify 미검증, 절전 2단계 의도(추정), **데이터시트 vs 코드 레지스터 해석 차이(§8, 실측 확인 필요)**, prox 비활성, 보드변종 ATI 실측 의존, ati_error 전역 무시.

**AC 충족**: AC-1~5 전부.

**향후**: README 로드맵 — 현재 구현 적정성 판단·autoATI vs FIXED·드리프트·채터링/콜드부트·ESD. §8 데이터시트 해석 차이는 실칩 측정으로 우선 규명 권고.
