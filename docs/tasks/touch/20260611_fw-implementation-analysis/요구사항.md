# 요구사항 — IQS323 터치 펌웨어 구현·시퀀스 분석

**TL;DR**: 현재 펌웨어가 IQS323을 **무엇을 어떻게** 설정·운용하는지 코드 ground truth로 분석·정리(개선/). 요구사항·데이터시트와 대조. 적정성 검토의 기반(개선안은 후속), 할루시네이션 없게 검증.

## 배경

- 회로(HW) 분석 완료. 은수님 지시로 **SW 관점** 현재 구현 코드·설정 시퀀스를 요구사항·데이터시트와 함께 분석.

- 코드 = `src/2__cm3/Cortex-M3-src/systemControl/tdc_touch.*·tdc_drv_iqs323.*·tdc_touch_config.h` + `main.c`·`initialize.c`.

1. 현재 펌웨어 구현(레이어 구조·초기화·채널설정·ATI·방전·판정·전원연계·통신)을 **코드 ground truth**로 정리.
