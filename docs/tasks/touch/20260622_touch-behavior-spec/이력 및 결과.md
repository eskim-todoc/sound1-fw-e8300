터치센서(IQS323) 전원 ON부터 절전 ULP 재부팅까지 전체 동작 플로우차트(부팅·노말 폴링·이벤트 E1~E11·stuck S1~S3·Re-ATI 게이트·에러/예외·절전 ULP) + 레지스터 설정 전수표(노말 18건·절전 2건·read 1건, 주소·값·비트 의미·데이터시트 근거·코드 라인)를 단일 스펙 `터치센서 동작·레지스터 스펙.md`로 작성. ground truth = 리팩토링 신규 3파일 소스 코드.
