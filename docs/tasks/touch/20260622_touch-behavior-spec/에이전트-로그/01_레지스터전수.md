# 01 레지스터 전수 추출

> **TL;DR**: tdc_touch_iqs323.c에서 write_register/read_register 호출을 전수 추출. 노말 설정 13건 + 절전 설정 2건 = 총 15건. Full ATI(0x36=0x040C), Touch Threshold(0x62=0x1008), Beta 4종(0xB0~0xB4), Power Mode(0xC0), LP Rate(0xC2), PM Timeout(0xC5), Events Enable(0xD3) 망라.

## 1. 노말 설정 — apply_settings() 호출 순서

`tdc_touch_iqs323_apply_settings()` [tdc_touch_iqs323.c:334-372] 가 부팅 1회 실행. 내부 순서:

1. ack_reset() → write 0xC0
2. confirm_reset() → read 0x10 (10회 루프)
3. sensor_setup() → write 0x50, 0x40, 0x30
4. touch_settings() → write 0x62
5. events_enable() → write 0xD3
6. beta_power_settings() → write 0xB0, 0xB1, 0xB2, 0xB4, 0x31, 0xC0, 0xC2, 0xC5
7. ATI Setup write → write 0x36
8. Boot Re-ATI → write 0xC0 (bit2)
9. RESEED → write 0xC0 (bit3)

## 6. Full ATI 핵심값 상세

| 항목 | 값 | 의미 |
|---|---|---|
| 0x36 전체 | 0x040C | Full ATI 모드. IC가 게인(Compensation+Multiplier) 자동 산출. MULT/COMP 레지스터(0x38/0x39) write 불필요 |

## 7. Touch Threshold 계수 상세

| 항목 | 값 | 의미 |
|---|---|---|
| Threshold 계수 (노말) | 16 (0x10) | 절대 임계 = (16 × LTA) / 256 = LTA × 6.25%. 계수 < 32 필수(FullATI SNR 하한) |
| Hysteresis 계수 (노말) | 8 (0x08) | Hysteresis = (8/256) × Threshold ≈ Threshold의 50%. 바운스 방지 |
| Threshold (절전) | 255 (0xFF) | (255 × LTA) / 256 ≈ LTA. 실질 무감 — 의도적 오탐 방지 |
| Hysteresis (절전) | 255 (0xFF) | 동일 최대값 |

> [!NOTE]
> DS A.17 Touch Settings 비트필드: 하위 바이트(LSB)=`TOUCH_THRESHOLD`[7:0], 상위 바이트(MSB)=`TOUCH_HYSTERESIS`[15:12]. Hysteresis 4bit(MSB bit[15:12])에 8(=0x8)을 쓰면 상위 바이트에서 bit[7]=1 위치(0x08을 MSB로 쓰므로 bits[15:8]=0x08). 실제 Hysteresis 필드는 상위 4비트(bits[15:12])이므로 MSB=0x08=0b00001000 → Hysteresis=0(bits[15:12]=0000). **코드 의도와 실제 비트 매핑 불일치 가능성 있음 — 실측 게이트 권고**.
