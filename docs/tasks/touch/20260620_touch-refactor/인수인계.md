## 3. 제어방법 (구현된 동작)

| # | 제어 | 구현 위치 |
|---|---|---|
| 1 | 부팅: MCLR→auto-ATI→ACK→setup→**Full ATI(0x36=0x040C)**→부팅 Re-ATI→READY | `tdc_touch.c`(init)+`iqs323.c`(apply_settings) |
| 2 | 노말 200ms 폴링·상태매핑·read hold | `tdc_touch.c`+`logic.c` |
| 3 | **Re-ATI 게이트(급소)**: 노터치 AND ati_active==0 AND ati_error AND 쿨다운 → 터치 중 보류 | `logic.c` |
| 4 | stuck 3단계: 30/60/90초 → RESEED→Re-ATI→MCLR | `logic.c`(stuck_eval) |
| 5 | 롱터치 2400ms 엣지 래치 → 절전 트리거 | `logic.c` |
| 6 | Beta/Power write (0xB0~B4·0xC0/C2/C5·0x31) | `iqs323.c`(beta_power_settings) |
| 7 | 단일채널 CRX0 (CH1/CH2 disable) | `iqs323.c`(sensor_setup) |
| 8 | 절전 ULP 2.2초 카운트 (구조 유지) | `main.c` func_sleep |
