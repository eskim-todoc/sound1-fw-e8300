## 3. 순수 FSM (테스트 대상)

- 공개 3함수: `logic_init(st,now_ms)`·`set_boot_ignore(st,now_ms)`·`logic_step(st,in,out)`. cfg 인자 폐기(상수 직접 참조).
- in `{now_ms,read_ok,pressed,ati_error,ati_active}` → out `{action,long_touch,curr_state,state_changed,boot_event}`(5필드). 상태 9필드(분산 static 통합).
- 내부 static `stuck_eval` 1개. 게이트·롱터치는 본문 인라인.
- **mock 0 유닛테스트**: 전역·static 0, in→out 결정론 → `st` 주입만으로 격리. (Rev.1 포트 mock 추상 불필요)

## 4. 제어방법 8대 매핑 (FullATI 단순안 보존)

부팅·노말폴링·**Re-ATI 게이트(터치중 보류 급소)**·stuck 3단계·SW 타임아웃·Beta/Power·단일채널·절전 → 파일·함수 1:1(99 §2). B99 §3 이벤트표(E1~E10·S1~S3) 전수 동등. 게이트(NOT_TOUCH)·stuck(TOUCH) 배타 → 단일 action 안전. read 실패 입력 정규화로 stale 캐시 race 0(전역 캐시 미신설).

## 5. 시간 상수 자동 파생

`tdc_touch_time.h`: ms 상수 + `TDC_TIME_TO_CNT(ms,interval)` 올림. 등가 1:1(`(2200,200)=11`·`(2000,200)=10`). ms 차분 판정(폴링·롱터치·stuck)은 카운트로 안 바꿈(지터 0). 절전 wake/롱터치도 ms→카운트 자동.

## 7. 마이그레이션·계획 연결

99 §5가 M1~M6 제시 — M1 time.h → M2 logic 신설+호스트 테스트 골격 → M3 iqs323 슬림화(880줄 삭제) → M4 연결 재배선(봉합 적용) → M5 config 정리 → M6 실기. 각 단계 빌드 가능(점진). 공개 API 3종 불변(main.c 0변경). 계획.md(Rev.2)에서 정식화. 정량 8종은 M6 실기 [실측 게이트].
