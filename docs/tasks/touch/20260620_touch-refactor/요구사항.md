# 터치 코드 3레이어 리팩토링 — 요구사항

**TL;DR**: Full ATI 터치 제어(20260619 구현, 미커밋)의 동작을 **기능 동등 보존**하면서, ① 시간 상수(폴링·롱터치·절전 wake)만 바꾸면 파생값(카운트·임계)이 자동 계산되게 하고, ② 코드를 **3레이어(HW 드라이버 / 순수 터치 FSM 로직 / 시간·이벤트 어댑터)**로 전면 재구조화한다. 순수 로직은 HW 비의존(I2C 등은 모듈 함수 호출로 격리)으로 만들어 유닛/모듈 테스트가 용이하도록 **작고 간단한 함수**로 분리한다. 워크플로우 다페르소나로 분석·설계·구현·검증·문서화한다.

---

## 1. 배경

- 20260619 Full ATI 구현(5파일 +458/−25, 미커밋, 정적 검증 PASS)이 기능은 수렴했으나 구조가 단일 파일에 절차적으로 뭉쳐 있어 유닛/모듈 테스트가 어렵다.
- 동작 분석(8노드)에서 폴링 200ms·롱터치 2400ms가 상수이나 파생값과의 연결이 암묵적임이 드러남.
- 은수님 지시: 시간 상수 자동 파생 + 터치 코드 전면 리팩토링(테스트 용이·작고 간단) + 워크플로우 문서화.

## 2. 핵심 설계 방향 (은수님 확정 — Rev.2 간결화)

> [!IMPORTANT]
> **Rev.1(3레이어 + 포트 추상) 폐기 (2026-06-20)**: 초기 3레이어 설계(L1 포트 추상·mock·L3 어댑터 분리)는 HAL/driver식 추상 레이어가 과도해 은수님 목표(의료기기 SW 밸리데이션 대비 **작고·간결·명확**)와 반대로 무거워졌다. 미커밋 구현 전부 git 되돌림. **Rev.2: HAL/driver 추상 탈피 + 2~3파일 간결 구조**로 재설계.

| 방향 | 내용 (Rev.2) |
|---|---|
| **목적** | 의료기기 SW 밸리데이션(유닛/모듈 테스트) 대비 — 코드가 작고·간결·명확·테스트 쉬운 구조 |
| **테스트 방식** | **순수 제어 로직만 HW 비의존으로 분리**(유닛테스트 대상). HW는 추상 레이어 없이 직접 함수 호출. 테스트는 향후 밸리데이션 팀이 작성(구조만 쉽게) |

| **HAL/driver 탈피** | 포트 vtable·mock·어댑터 분리·다중 추상 레이어 없음. 평평하고 직관적으로 |

## 3. 요구사항

- **요구사항_1 (시간 상수 자동 파생)**: 폴링 주기·롱터치 시간·**절전 wake 주기·절전 폴링·절전 롱터치**를 ms 단위 상수로 정의하면, 파생값(웨이크업 카운트·롱터치 카운트·임계 등)이 매크로로 **자동 계산**(올림 나눗셈 등)되어 동작. 은수님이 상수만 바꾸면 됨.
- **요구사항_2 (3레이어 분리)**:
  - **L1 HW 드라이버**: I2C·레지스터 read/write·force window — IQS323 종속. 순수 로직과 분리.
  - **L2 순수 터치 FSM 로직**: 상태머신·이벤트 처리·롱터치·Re-ATI 게이트·stuck 에스컬레이션 — **HW 비의존 순수 함수**(입력=상태·시간·플래그, 출력=액션·다음상태). 테스트 가능.
  - **L3 시간·이벤트 어댑터**: 시간 상수→파생, 폴링 게이팅, L2 액션을 L1 호출로 연결.
- **요구사항_3 (테스트 용이)**: 순수 함수는 입력→출력 결정론(전역 상태 최소화·주입). HW 의존성은 L1 인터페이스(함수 포인터/콜백 또는 모듈 호출)로 격리해 mock 가능. 작고 단일 책임 함수.
- **요구사항_4 (Full ATI 동작 보존)**: 20260619 동작(부팅·노말·절전·게이트·stuck·급소 수정) 기능 동등. 회귀 0.
- **요구사항_5 (워크플로우 문서화)**: 다페르소나 워크플로우로 현 코드 분석·3레이어 설계·구현·검증. 페르소나 json·로그·종합·순서도 전부 문서화.
- **요구사항_6 (한글·스타일)**: 한자 절대 금지. `tdc_` 접두어. 중괄호 필수. frontmatter+TL;DR.
