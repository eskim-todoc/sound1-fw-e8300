# 00 오케스트레이터 입력 — 터치 간결 재작성 (Rev.2)

**TL;DR**: Rev.1 3레이어(포트 추상·mock·어댑터 분리)를 폐기하고, **HAL/driver 추상 탈피 + 2~3파일 간결 구조**로 FullATI 단순안 제어를 재설계한다. 목적은 의료기기 SW 밸리데이션 대비 — **작고·간결·명확·테스트 쉬운** 코드. 순수 제어 로직만 HW 비의존으로 분리(유닛테스트 대상), HW는 추상 레이어 없이 직접 I2C. 제어방법정리 → 순수FSM·I2C직접·연결 설계 → adversarial 검증 → 종합. effort xhigh. 한자 금지.

## 1. 목표 (은수님 확정 Rev.2)

- **구조**: 2~3파일 간결 — ① 순수 제어 FSM(HW 0, 테스트) ② IQS323 I2C 직접 접근(드라이버 추상 탈피) ③ 얇은 연결.
- **HAL/driver 탈피**: 포트 vtable·mock·어댑터 분리·다중 추상 레이어 **없음**. 평평·직관.
- **테스트 용이**: 순수 제어 로직만 분리(유닛테스트 대상). 테스트는 향후 밸리데이션 팀 작성 — 구조만 쉽게.
- **제어방법**: FullATI 단순안(Full ATI·Re-ATI 게이트·stuck 3단계·SW 타임아웃·Beta·단일채널·시간상수 파생). 설계 확정본 재구현.
- **동작 보존**: 제어방법 기능 동등(회귀 0). 단 구조는 간결화.
