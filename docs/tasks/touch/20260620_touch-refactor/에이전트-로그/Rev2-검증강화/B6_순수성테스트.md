### 기준 ④ time.h HW 심볼 혼입 — 단독 include 시 문제 여부 — 조건부 무해(잠재 취약 [경미])

핵심 발견: `tdc_touch_time.h` 가 HW SDK 심볼을 **미선언 참조**.
- [tdc_touch_time.h:42] `#define TDC_TOUCH_ULP_TIMER_PRESCALE TIMER_PRESCALE_128`
- `TIMER_PRESCALE_128` 은 `src` 트리 어디에도 자체 정의 없음(grep 결과: time.h 본 라인 + `2__cm3_factory/.../main.c` 참조뿐, **정의처 0**). → 벤더 SDK(Ezairo/RSL CMSIS 계열) 헤더가 `ci_timer.h` 경유로 제공 [미명시: 정확한 SDK 헤더 경로 정본 미확인].
- `tdc_touch_time.h` 는 include 0건 → `TIMER_PRESCALE_128` 을 스스로 끌어오지 못함. 즉 **time.h 는 자체 완결(self-contained) 헤더가 아님**.

그러나 **컴파일 무해**인 이유(전처리 의미론):
- C 전처리에서 함수형/객체형 매크로 본문은 **전개(expand)될 때만** 토큰화·식별자 해석됨. 정의만 있고 미전개면 `TIMER_PRESCALE_128` 은 비활성 텍스트.
- `tdc_touch_logic.c` 가 전개하는 time.h 매크로 전수: `TDC_TOUCH_BOOT_WARN_MS`(5000)·`TDC_TOUCH_RE_ATI_COOLDOWN_MS`(2000)·`TDC_TOUCH_LONG_TOUCH_MS`(2400)·`TDC_TOUCH_STUCK_TIMEOUT_MS`(30000)·`TDC_TOUCH_READ_FAIL_HOLD_CNT`(→`TDC_TIME_TO_CNT(2000,200)` 순수 정수연산) [grep TDC_TOUCH_* in logic.c]. → 전부 순수 정수 리터럴/연산.
- logic.c 는 `TDC_TOUCH_ULP_TIMER_PRESCALE`·`..._TIMEOUT_VALUE`·`TIMER_PRESCALE_128` 을 **단 한 번도 참조 안 함**(grep `ULP_TIMER|PRESCALE|TIMEOUT_VALUE|TIMER_PRESCALE` in logic.c → 0건). HW 심볼 든 매크로는 main.c 만 전개 [main.c:943].

→ logic.c(+time.h) 호스트 단독 컴파일 시 `TIMER_PRESCALE_128` 미전개라 **에러 발생 안 함**. 기준 ④의 가설("HW 심볼 섞여 순수 테스트 단독 include 시 문제")은 **실현 안 됨** — 순수 테스트 차단 0. 치명 아님.

단 잠재 취약 [경미]: time.h 가 0-include 인데 HW SDK 심볼 의존을 본문에 둠 → "시간 수치 단일 소유" 헤더가 실은 SDK 컨텍스트(선행 `ci_timer.h` include)에 암묵 의존. 향후 누군가 `TDC_TOUCH_ULP_TIMER_PRESCALE` 을 순수 TU 에서 전개하면 즉시 미정의 식별자 에러. time.h:40-41 주석이 "자동 파생 불가·HW 공식 역산"을 명시해 의도는 문서화됐으나, 자체 완결성 결여 자체는 남음. → 순수성 위반 아님(logic 레이어 불침투), 헤더 위생 [경미].
