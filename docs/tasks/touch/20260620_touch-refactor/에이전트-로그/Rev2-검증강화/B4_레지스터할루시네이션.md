# B4 레지스터 할루시네이션 대조

**TL;DR**: 신규 `tdc_touch_iqs323.c` 의 레지스터 접근 전수(주소 매크로 15종·write 22회·read 1종)를 데이터시트 정본과 1:1 대조. **주소 매크로 15/15 데이터시트 §9 일치**, **System Status 비트(bit5/6/9/7) 정확**, **Power Mode 보존 수정(0x54·0x58·0x50 = bits[6:4]=101 No ULP) 정확**, **ATI Full 0x040C·Conv 0x057F·events 0x52·System Control MSB 0x07 정확**. **근거 없는 fabrication(할루시네이션) [치명] 0건.** 적출은 [경미] 2건: ① Touch Hysteresis 바이트 배치(MSB=hyst 전체 바이트 → A.17 필드 bits[15:12]엔 hyst>>4만 반영, 단 삭제된 구 드라이버와 byte-동일·실측게이트#3 기존 인지) ② Beta 비대칭 주석이 데이터시트 공식(damping=Beta/256, 해석_A)과 역방향 — 값은 [실측 게이트] 안전기본값이라 fabrication 아님. verdict PASS.

## 2. write 값 ↔ 데이터시트 비트 (전수)

### 2.1 ATI Full 전환 (0x36 = 0x040C) [확인됨]

- `write_register(REG_SENSOR0_ATI_SETUP, 0x0C, 0x04)` [iqs323.c:348] → word 0x040C.
- A.12 분해: bits[15:4] ATI Res Factor=64(Target=Base×64/16=×4) · bit3 ATI Band=1(Large 1/8) · bits[2:0]=100 Full.
- 데이터시트 reset 기본값 0x040C와 동일 [06 A.12 "기본값 0x040C"]. 99 종합 2.1 "0x040C(LSB 0x0C bits[2:0]=100 Full, bit3=1 Large Band, Res 64)"와 일치. **[확인됨]**

### 2.2 Sensor Setup (단일채널) [확인됨]

| write [줄] | 값(lsb,msb) | 의미 | 데이터시트 | 판정 |
|---|---|---|---|---|
| REG_SENSOR2_SETUP [:246] | 0x00,0x00 | CH2 disable (Enable Channel=0·CTx0=0) | A.5 | [확인됨] |
| REG_SENSOR1_SETUP [:250] | 0x00,0x00 | CH1 disable | A.5 | [확인됨] |
| REG_SENSOR0_SETUP [:255] | 0x01,0x01 | CH0: LSB bit0 Enable Channel=1, MSB bit0(=word bit8) CTx0=1 | A.5 reset 0x0101 | [확인됨] |

- 코드 주석 "enable_channel(LSB bit0) + ctx0(MSB bit0)" [iqs323.c:254]: A.5에서 Enable Channel=word bit0(LSB bit0), CTx0=word bit8(MSB bit0). **정확.** 0x0101 은 데이터시트 reset 동일값 — self-cap CRx0/CTx0 동일핀 set 요건([02 §5.12.1] CTx0 set, CRx0 는 0x33 reset 0x01CF 에서 이미 set·코드 미수정 유지)과 정합. **[확인됨]**

### 2.3 Touch Settings (0x62) — [경미] 1건 (Hysteresis 배치)

- `touch_settings(threshold, hysteresis)` → `write_register(REG_CH0_TOUCH, threshold, hysteresis)` [iqs323.c:264].
- 운용: threshold=16, hysteresis=8 [tdc_touch_iqs323.h:46·49]. 절전: (255,255) [iqs323.c:412].
- A.17: word bits[7:0]=Touch Threshold(8-bit), bits[15:12]=Touch Hysteresis(4-bit).
- **Threshold**: LSB=16 → bits[7:0]=16. **[확인됨]** (99 §4.3 "계수 12~24, 32 미만" 범위 내).
- **Hysteresis [경미]**: MSB 바이트 전체(=word bits[15:8])에 hyst 값을 씀. hyst=8 → MSB=0x08 → A.17 Hysteresis 필드(word bits[15:12]=MSB bits[7:4])=0, 값 8 은 word bits[11:8](미정의/reserved)에 위치. 즉 데이터시트 4-bit 필드 해석이면 실효 Hysteresis=0(=hyst>>4).
  - **단 fabrication 아님**: 삭제된 구 드라이버도 `msb.touch_hysteresis : 8 // [8:15]`로 **MSB 전체 바이트**에 raw 값을 썼다(`git show HEAD:tdc_drv_iqs323.h:249~252`). 신규 코드는 byte-for-byte 동일 인코딩 → **이 리팩토링이 새로 만든 오류 아님(carryover)**.
  - 데이터시트 비트폭 자체가 [실측 게이트]로 이미 등록됨([99 §6 실측게이트 #3 "Hysteresis 레지스터 비트폭 — A.17 4비트 vs 코드 8비트 매크로"]). 따라서 [경미]·기존 인지 갭.

### 2.4 Events Enable (0xD3 = 0x52) [확인됨]

- `write_register(REG_EVENTS_ENABLE, 0x52, 0x00)` [iqs323.c:270]. 주석 "bit6 ati_error | bit4 ati_event | bit1 touch_event = 0x52".
- 0x52 = `0101 0010`: bit6=1(ATI Error) · bit4=1(ATI Event) · bit1=1(Touch Event), 나머지 0. A.32/A.33 EVENTS_ENABLE 비트맵과 정확 일치. **[확인됨]** (단일채널 self-cap에 prox/slider/power event disable 합리적).

- **Beta 비대칭 주석 [경미]**: 주석 [iqs323.c:273~274·279~280] "LTA Normal(0xB1) 느리게 > LTA Fast(0xB2) 빠르게". 값 B1=8 > B2=2. **데이터시트 공식 `Damping factor = Beta/256`([02 §5.6], 해석_A)** 이면 큰 Beta=큰 alpha=**빠른** 추종이므로 B1(8)이 B2(2)보다 빠름 → 주석과 **역방향**. 주석 의도(B1 느림)는 **해석_B(reg=시프트 지수, 큰 값=느림)** 에서만 성립. 99 §6 실측게이트 #1 "Beta 레지스터 정수 해석_A/B [실측 게이트]"로 미확정 — 값 자체는 "[실측 게이트] 시험 write 1회 판별 후 고정" 안전기본값([iqs323.c:273], [tdc_touch_iqs323.h:43]). **fabrication 아님(주석↔데이터시트 공식 정합 불일치, 실측 1회로 해소)** → [경미].

### 2.6 System Control 0xC0 — Power Mode 보존 수정 (급소) [확인됨]

A.30: LSB bits[6:4]=Power Mode(101=Automatic No ULP), bit3=Reseed, bit2=Re-ATI, bit0=ACK Reset. MSB bits[2:0](=word bit8/9/10)=CH0/1/2 Timeout Disable.

| 호출 [줄] | lsb,msb | bits[6:4] Power | 트리거 비트 | MSB CH TO | 판정 |
|---|---|---|---|---|---|
| ack_reset [:215] | 0x01,0x00 | 000(무관) | bit0 ACK Reset | 0 | [확인됨] ACK 단발, Power 무관 |
| beta_power [:284] | 0x50,0x07 | **101 No ULP** | 없음 | CH0~2 disable | [확인됨] 99 §2.3 "101 Automatic No ULP" |
| 부팅 Re-ATI [:358] | 0x54,0x07 | **101 No ULP** | bit2 Re-ATI | disable | [확인됨] Power 보존 |
| RESEED [:364] | 0x58,0x07 | **101 No ULP** | bit3 Reseed | disable | [확인됨] Power 보존 |
| re_ati 공개 [:376] | 0x54,0x07 | **101 No ULP** | bit2 Re-ATI | disable | [확인됨] Power 보존 |
| reseed 공개 [:382] | 0x58,0x07 | **101 No ULP** | bit3 Reseed | disable | [확인됨] Power 보존 |
| apply_sleep [:417] | 0x00,0x07 | 000 Normal | 없음 | disable | **[확인됨]** (아래 주의) |

- **Power Mode 보존 수정 정확성(④ 핵심 검증)**: re_ati/reseed/부팅 트리거가 0xC0 LSB 에 트리거 비트만 단독(0x04/0x08)으로 쓰면 bits[6:4]=000(Normal)로 덮어 Automatic No ULP 가 풀린다. 신규 코드는 **0x54(=0x50|0x04)·0x58(=0x50|0x08)**로 Power 101 을 함께 보존 — 주석 [iqs323.c:355~357·375·381]과 정확 일치. **Rev2 1차 검증 치명(0xC0 덮음)의 정확한 수정.** [확인됨]
- **apply_sleep 0xC0=0x00/0x07 [확인됨·주의]**: 코드 주석 [iqs323.c:416] "CH0~CH2 timeout disable". LSB=0x00 → bits[6:4]=000 = **Power Mode Normal**(Automatic No ULP 아님). 헤더 task 의 "⑤ apply_sleep 0xC0=0x00/0x07 Power Normal 의도"는 **코드 실제와 일치**(LSB 0x00 → Power Normal). 절전 진입은 CFX 클럭 강하 후 IC 를 NP 고정(저속 1샷)으로 두려는 의도로 해석 가능. CH timeout disable(MSB 0x07) 유지. **fabrication 없음** — 단 이 의도가 절전 전류 최적과 충돌하는지는 B3(제어방법)·B6 소관, B4 범위 밖. 비트 자체는 [확인됨].

## 6. verdict

**PASS** — 레지스터 할루시네이션 [치명] 0건. 적출 [경미] 2건은 (1) 삭제된 구 드라이버와 byte-동일한 Hysteresis 인코딩 carryover(기존 실측게이트 인지), (2) Beta 안전기본값의 주석↔데이터시트 공식 정합 불일치(실측 1회로 해소 예정)로, 모두 fabrication 아님. 안전 기본값+[실측 게이트] 주석 정책 범위 내.
