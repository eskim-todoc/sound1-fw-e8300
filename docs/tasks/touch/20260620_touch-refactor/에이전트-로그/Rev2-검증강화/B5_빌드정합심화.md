### 4.1 [경미] tdc_touch.c `delay_ms` 선언 미해소 (암시적 선언)

- **전이 폐포 검증(스크립트)**: tdc_touch.c include 집합에서 도달 가능한 로컬 헤더 53개를 BFS 한 결과 **`ci_util.h` 미도달**(`initialize.h`/`ci_battery.h`/`ci_power.h`/`ci_boot.h`/`tdc_trims.h` 전부 미도달) [closure walk 실측]. SDK 헤더(`hw.h` 등)는 로컬 `ci_util.h` 를 include 할 수 없음.

- 심각도: **[경미]** (현 빌드 비차단). 단 `-Werror=implicit-function-declaration` 도입 시 즉시 **[치명] 승격**. **권고: tdc_touch.c 에 `#include <ci_util.h>` 추가.**
