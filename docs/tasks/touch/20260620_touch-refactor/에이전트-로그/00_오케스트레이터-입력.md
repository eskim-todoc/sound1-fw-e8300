# 00 오케스트레이터 입력 — 터치 3레이어 리팩토링 분석

**TL;DR**: Full ATI 터치 코드(2848줄)를 **3레이어(L1 HW 드라이버 / L2 순수 FSM 로직 / L3 시간·이벤트 어댑터)**로 재구조화하고 시간 상수를 자동 파생하는 설계 fan-out. 현코드 매핑 → L2/L1/L3/테스트/파일 설계 → adversarial 동작보존 검증 → 종합. 페르소나 상세 [`페르소나-정의.json`](페르소나-정의.json). effort xhigh. 한자 금지.

## 1. 목표 (은수님 확정)

- **테스트 방식**: 순수 로직 분리. HW 의존(I2C 등)은 모듈 함수 호출로 격리. 프레임워크 미도입.
- **리팩토링 강도**: 전면 3레이어 재구조화.
- **동작 보존**: Full ATI 단순안 기능 동등(회귀 0).
- **시간 상수 자동 파생**: 폴링·롱터치·절전 wake/폴링/롱터치를 ms 상수로 → 파생 카운트 자동 계산.

## 2. 3레이어 개념

- **L1 HW 드라이버**: I2C·레지스터·force window — IQS323 종속. (현 tdc_drv_iqs323 정리)
- **L2 순수 터치 FSM 로직**: 상태머신·이벤트·롱터치·Re-ATI 게이트·stuck — **HW 비의존 순수 함수**. 입력=상태·시간·플래그, 출력=다음상태·요청액션. 테스트 가능.
- **L3 시간·이벤트 어댑터**: 시간 상수→파생, 폴링 게이팅, L2↔L1 연결. 노말·절전 두 어댑터.
