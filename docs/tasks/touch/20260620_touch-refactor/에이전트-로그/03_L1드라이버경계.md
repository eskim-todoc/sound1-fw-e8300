# 03 L1 드라이버 경계 — HW 드라이버 인터페이스 설계

**TL;DR**: L2 순수 FSM이 필요로 하는 HW 액션을 **약한 추상 포트 헤더 `tdc_touch_port.h`** 7종으로 격리한다(`read_status`·`re_ati`·`reseed`·`mclr`·`is_ati_done`·`apply_settings`·`apply_sleep`). 은수님 결정대로 **함수 포인터 vtable이 아닌 모듈 직접 호출**을 기본으로 하되, 포트 헤더는 L2/L3가 `tdc_drv_iqs323_*` 구상 심볼을 직접 부르는 대신 `tdc_touch_port_*` **얇은 인라인 위임**(또는 `TDC_TOUCH_PORT_MOCK` 빌드가드 시 mock 링크)을 거치게 해 테스트 mock 지점 1곳을 확보한다. 현 드라이버 공개 API 12종은 전수 보존(시그니처 무변경) — 포트는 그 위에 얹는 **이름 격리 레이어**일 뿐 동작 0 변경. read_status_full의 3-상태 동시 반환·0xEEEE 글리치 false·discharge best-effort 등 급소 semantics는 포트 계약(contract)으로 명문화해 회귀 0을 보장한다.

---

## 1. 입력·역할 확인

- 역할(json `03`): L2가 필요로 하는 HW 동작을 인터페이스로 추상화(`read_status`·`re_ati`·`reseed`·`apply_settings`·`mclr`). 함수 포인터 vtable vs 직접 모듈 호출 — **은수님: 모듈 호출 격리**. mock/스텁 지점. `tdc_drv_iqs323`를 그 인터페이스 구현으로.
- 은수님 확정(요구사항 §2): L1 HW 드라이버는 I2C·레지스터 read/write·force window — IQS323 종속, 순수 로직과 분리. L2는 HW 비의존.
- 본 노드 결정: vtable보다 모듈 직접 호출 격리 우선, 단 테스트 mock 위해 **약한 추상(포트 헤더 `tdc_touch_port.h`)** 검토.

## 2. 현 드라이버 공개 API 전수 인벤토리 (경계의 출발점)

`tdc_drv_iqs323.h`가 노출하는 공개 API와 외부 호출처 [grep 전수]:

| # | 공개 API | 정의 | 외부 호출처 | L2 필요? | 비고 |
|---|---|---|---|---|---|
| 1 | `tdc_drv_iqs323_mclr_reset(void)` | `.c:940` | `tdc_touch.c:394` | 예(init) | 약 51ms 블로킹 |
| 2 | `tdc_drv_iqs323_is_auto_ati_done(void)` | `.c:945` | `tdc_touch.c:317` | 예(init 폴링) | 논블로킹 1회 read |
| 3 | `tdc_drv_iqs323_apply_settings(void)` | `.c:1131` | `tdc_touch.c:332` | 예(init 적용) | 1 tick 점유, 부팅 Re-ATI 내포 |
| 4 | `tdc_drv_iqs323_read_status(bool*,bool*)` | `.c:1303` | `main.c:891`(절전) | 아니오(절전만) | pressed·ati_error 2-상태 |
| 5 | `tdc_drv_iqs323_read_status_full(bool*,bool*,bool*)` | `.c:1322` | `tdc_touch.c:505` | **예(핵심)** | 3-상태 + 0xEEEE false |
| 6 | `tdc_drv_iqs323_re_ati_trigger(void)` | `.c:983` | `tdc_touch.c:237·288` | 예(게이트·stuck) | 게이트는 호출측 책임 |
| 7 | `tdc_drv_iqs323_reseed_only(void)` | `.c:970` | `tdc_touch.c:281` | 예(stuck stage1) | 순수 RESEED bit3 |
| 8 | `tdc_drv_iqs323_read_touch_margin(uint8_t*,uint16_t*)` | `.c:1357` | `tdc_touch.c:543` | 예(로그 한정) | MARGIN_LOG 가드 |
| 9 | `tdc_drv_iqs323_reseed(void)` | `.c:950` | `main.c:966`(절전) | 아니오(절전만) | 절전 감도+Prox+bit3 |
| 10 | `tdc_drv_iqs323_discharge_crx0(void)` | `.c:989` | `tdc_touch.c:551` | 예(방전) | best-effort, DISCHARGE 가드 |
| 11 | `tdc_drv_iqs323_apply_sleep_settings(void)` | `.c:1005` | `main.c:958`(절전) | 아니오(절전만) | 절전 어댑터 |
| 12 | `tdc_set/clear/is_iqs323_in_ulp_mode(void)` | `.c:20·25·30` | 드라이버 내부 + 절전 | 간접 | ULP 모드 플래그 |

추가 빌드가드 한정 API(테스트 경계 비대상): `tdc_drv_iqs323_calib_*`(CALIB 모드), `tdc_drv_iqs323_sleep_measure_dump`(SLEEP_MEASURE), `tdc_drv_iqs323_*_tuning`(RTT_TUNING).

**경계 관찰**:
- L2(`tdc_touch.c`)가 직접 부르는 드라이버 API는 **8종**(#1·2·3·5·6·7·8·10) — 이것이 L1 포트의 1차 후보다.
- 절전 4종(#4·9·11·12)은 main.c가 직접 부른다. L2 순수 FSM은 절전에 미관여(B99 §2.3 [확정]) → 절전은 **L3 절전 어댑터**가 L1을 직접 호출, L2 포트 계약에는 불포함.
- `tdc_touch_get_state`(L2 경계 함수)는 절전 ULP 루프(`main.c:993`)와 노말(`tdc_touch.c:419·440`) 양쪽에서 호출됨 → L2/L3 분리 시 시간축 주의(04 노드 영역, 03은 그 아래 read 포트만 책임).

## 3. 핵심 설계 결정 — 모듈 직접 호출 + 약한 포트 헤더

### 3.1 vtable vs 모듈 직접 호출 (은수님 결정 반영)

| 방식 | 장점 | 단점 | 채택 |
|---|---|---|---|
| 함수 포인터 vtable(`struct tdc_touch_hw_ops`) | 런타임 교체·mock 주입 깔끔 | 간접 호출 오버헤드, 임베디드에서 디버깅·정적분석 난해, 은수님 명시 비선호 | ✗ |
| 모듈 직접 호출(`tdc_drv_iqs323_*` 그대로) | 제로 오버헤드, 콜그래프 명확 | mock 불가(링커가 구상 심볼 고정) | △ 보강 필요 |
| **약한 포트 헤더(`tdc_touch_port.h`) + 인라인 위임/링크 치환** | 모듈 직접 호출 유지 + mock 1지점 + L2가 구상 드라이버명 비의존 | 파일 1개 추가 | **✓ 채택** |

**채택안 정의**: L2·L3는 드라이버 구상 심볼 `tdc_drv_iqs323_*`를 직접 부르지 않고 **포트 심볼 `tdc_touch_port_*`** 를 부른다. 포트는:
- **운용 빌드**(`TDC_TOUCH_PORT_MOCK==0`, 기본): 포트 함수가 대응 `tdc_drv_iqs323_*`를 **얇게 위임**(`static inline` 또는 1줄 함수). 컴파일러가 인라인 → 오버헤드 0. 콜그래프는 포트→드라이버로 단순.
- **테스트 빌드**(`TDC_TOUCH_PORT_MOCK==1`): 포트 함수 본체를 `tdc_touch_port_mock.c`가 제공(드라이버 비링크). 호출 기록·반환 스크립트로 L2 결정론 검증.

이 방식은 vtable의 런타임 간접성 없이(은수님 선호 충족) mock 단일 지점을 얻는 **컴파일타임 약한 추상**이다.

### 3.2 포트가 격리하는 것 / 격리하지 않는 것

- **격리(포트 경유 필수)**: System Status read(터치·ATI), Re-ATI, RESEED, MCLR, auto-ATI done 폴링, 터치 마진 read, 방전. 이들은 전부 I2C·레지스터·force window·`Sys_GPIO`·`ci_timer`·`Sys_Delay`를 만지는 HW 종속.
- **격리 불필요(드라이버 내부 유지)**: `i2c_write/read`, `force_window_open`, `wait_rdy_window_closed`, `write_register`, `read_register`, `ack/confirm_reset`, `sensor_setup`, `events_enable`, `touch_settings`, `prox_settings` 등 static 헬퍼 — 이들은 L1 내부 구현 디테일로 헤더에 노출 안 함(현재도 static, 무변경).

## 4. 포트 인터페이스 시그니처 (구체)

파일: **`tdc_touch_port.h`** (신규, `systemControl/`). L2가 필요로 하는 8 액션을 의미 단위로 명명. `tdc_drv_iqs323_*` 시그니처를 그대로 보존하되 이름만 HW-중립화.

```c
/* tdc_touch_port.h — L2 순수 FSM이 호출하는 HW 액션 포트(약한 추상).
 * 운용: tdc_drv_iqs323_* 로 인라인 위임. 테스트: tdc_touch_port_mock.c 로 치환.
 * 계약(contract) 위반은 회귀이므로 §5 semantics 를 반드시 보존한다. */
#ifndef TDC_TOUCH_PORT_H_
#define TDC_TOUCH_PORT_H_

#include <stdbool.h>
#include <stdint.h>

/* --- 초기화 액션 --- */
void tdc_touch_port_mclr_reset(void);            /* 매핑: tdc_drv_iqs323_mclr_reset  — 약 51ms 블로킹 */
bool tdc_touch_port_is_ati_done(void);           /* 매핑: tdc_drv_iqs323_is_auto_ati_done — 논블로킹 1회 */
void tdc_touch_port_apply_settings(void);        /* 매핑: tdc_drv_iqs323_apply_settings — 운용 설정 일괄 */

/* --- 폴링·판정 액션 (핵심) --- */
/* System Status 1회 read. 반환 true=통신 정상.
 * 0xEEEE 글리치는 false(상위 NOT_TOUCH 강제). out 3개 NULL 허용.
 * 매핑: tdc_drv_iqs323_read_status_full */
bool tdc_touch_port_read_status(bool *p_pressed, bool *p_ati_error, bool *p_ati_active);

/* --- 복구 액션 --- */
bool tdc_touch_port_re_ati(void);                /* 매핑: tdc_drv_iqs323_re_ati_trigger — 게이트는 호출측 책임 */
bool tdc_touch_port_reseed(void);                /* 매핑: tdc_drv_iqs323_reseed_only — 순수 RESEED(절전감도 미동반) */

/* --- 보조 액션 (빌드가드 시 no-op 위임) --- */
bool tdc_touch_port_discharge(void);             /* 매핑: tdc_drv_iqs323_discharge_crx0 — best-effort */
bool tdc_touch_port_read_margin(uint8_t *p_th_coeff, uint16_t *p_cur_coeff); /* 매핑: read_touch_margin */

#endif /* TDC_TOUCH_PORT_H_ */
```

운용 위임 구현(`tdc_touch_port.c` 또는 헤더 `static inline`):

```c
/* tdc_touch_port.c (TDC_TOUCH_PORT_MOCK==0 일 때만 빌드) */
#include <tdc_touch_port.h>
#include <tdc_drv_iqs323.h>

void tdc_touch_port_mclr_reset(void)    { tdc_drv_iqs323_mclr_reset(); }
bool tdc_touch_port_is_ati_done(void)   { return tdc_drv_iqs323_is_auto_ati_done(); }
void tdc_touch_port_apply_settings(void){ tdc_drv_iqs323_apply_settings(); }
bool tdc_touch_port_read_status(bool *p, bool *e, bool *a)
                                        { return tdc_drv_iqs323_read_status_full(p, e, a); }
bool tdc_touch_port_re_ati(void)        { return tdc_drv_iqs323_re_ati_trigger(); }
bool tdc_touch_port_reseed(void)        { return tdc_drv_iqs323_reseed_only(); }
bool tdc_touch_port_discharge(void)     { return tdc_drv_iqs323_discharge_crx0(); }
bool tdc_touch_port_read_margin(uint8_t *t, uint16_t *c)
                                        { return tdc_drv_iqs323_read_touch_margin(t, c); }
```

> [!NOTE]
> **MARGIN_LOG·DISCHARGE 빌드가드 처리**: 현 코드는 `#if TDC_TOUCH_MARGIN_LOG_ENABLE`/`#if TDC_TOUCH_CRX0_DISCHARGE_ENABLE`로 호출을 감싼다(`tdc_touch.c:533·548`). 포트 도입 후에도 **호출측 L2에서 가드 유지**(포트 함수는 항상 존재, 호출만 가드) — B99 §1의 "무가드 정의 → 미정의 참조 불가" 안전 패턴 동일 적용.

### 4.1 절전 경로는 포트 비포함 (경계 명확화)

절전 4종(`read_status`·`reseed`·`apply_sleep_settings`·`*_ulp_mode`)은 L2 포트에 넣지 않는다. 근거: B99 §2.3 — 절전에 `tdc_touch_process`·`proc_*` 호출 0건 [확정]. L3 절전 어댑터(04 노드)가 이들 드라이버 API를 **직접** 호출(또는 별도 `tdc_touch_sleep_port.h`로 분리). 03은 L2가 부르는 노말 포트만 책임진다. 단 절전 ULP 루프가 `tdc_touch_get_state→read_status_full`을 공유하므로, **read 포트 자체는 노말/절전 공통 재사용 가능**(시간축은 L3 어댑터가 주입, 03 read 포트는 시간 무관).

## 5. 포트 계약 (semantics) — 회귀 0 보존 핵심

mock·위임 어느 쪽이든 **반드시 보존**해야 할 동작 계약. 이것이 깨지면 B99의 급소가 무력화된다.

| 포트 함수 | 계약(반드시 보존) | 근거 |
|---|---|---|
| `read_status` | ① 3-상태 동시 반환(pressed·ati_error·ati_active) ② **0xEEEE → false**(통신 글리치를 read 실패로) ③ out NULL 허용 | `.c:1322·1333` / B99 E6·E7 |
| `read_status` 실패 시 | 반환 false만. **ATI 캐시 무효화는 L2 책임**(포트는 상태 안 가짐) | `tdc_touch.c:512`(급소 수정) |
| `re_ati` | bit2 write 1회. **게이트(터치중 보류)는 호출측 L2 책임** — 포트는 무조건 발행 | `.c:985` 주석 / B99 §3 E5 |
| `reseed` | bit3 write **only**. 절전 감도(100/80)·Prox 미동반(노말 오염 차단) | `.c:970` 주석 |
| `mclr_reset` | 약 51ms 블로킹 1회. DIO16 OUTPUT→LOW→INPUT 복원 | `.c:288` |
| `apply_settings` | ACK→설정→Full ATI write→Beta/Power→부팅 Re-ATI→RESEED→Power Mode 순서·내용 무변경(1 tick) | `.c:1131` / B99 §2.1 |
| `is_ati_done` | 논블로킹 1회 read. 0xEEEE·통신 실패 → false(미완료) | `.c:312` |
| `discharge` | best-effort(반환 무시 가능), verify 없음 | `.c:989` 주석 |

> [!CAUTION]
> **포트는 무상태(stateless) 위임만 한다.** ATI 캐시(`s_last_ati_error/active`)·read 실패 카운터·쿨다운·stuck 타이머·롱터치 래치는 전부 **L2 순수 FSM 상태**다(02 노드). 03 포트가 이를 떠안으면 "순수 로직 HW 비의존" 요구가 깨진다. 포트는 입력→I2C→출력만, 기억 없음.

## 6. mock/스텁 지점 (테스트 경계, 프레임워크 미도입)

### 6.1 mock 단일 지점

```
[운용]  L2 FSM ──call──▶ tdc_touch_port_* ──inline──▶ tdc_drv_iqs323_* ──▶ I2C/GPIO/HW
[테스트] L2 FSM ──call──▶ tdc_touch_port_* (mock)  ◀── 호출기록·반환 스크립트
                              └ tdc_touch_port_mock.c (드라이버·HW 비링크)
```

빌드 선택: `tdc_touch_config.h`(또는 테스트 빌드 정의)에 `TDC_TOUCH_PORT_MOCK`. 0=`tdc_touch_port.c` 링크, 1=`tdc_touch_port_mock.c` 링크. **L2·L1 소스 무수정**으로 mock 교체(링커 레벨 치환).

### 6.2 mock 골격 (호출 기록 + 반환 주입, 프레임워크 없이)

```c
/* tdc_touch_port_mock.c — TDC_TOUCH_PORT_MOCK==1 전용. Unity 등 미사용. */
#include <tdc_touch_port.h>

typedef struct {
    /* 다음 read_status 가 돌려줄 값(테스트가 사전 세팅) */
    bool next_read_ok;
    bool next_pressed, next_ati_error, next_ati_active;
    /* 호출 카운터(테스트가 검증) */
    int  cnt_read_status, cnt_re_ati, cnt_reseed,
         cnt_mclr, cnt_apply_settings, cnt_discharge, cnt_is_ati_done;
} tdc_touch_port_mock_t;

extern tdc_touch_port_mock_t g_tdc_touch_port_mock;  /* 테스트가 직접 조작 */

bool tdc_touch_port_read_status(bool *p, bool *e, bool *a)
{
    g_tdc_touch_port_mock.cnt_read_status++;
    if (!g_tdc_touch_port_mock.next_read_ok) { return false; }   /* 0xEEEE/통신실패 시뮬 */
    if (p) { *p = g_tdc_touch_port_mock.next_pressed; }
    if (e) { *e = g_tdc_touch_port_mock.next_ati_error; }
    if (a) { *a = g_tdc_touch_port_mock.next_ati_active; }
    return true;
}
bool tdc_touch_port_re_ati(void)   { g_tdc_touch_port_mock.cnt_re_ati++;   return true; }
bool tdc_touch_port_reseed(void)   { g_tdc_touch_port_mock.cnt_reseed++;   return true; }
void tdc_touch_port_mclr_reset(void){ g_tdc_touch_port_mock.cnt_mclr++; }

```

### 6.3 mock으로 검증 가능한 L2 결정론 (05 테스트 노드 연계)

- E5 게이트 4조건: mock에 `pressed=0, ati_error=1, ati_active=0` 세팅 → L2 tick → `cnt_re_ati==1` 기대, 쿨다운 중 `==1` 유지.
- E5'' burst 중: `ati_active=1` 세팅 → `cnt_re_ati==0`(미발행) 기대.
- 급소(read 실패 중 터치 유지): `next_read_ok=false` + 직전 캐시 stale → L2가 캐시 무효화로 `cnt_re_ati==0` 기대(터치 중 Re-ATI 누출 차단 검증).
- stuck 3단계: 시간 mock(04 tick 주입)으로 30/60/90초 → `cnt_reseed==1`→`cnt_re_ati`+1→MCLR 경로.

> [!NOTE]
> `mclr_reset`·`apply_settings`의 블로킹 delay(`Sys_Delay`·`ci_timer`)는 mock에서 즉시 반환 → 테스트가 실시간 대기 없이 결정론 검증. 단 **블로킹 자체가 동작인 경우는 시간 mock(04)으로 tick만 진행** — 03 포트 mock은 카운트·반환만.

## 7. tdc_drv_iqs323 재배치 (L1 구현으로 정리)

현 드라이버는 이미 "I2C·레지스터·RDY 윈도우·MCLR" 책임으로 잘 응집되어 있다(`.c:5` 주석). 03 변경은 **최소 침습**:

1. **시그니처 무변경** — 공개 12 API 그대로. 포트는 그 위에 얹는 이름 레이어일 뿐.
2. **drv 헤더에서 L2가 더는 직접 include 안 함** — `tdc_touch.c`는 `tdc_drv_iqs323.h` 대신 `tdc_touch_port.h`만 include(드라이버 구상 의존 제거). 단 `tdc_touch_config.h`는 별도 경로 유지(06 노드 영역).
3. **절전 API 분리 검토(선택)**: `read_status`·`reseed`·`apply_sleep_settings`·`*_ulp_mode`는 노말 L2와 무관 → 향후 `tdc_drv_iqs323_sleep.c`로 물리 분리 가능(06 노드 판단). 03은 논리 경계만 명시: **이들은 L2 포트 비포함**.

> [!IMPORTANT]
> **드라이버 내부 비대칭 회귀 주의**: `apply_settings`(운용)와 `apply_sleep_settings`(절전)는 ATI 시퀀스가 다르다(`.c:1131` vs `.c:1005`, `#if !FULL_ATI` 분기). 포트가 이 둘을 묶거나 단순화하면 절전 회귀. 03 포트는 **`apply_settings`만 노출**, `apply_sleep`은 절전 어댑터 전담으로 분리해 혼동 차단.

## 8. 미해결·결정 필요 (오케스트레이터/은수님 게이트)

- **결정_1 (포트 위임 형태)**: `static inline`(헤더) vs 별도 `.c` 1줄 함수. 인라인은 오버헤드 0이나 mock 치환이 `#if`로 복잡. **권고: `.c` 분리 + 링커 치환**(mock 깔끔, 인라인 손실은 LTO/소함수라 무시 가능) — 04·06 노드와 정합 필요.
- **결정_2 (절전 포트 분리 범위)**: 절전 4종을 별도 `tdc_touch_sleep_port.h`로 둘지, main.c가 드라이버 직접 호출 유지할지 — 04(L3 절전 어댑터) 노드 결론에 종속.
- **결정_3 (config·tuning 의존)**: `TDC_TOUCH_PORT_MOCK` 정의 위치(`tdc_touch_config.h` vs 테스트 전용 빌드 플래그) — 06 노드 파일 구성과 정합.
- **[실측 게이트]**: 포트 도입 후 인라인/분리 어느 형태든 **빌드 1회로 미정의 참조·-Werror 확인 필요**(B99 §6.4 #1과 동일 게이트). 동작 자체는 위임이라 무변경 [추정-강].
- **회귀 0 검증**: 포트 위임이 §5 계약을 1:1 보존하는지는 07(adversarial) 노드가 read_status_full 3-상태·0xEEEE·re_ati 무게이트·reseed bit3-only 4개 급소로 cross-check.
