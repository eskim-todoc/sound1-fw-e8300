# 요구사항: 터치 계측·디버그 + 절전 Full ATI 정합 + 부팅 해제 디바운스 + 메시지 정책

**TL;DR**: Full ATI 전환 리팩토링([20260619_touch-fullati-control](../20260619_touch-fullati-control/)) 후속. ① 200ms 폴링마다 LTA·Counts·절대임계·밴드초과 계측을 RTT로 표시(실측 튜닝용, Beta 값은 유지) ② 절전 진입의 threshold=255 무감(Fixed 잔재)을 제거하고 Full ATI 적응임계로 절전 중에도 터치 정상 감지·롱터치 깨움 ③ 부팅 boot_ignore 해제를 400ms(2폴링) 연속 not-pressed로 디바운스 ④ ci_print 레벨 정책(ATI=printw, Re-ATI=printi, 주기상태=printd, 기존 치명 printe 유지).

> [!NOTE]
> 본 작업은 은수님 지시(2026-06-22) + 인터뷰 4문항 확정 답변을 ground truth로 한다. 코드 현상태는 분석 서브에이전트 4종(드라이버·FSM·메시지·레지스터맵)으로 사전 확인했다.

## 1. 배경

- Full ATI 전환 리팩토링은 완료(빌드·실기 검증 대기) 상태. 그 위에서 **실측 튜닝 기반**을 마련하고, 리팩토링 과정에 남은 절전 경로의 Fixed 방식 잔재를 정리한다.
- 실측으로 Beta·임계 적정 범위를 찾기 위해, 먼저 IC 내부 수치(LTA·Counts·임계)를 RTT로 관측할 수 있어야 한다.

## 2. 기능 요구사항

### 요구사항_1 — 절전 Full ATI 정합 (Fixed 잔재 제거)

- `tdc_touch_iqs323_apply_sleep_settings()`의 `0x62 = 0xFFFF`(threshold=255, hysteresis=255) **무감 고정 설정을 제거**한다.
- 절전(ULP) 모드에서도 **Full ATI가 산출한 적응 임계**(또는 절전 전용 재산출 임계)로 터치를 정상 감지하도록 한다.
- 절전 진입 후에도 **터치 해제가 감지**되어야 하며, ULP 루프의 롱터치(약 2.2s)→재부팅 경로가 정상 동작해야 한다.
- 절전 전용 임계/ATI 재산출의 **구체 설계는 분석 페르소나가 절전 시퀀스 전체(진입→ULP 루프→깨움)를 규명한 뒤 계획에 제안** → 사용자 승인.

### 요구사항_2 — LTA 계측·디버그 표시 (실측 튜닝용)

- 노말 200ms 폴링마다 `ci_printd`로 다음을 표시한다:
  - LTA (CH0 `0x14`)
  - Filtered Counts (CH0 `0x13`)
  - 절대 터치임계 (`threshold × LTA / 256` 계산값)
  - Threshold/Hysteresis 원값(계수) + 현재 상태(pressed/state)
  - **LTA 밴드 초과 여부**(Counts가 절대임계를 넘었는지 한눈에)
- LTA/Counts read를 위한 신규 I2C read 경로 추가 필요(현재 `read_status()`는 `0x10`만 read).
- Beta(LTA 수렴 계수)는 **이번엔 값 변경 없이 현 8 유지**. 본 계측으로 실측 후 별도 작업에서 조정.

### 요구사항_3 — 부팅 터치 해제 400ms 디바운스

- 부팅 직후 boot_ignore 해제를 **단 1회 not-pressed가 아니라 400ms(=200ms 폴링 2회) 연속 not-pressed**일 때만 진짜 해제로 인식한다.
- 적용 범위: **boot_ignore 해제에만**. 일반 TOUCH↔NOT_TOUCH 천이는 현행(1 tick) 유지.

### 요구사항_4 — 메시지(ci_print) 레벨 정책

- 신규 이벤트 메시지:
  - ATI 에러 감지 시점 → `ci_printw`
  - Re-ATI 발행 시점 → `ci_printi`
  - 주기적 터치 상태 정보 → `ci_printd`
- 신규 메시지에는 `ci_printe` 사용 지양.
- 기존 치명 실패(I2C/write/read/apply fail)의 `ci_printe`는 **디버깅 가치상 유지**(일괄 전환하지 않음).

## 3. 비목표 (이번 범위 제외)

- Beta 값 변경 (실측 후 별도 작업)
- 일반 TOUCH↔NOT_TOUCH 천이 디바운스
- 기존 `ci_printe`(치명 실패) 일괄 printw 전환
- Hysteresis 비트 매핑 불일치([실측 게이트]) 확정 — 계측으로 관측만, 코드 정정은 별도

## 4. 확정 사항 (인터뷰 2026-06-22)

| 질문 | 확정 답변 |
|---|---|
| 절전 터치 동작 | Full ATI 적응임계 유지 (무감 255 제거, 절전 중 정상 감지·롱터치 깨움) |
| Beta 값 | 값 유지(8), 이번엔 계측/표시만 |
| 디버그 표시 항목 | LTA·Counts·절대임계·Threshold/Hysteresis 원값+상태·LTA밴드 초과여부 |
| ci_printe 범위 | 이벤트만 신규 규칙 적용, 기존 치명 printe 유지 |
| 400ms 디바운스 범위 | 부팅 boot_ignore 해제에만 (가정 제시·이의 없음) |

## 5. 제약·근거

- 코드 ground truth = 리팩토링 신규 3파일(`tdc_touch_iqs323`·`tdc_touch_logic`·`tdc_touch`) + `main.c`.
- 레지스터 주소: LTA `0x14`, Filtered Counts `0x13`, CH0 Touch Settings `0x62`(threshold[7:0]·hysteresis[15:12]), System Status `0x10`, System Control `0xC0`, ATI Setup `0x36`(Full=bits[2:0]=100).
- RTT(SEGGER) 출력, `ci_printf` 컴파일 게이트 현재 전부 활성. 한글 문자열 사용 가능.
- IQS323 RDY 윈도우(스트리밍) 타이밍 — 신규 read 추가 시 윈도우 내 I2C 접근 보장 필요(분석에서 확인).
