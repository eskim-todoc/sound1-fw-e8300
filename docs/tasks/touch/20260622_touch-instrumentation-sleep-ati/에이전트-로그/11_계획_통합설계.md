# 계획_통합설계 — 터치 계측·절전 Full ATI 정합·부팅 디바운스·메시지 정책

**TL;DR**: 4개 요구사항(절전 무감 제거·LTA 계측·부팅 디바운스·메시지 정책)을 5단계(P0~P4)로 구현한다. 파일 6종에 걸친 최소 변경 집합이며, 각 단계는 독립 빌드 가능하다. logic.c 순수성(HW/printf 0건)·기존 printe·공개 API 시그니처는 회귀 경계로 보호된다.

---

## 1. 전제: 분석 4종 결론 요약

| 분석 | 핵심 결론 |
|---|---|
| 01_절전ATI정합 | `tdc_touch_iqs323.c:413`의 `touch_settings(255, 255)` 1줄 제거로 충분. ATI Mode(0x36)·reseed 타이밍 변경 불필요. |
| 02_계측설계 | 신규 `tdc_touch_iqs323_read_debug()` API(0x13·0x14 read). `tdc_touch.c` 폴링 루프에 printd 삽입. `TDC_TOUCH_DEBUG_PRINT_ENABLE` 빌드가드. |
| 03_부팅디바운스 | `logic.h` 구조체 필드 1개(`boot_release_cnt`) + `tdc_touch_time.h` 상수 2개 + `logic.c` step() 블록 교체. |
| 04_메시지정책 | ATI 에러 printw·Re-ATI printi 원인 분기·주기 printd — 전부 `tdc_touch.c` 디스패치층에만. logic.c print 0건 불변. |

### 2.5 `tdc_touch_iqs323.c` / `tdc_touch_iqs323.h`

#### 2.5.1 `tdc_touch_iqs323.c` — 레지스터 주소 #define 추가

위치: `.c` 내부 `#define` 영역(tdc_touch_iqs323.c:17~31 블록) 하단:

```c

#define REG_CH0_LTA     0x14   /* Channel 0 LTA (read-only, 16-bit) */
```

**근거**: 헤더 미노출 패턴 유지(tdc_touch_iqs323.h 기존 REG_* 0건 확인). 공개 API와 분리.

#### 2.5.2 `tdc_touch_iqs323.c` — `tdc_touch_iqs323_read_debug()` 구현 추가

공개 6동작 영역(tdc_touch_iqs323.c:312 이후, `tdc_touch_iqs323_read_status` 다음) 에 추가:

```c
bool tdc_touch_iqs323_read_debug(tdc_touch_iqs323_debug_t *out)
{
    uint8_t lsb, msb;

    out->ok     = false;
    out->lta    = 0u;
    out->counts = 0u;

    /* Filtered Counts (0x13) read */
    if (!read_register(REG_CH0_COUNTS, &lsb, &msb))
    {
        ci_printe("[TOUCH] READ_DEBUG: COUNTS FAIL \r\n");
        return false;
    }
    out->counts = (uint16_t) (((uint16_t) msb << 8) | lsb);   /* little endian */

    /* LTA (0x14) read */
    if (!read_register(REG_CH0_LTA, &lsb, &msb))
    {
        ci_printe("[TOUCH] READ_DEBUG: LTA FAIL \r\n");
        return false;
    }
    out->lta = (uint16_t) (((uint16_t) msb << 8) | lsb);

    out->ok = true;
    return true;
}
```

**little endian 근거**: 데이터시트 §8.5 "16-bit data is little endian (LSB first)". `read_register()`의 `p_buf[0]=lsb, p_buf[1]=msb`(tdc_touch_iqs323.c:204~205) → `(msb<<8)|lsb`로 복원.

#### 2.6.2 계측 printd 삽입 (빌드가드 포함)

위치: `tdc_touch_logic_step()` 직후, 로그 블록(tdc_touch.c:154) 앞:

```c

    /* [신규] LTA·Counts 계측 출력 — 실측 튜닝용. 튜닝 완료 후 ENABLE=0 으로 비활성화. */

    if (in.read_ok)
    {
        tdc_touch_iqs323_debug_t dbg;
        if (tdc_touch_iqs323_read_debug(&dbg))
        {
            uint16_t delta   = (dbg.lta > dbg.counts) ? (dbg.lta - dbg.counts) : 0u;
            uint16_t abs_thr = (uint16_t) (((uint32_t) TDC_TOUCH_IQS323_THRESHOLD * dbg.lta) / 256u);
            ci_printd("[T] LTA=%u CNT=%u D=%u THR=%u(k=%u) H=%u %s %s\r\n",
                      (unsigned) dbg.lta,
                      (unsigned) dbg.counts,
                      (unsigned) delta,
                      (unsigned) abs_thr,
                      (unsigned) TDC_TOUCH_IQS323_THRESHOLD,
                      (unsigned) TDC_TOUCH_IQS323_HYSTERESIS,

```

**포맷 필드 설명**:

| 필드 | 내용 |
|---|---|
| `LTA=` | 0x14 CH0 LTA 16-bit 원값 |
| `CNT=` | 0x13 CH0 Filtered Counts 16-bit 원값 |
| `D=` | delta = LTA - CNT (0 클램프, self-cap 터치 시 증가 방향) |
| `THR=` | 절대임계 = threshold × LTA / 256 (데이터시트 §A.17) |
| `(k=)` | TDC_TOUCH_IQS323_THRESHOLD 원값 (현재 16) |
| `H=` | TDC_TOUCH_IQS323_HYSTERESIS 원값 (현재 8, 비트매핑 [실측 게이트]) |
| `P/.` | pressed 여부 (0x10 MSB bit1) |
| `**BAND**/band_in` | delta > abs_thr 초과 여부 (터치 임계 근접 마커) |

### P0 — 기반 상수·빌드가드 추가 (선행 필수)

**대상 파일**: `tdc_touch_time.h`, `tdc_touch_config.h`

**작업**:
