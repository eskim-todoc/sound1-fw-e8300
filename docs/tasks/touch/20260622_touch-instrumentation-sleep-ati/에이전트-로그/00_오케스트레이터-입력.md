# 오케스트레이터 입력

**TL;DR**: 페르소나 비중 분석/계획 3 : 검증 2 : 구현 1. 분석 4 + 계획 1 + 검증 2 = 7노드 fan-out. 코드 ground truth와 확정 답변을 공유 컨텍스트로 각 노드에 주입. 구현은 계획 승인 후 별도.

## 목표

Full ATI 리팩토링 후속 4개 변경의 분석·설계·검증:
1. 절전 진입의 threshold=255 무감(Fixed 잔재) 제거 → Full ATI 적응임계로 절전 중 터치 정상 감지·롱터치 깨움
2. 200ms 폴링마다 LTA·Counts·절대임계·밴드초과 계측을 RTT(printd)로 표시 (Beta 값은 유지)
3. 부팅 boot_ignore 해제를 400ms(2폴링) 연속 not-pressed로 디바운스
4. ci_print 레벨 정책 (ATI=printw, Re-ATI=printi, 주기=printd, 기존 치명 printe 유지)

## 코드 ground truth (사전 파악 4종 종합)

### 드라이버 (tdc_touch_iqs323.c/.h)
- `apply_settings()`: 0x62=0x0810(threshold=16, hyst=8), 0xB1 LTA Normal beta=8/8, 0xB2 Fast=2/2, 0x36=0x040C(ATI Full), 0xC0 Power Automatic No ULP(bits[6:4]=101), CH timeout disable.
- `apply_sleep_settings()`: **0x62=0xFFFF(threshold/hyst 255=무감)**, 0xC0=0x0700(Power Normal bits[6:4]=000, CH timeout disable). ← Fixed 잔재 대상.
- `read_status()`: 0x10만 read (pressed=MSB bit1, ati_active=LSB bit5, ati_error=LSB bit6).
- LTA(0x14)·Counts(0x13) read 코드 **없음**. REG_* 주소는 .c 내부 #define(헤더 미노출).
- `re_ati()`=0xC0←0x0754, `reseed()`=0xC0←0x0758, `mclr()`=GPIO DIO16 토글(I2C 아님).

### FSM (tdc_touch_logic.c/.h, tdc_touch.c)
- 폴링 주기 `TDC_TOUCH_POLL_INTERVAL_MS=200` (tdc_touch_time.h:18).
- boot_ignore 해제(logic.c:119-122): `read_ok && curr_state != TOUCH` **1회 즉시, 디바운스 없음**.
- NOT_TOUCH↔TOUCH: `in->pressed` 1tick 즉시 천이. 디바운스 없음.
- read 실패: 10회(2000ms)까지 ACT_HOLD 동결, 초과 시 NOT_TOUCH 강제.
- Re-ATI 게이트(logic.c:140-146): NOT_TOUCH && !ati_active && ati_error && now>=cooldown(2000ms).
- stuck 에스컬레이션: TOUCH 30s마다 RESEED→Re-ATI→MCLR.
- 상태구조체(logic.h:64-75): prev_state, read_fail_cnt, boot_ignore, boot_ready_ms, boot_5s_warned, first_touch_ms, long_latched, re_ati_cooldown_until_ms, stuck_anchor_ms, stuck_stage.
- logic.c는 **순수 FSM(HW/timer/printf 0건)** — 유닛테스트 가능. 메시지는 tdc_touch.c 디스패치에서.

### 메시지 (ci_printf.h)
- `ci_printe`(error,빨강,파일/함수/줄 접두), `ci_printw`(warn,노랑), `ci_printi`(info,초록), `ci_printd`(debug,기본색), `ci_printv`(verbose). 전부 printf 스타일·SEGGER RTT·컴파일 게이트 현재 전부 1.
- tdc_touch_iqs323.c: ci_printe 다수(I2C/write/read/apply 실패). tdc_touch.c: printi/printw(INIT·BOOT·RE-ATI·RESEED·MCLR·LONG TOUCH 등). logic.c: print 0건.
- 한글 문자열 사용 사례 있음(RTT UTF-8).

### 레지스터/Beta (데이터시트·앱노트)
- LTA `0x14`, Filtered Counts `0x13` (CH0, 16-bit read-only).
- 0x62: threshold[7:0], hysteresis[15:12]. 절대 터치임계 = threshold×LTA/256.
- Beta 0xB1/0xB2: NP/LP 8비트씩. **DS(Beta/256, 클수록 빠름) ↔ AZD004(2^β, 클수록 느림) 해석 정반대 → 실측 게이트.** 현재 8=중간(DS) 또는 매우느림(AZD004).
- ATI Full(0x36 bits[2:0]=100): IC가 MULT/COMP 자동 산출. threshold=255는 ATI를 끄는 게 아니라 임계를 무한대로(무감).

## 확정 답변 (인터뷰 2026-06-22)
- 절전: Full ATI 적응임계 유지(무감 255 제거). 절전 전용 임계/ATI 재산출 구체 설계는 분석이 제안.
- Beta: 값 유지(8), 계측/표시만.
- 디버그: LTA·Counts·절대임계·threshold/hyst 원값+상태·LTA밴드 초과여부.
- printe: 이벤트만 신규(ATI=printw, Re-ATI=printi, 주기=printd). 기존 치명 printe 유지.
- 400ms 디바운스: boot_ignore 해제에만. 일반 천이 현행 유지.
