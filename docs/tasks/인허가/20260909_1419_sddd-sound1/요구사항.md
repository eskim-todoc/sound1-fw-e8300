# Sound1 소프트웨어 상세 설계서 - 요구사항

**TL;DR**: 1.5세대 `SDDD-FW-TD20B`(단락 1,361 · 순서도 44점 · **SU-ID 186개**)를 승계해 Sound1 판을 Word 로 작성한다. 유닛 입도는 **1.5세대 수준 선별(~200개)**, 순서도는 **주요 SI 항목만(~12점)**, 진행은 **CFX -> CM3 -> 부트로더 단계별**이다. QCC5181 은 SAD 와 같은 판단으로 범위 밖이다.

---

## 1. 배경

[SAD 작업](../20260909_1129_sad-sound1/)의 후속이다. SAD 가 «어떤 모듈이 있는가»를 정했다면 SDDD 는 **«각 유닛이 무엇을 받아 무엇을 하고 무엇을 바꾸는가»**를 정한다. 후속 문서인 SUVC(유닛 검증 기준서)·SUVR(유닛 검증 보고서)이 이 문서의 SU-ID 를 그대로 참조하므로, **ID 체계와 입도가 이후 4종 문서의 분량을 결정한다.**

## 2. 인터뷰 기록

### 원본 실측 - 1.5세대 SDDD 구조

| 항목 | 값 |
|---|---|
| 분량 | 단락 1,361 · 표 14 · **이미지 44** · 3.25 MB |
| 용지 | A4, 여백 좌우 2.0 / 상 2.0 / 하 1.5 (SAD 와 동일) |
| **SI-ID**(항목) | 14개 - CFX 6 · CM3 5 · NRF 3. 각각 순서도 1점 |
| **SU-ID**(유닛) | **186개** - CFX 61 · CM3 107 · NRF 18 |

유닛 서술 서식은 4줄 고정이다.

```
SU-ID-CM3-073, I2C 데이터 쓰기 시작 유닛
    입력 파라미터 : 슬레이브 장치 주소, 송신 데이터 주소, 송신 데이터 개수
    반환 파라미터 : 없음
    수정 파라미터 : I2C 드라이버 상태
    기능 및 동작 :
    - I2C 인터페이스의 데이터 송신이 가능한지 확인하고 슬레이브 장치에 데이터를 송신을 시작 한다.
```

### Sound1 유닛 후보 실측

헤더 선언 함수 기준 **528개**. 1.5세대가 186개였으므로 그때도 전수가 아니라 선별이었다.

| 코어 | 모듈 | 후보 | | 코어 | 모듈 | 후보 |
|---|---|---:|---|---|---|---:|
| CFX | 시스템 제어 | 23 | | CM3 | 시스템 제어 | 164 |
| CFX | 오디오 입력/믹서 | 31 | | CM3 | 신호처리 | 7 |
| CFX | 신호처리 | 28 | | CM3 | 내부 자극 장치 실행 | 104 |
| CFX | 내부 자극 장치 실행 | 18 | | CM3 | 블루투스 통신 | 46 |
| BOOT | 부트로더 | 79 | | CM3 | 공통 | 28 |

### 질문_1 - 유닛 입도

**답변: 1.5세대 수준 선별 (~200개).** 내부 보조 함수·단순 getter/setter 는 묶거나 생략한다.

### 질문_2 - 순서도

**답변: 주요 SI 항목만 (~12점).** 유닛은 텍스트로만 기술한다.

> 근거: 순서도가 40점을 넘으면 코드가 바뀔 때마다 그림을 고쳐야 해 문서가 코드를 못 따라간다. 흐름이 실제로 갈라지는 항목에만 넣는다.

### 질문_3 - 진행 방식

**답변: CFX 부터 단계별.** CFX 장을 먼저 완성해 서술 방식을 확인받은 뒤 CM3·부트로더로 잇는다.

### SAD 에서 승계하는 결정 (재질문 없음)

| 항목 | SAD 결정 | SDDD 적용 |
|---|---|---|
| QCC5181 | 구조적으로만 포함, 펌웨어는 범위 밖 | **장(章)을 만들되 «범위 밖» 선언 + 확장 자리**. 1.5세대 6장(NRF)의 자리를 차지한다 |
| 부트로더/OTA | 포함하되 착탈 가능 | **독립 장으로 격리.** 본문 장 번호 상호참조 0건 유지 |
| 식별자 | 일괄 치환 가능한 형태 | `SDDD-FW-SND1` · `SND1-A-EXT` · `YYYY.MM.DD` 토큰 |

## 3. 요구사항

| 라벨 | 내용 | 수용 기준 |
|---|---|---|
| **요구사항_1** | 1.5세대 SDDD 의 **장 구성과 유닛 서술 서식(4줄)을 승계**한다 | 모든 SU-ID 항목이 입력/반환/수정 파라미터 + 기능 및 동작 4요소를 갖는다 |
| **요구사항_2** | 유닛의 **입력·반환 파라미터는 실제 함수 서명에서** 가져온다 | 지어낸 파라미터가 없다. 추출 스크립트가 산출물로 남는다 |
| **요구사항_3** | **기존 유닛 분해 자산을 승계**한다 - `20260626_i2s-beamforming-modularize/유닛-모듈-테스트맵.md` 의 14 유닛 / 6 모듈 | 해당 유닛에 **U/M 라벨 교차참조**가 붙는다 |
| **요구사항_4** | **순서도는 주요 SI 항목에만** 넣는다 | 순서도 수 <= 15 |
| **요구사항_5** | QCC 장은 «범위 밖» 선언 + 확장 자리, 부트로더 장은 **착탈 가능** | 장 번호 상호참조 0건 |
| **요구사항_6** | 산출물은 **Word(.docx)**, A4 인쇄 가능 | 표 폭 <= 17.0 cm |
| **요구사항_7** | **CFX 장을 먼저 완성**하여 제출한다 | CFX 장의 모든 유닛이 4요소를 갖춘 상태로 검토 가능 |

## 4. 범위 밖
