# SDDD 유닛 제외 체크리스트

**TL;DR**: 상세 설계서의 **항목 41개 · 유닛 351개** 전체 목록이다. **체크한 것이 문서에서 빠진다.**
표시를 마친 뒤 알려 주시면 문서를 다시 만든다.

---

> [!CAUTION]
> **체크 = 제외다.** `- [ ]` 는 유지, `- [x]` 는 문서에서 뺀다.
> 남길 것을 고르는 목록이 아니라 **뺄 것을 고르는 목록**이다.

## 쓰는 법

| 무엇 | 어떻게 |
|---|---|
| 유닛 하나를 뺀다 | 그 유닛 줄의 `[ ]` 를 `[x]` 로 바꾼다 |
| 항목을 통째로 뺀다 | **항목 제목 줄**의 `[ ]` 를 `[x]` 로 바꾼다. 그 아래 유닛을 하나씩 체크하지 않아도 된다 |
| 되돌린다 | `[x]` 를 `[ ]` 로 되돌린다. 원본 데이터는 그대로 있으므로 몇 번이든 오갈 수 있다 |

> [!NOTE]
> **번호는 원본 기준이다.** 유닛을 빼면 문서의 SU-ID 는 빈 번호 없이 다시 매겨진다.
> 이 체크리스트의 번호는 어느 유닛인지 가리키는 이름표이므로 그대로 둔다.
>
> 순서도가 붙은 항목(★)을 빼면 그 순서도도 함께 빠진다.

## 4. CFX Core  (항목 10 · 유닛 116)

### 4.1. System Control Module

- [ ] **[항목] 4.1.1. SI-ID-CFX-001, 시스템 초기화 항목 ★**  (유닛 17)
    - [ ] `CFX-001` 인터럽트 설정 유닛 · `app_configure_interrupts`<br>동작 모드에 따라 받아야 할 인터럽트만 열어, 필요 없는 인터럽트로 처리 주기가 흔들리지 않게 한다.
    - [ ] `CFX-002` 인터럽트 플래그 일괄 해제 유닛 · `app_clear_all_interrupt_flags`<br>설정을 바꾸기 직전까지 쌓인 과거 이벤트를 지워, 바뀐 설정에서 첫 처리가 잘못된 입력으로 시작하지 않게 한다.
    - [ ] `CFX-003` 반복 실행 허가 확인 유닛<br>Cortex-M3 의 초기화가 끝나기 전에 CFX 가 먼저 동작하여 준비되지 않은 공유 메모리를 읽는 것을 막는다.
    - [ ] `CFX-004` HEAR 정지 및 리셋 유닛<br>함수체인을 설정하기 전에 하드웨어 가속기를 알려진 초기 상태로 되돌린다.
    - [ ] `CFX-005` HEAR 함수체인 활성화 유닛<br>CFX 가 호출할 하드웨어 연산 묶음을 사용 가능한 상태로 등록한다.
    - [ ] `CFX-006` HEAR 기동 유닛<br>설정이 끝난 하드웨어 가속기를 실행 상태로 만들어 함수체인 호출을 받을 수 있게 한다.
    - [ ] `CFX-007` 오디오 경로 설정 유닛 · `tdc_configure_audio_path_all`<br>마이크에서 들어온 소리가 신호처리 입력까지 도달하도록 하드웨어 경로를 한 번에 배선한다.
    - [ ] `CFX-008` PCM 인터페이스 초기화 유닛 · `lib_init_PCM`<br>내부 이식장치로 자극 비트스트림을 내보낼 출력 인터페이스를 준비한다.
    - [ ] `CFX-009` PCM DIO 설정 유닛 · `LIB_PCM_DIOConfig`<br>PCM 신호선을 올바른 방향과 구동 세기로 세워 내부기와의 전송이 성립하게 한다.
    - [ ] `CFX-010` I2S 인터페이스 초기화 유닛 · `lib_init_I2S`<br>블루투스 콤보 칩셋이 보내는 외부 오디오를 받을 입력 인터페이스를 준비한다.
    - [ ] `CFX-011` 2채널 마이크 활성화 유닛 · `tdc_enable_2_DMICs`<br>지향성을 형성할 수 있도록 두 마이크를 모두 켠 상태로 기동을 시작한다.
    - [ ] `CFX-012` I2S 입력 활성화 유닛 · `lib_enable_I2S`<br>외부 오디오 수신을 시작하여 블루투스 콤보 칩셋이 보내는 소리를 받을 수 있게 한다.
    - [ ] `CFX-013` PCM 출력 활성화 유닛 · `lib_enable_PCM`<br>자극 비트스트림 송출을 시작한다. 초기화 순서에서 가장 마지막에 배치되는 출력 관문이다.
    - [ ] `CFX-014` 출력단 설정 유닛<br>오디오 경로를 귀로 들어 확인할 수 있는 점검용 출력을 준비한다.
    - [ ] `CFX-015` PCM 상태 초기화 유닛 · `fn_reset_PCM`<br>자극 프레임이 반드시 시작 지점부터 나가도록 출력 상태 기계를 원점으로 되돌린다.
    - [ ] `CFX-016` PCM 명령 경쟁 방지 플래그 초기화 유닛<br>두 코어가 같은 명령 버퍼를 동시에 건드려 명령이 반쯤 섞이는 것을 막는다.
    - [ ] `CFX-017` 포화 연산 모드 설정 유닛<br>연산 결과가 표현 범위를 넘을 때 소리의 부호가 뒤집히는 왜곡을 막는다.

- [ ] **[항목] 4.1.2. SI-ID-CFX-002, 주 제어 항목 ★**  (유닛 9)
    - [ ] `CFX-018` I2S 입력 유효성 확인 유닛<br>외부 오디오가 실제로 들어오는 중인지 판정하여, 들어오지 않을 때 빈 버퍼를 소리로 처리하지 않게 한다.
    - [ ] `CFX-019` I2S 입력 버퍼 복사 유닛<br>수신 FIFO 의 한 블록을 소프트웨어 버퍼로 옮겨, 다음 블록이 도착하기 전에 FIFO 를 비운다.
    - [ ] `CFX-020` I2S 스트리밍 상태 설정 유닛 · `tdc_i2s_set_streaming_state`<br>외부 오디오 입력 여부를 한 곳에 기록하여, 마이크 개수 전환과 믹싱 경로 선택이 같은 값을 보게 한다.
    - [ ] `CFX-021` I2S 스트리밍 상태 읽기 유닛 · `I2S_isStreaming`<br>기록된 외부 오디오 입력 여부를 다른 유닛이 참조할 수 있게 한다.
    - [ ] `CFX-022` 마이크 사용 개수 전환 유닛 · `tdc_enable_1_DMIC`<br>외부 오디오가 들어오는 동안 마이크를 1채널로 줄여, 두 입력을 합성할 때 경로를 단순하게 유지한다.
    - [ ] `CFX-023` 입력 동기 판정 유닛<br>한 블록 분량의 입력이 모두 갖추어진 시점에만 처리를 시작하여, 채널 간 블록 경계가 어긋난 채 합성되는 것을 막는다.
    - [ ] `CFX-024` 마이크 버퍼 시프트 복사 유닛 · `tdc_copy_DMIC_buffers`<br>지향성 형성에 필요한 직전 블록을 보존하면서 새 블록을 받아, 블록 경계에서도 시간차 합성이 끊기지 않게 한다.
    - [ ] `CFX-025` 자극 데이터 출력 유닛 · `pcmDataOut`<br>현재 출력 모드에 해당하는 비트스트림을 만들어 내부 이식장치로 내보낸다.
    - [ ] `CFX-026` 인터럽트 대기 유닛<br>처리할 일이 없는 동안 코어를 멈춰 소비 전력을 낮춘다.

- [ ] **[항목] 4.1.3. SI-ID-CFX-003, 저전력 대기 항목 ★**  (유닛 11)
    - [ ] `CFX-027` PCM 출력 비활성화 유닛 · `lib_disable_PCM`<br>자극 송출을 가장 먼저 끊어, 이후 정지 과정에서 생기는 어떤 데이터도 내부기로 나가지 않게 한다.
    - [ ] `CFX-028` 출력단 비활성화 유닛<br>점검용 오디오 출력을 정지시켜 대기 중 불필요한 전력 소모를 없앤다.
    - [ ] `CFX-029` I2S 비활성화 유닛 · `lib_i2s_disable`<br>외부 오디오 수신을 정지시킨다.
    - [ ] `CFX-030` ADC 및 마이크 비활성화 유닛 · `disable_DMIC`<br>마이크 입력 경로를 정지시켜 대기 중 소비 전력의 가장 큰 부분을 없앤다.
    - [ ] `CFX-031` IOC 비활성화 유닛<br>입출력 연결부의 배선을 모두 끊어, 정지된 블록에 신호가 남아 흐르지 않게 한다.
    - [ ] `CFX-032` FIFO 비활성화 유닛 · `disable_FIFO_all`<br>사용 중이던 모든 버퍼를 정지시켜 대기 중 인터럽트가 발생하지 않게 한다.
    - [ ] `CFX-033` HEAR 정지 유닛<br>하드웨어 가속기를 정지시켜 대기 중 연산이 진행되지 않게 한다.
    - [ ] `CFX-034` 인터페이스 DIO 복원 유닛<br>대기 중 신호선이 뜬 상태로 남아 상대 장치를 오동작시키는 것을 막는다.
    - [ ] `CFX-035` 대기 모드 인터럽트 전환 유닛<br>기상에 필요한 인터럽트만 남겨, 대기 중 불필요한 깨어남을 없앤다.
    - [ ] `CFX-036` 저전력 진입 명령 해제 유닛<br>수행이 끝난 명령을 지워, Cortex-M3 가 진입 완료를 확인하고 다음 명령을 낼 수 있게 한다.
    - [ ] `CFX-037` 기상 대기 유닛<br>기상 조건이 성립할 때까지 최소 전력으로 대기한다.

- [ ] **[항목] 4.1.4. 시스템 이벤트 처리 항목**  (유닛 9)
    - [ ] `CFX-038` 전원 모드 이벤트 처리 유닛 · `LB_Normal_PowerMode`<br>내부기 연결 여부를 먼저 가려, 연결되지 않은 상태에서 자극 관련 계산이 진행되지 않게 한다.
    - [ ] `CFX-039` 내부기 연결 처리 유닛 · `Normal_PowerMode_isdConnected`<br>내부기가 연결된 동안 설정 변경을 감지하여 필요한 계수만 다시 계산한다.
    - [ ] `CFX-040` 내부기 해제 처리 유닛 · `Normal_PowerMode_isdDisonnected`<br>내부기가 없는 동안 자극이 생성되지 않는 상태를 유지한다.
    - [ ] `CFX-041` 맵 변경 이벤트 처리 유닛 · `Normal_PowerMode_event_mapChange`<br>사용자가 프로그램을 바꾸면 그 맵에 맞는 자극 조건과 지향성 축을 다시 세운다.
    - [ ] `CFX-042` 오디오 파라미터 계산 이벤트 처리 유닛 · `Normal_PowerMode_event_audioParameterCalculation`<br>Cortex-M3 가 계산한 자극 레벨을 신호처리 계수에 반영한다.
    - [ ] `CFX-043` 자극 볼륨 변경 이벤트 처리 유닛 · `Normal_PowerMode_event_stimulationVolumeChange`<br>사용자가 자극 세기를 바꾸면 그 단계에 맞는 상한과 매핑 계수를 다시 세운다.
    - [ ] `CFX-044` 자극 및 오디오 볼륨 동시 변경 처리 유닛 · `Normal_PowerMode_event_both_stimulation_audio_volumeChange`<br>두 볼륨이 같은 블록에서 함께 바뀐 경우 계수를 한 번만 계산하여 처리 시간을 지킨다.
    - [ ] `CFX-045` 매핑 데이터 복사 유닛 · `copy_MappingData`<br>공유 메모리의 맵 데이터를 CFX 가 매 블록 빠르게 참조할 수 있는 형태로 옮긴다.
    - [ ] `CFX-046` 매핑 데이터 복사 유닛, 생성일자 제외 · `copy_MappingData_without_mappingDate`<br>맵 생성일자를 남겨 둔 채 나머지만 갱신하여, 변경 감지가 다시 걸리지 않게 한다.

    - [ ] `CFX-048` 독립 2버퍼 믹싱 유닛 · `tdc_audio_mix_2_buffers`<br>시간차가 필요 없는 두 입력을 단순히 더해 하나로 만든다.

    - [ ] `CFX-050` 게인 변환 테이블 조회 유닛 · `tdc_audio_gain_lookup_q8_16`<br>사용자 설정 단계를 실제 곱할 게인 값으로 바꾼다.

    - [ ] `CFX-052` 오디오 경로 일괄 설정 유닛 · `tdc_configure_audio_path_all`<br>마이크 개수가 바뀔 때 하드웨어 경로 전체를 일관되게 다시 세운다.
    - [ ] `CFX-053` 디지털 마이크 활성화 유닛 · `enable_DMIC`<br>마이크 인터페이스에 클럭을 공급하여 표본화를 시작한다.

    - [ ] `CFX-055` 아날로그 마이크 활성화 유닛 · `enable_AMIC`<br>아날로그 입력 경로를 점검할 수 있게 한다.
