# APx NofM 군별 합성파 및 설정 매뉴얼

## 2026-09-17 구형 파형 정리

사용자 요청으로 이전 구성 WAV6개(ch01-12, ch12-24, ch13-24, ch21-32, ch24-32, ch25-32)를 Windows 휴지통으로 이동했다. 현행 16톤3개와 검증 결과는 유지했다. 목록·매뉴얼·생성기의 구형 파일 보존 안내도 갱신했다. 아래 보존 기록은 정리 전 이력이다.

## 2026-09-17 요청 정정 반영 — 현재 구성

- 사용자 요청: NofM용 16채널 묶음을 시작점 8채널 간격으로 생성. 8~24는 17개이므로 1~16 / 9~24 / 17~32로 해석하고 작업 시작 시 설명했다.
- ch01-16.wav / ch09-24.wav / ch17-32.wav 생성, 각 16톤 및 시작점 1·9·17 검사 완료.
- 전체 RMS -24dBFS(1FS 기준), 각 파일 48kHz·PCM24·모노·1.024초. 재디코딩 검증 통과. 톤 간 진폭 차이 <0.000003dB, 비지정 FFT 성분 <-130.81dBc, 피크 -12.14~-11.52dBFS.
- 파형 목록의 APx 출력 방법을 유지하며 16톤 예시로 수정했다. 설정 매뉴얼·인덱스도 새3종으로 갱신했다. 파일의 수치 검증만 수행했으며 실재생·전극 출력은 미측정이다.
- 이전 WAV6개는 삭제하지 않고 보존하되 현행 문서에 구버전임을 명시했다. 아래 기록은 최초 요청 당시 이력이다.

## 요청·범위

2026-09-16: APx 주파수 합산 방법을 다시 문서화하고, 전극 1~12 / 12~24 / 24~32의 음향 입력 조합과 12자극/ms 조건을 확인한다. 기존 매뉴얼을 갱신한다. 펌웨어·장치 맵·정식 시험 기준서는 변경하지 않는다. 커밋·병합은 요청되지 않았다.

## 분석과 결정

- 요청 구간은 각각 12·13·9톤이며 그대로 제공한다. 정확히 12톤인 대안은 1~12 / 13~24 / 21~32이고 마지막 두 조합은 겹친다. 비중복 마지막 25~32의 8톤도 제공한다.
- 현재 작업 트리의 기본 맵1은 CIS·50us·3프레임·최대8자극/ms. 맵3은 NofM·14us·2프레임·12슬롯/ms. 장치 저장 맵을 직접 읽은 결과는 아니다.
- NofM의 선택 수는16. 매2ms 새 목록을 계산하고 12슬롯씩 쓰므로 둘째1ms에는 마지막4개 후 앞8개를 재전송한다. 12톤으로 특정12전극 반복을 보장하지 않는다.
- Hann창 대역간 누설, 기본 맵의 전극16 T=C, AGC·매핑 영향을 명시한다.
- AP 공식 문서에서 WAV Browse for file과 Multitone 편집 필드를 확인했다. 설치 장비 UI를 직접 실행하지 않았다. 기존 tmp의 v9.1 PDF 이름 파일은 HTML이어서 PDF 근거로 사용하지 않았다.
- 제공 WAV를 권장 경로로 한다. APx 네이티브 Multitone에서 48kHz/1536 길이가 허용되는지는 확인하지 못했으므로 무조건 가능한 설정으로 쓰지 않는다.
- 원래 매뉴얼의 32톤 중심 설명을 현재 군별 시험 중심으로 갱신했다. 정식 ID-9의 32톤 강약 시험은 대체하지 않음을 명시했다.

## 구현·검증

완료. [매뉴얼](../../../참고/인허가/사운드1/APx500%20Sound1%20N-of-M%20시험%20신호%20설정%20매뉴얼.md), [파형 목록](../../../참고/인허가/사운드1/APx%20NofM%20합성%20파형/파형%20목록.md).

- 재현 명령: Python 3 + NumPy 환경에서 이 폴더의 `스크립트/make_waveforms.py` 실행.
- 32주파수를 소스 `ci_fft_init_pass_bin_ch_32`의 대역 배정과 전수 대조했다.
- WAV6개: 48kHz·모노·PCM24·49152샘플, 위상0도, 상대레벨0dB, 전체RMS -24dBFS(1FS 기준).
- 파일 재읽기·PCM 디코드 일치·32ms 패턴 반복 일치·정확한 지정 FFT 성분을 확인했다.
- 톤 진폭 차이 최대 0.0000023dB 미만, 비지정 FFT 성분 최대 -131.43dBc 이하, 피크 약 -12.68~-11.62dBFS.
- 위 검증은 파일 신호에 대한 계산이다. APx 재생·스피커 응답·음압·전극 출력은 실기 미검증이다.
- 기존 사용자 수정 파일인 ci_map.c·ADC Excel 등은 변경하지 않았다.

## 남은 실기 확인

실제 장치의 선택 맵을 읽고, APx에서 WAV 재생과 음압을 설정한 뒤 여러1ms 구간의 PCM/전극 출력으로 비교한다. 특정12전극만의 강제 출력은 별도 요구 확정과 구현 범위가 필요하다.
