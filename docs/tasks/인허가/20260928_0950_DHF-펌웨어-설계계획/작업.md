## 목표와 범위

G드라이브 사운드1 참고폴더의 `01_설계 계획/SW/펌웨어`에 있는 SCCP·SCMP·SDP·SMP·SPRP·SRMP 6개 DOCX를 Sound1 TD24A-A-EXT용으로 전환한다. 산출물은 로컬 `docs/참고/인허가/사운드1/DHF/01_설계 계획/SW/펌웨어`에 같은 파일 체계로 만들며, 변경 위치·내용·이유를 설명하는 MD 한 개를 함께 둔다. 원본·펌웨어·기존 다른 산출물·Git 이력은 변경하지 않는다.

## 수용 기준과 계획

1. 각 원본 문서와 대응되는 TD24A 문서 6개를 만들고 원본 해시 불변을 확인한다.
2. 제목·제품명·문서 식별자·상호참조·적용 범위가 일치한다. 실제 승인·시험 수행·법적 적합성 확인을 새로 했다고 만들지 않는다.
3. 스타일·용지·여백·표·번호·그림·관계 파일을 보존한다. 예외는 이전 제품의 서명 제거, 필드 갱신 등 명시된 변경에 한정한다.
4. Sound1 CFX/HEAR/CM3·부트로더 범위 및 QCC 별도 펌웨어와의 인터페이스, 주요 변경의 시험 계획을 반영한다.
5. 원문과 최종본 페이지를 검토하고 변경 설명에 불확실성·검증 범위를 남긴다.

## 근거·결정

- 제품명: 사용자 2026-09-28 설명. Sound1 TD24A-A-EXT, 설리번1.5 TD23D-A-EXT, 설리번 TD20B-A-EXT. 참고 문서의 TD20B 표기는 승계 원본으로 보존하고 신규 문서의 식별만 전환한다.
- 사용자 요청은 서식 최소 변경이다. 원본 ZIP에서 지정한 OOXML 텍스트만 바꾸며 공통 문서 기본 서식으로 재작성하지 않는다.
- 원본 2020년 이름·직책·승인 날짜·서명은 Sound1 승인 근거가 아니므로 새 사본에서 비운다. 현 담당자·승인일·허가 적합성은 임의 확정하지 않는다.
- 기본 render_docx.py 실행은 묶음 런타임에 LibreOffice가 없어 실패했다. 사용자 설치 LibreOffice로 우회하지 않고 Word 읽기 전용 PDF 출력 및 PNG 변환으로 검증한다.

- Word 읽기 전용 필드 갱신 후 PDF 렌더: SCCP 8 / SCMP 12 / SDP 15 / SMP 7 / SPRP 8 / SRMP 14쪽. 원본과 동일.
- 전체 페이지 연락판 검토 및 밀집 표 페이지 확대 확인. 최종 번호 수정 후 SDP 15쪽 재확인. 검증 이미지는 `tmp/dhf-plans-20260928/final-v2`.

- 목차와 페이지는 기존 Word 필드 유지 및 열기 시 갱신 설정. 렌더는 갱신한 상태로 확인했으며 원본 전체를 Word 재저장하지 않아 서식을 보존.
- Git 커밋·병합·푸시, 참고 원본 및 펌웨어 변경 없음.

## 후속 수정 — 기존 방식 유지

- 사용자 지시: 작성 김은수 수석연구원, 일자·서명 및 검토·승인 빈칸. 개정 0, 품목 등급은 기존 제품과 동일. 기존 방식의 변경을 최소화.
- 이전 전환본의 NA 대체, 별도 승인·종결 조건, Git 브랜치 절차 재작성, 위험관리 필드 변경을 원문으로 복원. Sound1 구성·기능은 기존 문장 뒤에 짧게 추가.
- 머리말 0 및 최초 제정 이력 유지. 상태성 설명(검토본·전환안·적용 확인) 제거. 원본 보존 및 수정 설명 MD 동기화.
- 최종 QA: `verify_plans.py` 6종 통과. Word 렌더 `tmp/dhf-plans-20260928/minimal-v3`, 총 64쪽 전체 연락판 확인. 기존 표 이어짐 외 잘림·겹침 발견 없음.

## 후속 수정 — 실제 변경 추적

- 사용자 요청에 따라 원본과 현재 수정본을 Word CompareDocuments로 비교하여 `_변경추적.docx` 6종 추가. 기존 파일은 덮어쓰지 않았다.
- `track_compare.ps1`: 비교 작성자 김은수, 실제 삽입·삭제 이력 및 향후 변경 추적 활성화. 내용 검토를 위해 서식 차이 비교는 제외.
- `verify_tracked.py`: ZIP 유효성, 추적 설정, 삽입·삭제 존재, 수락 상태 본문과 현재 수정본 일치 검사 6종 통과. 수락 처리는 메모리상 XML 검사에 한정하며 파일의 이력은 유지.
- Word 표시 포함 PDF 및 전체 연락판 확인: SCCP8·SCMP12·SDP15·SMP7·SPRP8·SRMP17쪽. SRMP에 표시 상태의 공백 페이지·그림 캡션 분리가 있으나 원본 서식을 임의 조정하지 않았다. 추적본은 검토용이며 깔끔한 기존 수정본은 별도로 유지한다.
- 기존 승인 서명은 삭제 이력에만 남는다. 모든 변경 수락 상태에서 그림 수가 현재 수정본과 일치하는지 추가 확인.
- 루트 `지침/헌법.md` 및 `지침/운영/문서 기본 서식.md`에 원본 기반 Word 편집의 실제 변경 추적 기본 규칙 반영. Git 이력 변경 없음.

## 파일 중복 정리

- 사용자 승인에 따라 추적 없는 기존 DOCX 6개를 추적본으로 교체하고 `_변경추적` 접미어 제거. 산출물 폴더에는 기존 이름의 DOCX 6종만 남겼다.
- 교체 전후 SHA256 일치로 Word 내용·추적 이력 불변 확인. 참고 원본은 그대로이며, 추적 없는 내용은 변경 수락으로 얻을 수 있다.
- 향후 추적본 중복 생성 없이 본 파일에 이력을 포함하고, 파일명 구분이 필요할 때 접두어를 우선하도록 문서 기본 서식 지침에 반영.
- 이전 비교·검증 스크립트는 별도 수정본과 추적본이 있던 당시 구조용이므로 현재 파일에 그대로 재실행하지 않는다.

## 원문이 포괄하는 추가 설명 제거

- 사용자 지시: 기존 내용이 충분하면 추가하지 않는다. 원문 문체를 유지하고 가운뎃점 대신 `/`, `,`를 사용한다.
- `trim_additions.py`: 추가 설명 21개 문단 삭제/축소. 삭제 대상이 실제 삽입 제안 안에 있는지 확인한 후 철회했으며 원문 문장과 나머지 추적 이력은 보존했다.
- SCMP의 NRF/QCC5181 그림 차이 설명은 기존 그림을 그대로 해석하는 오류를 막는 데 필요하여 짧게 유지. 나머지 제품 기능 나열은 제거.
- 최신 `edits.json`과 산출물 변경 설명을 동기화. 본문과 머리말 등 Word 텍스트에서 가운뎃점 0건 확인. 기존 이름의 DOCX 6개만 갱신.
- Word PDF 출력 후 64쪽 전체 연락판 확인(SCCP8/SCMP12/SDP15/SMP7/SPRP8/SRMP14). 기존 페이지 구성을 유지했으며 추가 설명 삭제 반영 확인. 본문 변경 이력은 각 15/18/133/15/15/25건 유지. QA 위치는 `tmp/dhf-plans-20260928/trimmed`.

## 형상관리 분기 그림의 QCC 표기

- 사용자 승인 후 코드로 PNG의 NRF 글자만 QCC로 수정. 원본 해상도 2132x1381 및 투명도 전체 보존, 글자 영역 밖 픽셀 불변 확인.
- `이미지 참조/SCMP 형상관리 분기 구성.png` 저장. 문서의 기존 이미지 크기와 위치를 유지하고 삭제/삽입 이력으로 교체했다. 기존 이미지는 삭제 이력 안에서만 유지한다.
- NRF/QCC 대응 설명은 삽입 제안에서 철회. 다른 본문과 원본 서식은 변경하지 않았다.
- 이미지 생성 도구의 두 결과는 선명도 문제로 채택하지 않았다. 최종 이미지는 사용자 승인한 직접 편집 방식으로 생성.
