문서의 styles.xml, numbering.xml, fontTable.xml, theme과 본문의 모든 pPr·rPr·sectPr·tblPr·tblGrid·trPr·tcPr를 보존한다. 즉, 본문·제목의 실제 글꼴·크기·색·굵기·번호·들여쓰기·간격·탭·유지 옵션, 표의 폭·색·테두리·병합·행 높이를 재설정하지 않는다. 로고·절차도 및 앵커 위치·크기도 보존한다. 원본의 넓은 공백과 표지 박스·목차 색상 등은 사용자 지정 원본 서식이므로 새 기본 서식으로 교체하지 않는다.

## 편집 위치와 허용 범위

- 본문 위치는 `word/document.xml`의 문단 인덱스와 변경 전 텍스트를 함께 검증한다. `edits.json`이 85개 내용 변경 위치·새 문장·변경 이유·기대 원문을 소유한다.
- 제품명·문서번호: 표지·머리말·본문·관련 문서 표의 TD20B를 TD24A로 전환한다. 역사 설명의 TD20B/TD23D는 유지한다.
- 승인 슬롯: 표지의 이전 작성·승인 이름·직책·날짜 및 서명 이미지 2개는 비운다. 새 담당자나 승인일을 만들지 않는다. 머리말은 검토본으로 구분하고 날짜는 비운다. 개정표의 최초 행은 전환안 작성으로 표시한다.
- 절차·설계 슬롯: 기존 해당 문단·표 셀 안에서만 Sound1 범위와 검증 계획을 보완한다. 제목 수준과 절차도는 그대로 두며 SCMP 구형 분기 그림은 본문에서 개념 예시로 한정한다.
- 메타데이터의 이전 작성자·수정자·날짜는 승계하지 않는다. 승인 서명 미디어와 해당 관계는 의도된 제거 예외다.
- 필드는 삭제하거나 평문으로 만들지 않는다. settings에 updateFields를 설정하고 Word 메모리상 갱신 후 PDF 검증한다. 최종 DOCX의 필드 결과 캐시 갱신 여부는 별도로 확인한다.

## 검증 기준

원본 해시 불변, 6개 산출물 대응, 위 보존 속성 동등, 변경하지 않는 ZIP 부품 일치, 기존 제품번호 잔존의 맥락 검토, Word 열기·페이지 출력·잘림 검사. 문장 증가로 인한 자연스러운 줄바꿈·쪽수 변화는 허용하되 공통 스타일·표 폭·용지 변경으로 맞추지 않는다. 불가피한 국소 레이아웃 수정은 변경 설명에 별도 기록한다.
