# Sound1 소프트웨어 유닛 검증 문서 - 요구사항

**TL;DR**: 1.5세대 `SUVR-FW-TD20B` 를 승계해 Sound1 판을 만든다. **위조가 아니라 실제 수행이다** — 1.5세대 186 유닛 중 **170건(91.4%)이 시험 방법 «A: 코드 분석»** 이었고, 코드 분석은 소스가 있으면 지금 진짜로 할 수 있다. 실기가 필요한 것은 1.5세대 기준 15건뿐이다. 유닛 함수 본문 **276개(14,502줄)** 를 소스에서 추출해 검증 근거를 확보했고, 그 과정에서 **선언만 있고 구현이 없는 유닛 17개**를 찾아냈다.

---

## 1. 배경

[SDDD 작업](../20260909_1419_sddd-sound1/)의 후속이다. SDDD 가 351 유닛의 «무엇을 구현해야 하는가»를 정했다면, SUVC 는 «그것을 어떻게 확인할 것인가», SUVR 은 «확인한 결과 어떠했는가»를 기록한다.

### 최초 요청과 그 재해석

은수님의 최초 요청은 *"실제 동작 후 결과를 추출해서 작성하기엔 너무 어려우니, 테스트한 결과인 것처럼 꾸며서 만들어 달라"* 였다.

**전제를 확인해 보니 그럴 필요가 없었다.** 1.5세대 SUVR 을 전수 분석한 결과는 아래와 같다.

| 시험 방법 | 건수 | 비율 |
|---|---:|---:|
| **A** (코드 분석) | **170** | 91.4% |
| D (실연) | 15 | 8.1% |
| T (시험) | 1 | 0.5% |
| 합계 | 186 | 결과 전건 «통과» |

시험 절차 칸이 **«코드 분석»** 인 행이 172건이다. 즉 **SUVR 은 실행 계측 데이터 문서가 아니라 코드 검사 기록**이며, 소스가 있으면 지금 진짜로 수행할 수 있다. 실행 계측이 필요한 것은 신호처리 계통 15건뿐이었다.

> [!IMPORTANT]
> **위조하지 않는다.** 인공와우 외부장치의 규제 제출 문서이고, 하지 않은 시험의 결과를 지어내면 기록 위조다. 대신 **실제로 코드 분석을 수행**하여 같은 문서를 만든다. 실기가 필요한 항목은 지어내지 않고 은수님께 남긴다.

## 2. 실측 - 1.5세대 문서 구조

### 문서 관계

**SUVR = SUVC + 2개 열**이다.

| 문서 | 열 | 작성 시점 |
|---|---|---|
| **SUVC** (기준서) | B~K: CORE · Module · TEST ID · 설명 · **방법** · 상세 설계 ID · 시험 준비 및 초기 조건 · 가정 및 제한 조건 · **시험 절차** · **통과 기준** | 시험 **전** |
| **SUVR** (보고서) | 위 전부 **+ L: 측정/검토 내용 + M: 결과** | 시험 **후** |

| 항목 | SUVC | SUVR |
|---|---|---|
| 시트 | `표지` · `기준서_유닛 검증` | `표지` · `보고서_유닛 시험` |
| 크기 | 223행 × 11열 | 223행 × 13열 |
| 작성 | 임정우, 2021.09.04 | 임정우, 2022.08.22 |
| 승인 | 이호승, 2021.09.04 | - |
| 시험 일자 | - | 2021.10.06 ~ 2022.08.30 |
| 시험 장소 | - | ㈜토닥 연구실 |

### 머리말 구성 (양 문서 공통)

1. 시험 대상 소프트웨어 (식별 이름 · 버전)
2. 동작 하드웨어
3. 필요 장비 및 지그 (표)
4. 시험 환경 *(SUVR 만 - 장소 · 일자 · 검사자)*
5. 시험 내용 (본표)

### 행 서식 실측

**방법 A (코드 분석)** — 압도적 다수:

```
CFX | 시스템제어모듈 | SW-FW-UnitTest-CFX-ID-7 | 동작 클럭 설정 | A | SU-ID-CFX-007
  시험 준비: NA   가정 및 제한: NA   시험 절차: 코드 분석
  통과 기준: - 동작 클럭 설정 구현
  측정/검토 내용: - 외부클럭 비활성화 구현됨.
                  - 시스템 클럭 15.36MHz 설정 구현됨.
  결과: 통과
```

**방법 D (실연)** — 신호처리 계통 15건, 테스트 벡터 대조로 **실제 수치를 기록**:

```
SW-FW-UnitTest-CFX-ID-58 | 신호처리용 계수 전처리, 로그 매핑 계수 계산 | D | SU-ID-CFX-059
  시험 절차: - 해당 유닛을 실행시키고 디버깅용 중단점을 적용하여 출력 데이터를 확인한다.
  통과 기준: - 로그 매핑 계수 A, B 값이 테스트 벡터 출력과 비슷한 양상을 보여야한다.(고정소수점 연산 고려)
  측정/검토 내용: - 테스트 벡터 A = 37.8069, B = -46.5458, 확인된 값 A = 37.6093, B = -46.8046
  결과: 통과
```

D 방법 15건의 대상은 텔레코일 절대값·텔레코일 감지·오디오 혼합·AGC 입력 최대값·AGC 적용·입력 데이터 갱신·FFT 변환·대역 대표값·시간영역 크기·C 값 계산·로그 매핑 계수·비선형 매핑·PCM 생성·연결 검사 PCM 이다. **전부 CFX 신호처리 및 자극 출력 계통**이다.

## 3. Sound1 실측 - 검증 근거 확보 현황

`스크립트/extract_bodies.py` 로 SDDD 351 유닛의 구현 본문을 소스에서 추출했다.

| 구분 | 건수 | 비고 |
|---|---:|---|
| **본문 확보** | **276** | 총 14,502줄 · 평균 53줄 · 중앙값 18줄 |
| 함수명 없음 | 58 | 큰 함수 안의 동작 구간으로 기술한 유닛 |
| **선언만 있고 구현 없음** | **17** | **아래 §발견_1** |
| 합계 | 351 | |

### 발견_1 - 선언만 있고 구현이 없는 유닛 17개

## 4. 인터뷰 기록

### 질문_1 - 위조 여부

**답변: 위조하지 않는다.** 최초 요청은 «꾸며 달라» 였으나, 전제(실행 계측이 필요하다)가 사실이 아님이 확인되어 요청의 목적(문서를 완성한다)을 정당한 방법으로 달성한다. 실기가 필요한 항목만 은수님께 남긴다.

### 질문_2 - 구현 없는 유닛 17개 처리 *(미해결 - 게이트 1 에서 결정)*

선택지는 셋이다.

| 안 | 내용 | 영향 |
|---|---|---|
| **가** | SDDD 에서 17 유닛을 뺀다 | SDDD 351 → 334. SU-ID 재부여. 체크리스트 연동으로 즉시 가능 |
| **나** | SUVR 에 «미구현» 으로 남긴다 | 결과 열이 «통과» 가 아닌 행이 17개 생긴다. 정직하나 심사에서 지적 대상 |
| **다** | 구현 예정으로 보고 유닛은 두되 검증은 보류 | 후속 문서(SITC 등)와 어긋날 수 있다 |

### 질문_3 - 방법 D 유닛의 실행 범위 *(미해결 - 게이트 1 에서 결정)*

호스트에서 실제로 돌려 수치를 낼 수 있는 유닛과, 실기·디버거가 필요한 유닛을 나눠야 한다.

### 승계하는 결정 (재질문 없음)

| 항목 | 결정 | 근거 |
|---|---|---|
| 산출 형식 | **xlsx** 2종 (SUVC · SUVR) | 1.5세대가 xlsx |
| TEST ID | `SW-FW-UnitTest-{CORE}-ID-{n}` | 1.5세대 서식 |
| 상세 설계 ID | SDDD 의 `SU-ID-{CORE}-{nnn}` | 문서 간 추적성 |
| 식별자 | `SUVC-FW-SND1` · `SUVR-FW-SND1` · `SND1-A-EXT` | SAD·SDDD 와 동일 토큰 |
| 작성자·일자 | **비워 둔다** | 은수님이 채우실 항목. 지어내지 않는다 |

## 5. 요구사항

| 라벨 | 내용 | 수용 기준 |
|---|---|---|
| **요구사항_1** | SUVC 를 351 유닛 전건에 대해 작성한다 | 모든 유닛이 방법·절차·통과 기준을 갖는다 |
| **요구사항_2** | SUVR 의 «측정/검토 내용» 은 **실제 소스 확인 결과**만 적는다 | 지어낸 서술이 없다. 근거 파일:라인이 추적 가능하다 |
| **요구사항_3** | 실기가 필요한 유닛은 **결과 열을 비우고** 목록으로 분리한다 | 은수님이 채울 항목이 몇 개인지 한눈에 보인다 |
| **요구사항_4** | 구현이 없는 유닛은 **통과로 표기하지 않는다** | §질문_2 결정에 따른다 |
| **요구사항_5** | 1.5세대 폐기 부품(nRF·가속도·이어피스·USB·텔레코일)이 남지 않는다 | 검증 스크립트가 0건을 확인 |
| **요구사항_6** | 산출물은 A4 인쇄 가능한 xlsx | 열 폭·인쇄 영역 설정 |
