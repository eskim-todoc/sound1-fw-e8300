# 설계 입력 문서 편집 기준

- 대상: SGR/SR Word 2개, SRS/SSTC Excel 2개, 시스템 구성도 PowerPoint 1개. System Data는 문서만 복사한다.
- 기준 파일의 표/스타일/번호/여백/슬라이드 구성은 유지한다. 변경은 식별, 작성란, 현행 부품, 요구사항 추적과 시험 기준에 한정한다.
- Word는 원본과 수정본을 비교하여 본 파일에 실제 변경 이력을 저장한다. 원본의 서명과 과거 검토 완료 문구는 현재 승인으로 승계하지 않는다.
- Excel은 원본 패키지를 복사하고 변경 셀과 필요한 추가 행만 반영한다. 기존 행 순서와 식별 번호는 유지하고 추가 요구사항은 뒤에 이어 붙인다. 셀별 변경 전후는 별도 기록한다.
- 온라인 매트릭스는 읽기만 한다. 100~149행의 50개 식별자를 로컬 사양서와 시험 기준서에 연결한다. 입력과 합격 기준의 불일치는 검토 사항으로 표시한다.
- 구형 System Data는 원문을 보존하고 사용 범위를 안내한다. E8300 제조사 자료는 별도 하위 폴더에 원문으로 추가한다.
- 검증: 원본 해시, Word 변경 수락/거부, 스타일 보존, 50개 요구사항 연결, 수식 오류, 전체 페이지/슬라이드 표시를 확인한다.
