## 5. 반복 컴포넌트

### 5.1 표지

- 큰 제목과 모델명
- 작성/검토/승인 4열 × 5행 표
- 정식 승인 정보가 없으므로 성명·직책·일자·서명 칸은 공란

### 5.2 개정이력

- 열: 개정번호 / 개정내역 / 개정 위치 / 개정 일자
- rev.0 한 행에 `Sound1 필수성능시험 기준서 최초 작성` 기록
- 나머지 행은 향후 개정용 공란

### 5.3 목차

- Heading 1~3을 기반으로 자동 생성
- 원본의 PAGEREF 고정 목차를 복사하지 않고 새 필드로 갱신

### 5.4 시험 절

각 ID는 다음 순서로 반복한다.

1. 시험 설명
2. 시험 준비 및 초기 조건
3. 시험 진행
4. 세부 시험별 측정 방법
5. 통과 기준
6. 필요한 경우 근거·주의사항

### 5.5 표

- 셀 여백과 고정 열 폭을 사용한다.
- 행이 페이지를 걸쳐 쪼개지지 않게 설정한다.
- 긴 ADC 부록표는 머리행 반복을 켠다.
- 단위는 열 머리글에 둔다.
