## 4. 수치 기준

### 4.1 ADC 판정 범위

| 시험 음압 | 허용 음압 | Sound1 완제품 ADC 범위 |
|---:|---:|---:|
| 35 dB SPL | 30~40 dB SPL | 3~10 |
| 70 dB SPL | 65~75 dB SPL | 179~567 |
| 85 dB SPL | 80~90 dB SPL | 1,008~3,190 |
| 110 dB SPL | 105~110 dB SPL | 17,942~31,907 |

ID-6·7처럼 목표 음압을 더 좁게 지시하는 절차에는 같은 표의 해당 행을 직접 적용한다. 예: 34~36 dB SPL은 ADC 5~6, 69~71 dB SPL은 ADC 284~358, 74~76 dB SPL은 ADC 505~636이다.

## 5. 비기능 요구사항

- 1.5세대 문서의 회사 로고·머리글 형식·바닥글 양식·제목 계층·표 시각 언어를 유지한다.
- 오래된 외부기 사진이나 1.5세대 전용 앱 화면은 Sound1 자료로 오인되지 않게 제거하거나, 세대와 무관한 설정 설명만 남긴다.
- 최종 DOCX는 Word에서 필드를 갱신한 후 다시 저장하고, 렌더링 결과의 목차·페이지 수를 확인한다.
- 작업 중 원본 두 DOCX와 ADC XLSX는 수정하지 않는다.
