# Sound1 필수성능시험 기준서 - 계획

**TL;DR**: 1.5세대 rev.4를 서식·절차의 모체로 복제하되 깨진 외부 연결은 정적 내용으로 바꾸고, Sound1 완제품 ADC 표·2-DMIC 시험 상태·7,968.75 Hz 상한·현행 32-band 배정·ID-9 N-of-M을 통합한다. 모든 시험은 고정 입력·명목 출력·허용오차·합격 범위를 갖는 시험자 자립형 기준서로 만들고 Word 렌더링 전 페이지를 검사한다.

## 1. 분석 결론

1. 수치·동작 사실: 현행 펌웨어와 최신 ADC 산출물
2. 시험 절차의 완전성: 1.5세대 최종 기준서 rev.4
3. Sound1에서 넣으려던 범위: Sound1 초안
4. 서식과 시각 체계: 1.5세대 최종 기준서

| 항목 | 확인 결과 | 근거 |
|---|---|---|

| Bluetooth Classic 오디오 | I2S 스트리밍 중이면 1-DMIC로 전환 | `src/1__cfx/systemControl/system_control.c:69-76` |

## 4. ADC 적용 규칙

- `ADC = floor(262143 × 10^((SPL - 120 - 8.293)/20))`
- 디지털 최대 표현값 262,143과 수식의 120 dB는 환산 기준이다. Sound1 제품의 최대 입력 사양은 110 dB SPL이며 완제품 명목 ADC는 31,907이다.
- 본문 판정에는 완제품 열만 사용한다.
- 부록 1에는 1.5세대·Sound1 PCB·Sound1 완제품을 함께 제시하되, `판정용` 표시를 Sound1 완제품 열에만 둔다.
- ID-9의 85 dB SPL 멀티톤 목표는 ADC 1,008~3,190으로 갱신한다.

## 4.1 Gate 2 보완 설계

- 1차 결과물의 범위 중심 판정은 `이슈보고서_1_시험벡터-판정구조.md`에 기록한다.
- 모든 ID에 「고정 입력 / 명목 기대 출력 / 허용오차 / 합격 범위」 표를 둔다.
- 명목 ADC는 Sound1 완제품 환산식으로 계산하고, 음압 허용 범위의 양 끝값을 ADC 합격 범위로 사용한다.
- ID-7 전류는 1.5세대 수치 판정과 FFT bin·Hann 창의 중심/인접 응답을 결합해 대상 934 uA, 인접 872 uA, 비대상 500 uA로 고정한다.
- ID-8 전류는 현행 프로그램 2의 T=C 맵 값을 명목값으로 하고 각 값의 ±10%를 합격 범위로 둔다.
- ID-9 멀티톤은 총 85 dB SPL을 고정하고 전력 합산식으로 성분별 음압을 산출한다.

## 5. Word 구현

- 기준 문서를 작업본으로 복제한 뒤 문서 본문을 새 구조로 재조립한다.
- A4 세로, 좌·우·상 20 mm, 하 15 mm를 적용한다.
- 식별정보와 페이지 필드는 모든 페이지에서 안정적으로 보이도록 바닥글 한 줄에 `F7030-02 (Rev.1)` / `EPTC-SND1` / `SND1-A-EXT` / `Rev.0` / `2026.09.10` / `PAGE/NUMPAGES` 순으로 배치한다.
- 원본의 `LINK Excel.Sheet.12` 15개와 외부 `INCLUDEPICTURE` 1개는 제거하고 값과 그림을 내장한다.
- 장비 사진은 세대 공통 장비만 재사용한다. 1.5세대 외부기 사진과 세대 특정 앱 화면은 Sound1 자료로 오인될 수 있어 제외한다.
- 표지 승인란의 성명·직책·일자·서명은 공란으로 둔다.
- 목차는 Word 필드로 생성하고 최종 저장 전에 갱신한다.
