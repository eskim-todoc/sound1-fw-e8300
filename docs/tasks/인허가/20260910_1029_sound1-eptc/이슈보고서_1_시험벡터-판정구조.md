# 이슈보고서_1 - 시험벡터·판정구조

**TL;DR**: 1차 기준서 일부 시험이 입력·출력의 허용 범위만 제시해 명목 시험점과 기대값이 불명확했다. 모든 시험을 고정 입력, 명목 기대 출력, 허용오차, 합격 범위 구조로 바꾸고 Sound1 최대 입력 음압을 110 dB SPL로 확정한다.

## 1. 발견 시점

- Gate 2 결과물 검토 중 은수님이 발견했다.

## 2. 문제

- ID-1·2·6·7·8·9 일부 표가 허용 범위 또는 정성적 결과만 제시했다.
- 시험자가 어떤 고정값을 인가하고 어떤 명목값을 기준으로 오차를 계산해야 하는지 문서 하나만으로 결정할 수 없었다.
- 최대 입력 음압이 1.5세대의 120 dB SPL을 그대로 승계해 Sound1 목표와 달랐다.

## 3. 원인

- Sound1 ADC 환산표의 범위를 직접 합격 범위로 옮기는 데 집중해, 1.5세대 기준서가 갖고 있던 「고정 입력 → 명목 출력 → 허용오차 → 합격 범위」 구조를 충분히 승계하지 못했다.

## 4. 선택한 해결책

- 모든 시험 ID에 고정 시험벡터와 명목 기대 출력을 표로 명시한다.
- 허용오차와 하한·상한을 같은 행에 표시한다.
- ID-1과 ID-6의 최대 입력은 110 dB SPL로 변경한다.
- ADC 환산식의 120 dB는 수식 정규화 기준점으로만 유지하고 제품 최대 사양과 구분한다.
- ID-7은 FFT bin·Hann 창의 기대 응답을 채널별 전류 명목값과 범위로 제시한다.
- ID-8은 프로그램 2의 24채널 전류열을 명목값과 ±10% 범위로 제시한다.
- ID-9는 멀티톤 총 음압, 성분별 음압, ADC 명목값·범위, 기대 전극 집합을 모두 고정한다.

## 5. 승인 근거

- 은수님 지시: 시험 기준은 정확한 입력값, 기대 출력값, 허용오차와 합격 범위를 가져야 하며 Sound1 최대 입력 음압은 110 dB SPL로 한다.
