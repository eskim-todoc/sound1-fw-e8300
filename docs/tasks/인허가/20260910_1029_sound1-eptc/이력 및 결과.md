# Sound1 필수성능시험 기준서 - 이력 및 결과

**현재 상태**: 원본 rev4 서식을 보존한 Sound1 기준서 작성과 검증을 완료했다. 은수님이 문서의 29~120 dBSPL을 APx 보정 표시값으로 쓰도록 확정했다. 원본 ADC 숫자, 맵3 Positive First/14usec를 유지하고 NofM ID9를 추가했다. `[Sound1] EPTC-SND1 필수성능시험 기준서_원본서식_rev0.docx`를 로컬 사운드1 폴더와 공유 드라이브 사운드1 산출물에 저장했다. 기존 rev0는 보존했다.

## 2026.09.15 원본 서식 유지 재작성

- 원본 SHA256은 BA66A59D35DD48B1995023C840E35292CB41F276814C6A06EF8A0118A7B49283으로 이전 참조본과 동일하다.
- 이전의 머리글 교체·표 재설계 방식은 이번 요청에 적용하지 않는다. 원본 패키지를 복제하여 문서/머리글/바닥글의 텍스트와 신규 ID9만 편집한다.
- 작업본: 프로젝트 `tmp/eptc-original-format/sound1-working.docx`. 생성기 `build.py`, 서식 계약 `artifact.md`, 부품 비교 `changes.json`을 같은 임시 폴더에 둔다.
- styles.xml/numbering.xml/관계/이미지 등은 바이트 동일, 섹션 XML 동일. 승인표의 이전 서명과 승인 날짜는 작업본에서 비우고 표 서식은 유지했다.
- 원본 본문 70 dBSPL ADC=828(69~71:738~930), 부록 멤브레인 열=586(523~658)의 불일치를 확인했다. 이를 임의로 통일하지 않고 실측 기준을 사용자에게 확인 요청했다.
- 이전 최대 실제 음압110 dBSPL은 APx 보정 표시101.707 dBSPL이나 원본은 표시120을 요구한다. 적용할 상한을 사용자에게 확인 요청했다.
- 코드의 TDC_MAP_TEST_NOFM_USAGE_TIME=0, 맵3 NofM/Positive First/14usec를 확인했다. 맵3에도 16번 T=C=1500이 적용되어, 신규 ID9는 고역 우세 채널17~31과 고정채널16의 집합으로 구성했다.
- 패키지 렌더는 번들 LibreOffice 부재로 실패했다. Word 렌더는 원본 패키지와 별도 HDPhoto 제거/이미지 최적화 사본 모두 정체되어 이번 작업에서 실행한 자동화 인스턴스를 종료했다. 최종 렌더 검증은 미완료다.
- 이후 은수님이 표시70은 실제70+@이더라도 본문에70으로 기재하고 표는29~120까지 표현하도록 확정했다. 공통 조건에 APx -8.293dB 보정 표시 기준을 한 번 명시하고, 시험별 음압은 원본 숫자를 유지했다.
- 원본의 본문 ADC와 부록 두 열을 그대로 승계했다. 부록의 좌측을 Sound1 기준 ADC, 우측을 Sound1 멤브레인 비교로 명명하고 본문 판정이 좌측을 사용함을 명시했다. 이는 새로운 실측 결과를 작성한 것이 아니다.
- Word 정체 원인은 이전 강제 종료 이력에 대한 재열기 확인 대화상자였다. 해당 작업 인스턴스의 확인창을 처리한 후 열기/렌더 성공. 새 파일명에서 경고 없이 재개방도 확인했다.
- 원본 패키지 보존 사본과 Word 목차 갱신 사본을 대조하고 TOC/페이지 필드 캐시만 이식했다. 최종 변경 부품은 document.xml/header1.xml/footer1.xml 세 개이며 styles/numbering/theme/그림/관계 등은 원본 바이트와 동일하다.
- 섹션 XML, 원본23개 표의 tblPr/tblGrid 동일, 부록92행29~120 숫자 전체 동일, 목차 ID9 반영, Word46쪽 렌더 확인. 최종 패키지 재렌더와 검토 이미지의46쪽 텍스트·래스터를 전수 비교해 동일함을 확인했다.
- 승인표의 이전 서명/승인 날짜는 공란으로 두고 문서 개정번호0을 적용했다. 새 승인 사실이나 실기 통과 결과는 기재하지 않았다.
- 로컬/공유 드라이브 산출물의 SHA256 동일성 확인. 상세 결과는 `tmp/eptc-original-format/final-qa.json`, `delivery.json`이다.
