233 ['2'] 소프트웨어 통합 
234 [] 각각의 MCU에서 구현된 소프트웨어를 통합을 진행한다. 
235 [] 각 MCU에서 소프트웨어의 검증을 위해서 대응되는 MCU의 소프트웨어가 필요한 경우에는 해당 기능을 수행하는 테스트 코드로 진행할 수 있다.
236 [] 모든 MCU의 소프트웨어가 통합되면 시스템이 완성되게 된다.

272 ['2'] NRF 코어 소프트웨어 통합
273 [] NRF의 소프트웨어 모듈은 system control Module과 Bluetooth communication Module로 설계되었으며, Bluetooth communication module의 구현작업이 system control module의 동작상태에서 진행되기 때문에 추가적인 통합과정은 없으며, Bluetooth communication module의 통합이 시스템의 통합으로 귀결된다.
