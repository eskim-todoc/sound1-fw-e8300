213 ['10'] 하드웨어 구조
214 [] 인공달팽이관 외부장치의 하드웨어 플랫폼은 그림 1. 과 같으며, Ezaro 7100내부에 4개의 MCU, 외부에 1개의 MCU 및 주변장치로 구성되어 있다. 5개의 MCU중 CFX가 주 MCU이며 CFX core가 저전력 모드로 진입하면 다른 MCU에 전원 공급이 중단되어 동작이 멈추게 된다.

220 ['10'] MCU간 제어 인터페이스
221 ['2'] System Control module
222 [] 각 MCU의 시스템 제어 모듈간 순차적인 제어 흐름은 다음과 같이 설계한다.
223 [] 
224 [] 각각의 MCU간 제어용 인터페이스는 다음과 같다.
225 [] NRF와 CM3 : GPIO핀을 사용
226 [] CM3와 CFX : 인터럽트, 공유 메모리, 시스템 라이브러리
227 [] CFX와 Hear : 시스템 라이브러리, 인터럽트
228 [] 
229 ['2'] Signal Processing Module
230 [] 신호처리 모듈은 CM3와 CFX에서 실행이 되며 MCU간 파라미터는 공유 메모리를 통해서 전달된다.
231 [] 시스템 제어 모듈에서 신호처리 모듈에 필요한 파라미터를 제공한다.
232 [] CM3에서 신호처리에 필요한 파라미터를 1차적으로 계산하고, CFX는 이를 사용하여 추가적인 파라미터를 계산한다. 계산이 완료된 파라미터를 사용하여 CFX와 Hear Core는 오디신호 처리를 실행하여 내부기에 전달되는 전기 자극 크기를 계산한다.
233 [] 
234 [] 
235 ['2'] Internal Stimulation Device Execution Module
236 [] 내부기 제어 모듈은 CM3와 CFX에서 실행이 되며 MCU간 파라미터는 공유 메모리를 통해서 전달된다.
237 [] CM3는 I2C를 사용하여 FPGA와 통신하고, 내부기 실해에 필요한 명령을 CFX에 공유메모리를 사용하여 전달한다. 
238 [] CFX는 공유 메모리에 설정된 내부기 실행 모드에 따라 PCM 비트스트림을 생성하여 FPGA와 내부기에 전달한다.
239 [] 내부기 실행 모드일 경우, 매핑 데이터와 신호처리 모듈의 결과인 전기 자극 크기를 사용하여 PCM 비트스트림을 생성하게 된다.
240 [] 
241 ['2'] Bluetooth Communication Module
242 [] 블루투스 통신 모듈은 NRF와 CM3에서 실행되며 MCU간 파라미터는 SPI를 통해서 전달된다.
243 [] 
244 [] 외부 블루투스 장치(ex. 스마트 폰)에서 BLE 통신으로 데이터를 보내면, NRF 블루투스 스텍이 이를 수신하여 NRF 블루투스 통신 모듈에 전달한다.
245 [] NRF 블루투스 통신 모듈은 데이터가 수신되면 SPI 통신을 사용하여 CM3에 데이터를 전달하고, 그 결과를 SPI를 통해서 수신하여 BLE 스텍에 전달한다. 
246 [] CM3 블루투스 통신 모듈은 NRF에서 수신된 데이터를 처리하고 그 결과를 SPI 버퍼에 준비해 둔다.
