145 ['2'] 개요
146 [] 본 문서는 인공달팽이관 외부장치 펌웨어를 개발하기 위한 소프트웨어 아키텍쳐를 설계하고 기술한다.

148 ['2'] 목적
149 [] 인공달팽이관 외부장치 소프트웨어의 요구사항을 포함한 소프트웨어 아키텍쳐를 설계함으로써, 소프트웨어 개발 절차에 따라 안전한하고 일관성 및 정확성을 보장하는 소프트웨어가 개발 되는 것을 목적으로 한다.

182 ['10'] 하드웨어 플랫폼

184 [] 인공달팽이관 시스템 전체의 하드웨어 플랫폼은 아래 <그림 1.>과 같으며, 소프트웨어는 Ezairo 7150 시스템에서 동작하게 된다.

191 [] 
192 ['10'] 소프트웨어 아키텍쳐
193 [] 2절의 하드웨어 플랫폼을 기반으로 동작하는 인공달팽이관장치 소프트웨어는 아키텍쳐는 <그림 2.>와 같이 설계되었으며,
194 [] 
195 [] 
196 [] 
197 [] <그림 2. 인공와우 소프트웨어 아키텍쳐 블록도>
198 [] 
199 [] 각 MCU 별로 소프트웨어가 개별적으로 실행되게된다. 따라서 각 MCU별로 아키텍처를 설계한다.
200 [] 
201 ['2'] CFX Core용 소프트웨어 아키텍쳐
202 ['3'] 시스템 제어 모듈
203 [] 하드웨어 설정, EEPROM 접근, 보조장치 제어 등과 관련된 유닛들로 구성되어 시스템의 전체 동작을 제어한다.
204 [] 소프트웨어 항목은 다음과 같다.
205 ['4'] 시스템 초기화 항목
206 [] CFX 코어 및 하드웨어를 초기화 한다.
207 ['4'] 시스템 제어 항목
208 [] 시스템의 전체적인 실행과 관련된 항목으로, 이 항목이 완성되면 소프트웨어 구현이 완료되게 된다.
209 ['3'] 신호처리 모듈
210 [] 사운드 신호를 전기자극 신호로 변환하기 위한 오디오 신호처리를 유닛들로 구성되어 있으며, 최종 적으로 시스템 제어 항목에서 호출 및 실행되게 된다.
211 [] 
212 ['3'] 내부 자극 장치 실행 모듈
213 [] 내부 자극 장치에 전달되는 bitstream 생성과 관련된 유닛들로 구성되어 있다.
214 ['4'] PCM 제어 항목
215 [] CM3에서 제어하는 PCM 출력 모드에 따라 내부기에 전달되는 PCM을 생성한다.
216 [] 
217 ['2'] Hear Core용 소프트웨어 아키텍쳐
218 [] Hear Core의 소프트웨어는 디지털 신호처리 라이브러리를 묶은 Function Chain으로 동작이 실행되게 되어있으며, Function Chain은 CFX 시스템 제어항목에서 호출하게 된다. 
219 [] 
220 ['2'] CM3용 소프트웨어 아키텍쳐
221 ['2'] 시스템 제어 모듈
222 [] 하드웨어 설정, 공유 메모리 접근, 보조장치 제어 등과 관련된 유닛들로 구성되어 시스템의 전체 동작을 제어한다.
223 [] 소프트웨어 항목은 다음과 같다.
224 ['4'] 시스템 초기화 항목
225 [] CM3 및 하드웨어를 초기화 한다.
226 ['4'] 시스템 제어 항목
227 [] 시스템의 전체적인 실행과 관련된 항목으로, 다른 모듈 및 유닛의 파라미터를 확인하여 시스템 동작을 제어한다. 이 항목이 완성되면 소프트웨어 구현이 완료되게 된다.
228 ['3'] 신호처리 모듈
229 [] CFX에서 공유한 매핑 데이터를 사용하여 C/T 전류크기를 C/T 자극 레벨로 변환하여 CFX에 공유하는 유닛으로 구성되어 있다.
230 [] 
231 ['3'] 내부 자극 장치 실행 모듈
232 [] 내부 자극장치 제어 및 자극 출력 실행과 관련된 유닛들로 구성되어 있다.
233 ['4'] 내부기 실행 제어 항목
234 [] 내부 자극 장치 실행과 관련된 보조장치 설정, 내부 자극 장치 설정 및 내부 자극 장치 연결 검사와 관련된 유닛을 실행하여 내부기를 제어한다.
235 [] 
236 ['3'] 블루투스 통신 모듈
237 [] 리모콘 앱, 매핑 프로그램 통신과 관련된 유닛들로 구성되어 있다.
238 ['4'] 블루투스 통신 제어 항목
239 [] NRF에서 SPI통신으로 수신된 명령에 따라 관련 유닛을 실행한다.
240 [] 
241 ['2'] NRF용 소프트웨어 아키텍쳐
242 ['2'] 시스템 제어 모듈
243 [] 하드웨어 설정, 보조장치 제어 등과 관련된 유닛들로 구성되어 시스템의 전체 동작을 제어한다.
244 [] 소프트웨어 항목은 다음과 같다.
245 ['4'] 시스템 초기화 항목
246 [] NRF 및 하드웨어를 초기화 하고 BLE 스택을 초기화한다.
247 ['4'] 시스템 제어 항목
248 [] 시스템의 전체적인 실행을 담당하는 항목으로, 블루투스 통신 제어 항목을 실행하고, CM3의 제어 파라미터를 확인하여 시스템 동작을 제어한다. 이 항목이 완성되면 소프트웨어 구현이 완료되게 된다.
249 ['3'] 블루투스 통신 모듈
250 [] 블루투스 장치로 데이터 수신을 처리하는 유닛들로 구성되어 있다.
251 ['4'] 블루투스 통신 제어 항목
252 [] 블루투스 장치에서 데이터 수신이 발생되면 CM3로 전송하고 CM3의 응답을 블루투스 장치로 전달하는 유닛들을 제어한다.
