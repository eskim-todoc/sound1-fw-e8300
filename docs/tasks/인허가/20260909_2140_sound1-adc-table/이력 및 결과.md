# Sound1 입력 음압 대비 ADC 출력 테이블 - 이력 및 결과

**TL;DR**: 1.5세대 테이블의 생성 규칙을 밝히고, Sound1 실측 감쇠를 반영해 29~120 dB SPL 92 행 표를 만들었다. 참조용 **PCB -3.644 dB**, 판정용 **기구 조립 -8.293 dB** 다. 판정 기준은 은수님 지적(±5 dB 허용, 조립 감쇠로 인한 탈락 우려)에 따라 **시험 대상인 기구 조립 실측의 중앙**으로 잡았다. 조립은 감쇠만 시키므로 위험이 아래로만 흩어지는 점을 반영해 여유를 아래에 두었다. 검증 9 항 + 교차 검증 8 구획 전건 통과.

### 2026-09-09 21:50 - 발견_2, 1.5세대 테이블의 생성 규칙

```
미적용    ADC = floor(262143 x 10^((dB SPL - 120) / 20))
멤브레인   미적용 열을 3 dB 옮긴 것.  멤브레인[d] = 미적용[d - 3]
```

멤브레인 규칙은 범위 안 89 개 전건 일치. 처음에 «3 dB 낮춘 값을 새로 계산» 으로
보고 `round` 를 썼는데, 검증이 32 건 불일치를 잡아냈다. `floor` 로 바꾸니 13 건까지
줄었고, 멤브레인은 계산이 아니라 **표를 3 칸 민 것**임이 드러났다.

### 2026-09-10 - 판정 기준 재조정 (-5.593 -> -7.500)

은수님이 **±5 dB 허용 오차** 라는 시험 조건을 알려 주면서 전제가 바뀌었다.
「조립에 따른 감쇠로 시험 통과가 불가한 경우가 있을 수 있다」.

처음 기준(-5.593, 정상군 3 평균)으로는 **500C-1차가 -5.84 로 탈락**한다.

네 번에 걸쳐 후보를 검토했다.

| 후보 | 상한 여유 | 하한 여유 | 판정 |
|---|---:|---:|---|
| 정상군 3 평균 -5.593 | +3.02 | **-0.84** | 하한 탈락 |
| 실측 기구 6 중앙 -8.293 | +0.27 | +1.86 | 통과하나 위가 아슬하다 |
| 500D·500C-1차 중간 -9.096 | **-0.53** | +2.66 | **상한 탈락** |
| **-7.500** | **+1.07** | **+1.07** | **채택** |

**핵심은 «조립은 감쇠만 시키고 증가는 안 시킨다»** 는 성질이다.
이 성질이 아래를 열어 주는 동시에 **위를 조여 온다.** 그래서 상한은 「조립 감쇠가
거의 없는 극단 = PCB 최고(-3.57)」, 하한은 「실측 최저(-11.43)」 이고, 폭 7.87 dB 가
허용 10 dB 안에 담긴다. 그 중앙이 -7.499 → **-7.500** 이다.

이 결정으로 **9/9 의 「이상 3 시료 제외」가 뒤집혔다.** 시험 판정 기준은 대표 성능이
아니라 실제로 나올 수 있는 범위를 담아야 한다. 11 시료를 전부 쓴다.
대신 **이 시험만으로는 조립 불량을 걸러내지 못한다**는 점을 문서에 명시했다.

### 2026-09-10 - 여유 배분 재조정 (-7.500 -> -8.293)

은수님이 다시 짚으셨다. **「실측된 결과에 따르면 위보다는 아래쪽으로 여유를 더 두는 게
좋지 않냐」.** 맞는 지적이었다.

-7.500 은 **상한을 「조립 감쇠 0 인 극단 = PCB 최고 -3.57」 로 잡은** 결과였다.
그래서 「대칭」 으로 보였지만, **시험 대상인 기구 조립 실측**을 기준으로 다시 재면
이렇게 된다.

| 기준 | 실측 상한 여유 | 실측 하한 여유 |
|---|---:|---:|
| -7.500 | **+2.65** | **+1.07** |

**위가 2.5 배 여유롭다.** 일어나지 않는 쪽에 여유를 몰아 준 셈이다.

근거는 실측에 있다. 기구 자체 감쇠(그룹 감쇠 - PCB 평균)를 보면 **아래로는 7.79 dB
까지 벌어지는데 위로는 1.51 dB 에서 멈춘다.**

| 시료 | 500E | 500F | 500A | 500D | 500C-2차 | 500C-1차 |
|---|---:|---:|---:|---:|---:|---:|
| 기구분 감쇠 | 1.51 | 2.01 | 2.33 | 3.11 | 3.83 | **7.79** |

상한을 실측 최고(500E -5.15)로 옮겼다. 하한은 그대로 실측 최저(-11.43).

| 후보 | 실측 상한 | 실측 하한 | 조립 감쇠 0 인 극단 | 판정 |
|---|---:|---:|---:|---|
| -7.500 | +2.65 | +1.07 | +1.07 | 아래가 빠듯 |
| **-8.293** | **+1.86** | **+1.86** | **+0.27** | **채택** |
| -8.500 | +1.65 | +2.07 | +0.07 | 안전망 상실 |
| -9.000 | +1.15 | +2.57 | **-0.43** | 극단 탈락 |

**아래 여유 1.07 → 1.86 dB.** 통과 하한도 -12.50 → **-13.29 dB** 로 내려갔다.
그러면서 조립 감쇠가 0 인 물리적 극단도 **+0.27 로 여전히 담는다.**

-8.500 은 아래를 0.21 더 얻는 대가로 그 안전망을 거의 잃어(+0.27 → +0.07) 택하지 않았다.

교차 검증기에 **「아래 여유가 위 여유보다 좁지 않은가」** 검사를 새로 넣었다.
이 판단이 다시 뒤집히면 검증기가 잡는다.

### 2026-09-10 - 원본 측정 기록에 산출 기준 기입

은수님 지시로 공유 드라이브 원본
(`Sound1 필수성능시험 준비 시료별 측정 기록.xlsx`)의 「Sound1 시료 측정 데이터」
시트 **AD·AE 열**에 산출 결과를 기존 시료와 같은 형식으로 넣었다.

| 자리 | 내용 |
|---|---|
| AD3:AE3 (병합) | `Sound1 산출 기준` |
| AD4 / AE4 | `PCB 상태` / `기구 조립` |
| AD5:AE18 | 45~110 dB SPL 14 행 |

**두 가지를 원본 규칙에 맞췄다.**

1. **한 행 아래 정렬.** 원본은 음압이 `B4:B17`, 측정값이 `r5:r18` 이다(발견_1).
   차트 계열도 `x=$B$4:$B$17, y=$?$5:$?$18` 로 짜여 있어 작성자도 이 밀림을
   알고 맞춰 둔 것이다. **새 열도 r5 부터 넣어야 기존 차트와 어긋나지 않는다.**
2. **서식은 기존 시료 열(AB:AC)에서 복사**해 붙였다.

차트에도 계열을 하나씩 더했다. 기존 계열이 「평균」 열만 쓰므로 같은 방식이다.

| 차트 | 기존 계열 | 추가 |
|---|---|---|
| Chart 1 (PCB) | 501C·501D·501E·501F·5020 | `Sound1 산출 기준 (PCB 상태)` ← AD |
| Chart 2 (기구) | 500C-1차·500D·500C-2차 | `Sound1 산출 기준 (기구 조립)` ← AE |

기준선임이 드러나도록 **검은 파선 + 표식 없음**으로 그렸다.

> [!NOTE]
> **Chart 2 에는 500A·500E·500F 가 없다.** 원본 차트 XML 의 계열 색인이 1·2·6 으로
> 띄엄띄엄한 것으로 보아 지워진 흔적이다. 이 작업에서는 **손대지 않았다.**
> 감쇠가 큰 세 시료만 비교하려던 의도일 수 있어 은수님 확인이 필요하다.

**도구 선택.** openpyxl 은 차트를 보존하지 못해 **Excel COM** 을 썼다.

**막힌 곳 둘.**

| 증상 | 원인 | 조치 |
|---|---|---|
| `CutCopyMode = 0` 대입 실패 | PowerShell 강타입 COM 래퍼가 열거형 변환을 거부 | 그 줄을 없앴다. 다음 작업에서 자동 해제된다 |
| **계열 이름이 `$B$4:$B$17` 로 들어감** | `Name` 을 먼저 주고 `XValues` 를 나중에 주면 Excel 이 이름을 다시 추론해 **덮어쓴다** | **값 -> 이름 순서**로 바꿨다 |

두 번째는 검증기가 잡았다. 처음 검증에는 **계열 «이름» 검사가 없어** 계열 수만 보고
통과로 넘겼다. 검사를 보태고서야 드러났다. **셌지만 읽지는 않았던 것이다.**

원본을 덮어쓰기 전에 해시로 무변경을 확인했고, 수정 전/후 사본을 저장소에 남겼다.

### 2026-09-10 - 차트에 ±5 dB 허용 범위 + 머리 설명문 오류 정정

은수님이 산출 테이블을 원본 첫 시트에 통째로 복사해 넣으신 뒤,
**차트에서 ±5 dB 범위를 바로 볼 수 있게** 해 달라고 하셨다.

**먼저 오류 하나가 드러났다.** 복사된 시트의 머리 설명문(B4)이 옛 기준 시절
문구였다. 기준을 두 번 바꾸면서 **표 «값» 만 다시 만들고 설명문은 두었다.**

| 적혀 있던 것 | 실제 |
|---|---|
| `ADC = round(...)` | **floor**. 스크립트 주석에는 「1.5세대 표는 내림이다」 라고 적어 두고도 머리엔 round 라 썼다 |
| 기구 조립 `(3 시료)` | **6 시료**의 상·하한 중앙 |
| 「실측 **평균**이다」 | PCB 만 평균, 기구는 **중앙** |

`verify_all.py` 는 표 **값**만 대조하고 **설명문은 읽지 않았다.** 차트 계열 이름 때와
같은 구멍이다 - **세었지만 읽지 않았다.** 설명문 검사 6 항을 새로 넣었다.

**범위 표시 방법.** 오차 막대(Error Bars)와 상·하한 계열 중 후자를 골랐다.

- 로그 축이라 상·하한이 기준선과 **평행한 띠**로 보여 범위를 훑기 쉽다
- **값이 셀에 남아** 시험 기록지에서 바로 참조할 수 있다
- 오차 막대는 점마다 끊긴 세로선이라 「범위」로 읽히지 않는다

| 자리 | 내용 |
|---|---|
| AF3:AG3 / AF4·AG4 | `허용 범위 (PCB 상태)` / `+5 dB`·`-5 dB` |
| AH3:AI3 / AH4·AI4 | `허용 범위 (기구 조립)` / `+5 dB`·`-5 dB` |
| 차트 계열 4 개 | `허용 상한 (+5 dB)` · `허용 하한 (-5 dB)`, 회색 얇은 점선 |

**덤으로 알게 된 것.** 음압 격자가 5 dB 간격이라 **±5 dB 허용 폭이 정확히 이웃 행**이다.
80 dB SPL 의 허용 범위 567~1794 는 곧 **75 dB 칸과 85 dB 칸**이다. 계산할 필요가 없다.
산출 근거 §3.2 와 표 머리 설명문에 적었다.

**막힌 곳 둘.**

| 증상 | 원인 | 조치 |
|---|---|---|
| `Cells.Item($r, 32).Value2 = <int>` 캐스팅 실패 | PowerShell 이 COM 인덱서 오버로드를 잘못 골랐다 | `Range("AF$r")` 문자열 주소로 바꿨다 |
| 서식 붙여넣기가 **병합까지 딸려 왔다** | `PasteSpecial(-4122)` 는 병합도 서식으로 본다 | `UnMerge()` 후 다시 병합 |

앞서 겪은 heredoc 백슬래시 문제도 여기서 재발했다. **PowerShell 스크립트를 만들 때
백슬래시를 아예 쓰지 않도록** 경로를 `/` 로, 정규식을 `-like` 패턴으로 바꿨다.
