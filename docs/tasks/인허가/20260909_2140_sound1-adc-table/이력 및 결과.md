# Sound1 입력 음압 대비 ADC 출력 테이블 - 이력 및 결과

**TL;DR**: 1.5세대 테이블의 생성 규칙을 밝히고, Sound1 실측 감쇠(**PCB -3.644 dB · 기구 -5.593 dB**)를 반영해 29~120 dB SPL 92 행 표를 만들었다. 조립 이상이 의심되는 3 시료는 기준에서 뺐다. 검증 9 항 + 교차 검증 8 항 전건 통과.

### 2026-09-09 21:40 - 발견_1, 원본 시트의 행 정렬

측정값이 헤더보다 **한 행 아래**에 있었다. 그대로 읽으면 45 dB SPL 측정이
통째로 빠지고 마지막 행 데이터가 음압 없이 뜬다.

처음에는 수치(감쇠 편차)로 두 가설을 가리려 했으나 **두 가설의 변화폭이 비슷해
갈리지 않았다.** 구조로 판정을 바꿨다.

| 근거 | 값 |
|---|---|
| 음압 값 14 개 ↔ 측정 행 14 개 | 일치 |
| 4 행 측정값 | 없다 (부제 행) |
| 18 행 측정값 / 음압 값 | 있다 / 없다 |

`analyze.py` 가 매 실행마다 이 구조를 확인한다.

### 2026-09-09 21:50 - 발견_2, 1.5세대 테이블의 생성 규칙

```
미적용    ADC = floor(262143 x 10^((dB SPL - 120) / 20))
멤브레인   미적용 열을 3 dB 옮긴 것.  멤브레인[d] = 미적용[d - 3]
```

멤브레인 규칙은 범위 안 89 개 전건 일치. 처음에 «3 dB 낮춘 값을 새로 계산» 으로
보고 `round` 를 썼는데, 검증이 32 건 불일치를 잡아냈다. `floor` 로 바꾸니 13 건까지
줄었고, 멤브레인은 계산이 아니라 **표를 3 칸 민 것**임이 드러났다.

### 2026-09-09 21:55 - 발견_3, 원본 88 dB SPL 이상치

| 음압 | 원본 | 모델 | 차 |
|---:|---:|---:|---:|
| 88 | 6564 | 6584.7 | **-20** |

나머지 12 건은 ±1 의 부동소수점 차이인데 이 한 건만 크다. 6584 를 6564 로 적은
입력 오류로 보인다. **범위 밖이라 고치지 않고 기록만 남겼다.**

이 발견 때문에 방침을 바꿨다. 참조용 1.5세대 두 열은 **재계산하지 않고 원본을
그대로 싣는다.** 재계산하면 원본과 어긋나고 이상치도 조용히 사라진다.

### 2026-09-09 22:00 - 발견_4·5, 중복 기재와 시료별 감쇠

500A 가 16 열과 26 열에 두 번 있고 **값이 완전히 같다.** 중복으로 보아 한 번만 셈했다.

| 그룹 | 감쇠 범위 | 판정 |
|---|---|---|
| PCB 5 시료 | -3.57 ~ -3.75 (범위 0.18) | 매우 고르다 |
| 기구 정상 3 시료 | -5.15 ~ -5.97 (범위 0.82) | 채택 |
| 기구 이상 3 시료 | -6.76 / -7.48 / -11.43 | 제외 |

**같은 500C 가 1차 -11.43 에서 2차 -7.48 로 4 dB 달라진 것**이 조립 편차의 가장
분명한 증거다.

### 2026-09-09 22:20 - 교차 검증에서 정밀도 문제를 잡음

`make_table.py` 의 자체 검증은 통과했으나, 독립으로 만든 `verify_all.py` 가
**문서에 적은 -3.644 로 다시 계산하면 표와 ±1 씩 어긋나는 자리가 19 건** 있음을
잡아냈다. 생성기가 실측 평균의 전체 자리(-3.6443...)를 쓰고 있었기 때문이다.

**감쇠를 소수 3 자리로 확정했다.** 문서만 보고도 같은 표가 나와야 한다.
측정 평균이라 3 자리면 충분하고, 전체 자리를 쓰는 것이 오히려 과잉 정밀이다.

### 2026-09-09 22:30 - 검증 완료
