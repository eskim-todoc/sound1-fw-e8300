# Sound1 입력 음압 대비 ADC 출력 테이블 - 요구사항

**TL;DR**: 1.5세대와 Sound1 은 **같은 스펙의 마이크**를 쓴다. 그래서 1.5세대 테이블의 생성 규칙을 그대로 두고 **Sound1 의 실측 감쇠만 반영**해 테이블을 만든다. 감쇠는 고음압 평탄 구간에서 구했고, **PCB 상태 -3.644 dB · 기구 조립 -5.593 dB** 다. 조립 이상이 의심되는 3 시료는 기준 산출에서 뺐다.

## 1. 배경

원본: `G:\공유 드라이브\20_프로젝트별\01_project sound1\99_공유\인허가 관련\Sound1 필수성능시험 준비 시료별 측정 기록.xlsx`
(재현을 위해 `스크립트/측정원본.xlsx` 로 복사해 두었다)

| 시트 | 내용 |
|---|---|
| 1.5세대 입력 음압 대비 ADC 출력 테이블 | 29~120 dB SPL, 멤브레인 미적용 / 고려 두 열 |
| Sound1 시료 측정 데이터 | 12 열(시료 11 + 중복 1), 45~110 dB SPL, 최대/평균 |

Sound1 시료는 두 그룹이다.

- **PCB 상태** (5) : 501C, 501D, 501E, 501F, 5020 — 기판만 놓고 측정
- **기구 조립 상태** (6) : 500A, 500C-1차, 500C-2차, 500D, 500E, 500F — 패키징된 상태

기구가 음압을 감쇠시키는 상황이고, 그중 **500C-1차·500C-2차·500D 가 다른 기기보다 대체로 낮다**는 것이 은수님 관찰이다.

## 2. 실측으로 확인한 것

### 발견_1 - 원본 시트의 행 정렬

측정값이 **헤더보다 한 행 아래**에 있다. 그대로 읽으면 45 dB SPL 측정이 통째로 빠지고 마지막 행 데이터가 음압 없이 뜬다.

| 근거 | 값 |
|---|---|
| 음압 값 개수 (4~17 행) | 14 (45~110) |
| 측정값이 있는 행 개수 (5~18 행) | 14 |
| 4 행에 측정값 | **없다** (「최대/평균」 부제만 있다) |
| 18 행에 측정값 | **있다** |
| 18 행에 음압 값 | **없다** |

한 행 아래로 읽어야만 앞뒤가 맞는다. `analyze.py` 가 매번 이 구조를 확인하고, 깨지면 경고를 낸다.

### 발견_2 - 1.5세대 테이블의 생성 규칙

```
미적용    ADC = floor(262143 x 10^((dB SPL - 120) / 20))      262143 = 2^18 - 1
멤브레인   미적용 열을 3 dB 옮긴 것.  멤브레인[d] = 미적용[d - 3]
          표 범위 밖인 29~31 dB 는 최소값 7 로 채워져 있다
```

멤브레인 규칙은 **범위 안 89 개 전건이 어긋남 0** 이다. 반올림은 내림이다 (`round` 는 32 건, `floor` 는 13 건 어긋난다).

### 발견_3 - 원본 88 dB SPL 값의 이상

| 음압 | 원본 | 모델 | 차 |
|---:|---:|---:|---:|
| 88 | **6564** | 6584.7 | **-20** |

나머지 12 건의 어긋남은 모두 ±1 의 부동소수점 차이인데 이 한 건만 크게 튄다. **6584 → 6564 로 자리가 바뀐 입력 오류로 보인다.** 다만 이 작업 범위 밖이라 고치지 않고, 참조 열에는 원본을 그대로 실었다.

### 발견_4 - 500A 중복 기재

16 열과 26 열이 모두 「500A」 이고 **값이 완전히 같다**. 중복 기재로 보아 한 번만 셈했다.

### 발견_5 - 시료별 감쇠

1.5세대(멤브레인 미적용) 대비, 고음압 평탄 구간(80~110 dB SPL) 평균이다.

| 그룹 | 시료 | 감쇠 | 구간 편차 |
|---|---|---:|---:|
| **PCB** | 501C | -3.63 | 0.32 |
| PCB | 501D | -3.68 | 0.49 |
| PCB | 501E | -3.75 | 0.31 |
| PCB | 501F | -3.57 | 0.43 |
| PCB | 5020 | -3.60 | 0.65 |
| **기구** | 500E | -5.15 | 0.20 |
| 기구 | 500F | -5.65 | 0.33 |
| 기구 | 500A | -5.97 | 0.57 |
| 기구 | 500D | **-6.76** | 0.45 |
| 기구 | 500C-2차 | **-7.48** | 0.66 |
| 기구 | 500C-1차 | **-11.43** | 0.37 |

**PCB 5 시료는 -3.57 ~ -3.75 dB 로 매우 고르다** (범위 0.18 dB). 기준으로 삼기에 충분하다.

기구 조립은 셋으로 갈린다. 은수님 관찰대로 500C-1차·500C-2차·500D 가 낮다. **같은 500C 가 1차 -11.43 에서 2차 -7.48 로 4 dB 나 달라진 것**은 시료 자체가 아니라 **조립 편차**를 가리킨다.

## 3. 인터뷰 기록

### 질문_1 - 테이블 기준

**답변: 두 열 모두.** 1.5세대가 「미적용 / 멤브레인 고려」 두 열을 둔 것처럼 Sound1 도 「PCB 상태 / 기구 조립 상태」 두 열을 둔다. 시험 조건에 따라 골라 쓸 수 있고 기구 감쇠량도 드러난다.

### 질문_2 - 이상 시료 처리

**답변: 제외하고 기록은 남긴다.** 정상군 3 개(500A·500E·500F)로 기준을 잡고, 제외한 이유와 수치를 문서에 남긴다.

### 질문_3 - 저음압 구간

**답변: 고음압 기준으로 일괄.** 45~60 dB SPL 은 잡음 바닥 탓에 감쇠가 흔들린다. 실측값을 그대로 쓰면 오히려 틀린다. 전 구간에 하나의 dB 차를 적용하고 편차는 문서에 기록한다.

## 4. 요구사항

| 라벨 | 내용 | 수용 기준 |
|---|---|---|
| **요구사항_1** | 1.5세대 테이블의 생성 규칙을 밝히고 그대로 따른다 | 규칙을 수식으로 적고, 원본과 대조해 어긋남 0 |
| **요구사항_2** | Sound1 감쇠는 **실측**에서만 구한다 | 시료별 수치와 산출 구간이 문서에 있다 |
| **요구사항_3** | 참조용 1.5세대 두 열은 **원본을 그대로** 싣는다 | 재계산하지 않는다. 원본과 어긋남 0 |
| **요구사항_4** | 제외한 시료와 이유를 남긴다 | 3 시료의 수치와 판단 근거가 문서에 있다 |
