# Sound1 음압 기준과 32채널 예상 전류표

## 목표와 범위

- 1.5세대의 음압 설정·전압 측정 방식을 유지하며 Sound1 ADC 환산값을 기준서에 명시한다.
- 7개 주파수(3815, 100, 114, 128, 2869, 3038, 3217 Hz), 6개 음압 범위(74~76, 69~71, 119~120, 34~36, 40~42, 98~110 dB SPL), 오디오 볼륨 1/10 선택에 따라 32전극 결과가 갱신되는 Excel을 만든다.
- 프로그램 1, 자극 볼륨 4, 50 us, 기본 맵(전극16 T=C=1500 uA)을 사용한다. 119~120은 110 dB SPL 제품 사양 밖 비교 조건으로 표시한다.
- 음압 범위에 따른 예상 출력 변동과 시험 허용오차를 구분한다. 실측 합격 이력을 생성하지 않는다.

## 근거와 계획

기존 ADC 모델은 완제품 감쇠 -8.293 dB이다. ci_map.c, stimulationParaCal.c, agc.c, FrequencyAnalysis.c, nonlinearMapping.c와 512점 Hann/pass-bin을 대조한다. 기존 단일 대역 계산을 32대역 FFT와 16표본 AGC 블록으로 확장한다. DSP 수학 라이브러리와 HEAR 내부 연산은 이상 수학 모델로 근사하며, 명목 계산의 한계로 명시한다.

1. 입력 조건별 신호를 16 kHz로 생성하고 정수 AGC·512 FFT로 대역 대표값을 계산한다.
2. Excel에서 조건 선택, T/C 매핑, PCM Amplitude, 전류를 연결한다.
3. 기준서의 ID-6/7 조건 및 ADC 설정 문구를 갱신하고 원본을 보관한다.
4. 수식 교차검증, 모든 선택 조합, 문서/시트 렌더링을 검토한다.

## 상태

작성 및 계산 검증 완료. 기존 기준서의 ID-7 주파수가 FFT 중심으로 바뀌고 전류는 1.5세대 값으로 남아 있었다. 요청 주파수를 복원하고 Sound1 ADC·전류 예상값으로 갱신했다. 실기 전류 허용차의 확정은 별도다.

## 산출물과 검증

- `docs/참고/인허가/사운드1/Sound1 ID-6 ID-7 32채널 예상 전류표.xlsx`: 4개 시트, B4/B5/B6 선택으로 32전극의 PCM 및 전류 하/중/상 표시. 프로그램 1, 자극 볼륨 4 고정.
- 같은 폴더의 `[Sound1] EPTC-SND1 필수성능시험 기준서_rev0.docx`: ID-6/7 입력 ADC와 전류 예상표, 추가 음압 구간, 전극16 예외, 실제 측정 방법 유지. 35쪽·28표·그림18개. 119~120은 사양 밖 비교로 분리하고 기존 109~110 상한 시험을 보존했다.
- Excel 84조건 × 32전극 × 3전류 = 8,064개를 호스트 모델과 대조하여 일치했다. 내보내기 후 재열기·재계산에서도 기본 조건이 일치했고 수식 오류는 0건이다. Excel 데스크톱 직접 조작 시험은 수행하지 않았다.
- Excel 4개 시트 렌더링 확인. Word는 번들 LibreOffice 부재로 Word PDF 출력·Poppler PNG 대체 검증을 수행했다. 35쪽 전체 검토 후 서식 수정된 4쪽을 재검토했고, 다른 31쪽 PNG는 해시가 동일했다. 표 잘림·누락 없음.
- Word 자동 재페이지화 경로가 정지하여 이 작업에서 시작한 Word 프로세스만 종료하고 읽기 전용 PDF 출력 경로로 검증했다. 사용자 Word 프로세스는 종료하지 않았다.
- 검증 중 음압 문자열의 `~`와 MATCH 처리 차이를 발견하여 음압 하한을 숫자로 추출한 뒤 조회하도록 수정했다. 최종 84조건 검증은 수정 후 수행했다.

## 계산 해석과 남은 판단

16 kHz 위상 0 정현파를 믹서 출력 ADC 진폭으로 가정했다. 2초 안정화 뒤 1초간 1 ms 간격의 512표본 창 1,000개를 계산하고, 각 범위의 1 dB 격자와 중간 음압을 합쳐 최소·최대를 구했다. 중간값은 중간 음압의 시간 중앙값이다. HEAR FFT와 DSP log/power는 이상 함수 근사이므로 비트 정확 모델이나 모든 연속 음압·위상의 보증 범위가 아니다. 빔포밍·기구 주파수 응답·잡음·물리 DAC 오차는 포함하지 않았다.

전류는 CM3/CFX 코드 환산값 `497 + floor(19333 × PCM / 4096)`이다. 전극16은 기본 맵 T=C=1500이므로 PCM211, 환산1492 uA로 고정된다. 범위가 넓어졌다는 이유로 실기 허용차를 임의 생성하지 않았으며, 기준서의 ID-6/7 전류 판정은 승인된 허용차 적용 전까지 확정하지 않는 것으로 구분했다.

생성 코드 원본은 이 작업의 `스크립트/`, 모델 중간값 및 검증 로그는 `검증/`에 보존한다. 저장소 루트에서 `simulate.py`를 실행한 후 `build.mjs`를 실행하며, Node의 `@oai/artifact-tool` 의존성 연결이 필요하다. Word 편집기는 최초 312단락 원본만을 받도록 보호했고 이번 원본 백업은 `tmp/sound1-32ch/standard-before.docx`에 남겼다.

기존 자극 파라미터 계산 Excel은 변경하지 않았다. 펌웨어 소스 변경, 커밋·병합·푸시, 공유 드라이브 동기화는 수행하지 않았다.
