# Sound1 소프트웨어 아키텍쳐 기술서 - 이력 및 결과

**TL;DR**: 1.5세대 `SAD-FW-TD20B` 를 승계해 Sound1 판 소프트웨어 아키텍쳐 기술서를 Word 로 작성한다. 범위는 CFX·HEAR·CM3 + 부트로더/OTA 이고, **QCC5181 은 구조적으로만 포함**한다. 착탈 구조(QCC 는 추가 가능·부트로더는 제거 가능)가 설계의 핵심이다.

## 시계열 로그

### 2026-09-09

- **11:29 착수**: 은수님 지시 - *"docs/참고/인허가/1.5세대 폴더의 1.5세대 기반 소프트웨어 밸리데이션 문서를 기반으로 사운드1 폴더에 사운드1의 소프트웨어 밸리데이션 문서를 작성해야해. 우선 주의사항 문서를 읽고, 소프트웨어 아키텍처 문서를 어떻게 하면 좋을지 분석 및 구현을 해보자. 결과는 워드문서로 해야해."*
  - 부수 지시: *"내용이 중요하며, ID 같은 번호는 향후에 모든 내용이 확정되면 일괄 업데이트할 수도 있어."*
  - 브랜치 `claude_feature_sound1-sad` 생성.
- **주의사항 (필독) 문서 확인**: 1.5세대 -> Sound1 변경 5건(QCC 교체·터치 센서·배터리 주체 이동·충전기 상태 SPI·이어피스/USB 제거). 은수님이 *"이 외에 추가된 기능이나 제거된 기능도 있긴 할 건데... 직접 분석할 필요도 있어"* 라고 하셔서 **소스 조사로 보강**.
- **1.5세대 SAD 해부**: 단락 126·표 6·그림 4. 골격은 «1 서론 / 2 하드웨어 플랫폼 / 3 소프트웨어 아키쳐(코어별) / 4 요구사항 추적성(RID 68항) / 5 아키텍쳐 검증».
  - **원본 결함 2건 발견**: (가) *"Ezairo 7150 시스템에서 동작"* 이라는 세대 어긋난 문장(P043), (나) CM3·NRF 하위 «시스템 제어 모듈»의 Heading 레벨 오류(P080·P101). **승계하지 않기로 결정.**
- **소스 델타 보강 5건**: 크래들 뚜껑 상태 수신(`ble_communication.c:128`) · 2-DMIC 빔포밍 · I2S 브리지 · 부트로더/OTA · NofM 자극 기법. 모두 1.5세대 SAD 에 **대응 절이 없다**.
  - **이어피스는 «제거» 사양이나 소스에 검출 코드 잔존**(`shared_memory.h:200` 등). 문서는 사양 기준으로 쓰고 잔존 코드 정리는 후속 과제로 분리.
- **인터뷰 (질문_1~3)**: 은수님 답변으로 문서 구조 확정.
  - 범위: CFX·HEAR·CM3 + 부트로더/OTA. 캘리브레이션 제외.
  - **QCC5181 은 «구조적으로 포함», 펌웨어 내용은 향후 추가 가능한 자리로.** 부트로더/OTA 는 **향후 제거 가능한 구성으로.**
  - 추적성 표: 68항 승계 + 변경 표기. 블록도: PNG 신규 작성.
- **설계 결정**: 착탈 요구를 **«4절 프로세서 간 인터페이스» 신설**로 푼다. QCC 내부를 못 쓰는 상태에서도 문서가 완결되려면 «경계에서 오가는 것»을 별도 절로 분리해야 한다.
- **추적성 판정 완료**: 유지 54 · 변경 10 · 삭제 1(RID-66 이어피스) · **확인 필요 3(RID-49·50·54)** · 신규 제안 8(RID-69~76).
- **산출**: `요구사항.md` · `계획.md` · 본 문서.

- **구현 (Step 1~10)**:
  - **Step 1** 블록도 2점을 PIL 로 생성. 직교 라우팅으로 2회 재작업(첫 판은 화살표가 코어 상자에 붙어 «마이크 -> HEAR» 처럼 잘못 읽혔고, 블루투스 선이 송신 코일 위를 지났다).
  - **Step 2~9** `python-docx` 로 문서 생성. 6개 절 + 표 11개 + 그림 2점.
  - **Step 10** 자체 검증 7항 수행 - `스크립트/verify_sad.py`.
- **구현 중 발견한 결함 2건 (수정 완료)**:
  - `python-docx` 기본 용지가 **Letter(21.59 cm)** 였다. A4 로 명시하지 않으면 본문 폭이 17.59 cm 가 되어 1.5세대 서식과 어긋난다. `page_width/page_height` 를 A4 로 고정.
