[51 P TDC10] 인공달팽이관 외부장치 Sound1은 E8300의 CFX, HEAR, Cortex-M3와 외부 QCC5181 및 주변장치로 구성된다. 부트로더가 하드웨어와 실행 이미지를 준비하고 각 코어를 기동한다.
[52 P TDC14] 
[53 P TDC15] <그림 1. 인공달팽이관 외부장치의 하드웨어 플랫폼>
[54 P ] 
[55 P TDC1] 		MCU간 제어 인터페이스
[56 P TDC10] 외부장치의 동작은 시스템 제어, 신호처리, 내부기 실행, 블루투스 통신의 네 기능 모듈로 나누어 설계한다. 하나의 기능을 여러 코어가 나누어 수행하므로, 이 장에서는 각 모듈의 담당 범위와 코어 사이에 전달할 데이터, 실행 순서를 설명한다.
[57 P TDC10] 각 모듈은 아래의 역할을 수행하는 유닛으로 나누어 구현한다. 뒤의 상세 설계에서는 CFX, HEAR, CM3별로 담당 모듈과 유닛을 정의하고 입력, 출력, 처리 방법을 설명한다. 부트로더는 응용 프로그램을 시작하기 전의 별도 단계로 다룬다. QCC는 E8300과의 연결을 설명하고 내부 상세 설계는 별도 자료를 반영한다.
[58 P TDC2] 		System Control module
[59 P TDC20] 각 MCU의 시스템 제어 모듈간 순차적인 제어 흐름은 다음과 같이 설계한다.
[60 P ] 
[61 P TDC24] 
[62 P TDC25] <그림 2. 시스템 제어 연계>
[63 P TDC20] 각각의 MCU간 제어용 인터페이스는 다음과 같다.
[64 P TDC20] QCC와 CM3 : SPI 통신 및 GPIO 제어 핀. QCC와 CFX : I2S 오디오 입력.
[65 P TDC20] CM3와 CFX : 인터럽트, 공유 메모리, 시스템 라이브러리
[66 P TDC20] CFX와 Hear : 시스템 라이브러리, 인터럽트
[67 P TDC20] 시스템 제어는 전원과 연결 상태에 따라 실행할 기능을 정하고 각 코어가 필요한 시점에 동작하도록 한다. 따라서 CM3에는 전원/절전 상태, 터치 입력, LED 표시, 설정 저장과 주변장치 통신을 담당하는 유닛이 필요하다. CFX에는 인터럽트와 반복 실행, 입력 버퍼 준비, 맵/볼륨 변경 반영을 담당하는 유닛이 필요하다.
[68 P TDC20] 설정값을 전달하는 일과 그 설정으로 처리를 시작하는 일을 구분한다. CM3가 공유 메모리에 설정한 값은 CFX가 반영하고, FIFO와 HEAR의 완료 이벤트를 확인한 뒤 다음 처리를 진행하도록 한다. 아직 준비되지 않은 입력이나 계산 결과를 사용하지 않도록 상태 확인과 완료 처리를 둔다.
[69 P ] 
[70 P TDC2] 		Signal Processing Module
[71 P TDC20] 신호처리 모듈은 CM3, CFX와 HEAR에서 역할을 나누어 실행하며 코어 간 파라미터는 공유 메모리로 전달한다.
[72 P TDC20] 시스템 제어 모듈에서 신호처리 모듈에 필요한 파라미터를 제공한다.
[73 P TDC20] CM3는 맵의 T/C 전류와 펄스폭으로 내부기 파라미터를 계산한다. CFX는 전달된 디지털 T/C와 오디오 설정으로 매핑 계수를 계산하고, HEAR의 벡터/주파수 분석 결과로 자극 크기를 만든다.
[74 P TDC20] 입력 소리가 전극별 자극 크기로 바뀌기까지의 단계를 나누어 구현한다. CFX에는 마이크/I2S 입력 선택과 혼합, 두 마이크 빔포밍, AGC, 주파수 대역 대표값 계산, T/C 범위 매핑과 CIS/NofM 처리를 담당하는 유닛을 둔다. HEAR에는 절대값/최대값과 FFT/크기를 계산하는 처리 단위를 둔다.
[75 P TDC20] CM3에는 펄스폭에 따른 프레임 수와 전송 가능한 채널 수, 내부기 DAC 범위와 디지털 T/C를 계산하여 공유하는 유닛을 둔다. 이 설정과 CFX/HEAR의 오디오 계산 결과를 구분해야 맵이 바뀌었을 때도 같은 조건으로 전극별 자극 크기를 만들 수 있다.

[79 P TDC25] <그림 3. 신호처리 연계>
[80 P TDC2] 		Internal Stimulation Device Execution Module
[81 P TDC20] 내부기 제어 모듈은 CM3와 CFX에서 실행이 되며 MCU간 파라미터는 공유 메모리를 통해서 전달된다.
[82 P TDC20] CM3는 I2C를 사용하여 FPGA와 통신하고, 내부기 실행에 필요한 명령을 공유 메모리로 CFX에 전달한다.
[83 P TDC20] CFX는 공유 메모리에 설정된 내부기 실행 모드에 따라 PCM 비트스트림을 생성하여 FPGA와 내부기에 전달한다.
[84 P TDC20] 내부기 실행 모드일 경우, 매핑 데이터와 신호처리 모듈의 결과인 전기 자극 크기를 사용하여 PCM 비트스트림을 생성하게 된다.
[85 P TDC20] 내부기 실행은 연결 준비와 상태 확인, 자극 데이터 전송으로 나누어 구현한다. CM3에는 FPGA 통신, 내부기 전원/연결 상태 관리, 명령 요청과 완료 확인을 담당하는 유닛을 둔다. CFX에는 실행 모드 선택과 PCM 명령 구성, 실시간 자극 패킷과 프레임 출력을 담당하는 유닛을 둔다.
[86 P TDC20] 신호처리에서 구한 자극 크기만으로 출력하지 않고, 현재 실행 모드와 맵의 채널/프레임 조건을 함께 사용한다. CM3의 명령 요청과 CFX의 전송 완료를 구분하여 같은 명령을 중복 실행하거나 전송 중인 데이터를 덮어쓰지 않도록 한다.

[94 P TDC25] <그림 5. 블루투스 연계>
[95 P TDC20] [QCC 자료 입력] 여기에 QCC 내부 모듈과 E8300 연결 경로를 보완한 그림을 넣으세요. 자료 수령 후 그림의 QCC 내부 영역을 채우고, 하드웨어 구조와 다른 모듈의 연계 그림에도 영향이 있는지 확인한다.
[96 P TDC20] 외부 블루투스 장치에서 전달된 제어 명령을 QCC가 SPI 경로로 CM3에 전달한다.
[97 P TDC20] QCC는 CM3에서 준비한 응답을 수신하여 외부 장치로 전달한다.
[98 P ] 
[99 P TDC20] CM3는 수신 명령을 구분하여 리모콘, 매핑 및 시스템 정보 처리를 실행하고 응답을 SPI 버퍼에 준비한다.
[100 P TDC20] 블루투스 명령은 수신, 명령 구분과 실행, 응답 준비로 나누어 처리한다. CM3에는 SPI 수신 데이터 확인, 리모콘/매핑 명령 처리, 시스템 정보 응답, 갱신 데이터 전달을 담당하는 유닛을 둔다. 명령별 동작을 분리하여 수신 버퍼를 정리하기 전에 필요한 처리를 끝내도록 한다.
[101 P TDC20] QCC와 E8300 사이의 제어 명령과 응답은 SPI로 전달하고 스트리밍 오디오는 I2S로 CFX에 전달한다. 명령 통신과 오디오 처리는 입력 경로와 완료 시점이 다르므로 따로 다룬다. QCC 내부의 블루투스 처리는 별도 상세 설계 자료에 따라 추가한다.

[108 P TDC10] 소프트웨어 아키텍쳐 기술서에서 정의한 기능 모듈을 소프트웨어 항목과 유닛으로 구체화한다. 한 유닛은 하나의 기능을 수행하는 단위이며 같은 상태의 설정/조회 함수는 함께 둔다. 계산 단계나 완료 시점이 다른 기능은 별도 유닛으로 나눈다.
[109 P TDC10] 소프트웨어 항목에는 SI-ID, 유닛에는 SU-ID를 부여하여 실행 코어와 기능을 구분한다. 각 유닛의 목적, 입력, 출력, 처리 순서와 인터페이스를 아래에 정의한다.
[110 P TDC10] 분기, 반복 또는 상태 전환이 중요한 유닛에는 설계 순서도를 둔다. 단순 설정/조회는 본문으로 설명한다. 마름모는 조건 판단, 사각형은 처리, 둥근 상자는 시작/종료를 나타낸다. 다음 호출을 기다리는 경로는 해당 호출에서 끝나며 다음 이벤트에서 이어진다.
