[100 P 2] 모듈 구현 단계
[101 P 3] Hardware interface module 구현
[102 P ] 가장 중요한 MCU와 그 주변장치에 대한 초기화와 활성화 후 동작을 시작하여야 전체 시스템이 정상 동작이 가능하게 된다. 특히, 제일 중요한 사운드 처리기의 신호를 항상 확인한다. 따라서, HW interface module을 가장 먼저 구현해야 한다.
[103 P 3] System management module 구현
[104 P ] 장치의 HW가 동작하기 시작한다고, 전체 시스템이 정상 동작을 하는 것이 아니다. 전체 시스템이 동작하기 위해서는 장치의 각 부분들의 현재 상태를 읽고 다음 상태를 결정해야 하는데, 이러한 역할은 System management module에서 수행한다.
[105 P 3] Bluetooth module 구현
[106 P ] 이 모듈은 Audio 통신과 데이터 통신에 모두 필요한 기능이고, 시스템의 상태와 필요한 HW 입력에 따라 활성화와 동작이 제어되므로 HW interface module과 System management module이 구현된 후에 이 모듈들의 기능을 사용해 구현하고, 통신 테스트를 수행한다.
[107 P 3] Security module 구현
[108 P ] 보안 모듈은 전체 시스템을 설정하고 제어하므로, 다른 모듈들이 모두 구성된 후에 구현하여 정상 동작하는 것을 확인한 후에 보안 모듈과 통합하는 방식으로 한다. 특히, 민감하고 주요 데이터는 BLE를 통해 송수신되므로 BLE 연결의 보안에 중점을 둔다.
[109 P 2] 모듈 통합 단계
[110 P 3] System management module과 통합
[111 P ] 서로 밀접히 연계된 모듈들을 서로 통합하면서 개별 모듈들의 동작을 검증하고 필요하다면 프로그램의 수정을 진행한다.
[112 P ] [System management module] + [Hardware interface module]
[113 P ] Hardware interface module의 각 입력 신호가 System management module로 전달되어 상태로 변환되는지를 확인하고, 그 상태에 따른 결과가 Hardware interface module로 전달되어 원하는 출력이 되는지 확인한다.
[114 P 3] Bluetooth module과 통합
[115 P a8] Bluetooth module은 시스템 상태에 따라 활성화와 동작이 되므로, System management module 에 통합된다.
[116 P ] [System management module + Hardware interface module]+ [Bluetooth module]
[117 P ] Bluetooth module은 시스템 상태에 따라 동작이 결정된다. 그리고, 현재 Bluetooth 상태들을, Classic 또는 BLE 연결상태 같은, 다시 System management module에 전달하게 된다.
[118 P 3] Security module과 통합
[119 P a8] 보안 모듈의 초기화 및 설정은 System management module에서 수행되고 보안 설정에 따른 주요 동작은 Bluetooth module에서 수행되므로, System management module이 Bluetooth module에 통합된 후에 Security module은 이에 통합된다.
[120 P ] [ System management module + Bluetooth module ] + [ Security module ]
[121 P ] Bluetooth pairing과 BLE service 보안 설정은 시스템 시작전에 결정되고 초기화시에 설정을 수행한다. 그리고, BLE 연결시에 보안 정책에 따른 인증을 수행하게 된다.
[122 P 3] 누적 통합 
[123 P ] 모듈들을 누적해가면서 동작을 검증하고 필요하다면 프로그램의 수정을 진행한다.
[124 P ] [ System management module + Hardware interface module + Bluetooth module ] + [ Security module ]
[125 P ] Bluetooth module은 시스템 상태에 따라 동작이 결정된다. 이러한 상태는 HW 입력을 통해 결정되어 Bluetooth가 활성화되고, 동작이 진행되며, HW 마이크 폰으로 주변 소리를 입력 받고, Battery level과 같은 처리하는 정보 또한 입력 받는다. 이러한, 과정은 모두 보안 모듈의 설정과 제어를 통해 이루어진다.
[126 P 3] 시스템 통합 검증
[127 P ] 모든 모듈들을 통합한 상태에서 스마트폰의 리모콘/매핑 앱과 연동을 검증하고 필요에 따라서 프로그램을 수정을 진행한다.
[128 P a8] [ Remocon/Mapping On ] + [ System management module + Hardware interface module + Bluetooth module + Security module ]
[129 P ] 
[130 P 3] 장치 통합 검증
[131 P ] 전체 TD24A의 시스템인 외부장치, 스마트 케이스 그리고 스마트폰을 가지고 전체적인 사용 시나리오를 테스트하고 검증한다. 그리고, 필요에 따라서 프로그램을 수정을 진행한다.
[132 P ] [ Remocon/Mapping On ] + [ Smart case ] + [ System management module + Hardware interface module + Bluetooth module + Security module ]
[133 P ] 외부 장치는 외부 충전과 Bluetooth Audio 통신 테스트에 필요하다.
