[153 P TDC20] 메시지 경계: QCC BLE Data 메시지는 type 1바이트와 data 0~19바이트로 총 1~20바이트이다. E8300 SPI 전송 프레임은 별도 길이 1바이트를 포함한 21바이트이다. 무선 메시지와 물리 SPI 프레임을 같은 계층의 길이로 취급하지 않는다.
[154 P TDC20] 제어 핀: E8300 QCC_CTRL(DIO24)은 High=정상 동작 요청, Low=종료 요청이며 초기값은 Low이다. ISD_CHECK(DIO13)는 High=내부기 연결, Low=미연결이며 초기값은 Low이다. CFX I2S_FLAG(DIO29)는 Low=입력 유효이다. QCC의 shutdown_ind 또는 I2S enable이라는 논리 이름만으로 물리 핀 극성을 변경하지 않는다.
[155 P TDC20] 오디오 경로: QCC Classic 수신 오디오는 I2S로 CFX에 전달한다. SRS의 출력 사양은 24bit·16kHz이다. E8300 PCM1은 slave, 24bit, MSB 우선/정렬, 상승 에지, 2word 설정이며 16표본 블록을 처리한다. 16kHz 표본율과 0~8kHz 오디오 대역 요구는 구분한다. CFX는 일반 I2S 게인 1과 마이크 Gain A, 크래들 I2S Gain B와 마이크 Gain A, 매핑 연결 중 두 게인 1을 적용하며 혼합 후 2로 나누지 않는다.

[192 P TDC10] E8300 공유 메모리·SPI·I2S·제어 핀의 기존 연계와 제공 QCC 모듈 간 기능 연결을 대조하였다. E8300 정적 인터페이스 정의는 유지한다. QCC 종료 극성·충전 상태 변환·실제 무선/오디오/보안 계약의 상충과 실측 미제공은 해당 미비 안내로 보존한다. 본 검토는 제공 설계의 분석이며 구현 또는 통합시험 통과를 의미하지 않는다.

[195 P TDC10] 기존 E8300의 지원 소프트웨어 식별·관리 범위는 유지한다. QCC는 제공설계 수준을 반영했으며 지원 소프트웨어의 정확한 제품·버전과 운영 검토 완료는 확인되지 않았다.
