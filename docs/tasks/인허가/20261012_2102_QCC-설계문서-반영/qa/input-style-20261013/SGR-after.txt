DMIC2는 E8300과 QCC에 함께 연결되며, 통화 상향 마이크 입력과 I2S 수신 오디오는 서로 다른 경로다. BLE의 리모콘/매핑 명령과 응답은 SPI로 E8300에 중계한다.√ 보호 대상 BLE 데이터 접근에는 페어링과 CRA 인증을 요구한다. 오디오 송신, 연결 제한 및 인증/키 관리 조건은 소프트웨어 요구사항 사양서에 따른다.소프트웨어와 사용자간 인터페이스사용자는 사운드처리기를 터치하여 사운드처리기를 제어하고 LED를 확인하여 사운드 처리기의 상태를 확인한다.사용자에 의해 조정되는 소프트웨어 특징사용자는 사운드 처리기의 UI를 사용하여 전원을 켜고/끌 수 있으며, 리모콘 앱을 사용하여 맵 프로그램, 자극 볼륨, 마이크 감도, LED 알림 등을 조정할 수 있다.소프트웨어 동작 환경프로그램 언어C language, Assembly language.운영 체재E8300 펌웨어는 별도 운영체제 없이 동작한다.QCC5181은 제조사 제공 Built-in library와 scheduler를 사용하는 펌웨어로 구성한다. QCC의 실행 환경은 E8300의 운영체제 사용 여부와 별도로 정의한다.QCC의 실제 ADK/실행 환경, scheduler 구성과 사용 버전은 미확정이다.기성용 소프트웨어 사용onsemi E8300 SDK와 제조사 제공 라이브러리를 사용한다.QCC5181은 제조사 제공 Bluetooth stack과 Built-in library를 사용한다.QCC 제조사 소프트웨어의 식별/버전, 사용 범위와 검토 근거는 미확정이다.
