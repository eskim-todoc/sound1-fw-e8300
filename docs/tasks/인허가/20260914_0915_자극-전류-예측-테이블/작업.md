# Sound1 자극 전류 예측 테이블

## 목적

CM3 `ci_map.c`의 기본 맵과 `stimulationParaCal.c`의 DAC 범위·T/C 환산식을 코드 그대로 재현하고, CFX의 음압 입력·AGC·FFT 대역 대표값·로그 매핑·PCM 패킷 경로를 연결한다. 사용자가 음압, 주파수, 오디오 볼륨, 자극 볼륨과 맵을 바꾸면 예상 PCM Amplitude와 출력 전류가 다시 계산되는 Excel을 만든다.

## 범위

- 포함: 기본 맵 1~4, 활성 ISD 1.1.2 DAC 상수, 32대역 기본 패스빈, 필수성능 ID-6 입력 벡터, 코드 모델과 현 기준서 값의 비교.
- 제외: 마이크·기구·공간 배치의 시료 편차, 내부기 DAC 실물 오차, HEAR `vMag` 테이블 근사의 비공개 내부 LUT 재현.

## 완료 기준

1. 기본 맵의 펄스폭·전략·대역 수·T/C·xMin/xMax가 소스와 일치한다.
2. `stimulationParaCal.c`의 DAC slope/offset 선택, 레지스터 값, T/C 255 환산, 프레임 수를 정수 절삭까지 재현한다.
3. CFX의 오디오 볼륨·자극 볼륨·로그 매핑·PCM Amplitude 및 패킷 필드를 추적 가능하게 표시한다.
4. 입력 dB SPL과 주파수로부터 Sound1 명목 ADC 및 예상 대역 대표값을 계산한다.
5. PCM Amplitude를 활성 ISD 1.1.2 설정에 따른 예상 출력 전류로 역환산한다.
6. 필수성능 ID-6의 6개 조건에 대해 코드 모델값, 현재 기준서 명목값, 차이를 한 표에서 비교한다.
7. 수식 오류가 없고, 입력 경계와 대표 조건을 바꿔도 계산이 정상적으로 갱신된다.
8. 모든 시트를 렌더링해 잘림·겹침·가독성 문제 없이 검토한다.

## 근거

- CM3 기본 맵: `src/2__cm3/Gen1_5/FS/ci_map.c`
- CM3 자극 파라미터: `src/2__cm3/Cortex-M3-src/signalProcessing/stimulationParaCal.c`
- 활성 내부기 상수: `src/2__cm3/99_includeBoard/isd_ver1_1_2.h`
- CFX AGC·주파수 분석·로그 매핑·PCM: `src/1__cfx/signalProcessing/`
- FFT 패스빈·Hann 계수: `src/2__cm3/Gen1_5/FS/ci_fft.c`
- HEAR 함수 정의: HEAR Configurable Accelerator Reference Manual의 Win_DFT_R_Forward 및 vMag 절.
- Sound1 ADC 모델과 필수성능 벡터: `docs/tasks/인허가/20260910_1029_sound1-eptc/`

## 계획

1. CM3 기본 맵과 DAC 설정 결과를 독립 계산으로 재현한다.
2. CFX 정상상태 신호 경로와 32대역 패스빈을 계산 모델로 정리한다.
3. Excel을 입력·계산·결과·근거 시트로 구성한다.
4. 대표 벡터와 경계값을 독립 계산 결과에 대조한다.
5. 수식·시각 검증 후 최종 파일만 전달한다.
