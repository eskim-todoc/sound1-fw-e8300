## 목표와 범위

### 후속: 주파수별 예상 자극 전류 표

- 표시 형식 후속 변경: 주파수마다 ADC / 전류 −10% / 예상 전류 / 전류 +10%로 분리했다. 볼륨별 92행·45열이며, 기존 ADC·예상 전류 2,024쌍 보존과 ±10% 끝값 4,048개를 상세 CSV와 대조해 통과했다. 범위는 예상 전류의 0.9/1.1배를 소수점 한 자리로 표시하며 상한 절삭하지 않는다. 저소음 모델의 실측 차이를 해소한 것으로 해석하지 않는다. 아래 초기 제작 당시의 12열 기록은 당시 결과다.

- 사용자 확정 조건: 기본 맵 1, 오디오 볼륨 1과 10, 자극 볼륨 4. 기존 ADC 합체 표를 수정하지 않고 별도 표로 변환한다.
- 산출물: [주파수별 예상 자극 전류 테이블](../../../참고/인허가/사운드1/주파수별%20예상%20자극%20전류%20테이블.md). 각 볼륨별 92행·11주파수, 총 2,024개 전류 값.
- 계산: [재현 스크립트](adc_current_table.py)가 기존 20260914_32채널-시험표 모델을 재사용한다. 이전 음압→ADC 환산은 사용하지 않고 현재 ADC 셀을 직접 순음 진폭으로 주입한다. AGC→FFT→밴드 최대→비선형 매핑→PCM→전류 경로와 현재 기본 맵·DAC 계수를 대조했다.
- 선택 전극: 100/1048/1438/1500/1593/2869/3038/3217/3815/4037/7900Hz 순서로 1/15/18/18/18/24/24/25/26/26/32. 사용 FFT bin 중 주파수가 가장 가까운 bin의 밴드이며 전체 전극 최대값을 선택하지 않는다.
- 근거와 재현: [입력·소스 SHA256](전류-계산-근거.json), [입력 ADC·PCM·전류 최소/중앙/최대](전류-계산-상세.csv). 표의 대표값은 마지막 1초 1,000개 PCM의 아래쪽 중앙값을 전류로 변환한 값이다.
- 실제 검증: ADC 원본 SHA256 불변, 1,012개 ADC와 상세 입력 전수 일치, 출력 2,024키 중복·누락 없음, 전류=497+floor(19333×PCM/4096) 전수 일치, 모든 최소≤중앙≤최대 및 497~1492µA 범위 확인. GFM 파서에서 전극 표11×3, 전류 표92×12 두 개 확인.
- 경계 검사: CM3 offset register109→497µA, T/C 진폭0/211, PCM211→1492µA, T=C인 전극16의 고정1492µA 확인. 예시1048Hz·70dB는 볼륨1 907µA / 볼륨10 1469µA.
- 한계: 원표의 블록최대 평균과 순음피크는 동일하지 않을 수 있다. HEAR와 DSP 라이브러리는 이상적인 함수로 근사한다. 실측·실기 검증은 하지 않았으며 사용자가 알려 준 공유 드라이브 Word는 이번 계산 입력으로 사용하지 않았다. ±10% 허용차를 예상값에 포함하지 않는다. 펌웨어·기존 Word/Excel·Git 이력은 변경하지 않았다.

최초 요청은 사용자가 추가한 [ADC 테이블](../../../참고/인허가/사운드1/ADC%20테이블.md)의 29~120 dB SPL, 7개 주파수 열에서 빈 ADC 칸을 채우는 것이었다. 1048Hz 열은 제공된 기준곡선으로 보존한다. 괄호 안은 측정 기간의 최대, 밖은 평균이라는 사용자 정의를 따른다. 후속 요청으로 시험 기준 후보와 주파수·빔포밍 원인 분석을 추가했다. 실제 시험 수행이나 새로운 합격 기준 확정은 포함하지 않는다. 펌웨어·다른 Word·Excel·Git 이력은 변경하지 않는다.

## 수용 기준

1. 원래 기록된 모든 숫자와 1048Hz 기준 92개가 보존되고, ADC 데이터 칸에 빈칸 또는 하이픈이 남지 않는다.
2. 최대·평균을 별도로 계산하며 새 수치는 보간/외삽/표시상한을 구분한다. 계산식과 예시로 재현할 수 있다.
3. 기존 실측에 포함된 빔포밍·기구·측정계 영향을 다시 감쇠시키지 않는다. 독립 기구 전달함수를 측정했다고 주장하지 않는다.
4. 3815Hz·75dB 평균23은 확인 전 원값을 보존하되 주변 보간의 기준에서 제외한다. 다른 요동을 임의로 고치지 않는다.
5. 계산 전수 검증과 별도 구현 검산, 원본 보존, Markdown 표 구조·내부 링크를 확인한다. 실기 검증은 미실행으로 구분한다.

## 근거와 실행 계획

- [입력 원본](ADC%20테이블_입력원본.md)을 보존한 뒤 파싱한다. 1048Hz 기준값을 R(L)로 두고 실측 최대·평균 각각에 대해 실측/R 비율을 구한다.
- 이웃 실측 사이에서는 로그 비율을 음압에 대해 선형 보간한다. 범위 밖은 가장 가까운 실측의 비율을 유지한다. 측정 범위 밖에서 새로운 주파수 응답이나 잡음 바닥을 만들어 넣지 않는다.
- 표의 1048Hz 최고값262143을 표시상한으로만 사용한다. 상한 제한값은 실제 클리핑 파형이나 평균을 예측한 결과로 간주하지 않는다.
- ADC 공유값은 HEAR 절대값·16개 최댓값 결과이며 CFX가 AGC 전에 공유한다. 평균/최대 차이를 RMS 변환이나 하나의 일정 배율로 대신하지 않는다.
- 계산은 스크립트에서 수행하고 실제 Markdown 수정은 apply_patch로 적용한다. 기존 사용자 소스 변경과 다른 파일은 보존한다.

## 결정 이력

- 2026-09-23: 사용자 요청은 새 표 빈칸 채우기. 3815Hz·75dB 평균23의 확인을 비동기 질문했으며, 답변 전까지 원값 유지·보간 제외로 진행한다.
- 2026-09-23 후속: 사용자가 시험 기준 관점의 표 구성과 주파수·빔포밍 수학 모델 분석을 요청했다. 모든 주파수에서 왼쪽 빔포밍·선택 방향 정면의 동일 배치였음을 사용자 답변으로 확인했다.
- 후속 범위: 기존 관측표와 별도로 매끄럽고 단조 증가하는 중심값 후보를 만들고, ±5dB는 중심곡선의 L−5/L+5 행으로 해석한다. 수학 모델·자료 내 적합성 검사와 실제 제품 시험을 구분한다. 주파수별 보정은 이 자료에 대한 후보이며 정식 규격 확정이나 전체 생산품 대표성 승인을 대신하지 않는다.
- 후속 수용 기준 A: 원 실측51쌍·1048Hz 92개 불변. B: 지연합·16표본 최대값 모델을 독립 정현파 계산으로 검산. C: 대표 계수·허용범위·고음압 포화 및 범위 밖을 재현 가능하게 구분. D: 미측정 주파수는 물리적으로 계산되는 부분과 경험적 보간을 구분. E: 펌웨어·기존 Word·Excel·Git 이력 불변.

## 후속 결과: 시험 기준안과 주파수 모델

- [시험 기준안 및 분석](../../../참고/인허가/사운드1/ADC%20주파수별%20시험%20기준안%20및%20빔포밍%20분석.md): 원표와 분리한 최대값 중심 기준 후보. 기존 ADC 표와 인덱스에서 연결했다. 기존 표의 숫자는 변경하지 않았다.
- 공통 55·60·65·70·75·80dB의 최대값/R 비율을 dB로 바꾸어 중앙값을 취한 뒤 0.1dB로 반올림했다. 100/114/128/1048/3038/3815/4037/7900Hz의 계수는 −0.1/−1.3/−3.4/0/+1.8/−3.3/−4.4/−2.3dB다. ±5dB는 C(L−5)~C(L+5)를 사용한다.
- 후보와 기존 최대51점의 수치 대조는 전부 범위 내다. 계수 산정에 쓴42점과 나머지9점을 분리했으며 독립 제품 검증이라고 표기하지 않았다. 최대 진폭 잔차2.10862dB. 3038Hz 119/120dB 중심287055/322506은 상한초과로 공개하고 잘라 맞추지 않았다.
- 동일 정면, 두 동일 마이크, d22mm·c343m/s·fs16kHz·지연1.025표본 가정에서 7900Hz의 지연합 감쇠는 −0.000016043dB. 128Hz는 반대쪽에서도 −0.011548dB여서 수 dB 차이를 순수 방향 효과로 설명하지 못한다. 실제 코드 실행·배선·개별 마이크 전달함수를 검증한 것은 아니다.
- 16표본 최대의 균등위상 평균은 100/7900Hz 약79.6695%,1048Hz 약99.7974%. 무선 조회의 위상 고정 가능성 때문에 관측 최대 또한 전체 진폭과 같다고 단정하지 않았다. 정확한4k/8k에서 오래 기다려도 최대를 놓칠 수 있는 반례를 포함했다.
- 연속100ms/1600표본 전체 최대라면 이번8주파수의 타이밍 손실 최악0.00167445dB. 현재 무선 공유는 누적 최대가 아니므로 이 취득 조건과 구별했다. 미측정 주파수는 물리 모델과 경험적 로그주파수 보간을 나누고,7900Hz 밖의 절대ADC 외삽은 제공하지 않았다.

초기 검사에서 빈칸의 굵은 서식 `**_-_**`를 숫자로 취급한 검사 코드와 정수 반올림 뒤 엄격 증가를 요구한 검사가 실패했다. 원자료나 모델 수치를 바꾸지 않고 빈칸 정규화·비감소 계약으로 검사 오류를 수정하여 재실행했다. Node의 Windows ESM 경로는 file URL로 수정 후 GFM검사를 통과했다. Knowles 웹 PDF는 재조회 실패하여 해당 스펙의 수치를 새 근거로 채택하지 않았다. 대신 현 소스·제조사 로컬 SDK HTML·MathWorks 1차 설명과 자체 수치 모델을 사용했다.

## 후속 표시 수정: 숫자만 표시하고 시작·끝 비교 안내

- 사용자 요청에 따라 ADC 표 셀의 `≈`·`외`·`외·상` 접두어를 제거했다. 보간181·외삽412·상한제한2의 계산과 ADC 숫자는 변경하지 않았다. 설명부에는 실측/계산 구분과3038Hz119·120dB의 표시상한 제한을 남겼다.
- ‘시작·끝’은 승인된 성능 범위가 아니라 **실측이 확보된 범위의 경계**로 해석하여 먼저 안내한 뒤 적용했다. 100Hz35~90dB,114Hz35~80dB,나머지55~80dB의 양 끝14칸에만 `<small>` 주석을 붙였다. 중간 실측의 기존 굵은 괄호 서식도 유지했다.
- 기준안에서 채택했던 최대값 통계와 일관되게 괄호 안 최대ADC를1048Hz 기준곡선에 역대응시켰다. 이웃 기준 ADC의 로그 보간 역함수를 사용하고 소수1자리로 표시했다. 예:100Hz35dB 최대34 →1048Hz36.7dB,100Hz90dB 최대7825 →1048Hz89.8dB. 평균값이나 실제 입력 음압을 바꾼 것이 아니다.
- 검증: 변경 직전 표와 변경 후 표의92행 ADC 숫자를 전수 비교하여 동일함을 확인했다. `adc_estimate.py --verify`, unittest11항 통과. 역산은45자리Decimal log10으로14끝점을 독립 검산하고 범위 밖·NaN 거부를 검사했다. GFM파싱/HTML변환에서 본표92×9·전체표3개·작은 시작주석7개/끝주석7개·빈칸0 확인. 대상 앱의 실제 글자 크기는 시각 검사하지 않았다.
- 수정 대상은 기존 ADC 표, 재현 생성기, 기존 검사 및 이 작업 기록뿐이다. 원자료·기준안의 중심값·펌웨어·Word·Excel·Git 이력은 변경하지 않았다.

## 후속 요청: ADC 추가 테이블 확장

- 사용자 요청: 새 `ADC 추가 테이블.md`의 측정값을 바탕으로 같은 문서에 앞서와 같은 표를 더 구성한다.
- 입력: 1438·1500·1593·2869·3217Hz,65·70·75·80dB의20개 값. 기존 정의에서 괄호 없는 값은 평균이므로 이 자료는 평균값으로 해석한다고 먼저 안내했다. 최대값 열을 새로 추정하지 않는다. 주파수1438·1593은 기록대로 사용하며 FFT bin 주파수로 치환하지 않는다.
- 원본 파일 SHA256: `cc80fa595602ef467766d437348d5c02f01e636e2fc91b3aa7b1dd9e65323ccd`. [입력 원본](ADC%20추가%20테이블_입력원본.md)에 보존했으며 저장 후 해시도 동일함을 확인했다.
- 계획: 기존1048Hz R(L)92개를 재사용한다. 실측점은 그대로 유지하고 그 사이는 ADC/R의 로그 비율 보간,65dB 아래·80dB 위는 가까운 끝점 비율을 유지한다. 기존과 같은262143 표시상한을 적용하되 해당7칸과 제한 전 계산값을 따로 밝힌다.
- 추가 수용 기준: A 원측정20개와 기준92개 불변, B 29~120dB×5주파수460칸 및 독립Decimal 검산, C 시작·끝10곳만 작은1048Hz 대응 음압 표기·최대값 오인 방지, D 원문과 생성기 일치·Markdown 구조·내부 링크 확인, E 기존 ADC 문서·기준안·펌웨어·Excel·Git 이력 보존.
