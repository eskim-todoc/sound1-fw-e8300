# 분석

**TL;DR**: 죽은 구역 **10곳 235줄**, 지시자 32줄. ecap 에는 **조건부 `#if` 가 없어**(전부 `#if 0`/`#if 1`) 전처리기 분기를 통째로 걷어낼 수 있다. 검증은 **살아 있는 줄 대조 + `.text` 바이트 비교** 두 겹으로 한다.

## 1. 죽은 구역 전수

| # | 형태 | 줄 | 죽은 크기 |
|---|---|---|---|
| 1 | `#if 0`/`#else` | 395~404 | 3 |
| 2 | `#if 0`/`#else` | 406~420 | 9 |
| 3 | `#if 0`/`#else` (중첩 `#if 0` 555~564 포함) | 529~605 | **60** |
| 4 | `#if 0`/`#else` | 609~618 | 3 |
| 5 | `#if 0`/`#else` | 620~636 | 13 |
| 6 | `#if 1`/`#else` | 770~774 | 1 (뒷 가지) |
| 7 | `#if 0`/`#else` | 902~910 | 4 |
| 8 | `#if 0`/`#else` | 1182~1266 | 37 |
| 9 | **`#if 0`** (else 없음) | **1269~1370** | **100** |
| 10 | `#if 0` (else 없음) | 1381~1389 | 7 |
| | | **소계** | **235** |

`#if 1`/`#endif`(708~720) 하나는 else 가 없어 죽은 줄이 0이다. 지시자만 걷는다.

**조건부 `#if`(`#ifdef` 등)가 하나도 없다.** 전부 `#if 0` 또는 `#if 1` 이라 판정이 확정적이다.

## 2. 왜 지표로 검증할 수 없는가

`tests/metrics.sh` 는 행 앵커로 센다.

```sh
grep -cE '^[[:space:]]*if[[:space:]]*\('
```

**`#if 0` 안의 `if` 도 걸린다.** 죽은 코드를 지우면 지표가 줄어드는 것이 당연하고, 줄어든 크기가 옳은지 판정할 기준이 없다.

> [!NOTE]
> **도구의 결함이 아니라 용도의 문제다.** 지표는 «함수 추출로 분기가 보존됐는가» 를 보는 도구다. 죽은 코드 제거는 애초에 분기 수를 줄이는 작업이라 대상이 아니다.

## 3. 검증 설계 - 두 겹

### 3.1 살아 있는 줄 대조 (정적)

전후 파일에서 **컴파일되는 줄만** 뽑아 리스트로 비교한다.

- 죽은 가지를 지우다 산 가지를 건드리면 → 걸린다
- 지시자 삭제로 줄이 어긋나면 → 걸린다
- 산 가지의 내용이 바뀌면 → 걸린다

**이것이 «컴파일 결과가 같다» 에 가장 가까운 정적 증거다.**

### 3.2 `.text` 바이트 비교 (자산_1)

크기가 같아도 내용이 다를 수 있으므로 `cmp -l` 로 전수 비교한다.

**차이가 예상된다** — ecap 에 `__LINE__` 이 있고 줄이 밀리므로 그 즉치가 바뀐다. 따라서 «0바이트» 가 아니라 **«다른 바이트가 몇 개이고 각각 무엇인지»** 를 대야 한다.

| 항목 | ecap |
|---|---|
| `TDC_PRINTF_*` (매크로 안에 `__LINE__` 은닉) | **0건** |
| 명시 `__LINE__` | 6건 (살아 있는 것) |

**`TDC_PRINTF` 가 0건인 것이 이 검증을 쉽게 만든다.** 자산_1 이 경고한 «보이지 않는 `__LINE__`» 이 없어, 소스에서 보이는 6개만 추적하면 된다.

### 3.3 원본 재빌드 시 주의

`.text` 를 비교하려면 원본으로 되돌려 한 번 더 빌드해야 한다.

> [!CAUTION]
> **자산_Q**: `Copy-Item` 은 원본의 `LastWriteTime` 을 보존해 make 가 재컴파일을 건너뛴다. 되돌린 뒤 타임스탬프를 갱신해야 한다.

## 4. 제거 후 예상

| 항목 | 예상 |
|---|---|
| 줄 수 | 1,455 → **1,188** (267 감소) |
| 죽은 줄 | 235 → **0** |
| `text` 크기 | **불변** (컴파일되지 않던 것을 지웠다) |
| `.text` 바이트 | **일부 다름** - 밀린 `__LINE__` 즉치만 |
| `data`·`bss` | **불변** |
