# 요구사항 - stim_para_setting 분해

**TL;DR**: 자극 본체 두 상태 기계(모노폴라 320줄 · 바이폴라 708줄)를 case 별로 나눈다. **이 프로젝트에서 가장 위험한 리팩터링**이라 동작 불변 입증이 요구사항의 절반을 차지한다.

## 1. 배경

[분해 분석](../20260806_0834_isd-대형함수-분해-분석/분석.md) §6.4 의 **단계_4**. 분석이 «자극 본체 · 최고 위험» 으로 분류했고, 단계_3(`specific_stim`)을 먼저 한 이유도 **같은 형태를 낮은 위험에서 연습**하기 위해서였다.

## 2. 요구사항

### 요구사항_1 - 두 함수를 각각 case 별로 나눈다

`tdc_isd_set_stim_para_monopolar`(6 case) · `tdc_isd_set_stim_para_bipolar`(16 case).

### 요구사항_2 - 두 상태 기계를 섞지 않는다

> [!CAUTION]
> **두 함수가 같은 이름의 `static` 을 각자 갖는다** (`flowControlCounter` 등). 함수-지역이라 이름이 같아도 별개다.
>
> 승격할 때 그대로 올리면 **하나로 합쳐져 서로를 밟는다.** 접두어로 갈라야 한다.

### 요구사항_3 - 반복 블록은 인자화해 합친다

`bi` 의 `case 14·16·18·20·22·24` 가 전부 29줄로 같아 보인다. **다만 «같아 보인다» 를 근거로 삼지 않는다** - 본문 해시로 대조하고, 다른 것이 섞여 있으면 인자로 흡수하거나 합치지 않는다.

### 요구사항_4 - 손으로 옮기지 않는다

1,111줄에 case 22개다. **기계로 추출하고 검증은 지표로 한다.**

### 요구사항_5 - 동작 불변을 지표와 심볼로 입증

- 구조 지표: 변하면 **크기까지** 설명
- `bss` 심볼: 승격한 static 이 **1:1 로 대응**하는지 확인

## 3. 제약

| # | 제약 |
|---|---|
| 제약_1 | **동작 불변.** 일상 청취의 자극 경로다 |
| 제약_2 | 코드 포맷 조건 · CP949 금지 문자 |
| 제약_3 | `tdc_` 접두어 · 두 경로가 이름으로 구분될 것 |
| 제약_4 | 실기 대기가 9건이 된다 |

## 4. 완료 조건

- [ ] 두 디스패처가 상태 표만 남는다
- [ ] 두 상태 기계의 static 이 섞이지 않는다 (**심볼로 확인**)
- [ ] 구조 지표 불변 또는 크기까지 설명
- [ ] 호스트 514 PASS 유지
- [ ] ARM 에러 0 · 경고 증가 0
- [ ] `text` **감소** (중복 병합이 있으므로)
