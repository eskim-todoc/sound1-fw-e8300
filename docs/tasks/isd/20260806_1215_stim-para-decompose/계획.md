# 계획

**TL;DR**: 스크립트가 **본문을 원문 그대로 옮기고 껍데기만 생성**한다. 검증은 **구조 지표 예측치**와 **bss 심볼 1:1 대조** 둘로 한다.

## 1. 기계 추출 설계

스크립트가 하는 일 넷.

| # | 하는 일 | 실패 시 |
|---|---|---|
| 1 | case 블록을 **중괄호 짝맞추기**로 잘라낸다 | 못 찾으면 중단 |
| 2 | 블록이 참조하는 지역변수만 골라 그 함수에 선언 | 빠지면 **컴파일 실패** |
| 3 | `static` 이름에 `s_mono_`·`s_bi_` 접두어 | - |
| 4 | **case 집합이 기대와 다르면 중단** | 중단 |

> [!IMPORTANT]
> **본문은 한 글자도 고치지 않는다.** 유일한 예외가 병합 두 곳의 루프 헤더이고, 그것도 치환 건수를 1건으로 못 박는다.

## 2. 불변량과 예측치

**유형: 함수 추출 + 중복 병합**

| 지표 | 예측 | 근거 |
|---|---|---|
| `case`·`switch`·`default`·`if`·`else`·`or`·`and` | **불변** | 코드를 옮기기만 한다 |
| **`for`** | **정확히 -12** | `send_reference_range` 2블록×2루프 → 1×2 = **-2**<br>`read_reference_burst` 6블록×2루프 → 1×2 = **-10** |
| **`return`** | **정확히 +16** | 추출 함수 16개가 각각 `return` 하나 |
| 호스트 | 514 PASS 유지 | |
| ARM | 에러 0 · 경고 증가 0 | |
| `text` | **감소** | 중복 8블록 제거 |
| `data`·`bss` | **불변** | 승격은 저장을 안 바꾼다 |

**다른 값이 나오면 원인을 찾을 때까지 커밋하지 않는다.**

## 3. bss 심볼 대조 절차

요구사항-검증의 보완이다.

```
1. 분해본 빌드 -> bss 심볼 목록
2. 원본으로 되돌리고 빌드 -> bss 심볼 목록
3. 두 목록을 대조 -> 승격한 static 이 1:1 대응하는가
4. 분해본으로 복원
```

> [!CAUTION]
> **`Copy-Item` 은 타임스탬프를 보존한다.** 되돌린 뒤 `LastWriteTime` 을 갱신하지 않으면 make 가 «최신» 으로 보고 재컴파일을 건너뛴다. 그러면 «원본도 같은 크기» 라는 거짓 결론이 난다.

## 4. 실기 확인 항목

| 항목 | 확인 |
|---|---|
| **라이브 자극 - 모노폴라** | 소리가 정상인가 |
| **라이브 자극 - 바이폴라** | 소리가 정상인가. 기준전극 설정 16단계가 정상인가 |
| **라이브 자극 - 공통접지** | 모노폴라 경로를 탄다(디스패처) |
| 맵 전환 | 모드가 다른 맵 사이를 오갈 때 정상인가 |
| 에러 로그 | 정상 동작에서 에러가 없을 것 |

> [!IMPORTANT]
> **모드별로 다 봐야 한다.** 디스패처가 모드로 갈라 **모노폴라·공통접지는 `_monopolar`, 바이폴라만 `_bipolar`** 를 탄다. 두 경로는 이제 별개의 `static` 집합을 갖는다 - 한쪽만 확인하면 나머지가 미검증이다.
>
> **맵 전환도 봐야 한다.** 두 상태 기계의 카운터가 독립이므로, 모드가 바뀌며 오갈 때 이전 상태가 남아 있는지가 드러난다.
