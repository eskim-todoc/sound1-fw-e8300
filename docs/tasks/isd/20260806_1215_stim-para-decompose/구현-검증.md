### 4.1 `bss` -4 의 정체

승격은 중립이어야 하므로 추적했다. **§3 에서 심볼이 13:13 로 대응하고 합계도 300바이트로 같다**(포인터 4개 16 + 정수 7개 28 + 배열 2개 256).

원인은 **`-fdata-sections` 로 각 static 이 자기 섹션을 갖는데, 선언 순서가 바뀌며 섹션 간 정렬 패딩이 달라진 것**이다. 데이터 손실이 아니다.

> [!CAUTION]
> **«4바이트니까 괜찮겠지» 로 넘기면 안 된다.** 진짜로 하나가 사라져도 비슷한 크기로 보인다. 심볼을 세어야 갈린다.

### 4.2 추적 중 겪은 것

원본으로 되돌려 빌드했는데 **크기가 그대로 나왔다.** PowerShell `Copy-Item` 이 원본의 `LastWriteTime` 을 함께 복사해 make 가 재컴파일을 건너뛴 것이다. `LastWriteTime` 을 갱신하고서야 제대로 나왔다.
