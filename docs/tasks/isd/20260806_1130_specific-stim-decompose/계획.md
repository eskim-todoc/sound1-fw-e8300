# 계획

**TL;DR**: 한 파일 재작성이라 단계를 나눌 수 없다. 대신 **작업 전 지표 기준선을 저장**하고, 재작성 후 대조한다. 불변량은 «지표 불변 또는 설명 가능 + `data`·`bss` 불변» 이다.

## 1. 변경

| 파일 | 성격 |
|---|---|
| `isd/tdc_isd_map_specific_stim.c` | **전면 재구성** (576줄 1함수 → 12함수) |

헤더는 바뀌지 않는다 — 외부에 노출되는 것은 `tdc_isd_map_specific_stim_step()` 하나 그대로다. **호출부(`tdc_ble_mapping.c:413`)도 무변경**이다.

## 2. 순서

| 단계 | 내용 |
|---|---|
| 1 | **지표 기준선 저장** (`metrics.sh --save`) |
| 2 | 파일 재작성 |
| 3 | 지표 대조 → 변화가 있으면 **크기까지 설명** |
| 4 | ARM 빌드 |
| 5 | 호스트 회귀 |

> [!IMPORTANT]
> **1이 2보다 먼저다.** 재작성 후에는 원본 지표를 다시 잴 수 없다(git 에서 꺼내면 되지만, 그 절차를 잊으면 대조를 건너뛰게 된다).

## 3. 불변량

**유형: 함수 추출 (조건 분기 총수 보존)**

| 항목 | 기대 |
|---|---|
| `case`·`switch`·`if`·`else`·`or`·`and` | **불변** |
| `for` | **변할 수 있다** - `case 5`·`case 7` 병합으로 4 → 2 |
| 호스트 | 514 PASS 유지 |
| ARM | 에러 0 · **경고 증가 0** |
| **`data`·`bss`** | **불변** - static 승격이 저장을 안 바꿨다는 증거 |
| `text` | **증가 예상** - 함수 호출 오버헤드. 수백 바이트면 정합 |

> [!NOTE]
> **`.elf` 바이트 동일을 기대하지 않는다.** 함수 경계가 생기므로 코드 생성이 달라진다.

## 4. 위험

| 위험 | 완화 |
|---|---|
| 재작성 중 로직 누락·오전사 | 지표 대조 + 구간별 원본 대조 |
| static 승격이 초기화 순서를 바꿈 | 초기값을 원본 그대로 옮긴다(`flowCounter = 0` · `TransferabelChannelNum = df_MaxNumTransferableChannel` · `cofigureDoneCounter = 100` · `pulseDurationNop_idex = 1` · `bipolarFIFO_index = 0`) |
| `pcm_index` 흐름이 끊김 | 분석 §4 |
| 실기 대기 8건 | 대장 등재 |

## 5. 실기 확인 항목

| 항목 | 확인 |
|---|---|
| **0x65 특정자극 - 모노폴라** | 자극이 나오는가. flow 1 의 +6 점프(3·5·7 생략)가 정상인가 |
| **0x65 특정자극 - 바이폴라** | 자극이 나오는가. flow 3·5·7 기준전극 전송이 정상인가 |
| 자극 유지시간 | 설정한 시간만큼 유지되고 정상 종료되는가 |
| 에러 로그 | 정상 동작에서 에러가 없을 것 |

> [!IMPORTANT]
> **모노폴라와 바이폴라를 둘 다 봐야 한다.** flow 1 이 모드에 따라 갈라져 **바이폴라만 3·5·7 을 거친다.** 한쪽만 확인하면 나머지 경로는 검증되지 않는다.
