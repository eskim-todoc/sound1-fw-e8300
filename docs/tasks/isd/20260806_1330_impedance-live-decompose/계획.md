# 계획

**TL;DR**: 파일마다 스크립트를 따로 쓴다. 예측치는 **impedance 전 지표 불변**, **live `return` +10 외 불변**이다.

## 1. 순서

| 단계 | 내용 |
|---|---|
| 1 | 파일별 기준선 저장 |
| 2 | impedance 추출 → 지표 대조 → 빌드 |
| 3 | live 추출 → 지표 대조 → 빌드 |
| 4 | 호스트 회귀 |

**impedance 를 먼저** 한다 - 폭발 반경이 작다(피팅 진단 vs 일상 청취).

## 2. 예측치

| 파일 | 지표 예측 | 근거 |
|---|---|---|
| `impedance` | **전부 불변** | 병합 없음. 반환값도 없어(`void`) `return` 도 안 는다 |
| `live` | **`return` +10, 나머지 불변** | 추출 함수 10개가 각각 `return` |

**다른 값이 나오면 원인을 찾을 때까지 커밋하지 않는다.**

크기: `text` **증가 예상**(호출 오버헤드), `data`·`bss` **불변**.

## 3. 스크립트 안전장치

| 장치 | 막는 것 |
|---|---|
| **전처리기 인식 중괄호 매칭** | 분석 §1.1 - 죽은 가지를 빼고 센다 |
| **블록 크기 상한 검사** | 경계가 틀려 `switch` 를 삼키면 중단 |
| **case 집합 대조** | 빠뜨리거나 더하면 중단 |
| **치환 시 멤버 제외** | 분석 §4 - 앞이 `.` 이나 `->` 면 넘긴다 |

## 4. 실기 확인 항목

| 대상 | 항목 |
|---|---|
| **impedance** | ① **전 채널 측정**(0x62 channel=255) ② **개별 채널 측정** ③ 측정값이 앱에 정상 표시 |
| **live** | ① 라이브 시작·정지 ② **자극 볼륨 조정** ③ **마이크 감도** ④ **자극 알림음** ⑤ 이퀄라이저 읽기 ⑥ 기기 상태 읽기 ⑦ **연결 끊김 후 재연결**(HoldOn 재설정 경로) |

> [!IMPORTANT]
> **live 는 하위명령이 10갈래라 전부 눌러 봐야 한다.** 각 갈래가 이제 별개 함수이므로 한둘만 보면 나머지가 미검증이다.
>
> 특히 **⑦ 재연결**은 `HoldOn` 의 `needResetting`·`reConnectionCounter` 를 거치는 경로라 평소에는 안 지나간다.
