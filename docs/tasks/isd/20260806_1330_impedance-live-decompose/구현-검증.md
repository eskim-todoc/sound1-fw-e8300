# 구현 검증

**TL;DR**: 완료 조건 5개 충족. **예측치와 정확히 일치** — impedance 전 지표 불변, live `return` +10 외 불변. **다만 도달까지 세 번 틀렸고 세 번 다 서로 다른 장치가 잡았다.**

## 1. 완료 조건

| # | 조건 | 결과 |
|---|---|---|
| 1 | 두 디스패처가 상태 표만 | **충족** |
| 2 | 지표가 예측대로 | **충족** - §2 |
| 3 | 호스트 514 PASS | **충족** |
| 4 | ARM 에러 0 · 경고 증가 0 | **충족** |
| 5 | `data`·`bss` 불변 | **충족** |

## 2. 구조 지표

### impedance - 전부 불변 (예측대로)

| 지표 | 전 | 후 |
|---|---|---|
| `case` | 9 | 9 |
| `switch` | 1 | 1 |
| `default` | 1 | 1 |
| `if` | 28 | 28 |
| `else` | 14 | 14 |
| `for` | 9 | 9 |
| `while` | 2 | 2 |
| `return` | 0 | 0 |

### live - `return` +10 외 불변 (예측대로)

| 지표 | 전 | 후 |
|---|---|---|
| `case` | 14 | 14 |
| `switch` | 2 | 2 |
| `default` | 0 | 0 |
| `if` | 39 | 39 |
| `else` | 26 | 26 |
| `for` | 4 | 4 |
| **`return`** | 1 | **11** (+10 = 추출 함수 수) |

## 5. 세 번 틀렸고 세 번 다 다른 것이 잡았다

| # | 실수 | 증상 | 잡은 것 |
|---|---|---|---|
| 1 | 전처리기 분기로 중괄호가 안 맞아 `case 0` 이 `switch` 전체를 삼킴 | 본문 490줄, 지표 전반 부풀음 | **구조 지표** |
| 2 | 이름 치환이 구조체 멤버까지 바꿈 | `has no member named 's_iterationNum'` | **컴파일러** |
| 3 | `startFlag` 블록에 여는 중괄호 포함 | `invalid storage class for function` | **컴파일러** |

> [!CAUTION]
> **1번은 컴파일러가 못 잡는다.** `case 1` 이하가 `case 0` 안에 중첩된 형태가 되어 문법상 성립할 수 있다. **구조 지표만이 잡는다.**
>
> 반대로 2·3번은 지표를 재기 전에 컴파일이 깨지므로 지표가 못 잡는다. **두 장치가 서로 다른 층을 본다.**
