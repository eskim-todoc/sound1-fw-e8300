## 축_2 - 논리 정합성

### 정합_1 - impedance 「전부 불변」이 정말 성립하는가

성립해야 한다. 병합이 없고, 코드를 옮기기만 하며, 반환값이 없어 `return` 도 늘지 않는다. **`while` 2개도 그대로다.**

**이것이 가장 엄격한 형태의 검증**이다. 어느 지표든 움직이면 무언가 잘못된 것이다.

### 정합_2 - 스크립트 안전장치가 분석의 함정을 전부 덮는가

| 분석이 지적한 함정 | 대응 장치 |
|---|---|
| §1.1 전처리기 중괄호 | 전처리기 인식 매칭 |
| §4 멤버 오치환 | 치환 시 `.`·`->` 제외 |
| §2.1 열거형 라벨 | 파일별 정규식 |
| §2.1 `default` 부재 | 디스패처에 임의로 넣지 않는다 |
| §2.1 인자 전달 | 추출 함수 시그니처에 `ISD_state` |

**덮는다.** 다만 **경계 지정(행 번호)은 사람이 적는다** - 그건 장치가 없다. 크기 상한 검사가 부분적으로 막는다.

### 정합_3 - live 실기 7항목이 과한가

과하지 않다. **분해 전에는 한 함수라 어느 갈래를 눌러도 같은 코드를 지나갔다.** 이제는 10개 함수로 갈렸으므로 갈래마다 독립적으로 확인해야 한다.
