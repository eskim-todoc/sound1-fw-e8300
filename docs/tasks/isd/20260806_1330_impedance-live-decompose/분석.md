# 분석

**TL;DR**: `impedance` 는 `flowCounter` 9상태 + `switch` 밖 71줄, `live` 는 `subCommand` 10갈래다. **파일마다 함정이 다르다** — `impedance` 는 전처리기가 중괄호를 쪼개고, `live` 는 열거형 라벨·인자 전달·`default` 부재가 걸린다.

## 1. impedance 구조

| 구간 | 줄 | 크기 |
|---|---|---|
| `startFlag` 리셋 | 74~92 | 19 |
| `case 0` | 97~218 | **117** |
| `case 1` | 219~239 | 16 |
| `case 2` | 240~268 | 24 |
| `case 4` | 269~382 | **109** |
| `case 6` | 383~388 | 1 |
| `case 8` | 389~447 | 54 |
| `case 10` | 448~515 | 63 |
| `case 12` | 516~521 | 1 |
| `case 14` | 522~585 | 59 |
| **`switch` 밖** | **591~661** | **71** |

`case` 번호는 1ms 경과 시간이다. 6·12 가 한 줄인 것은 **PCM 출력 모드만 바꾸고 하드웨어 응답을 기다리는 구간**이기 때문이다.

### 1.1 전처리기가 중괄호를 쪼갠다

`case 0` 안의 `#if 1`(163) / `#else`(186) / `#endif`(208) 이 문제다.

```
169: {        <- #if 1 가지에서 연다
192: {        <- #else 가지에서도 연다
209: }        <- #endif 뒤. 닫는 것은 하나뿐
```

**원시 텍스트만 세면 여는 것이 하나 많아 짝이 영영 안 맞는다.** 죽은 가지를 빼고 세야 한다.

> [!CAUTION]
> 이 사실을 모르고 추출하면 `case 0` 이 `switch` 전체를 삼킨다(490줄). 그래도 **컴파일은 통과할 수 있다** - `case 1` 이하가 `case 0` 안에 중첩된 형태가 되기 때문이다. 구조 지표만이 잡는다.

## 2. live 구조

| 하위명령 | 줄 |
|---|---|
| `en__allParameter` | 48 |
| `en__Start` | 86 |
| `en__StimulationVolumeAdjust` | 31 |
| `en__MicSensitivityAdjust` | 29 |
| `en__mapping_Stimul_indicator` | 45 |
| `en__readEqualizer` | 87 |
| `en__readDeviceStatus` | 30 |
| **`en__HoldOn`** | **285** |
| `en__Stop` | 17 |
| `en__Standby` | 22 |

`switch` 밖 블록은 없다. 앞의 `if (prev_subCommand != ...)` 은 진입 전 리셋이다.

### 2.1 impedance 와 다른 점 넷

| 항목 | 차이 |
|---|---|
| `case` 라벨 | **열거형 이름** (`en__HoldOn` 등). 정규식이 다르다 |
| `ISD_state` | **함수 인자**. 추출 함수에 넘겨야 한다 |
| 반환값 | `sitmulationIndicatorTrigger` - **한 갈래만 설정**(`stim_indicator`) |
| `default` | **없다**. 임의로 넣으면 지표가 바뀐다 |

### 2.2 `HoldOn` 285줄은 왜 남기는가

두 갈래로 보이지만 **뒷 갈래가 `#else` 안**이다(죽은 코드). 살아 있는 부분만 보면 그만큼 크지 않다.

죽은 `#else` 를 지우는 것은 **단계_1(죽은 코드 제거)** 의 몫이고 `#if 0`/`#else` 보존 여부는 은수님 판단이다. **지금 나누면 죽은 코드를 함수로 승격시키는 꼴**이라 그대로 둔다.

## 3. static 목록

| 파일 | 승격 대상 |
|---|---|
| `impedance` | 15개 - `flowCounter` · `electrodeNum` · `iterationNum` · DAC 4종 · `toggle_start_end_pulseWidth` · `mappingPacket` 등 |
| `live` | 10개 - `prev_subCommand` · `flowCounter` · `p_mappingPacket` · `needResetting` · `calculationParameter` 등 |

두 파일 사이에 이름 충돌은 없다(다른 파일이라 무관). **단계_4 와 달리 접두어는 `s_` 하나만 쓴다.**

## 4. 이름 치환의 함정

`impedance` 의 static `iterationNum` 은 **구조체 멤버와 이름이 같다**.

```c
static int iterationNum;                          // 파일 static
mappingPacket->impedanceCheck.iterationNum        // 남남
```

단순 `\bname\b` 치환은 **멤버까지 바꾼다**. 앞이 `.` 이나 `->` 면 넘겨야 한다.
