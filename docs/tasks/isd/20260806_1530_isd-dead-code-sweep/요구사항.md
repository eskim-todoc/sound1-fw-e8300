# 요구사항 - isd 죽은 코드 일괄 제거

**TL;DR**: 남은 7파일의 죽은 코드를 걷어낸다. **다만 «죽은 코드» 의 정의를 먼저 좁혀야 한다** — 앞선 계량이 조건부 컴파일의 비활성 가지까지 세고 있었다.

## 1. 배경

2026-08-06 은수님 *"전부 지워"*. ecap·live 에 이은 단계_1 마무리다.

## 2. 요구사항

### 요구사항_1 - «죽은 코드» 를 다시 정의한다

> [!CAUTION]
> **직전 보고의 «191줄» 은 두 가지를 섞은 수치다.**
>
> | 구분 | 지워도 되나 |
> |---|---|
> | **결정적 죽음** - `#if 0` · `#if 1` 의 `#else` | **된다.** 소스에 답이 박혀 있다 |
> | **조건부 비활성** - `#ifdef X` 등의 비활성 가지 | **안 된다.** 빌드 설정을 바꾸면 살아난다 |

**착수 전에 파일별로 갈라 세고, 조건부는 대상에서 뺀다.**

### 요구사항_2 - 검증이 도구와 전제를 공유하면 안 된다

ecap·live 에서 쓴 «살아 있는 줄 대조» 는 **조건부 `#if` 가 없는 파일에서만** 유효했다. 조건부가 있으면 도구와 검증이 같은 가정을 써서 서로의 실수를 못 본다.

**다른 각도에서 보는 독립 검증기가 필요하다.**

### 요구사항_3 - 검증기를 «알려진 버그» 로 먼저 시험한다

새 검증기가 통과했을 때 그것이 **«안전해서» 인지 «검증기가 무딘» 것인지** 구분할 수 없다. 일부러 틀린 결과를 만들어 잡히는지 본다.

### 요구사항_4 - `.text` 차이를 명령어 단위로 설명한다

## 3. 제약
