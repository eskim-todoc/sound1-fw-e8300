# 계획

**TL;DR**: 규칙을 «결정적만 지우고 조건부는 불가침» 으로 못 박고, **검증기를 버그본으로 먼저 시험한 뒤** 본 작업에 쓴다.

## 1. 제거 규칙

| 형태 | 조건부 밖 | 조건부 안 |
|---|---|---|
| `#if 0 ... #endif` | **지운다** | **지운다** (어느 설정에서도 안 산다) |
| `#if 1` 의 `#else` 가지 | **지운다** | 안 한다 |
| `#if 1` 언랩 (지시자만) | 지운다 | **안 한다** (검증 판정이 흐려진다) |
| 조건부 가지 내용 | - | **절대 안 지운다** |

## 2. 절차

| 단계 | 내용 |
|---|---|
| 1 | 파일별로 결정적/조건부를 갈라 센다 |
| 2 | 원본 7개 사본 |
| **3** | **검증기를 버그본으로 시험 - 잡히는지 확인** |
| 4 | 고친 스크립트 적용 |
| 5 | **독립 검증기로 파일별 확인** |
| 6 | ARM 빌드 |
| 7 | 원본 되돌려 빌드 → `.text` 추출 (타임스탬프 갱신) |
| 8 | 명령어 단위 디스어셈블 diff |
| 9 | 호스트 회귀 |

> [!IMPORTANT]
> **3단계가 4보다 앞선다.** 검증되지 않은 검증기로 본 작업을 확인하면 통과가 아무 뜻이 없다.

## 3. 예측

| 항목 | 예측 |
|---|---|
| 삭제 | 결정적 116줄 + 지시자 |
| `tdc_isd_fpga.c` · `stim_para_setting.c` | **변경 없음** (전부 조건부) |
| `text`·`data`·`bss` 크기 | **불변** |
| **바뀐 명령어** | **17개** (밀린 `__LINE__` 운반체 수) |
| 호스트 | 514 PASS |
| 실기 | **대기 불변** |

## 4. 위험

| 위험 | 완화 |
|---|---|
| 조건부 가지 삭제 (1차 결함 재발) | 규칙 + 독립 검증기 |
| 검증기가 무딤 | 3단계 버그본 시험 |
| 개행 변경 | 원본 개행을 감지해 그대로 쓴다 |
