# 요구사항 - map_live 죽은 코드 제거

**TL;DR**: `tdc_isd_map_live.c` 의 죽은 145줄을 걷어낸다. ecap 과 같은 절차이나 **전제 하나가 다르다** — 이 파일은 `TDC_PRINTF` 를 쓰므로 `__LINE__` 운반체가 더 많고 `.text` 차이도 커진다.

## 1. 배경

2026-08-06 은수님 — *"map_live 죽은 코드도 제거해"*. [ecap 제거](../20260806_1420_ecap-dead-code-removal/) 에 이은 단계_1 의 두 번째다.

**ecap 작업의 구현-검증 §6 이 미리 경고했다**: *"다른 파일에 같은 작업을 한다면 전제 하나가 깨진다. map_live 등은 TDC_PRINTF 를 쓰므로 매크로 안에 숨은 `__LINE__`(자산_1)까지 세어야 하고 그만큼 `.text` 차이가 커진다."*

## 2. 요구사항

### 요구사항_1 - 컴파일되지 않는 것만 지운다

ecap 과 같은 규칙. **조건부 `#if`/`#ifdef` 는 건드리지 않는다.**

### 요구사항_2 - 살아 있는 줄 불변을 증명한다

스크립트 내장 대조. 어긋나면 파일을 쓰지 않는다.

### 요구사항_3 - `.text` 차이를 **명령어 단위로** 설명한다

> [!CAUTION]
> ecap 은 차이가 2바이트라 값 비교만으로 설명됐다. **여기는 더 많을 것이므로 바이트 값만 맞춰 보면 우연의 일치를 걸러낼 수 없다.**
>
> **차이가 난 주소를 디스어셈블해 «이 명령어가 `__LINE__` 을 싣는다» 를 확인한다.**

### 요구사항_4 - 예측치와 실제가 다르면 원인을 찾는다

예측보다 **적게** 나와도 넘기지 않는다. 적은 것도 예측이 틀렸다는 뜻이다.

## 3. 제약

| # | 제약 |
|---|---|
| 제약_1 | 살아 있는 코드 무변경 |
| 제약_2 | 조건부 `#if` 유지 |
| 제약_3 | 함수 구조는 건드리지 않는다 (분해는 별건) |
