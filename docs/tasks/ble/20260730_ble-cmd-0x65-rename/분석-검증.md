# 분석 검증 - BLE 0x65 계층 네이밍 개명

## 2. 축_2 - 논리 정합성

| 과거 작업 기록 | **52** | **48** |

**원인 2건**:

| # | 원인 | 정정 |
|---|---|---|
| 오류_1 | **자기 폴더를 총계에 포함했다.** 분석 문서를 쓰는 동안 이번 작업 폴더의 참조가 20 -> 34 로 계속 늘어 총계가 77 -> 91 로 움직였다 | 집계 기준을 **자기 폴더 제외**로 고정. 57 은 고정값 |

> [!NOTE]
> **자기 참조 집계의 함정.** 개명 작업의 문서는 구 이름을 반드시 인용하므로, `grep` 총계를 지표로 쓰면 **문서를 쓰는 행위 자체가 지표를 움직인다.** 완료 기준(기준_1)이 이 함정에 걸리지 않는지 확인했다 - 기준_1 은 `src/` + `tests/` 만 대상이라 무관하다. **문서 기준은 별도로 "카탈로그 1건 갱신"만 판정**한다.

**주 불변량 단독으로는 상수 오타를 못 잡는다.** 보조 지표 3종이 그 틈을 덮는 구조가 정합함을 확인했다.
