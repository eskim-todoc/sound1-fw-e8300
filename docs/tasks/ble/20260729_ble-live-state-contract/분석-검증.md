## 검증 축 3 - 근거 검증

### 3.1 실측 확인

| 서술 | 방법 | 판정 |
|---|---|---|
| 게이트 4곳이 동일 골격 | 함수별 `awk` 추출 후 대조 | **확인** - 인자 · 순서 · 부수효과 동일 |
| 유일한 차이가 호출 줄바꿈 | `sed` 로 `else` 블록 원문 출력 | **확인** - `sub04` 만 한 줄, 나머지 3개는 `__LINE__` 이 둘째 줄 |
| `sub03` 의 `__LINE__` = 574 | `:571~578` 원문 - `else`(571) `{`(572) 호출(573) `__LINE__`(574) | **확인** |
| `sub04` 의 `__LINE__` = 605 | `:603~608` 원문 - 한 줄 호출 | **확인** |
| **네 함수 모두 `else` 가 마지막 블록** | 각 함수 끝 5줄 출력 - `else` 닫는 `}` 다음이 바로 함수 끝 `}` | **확인** (`:578`·`:608`·`:699`·`:755`) |
| 게이트 위치 4곳 | `grep -n` | 확인 (`:554`·`:587`·`:624`·`:709`) |
| 본문 안 별도 `Standby` 복귀 | `awk` 집계 | 확인 - `sub05` 2곳 · `sub06` 2곳 |

**위험_4 가 해소됐다.** `else` 가 마지막 블록이므로 게이트를 조기 반환으로 바꿔도 뒤에 빠뜨릴 코드가 없다. 본문을 그대로 왼쪽으로 당기면 된다.
