### 3.2 미결_4 의 전제 확정

요구사항 미결_4 는 "현재 게이트 테스트가 하위 3·4 만 덮는다"를 전제로 한다. 실측했다.

| 테스트 그룹 | 커버 |
|---|---|
| `0x66 하위 3 자극 볼륨 - 선행 상태 HoldOn 요구` | 하위 3 게이트 (거부 · 수락 양쪽) |
| `0x66 하위 4 마이크 감도 - 선행 상태와 범위` | 하위 4 게이트 |
| **하위 5 알림 자극** | **없음** |
| **하위 6 이퀄라이저 읽기** | **없음** |

**게이트 4곳 중 2곳이 검증 밖이다.** 단계_3 착수 때 데이터 인덱스 2~15 가 커버리지 0 이었던 것과 같은 구도다. 가드를 공통 함수로 바꾸면 **4곳이 한 함수에 수렴하므로**, 그 함수가 틀리면 4곳이 동시에 깨진다. 테스트 선행이 단계_3 보다 더 중요하다.
