### 보완 지시_1 - 검증_3 의 기준을 고칠 것

계획 §4 검증_3 은 "조건 분기 총수가 전환 전후 동일"을 기준으로 삼았으나, **가드 추출은 총수를 줄인다**(8 -> 5). 4개의 `if/else` 쌍이 가드 하나로 수렴하는 것이 이 작업의 목적 자체이므로 감소가 정상이다.

**수정된 기준**:

| 지표 | 기대 |
|---|---|
| `en__HoldOn` 비교 | 4 -> **1** (가드 안 한 곳) |
| `en__Command_Order` 전송 | 4 -> **1** |
| 게이트 실패 시 `Standby` 복귀 | 4 -> **1** |
| **본문 안 `Standby` 복귀** | `sub05` 2 + `sub06` 2 = **4 유지** (범위 검사용, 건드리지 않음) |
| 그 외 본문의 `if`·`else`·`for` | **전부 유지** |

즉 "총수 동일"이 아니라 **"게이트 관련은 4->1 로 수렴, 본문은 불변"** 이 정확한 불변량이다. 단계 ⑦ 구현 시 이 표로 대조한다.
