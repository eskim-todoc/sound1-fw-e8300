## 2. 변경 요약

### 2.1 대상

- 파일: `src/2__cm3/Cortex-M3-src/BleCommunication/ci_ble_control_boot.c`
- 함수: `_fetch_packet_boot_select()` (OTA DFU 후 부팅 슬롯 선택 패킷 처리·재부팅)
- 변경: +15/-15

### 2.2 시퀀스 (변경 후)

1. 응답 패킷 송신 (`_send_resp_packet_boot`)
2. **신규**: 20 ms 워치독 리프레시 + 대기 (응답 송신 완료 시간 확보)
3. **신규**: `snd_qcc_set_mode(SND_QCC_MODE_SHUTDOWN)` 호출 (QCC_CTRL = 0 유지)
4. **변경**: 2.2 초 대기 (2200 × 1 ms, 워치독 리프레시 매회) — QCC 안정 절전 진입 시간 (사양 ≥ 2 초)
5. `SYS_WATCHDOG_RESET()` — Ezairo 재부팅

### 2.3 변경 전 대비

| 단계 | 변경 전 | 변경 후 |
|---|---|---|
| 응답 송신 대기 | 없음 | 20 ms |
| QCC 절전 명령 | 없음 | `snd_qcc_set_mode(SHUTDOWN)` |
| 주 대기 | 100×10 ms = 1 초 | 2200×1 ms = 2.2 초 |
| 워치독 주기 | 10 ms | 1 ms |
| 신규 include | — | `<snd_qcc.h>` |

### 2.4 의도

사용자(다) 명시 — "OTA DFU 펌웨어 업데이트 후 Ezairo 재부팅 전에 QCC 를 절전 모드로 진입 시킨 후 재부팅". 효과: ① 재부팅 후 QCC 비활성 → 전력 절약, ② Ezairo 재시작 시 QCC 와의 race condition 회피, ③ 응답 송신 완료 보장.
