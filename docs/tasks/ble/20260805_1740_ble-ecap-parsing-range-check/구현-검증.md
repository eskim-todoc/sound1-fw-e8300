# 구현 검증 - 0x63·0x64 eCAP 파싱 범위 검사

## 2. 검증 지표 - 사전 예측 대조

> [!IMPORTANT]
> **6종 전부 일치.** 방어 추가 유형의 불변량 «정상 경로 불변 + 예측된 분기만 증가» 가 성립했다.

| 지표 | 기준선 | 커밋_1 후 (예측) | 커밋_2 후 (예측) | 실측 | 판정 |
|---|---|---|---|---|---|
| `^\s*if \(` | 5 | 16 (16) | 24 (24) | **24** | **일치** |
| `^\s*else` | 0 | 1 (1) | 2 (2) | **2** | **일치** |
| `\|\|` (주석행 제외) | 1 | 10 (10) | 16 (16) | **16** | **일치** |
| `&&` (주석행 제외) | 5 | 5 | 5 | **5** | **불변** |
| `^\s*return` | 1 | 1 | 1 | **1** | **불변** |
| `fetched_command *=` | 3 | 3 | 3 | **3** | **불변** |

**뒤 세 지표가 0x62 무변경의 증거다.** `&&` 5개와 조기 `return` 1개는 0x62 임피던스에만 있는 것이고, `fetched_command =` 는 함수마다 정확히 하나여야 한다. `git diff` 에 `impedance` 를 포함한 라인이 **0건**인 것으로 교차 확인했다.

### 지표 오염 방지 (이월_I 대응)

이번 코드는 블록마다 한글 주석을 다는 형태라 이월_D 에서 겪은 «주석이 지표를 오염» 함정에 그대로 노출된다. **전 지표를 행 앵커(`^[[:space:]]*`)와 주석행 제외(`grep -vE '^[[:space:]]*(//|/\*|\*)'`)로 측정**했다. 신규 주석에 `if` · `else` · `||` 가 들어가지 않도록 작성 시 통제했다.

### 3.1 과잉 차단 검출 (노하우_5 - 실기 대체)

실기가 불가하므로 «정상 입력에서 방어가 걸리지 않을 것» 을 호스트 테스트가 대신했다.

| 확인 | 케이스 |
|---|---|
| 정상 패킷 전 필드 적재 | 0x63 14필드 · 0x64 7필드 값 단언 + `에러 0` |
| 각 필드 하한 통과 | 부등호 반전 검출 |
| 각 필드 상한 통과 | 상한 off-by-one 검출 |
| 미검사 필드는 255 도 통과 | 의도치 않은 검사 추가 검출 |

**`if (x < 1)` 을 `if (x <= 1)` 로 잘못 쓰면 «하한 1 통과» 케이스가 즉시 깨진다.** 정적 지표로는 못 잡는 오류다.

### 3.2 OOB 차단 전용 케이스

`255` 를 두 전극 필드에 넣어 거부되는지 각각 확인했다. `electrodeMap[254]` 가 `s_manu_table` 을 침범하던 바로 그 입력이다. **거부 시 `fetched_command` 가 `en__mapping_IDLE` 로 남는 것까지 단언**했다 — 이것이 `isd/` 도달을 막는 실제 기전이다(분석 §1).

### 3.3 시험하지 못한 경계 (은폐 금지)

`uint8_t` 페이로드라 패킷에 실을 수 없는 경계가 있다.

| 필드 | 시험 불가 경계 | 이유 |
|---|---|---|
| `iterationNum` · `pulseWidth` | 상한 255 의 «+1» | 256 을 1바이트에 못 싣는다 |
| `firstPulsePhase` · `adcSamplingFreq` · `adcMeasurementDelay` | 하한 0 의 «-1» | 음수를 못 싣는다 |

**해당 검사식은 죽은 코드다**(계획-검증 확인_1 에서 0x65 형태 일치를 위해 의도적으로 유지하기로 판단). 실행 경로가 없으므로 오류가 잠복할 여지도 없다.
