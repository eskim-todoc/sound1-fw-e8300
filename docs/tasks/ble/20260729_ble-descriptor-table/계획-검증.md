## 검증 축 3 - 근거 검증

### 3.1 경계 상수 다중집합 검산 - 계획 §7.1 과 완전 일치

계획이 예고한 다중집합을 분석 §1.1~1.3 표에서 손으로 세어 대조했다.

**하한(min) 23개**

| 값 | 출처 | 개수 |
|---|---|---|
| 1 | 유형_A 6개(`stimulVolume`·`audioVolume`·`indicatorChannel`·`strategy`·`mode`·`numFreqBand`) + 유형_B 6개 | **12** |
| 0 | 유형_A 2개(`indicatorAmplitude`·`firstPulsePhase`) + 유형_C 8개 | **10** |
| 13 | 유형_A `pulsePhaseWidth` | **1** |
| **합계** | | **23** |

**상한(max) 23개**

| 값 | 출처 | 개수 |
|---|---|---|
| 1800 | 유형_A `indicatorAmplitude` 1 + 유형_C 8 | **9** |
| 100 | 유형_B 6 | **6** |
| 32 | `indicatorChannel`·`numFrequencyBand` | **2** |
| 4 · 10 · 3 · 6 · 1 · 255 | `stimulVolume`·`audioVolume`·`strategy`·`mode`·`firstPulsePhase`·`pulsePhaseWidth` | **각 1 = 6** |
| **합계** | | **23** |

**총 46개 상수가 엔트리 23개 x 2 와 정확히 맞는다.** 계획 §7.1 의 예상 표와 일치하며, 검증_5(전환 전후 다중집합 비교)의 기준값으로 확정한다.

### 3.2 정정 - 예상 줄수가 낙관적이었다

| 항목 | 초안 | 재산정 | 사유 |
|---|---|---|---|
| 대상 함수 | 60~80줄 | **90~100줄** | 전처리 30줄 + 후처리 47줄 = **77줄이 무변경**인데 초안은 "81줄"로 뭉뚱그린 뒤 총합을 과소 추정 |
| 새 코드 | 70줄 | **140줄** | 타입·매크로·단언을 계산에 넣지 않았다 |
| 파일 전체 | 550줄 | **660~680줄** | 위 둘의 귀결 |

**정정의 함의**: 파일 줄수 감소가 21% 로 크지 않다. 계획 §10 에 **"성과는 줄수가 아니라 분기 밀도"** 임을 명시하는 `[!IMPORTANT]` 를 추가했다. 대상 함수는 여전히 409 -> 약 95줄(**77% 감소**)이고, 신규 140줄 중 약 90줄은 **분기 없는 선언적 데이터**다.

> [!NOTE]
> 요구사항 기준_5("대상 함수 줄수 유의미 감소")는 **함수 기준**이므로 정정 후에도 충족된다. 파일 전체 줄수는 애초에 기준이 아니었다.
