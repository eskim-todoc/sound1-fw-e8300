## 완료 요약

**결과**: `remoteControl.c`의 `case EN__SND_BT_CMD_GENERAL_DEBUG`(0x8F) 처리 로직을 신규 `tdc_remote_general_debug.c/.h`로 분리 완료. 동작 동일 리팩토링.

**변경 파일 (3)**:
- `src/2__cm3/Cortex-M3-src/BleCommunication/tdc_remote_general_debug.h` (신규) — 공개 API `int tdc_remote_general_debug_handle(int *tx_buf, int tx_index);`
- `src/2__cm3/Cortex-M3-src/BleCommunication/tdc_remote_general_debug.c` (신규) — 진입 함수 + `gd_handle_touch_debug`/`gd_handle_no_backtel`/`gd_handle_map_init` static 3개
- `src/2__cm3/Cortex-M3-src/BleCommunication/remoteControl.c` — `#include "tdc_remote_general_debug.h"` 추가 + case 블록 108→8줄 축약

**설계 확정**:
- 시그니처 `int tdc_remote_general_debug_handle(const ST__REMOTECONTROL_PACKET *packet, int *tx_buf, int tx_index)` (갱신된 tx_index 반환). 패킷을 인자로 주입받아 **전역 의존 없이 독립 수행**(초기 `extern` 방식에서 은수님 제안으로 개선).
- case는 `tx_index = tdc_remote_general_debug_handle(&remoteDataPacket, bufferForSPI_tx, tx_index);` + `writeDataToSpiTxBuff` + `clearRemoteColtrolCommand` 잔류.

**검증 (전수 PASS)**:
- 회귀 노드: option 1/2/3/else 응답 바이트 순서·값·비트마스킹(`>>8 & 0x00FF`)·부수효과(OTA DFU CONN/DISCONN 분기, `ci_map_init_map_data` 4회 인자·순서, `SYS_WATCHDOG_REFRESH` 4회)·로그 문자열 100% 동일 → 회귀 없음.
- 컴파일 정합성 노드: include 경로 해결(tdc_touch.h·ci_ble_control_ota.h·ci_map.h·ci_printf.h·hw.h 전부), 심볼 선언·시그니처 일치, `extern` 타입 정합, 중복 정의/case 0 → PASS.
