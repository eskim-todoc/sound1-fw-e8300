# 요구사항 — 범용 디버깅 프로토콜 파일 분리

**TL;DR**: `remoteControl.c`(1627줄)의 `case EN__SND_BT_CMD_GENERAL_DEBUG`(1339~1446행)에 구현된 범용 디버깅 프로토콜(option 1/2/3) 처리 로직을 `tdc_remote_general_debug.c/.h` 별도 파일로 분리한다. case 블록은 함수 1회 호출 + SPI TX 기록 + 명령 종료로 간결화한다. 기존 동작을 그대로 보존한다(동작 동일 리팩토링).

## 배경

`remoteControl.c`가 1627줄로 비대해지고 있고, 은수님이 현재 구현 중인 범용 디버깅 프로토콜(`EN__SND_BT_CMD_GENERAL_DEBUG` = 0x8F) 처리 코드가 계속 늘어날 예정이다. 이 프로토콜 처리만 `tdc_` 접두어 파일로 분리해 파일 비대화를 막고 관심사를 분리한다.

## 요구사항 목록

- **요구사항_1**: `Cortex-M3-src/BleCommunication/` 폴더에 `tdc_remote_general_debug.c` / `tdc_remote_general_debug.h` 신규 생성.
- **요구사항_2**: 현재 case 블록의 option 1/2/3 로직을 새 파일로 **그대로 이전**하되, option별 `static` 헬퍼 함수로 분리 리팩토링한다(동작 동일).
- **요구사항_3**: 진입 함수 시그니처는 `int tdc_remote_general_debug_handle(int *tx_buf, int tx_index)` — 갱신된 `tx_index`를 반환. `remoteDataPacket`은 `extern` 전역 접근.
- **요구사항_4**: `remoteControl.c`의 case 블록을 아래 목표 형태로 축약한다.
  ```c
  case EN__SND_BT_CMD_GENERAL_DEBUG:
  {
      tx_index = tdc_remote_general_debug_handle(bufferForSPI_tx, tx_index);
      writeDataToSpiTxBuff(bufferForSPI_tx, tx_index);  // 송신 데이터 SPI TX버퍼에 복사
      clearRemoteColtrolCommand();                      // 명령 종료
  }
  break;
  ```
- **요구사항_5**: 최신 `tdc_` 파일 컨벤션(`tdc_touch_logic`) 준수 — 헤더가드 `TDC_REMOTE_GENERAL_DEBUG_H_`, 한글 블록 주석, Doxygen 미사용, snake_case, Allman 브레이스.
- **요구사항_6**: 빌드 통합 — `.cproject`는 `Cortex-M3-src` 폴더 단위 등록이라 수정 불필요. 파일만 올바른 폴더에 배치.

## 비범위 (Out of scope)

- 프로토콜 **기능 자체의 변경·확장**은 하지 않는다(향후 은수님이 새 파일에서 진행). 본 작업은 순수 분리 리팩토링.
- option 1/2/3의 로직·응답 바이트 포맷은 **그대로 보존**(동작 변경 금지).
- `Debug/` 폴더의 자동생성 `subdir.mk`는 git 비추적 산출물 — 커밋 대상 아님(Eclipse 재생성).

## 완료 기준

- `tdc_remote_general_debug.c/.h` 생성 + case 블록 목표 형태로 축약 완료.
- 분리 전후 응답 바이트 포맷·동작이 동일함을 코드 diff로 검증(회귀 없음).
- 빌드 컨벤션·네이밍·스타일 검증 노드 통과.
