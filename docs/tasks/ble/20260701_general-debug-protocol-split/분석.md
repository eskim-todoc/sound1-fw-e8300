# 분석 — 현황 및 의존 관계

**TL;DR**: 서브에이전트 2노드 병렬 조사로 case 블록 구조·의존 심볼 원형·빌드 통합 방식을 확정했다. 핵심 제약은 `bufferForSPI_tx`·`tx_index`가 **함수 지역 변수**라 인자 전달이 필요하고, `remoteDataPacket`은 전역이라 `extern` 접근 가능하다는 점. `.cproject`는 폴더 단위 등록이라 빌드 통합에 수정이 불필요하다.

## 1. 대상 파일·위치

- 대상: `src/2__cm3/Cortex-M3-src/BleCommunication/remoteControl.c` (1627줄)
  - (동명 파일 `Sullivan1_5__CM3`·`2__cm3_factory`에는 GENERAL_DEBUG case 없음 → 대상 아님)
- 신규 파일 위치: 같은 `Cortex-M3-src/BleCommunication/` 폴더

## 2. case 블록 구조 (remoteControl.c:1339~1446)

`#if 1 ... #endif`로 감싼 `case EN__SND_BT_CMD_GENERAL_DEBUG:` 블록. 은수님이 이미 구현:

| option | 의미 | 핵심 동작 | 응답 바이트 |
|---|---|---|---|
| 1 | 터치센서 디버깅 | `tdc_touch_debug_get_recent_*()` 7종 조회 | command + option + lta(2) + count(2) + delta(2) + abs_thr(2) + pressed + ati_error + ati_active = 13B |
| 2 | 백텔 체크 무시 | `data[1]`로 `tdc_set_ota_dfu_conn_state()` CONN/DISCONN | command + option + noBacktel_mode = 3B |
| 3 | 맵 초기화 | `data[1]`(RL)로 `ci_map_init_map_data()` 4회 + `SYS_WATCHDOG_REFRESH()` | command + option + RL = 3B |
| else | 미지정 | command loop-back만 | command = 1B |

- 공통 마무리: `writeDataToSpiTxBuff(bufferForSPI_tx, tx_index)` + `clearRemoteColtrolCommand()`.
- 진입점: `remoteControl(bool isdConnection)` (647행) 내 `switch (remoteDataPacket.command)` (804행).

## 3. 의존 심볼 원형

| 심볼 | 정의 위치 | 원형/특성 |
|---|---|---|
| `remoteDataPacket` | remoteControl.c:23 (전역) | `ST__REMOTECONTROL_PACKET`, `.command`·`.data[19]`(int) — **전역, extern 접근 가능** |
| `bufferForSPI_tx` | remoteControl.c:654 (**지역**) | `int[BLE_DataPacketSize=20]` — **인자 전달 필요** |
| `tx_index` | remoteControl.c:656 (**지역**) | `int`, 0 초기화, `buf[tx_index++]` 누적 — **인자 전달 + 반환 필요** |
| `writeDataToSpiTxBuff` | driver_SPI.h:55 | `void writeDataToSpiTxBuff(int *source, int dataSize)` |
| `clearRemoteColtrolCommand` | remoteControl.h:48 | `void (void)` — 전역 remoteDataPacket 직접 조작 |
| `EN__SND_BT_CMD_GENERAL_DEBUG` | ble_commonProtocol.h:115 | enum `= 0x8F` |

## 4. 설계 결론 (은수님 승인 반영)

- **로직 처리**: 그대로 이전 + option별 static 함수 분리.
- **시그니처**: `int tdc_remote_general_debug_handle(int *tx_buf, int tx_index)` 반환형. `remoteDataPacket`은 `extern` 전역 접근.
- 데이터 흐름: 새 함수가 `tx_buf`에 응답을 채우고 최종 `tx_index`를 반환 → 호출부에서 `tx_index = tdc_remote_general_debug_handle(...)` 대입 → 기존 관용구(`writeDataToSpiTxBuff`·`clearRemoteColtrolCommand`)는 case에 잔류.

## 5. 빌드 통합 방식

- `.cproject`(src/2__cm3/.cproject:129~137)의 `sourceEntries`가 `Cortex-M3-src`를 **폴더 단위**로 등록 → 새 파일을 폴더에 두면 자동 인식, **`.cproject` 수정 불필요**.
- `Debug/Cortex-M3-src/BleCommunication/subdir.mk`는 Eclipse Managed Build가 재생성하는 **git 비추적**(`.gitignore`: `Debug`) 자동생성물 → 커밋 대상 아님. Eclipse Refresh(F5)+Build로 반영.
- 커맨드라인 make만 쓰는 경우에 한해 `subdir.mk`의 `C_SRCS/OBJS/C_DEPS` 수동 추가 필요(로컬 한정, 비커밋).

- 자체 헤더 최우선 include → 표준 라이브러리 → 프로젝트 헤더(`""`).
