# 입출력 계약표 - 추출 함수

**TL;DR**: `fetch_packet` 에서 추출한 각 함수가 무엇을 읽고 무엇을 바꾸는지 명시한다. 전역·static 접근이 많아 시그니처만으로는 계약이 드러나지 않으므로, **읽기/쓰기 대상을 전수 기재**한다. 수용_1b_3 의 산출물이다.

## 0. 공통 계약

| 항목 | 내용 |
|---|---|
| 입력 | `const uint8_t *Rx_dataPacket` - 수신 패킷 21바이트. **인덱스 0 은 명령 헤더로 호출자가 이미 읽었다.** 각 함수는 인덱스 1(`df_payloadStartIndex`)부터 파싱한다 |
| 반환 | `void` - 응답 송신까지 함수 안에서 완결 |
| 공유 상태 | `mappingPacket` 은 **`tdc_ble_mapping_get_packet()`** 으로 접근 (포인터 반환, 쓰기 가능) |
| 에러 응답 | `tdc_sys_error_send_to_app(command, majorError, minorError, __LINE__)` |

> [!IMPORTANT]
> **`__LINE__` 은 에러 응답 패킷의 5·6번째 바이트로 앱에 전송된다**(`tdc_sys_error.c:168-169`). 함수를 추출하면 라인 번호가 바뀌므로 **에러 응답의 이 2바이트는 값이 달라진다.** 에러 분류는 앞선 `majorError`/`minorError` 가 담당하고 라인 번호는 발생 위치 표시용이므로 동작에는 영향이 없다고 판단했다. 검증 시 이 2바이트는 대조에서 제외한다.

## 1. measure 그룹 (`tdc_ble_map_measure.c`) - 1b-1

원본: `tdc_ble_mapping.c` (추출 전) `:129`~`:219`

### 1.1 `tdc_ble_map_measure_impedance_check` (0x62)

| 구분 | 대상 |
|---|---|
| 패킷 읽기 | 인덱스 1~6 (6바이트) |
| **쓰기** | `mappingPacket.impedanceCheck.{iterationNum, channel, pulseWidth_start_usec, pulseWidth_end_usec, stimulationLevel_uA}` |
| **쓰기** | `mappingPacket.fetched_command` = `en__mapping_impedanceChekck` (전 범위 검사 통과 시에만) |
| 범위 검사 | `iterationNum` 1~255 · `channel` 1~32 또는 255 · `pulseWidth_start_usec` 13~255 · `pulseWidth_end_usec` 13~255 · `stimulationLevel_uA` 1~1024 |
| 실패 시 | `tdc_sys_error_send_to_app(0x62, en__EN__BLE_PROTOCOL_ERROR, en__OutOfDataRange, __LINE__)` |
| 공유 static | **없음** |
| 원본 대비 | 중첩 if 통과 시 `break` -> `return` 으로 전환 (조기 탈출 의미 동일) |

### 1.2 `tdc_ble_map_measure_ecap_masking` (0x63)

| 구분 | 대상 |
|---|---|
| 패킷 읽기 | 인덱스 1~16 (16바이트) |
| **쓰기** | `mappingPacket.eCapMeasurement.{iterationNum, pulseWidth, firstPulsePhase, stimulatonMode, stimulationElectrodeNum, bipolarReferenceElectrodeNum, measurementElectrodeNum, stimulationLevel_uA_masker, stimulationLevel_uA_probe, maskerProbeInterval_numFrame, adcPreampGain, adcSamplingFreq, adcMeasurementDelay, measurementSampleNum}` |
| **쓰기** | `mappingPacket.fetched_command` = `en__mapping_eCAP_Measurement_masking` (무조건) |
| 범위 검사 | **없음** (원본에도 없다) |
| 공유 static | **없음** |

### 1.3 `tdc_ble_map_measure_ecap_alternative` (0x64)

| 구분 | 대상 |
|---|---|
| 패킷 읽기 | 인덱스 1~8 (8바이트) |
| **쓰기** | `mappingPacket.eCapMeasurement.{iterationNum, pulseWidth, stimulatonMode, stimulationElectrodeNum, bipolarReferenceElectrodeNum, measurementElectrodeNum, stimulationLevel_uA_masker}` |
| **쓰기** | `mappingPacket.fetched_command` = `en__mapping_eCAP_Measurement_alternative` (무조건) |
| 범위 검사 | **없음** |
| 공유 static | **없음** |

> [!NOTE]
> 0x63 과 0x64 는 **같은 `eCapMeasurement` 구조체를 쓰되 채우는 필드가 다르다.** 0x64 는 `firstPulsePhase`·`stimulationLevel_uA_probe`·`maskerProbeInterval_numFrame`·`adc*` 4종을 건드리지 않으므로 **직전 0x63 의 값이 남는다.** 원본과 동일한 동작이며 이 작업에서 바꾸지 않았다.

### 1.4 호출자 측 변경

`tdc_ble_mapping.c` 의 case 3개가 함수 호출로 대체됐다. `index`·`value` 지역 변수는 다른 case 가 계속 쓰므로 선언을 유지했다.

```c
case en__mapping_impedanceChekck:  // 0x62
{
    tdc_ble_map_measure_impedance_check(Rx_dataPacket);
}
break;
```
