### 정정 사항

| # | 위치 | 내용 |
|---|---|---|
| 정정_1 | 전 문서의 줄 수 | **측정 도구 오류.** PowerShell `Get-Content \| Measure-Object -Line` 은 **빈 줄을 세지 않는다.** 이 값을 물리 줄 수로 오인해 전 문서에 기록했다. LF 개수 기준 재실측으로 확정 |

> [!CAUTION]
> **측정 노하우 - `Measure-Object -Line` 을 줄 수로 쓰지 말 것.** 빈 줄이 빠져 실제보다 **최대 20% 이상 적게** 나온다. 물리 줄 수는 LF 개수로 세야 한다.
>
> ```powershell
> $raw = [System.IO.File]::ReadAllText($path)
> $lines = ([regex]::Matches($raw, "`n")).Count + $(if ($raw.EndsWith("`n")) { 0 } else { 1 })
> ```
>
> 이 오류는 서브에이전트 노드 03·05 가 각각 독립적으로 실측해 정정해 왔다. **노드 산출물이 오케스트레이터의 사전 브리핑을 반증한 사례**로, 2차 리팩토링 노하우_4("도구를 먼저 의심하라")가 이번에도 적중했다.
