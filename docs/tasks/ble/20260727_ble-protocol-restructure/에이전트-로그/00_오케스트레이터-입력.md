# 00 오케스트레이터 입력

**TL;DR**: ③ 분석을 7노드 병렬 fan-out 으로 수행한다. 축은 프로토콜 카탈로그 · 디스패치 경로 · 매핑 핸들러 골격 · **라이브모드 심층** · 리모콘 및 기타 핸들러 · 실측 로그 디코딩 · 인접 모듈 결합도. 전 노드 **읽기 전용**(코드 변경 금지)이며 `파일:라인` 근거를 의무화한다.

## 1. 오케스트레이터가 사전 파악한 사실

fan-out 프롬프트를 정확히 쓰기 위해 오케스트레이터가 직접 확인한 내용이다. 노드에는 이 사실을 **가설이 아닌 확인된 출발점**으로 제공한다.

## 3. 전 노드 공통 제약 (프롬프트에 삽입)

1. **읽기 전용.** 소스 코드(`src/`)를 절대 수정하지 않는다. Edit/Write 는 자기 로그 파일에만 사용한다.
2. **`파일:라인` 근거 의무.** 사실 주장마다 근거를 단다. 근거를 못 찾으면 "미확인"으로 표기하고 추측과 구분한다.
3. **BLE 프로토콜 정의는 미참조여도 제거 제안 금지** (`docs/참고/cm3-소스-트리-규약.md §2.1`).
4. **결과를 지정된 로그 파일에 직접 `Write` 한다.** 응답 본문에만 쓰고 끝내지 않는다.
5. 문서는 GFM + frontmatter(`name`/`purpose`/`type`/`tags`) + TL;DR. 다이어그램은 **Mermaid**(ASCII 금지). 라벨은 한글 + `_번호`(`발견_1`), 알파벳 약어(`F1`) 금지.
6. 모델 `sonnet`, effort 미지정(세션 상속) - 루트 지침 §5.
