# 에이전트 로그 인덱스

**TL;DR**: ③ 분석을 7노드 병렬 fan-out 으로 수행했다. 전 노드 완료. **노드 간 독립 교차 검증이 4건 성립**했고, 그중 하나는 **노드가 오케스트레이터의 사전 브리핑을 반증**한 건이다(줄 수 오측). 오케스트레이터가 직접 재검증한 항목 7건은 §3 에 기록한다.

## 2. 노드 간 교차 검증 (독립 도달)

서로 다른 노드가 **서로 모르는 상태에서 같은 결론**에 도달한 항목이다. 신뢰도가 가장 높은 발견들이다.

| # | 발견 | 독립 확인 노드 |
|---|---|---|
| 교차_1 | `en__mapping_testStimulation`(0x90) 은 디스패처가 매핑으로 라우팅하지만 핸들러 case 가 없다 | 01 · 03 · 07 (3중) |
| 교차_2 | 0xA0~0xAF(믹싱 게인) 대역은 CM3 코드에 실재하지 않는다. 게인 제어는 0x8C 전담 | 01 · 05 |
| 교차_3 | RX 패킷 `[20]` 은 유효 데이터가 아니다(배열 20원소 초과 접근). 전 로그에서 `01` 고정 | 02 · 06 + 오케스트레이터 |
| 교차_4 | TX 패킷 `[20]` 은 전송 길이(`dataSize`) | 01 · 02 · 06 |
| 교차_5 | `ble/` 줄 수 오측 정정 (`Measure-Object -Line` 함정) | 03 · 05 (**오케스트레이터 브리핑 반증**) |

> [!NOTE]
> **교차_5 는 fan-out 의 가치를 보여준 사례다.** 오케스트레이터가 사실로 제공한 수치를 노드 2개가 각각 독립 실측으로 뒤집었다. 루트 지침의 "노드 산출물을 무비판 수용하지 말라"는 역방향으로도 성립한다 - **오케스트레이터의 입력도 검증 대상이다.**

## 3. 오케스트레이터 직접 재검증

노드 판정을 그대로 채택하지 않고 소스로 재확인한 항목이다 (2차 리팩토링 노하우_5 준용 - 기계·에이전트 판정 맹신 시 파손).

| # | 항목 | 노드 주장 | 재검증 결과 |
|---|---|---|---|
| 재검증_1 | `ble/` 줄 수 | 03·05: 2,196 / 1,389 | **확인.** LF 기준 실측 일치. 오케스트레이터 최초값이 오측 |
| 재검증_2 | RX `[20]` 범위 초과 | 02: OOB read | **확인.** `Rx_DataPacket[BLE_DataPacketSize]`=20원소(`tdc_hal_spi.c:22`), 로그가 `[20]` 접근(`tdc_ble_communication.c:282`) |
| 재검증_3 | OOB **write** 여부 | (미주장) | **없음.** 복사 루프가 `i < BLE_DataPacketSize`(`tdc_hal_spi.c:159-162`)로 정확. 21번째 수신 바이트는 폐기 |
| 재검증_4 | 라이브 재진입 가드 | 04: Stop 포함 전량 거부 | **확인, 단 조건 정밀화 필요.** `command != IDLE` **그리고** 서브상태가 HoldOn/Standby 아님 - 두 조건 동시 성립 시에만 (`tdc_ble_mapping.c:89-112`) |
| 재검증_5 | 서브커맨드 체계 | 04·06 | **확인.** 0 Standby / 1 allParameter / 2 Start / 3 StimulationVolumeAdjust / 4 MicSensitivityAdjust / 5 알람 / 8 Stop / 9 HoldOn (`tdc_ble_mapping.c:315-326` 주석 + case 구현 일치) |
| 재검증_6 | 핸들러 없는 명령 | 01: 0x51·0x53·0x58·0x90 | **확인.** 해당 `case` 문 grep 결과 **0건** |
| 재검증_7 | isd -> ble 역호출 규모 | 07: 39+11 지점 | **확인(규모 상향).** `tdc_ble_mapping_get_packet` · `tdc_ble_mapping_clear_command` · `tdc_ble_remote_clear_command` 3함수 grep 결과 `isd/` 6파일에서 **56회**, 전체 119회 |
| 재검증_8 | 자극 step 직접 구동 | 07: 4곳 | **확인.** `tdc_ble_mapping_step()` switch 안에서 매 tick 직접 호출 - `:1902` impedance · `:1919` ecap · `:1943` specific_stim · `:1956` live |
