# 요구사항 - 바이폴라 기준전극 99 · 0x65 경로 방어 (이월_D)

**TL;DR**: 라이브(0x66) 경로의 2중 방어를 특정자극(0x65) 경로에 **이식**한다. 신규 설계가 아니라 **검증된 코드의 대칭 적용**이다. 파싱(`ble/`)은 건드리지 않고 **`isd/` 한 파일만** 고쳐 라이브와 동일한 방어 위치를 유지한다.

## 1. 배경

| 항목 | 내용 |
|---|---|
| 결함 | 바이폴라 + 기준전극 99 조합에서 `electrodeMap[98]` 범위 밖 읽기 -> `s_tdc_table` 포인터값이 ISD 레지스터로 -> FIFO 클리어 -> 백텔 카운트 0 |
| 확증 | [`20260730_ble-cmd-0x65-rename/구현-검증.md §3`](../20260730_ble-cmd-0x65-rename/구현-검증.md) (은수님 지적) |
| 비대칭 | 라이브 경로는 2026-07-27 에 2중 방어, **0x65 경로는 0중** |
| 지시 | 은수님 - "이월_D 지금 바로 진행해" |

## 2. 요구사항

| 요구사항_2 | `case 5`(`:258`) 의 레지스터 조합에 **`0x1F` 마스크** 적용 | `tdc_isd_stim_para_setting.c:577` |

## 4. HW 레지스터 5게이트

> [!CAUTION]
> 루트 지침 §7 - HW 레지스터·설정 변경 전 5게이트. **추측이 섞이면 변경 금지.**

### 게이트_1 - 대상 식별

| 항목 | 값 |
|---|---|
| 레지스터 | `ISD_registerAddr_en__bipolar_referenceElectroldIndex` = **0x04** (`board/isd_ver1_1_2.h:17`) |
| 조합 구조 | `주소 << 1 \| R/W` 를 `<< 8` 한 뒤 데이터 OR |
| 대상 필드 | 데이터부 **비트 [4:0]** (기준전극 번호 0~31) |
| 변경 내용 | 데이터 OR 에 `0x1F &` 마스크 추가 (2곳) + 대입 전 범위 검사 (1곳) |

### 게이트_2 - 근거 확인

| 근거 | 출처 |
|---|---|
| 기준전극 번호가 **비트 [4:0]** 범위다 | `tdc_isd_stim_para_setting.c:576` · `:604` 주석 |
| **범위 초과 시 FIFO 클리어 -> 백텔 카운트 0** | 동 |
| `electrodeMap` 은 32원소 (`[0..31]`), 값도 0~31 | `board/electrodeMapping.h:5`, `electrodeMapping.c:3` |
| 더미값 31 = `0x1F` 이라 마스크를 통과한다 | `board/isd_ver1_1_2.h:42` `unusedReferenceElectrode_DummyNum 31` |
| 라이브 경로에서 **실기 검증된 방식** | 2026-07-27 적용, 이후 실기 정상 |

**추측 없음.** 모든 값이 소스에서 확인된다.

### 게이트_3 - 전후 시뮬레이션

**마스크 (요구사항_2·3)**

| 입력 `bipolarReferenceElectrodeNum[i]` | 현재 | 변경 후 | 차이 |
|---|---|---|---|
| 0~31 (정상) | 그대로 OR | `0x1F & v` = **v** | **없음** |
| 31 (더미값) | 그대로 OR | `0x1F & 31` = **31** | **없음** |
| 0x112EA (쓰레기) | 상위 비트까지 오염 | `0x1F & 0x112EA` = **0x0A** | **오염 차단** |

**정상 범위에서 비트 단위로 동작이 동일하다.** 이것이 마스크 추가가 안전한 이유다.

**범위 검사 (요구사항_1·5)**

| 조합 | 현재 | 변경 후 |
|---|---|---|
| 바이폴라 + 기준전극 1~32 | `electrodeMap[0..31]` 정상 대입 | **동일** |
| 바이폴라 + 기준전극 **99** | `electrodeMap[98]` 쓰레기 대입 | **대입 건너뜀 -> 더미값 31 유지** |
| 모노폴라 (`stimulatonMode != en__bipolar`) | `:206` 에서 `case 3` 건너뜀 | **동일** (검사 도달 안 함) |

### 게이트_4 - 부작용

| # | 부작용 후보 | 판정 |
|---|---|---|
| 부작용_1 | 정상 자극 동작 변화 | **없음** - 0~31 에서 마스크·검사 모두 무영향 |
| 부작용_2 | 바이폴라+99 의 동작이 바뀐다 | **의도된 변경** - 쓰레기 기준전극 -> 더미 기준전극(31). 라이브와 동일 동작 |
| 부작용_3 | 코드 크기 증가 | 범위 검사 1블록 + 마스크 2곳. **수십 바이트 예상**. 결함 수정이므로 수용 |

### 게이트_5 - 불확실성 명시

|---|---|---|
| 불확실_1 | 정상 앱이 바이폴라+99 를 실제로 보내는가 | **미확정.** 이월 항목은 "보내지 않는다"고 기록. 보내지 않아도 방어는 유효하며 정상 경로에 영향이 없다 |
