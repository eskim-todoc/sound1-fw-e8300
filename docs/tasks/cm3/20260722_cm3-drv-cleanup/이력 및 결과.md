# 이력 및 결과 — drv 사장 드라이버 제거

**TL;DR**: board 레거시 정리의 직접 후속. 삭제된 보드에 묶여 영구 사장이 된 PMIC 드라이버 2종과, 호출자가 없는 배터리 게이지·가속도 센서 드라이버 2종을 제거해 `drv/` 를 10 → 2파일로 줄였다. 잔존 68개 오브젝트의 기계어 동일로 동작 보존을 확정.

## 요구 (은수님 지시)

> "drv 폴더에서도 `tdc_drv_isl9122.h` 말고는 사용하는 게 하나도 없잖아? 가속도 센서도 안 쓰고. isl9122만 남기고 제거해도 되지 않아? 물론 사용되는 곳이 있는지 먼저 검사하고, 의존성이 있는 게 있는지 확인하고."

→ **검사 결과 지적이 정확했다.** 다만 소스 grep 으로는 반대 결론이 나오므로(§검출_1) 링크 레벨 판정이 필요했다.
