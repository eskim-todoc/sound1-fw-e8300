# ④ 분석 검증 — 2__cm3 2차 리팩토링

**TL;DR**: `분석.md` 를 3축(지침 준수·논리 정합·근거)으로 자체 검증했다. 근거는 링크 레벨 데이터(재현 가능)와 소스 라인으로 뒷받침되며, 노드 상충 7건이 전부 실측으로 심판됐다. **정정 1건**(KKK 를 "오타"로 본 초기 서술 → "의도적 비활성화"로 교정, `분석-데이터/06`)을 반영했다. 남은 불확실성은 §3 에 명시.

## 1. 지침 준수 축

| 지침 | 준수 여부 |
|---|---|
| 사장 판정은 링크 레벨 (`코딩/작업 규칙.md` 회귀 검증) | **준수** — `--print-gc-sections` 로 확정. grep 단독 판정 안 함 |
| root cause 가설 ≥3 cross-check | **준수** — 노드 상충 7건을 링크·`nm`·소스 3자 대조로 판정 |
| HW 레지스터·설정 변경 5게이트 | **해당 없음** — 본 작업은 사장 코드 제거이지 레지스터 값 변경이 아님. 단 `configure_sleep`·`LSAD`·`I2C_cfx` 등 HW 인접 항목은 위험도 `주의`로 격리 |
| 불가침 존중 | **준수** — `cfx_cm3_sharedMemoryAll`·`FS_MEM_UART` 레이아웃·`*_IRQHandler`·SDK·5대 FSM·`lib/` 원본 API 를 제거 목록에서 제외 |
| 추측 섞이면 변경 금지 | **준수** — 코드로 판단 불가한 5모듈을 G4 로 격리, 은수님 확인 전 미실행 |

## 2. 논리 정합 축

| 검증 | 결과 |
|---|---|
| "링커가 버린 것 = 사장" 논리 | **정합** — `-ffunction-sections`+`--gc-sections` 빌드에서 폐기 섹션은 최종 바이너리 부재를 의미. §신규_1 |
| 연쇄 사장 처리 | **정합** — `tdc_pwr_lsad_*` 가 grep 5건이나 호출자 전부 사장/`#if 0`. 링커 판정이 이를 자동 반영 |
| G1 선행 필수 논리 | **실증됨** — 임시 트리에서 UART 헤더 선삭제 시 `tdc_shm.c:283`·`tdc_hal_dio.c:121-122` 2곳만 실패. G1(이관)+`configure_sleep` 동반 제거로 해소 확인 |
| `.elf` 완전 일치 주장 | **실증됨** — G1+G2 적용본 `.text` md5 = baseline (`dc0c5fb2861cf6e7577c75c2bb66c1d6`) |
| 유령 선언(정의 없음)의 안전성 | **정합** — 호출 시 링크 에러가 나므로 현재 호출 0건이 구조적으로 보장 |

## 3. 근거 축 — 사실 vs 추정 분리

**사실 (재현 가능/`파일:라인` 확인)**

- 사장 함수 70·데이터 24: `분석-데이터/05` + `.tsv` 원자료. `--print-gc-sections` 재실행으로 재현 가능
- G1+G2 `.elf` 일치: `size`/`nm`/`md5` 실측 로그
- KKK 이력: `git log -S` 로 접미사 없는 버전 부재 확인 (`분석-데이터/06`)
- 전하량 검사 3중 생존: `isd/tdc_isd_map_{impedance,ecap,specific_stim}.c` 라인 확인

**추정 (미확인 — 게이트에서 실증 필요)**

| 항목 | 상태 | 해소 시점 |
|---|---|---|
| `DSP_PRAM1_REMAP_BASE` vs `D_DSP_PRAM1_BASE` 실주소 일치 | SDK 헤더 리터럴 미확인. 명명·주석 정황만 | G1 검증 시 `.map` 대조 |
| G3~G5 각 항목의 `.elf` 불변 | G1·G2 만 실증. G3+ 는 미실행 | 각 게이트에서 대조 |
| `sys_earpiece`·`pwr_lsad`·`hal_i2c_cfx` 재활성 계획 | 코드로 판단 불가 | G4 은수님 확인 |

## 5. 종합 판정

분석은 **구현 착수 가능** 수준으로 검증됐다. 링크 레벨이라는 재현 가능한 근거를 축으로, 소스 조사의 오탐을 교차 심판으로 걸러냈다. 미확인 3건은 전부 **게이트 검증 또는 은수님 확인으로 해소되는 구조**이며, 어느 것도 G1~G3 진행을 막지 않는다.
