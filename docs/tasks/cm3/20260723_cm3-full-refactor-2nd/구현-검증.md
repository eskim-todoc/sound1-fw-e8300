# ⑧ 구현 검증 — 2__cm3 2차 리팩토링

**TL;DR**: 6개 게이트 전부 구현·검증 완료. **링크 레벨 사장 함수 70 -> 0**, 소스 **4,365줄 감소**, 빌드 경고 **2 -> 0**. 게이트마다 `.elf` 대조로 동작 보존을 실증했고, 바이너리가 변한 지점은 **전부 원인을 규명**했다(`__LINE__` 인코딩 · 벡터 weak 폴백 · 스택 오프셋). 은수님 실기 확인 1회 통과(G1~G4b).

## 3. 바이너리가 변한 지점 — 전부 원인 규명

동작 보존이 목표였으므로, `.elf` 가 달라진 모든 지점의 원인을 확인했다.

| # | 현상 | 원인 | 근거 |
|---|---|---|---|
| 1 | `.text` 소량 차이 (6·64·72·89바이트 등) | **`__LINE__` 값 이동** — `tdc_printf.h` 의 `TDC_PRINTF_E` 가 `__LINE__` 사용 | 라인 보존 대조본이 baseline 과 바이트 동일 |
| 2 | G3 `.text` -1,400 | 사장 함수의 **문자열 리터럴**이 `.rodata.str` 병합 섹션에서 함께 정리 | 실행 함수 코드 총합은 -10B |
| 3 | ISD `.text` -12 | **`__LINE__` 이 255 경계를 넘어 인코딩 축소** `movw`(4B) -> `movs`(2B) | 디스어셈블: `movw r2,#283` -> `movs r2,#213`, 니모닉 차이는 이것뿐 |
| 4 | G4b `.text` -184 · `.bss` -4 | `LSAD_IRQHandler` 제거 -> `libcmsis.a` **weak 정의로 폴백** | 벡터 핸들러 94개 유지, 사라진 함수 1개뿐 |
| 5 | `hal_i2c_cfx` `.text` -24 | `CFX_1_IRQHandler` 동일 폴백 | 상동 |
| 6 | G6 `.text` -432 | 미사용 지역변수 제거로 **스택 프레임 축소** | 감소분이 대상 4개 함수 합과 정확히 일치 |
| 7 | `impedance_step` `.text` **+176** | 스택 오프셋 이동으로 `ldr`->`ldr.w` 인코딩 확대 | **호출 64개 차이 0 · 분기 67개 동일**, 니모닉 개수 동일 |

> [!IMPORTANT]
> **7번이 이 검증의 핵심 사례다.** 코드가 *늘어난* 유일한 지점인데, 디스어셈블 대조로 **명령 개수와 호출·분기 시퀀스가 완전히 같고 인코딩 폭만 바뀐 것**을 확인했다. 크기 증감만으로 회귀를 판단하면 안 된다는 근거다.

## 4. 안전장치 — 제거하지 않은 것

기계적 판정을 그대로 따르지 않고 걸러낸 항목들이다. **이 목록이 검증의 실질**이다.

| 대상 | 도구 판정 | 실제 | 조치 |
|---|---|---|---|
| `devFwVer_type/num` | 사장 | `static const` 상수 폴딩으로 **저장소만** 죽음. 심볼은 `main():348` 에서 참조 | **제외** (제거 시 컴파일 에러) |
| `pabs_thr` (`tdc_touch.c`) | 미사용 | `#if (PRINT_ENABLE)` 블록이 사용 | **제외** (스위치 켜면 컴파일 에러) |
| `tdc_sys_reset_nrf` · `nrf_off_command` | 빈 몸통 | **살아 있고 실행됨**. `main.c:839` 주석에 "시퀀스 유지, 실효 없음" 명시 | **권고 철회** |
| `tdc_led_memory_error` | 1차 이월 사장 | `tdc_sys_init.c:280` 실사용 | **이월 목록 오탐 정정** |
| BLE 프로토콜 정의 | 미참조 | 앱·리모콘과의 **통신 규약** | **전량 존치** + 규약 문서에 원칙 명문화 |
| `NVM_BOOT_INFO_SIZE` | 사장 | 복원한 `s_boot_info[]` 가 사용 | 1차 제외 -> `bootloader_CRC_calc` 와 함께 최종 제거 |
| `prevPcmOutputMode` | 값만 넣음 | **복원 누락 로직 버그의 증거** (§6) | **보존** |
| `isd/tdc_isd_map_*` FSM | 일부 사장 | 의료 자극 제어 | 구조 미변경, 미사용 지역변수만 정리 |

## 7. 종합 판정

**동작 보존이 입증됐다.**

1. 제거 대상은 전부 **링크 레벨로 최종 바이너리 부재가 확인된 것**이거나, **전처리 단계에서 컴파일되지 않던 코드**다
2. 바이너리가 변한 7개 지점은 **모두 원인이 규명**됐고, 어느 것도 실행 로직 변경이 아니다
3. 기계적 판정을 따랐다면 깨졌을 항목 8건을 **개별 검토로 걸러냈다**
4. 벡터 테이블 변화(2건)는 SDK weak 정의 폴백으로 안전이 보장되고, 해당 인터럽트는 활성화 경로 자체가 없음을 사전 확인했다
5. 은수님 실기 확인 통과

**병합 가능하다.**
