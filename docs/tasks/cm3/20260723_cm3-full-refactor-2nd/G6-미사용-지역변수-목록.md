# G6 — 미사용 지역변수 목록

**TL;DR**: `-Wall -Wextra` 가 지적한 미사용 지역변수 **117건**(25개 파일). 2차 리팩토링 G1~G5 완료 시점 기준으로 다시 뽑은 최신 목록이다. **G6 는 다른 게이트와 성격이 다르다** - 아래 §주의 참조.

## 주의 - 왜 G6 만 따로 떼어 놨나

이 프로젝트는 `-O0`(최적화 없음)로 빌드한다. 그래서 **쓰지 않는 지역변수도 스택에 자리를 차지한다.**

| | 다른 게이트(G1~G5) | **G6** |
|---|---|---|
| 제거 대상 | 죽은 코드(애초에 컴파일 안 됨) | **살아있는 함수 안의 변수** |
| 바이너리 영향 | 없음 (또는 `__LINE__` 이동뿐) | **스택 프레임이 줄어 함수 프롤로그·에필로그가 바뀜** |
| 검증 방법 | `.elf` 바이트 동일 | **성립하지 않음** |

즉 G6 는 "동작은 같은데 바이너리는 바뀌는" 작업이라, 지금까지 써 온 검증 기준을 쓸 수 없다. `-O2` 였다면 컴파일러가 알아서 없애 애초에 차이가 안 났을 것이다.

> [!NOTE]
> **실익도 크지 않다.** 미사용 지역변수는 코드 크기를 늘리지 않고(명령이 생기지 않음) 스택만 조금 쓴다. 가독성·경고 정리가 주된 이득이다.

## 참고

- 이 목록은 **지역변수만**이다. 전역·static 사장 변수는 G3 에서 링크 레벨로 이미 정리했다.
- `-Wunused-but-set-variable`(설정만 하고 안 읽음)은 **로직 실수의 신호일 수도 있다.** 단순 삭제 전에 "원래 이 값을 썼어야 하는 것 아닌가"를 한 번 보는 편이 낫다.
- 이 문서와 별개로, 경고 전체에는 `-Wenum-conversion` 39건 · `-Wpointer-sign` 17건 · `-Wswitch` 15건 등도 있다. 이들은 미사용이 아니라 **타입 정합성** 문제라 G6 범위 밖이다.
