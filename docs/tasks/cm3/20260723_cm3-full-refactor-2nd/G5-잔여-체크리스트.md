# G5 잔여 — 제거 여부 판단 체크리스트

> [!IMPORTANT]
> **사용법**: `- [x]` = **제거**, `- [ ]` = **보류(그대로 둠)**.
> 제 권고를 미리 채워 뒀습니다. **체크를 켜고 끄신 뒤 저장만 하시면** 제가 읽어서 체크된 것만 제거합니다.

**TL;DR**: G5 미처리 **80건**(매크로·타입 48 · 죽은 블록 32). 전부 **현재 소스에 실재함을 grep 으로 확인**했습니다. 기본 체크는 제거 권고 항목에만 켜 두었습니다.

## 왜 남았나
