## 축_2 — 논리 정합성

### 도구결함_1 (발견 · 수정 완료) — 06 공유 인터페이스 정규식 버그

초판 `06_공유-인터페이스.md` 는 **타입 19개 전부 복제본 부재('-')** 로 출력했다. 필드는 105/105 존재로 나와 자기모순이었고(같은 파일의 복제인데 타입만 전부 없을 수 없음), spot-check(`grep -c ST__CFX_CM3_SharedMemory` → CFX **27** / calibration **26**)로 실체 확인.

**원인**: f-string 안의 `rf'\\b{n}\\b'` 가 raw 문자열에서 이스케이프 중첩되어 word-boundary `\b` 가 아닌 **리터럴 `\b` 문자열**로 컴파일됨. 필드 검사는 `rf"\b{n}\b"`(단일 백슬래시)라 정상이었다.

**조치**: 수정 재생성 — **타입 19/19 · 필드 105/105 복제 존재**. `분석.md §7` 은 수정본 기준. 데이터 파일 헤더에 버그 이력 명기.

**교훈**: 자기모순 신호(필드 O / 타입 전부 -)를 놓치지 않는 cross-check 가 자동화 census 의 필수 짝이다.

### 도구결함_2 (발견 · 실증으로 대체) — static 후보의 비호출 참조 미검사

스크립트는 static 함수의 사장 판정에 `이름(` 패턴만 사용 — **함수 포인터 테이블 참조(`{"help", handle_help, ...}`)를 놓친다**. spot-check 로 `tdc_ui_command.c:795~796` 테이블을 실증, **static 후보 12개 전원 오탐 확정**. `분석.md §6` 분류표에 반영됨.

### 정합확인_1 — 함수 총수 불일치 (허용 오차)

1차 recon(census_prefix)은 SEGGER 포함 689(제외 652), 정밀(census_full)은 645. 차이 약 1% — 정의 검출 정규식 개선(선언 오탐 제거) 때문. **규모 산정 목적상 허용**, 개별 함수 목록은 정밀본 기준.
