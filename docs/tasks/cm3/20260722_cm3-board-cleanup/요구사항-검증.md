# ② 요구사항-검증

**TL;DR**: 요구 4건이 확정 결정에 전부 매핑됐다. **결함 2건 검출** — 요구_3("Board_\* 는 Sound1")의 해석이 중의적이었던 점(질의로 해소), `board.h` 의 죽은 `#else` 블록이 초기 요구에 없었던 점(기능_3 으로 추가).

## 1. 축 1 — 지침 준수

| 지침 | 검증 | 결과 |
|---|---|---|
| 모호 시 질문 (루트 §2) | `Board_*` 유지 범위와 FPGA 2.8 거취를 선택지로 제시해 확정 | ✅ 추측 진행 없음 |
| 동작 보존 | 비기능_1 로 명시 | ✅ |
| 되돌릴 수 있는 삭제 | `git rm` + 이력 보존(비기능_3) | ✅ |
| 문서 메타 | frontmatter + TL;DR | ✅ |

## 2. 축 2 — 논리 정합

| 검증 | 결과 |
|---|---|
| 요구 4건이 확정 결정에 매핑되는가 | ✅ 요구_1·2→기능_1, 요구_3→Board 결정, 요구_4→FPGA·ISD 결정 |
| "최신 버전만"(요구_4)과 실제 선택 버전이 일치하는가 | ⚠️ **FPGA 는 불일치** — 파일상 최신은 `2_8_0` 이나 선택된 것은 `2_7_0`. 질의로 **2.7 유지** 확정 (결함_1) |
| 삭제 개수 산술 | ✅ Board 9 + FPGA 6 + ISD 3 = **18**, 29 − 18 = **11** |
| `#error` 유지가 요구와 충돌하는가 | ✅ 충돌 없음. 파일 축소와 가드 유지는 독립 |

## 3. 축 3 — 근거 검증

| 주장 | 방법 | 결과 |
|---|---|---|
| "최신 말고는 사용되지 않는다"(요구_1) | 선택자 `#if/#elif` 구조 + 직접 include 전수 grep | ✅ 정확. 비선택 파일은 전처리 진입 자체가 없음 |
| 현재 선택 조합 | `processorDirective.h:10,16,21` | ✅ `Board_is_OTE_VER_1_5` · `FPGA_Ver_is_270` · `ISD_Ver_is_112` |
| 공통 헤더 4종이 실제 활성인가 | 참조 grep | ✅ `processorDirective.h`(20+ 파일) · `99_eeprom_address.h`(3) · `DIO_PIN_Config.h`(Board_* 경유) · `electrodeMapping.h`(isd 5) |
| `Board_*` 10개 중 도달 가능한 것 | `board.h` 분기 대조 | ✅ 3개만(1.5/1.3/TD_DEV 1.4). 나머지 7개는 분기 없음 |

## 4. 검출 결함

| ID | 결함 | 조치 |
|---|---|---|
| 결함_1 | **요구_4 "최신 버전"이 중의적**이었다. 파일 기준 최신(`FPGA_ver2_8_0`)과 `processorDirective.h` 선택 버전(`2_7_0`)이 다르며, 둘은 **레지스터 비트맵 비호환**이다 | 차이표를 제시해 질의 → **2.7 유지·2.8 삭제** 확정. 차이는 `분석.md §5` 에 기록해 소실 방지 |
| 결함_2 | **`board.h` 의 비-1.5 `#else` 핀 블록**이 초기 요구에 없었다. Board 를 1.5 하나로 좁히면 이 블록도 도달 불가가 된다 | **기능_3 으로 추가**. `분석.md §6` 에 무해성 근거 기록 |

## 5. 결론

요구사항은 **③ 분석 진입에 충분**하다. 결함 2건은 요구사항·분석에 반영했다.
