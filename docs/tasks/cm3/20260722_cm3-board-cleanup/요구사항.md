# ① 요구사항 — board/ 레거시 헤더 정리

**TL;DR**: `source/board/` 29파일 중 18개가 Sullivan 1~1.5 세대 레거시다. Sound1 이 실제로 쓰는 조합(**보드 OTE 1.5 · FPGA 2.7 · ISD 1.1.2**)만 남기고 나머지를 제거한다. 선택자 3개도 단일 분기로 단순화하되 **`#error` 가드는 유지**한다.

## 1. 배경

`board/` 는 Sullivan1 → 1.5 세대에 걸쳐 누적된 보드 리비전·FPGA 리비전·내부이식장치(ISD) 리비전 헤더가 전부 쌓여 있다. `processorDirective.h` 의 `#define` 으로 하나만 선택되고 나머지는 컴파일되지 않는다.

제품이 **Sound1** 으로 바뀐 지금, 쓰이지 않는 세대의 헤더가 트리 가독성과 탐색을 방해한다.

## 2. 은수님 지시 (원문 취지)

| # | 지시 |
|---|---|
| 요구_1 | board 폴더 헤더가 너무 많고, **최신 버전 말고는 사용되지 않는 구조**다 |
| 요구_2 | 전부 **Sullivan1 ~ 1.5 세대 레거시**다. 지금은 Sound1 이니 목록을 수정하고 싶다 |
| 요구_3 | `Board_*` 는 Sound1 에 해당하는 항목이다 |
| 요구_4 | **FPGA · ISD 는 `processorDirective.h` 가 지정하는 최신 버전만** 쓰면 된다 |

## 3. 확정 결정 (협의 결과)

| 대상 | 결정 | 근거 |
|---|---|---|
| **Board_\*** | `Board_OTE_ver1_5.h` **1개만** 유지, 9개 삭제 | 은수님 선택. Sound1 = OTE 1.5 기반 |
| **FPGA_ver\*** | `FPGA_ver2_7_0.h` **1개만** 유지, 6개 삭제 | 은수님 선택. `FPGA_ver2_8_0.h`(2.7보다 신규·비호환 비트맵)도 **삭제 확정** — git 이력에 보존됨 |
| **isd_ver\*** | `isd_ver1_1_2.h` **1개만** 유지, 3개 삭제 | 요구_4 |
| **선택자 3개** | 단일 분기로 축소하되 **`#else #error` 유지** | 잘못된 `#define` 시 조용히 빌드되지 않고 **즉시 실패**해야 한다 |
| **공통 헤더** | `processorDirective.h` `99_eeprom_address.h` `DIO_PIN_Config.h` `electrodeMapping.c/.h` 유지 | 전부 활성 참조 있음 |

## 4. 요구사항

### 기능 요구

| ID | 요구 | 수용 기준 |
|---|---|---|
| 기능_1 | 레거시 버전 헤더 18개 삭제 | `board/` 파일 수 29 → **11** |
| 기능_2 | 선택자 3개 단일 분기화 | `board.h` · `FPGA.h` · `internalStimulationChip.h` 각각 분기 1개 + `#error` |
| 기능_3 | `board.h` 의 비-1.5 핀 정의 `#else` 블록 제거 | OTE 1.5 가 유일 선택지이므로 도달 불가 |
| 기능_4 | `processorDirective.h` 의 사라진 선택지 주석 정리 | 삭제된 보드·ISD 를 가리키는 주석 `#define` 잔존 0 |

### 비기능 요구

| ID | 요구 | 수용 기준 |
|---|---|---|
| 비기능_1 | **동작 100% 보존** | 삭제 대상은 전부 비선택(미컴파일) 파일. 선택된 조합의 전처리 결과 불변 |
| 비기능_2 | 잘못된 설정 시 조용한 실패 금지 | 미지원 버전 `#define` 시 `#error` 로 즉시 중단 |
| 비기능_3 | 이력 보존 | `git rm` 사용. 삭제된 FPGA 2.8 등은 git 이력에서 복원 가능 |

## 5. 범위 밖

| 항목 | 사유 |
|---|---|
| `board/` 파일 `tdc_` 접두어 rename | 전면 리팩토링에서 **보드 정의는 제외** 처리했다. 별도 판단 필요 |
| FPGA 버전 상향(2.7 → 2.8) | 은수님이 2.7 유지를 선택. 실기 검증이 필요한 동작 변경 |
| `99_eeprom_address.h` 내용 정리 | EEPROM 주소맵 — 별도 사안 |
| `electrodeMapping.c` 의 `#if 1` 분기 정리 | 임피던스 지그용 대체 매핑 — 시험 자산 |
