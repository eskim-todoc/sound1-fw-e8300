# ⑤ 계획 — 2단계 · 단일 게이트

**TL;DR**: 단계_1(삭제) → 단계_2(선택자 단순화)를 커밋 2개로 쌓는다. 핵심 검증은 **[전처리동등성]** — 선택 조합(`OTE 1.5`/`FPGA 2.7`/`ISD 1.1.2`)의 전처리 결과가 작업 전후 동일함을 실증한다. 로직 변경 0 이므로 게이트는 1회.

## 1. 단계_1 — 레거시 헤더 삭제 (커밋 1)

`git rm` 으로 18파일 제거. **파일만 지우고 선택자는 이 단계에서 건드리지 않는다** — 삭제와 편집을 분리해 회귀 원인을 특정 가능하게 한다.

| 그룹 | 삭제 |
|---|---|
| Board (9) | `Board_ALASKA_3.h` · `Board_Bingley_devBoard.h` · `Board_Evaluation.h` · `Board_OTE_ver1_0.h` · `Board_OTE_ver1_1.h` · `Board_OTE_ver1_2.h` · `Board_OTE_ver1_3.h` · `Board_OTE_ver1_4.h` · `Board_TD_DEV_ver_1_4.h` |
| FPGA (6) | `FPGA_ver1_0_0.h` · `FPGA_ver1_1_0.h` · `FPGA_ver2_0_0.h` · `FPGA_ver2_1_0.h` · `FPGA_ver2_4_0.h` · `FPGA_ver2_8_0.h` |
| ISD (3) | `isd_ver1_0_0.h` · `isd_ver1_1_0.h` · `isd_ver1_1_1.h` |

> [!NOTE]
> 이 시점에서 선택자는 **존재하지 않는 파일을 가리키는 `#elif` 분기**를 갖게 되지만, 해당 분기는 `#if` 로 비활성이라 **전처리기가 파일을 찾지 않는다**. 빌드는 정상이다. 단계_2 에서 정리한다.

**검증_구조_1**: `board/` 파일 수 29 → **11**. 삭제된 파일명을 참조하는 include **0건**(선택자 내 `#elif` 분기 제외).

## 2. 단계_2 — 선택자 단순화 (커밋 2)

### 2.1 `FPGA.h`

```c
#include <processorDirective.h>

#if defined(FPGA_Ver_is_270)
#include <FPGA_ver2_7_0.h>
#else
#error FPGA version is NOT selected or NOT supported. (지원: FPGA_Ver_is_270)
#endif
```

### 2.2 `internalStimulationChip.h`

```c
#include <processorDirective.h>

#if defined(ISD_Ver_is_112)
#include <isd_ver1_1_2.h>
#else
#error ISD version is NOT selected or NOT supported. (지원: ISD_Ver_is_112)
#endif
```

### 2.3 `board.h`

- 상단 `#if defined(Board_is_OTE_VER_1_5) … #else … #endif` 의 **`#else` 블록 제거** (nRF51822 시절 핀맵 — 도달 불가, `분석.md §6`)
- 하단 선택자를 단일 분기로 축소

```c
#include <processorDirective.h>

#if !defined(Board_is_OTE_VER_1_5)
#error Board is NOT selected or NOT supported. (지원: Board_is_OTE_VER_1_5)
#endif

/* EEPROM · QCC SPI 핀 (OTE 1.5) */
… (기존 1.5 분기 내용 그대로)

#include <Board_OTE_ver1_5.h>
```

### 2.4 `processorDirective.h`

사라진 선택지를 가리키는 주석 `#define` 을 제거한다.

| 현행 | 조치 |
|---|---|
| `// #define Board_is_TD_DEV_ver_1_4` | 삭제 |
| `#define Board_is_OTE_VER_1_5` | **유지** |
| `// #define Board_is_OTE_VER_1_4` | 삭제 (결함_B — 풀면 `#error` 나는 함정) |
| `// #define Board_is_OTE_VER_1_3` | 삭제 |
| `#define FPGA_Ver_is_270` | **유지** |
| `// #define ISD_Ver_is_111` | 삭제 |
| `#define ISD_Ver_is_112` | **유지** |

**검증_구조_2**: 선택자 3개가 각각 분기 1개 + `#error`. 존재하지 않는 파일을 가리키는 `#include` **0건**. `processorDirective.h` 에 삭제된 보드·ISD 를 가리키는 주석 `#define` **0건**.

## 3. 핵심 검증 — [전처리동등성]

작업 전후로 **선택된 조합의 전처리 결과가 동일**함을 실증한다.

| 방법 | 내용 | 우선순위 |
|---|---|---|
| **방법_A (강)** | `arm-none-eabi-gcc -E` 로 `board.h`·`FPGA.h`·`internalStimulationChip.h` 를 각각 전처리해 **작업 전 커밋본과 diff**. 0 이어야 한다 | 툴체인 접근 가능 시 |
| **방법_B (대체)** | 유지 3파일(`Board_OTE_ver1_5.h`·`FPGA_ver2_7_0.h`·`isd_ver1_1_2.h`)이 **byte 무변경**임을 확인 + 선택자 편집이 활성 분기 텍스트를 바꾸지 않았음을 diff 로 확인 | 방법_A 불가 시 |

> [!IMPORTANT]
> 방법_B 로 갈 경우, **`board.h` 의 `#else` 블록 제거**가 유일한 실질 텍스트 변경이므로 이 부분만 집중 확인한다 — 해당 블록이 정의하던 심볼(`ENABLE_NRF_ADV_LowPower` 등)이 현재 빌드에서 **이미 미정의**였음을 grep 으로 재확인한다.
