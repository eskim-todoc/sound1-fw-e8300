## 2. 심볼 표 - 「정상 경로 무변경」

### 2.2 크기가 바뀐 기존 심볼 4개 - 전부 설명된다

| 심볼 | 전 → 후 | 판정 |
|---|---|---|
| `tdc_tx_pmic_run_console` | 560 → **724** (+164) | **의도한 편집.** 명령 분기 2개(`m`·`c`)와 출력 3줄이 늘었다 |
| `__func__.3` | `[14,18,32,41,43]` → `[14,18,**21**,32,41,43]` | **추가**됐다. 기존 5개는 그대로 |
| `__func__.4` | `[13,21,33,40,42]` → `[13,21,**27**,33,40,42]` | 동 |
| `__func__.5` | `[19,19]` → `[19,19,**23**]` | 동 |

> [!IMPORTANT]
> **`__func__.N` 셋은 «크기가 바뀐» 것이 아니라 «원소가 늘어난» 것이다.** 컴파일러가 `TDC_PRINTF_*` 안의 `__func__` 를 위해 만드는 함수명 문자열이고, **새 함수가 생겼으니 새 문자열이 생기는 것이 맞다.** 기존 원소는 하나도 바뀌지 않았다.
>
> 이름별 **다중집합**으로 비교했기에 보인 것이다. 단순 `join` 이었다면 교차곱에 묻혔다(자산_15).

### 2.3 `__LINE__` 이 밀렸는데 왜 크기가 그대로인가

`tdc_test_tx_pmic.c` 에는 `TDC_PRINTF_E` 가 7곳 있고 그 앞에 코드를 60줄 넘게 끼워 넣었다. **`__LINE__` 값은 전부 밀렸다.**

그런데 `tdc_tx_pmic_apply()` 등 편집하지 않은 함수의 크기는 **변하지 않았다.** 밀린 값이 전부 **`movs`(0~255) 범위 안에서** 움직여 인코딩 폭이 그대로였기 때문이다(자산_2). 파일 최대 줄 수가 260줄대라 255 경계를 넘는 지점이 거의 없다.

**«크기 불변» 이 «줄 번호 불변» 을 뜻하지 않는다.** 오류 로그의 줄 번호는 바뀐다.

## 3. 크기

| 항목 | 전 | 후 | 차 |
|---|---|---|---|
| `text` | 188,876 | **190,628** | **+1,752** |
| `data` | 4,664 | **4,664** | **불변** |
| `bss` | 21,800 | **21,800** | **불변** |
| 심볼 바이트 합 | 174,498 | 175,433 | +935 |

`text` 증가분 1,752 중 심볼이 935, 나머지 **817 은 문자열 상수**다(모드 이름 5개 · 포맷 문자열 8개 · `__func__` 3개). 심볼로 잡히지 않는 `.rodata` 다.

> [!NOTE]
> **`bss` 불변이 중요하다.** 새 상태 변수를 하나도 만들지 않았다는 뜻이다. 모드는 IC 레지스터가 갖고 있고 펌웨어는 매번 읽는다 — **캐시하지 않았다.** 캐시하면 IC 가 리셋됐을 때 펌웨어의 기억과 실제가 어긋난다.

## 5. 코드로 확인할 수 없는 것

| 항목 | 왜 |
|---|---|
| 각 모드에서 실제 `VOUT` | **오실로스코프·멀티미터가 필요하다** |
| `c` 출력이 `0x89`/`0x8D` 로 나오는가 | I2C 통신이 필요하다. 게이트_3 예측의 실증 |
| 모드 전환 시 과도 파형 | 측정 |
| Forced PWM 의 입력 전류 증가폭 | 측정 |

**이 파일들은 호스트 러너가 컴파일하지 않는다.** 자동으로 본 것은 **컴파일 성공·포맷·심볼 표·크기**뿐이다.

## 6. 실기 확인 항목 (대장 §1 에 등재)

| # | 확인 |
|---|---|
| ① | 콘솔 진입 시 `mode = m0 NORMAL` 이 출력되는가 |
| ② | `c` 가 `CONV_CFG(0x12) = 0x81` 과 `EN_AND 1 DISCH 0 DVSRATE 0 FMODE 0 TYPE1 1` 을 내는가 |
| ③ | `m2` 후 `c` 가 **`0x89`** · `FMODE 2` 를 내는가 (**다른 필드 불변**) |
| ④ | `m3` 후 `c` 가 **`0x8D`** · `FMODE 3` 을 내는가 + 경고 2줄이 뜨는가 |
| ⑤ | **`m3` 상태에서 TX 출력 전압이 배터리 전압까지 떨어지는가** (승압 정지 확인) |
| ⑥ | `m0` · `r` 로 NORMAL 복귀 |
| ⑦ | `m1` 이 거부 메시지를 내는가 |
| ⑧ | `+N`/`-N`/`=N`/`?`/`r`/방향키 **기존 명령 무회귀** |

> [!CAUTION]
> **⑤ 를 할 때 자극을 걸지 말 것.** Forced Bypass 에는 과전류 보호가 없다(데이터시트 §5.10). 무부하에서 전압만 본다.
