# 요구사항

**TL;DR**: 은수님 지시 둘 - ① **바이패스 모드 이해가 맞는지 검토**하고 ② `tdc_test_tx_pmic_console()` 에 **모드 조회·변경 명령**을 넣는다. 데이터시트 분석은 **[`docs/참고/pmic-isl99122a/README.md`](../../../참고/pmic-isl99122a/README.md)** 에 따로 정리해 나중에 다시 볼 수 있게 한다.

## 1. 지시 원문

> 내가 docs/참고 밑에 PMIC - ISL9122A 문서를 넣어놨을거야. pdf 문서야. 뭘 원하냐면, 일단 이 IC는 모드가 존재하는데 바이패스 모드에서는 입력 전압이 출력보다 크면, 입력 전압을 출력으로 바이패스시키고, 입력이 낮아지면 부스트 방식으로 승압하는 모드가 있다고 하거든? 그게 맞는지 검토하고, 지금 main에서 tdc_test_tx_pmic_console() 함수를 활성화 시키면 PMIC를 테스트하는 함수로 진입하는데, 이 안에서 특정 명령을 입력하면 현재 모드를 확인하거나, 원하는 모드로 변경하는 기능을 추가하고 싶어. 이거 새 작업이니까 브랜치도 따고 문서 정리도 꼼꼼히좀 해봐. pdf 읽고 끝내지만 말고 분석한 내용도 나중에 또 볼수 있게 별도로 정리해놓고. (2026-08-07)

## 2. 요구 분해

| # | 요구 | 판정 기준 |
|---|---|---|
| 요구_1 | **바이패스 이해 검토** | 데이터시트 근거(절·쪽)를 달아 맞다/틀리다를 명확히 답한다 |
| 요구_2 | **데이터시트 분석을 별도 문서로** | `docs/참고/` 아래에 재사용 가능한 형태. 작업 폴더 안이 아니라 **부품 참고 문서**로 |
| 요구_3 | **콘솔에 모드 조회 명령** | 현재 `FMODE` 를 읽어 사람이 읽을 수 있게 출력 |
| 요구_4 | **콘솔에 모드 변경 명령** | 원하는 모드로 바꾸고 **되읽어 확인** |
| 요구_5 | **새 브랜치** | `claude_feature_*` |
| 요구_6 | 문서 꼼꼼히 | 8단계 산출물 |

## 3. 제약

| # | 제약 | 근거 |
|---|---|---|
| 제약_1 | **`FMODE = 0x1` 은 쓰지 못하게 막는다** | 데이터시트 Table 5 «RESERVED. DO NOT USE» |
| 제약_2 | **다른 비트를 건드리지 않는다** | `CONV_CFG` 에는 `EN_AND`·`DISCH`·`DVSRATE`·`TYPE1` 이 같이 산다. **읽고-고쳐-쓰기** 필수 |
| 제약_3 | **모드 전환 명령 사이 1ms 이상** | §5.10 - Forced Bypass ↔ Regulation 을 오갈 때 요구된다 |
| 제약_4 | **Forced Bypass 는 과전류 보호가 없다** | §5.10 Note. 명령을 막지는 않되 **경고를 띄운다** |
| 제약_5 | 정상 동작 경로를 건드리지 않는다 | 콘솔은 테스트 전용이다. `main.c` 진입 한 줄 외에 자극·BLE 경로에 영향이 없어야 한다 |
| 제약_6 | HW 레지스터 **5게이트** 통과 | 루트 지침 §7 |
| 제약_7 | 코드 포맷 조건 11개 | [`docs/참고/clang-format/README.md`](../../../참고/clang-format/README.md) |
| 제약_8 | **`main.c` 의 콘솔 호출 활성화는 커밋하지 않는다** | 은수님 로컬 측정 설정이다(미커밋 상태로 유지) |

## 4. 완료 조건

| # | 조건 |
|---|---|
| 1 | 참고 문서가 데이터시트 절·쪽 인용과 함께 존재하고 **요구_1 에 답한다** |
| 2 | 콘솔에서 **모드 조회**가 동작한다 (코드 경로 확인) |
| 3 | 콘솔에서 **모드 변경**이 동작하고 되읽기로 확인한다 |
| 4 | `FMODE = 0x1` 요청이 **거부**된다 |
| 5 | 모드 변경이 `CONV_CFG` 의 **다른 비트를 보존**한다 |
| 6 | ARM 빌드 **에러 0 · 경고 0** |
| 7 | 호스트 **514 PASS** (회귀 없음) |
| 8 | `clang-format --dry-run -Werror` 무경고 |
| 9 | 실기 확인 항목이 상시 점검 대장에 등재된다 |
