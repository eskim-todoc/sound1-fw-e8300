## 요구_1 답변 (은수님 질문)

**«바이패스 모드에서 입력이 출력보다 크면 통과시키고, 낮아지면 부스트로 승압한다» 는 절반만 맞다.**

| 진술 | 판정 |
|---|---|
| 입력이 낮아지면 **부스트로 승압** | **맞다** |
| 입력이 크면 **입력을 출력으로 통과** | **아니다 — 강압(Buck)한다** |
| 그 둘을 **바이패스 모드 하나**가 한다 | **아니다** |

- **Bypass 는 `VIN` 이 `VOUT` ±1% 인 좁은 구간의 자동 전이 상태**다. `VIN > VOUT` 이면 Buck 으로 강압해 `VOUT` 을 `VSET` 으로 지킨다.
- **Forced Bypass(`FMODE=0x3`)는 스위칭을 꺼서 승압하지 않는다.** 과전류 보호도 없다.
- 은수님이 그린 거동(«높으면 그대로, 낮아지면 승압»)을 하는 **IC 모드는 없다.** 하려면 펌웨어가 배터리 전압을 보고 `FMODE` 를 토글해야 하는데, 자극 출력 레일에 보호 없는 모드를 쓰는 셈이라 권하지 않는다.

## 접은 것

| 후보 | 왜 |
|---|---|
| `INTFLG_REG(0x03)` 조회 명령 | 요청 범위 밖. «읽으면 지워진다» 는 성질까지 다뤄야 해 별건이 맞다 |
| 배터리 연동 자동 모드 토글 | 정책이고, Forced Bypass 의 과전류 보호 부재 때문에 권하지 않는다 |
| 모드를 펌웨어에 캐시 | IC 가 리셋되면 기억과 실제가 어긋난다. 매번 읽는다 (`bss` 불변의 이유) |
| 명령 이름을 `mode` 로 | 입력기가 **`d` 를 먼저 소비**해 문자열이 잘린다 |
| 폴더명 오타(`pmic-isl99122a`) 수정 | 은수님이 만든 폴더다. 참고 문서 §7 에 적어 두고 판단을 남긴다 |
