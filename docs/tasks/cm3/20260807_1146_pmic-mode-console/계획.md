# 계획

**TL;DR**: 드라이버에 **함수 3개**(`read_mode`·`write_mode`·`mode_name`)를 넣고 콘솔에 **명령 2개**(`m`·`c`)를 붙인다. `write_mode` 는 **읽고-고쳐-쓰고-되읽는다.** 정상 동작 경로는 한 줄도 안 바뀐다.

## 1. 드라이버 API

`drv/tdc_drv_isl9122.h`

```c
/* CONV_CFG(0x12) 의 FMODE[3:2] - 데이터시트 FN8947 Rev.1.03 Table 5 (p.25) */
#define TDC_DRV_ISL9122_CONV_CFG_FMODE_MASK  0x0C
#define TDC_DRV_ISL9122_CONV_CFG_FMODE_SHIFT 2

typedef enum
{
    TDC_DRV_ISL9122_FMODE_NORMAL        = 0,
    TDC_DRV_ISL9122_FMODE_RESERVED      = 1,
    TDC_DRV_ISL9122_FMODE_FORCED_PWM    = 2,
    TDC_DRV_ISL9122_FMODE_FORCED_BYPASS = 3,
} tdc_drv_isl9122_fmode_t;

bool        tdc_drv_isl9122_read_mode(tdc_drv_isl9122_fmode_t *p_mode);
bool        tdc_drv_isl9122_write_mode(tdc_drv_isl9122_fmode_t mode);
const char *tdc_drv_isl9122_mode_name(tdc_drv_isl9122_fmode_t mode);
```

### 1.1 `write_mode` 의 순서 - 넷 다 필요하다

| # | 단계 | 없으면 |
|---|---|---|
| 1 | **금지값 거부** (`RESERVED` · 범위 밖) | 데이터시트가 쓰지 말라는 조합을 쓴다 |
| 2 | **읽기** | 3의 재료가 없다 |
| 3 | **고쳐 쓰기** (`FMODE` 만 교체) | `EN_AND`·`TYPE1` 등을 덮어써서 변환기가 꺼지거나 오차증폭기가 바뀐다 |
| 4 | **2ms 지연 후 되읽기 검증** | 지연이 없으면 §5.10 의 1ms 규칙을 어긴다. 되읽기가 없으면 I2C ACK 만 보고 «됐다» 고 착각한다 |

```c
newValue = (currentValue & ~FMODE_MASK) | ((mode << FMODE_SHIFT) & FMODE_MASK);
```

## 2. 콘솔 명령

| 명령 | 동작 |
|---|---|
| **`m`** | 현재 모드 조회 — `m<N>  <이름>` |
| **`m0`** | Normal (자동 전환) |
| **`m1`** | **거부** — 데이터시트 RESERVED |
| **`m2`** | Forced PWM |
| **`m3`** | Forced Bypass — **경고 2줄 출력 후** 적용 |
| **`c`** | `CONV_CFG` 원시값 + 비트 해독 (`EN_AND`/`DISCH`/`DVSRATE`/`FMODE`/`TYPE1`) |

> [!CAUTION]
> **명령 문자로 `w`·`s`·`a`·`d` 를 쓰면 안 된다.** 입력기가 엔터 없이 즉시 소비한다(분석 §2.1). `m`·`c` 는 비어 있다.

기존 명령(`+N` `-N` `=N` `r` `?` 방향키)은 **건드리지 않는다.**

### 2.1 표시 보강

| 지점 | 추가 |
|---|---|
| 콘솔 진입 배너 | `m`·`c` 사용법 한 줄 |
| 콘솔 진입 직후 | **현재 모드 1회 출력** |
| `r`(리셋) 성공 후 | **모드 재출력** — 리셋이 `CONV_CFG` 에 `0x81` 을 써서 **Normal 로 되돌리기 때문** |

## 3. 절차

| 단계 | 내용 | 검증 |

| 1 | 헤더에 마스크·열거형·선언 추가 | |
| 2 | 드라이버에 함수 3개 구현 | |
| 3 | 콘솔에 출력 함수 2개 + 설정 함수 1개 | |
| 4 | 명령 분기 삽입 (`?` 뒤, 부호 파싱 앞) | |
| 5 | 배너·진입 출력 보강 | |
| 6 | `clang-format --dry-run -Werror` | 무경고 |
| 7 | ARM 빌드 | 에러 0 · 경고 0 |
| 8 | 호스트 회귀 | 514 PASS |

## 4. 「정상 경로 무변경」을 어떻게 보이나

**심볼 크기 표를 쓴다**(자산_15). 이번 변경은 새 함수를 **추가**만 하므로 기대는 이렇다.

| 관측 | 판정 |
|---|---|
| 새 심볼 3개(+콘솔 static) 등장 | 정상 |
| **기존 함수 크기가 변함** | **`__LINE__` 운반체를 품은 경우만 허용** |
| 기존 함수가 사라짐 | 실패 |
| `data`·`bss` 변화 | **없어야 한다** — 새 상태 변수를 만들지 않는다 |

> [!NOTE]
> `tdc_drv_isl9122.c` 에는 `TDC_PRINTF_E` 도 명시 `__LINE__` 도 없다. 이 파일에 함수를 넣어도 **같은 파일 안에서는 `__LINE__` 이 밀리지 않는다.** `.text` 증가는 순수 코드 추가분이어야 한다.

## 5. 예측

| 항목 | 예측 |
|---|---|
| 새 심볼 | `tdc_drv_isl9122_read_mode` · `..._write_mode` · `..._mode_name` **3개** (콘솔 static 은 인라인될 수 있다) |
| 사라진 심볼 | **0** |
| 크기 변한 기존 함수 | **0** (두 파일 모두 `__LINE__` 운반체 밀림이 없다) |
| `data` · `bss` | **불변** |
| `.text` | **증가.** 문자열 상수 5개 + 함수 3개 |
| 호스트 | **514 PASS** (이 파일들은 호스트가 컴파일하지 않는다 — 무변화가 정상) |
| ARM | 에러 0 · 경고 0 |
| 실기 대기 | **13건** (+1) |

## 6. 위험

| 위험 | 완화 |
|---|---|
| `CONV_CFG` 다른 비트 파괴 | 읽고-고쳐-쓰기 + `c` 명령으로 실기 육안 확인 |
| RESERVED 기입 | 드라이버·콘솔 **양쪽에서** 거부 |
| Forced Bypass 의 OCP 부재 | 경고 출력. 콘솔은 자극을 돌리지 않아 사실상 무부하 |
| 1ms 규칙 위반 | 쓰기 뒤 2ms 지연 |
| 새 명령이 입력기에 먹힘 | `w`·`s`·`a`·`d` 회피 (분석 §2.1) |
| 열거형 범위 비교 경고 | `int` 로 캐스팅 후 비교 |
| 은수님 `main.c` 로컬 변경 커밋 | **스테이징에서 제외**(제약_8) |
