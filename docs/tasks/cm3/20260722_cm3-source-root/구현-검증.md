> **학습**: 자동화 스크립트의 문자열 매칭은 **부분 문자열이 상위 경로를 삼키는 사고**가 반복된다. 제거·치환 대상은 항상 **정확 일치(exact match)** 로 판정하고, **예상 건수와 실제 건수를 대조**해야 한다. 이번엔 "제거 5건 ≠ 예상 3건"이 즉시 잡아냈다.

## 6. 게이트 — 은수님 조치 요청

> [!IMPORTANT]
> `.cproject` 가 바뀌었으므로 **다음 순서를 지켜주셔야** 구 경로 잔재로 인한 오탐이 없습니다.
>
> 1. Eclipse **Project → Clean...** (전체)
> 2. **F5 Refresh** (프로젝트 선택 후)
> 3. **Project → C/C++ Index → Rebuild**
> 4. **Build**
> 5. 실기 확인 — 부팅 · BLE · 자극 · EEPROM · 터치 · LED

빌드 실패 시 가장 유력한 원인은 **`-I` 미등록 헤더**입니다. 오류 메시지의 헤더 이름을 알려주시면 즉시 경로를 추가하겠습니다.
