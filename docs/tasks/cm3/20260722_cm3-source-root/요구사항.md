# ① 요구사항 — 2__cm3 소스 루트 분리

**TL;DR**: 빌드 산출물 `Debug/` 가 소스 폴더와 루트에서 혼재해 트리 가독성이 무너진 문제를 해소한다. 소스 전체를 `source/` 단일 루트로 옮기고, 레거시 폴더 3개를 의미명으로 정리하며, include 표기를 `<...>` flat 으로 통일한다. **CM3 한정**.

## 1. 배경

전면 리팩토링(`20260720_cm3-full-refactor`)으로 15개 도메인 폴더 재편은 끝났으나, 그 폴더들이 **프로젝트 루트에 평면 배치**돼 있다. Eclipse CDT managed build 가 소스 트리를 그대로 미러링하므로 `Debug/` 아래에 동일 이름 폴더 20개가 복제되고, 루트에서 소스와 산출물이 섞여 보인다.

## 2. 은수님 지시 (원문 취지)

| # | 지시 |
|---|---|
| 요구_1 | `Debug` 폴더가 소스 폴더와 혼재해 보기 어렵다 — **소스는 별도 루트 폴더 아래로 구조화** |
| 요구_2 | 자동으로 include 되는 경로가 보인다 — 정리 대상 |
| 요구_3 | 헤더 include 는 **`""` 가 아니라 `<>`** 를 쓰고 싶다 |
| 요구_4 | include 에 **경로(`a/b.h`)를 붙이고 싶지 않다** — `b.h` flat 유지 |
| 요구_5 | 이번 변경은 **CM3 한정** (형제 프로젝트 제외) |
| 요구_6 | 다른 프로젝트에서 잘 쓰이는 구조를 따져 방향 제시 → 협의 완료 (`분석.md §2`) |

## 3. 확정 결정 (협의 결과)

| 항목 | 결정 | 근거 |
|---|---|---|
| 소스 루트 이름 | **`source/`** | 형제 프로젝트 `0__bootloader`·`5__calibration` 이 이미 `source/` 사용. repo 경로가 `src/2__cm3/src/` 가 되는 중복 회피 |
| 모듈 배치 | **co-location 유지** (`.c`/`.h` 동거) | 이미 G0~G8 로 정착. 헤더·소스 물리 분리(STM32Cube 식)는 유지보수 시 두 폴더 왕복 비용 |
| include 표기 | **전부 `<...>`** (프로젝트·시스템 헤더 공통) | 요구_3. 현재 이미 `<>` 568건 vs `""` 419건으로 `<>` 우세 |
| include 경로 | **flat 유지** (`<tdc_hal_i2c.h>`) | 요구_4. 헤더 basename 전역 중복 **0건**으로 전제 충족 |
| `-I` 경로 | **폴더당 1개 유지** | flat include 의 필연적 대가. 규약으로 관리 |
| 적용 범위 | **`src/2__cm3` 한정** | 요구_5 |

## 4. 요구사항

### 기능 요구

| ID | 요구 | 수용 기준 |
|---|---|---|
| 기능_1 | 소스 전체를 `source/` 아래로 이동 | 프로젝트 루트에 남는 것은 `source/` · `Debug/` · `sections.ld` · Eclipse 메타(`.cproject`/`.project`/`.settings`/`.gitignore`) 뿐 |
| 기능_2 | 레거시 폴더 3개 정리 | `Cortex-M3-src/` → `source/`(main 승격) · `Gen1_5/` → `source/lib/` · `99_includeBoard/` → `source/board/` |
| 기능_3 | 루트 잔여 헤더 2개 귀속 | `99_eeprom_address.h` · `processorDirective.h` → `source/board/` |
| 기능_4 | include 표기 `<>` 통일 | `#include "..."` 잔존 **0건** |
| 기능_5 | `.cproject` 경로 갱신 | `-I` 전부 `source/` 기준. 사장 경로(`linked/include`·루트) 제거 |

### 비기능 요구

| ID | 요구 | 수용 기준 |
|---|---|---|
| 비기능_1 | **동작 100% 보존** | 이동·표기 변경만. 로직·조건·상수 무변경 |
| 비기능_2 | 공유 ABI 무변경 | `cfx_cm3_sharedMemoryAll` 구조체/필드/인스턴스 diff 0 |
| 비기능_3 | 링커 스크립트 보존 | `sections.ld` 는 루트 유지 (makefile 이 절대경로 `-T` 참조) |
| 비기능_4 | git rename 추적 | `git mv` 사용으로 이력 연속성 확보 |
| 비기능_5 | 규약 문서화 | "새 폴더 추가 시 `-I` 등록 필수" 를 `tdc_convention.md` 에 명시 |
