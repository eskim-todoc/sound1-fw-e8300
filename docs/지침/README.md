# 지침 (Sound1 특화)

**TL;DR**: Sound1만의 하드웨어·도메인 특화 지침을 모은다. 전역 컨벤션·작업 진행·Git 규칙 등은 루트 [`docs/지침/`](../../../../docs/지침/)을 따른다 — 본 폴더는 그 위에 얹는 프로젝트 예외만.

| 파일 | 목적 | 사용 시점 |
|---|---|---|
| [`레지스터 변경 검증 체크리스트.md`](레지스터%20변경%20검증%20체크리스트.md) | I2C 디바이스 레지스터 변경 시 필수 검증 절차 | 실기 테스트 전 (코드 변경 직후·머지 전) |
| [`SW 밸리데이션 계층화 방법론.md`](SW%20밸리데이션%20계층화%20방법론.md) | 코드를 유닛/모듈/시스템으로 분해하고 테스트 계층·의존성 순서를 정의하는 표준 | **모든 리팩토링·모듈화 작업** 분석·계획·검증 시 |

> [!NOTE]
> 새 Sound1 특화 지침 추가 시 이 표에도 행을 추가한다. 충돌 시 본 폴더가 루트보다 우선 (루트 [`문서 작성 규칙.md §2.1`](../../../../docs/지침/일반/문서%20작성%20규칙.md)).
