## 4. 검증 노하우 (이 세션의 최대 자산)

### 노하우_1 — `--print-gc-sections` 가 사장 판정의 최종 심판이다

1차의 `nm -u` 보다 강하다. CM3 빌드는 이미 `-ffunction-sections -fdata-sections` + `--gc-sections` 를 쓰므로, **`--print-gc-sections` 하나만 더 붙이면 링커가 폐기한 섹션을 전부 출력**한다. 연쇄 사장(사장 함수만이 호출하는 함수)까지 자동으로 잡힌다.

```sh
arm-none-eabi-gcc ... -Xlinker --gc-sections -Xlinker --print-gc-sections \
  -o gc.elf $(find source -name '*.o') -lcmsis -lfatfs -lnvmlib -lHAL 2> gcsections.txt
```

**못 잡는 것**: 매크로·타입·enum, 미사용 `static inline` 헤더 함수, `KEEP()` 보호 섹션. 이건 소스 조사로 보완해야 한다.

### 노하우_2 — 라인 보존 대조본으로 `.elf` 바이트 동일을 합격 기준으로 쓴다

죽은 코드를 지우면 최종 바이너리는 **바이트 단위로 같아야 한다**. 문제는 줄을 지우면 `__LINE__` 이 밀려 diff 가 생긴다는 것.

**해법**: 삭제 대신 **빈 줄로 치환**한 대조본을 따로 만들어 baseline 과 비교한다. 그것이 바이트 동일이면, 실제 커밋본의 소량 차이는 `__LINE__` 이동으로 설명된다. G1·G2·G4a 를 이 방식으로 **md5 완전 일치**까지 실증했다.

### 노하우_3 — `__LINE__` 은 값뿐 아니라 **코드 크기**도 바꾼다

ARM Thumb 는 즉시값이 255 이하면 `movs`(2B), 초과면 `movw`(4B)를 쓴다. 줄을 지워 `__LINE__` 이 255 아래로 내려가면 **명령이 짧아진다.**

> 실측: `tdc_isd_fpga_read_pulse_width` 의 `movw r2,#283` -> `movs r2,#213`. 3함수 x 2곳 = `.text` -12B.

반대로 **스택 오프셋이 밀리면 `ldr` -> `ldr.w` 로 늘어난다**(실측 +176B). **크기 증감만으로 회귀를 판단하면 안 되고, 디스어셈블로 니모닉·호출 시퀀스를 대조해야 한다.**

### 5.1 공유 ABI drift 상세 (이월_5)

`cfx_cm3_sharedMemoryAll` 은 CM3 와 CFX 가 **같은 물리 메모리(PRAM5)를 읽고 쓰는 통로**라, 각 프로젝트가 동일한 구조체 정의를 **복제**해서 갖는다. 사본이 3벌이다.

| 프로젝트 | 파일 | 최상위 필드 수 |
|---|---|---|
| `2__cm3` | `cfx_link/tdc_shm.h` | **35** (기준) |
| `1__cfx` | `environment/shared_memory.h` | **35** |
| `5__calibration` | `include/cfx_cm3_sharedMemory.h` | **28** |

calibration 에 없는 7개(전부 구조체 **끝**에 위치):
`is_enabled_mute_stimulation_under_t_level` · `mute_stimulation_t_level_offset` ·
`is_pcm_specific_command_reading` · `pcm_specific_command_read_index` ·
`gain_table_index_a` · `gain_table_index_b` · `is_i2s_source_cradle`

> [!CAUTION]
> **지금 안 깨지는 이유는 누락분이 끝에 몰려 있어 앞 28개 필드의 오프셋이 보존되기 때문이다. 정합해서가 아니라 우연이다.**
>
> 누군가 구조체 **중간**에 필드를 하나 넣으면 그 뒤 주소가 전부 밀리는데, calibration 은 옛 배치로 읽는다. **컴파일 에러도 경고도 없이 엉뚱한 값을 읽는다.** 자극 파라미터가 걸린 구조체라 위험하다.

**작업 시 주의**: 3프로젝트를 동시에 빌드해 검증해야 하고(CFX 는 LPDSP32, calibration 은 별도 툴체인), 필드 추가는 공유 메모리 주소 배치를 바꿀 수 있어 실기 확인이 필수다.
