## 3. 자산 - 다음 세션이 반드시 알아야 할 것

> [!IMPORTANT]
> 아래는 이번 세션에서 **실측으로 확인한 함정과 규칙**이다. 모르면 같은 곳에 다시 빠진다.

### 자산_1 - `.elf` 바이트 비교의 함정 2건

**이 프로젝트에서 «줄이 밀리면 `.text` 가 거의 항상 바뀐다.**

```c
util/tdc_printf.h:36
  tdc_printf_file_func_line(__SHORT_FILE__, __func__, __LINE__);
```

**`TDC_PRINTF_E` 가 `__LINE__` 을 품는다.** 소스에서 `grep __LINE__` 을 해도 **보이지 않는다**. 주석 6줄만 넣어도 그 뒤 `TDC_PRINTF_E` 개수만큼 즉치가 바뀐다(실측 — `.text` 11바이트).

> [!CAUTION]
> **2026-08-06 정정 — 원래 «모든 `TDC_PRINTF_*`» 라고 적었으나 틀렸다.** `__LINE__` 을 품는 것은 **`TDC_PRINTF_E` 하나뿐**이다.
>
> | 매크로 | 정의 | `__LINE__` |
> |---|---|---|
> | **`TDC_PRINTF_E`** (`:35~37`) | `tdc_printf_file_func_line(...__LINE__);` + `SEGGER_RTT_printf(...)` | **품는다** |
> | `TDC_PRINTF_W`·`_I`·`_D`·`_V` (`:43`·`:49`·`:55`·`:61`) | `SEGGER_RTT_printf(...)` 뿐 | **없다** |
>
> **`.text` 변화를 셀 때 `grep -c "TDC_PRINTF_"` 가 아니라 `grep -c "TDC_PRINTF_E"` + 명시 `__LINE__` 을 센다.**
>
> [map_live 죽은 코드 제거](../tasks/isd/20260806_1450_live-dead-code-removal/구현-검증.md) 에서 드러났다 — 12바이트를 예측했는데 8이 나왔고, «적게 나왔으니 다행» 으로 넘기지 않고 파고들어 찾았다. 진짜 운반체만 세니 8개 → 8바이트로 정확히 맞았다.

또 `main.c:115` 의 `__DATE__` 가 빌드 날짜를 문자열로 박으므로 **날짜 경계를 넘겨 빌드하면 그것만으로 1바이트가 달라진다**(실측 — `Aug  5` → `Aug  6`).

| 상황 | 대응 |
|---|---|
| «바이트 동일» 주장 | **`cmp -l` 전수 비교.** 디스어셈블리에서 즉치 하나 찾은 것으로는 부족 |
| 줄 수가 바뀌는 편집 | `.text` 변화를 **예상해야 한다** |
| 줄 수 보존 가능한 편집 | 보존하면 문제를 통째로 피한다 (이월_2 커밋_1 이 그렇게 했다) |
| 소량 바이트 어긋남 | **`__DATE__` 를 먼저 의심** |

### 자산_2 - 순수 개명·승격의 진짜 불변량

**«`.elf` md5» 가 아니라 «로드 섹션(`.text`/`.data`) 바이트 동일»** 이다. md5 는 심볼 이름 변경(맹글링 접미사 `.5` → 없음)에 민감해 **과잉 검출**한다.

깨졌을 때 진단 순서: `nm -n` 으로 주소 대조 → `objcopy -j .text -O binary` 로 내용 대조.

### 자산_3 - 이월 항목의 전제는 착수 시점에 자주 뒤집힌다

이번 세션에만 **3회**.

| 이월 | 등록 문구 | 실제 |
|---|---|---|
| 이월_2 | `fetch_packet` 약 1,340줄 | **두 함수** (파싱 570 + 실행 752) |
| 이월_C | 명령별 «분해» 필요 | **이미 분해돼 있었다.** 남은 건 네이밍 |

**등록은 그 시점의 관찰이다. 착수 전 실측이 원칙이다.**

### 자산_4 - `static` 위험은 «개수» 가 아니라 «`switch` 안/밖»

리모콘 `static` 5개 중 실질 위험은 **2개**였다. `step()` 의 셋은 전부 디스패치 **이전** 구간이라 case 를 빼도 본체에 남는다.

그리고 **접근자는 파일 분할 시에만 필요하다.** 단계_1b 가 접근자를 만든 것은 파일을 나눴기 때문이지 함수를 뺐기 때문이 아니다. 이 구분을 못 하면 하지 않아도 될 작업을 한다.

### 자산_5 - 기계 추출은 «패턴에 맞는 것» 만 처리한다

스크립트로 570줄을 옮기면 실수가 없지만, **패턴에 안 맞는 예외가 조용히 빠진다.**

| 사례 | 누락 |
|---|---|
| 이월_F | 0x64 경계 케이스 4건 |
| 이월_2 | 0x40 (case 가 아니라 게이트 밖 `if`) |

**계획 목록과 결과물을 항목 단위로 대조하는 절차가 필요하다.** 두 작업 연속 재발했다.

### 자산_6 - 검증 도구의 실패 모드는 «틀린 값» 이 아니라 «매번 다른 방식»

거짓 판정 2건이 전부 패턴 불일치였다(주석 속 `case` · `#include` 줄). `tests/metrics.sh` 가 그 방식을 코드로 고정한다.

```sh
bash tests/metrics.sh --save <이름> <파일>    # 변경 전
bash tests/metrics.sh --diff <이름> <파일>    # 변경 후 (달라지면 exit 1)
bash tests/metrics.sh --func <함수명> <파일>   # 함수 범위만
```

**한계도 함께 적혀 있다** — 매크로 안의 분기는 못 세고, 지표 불변은 필요조건일 뿐이다.

### 자산_7 - 테스트 선행이 미문서화 동작을 잡는다

리모콘 안전망을 먼저 깔았더니 **분해 전에** 2건이 드러났다.

1. 패스키 미인증 시 조용한 무시가 아니라 `en__NO_SECURITY` 에러 후 명령 해제
2. `fetch_packet:74` 의 «이전 명령 미완료» 가드가 주석과 달리 **직전 명령까지 IDLE 로 지우고** `data[]` 는 새 패킷으로 덮는다

**둘째는 분해하면서 거의 확실히 놓쳤을 동작이다.**

### 자산_8 - 호스트 컴파일 장벽은 «의존이 많아서» 가 아니라 «헤더 한 줄»

`ble/remote/` 가 호스트에서 안 되던 원인은 include 21개가 아니라 SDK `ff.h:38` 의 `#if defined(_WIN32)` 가지 하나였다. **오류 메시지의 include 사슬을 끝까지 따라가면 절단점이 나온다.**

`tests/unit/` 의 shim 3개(`tdc_fs_event_log.h` · `tdc_hal_timer.h` · `tdc_fs_stim_mute.h`)가 그 사슬을 끊는다. `src/` 는 무변경이다.

### 자산_9 - `git add` 는 파일 단위로만

디렉터리(`git add src/`)로 주다 은수님 로컬 파일이 **두 번** 섞였다. 둘 다 되돌렸지만 절차로 지키려다 두 번 어겼다. **이제 pre-commit 훅이 막는다**(`--no-verify` 로만 우회 가능).

## 5. 내가 더 할 수 있는 것 (권하지 않음)

**리모콘 파일 분할**(1,621줄 → 명령 그룹별)은 코드 변경이라 **실기 대기가 6건으로 는다.** 이미 5건이라 문제 발생 시 원인을 좁히기 어려워진다. **실기를 한 번 몰아서 한 뒤가 안전하다.**

## 6. 다음 세션 권장 순서

1. 루트 헌법 `E:\workspace\rules\CLAUDE.md` 명시 Read
2. **[`상시 점검 대장.md`](../상시%20점검%20대장.md) Read → §1 알림_2 상태 확인 → 첫 응답에 보고**
3. 이 문서 (특히 **§3 자산**)
4. `bash tests/unit/run.sh` 로 현재 상태 확인 (**431 PASS** 여야 정상)
5. 은수님께 실기 가능 여부 확인 → 가능하면 §4.1 순서대로
6. 실기 불가면 §4 의 결정 사안 중 무엇을 진행할지 확인

## 7. 불가침 (누적)

| 항목 | 이유 |
|---|---|
| `tdc_ble_cmd_0xNN[_subMM_idxKK]_<이름>` 계층 네이밍 | `grep "0xNN_"` 로 명령 전체를 훑는다 |
| **리모콘은 층 구분자 `_parse_`/`_step_`** (신규) | 같은 명령이 파싱·실행 두 층에 모두 있다 |
| 테이블 주도 재도입 금지 | 기준은 **사람이 눈으로 보고 관리하기 쉬운가** |
| 과분해 금지 | 4줄 위임을 함수로 빼면 «한 줄을 감싼 한 줄 함수» |
| 방어 위치 — **자극은 `isd/`, 측정은 파싱** (정정) | 계열 취향이 아니라 **검증 가능한 위치**와 **정상 입력 여부**로 갈린다 |
| `tests/unit/` 의 `src/` 무변경 | shim 은 `tests/unit/` 안에서만 |
| 은수님 로컬 파일 미커밋 | 이제 훅이 강제 |
| BLE 프로토콜 정의 · 공유 ABI · `sections.ld` | 기존 |
