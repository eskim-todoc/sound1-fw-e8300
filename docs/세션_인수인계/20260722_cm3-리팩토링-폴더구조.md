## 4. 검증 노하우 (이 세션의 최대 자산)

작업 문서에 흩어져 있는 것을 모았다. **다음 작업에서 그대로 재사용할 것.**

### 노하우_1 — 사장 코드는 링크 레벨로 판정한다

소스 grep 은 `#if 0` · 비활성 전처리 분기 안의 호출을 "사용 중"으로 오판한다. drv 정리에서 **grep 은 5개 드라이버 전부 사용 중이라 했으나 실제로는 1개만 살아 있었다.**

```sh
# 전 소스 컴파일 후 미정의 참조로 호출 관계 확정
arm-none-eabi-gcc -c ... -o x.o
arm-none-eabi-nm -u x.o          # 누가 무엇을 부르는가
arm-none-eabi-nm --defined-only  # 무엇이 실제로 제공되는가
```

툴체인 경로: `C:\Program Files (x86)\ON Semiconductor\Ezairo 8300 SDK\arm_tools\bin\`

### 노하우_2 — 동작 보존은 전처리·기계어로 실증한다

"논리적으로 안 바뀐다"보다 강한 증거를 만들 수 있다. 작업 전 트리를 `git worktree` 로 꺼내 동일 조건으로 컴파일해 대조한다.

| 강도 | 방법 | 판정 |
|---|---|---|
| 중 | `gcc -E` 전처리 산출물 diff | board 정리에서 **69파일 차이 0** |
| **강** | `.o` 심볼 테이블 + `size` 대조 | drv 정리에서 **68 오브젝트 기계어 완전 동일** |

### 노하우_3 — `__FILE__` 이 비교를 오염시킨다

두 트리를 **다른 경로**에 두고 산출물을 비교하면, 로그 매크로가 박는 `__FILE__` 문자열이 `.rodata` 를 경로 길이만큼 부풀린다. drv 정리에서 **건드리지도 않은 21개 파일이 일률적으로 48바이트씩** 줄어 한참 헤맸다(워크트리 경로가 정확히 48자 더 길었다).

```sh
-fmacro-prefix-map=<소스루트>/=      # 컴파일 시
sed -E 's#[^"]*src/2__cm3/source/##g' # 전처리 산출물 비교 시
```

> **단서**: 무관한 파일까지 **균일한 크기**로 변하면 코드 변경이 아니라 **빌드 환경 차이**를 의심하라.

### 노하우_4 — 자동 검증의 "차이 발생"은 먼저 도구를 의심한다

이 세션에서 자동 검증이 이상을 보고한 **5번 중 5번이 검증 도구 자체의 결함**이었다.

| 사례 | 진짜 원인 |
|---|---|
| `.cproject` 제거 5건 ≠ 예상 3건 | 문자열 **부분 매칭** — `Gen1_5` 패턴이 `Gen1_5/SEGGER_RTT` 까지 삼킴 |
| 전처리 diff "차이 발생" | `-I lib/tiny-AES-c` 누락으로 산출물이 비었는데 `2>/dev/null` 로 오류를 가림 |
| 전처리 diff 6파일 차이 | `__FILE__` 경로 정규화 패턴이 Windows 형식(`C:/...`)을 못 잡음 |
| 코드 크기 21파일 감소 | 노하우_3 |
| 심볼 방어검사 5종 경보 | 사용처가 전부 주석 코드 / 이미 미정의 |

**대응**: ① 제거·치환은 **정확 일치**로 판정 ② **예상 건수와 실제 건수를 대조** ③ stderr 를 가리지 말 것.

### 노하우_5 — Eclipse CDT 의 결속 지점

| 항목 | 주의 |
|---|---|
| include 경로 | **도구마다 독립**. `.c/.h` 는 *Cross ARM C Compiler*, **`.S/.s` 는 *Cross ARM GCC*(어셈블러)**. 후자를 놓쳐 빌드가 깨진 적 있음 |
| `<>` 전환의 함정 | `""` 는 **자기 파일 디렉터리를 먼저** 탐색한다. `<>` 로 바꾸면 그 폴백이 사라지므로 **반드시 `-I` 등록**해야 한다 |
| `sourceEntries` | `name="source"` 단일 entry. 새 폴더는 자동 포함되지만 **`-I` 는 수동 등록 필요** |
| 파일 삭제·이동 후 | **F5 Refresh** 필수. `.cproject` 변경 시엔 **Clean + Index Rebuild** 까지 |
| stale 인덱스 | 같은 심볼이 상대/절대 두 경로로 보이면 인덱스 문제다. Index Rebuild 로 해소 |

### 노하우_6 — 인코딩 (프로젝트 고유 함정)

소스 주석에 **CP949 비호환 문자 금지**(`—` `–` `≈` `µ` `►`). Eclipse clang-format 플러그인이 UTF-8→CP949→UTF-8 왕복을 시켜 **파일은 UTF-8 인 채 해당 문자만 `?` 로 죽는다**. `.githooks/pre-commit` 이 차단하지만 애초에 쓰지 않는 게 답. 한글·`·`·`→`·`×` 는 안전.
